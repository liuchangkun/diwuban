# 知识管理系统方案

> **目标**: 建立多层次知识管理体系,减少重复学习成本,提升 AI 助手工作效率,节省 tokens

---

## 📊 现状分析

### 当前痛点
1. **重复读取代码**: 每次对话都需要重新读取相同文件,浪费 tokens
2. **上下文丢失**: 会话结束后,学到的知识无法持久化
3. **文档分散**: 规范/架构/业务知识散落在多个文档中
4. **搜索低效**: 缺少结构化索引,难以快速定位信息

### 期望目标
- ✅ 减少 70% 以上的代码重复读取
- ✅ 跨会话保留关键决策和经验
- ✅ 5秒内定位到任意知识点
- ✅ 自动更新知识库,无需手动维护

## 🧠 L2: 动态记忆层

### 方案A: 使用 MCP Memory工具 (推荐)

#### 优势
- ✅ 原生支持知识图谱
- ✅ 跨会话持久化
- ✅ 语义搜索能力强
- ✅ 无需额外开发

#### 使用策略
```
实体类型 (Entities):
- 模块 (Module): app.services.calculation
- 函数 (Function): calculate_efficiency
- 配置 (Config): database.pool.max_size
- 决策 (Decision): ADR-2025-001
- 阈值 (Threshold): pump_efficiency_min=0.3
- 约定 (Convention): SQL参数化规则

关系类型 (Relations):
- depends_on: 模块A 依赖 模块B
- configures: 配置项 控制 功能
- fixes: 修复 解决 BUG
- implements: 函数 实现 算法
- validates: 验证器 检查 指标
```

#### 典型用例
```python
# 记录关键阈值
memory.create_entities([
    {"name": "pump_efficiency_threshold", "type": "Threshold", "value": "0.30"}
])

# 记录模块依赖
memory.create_relations([
    {
        "from": "calculation.pump_efficiency",
        "to": "calculation.pump_head",
        "type": "depends_on"
    }
])

# 快速检索
results = memory.search_nodes("泵效率计算依赖哪些模块")
```

## 🔍 L3: 实时索引层

### 核心需求
- 快速定位文件/函数/类
- 避免全文搜索浪费 tokens
- 支持模糊匹配

### 方案: 代码映射文件

#### 结构设计
```json
// docs/.code-index.json (自动生成,不手动编辑)
{
  "version": "1.0",
  "generated_at": "2025-12-16T14:00:00Z",
  "modules": {
    "app.services.calculation": {
      "path": "app/services/calculation/__init__.py",
      "functions": ["get_calculator", "register_metric"],
      "classes": [],
      "dependencies": ["app.adapters.db", "app.core.config"]
    },
    "app.services.calculation.metrics.pump_efficiency": {
      "path": "app/services/calculation/metrics/pump_efficiency/calculator.py",
      "functions": ["calculate"],
      "classes": ["PumpEfficiencyCalculator"],
      "key_concepts": ["效率计算", "hydraulic_power", "shaft_power"]
    }
  },
  "apis": {
    "calculate_efficiency": {
      "module": "app.services.calculation.metrics.pump_efficiency",
      "signature": "(flow: float, head: float, power: float) -> dict",
      "doc": "计算泵效率,返回效率值和质量等级"
    }
  },
  "configs": {
    "database.pool.max_size": {
      "file": "configs/database.yaml",
      "default": 10,
      "description": "数据库连接池最大连接数"
    }
  }
}
```

#### 自动生成脚本
```python
# scripts/tools/gen_code_index.py
"""
遍历 app/ 目录:
1. 使用 ast 解析 Python 文件
2. 提取函数/类签名
3. 分析 import 依赖
4. 生成 JSON 索引文件
"""
```

#### 使用方式
```python
# AI助手可以直接读取索引,而不是扫描文件
index = json.load(open("docs/.code-index.json"))
target = index["apis"]["calculate_efficiency"]
# 直接定位到 app/services/calculation/metrics/pump_efficiency/calculator.py
```

## 🔄 知识更新流程

### 自动触发机制

```
代码提交 (git commit)
    ↓
pre-commit hook
    ↓
┌───────────────────────────────────────┐
│ 1. 扫描变更文件 (git diff)           │
│ 2. 识别变更类型                       │
│ 3. 更新对应知识层                     │
│    - L1: 检查是否需要更新文档         │
│    - L2: 自动添加 PLAYBOOKS 条目      │
│    - L3: 重新生成代码索引             │
└───────────────────────────────────────┘
    ↓
提交成功 ✅
```

### 实施脚本
```bash
# .git/hooks/post-commit
#!/bin/bash
python scripts/tools/update_knowledge_system.py
```
