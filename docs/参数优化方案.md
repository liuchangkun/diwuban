# 泵参数优化方案

## 📊 问题分析

### 当前问题
1. **计算的泵出口压力偏高 120-180%**
   - 实测总管出口压力：0.42 MPa
   - 计算的泵出口压力：0.94-1.20 MPa
   - 误差：+120% ~ +180%

2. **根本原因**
   - 没有泵的特性曲线（扬程-流量关系）
   - 参数（K_eq, L_offset, pipe_diameter）可能不准确
   - 计算公式可能存在问题

### 可用的实测数据
- ✅ **总管出口压力**（main_pipeline_outlet_pressure）：设备7，实测传感器
- ✅ **水池液位**（pool_liquid_level）：设备8，实测传感器
- ✅ **泵流量**（pump_flow_rate）：设备1-6，实测传感器
- ✅ **泵运行状态**（running）：设备1-6，实测传感器

## 🎯 优化方案

### 方案1：基于物理约束的参数校准（推荐）

**核心思路**：
- 利用实测总管出口压力作为校准基准
- 物理约束：总管出口压力 ≈ MAX(各泵出口压力)（并联系统）
- 反推泵的扬程和入口压力参数

**优化步骤**：

#### 步骤1：简化计算模型

当前模型过于复杂，存在循环依赖。简化为：

```
1. 泵入口压力（pump_inlet_pressure）：
   P_in = P_atm + ρ×g×pool_liquid_level / 1e6
   （忽略管道损失，因为水池在泵上方，静压头占主导）

2. 泵扬程（pump_head）：
   从实测总管出口压力反推：
   H = (P_main_out - P_in) × 1e6 / (ρ×g)

3. 泵出口压力（pump_outlet_pressure）：
   P_out = P_in + ρ×g×H / 1e6 = P_main_out
```

**优点**：
- 简单直接，避免循环依赖
- 利用实测数据，精度高
- 不需要特性曲线

**缺点**：
- 假设所有泵的出口压力相同（并联系统的近似）
- 忽略了管道损失

#### 步骤2：建立扬程-流量经验模型

使用实测数据拟合扬程-流量关系：

```python
# 从实测数据反推扬程
H_measured = (P_main_out - P_in) × 1e6 / (ρ×g)

# 拟合扬程-流量关系（二次多项式）
H = a + b×Q + c×Q²

# 或者使用分段线性模型
if Q < Q1:
    H = H0
elif Q < Q2:
    H = H0 - k1×(Q - Q1)
else:
    H = H0 - k1×(Q1 - Q1) - k2×(Q - Q2)
```

**优点**：
- 基于实测数据，准确性高
- 可以捕捉非线性关系
- 可以用于预测

**缺点**：
- 需要足够的数据覆盖不同工况
- 可能存在过拟合

### 方案2：机器学习参数优化

**核心思路**：
- 使用优化算法（如遗传算法、粒子群优化、差分进化）
- 目标函数：最小化计算值与实测值的误差
- 优化参数：K_eq, L_offset, pipe_diameter, 扬程曲线参数

**优化目标**：
```
minimize: RMSE = sqrt(mean((P_main_out_measured - P_main_out_calculated)²))
```

**约束条件**：
```
0.5 ≤ K_eq ≤ 10.0        # 等效损失系数
1.0 ≤ L_offset ≤ 5.0     # 垂直距离 (m)
0.2 ≤ pipe_diameter ≤ 0.5  # 管道直径 (m)
50 ≤ H_a ≤ 150           # 扬程曲线参数
0 ≤ H_b ≤ 0.01           # 扬程曲线参数
```

**实现**：
- 已提供脚本：`scripts/python/optimize_pump_parameters.py`
- 使用 scipy.optimize.differential_evolution 进行全局优化

**优点**：
- 自动优化，无需人工调参
- 可以同时优化多个参数
- 可以找到全局最优解

**缺点**：
- 计算量大，耗时长
- 可能陷入局部最优
- 需要合理设置参数边界

### 方案3：分段校准（最实用）

**核心思路**：
- 将工况分为几个典型区间（低流量、中流量、高流量）
- 每个区间使用不同的参数或修正系数
- 基于实测数据进行分段校准

**实施步骤**：

#### 步骤1：工况分类
```python
# 根据流量分类
if Q < 500:
    工况 = "低流量"
elif Q < 1500:
    工况 = "中流量"
else:
    工况 = "高流量"
```

#### 步骤2：分段校准参数
```python
# 低流量工况
if 工况 == "低流量":
    K_eq = 1.0
    correction_factor = 0.4  # 修正系数

# 中流量工况
elif 工况 == "中流量":
    K_eq = 3.0
    correction_factor = 0.45

# 高流量工况
else:
    K_eq = 5.0
    correction_factor = 0.5
```

#### 步骤3：应用修正系数
```python
# 计算基础扬程
H_base = (P_main_out - P_in) × 1e6 / (ρ×g)

# 应用修正系数
H_corrected = H_base × correction_factor

# 计算泵出口压力
P_out = P_in + ρ×g×H_corrected / 1e6
```

**优点**：
- 简单实用，易于实施
- 可以针对不同工况优化
- 计算量小

**缺点**：
- 需要人工设置分段点
- 分段边界可能不连续

## 🚀 推荐实施路径

### 阶段1：快速修复（1-2天）

1. **简化计算模型**
   - 修改 pump_inlet_pressure：忽略管道损失
   - 修改 pump_head：从实测总管出口压力反推
   - 修改 pump_outlet_pressure：使用总管出口压力代替

2. **验证修复效果**
   - 对比修复前后的误差
   - 确认误差降低到可接受范围（< 10%）

### 阶段2：参数优化（3-5天）

1. **建立扬程-流量经验模型**
   - 收集不同工况的数据
   - 拟合扬程-流量关系
   - 验证模型精度

2. **分段校准**
   - 识别典型工况
   - 为每个工况设置参数
   - 验证校准效果

### 阶段3：持续优化（长期）

1. **数据驱动的参数更新**
   - 定期使用新数据重新校准
   - 监控计算精度
   - 自动调整参数

2. **异常检测和告警**
   - 监控计算误差
   - 识别异常工况
   - 触发重新校准
