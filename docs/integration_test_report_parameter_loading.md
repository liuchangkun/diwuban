## 🐛 发现的问题和修复

### 问题1: Decimal 类型转换

**问题描述**: 数据库返回的参数值是 `decimal.Decimal` 类型，直接与 float 进行运算会抛出 `TypeError`

**错误信息**:
```
TypeError: unsupported operand type(s) for -: 'decimal.Decimal' and 'float'
```

**修复方案**: 在测试代码中使用 `float()` 转换 Decimal 类型

**修复位置**:
- `test_scenario_1_full_prepare_and_run_flow` 第137行
- `test_scenario_2_parameter_update_takes_effect` 第231行

**状态**: ✅ 已修复

---

### 问题2: 计算函数提前返回

**问题描述**: 场景5中，计算函数没有抛出预期的 `ValueError`，因为测试数据缺少必需的输入字段

**原因**: `calculate_pump_inlet_pressure_method_b` 函数在第66行检查 `pool_liquid_level` 是否存在，如果不存在则提前返回空数组，不会执行到参数检查代码

**修复方案**: 修改测试数据，提供 `pool_liquid_level` 字段

**修复前**:
```python
data = {
    'pump_outlet_pressure': np.array([0.5, 0.6, 0.7]),
    'pump_head': np.array([50.0, 55.0, 60.0])
}
```

**修复后**:
```python
data = {
    'pool_liquid_level': np.array([5.0, 6.0, 7.0])  # 水池液位（m）
}
```

**状态**: ✅ 已修复
