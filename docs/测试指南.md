## 记忆更新自检（对话收尾自动执行）
- 目标：无需守护进程；每轮对话结束前由助手自动执行一次“更新PLAYBOOKS”。也支持手动命令。
- 手动验证（可选）：
  1) 在 app/*.py、scripts/sql/*.sql、configs/*.yaml|yml|json 做一个小改动并保存。
  2) 正常结束对话（无需任何口令）。
  3) 检查：
     - `docs/PLAYBOOKS/对话记忆.md` 出现“当轮对话摘要”。
     - 相关目标文档出现本次条目（如 改进与优化记录.md/数据库变更记录.md/配置变更记录.md）。
     - `docs/PLAYBOOKS/INDEX.md` 的 MEMORY_AUTO 区块“生成时间”已更新。
- 手动运行命令：`python scripts/dev/scan_changes_and_update_memory.py`
- 降噪与规则：忽略 docs/** 人为文档编辑与系统输出目录；数据库变更双写；严格识别“决策/修复”；记录新增与删除并标注兼容性/迁移/回滚。

## 乱码清理与预防
- 现象：`对话记忆.md` 中出现形如 `"\344\270\252..."` 的条目（多为中文路径被转义）。
- 根因：Git 在 Windows 默认 `core.quotepath=true` 会将非 ASCII 路径转义；再叠加代码页差异导致写入“乱码串”。
- 一次性清理：
  - 执行：`python scripts/dev/cleanup_dialog_memory.py`
  - 效果：移除历史乱码行，并自动刷新 MEMORY_AUTO。
- 预防措施（脚本已内置）：
  - 变更扫描脚本已强制 `git -c core.quotepath=false`，并采用“优先 UTF-8，失败回退系统编码”的解码策略。
  - 可选的仓库级设置（非必须）：`git config core.quotepath false`。
