# 缺失指标计算修复任务文档

## 📋 任务背景

### 问题概述
历史数据计算流程存在严重的指标缺失问题，导致大量指标无法计算：
- **时间范围**：2025-05-31 18:00:00 至 19:59:59（2小时，UTC时区）
- **影响设备**：55台设备
- **数据规模**：515,355条原始测量数据
- **计算成功率**：仅2.5%（约54,555 / 2,340,000条预期指标）
- **核心问题**：pump_inlet_pressure 缺少计算方法，导致依赖链断裂

### 任务目标
1. ✅ 完成数据库表结构全面调研（25个相关表）
2. ✅ 识别代码与数据库一致性问题（9个问题）
3. 🔄 制定详细的修复方案（按优先级分为4级）
4. ⏳ 执行修复并验证结果
5. ⏳ 生成验证报告和遗留问题清单
