#### 风险1：参数优先级冲突

**原风险描述**：设备额定参数可能覆盖计算参数

**原缓解措施**：
- 确保参数加载顺序正确：全局 → 额定 → 设备级
- 添加日志记录参数来源

**✅ 补充具体解决方案**：

**1. 参数冲突检测逻辑**
```python
def detect_parameter_conflicts(
    global_params: Dict[str, float],
    rated_params: Dict[str, float],
    station_params: Dict[str, float],
    device_params: Dict[str, float]
) -> List[Dict[str, Any]]:
    """检测参数冲突"""
    conflicts = []
    
    all_keys = set(global_params.keys()) | set(rated_params.keys()) | \
               set(station_params.keys()) | set(device_params.keys())
    
    for key in all_keys:
        sources = []
        values = []
        
        if key in global_params:
            sources.append('global')
            values.append(global_params[key])
        if key in rated_params:
            sources.append('rated')
            values.append(rated_params[key])
        if key in station_params:
            sources.append('station')
            values.append(station_params[key])
        if key in device_params:
            sources.append('device')
            values.append(device_params[key])
        
        # 如果有多个来源且值不同，记录冲突
        if len(sources) > 1 and len(set(values)) > 1:
            conflicts.append({
                'param_name': key,
                'sources': sources,
                'values': dict(zip(sources, values)),
                'final_value': values[-1],  # 最高优先级的值
                'final_source': sources[-1]
            })
    
    return conflicts
```

**2. 冲突解决策略**
- **策略A（推荐）**：使用最高优先级的值，记录警告日志
- **策略B**：如果差异超过阈值（如>20%），拒绝加载并要求人工确认
- **策略C**：创建参数冲突审计表，记录所有冲突供后续分析

**3. 验证方法**
```python
# 测试用例

    rated_params = {'rho': 998.0}  # 冲突！

- 如果冲突检测导致问题，可以禁用冲突检测功能

def load_parameters(self, device_id: int, method_id: str) -> Dict[str, Any]:
    """加载参数（支持多种类型）"""
    query = """
        SELECT param_name, param_value, param_value_text, param_type
        FROM calculation_parameters
        WHERE method_id = %s
    """
    cur.execute(query, (method_id,))
    
    params = {}
    for row in cur.fetchall():
        param_name, param_value, param_value_text, param_type = row
        
        if param_type == 'numeric':
            params[param_name] = float(param_value)
        elif param_type == 'text':
            params[param_name] = param_value_text
        elif param_type == 'boolean':
            params[param_name] = bool(param_value)
        elif param_type == 'json':
            params[param_name] = json.loads(param_value_text)
    
    return params
```
