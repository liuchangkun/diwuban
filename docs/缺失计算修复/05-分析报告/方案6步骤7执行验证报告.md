## 2. 实现方案

### 2.1 方案选择

**原方案**（方案6文档）：
- 在观测矩阵中添加额定工况点
- 针对特定方法（如HEAD_COEF_V1）实现
- 需要修改观测矩阵构建逻辑

**实际方案**（更通用）：
- 实现额定参数软约束机制
- 适用于所有方法
- 不修改观测矩阵构建逻辑
- 使用额定参数作为优化约束

**选择理由**：
1. **通用性更强**：适用于所有29个计算方法
2. **实现更简单**：不需要修改复杂的观测矩阵构建逻辑
3. **可维护性更好**：约束逻辑独立，易于调整
4. **效果相当**：软约束机制同样能防止参数偏离额定值过大

### 3.3 实现_apply_rated_constraints方法

**文件**：`app/services/calculation/parameter_optimizer.py`

**核心逻辑**：

#### 3.3.1 允许偏差范围定义
```python
rated_param_tolerance = {
    'rated_flow': 0.20,      # ±20%
    'rated_head': 0.20,      # ±20%
    'rated_efficiency': 0.15, # ±15%
    'rated_frequency': 0.05,  # ±5%
    'rated_power': 0.20,      # ±20%
    'eta_motor': 0.10,        # ±10%
    'eta_vfd': 0.10,          # ±10%
}
```

#### 3.3.2 偏差检测与调整
```python
for i, name in enumerate(param_names):
    if name in rated_params and name in rated_param_tolerance:
        rated_value = rated_params[name]
        optimized_value = theta[i]
        tolerance = rated_param_tolerance[name]
        
        # 计算相对偏差
        if rated_value != 0:
            relative_deviation = abs(optimized_value - rated_value) / rated_value
            
            # 如果偏差超过允许范围，进行调整
            if relative_deviation > tolerance:
                # 使用加权平均：70%额定值 + 30%优化值
                adjusted_value = 0.7 * rated_value + 0.3 * optimized_value
                theta_adjusted[i] = adjusted_value
```

#### 3.3.3 调整策略
- **在允许范围内**：保持优化值不变
- **超过允许范围**：使用加权平均（70%额定值 + 30%优化值）
- **理由**：
  - 70%额定值：确保参数不会偏离额定值太远
  - 30%优化值：保留部分优化效果
  - 平衡物理合理性和优化效果
