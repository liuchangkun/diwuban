### ✅ 问题4.1：精度等级设置不合理

**修复时间**：2025-10-26 18:45:00 - 18:50:00

#### 问题分析

**问题描述**：
- `main_pipeline_inlet_pressure_method_c` 的 `accuracy_level='medium'`
- 但 method_c 使用多个泵的平均值，理论上精度应该高于 method_a（单个泵的值）

**影响范围**：
- 方法选择时可能优先选择精度较低的方法
- 影响计算结果的整体精度

**严重程度**：⚪ 轻微（影响有限，但应修正以保持逻辑一致性）

#### 修复方案

**SQL脚本**：`migrations/fix_accuracy_level_method_c.sql`

```sql
-- 提升 method_c 的精度等级从 medium 到 high
UPDATE calculation_method_registry
SET accuracy_level = 'high',
    updated_at = NOW()
WHERE method_id = 'main_pipeline_inlet_pressure_method_c'
  AND metric_key = 'main_pipeline_inlet_pressure';
```

**修复理由**：
- method_c 使用多个泵的平均值，比单个泵的值更稳定
- 平均值可以减少单个泵的测量误差
- 精度应该高于 method_a（单个泵的值）
