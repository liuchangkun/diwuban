- 提高计算精度

**需要的数据**：

每个设备需要以下额定参数（从设备铭牌或技术文档获取）：

| 参数名 | 说明 | 单位 | 示例值 |
|-------|------|------|--------|
| rated_flow | 额定流量 | m³/h | 400.0 |
| rated_head | 额定扬程 | m | 50.0 |
| rated_efficiency | 额定效率 | - | 0.75 |
| rated_frequency | 额定频率 | Hz | 50.0 |
| rated_power | 额定功率 | kW | 75.0 |
| eta_motor | 电机效率 | - | 0.92 |
| eta_vfd | 变频器效率 | - | 0.97 |

**数据录入SQL模板**：

```sql
-- 示例：为设备129录入实际额定参数
INSERT INTO device_rated_params (
    device_id, param_name, param_value, 
    confidence_score, updated_by, updated_at
) VALUES
-- 额定流量
(129, 'rated_flow', 450.0, 1.0, 'manual_data_entry', NOW()),
-- 额定扬程
(129, 'rated_head', 55.0, 1.0, 'manual_data_entry', NOW()),
-- 额定效率
(129, 'rated_efficiency', 0.78, 1.0, 'manual_data_entry', NOW()),
-- 额定频率
(129, 'rated_frequency', 50.0, 1.0, 'manual_data_entry', NOW()),
-- 额定功率
(129, 'rated_power', 80.0, 1.0, 'manual_data_entry', NOW()),
-- 电机效率
(129, 'eta_motor', 0.93, 1.0, 'manual_data_entry', NOW()),
-- 变频器效率
(129, 'eta_vfd', 0.97, 1.0, 'manual_data_entry', NOW())
ON CONFLICT (device_id, param_name) 
DO UPDATE SET
    param_value = EXCLUDED.param_value,
    confidence_score = EXCLUDED.confidence_score,
    updated_by = EXCLUDED.updated_by,
    updated_at = EXCLUDED.updated_at;
```

**验证SQL**：

```sql
-- 查看设备129的额定参数
SELECT device_id, param_name, param_value, confidence_score, updated_by
FROM device_rated_params
WHERE device_id = 129
ORDER BY param_name;

-- 查看所有设备的额定参数统计
SELECT 
    device_id,
    COUNT(*) as param_count,
    array_agg(param_name ORDER BY param_name) as params
FROM device_rated_params
GROUP BY device_id
ORDER BY device_id;
```
