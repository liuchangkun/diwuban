## 🔍 详细问题分析

### 问题1：参数名不一致（2个方法）

#### 1.1 EFF_SIMPLE_V1 - pump_efficiency

**问题描述**：
- **数据库参数名**：`eta_motor`
- **代码使用参数名**：`eta_motor_assumed`
- **影响**：参数无法正确读取，使用默认值0.92

**代码位置**：`app/services/calculation/methods/eff_simple_v1.py:21`
```python
eta_motor = float(params.get('eta_motor_assumed', 0.92))  # ❌ 参数名错误
```

**数据库配置**：
```sql
SELECT param_name, param_value FROM calculation_parameters 
WHERE method_id = 'EFF_SIMPLE_V1' AND param_name = 'eta_motor';
-- 结果：eta_motor = 0.92
```

**修复建议**：
- **方案A**：修改代码，将 `eta_motor_assumed` 改为 `eta_motor`（推荐）
- **方案B**：修改数据库，将 `eta_motor` 改为 `eta_motor_assumed`

#### 1.2 pump_head_method_main - pump_head

**问题描述**：
- **数据库参数名**：`b_H`（未使用）
- **代码使用参数名**：`P_atm`（未配置）
- **影响**：代码使用硬编码的 P_atm=0.101325，无法从数据库读取

**代码位置**：`app/services/calculation/calculators.py:129`
```python
P_atm = float(params.get('P_atm', 0.101325))  # ❌ 数据库中未配置
```

**数据库配置**：
```sql
SELECT param_name, param_value FROM calculation_parameters 
WHERE method_id = 'pump_head_method_main';
-- 结果：rho=1000.0, g=9.80665, b_H=0.0（b_H未被使用）
```

**修复建议**：
- 在 `calculation_parameters` 表中添加 `P_atm` 参数
- 删除未使用的 `b_H` 参数
