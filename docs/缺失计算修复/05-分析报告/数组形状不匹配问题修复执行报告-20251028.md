**文件**: `app/services/calculation/methods/eff_simple_v1.py`  
**位置**: Lines 18-29  
**修改内容**:

```python
def nz(x):
    """对齐数组长度到 n，处理不同长度的输入数组"""
    if not isinstance(x, np.ndarray):
        return np.full(n, np.nan)
    if len(x) != n:
        # 数组长度不一致时，对齐到 n
        aligned = np.full(n, np.nan)
        copy_len = min(len(x), n)
        aligned[:copy_len] = x[:copy_len]
        return aligned
    return x
```

**修复原因**: 原始 `nz()` 函数在数组长度不一致时直接返回原始数组，导致后续运算时数组长度不匹配。
