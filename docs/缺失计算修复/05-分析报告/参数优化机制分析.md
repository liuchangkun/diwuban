## 🔧 参数优化器工作原理

### 核心算法：RLS（递归最小二乘法）

**算法简介**：
- **全称**：Recursive Least Squares（递归最小二乘法）
- **用途**：在线参数估计，适用于实时数据流
- **优势**：
  - 不需要存储所有历史数据
  - 计算效率高（O(n²)，n为参数数量）
  - 支持遗忘因子（对旧数据降权）

**更新公式**：
```
1. 增益矩阵：K(k) = P(k-1)φ(k) / [λ + φ(k)ᵀP(k-1)φ(k)]
2. 参数更新：θ(k) = θ(k-1) + K(k)[y(k) - φ(k)ᵀθ(k-1)]
3. 协方差更新：P(k) = [P(k-1) - K(k)φ(k)ᵀP(k-1)] / λ
```

其中：
- θ：参数向量
- φ：观测向量（输入特征）
- y：输出值（目标值）
- P：协方差矩阵（参数不确定性）
- λ：遗忘因子（0 < λ ≤ 1）

**遗忘因子**：
- λ = 1：标准RLS，所有数据权重相同
- λ < 1：指数遗忘RLS，旧数据权重衰减
- 推荐值：0.95-0.99
- 当前设置：0.98（在初始化时设置）

def _apply_constraints(
    self,
    theta: np.ndarray,
    param_names: List[str],
    param_bounds: Dict[str, Tuple[float, float]]
) -> np.ndarray:
    """应用参数约束"""

## 🔗 参数优化与额定参数的关联

### 当前状态：完全未关联

**问题**：
1. ❌ 优化器不读取设备额定参数
2. ❌ 优化时不使用额定工况点作为约束
3. ❌ 优化后不验证在额定工况点的精度
4. ❌ 优化结果可能偏离设备实际特性

**示例**：HEAD_COEF_V1的优化

**当前优化过程**：
```python
# 1. 读取历史数据（pump_flow_rate, pump_head）
measured_data = {
    'pump_flow_rate': [100, 150, 200, 250, 300, 350, 400],  # m³/h
    'pump_head': [60, 58, 55, 52, 48, 44, 40]  # m
}

# 2. 优化a0-a5系数，使拟合曲线最小化RMSE
# 没有使用额定工况点约束！

# 3. 优化结果
optimized_params = {
    'a0': 65.2,  # 可能偏离实际
    'a1': -0.0015,
    'a2': 0.0,
    ...
}

# 4. 验证：在额定工况点（rated_flow=400, rated_head=50）
H_rated = 65.2 - 0.0015 * 400 = 64.6 m  # ❌ 偏离rated_head=50m
```

**问题**：
- 优化后的曲线在额定工况点误差较大（64.6 vs 50）
- 可能在额定工况点附近精度降低
- 不符合设备实际特性

### 应该实现：使用额定参数作为约束

**改进方案**：

#### 方案1：添加额定工况点作为观测数据

**实现细节**：
```python
def _build_observation_matrix_with_rated_point(
    self,
    measured_data: Dict[str, np.ndarray],
    calculated_data: Dict[str, np.ndarray],
    rated_params: Dict[str, float],
    method_id: str
) -> Tuple[np.ndarray, np.ndarray]:
    """构建观测矩阵（包含额定工况点）"""
    
    if method_id == 'HEAD_COEF_V1':
        # 1. 从历史数据构建观测矩阵
        Q = measured_data['pump_flow_rate']
        H = calculated_data['pump_head']
        
        # 过滤有效数据
        valid = (Q > 0) & (H > 0) & ~np.isnan(Q) & ~np.isnan(H)
        Q_valid = Q[valid]
        H_valid = H[valid]
        
        # 2. 添加额定工况点（重复多次以增加权重）
        rated_flow = rated_params.get('rated_flow')
        rated_head = rated_params.get('rated_head')
        
        if rated_flow and rated_head:
            # 重复10次，增加额定工况点的权重
            Q_rated = np.full(10, rated_flow)
            H_rated = np.full(10, rated_head)
            
            Q_all = np.concatenate([Q_valid, Q_rated])
            H_all = np.concatenate([H_valid, H_rated])
        else:
            Q_all = Q_valid
            H_all = H_valid
        
        # 3. 构建观测矩阵 [1, Q, Q², Q³, Q⁴, Q⁵]
        X = np.column_stack([
            np.ones(len(Q_all)),
            Q_all,
            Q_all**2,
            Q_all**3,
            Q_all**4,
            Q_all**5
        ])
        y = H_all
        
        return X, y
```

#### 方案2：使用等式约束优化

```python
def optimize_with_equality_constraint(
    self,
    method_id: str,
    measured_data: Dict[str, np.ndarray],
    rated_params: Dict[str, float],
    current_params: Dict[str, float]
) -> Dict[str, float]:
    """
    使用等式约束优化参数
    
    约束条件：H(rated_flow) = rated_head
    """
    from scipy.optimize import minimize
    
    # 1. 定义目标函数（最小化RMSE）
    def objective(theta):
        H_pred = self._predict_head(measured_data['pump_flow_rate'], theta)
        H_true = measured_data['pump_head']
        return np.sqrt(np.mean((H_pred - H_true)**2))
    
    # 2. 定义等式约束
    def equality_constraint(theta):
        """约束：H(rated_flow) = rated_head"""
        rated_flow = rated_params['rated_flow']
        rated_head = rated_params['rated_head']
        H_at_rated = self._predict_head(np.array([rated_flow]), theta)[0]
        return H_at_rated - rated_head  # 应该等于0
    
    # 3. 优化
    from scipy.optimize import NonlinearConstraint
    constraint = NonlinearConstraint(equality_constraint, 0, 0)  # 等式约束
    
    result = minimize(
        objective,
        x0=list(current_params.values()),
        method='SLSQP',
        constraints=[constraint]
    )
    
    # 4. 返回优化后的参数
    param_names = sorted(current_params.keys())
    optimized_params = {name: result.x[i] for i, name in enumerate(param_names)}
    
    return optimized_params
```

## 📊 优化效果验证

### 当前验证方法

**指标**：
- RMSE：均方根误差
- MAE：平均绝对误差
- R²：决定系数
- MAPE：平均绝对百分比误差

**问题**：
- ⚠️ 这些指标是全局的，未单独验证额定工况点
- ⚠️ 未验证优化后的参数是否物理合理
- ⚠️ 未验证优化后的曲线是否单调（扬程应随流量增加而降低）

### 改进的验证方法

#### 1. 额定工况点误差

```python
def validate_at_rated_point(
    self,
    optimized_params: Dict[str, float],
    rated_params: Dict[str, float],
    method_id: str
) -> float:
    """验证在额定工况点的误差"""
    
    if method_id == 'HEAD_COEF_V1':
        rated_flow = rated_params['rated_flow']
        rated_head = rated_params['rated_head']
        
        # 计算在额定流量下的扬程
        a0 = optimized_params['a0']
        a1 = optimized_params['a1']
        a2 = optimized_params['a2']
        a3 = optimized_params['a3']
        a4 = optimized_params['a4']
        a5 = optimized_params['a5']
        
        H_pred = a0 + a1*rated_flow + a2*rated_flow**2 + a3*rated_flow**3 + \
                 a4*rated_flow**4 + a5*rated_flow**5
        
        # 计算相对误差
        error = abs(H_pred - rated_head) / rated_head
        
        logger.info(
            f"额定工况点验证: Q={rated_flow}, H_pred={H_pred:.2f}, "
            f"H_rated={rated_head:.2f}, error={error:.2%}"
        )
        
        return error
```

#### 2. 物理合理性验证

```python
def validate_physical_reasonableness(
    self,
    optimized_params: Dict[str, float],
    method_id: str
) -> bool:
    """验证参数的物理合理性"""
    
    if method_id == 'HEAD_COEF_V1':
        # 验证1：a0应该为正（零流量时的扬程）
        if optimized_params['a0'] <= 0:
            logger.error("a0应该为正")
            return False
        
        # 验证2：曲线应该单调递减（dH/dQ < 0）
        # 检查在多个流量点的导数
        Q_test = np.linspace(0, 500, 100)
        dH_dQ = (
            optimized_params['a1'] +
            2 * optimized_params['a2'] * Q_test +
            3 * optimized_params['a3'] * Q_test**2 +
            4 * optimized_params['a4'] * Q_test**3 +
            5 * optimized_params['a5'] * Q_test**4
        )
        
        if np.any(dH_dQ > 0):
            logger.warning("扬程曲线在某些区域不是单调递减")
            return False
        
        return True
```

## 🚀 改进方案总结

### 改进1：集成设备额定参数

**目标**：优化时使用额定参数作为约束

**实施步骤**：
1. 修改 `optimize_parameters()` 方法，添加 `rated_params` 参数
2. 在构建观测矩阵时，添加额定工况点数据
3. 增加额定工况点的权重（重复10次）
4. 验证优化后在额定工况点的精度

### 改进2：添加物理约束

**目标**：确保优化后的参数物理合理

**实施步骤**：
1. 添加等式约束：H(rated_flow) = rated_head
2. 添加不等式约束：a0 > 0, dH/dQ < 0
3. 使用约束优化算法（如SLSQP）

### 改进3：改进验证方法

**目标**：全面验证优化效果

**实施步骤**：
1. 添加额定工况点误差验证
2. 添加物理合理性验证
3. 添加曲线单调性验证
4. 记录验证结果到数据库

### 改进4：定期重新优化

**目标**：适应设备特性变化

**实施步骤**：
1. 设置优化触发条件（如每月一次，或累计1000条新数据）
2. 自动触发参数优化
3. 对比优化前后的精度
4. 如果精度提升显著（如RMSE降低10%），则更新参数
