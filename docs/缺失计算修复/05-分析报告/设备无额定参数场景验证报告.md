## 📈 技术分析

### 5层参数优先级系统的降级策略

**参数来源优先级（从低到高）**：
1. 全局计算参数（calculation_parameters, device_id=NULL, station_id=NULL）
2. **全局默认额定参数（global_default_rated_params）** ← 降级策略
3. 设备额定参数（device_rated_params, device_id=X）
4. 泵站级计算参数（calculation_parameters, station_id=X, device_id=NULL）
5. 设备级计算参数（calculation_parameters, device_id=X）

**降级机制**：
- 当设备没有额定参数时（第3层为空），系统自动使用第2层的全局默认额定参数
- 这确保了所有设备都能获得必要的额定参数
- 避免了因缺少额定参数导致的计算失败

### 系统鲁棒性提升

**容错性**：
- 设备无额定参数时，系统不会崩溃
- 自动降级到全局默认值
- 记录警告日志，便于后续补充实际额定参数

**灵活性**：
- 支持设备级、泵站级、全局级参数配置
- 支持参数的逐步完善（先用默认值，后补充实际值）
- 支持参数的动态更新

**可维护性**：
- 参数来源清晰（param_sources字典记录）
- 日志记录完整（警告日志提示使用默认值）
- 代码逻辑清晰（5层优先级系统）
