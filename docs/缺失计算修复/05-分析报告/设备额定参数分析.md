## 📊 device_rated_params 表分析

### 表结构

**实际表结构**（键值对格式）：
```sql
CREATE TABLE device_rated_params (
    id BIGSERIAL PRIMARY KEY,
    device_id BIGINT REFERENCES dim_device(device_id),
    param_key TEXT NOT NULL,        -- 参数名称（如 'rated_frequency'）
    value_numeric NUMERIC,           -- 数值型参数值
    value_text TEXT,                 -- 文本型参数值
    unit TEXT,                       -- 单位
    source TEXT,                     -- 数据来源
    effective_from TIMESTAMPTZ,      -- 生效开始时间
    effective_to TIMESTAMPTZ,        -- 生效结束时间
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

**说明**：
- 采用键值对（EAV）模式存储，每个参数一行
- 每个设备有7个参数记录（rated_frequency, poles_pair, rated_efficiency, rated_flow, rated_head, eta_motor, eta_vfd）

### 数据内容

**设备数量**：3个设备（129, 130, 131）
**参数完整性**：100%（所有设备都有完整的7个额定参数）
**总记录数**：21条（3设备 × 7参数）

**参数汇总表**（转置视图）：

| device_id | rated_frequency | poles_pair | rated_efficiency | rated_flow | rated_head | eta_motor | eta_vfd |
|-----------|----------------|------------|------------------|------------|------------|-----------|---------|
| 129 | 50 | 2 | 0.78 | 400 | 25 | 0.93 | 0.97 |
| 130 | 50 | 2 | 0.78 | 400 | 25 | 0.93 | 0.97 |
| 131 | 50 | 2 | 0.78 | 400 | 25 | 0.93 | 0.97 |

**参数说明**：
- **rated_frequency**：额定频率（50Hz），用于转速计算
- **poles_pair**：极对数（2，即4极电机），用于转速计算
- **rated_efficiency**：额定效率（0.78），用于效率计算和验证
- **rated_flow**：额定流量（400 m³/h），用于流量计算和验证
- **rated_head**：额定扬程（25 m），用于扬程计算和验证

## 🔍 当前参数加载机制分析

### load_parameters() 方法实现

**文件位置**：`app/services/calculation/orchestrator.py:682-720`

**当前实现**：
```python
def load_parameters(self, device_id: int, method_id: str) -> Dict[str, float]:
    """加载计算参数"""
    with get_connection() as conn:
        with conn.cursor() as cur:
            # 先尝试加载设备特定参数
            query = """
                SELECT param_name, param_value
                FROM calculation_parameters
                WHERE device_id = %s AND method_id = %s
            """
            cur.execute(query, (device_id, method_id))
            rows = cur.fetchall()
            
            if not rows:
                # 如果没有设备特定参数，加载全局默认参数
                query = """
                    SELECT param_name, param_value
                    FROM calculation_parameters
                    WHERE device_id IS NULL AND method_id = %s
                """
                cur.execute(query, (method_id,))
                rows = cur.fetchall()
            
            params = {row[0]: float(row[1]) for row in rows}
    
    return params
```

**问题分析**：
1. ❌ **只查询 calculation_parameters 表**：完全忽略 device_rated_params 表
2. ❌ **参数来源单一**：只有计算参数，没有设备额定参数
3. ❌ **优先级不完整**：只有"设备级 → 全局级"，缺少"泵站级"
4. ❌ **参数未合并**：即使查询两个表，也没有合并逻辑

### 应该实现的加载机制

**理想实现**：
```python
def load_parameters(self, device_id: int, method_id: str) -> Dict[str, float]:
    """
    加载计算参数（合并多个来源）
    
    参数来源优先级：
    1. 设备级计算参数（calculation_parameters, device_id=X, method_id=Y）
    2. 设备额定参数（device_rated_params, device_id=X）
    3. 泵站级计算参数（calculation_parameters, station_id=X, method_id=Y）
    4. 全局计算参数（calculation_parameters, device_id=NULL, method_id=Y）
    5. 代码默认值（params.get('xxx', default_value)）
    """
    params = {}
    
    # 1. 加载全局计算参数（最低优先级）
    params.update(load_global_calculation_params(method_id))
    
    # 2. 加载泵站级计算参数（如果有）
    station_id = get_station_id(device_id)
    params.update(load_station_calculation_params(station_id, method_id))
    
    # 3. 加载设备额定参数（重要！）
    params.update(load_device_rated_params(device_id))
    
    # 4. 加载设备级计算参数（最高优先级）
    params.update(load_device_calculation_params(device_id, method_id))
    
    return params
```

## 🎯 额定参数应该如何使用

### 哪些方法需要使用额定参数

| 计算方法 | 需要的额定参数 | 用途 |
|---------|--------------|------|
| pump_speed_method_a | rated_frequency, poles_pair | 计算额定转速 n_ref = 120 * rated_frequency / poles_pair |
| pump_speed_method_b | poles_pair | 计算同步转速 n_sync = 120 * f / poles_pair |
| pump_speed_method_c | rated_frequency, poles_pair | 标定关系 a = 120 / poles_pair |
| pump_efficiency_* | rated_efficiency, eta_motor | 效率上限验证、电机效率 |
| pump_flow_rate_* | rated_flow | 流量合理性验证 |
| pump_head_* | rated_head | 扬程合理性验证 |
| pump_torque_* | rated_flow, rated_head, eta_motor | 扭矩计算和验证 |

| 物理验证器 | rated_flow, rated_head, rated_efficiency | 验证计算结果是否在合理范围 |

## 📈 影响分析

### 对计算精度的影响

**当前情况**：
- 所有设备使用相同的通用参数
- 无法体现设备之间的差异
- 计算精度降低

**示例**：
```python
# 当前：所有设备使用相同的 eta_motor
eta_motor = params.get('eta_motor', 0.92)  # 全局默认值

# 应该：每个设备使用自己的 eta_motor
# 设备129: eta_motor = 0.93（从 device_rated_params 读取）
# 设备130: eta_motor = 0.93
# 设备131: eta_motor = 0.93
```

### 对方法选择的影响

**当前情况**：
- 方法选择器不检查额定参数是否存在
- 可能选择需要额定参数的方法，但参数不可用
- 导致计算失败或使用不准确的默认值

**应该实现**：
```python
# method_selector.py 中应该检查
if method_requires_rated_params(method_id):
    if not has_rated_params(device_id):
        # 跳过此方法，选择不需要额定参数的备选方法
        continue
```

### 对参数优化的影响

**当前情况**：
- 参数优化器无法使用设备额定参数作为约束
- 优化结果可能偏离设备实际特性

**应该实现**：

## 🔧 修复建议

### 修复1：修改 load_parameters() 方法

**目标**：使其能够加载设备额定参数

**实施步骤**：
1. 在 `load_parameters()` 方法中添加查询 `device_rated_params` 表的逻辑
2. 将额定参数合并到 `params` 字典中
3. 确保参数优先级正确：设备级计算参数 > 设备额定参数 > 全局计算参数

**代码修改**：
```python
def load_parameters(self, device_id: int, method_id: str) -> Dict[str, float]:
    """加载计算参数（包括设备额定参数）"""
    params = {}
    
    with get_connection() as conn:
        with conn.cursor() as cur:
            # 1. 加载全局计算参数
            query = """
                SELECT param_name, param_value
                FROM calculation_parameters
                WHERE device_id IS NULL AND method_id = %s
            """
            cur.execute(query, (method_id,))
            for row in cur.fetchall():
                params[row[0]] = float(row[1])
            
            # 2. 加载设备额定参数（新增！）
            query = """
                SELECT param_key, value_numeric
                FROM device_rated_params
                WHERE device_id = %s AND value_numeric IS NOT NULL
            """
            cur.execute(query, (device_id,))
            for row in cur.fetchall():
                params[row[0]] = float(row[1])
            
            # 3. 加载设备级计算参数（最高优先级）
            query = """
                SELECT param_name, param_value
                FROM calculation_parameters
                WHERE device_id = %s AND method_id = %s
            """
            cur.execute(query, (device_id, method_id))
            for row in cur.fetchall():
                params[row[0]] = float(row[1])
    
    return params
```
