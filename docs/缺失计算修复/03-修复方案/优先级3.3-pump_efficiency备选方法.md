# 优先级3.3：pump_efficiency 缺少备选计算方法

## 📋 问题描述

### 具体表现
1. **数据库层面**：
   - `calculation_method_registry` 表中 pump_efficiency 只有1个方法（EFF_SIMPLE_V1）
   - 缺少基于特性曲线的高精度方法

2. **代码层面**：
   - CALCULATOR_REGISTRY 中只有 EFF_SIMPLE_V1
   - 没有备选方法

3. **运行时表现**：
   - 如果 EFF_SIMPLE_V1 的依赖不满足，pump_efficiency 无法计算
   - 缺乏容错能力

### 根本原因
- **方法单一**：只实现了一个简化方法
- **缺少高精度方法**：没有基于特性曲线的方法

### 影响范围
- pump_efficiency 计算成功率低（依赖单一方法）
- 计算精度受限（只有简化方法）

### 严重程度
🟢 **中等**（影响计算精度和成功率，建议补充）

### 步骤2：实现 EFF_CURVE_V1 方法

**创建 `app/services/calculation/methods/eff_curve_v1.py`**：

```python
"""基于特性曲线的效率计算"""

import numpy as np
from typing import Dict, Optional

def calculate_pump_efficiency_eff_curve_v1(
    data: Dict[str, float],
    params: Dict[str, float],
    device_id: Optional[int] = None
) -> Optional[float]:
    """
    基于特性曲线的效率计算
    
    从 pump_characteristic_curves 表中读取 Q-η 曲线数据，
    根据当前流量插值计算效率。
    
    Args:
        data: 包含 pump_flow_rate 的数据字典
        params: 参数字典（包含 eta_min, eta_max）
        device_id: 设备ID
    
    Returns:
        效率值（0-1之间），如果无法计算则返回 None
    """
    Q = data.get('pump_flow_rate')
    if Q is None or device_id is None:
        return None
    
    # 从数据库读取特性曲线
    curve_data = _load_efficiency_curve(device_id)
    if not curve_data:
        return None
    
    # 插值计算效率
    Q_curve = np.array([point['flow_rate'] for point in curve_data])
    eta_curve = np.array([point['efficiency'] for point in curve_data])
    
    # 线性插值
    eta = np.interp(Q, Q_curve, eta_curve)
    
    # 边界检查
    eta_min = params.get('eta_min', 0.0)
    eta_max = params.get('eta_max', 1.0)
    
    if eta < eta_min or eta > eta_max:
        return None
    
    return eta / 100.0  # 转换为0-1范围

def _load_efficiency_curve(device_id: int):
    """从数据库加载效率曲线"""
    from app.db import get_db_connection
    
    conn = get_db_connection()
    cursor = conn.cursor()
    
    query = """
        SELECT flow_rate, efficiency
        FROM pump_characteristic_curves
        WHERE device_id = %s
          AND curve_type = 'Q-η'
          AND efficiency IS NOT NULL
        ORDER BY flow_rate
    """
    cursor.execute(query, (device_id,))
    
    results = cursor.fetchall()
    if not results:
        return None
    
    return [{'flow_rate': row[0], 'efficiency': row[1]} for row in results]
```
