## 📋 问题描述

### 具体表现
1. **性能问题**：
   - 每次计算都需要从数据库查询方法注册信息
   - 每次计算都需要从数据库加载参数
   - 重复计算相同的中间结果
   - 数据库查询成为性能瓶颈

2. **资源浪费**：
   - 大量重复的数据库查询
   - 相同的计算被重复执行
   - 内存未被有效利用

### 根本原因
- **缺少缓存机制**：未实施任何缓存策略
- **设计未考虑性能**：初期设计未考虑大规模数据处理

### 影响范围
- 计算性能低下（每批次耗时较长）
- 数据库负载较高
- 系统吞吐量受限

### 严重程度
🟢 **中等**（影响性能，但不影响功能正确性）

## 🔧 修复步骤

### ⚠️ 技术方案调整说明

**原计划**：使用Redis实现分布式缓存
**调整后**：使用Python内存缓存（环境限制，无Redis）

**调整原因**：
- 当前环境不支持Redis
- 单机部署场景，内存缓存已足够
- 简化部署和维护

### 步骤1：实施方法注册缓存

**方案**：使用 `functools.lru_cache` 缓存方法查询结果

**修改文件**：`app/services/calculation/method_selector.py`

```python
from functools import lru_cache
from typing import List, Dict

@lru_cache(maxsize=128)
def get_methods_for_metric_cached(metric_key: str) -> tuple:
    """
    缓存方法查询结果
    
    注意：返回tuple而非list，因为lru_cache要求返回值可哈希
    """
    from app.adapters.db import get_connection
    
    query = """
        SELECT method_id, priority, dependencies, conditions, accuracy_level
        FROM calculation_method_registry
        WHERE metric_key = %s AND is_enabled = true
        ORDER BY priority DESC
    """
    
    with get_connection() as conn:
        with conn.cursor() as cur:
            cur.execute(query, (metric_key,))
            results = cur.fetchall()
    
    # 转换为tuple以支持缓存
    return tuple(
        {
            'method_id': row[0],
            'priority': row[1],
            'dependencies': row[2],
            'conditions': row[3],
            'accuracy_level': row[4]
        }
        for row in results
    )


def get_methods_for_metric(metric_key: str) -> List[Dict]:
    """
    获取指标的计算方法（带缓存）
    """
    # 调用缓存版本，转换回list
    cached_results = get_methods_for_metric_cached(metric_key)
    return list(cached_results)
```

**优点**：
- 简单高效，无需外部依赖
- 自动管理缓存大小（LRU策略）
- 线程安全

**缺点**：
- 缓存不会自动失效（需要重启进程）
- 不支持分布式部署

### 步骤2：实施参数加载缓存

**方案**：使用 `cachetools` 库实现TTL缓存

**安装依赖**：
```bash
pip install cachetools
```

**修改文件**：`app/services/calculation/orchestrator.py`

```python
from cachetools import TTLCache, cached
from cachetools.keys import hashkey
import threading

# 创建TTL缓存（5分钟过期）
_param_cache = TTLCache(maxsize=1000, ttl=300)
_param_cache_lock = threading.RLock()


@cached(cache=_param_cache, lock=_param_cache_lock, key=lambda method_id, device_id: hashkey(method_id, device_id or 0))
def load_parameters_cached(method_id: str, device_id: int = None) -> Dict[str, float]:
    """
    加载计算参数（带缓存）
    
    缓存策略：
    - 最大缓存1000个参数集
    - TTL=5分钟（参数更新后5分钟内生效）
    - 线程安全
    """
    from app.adapters.db import get_connection
    
    query = """
        SELECT param_name, param_value
        FROM calculation_parameters
        WHERE method_id = %s
          AND (device_id = %s OR device_id IS NULL)
        ORDER BY device_id DESC NULLS LAST
    """
    
    with get_connection() as conn:
        with conn.cursor() as cur:
            cur.execute(query, (method_id, device_id))
            results = cur.fetchall()
    
    # 转换为字典
    params = {}
    for row in results:
        param_name = row[0]
        if param_name not in params:  # 优先使用设备特定参数
            params[param_name] = float(row[1])
    
    return params


def load_parameters(method_id: str, device_id: int = None) -> Dict[str, float]:
    """
    加载计算参数（公共接口）
    """
    return load_parameters_cached(method_id, device_id)
```

**优点**：
- 支持TTL自动过期
- 支持最大缓存数量限制
- 线程安全
- 可手动清除缓存

**缺点**：
- 需要额外依赖

### 步骤3：实施计算结果缓存（可选）

**方案**：使用自定义内存字典缓存中间计算结果

**修改文件**：`app/services/calculation/calculators.py`

```python
from typing import Dict, Tuple
import numpy as np
import hashlib
import json

# 全局缓存字典
_calculation_cache: Dict[str, np.ndarray] = {}
_cache_max_size = 10000  # 最大缓存条目数


def _generate_cache_key(method_id: str, data: Dict[str, np.ndarray], params: Dict[str, float]) -> str:
    """
    生成缓存键
    
    基于方法ID、输入数据和参数生成唯一键
    """
    # 简化：只使用方法ID和数据的哈希
    data_hash = hashlib.md5(
        json.dumps({k: v.tolist() if isinstance(v, np.ndarray) else v for k, v in data.items()}, sort_keys=True).encode()
    ).hexdigest()[:16]
    
    params_hash = hashlib.md5(
        json.dumps(params, sort_keys=True).encode()
    ).hexdigest()[:16]
    
    return f"{method_id}:{data_hash}:{params_hash}"


def calculate_with_cache(method_id: str, calculator_func, data: Dict[str, np.ndarray], params: Dict[str, float]) -> np.ndarray:
    """
    带缓存的计算函数
    
    Args:
        method_id: 方法ID
        calculator_func: 计算函数
        data: 输入数据
        params: 参数
    
    Returns:
        计算结果
    """
    # 生成缓存键
    cache_key = _generate_cache_key(method_id, data, params)
    
    # 检查缓存
    if cache_key in _calculation_cache:
        return _calculation_cache[cache_key].copy()
    
    # 执行计算
    result = calculator_func(data, params)
    
    # 存入缓存（如果未超过最大大小）
    if len(_calculation_cache) < _cache_max_size:
        _calculation_cache[cache_key] = result.copy()
    
    return result


def clear_calculation_cache():
    """清除计算结果缓存"""
    global _calculation_cache
    _calculation_cache.clear()
```

**注意**：
- 计算结果缓存适用于批量计算场景
- 对于实时计算，可能不适用
- 需要定期清理缓存以避免内存溢出
