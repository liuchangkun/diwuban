# 优先级2.3：main_pipeline 方法未注册到 CALCULATOR_REGISTRY

## 📋 问题描述

### 具体表现
1. **代码层面**：
   - `app/services/calculation/calculators.py` 中已实现 `calculate_main_pipeline_inlet_pressure_method_a` 和 `calculate_main_pipeline_inlet_pressure_method_c`
   - 但这两个函数未注册到 `CALCULATOR_REGISTRY` 字典中
   - CALCULATOR_REGISTRY 中只有 `main_pipeline_inlet_pressure_method_b` 和 `PIN_COEF_V1`

2. **数据库层面**：
   - `calculation_method_registry` 表中有4个方法的记录
   - 但代码中只能调用其中2个

3. **运行时表现**：
   - 方法选择器选择 method_a 或 method_c 后，无法找到对应的计算函数
   - 抛出 KeyError 或返回 None
   - 计算失败

### 根本原因
- **代码不一致**：实现了函数但忘记注册
- **缺乏自动化检查**：没有自动检查数据库方法与代码注册的一致性
- **文档缺失**：没有明确说明新增方法需要注册

### 影响范围

#### 直接影响
- main_pipeline_inlet_pressure_method_a 和 method_c 无法被调用
- 即使这两个方法被选中，也会计算失败

#### 间接影响
- main_pipeline_inlet_pressure 的计算成功率下降（4个方法中2个无法使用）
- 所有依赖 main_pipeline_inlet_pressure 的下游指标受影响

### 严重程度
🟡 **严重**（导致已实现的方法无法使用，应尽快修复）

### 步骤4：添加一致性检查脚本

**创建 `scripts/python/check_method_consistency.py`**：

```python
#!/usr/bin/env python3
"""检查数据库方法与代码注册的一致性"""

import sys
from app.db import get_db_connection
from app.services.calculation.calculators import CALCULATOR_REGISTRY

def check_consistency():
    """检查一致性"""
    conn = get_db_connection()
    cursor = conn.cursor()
    
    # 查询数据库中的所有方法
    cursor.execute("SELECT method_id FROM calculation_method_registry WHERE is_enabled = true")
    db_methods = set(row[0] for row in cursor.fetchall())
    
    # 获取代码中注册的方法
    code_methods = set(CALCULATOR_REGISTRY.keys())
    
    # 找出差异
    only_in_db = db_methods - code_methods
    only_in_code = code_methods - db_methods
    
    # 报告结果
    print(f"✅ Database methods: {len(db_methods)}")
    print(f"✅ Code methods: {len(code_methods)}")
    
    if only_in_db:
        print(f"\n❌ Methods in DB but not in code ({len(only_in_db)}):")
        for method in sorted(only_in_db):
            print(f"  - {method}")
    
    if only_in_code:
        print(f"\n⚠️  Methods in code but not in DB ({len(only_in_code)}):")
        for method in sorted(only_in_code):
            print(f"  - {method}")
    
    if not only_in_db and not only_in_code:
        print("\n✅ All methods are consistent!")
        return 0
    else:
        print("\n❌ Inconsistency detected!")
        return 1

if __name__ == '__main__':
    sys.exit(check_consistency())
```
