## 📋 问题描述

### 具体表现
1. **追溯困难**：
   - 无法追溯计算结果的来源方法
   - 无法追溯计算使用的参数版本
   - 无法追溯计算的中间过程
   - 问题排查困难

2. **审计缺失**：
   - 缺少计算过程的完整记录
   - 缺少参数变更的审计日志
   - 缺少方法选择的决策记录

### 根本原因
- **设计未考虑审计**：初期设计未考虑审计追溯需求
- **日志不完整**：现有日志信息不足以支持完整追溯

### 影响范围
- 问题排查效率低
- 无法进行质量审计
- 无法进行性能分析

### 严重程度
🟢 **中等**（影响运维效率，但不影响功能正确性）

---

## 🔧 修复步骤

### ⚠️ 技术方案调整说明

**原计划**：创建新的审计表
**调整后**：优先复用现有表，扩展现有字段

**调整原因**：
1. **现有表已具备审计能力**：
   - `fact_measurements.source_hint` 已记录计算来源
   - `calculation_failures_log` 已记录失败信息
   - `calculation_performance_metrics` 已记录性能指标

2. **避免数据冗余**：
   - 不在 `fact_measurements` 中存储审计数据（违反表设计原则）
   - 复用现有字段，减少存储开销

3. **简化实施**：
   - 无需创建新表和索引
   - 无需修改数据库schema

## 🔧 修复方案

### 方案：扩展现有字段，无需创建新表

#### 步骤1：扩展 fact_measurements.source_hint 格式

**当前格式**：
```
calculation_{method_id}
```

**扩展格式**：
```
calculation:{method_id}|params_version:{version}|priority:{priority}|duration_ms:{duration}
```

**示例**：
```
calculation:pump_inlet_pressure_method_b|params_version:20251025|priority:90|duration_ms:12
```

**实施代码**：
```python
def generate_source_hint(method_id: str, params_version: str = None, priority: int = None, duration_ms: float = None) -> str:
    """
    生成审计追溯的 source_hint
    
    Args:
        method_id: 计算方法ID
        params_version: 参数版本（可选，格式：YYYYMMDD）
        priority: 方法优先级（可选）
        duration_ms: 计算耗时（可选）
    
    Returns:
        格式化的 source_hint 字符串
    """
    parts = [f"calculation:{method_id}"]
    
    if params_version:
        parts.append(f"params_version:{params_version}")
    
    if priority is not None:
        parts.append(f"priority:{priority}")
    
    if duration_ms is not None:
        parts.append(f"duration_ms:{int(duration_ms)}")
    
    return "|".join(parts)


# 使用示例
source_hint = generate_source_hint(
    method_id="pump_inlet_pressure_method_b",
    params_version="20251025",
    priority=90,
    duration_ms=12.5
)
# 结果: "calculation:pump_inlet_pressure_method_b|params_version:20251025|priority:90|duration_ms:12"
```

def log_calculation_failure_with_audit(
    station_id: int,
    device_id: int,
    metric_key: str,
    ts_second: datetime,
    attempted_methods: List[Dict],
    params_used: Dict[str, float],
    error_type: str,
    error_message: str
):
    """
    记录计算失败，包含完整审计信息
    """
    from app.adapters.db import get_connection
    
    error_details = {
        "attempted_methods": attempted_methods,
        "params_used": params_used,
        "execution_context": {
            "batch_id": datetime.now().strftime("%Y%m%d_%H%M%S"),
            "device_id": device_id,
            "ts_second": ts_second.isoformat()
        }
    }
    
    query = """
        INSERT INTO calculation_failures_log (
            station_id, device_id, metric_key, ts_second,
            method_id, error_type, error_message, error_details, created_at
        ) VALUES (%s, %s, %s, %s, %s, %s, %s, %s, NOW())
    """
    
    with get_connection() as conn:
        with conn.cursor() as cur:
            cur.execute(query, (
                station_id, device_id, metric_key, ts_second,
                attempted_methods[0]['method_id'] if attempted_methods else None,
                error_type, error_message, json.dumps(error_details)
            ))
        conn.commit()

#### 步骤3：创建审计查询函数

**实施代码**：
```python
def audit_calculation_result(device_id: int, metric_key: str, ts_second: datetime) -> Dict:
    """
    审计追溯计算结果
    
    Args:
        device_id: 设备ID
        metric_key: 指标键
        ts_second: 时间戳
    
    Returns:
        审计信息字典
    """
    from app.adapters.db import get_connection
    
    # 查询计算结果
    query_result = """
        SELECT value, source_hint, quality_meta, inserted_at
        FROM fact_measurements fm
        JOIN dim_metric_config dmc ON fm.metric_id = dmc.id
        WHERE fm.device_id = %s
          AND dmc.metric_key = %s
          AND fm.ts_bucket = %s
    """
    
    # 查询失败日志
    query_failures = """
        SELECT method_id, error_type, error_message, error_details, created_at
        FROM calculation_failures_log
        WHERE device_id = %s
          AND metric_key = %s
          AND ts_second = %s
        ORDER BY created_at DESC
    """
    
    with get_connection() as conn:
        with conn.cursor() as cur:
            # 查询结果
            cur.execute(query_result, (device_id, metric_key, ts_second))
            result = cur.fetchone()
            
            # 查询失败记录
            cur.execute(query_failures, (device_id, metric_key, ts_second))
            failures = cur.fetchall()
    
    # 解析 source_hint
    source_info = {}
    if result and result[1]:
        parts = result[1].split('|')
        for part in parts:
            if ':' in part:
                key, value = part.split(':', 1)
                source_info[key] = value
    
    return {
        "result": {
            "value": float(result[0]) if result else None,
            "source_hint": result[1] if result else None,
            "source_info": source_info,
            "quality_meta": result[2] if result else None,
            "inserted_at": result[3] if result else None
        },
        "failures": [
            {
                "method_id": f[0],
                "error_type": f[1],
                "error_message": f[2],
                "error_details": f[3],
                "created_at": f[4]
            }
            for f in failures
        ]
    }


# 使用示例
audit_info = audit_calculation_result(
    device_id=101,
    metric_key="pump_inlet_pressure",
    ts_second=datetime(2025, 5, 31, 18, 0, 0)
)

print(f"计算方法: {audit_info['result']['source_info'].get('calculation')}")
print(f"参数版本: {audit_info['result']['source_info'].get('params_version')}")
print(f"计算耗时: {audit_info['result']['source_info'].get('duration_ms')}ms")
print(f"失败次数: {len(audit_info['failures'])}")
```
