# 优先级3.2：设备参数硬编码问题

## 📋 问题描述

### 具体表现
1. **数据库层面**：
   - pump_speed_method_b 的 conditions 包含 `{"slip": 0.02, "pole_pairs": 2}`
   - 这些是设备特定参数，不应硬编码在 conditions 中

2. **代码层面**：
   - 设备参数应该从 `device_rated_params` 表中读取
   - 硬编码导致无法适配不同设备

### 根本原因
- **设计不当**：将设备参数放在方法条件中
- **缺乏参数管理**：没有使用 device_rated_params 表

### 影响范围
- pump_speed_method_b 只能用于特定设备（slip=0.02, pole_pairs=2）
- 其他设备无法使用此方法

### 严重程度
🟢 **中等**（影响方法的通用性，应修复）

## 🔧 修复步骤

### 步骤1：移除 conditions 中的设备参数

    updated_at = NOW(),

### 步骤3：修改代码从 device_rated_params 读取参数

```python
# 在 app/services/calculation/calculators.py 中修改 calculate_pump_speed_method_b

def calculate_pump_speed_method_b(data, params, device_id=None):
    """
    方法B：从频率和极对数计算
    n = (60 * f / p) * (1 - slip)
    """
    f = data.get('pump_frequency')
    
    # 从 device_rated_params 读取参数
    if device_id:
        slip = _get_device_param(device_id, 'slip', default=0.02)
        pole_pairs = _get_device_param(device_id, 'pole_pairs', default=2)
    else:
        slip = params.get('slip', 0.02)
        pole_pairs = params.get('pole_pairs', 2)
    
    if f is None:
        return None
    
    n = (60 * f / pole_pairs) * (1 - slip)
    return n

def _get_device_param(device_id, param_key, default=None):
    """从 device_rated_params 表读取设备参数"""
    from app.db import get_db_connection
    
    conn = get_db_connection()
    cursor = conn.cursor()
    
    query = """
        SELECT value_numeric
        FROM device_rated_params
        WHERE device_id = %s 
          AND param_key = %s
          AND (effective_to IS NULL OR effective_to > NOW())
        ORDER BY effective_from DESC
        LIMIT 1
    """
    cursor.execute(query, (device_id, param_key))
    result = cursor.fetchone()
    
    return result[0] if result else default
```
