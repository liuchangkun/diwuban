# 优先级2.1：main_pipeline_inlet_pressure 方法优先级设置不当

## 📋 问题描述

### 具体表现
1. **数据库层面**：
   - `calculation_method_registry` 表中 main_pipeline_inlet_pressure 的4个方法优先级设置不合理
   - method_a (priority=100) 依赖 pump_inlet_pressure，但 pump_inlet_pressure 本身缺失
   - method_c (priority=80) 也依赖 pump_inlet_pressure
   - method_b (priority=90) 和 PIN_COEF_V1 (priority=70) 不依赖 pump_inlet_pressure

2. **运行时表现**：
   - 方法选择器优先选择 method_a，但因 pump_inlet_pressure 缺失而失败
   - 回退到 method_b 或 PIN_COEF_V1 时，可能已经浪费了计算资源
   - 在 pump_inlet_pressure 修复前，高优先级方法完全无法使用

### 根本原因
- **优先级设置未考虑依赖可用性**：method_a 和 method_c 依赖 pump_inlet_pressure，但优先级高于不依赖的方法
- **缺乏动态优先级调整机制**：无法根据依赖可用性动态调整方法优先级
- **设计假设错误**：假设 pump_inlet_pressure 总是可用

### 影响范围

#### 直接影响
- main_pipeline_inlet_pressure 计算效率低下（优先尝试必然失败的方法）
- 计算失败日志中充斥着 method_a 和 method_c 的失败记录

#### 间接影响
- 所有依赖 main_pipeline_inlet_pressure 的下游指标计算延迟
- 计算性能下降（无效尝试浪费资源）

### 严重程度
🟡 **严重**（影响计算效率和日志质量，应尽快修复）

## 🔧 修复步骤

### 步骤1：调整方法优先级

**策略**：在 pump_inlet_pressure 修复前，降低依赖它的方法的优先级；修复后再恢复。

```sql
-- 降低依赖 pump_inlet_pressure 的方法优先级
UPDATE calculation_method_registry
SET priority = 60,
    updated_at = NOW(),
    updated_by = 'manual_fix_2.1_temp'
WHERE method_id IN ('main_pipeline_inlet_pressure_method_a', 'main_pipeline_inlet_pressure_method_c')
  AND metric_key = 'main_pipeline_inlet_pressure';

-- 提高不依赖 pump_inlet_pressure 的方法优先级
UPDATE calculation_method_registry
SET priority = 100,
    updated_at = NOW(),
    updated_by = 'manual_fix_2.1_temp'
WHERE method_id = 'main_pipeline_inlet_pressure_method_b'
  AND metric_key = 'main_pipeline_inlet_pressure';

UPDATE calculation_method_registry
SET priority = 90,
    updated_at = NOW(),
    updated_by = 'manual_fix_2.1_temp'
WHERE method_id = 'PIN_COEF_V1'
  AND metric_key = 'main_pipeline_inlet_pressure';
```

**调整后的优先级**：
| 方法ID | 原优先级 | 新优先级 | 依赖 pump_inlet_pressure | 说明 |
|--------|---------|---------|------------------------|------|
| method_b | 90 | 100 | 否 | 提升为最高优先级 |
| PIN_COEF_V1 | 70 | 90 | 否 | 提升为次高优先级 |
| method_a | 100 | 60 | 是 | 降低优先级（临时） |
| method_c | 80 | 60 | 是 | 降低优先级（临时） |

### 步骤4：添加方法选择日志

**建议**：在 `app/services/calculation/method_selector.py` 中添加日志，记录方法选择过程。

```python
# 在 select_method 函数中添加日志
import logging

logger = logging.getLogger(__name__)

def select_method(metric_key, available_data, device_type, ...):
    methods = _load_methods_from_db(metric_key)
    
    for method in methods:
        logger.debug(f"Trying method {method['method_id']} (priority={method['priority']})")
        
        # 检查依赖
        if not check_dependencies(method, available_data):
            logger.debug(f"Method {method['method_id']} failed dependency check")
            continue
        
        # 检查条件
        if not check_conditions(method, ...):
            logger.debug(f"Method {method['method_id']} failed condition check")
            continue
        
        logger.info(f"Selected method {method['method_id']} for {metric_key}")
        return method
    
    logger.warning(f"No suitable method found for {metric_key}")
    return None
```

### 优先级调整依据
| 方法ID | 精度等级 | 依赖复杂度 | 计算成本 | 推荐优先级 |
|--------|---------|-----------|---------|-----------|
| method_a | high | 低（1个依赖） | 低 | 100（pump_inlet_pressure可用时） |
| method_b | high | 低（1个依赖） | 低 | 90 |
| method_c | medium | 高（多个依赖） | 中 | 80（pump_inlet_pressure可用时） |
| PIN_COEF_V1 | medium | 中（2个依赖） | 中 | 70 |

**优先级设置原则**：
1. **精度优先**：精度高的方法优先级高
2. **依赖可用性**：依赖可用的方法优先级高
3. **计算成本**：成本低的方法优先级高
4. **稳定性**：稳定的方法优先级高

## 🔄 回滚方案

### 回滚到调整前状态
```sql
-- 恢复原始优先级
UPDATE calculation_method_registry
SET priority = CASE method_id
    WHEN 'main_pipeline_inlet_pressure_method_a' THEN 100
    WHEN 'main_pipeline_inlet_pressure_method_b' THEN 90
    WHEN 'main_pipeline_inlet_pressure_method_c' THEN 80
    WHEN 'PIN_COEF_V1' THEN 70
    END,
    updated_at = NOW(),
    updated_by = 'rollback_2.1'
WHERE metric_key = 'main_pipeline_inlet_pressure'
  AND method_id IN (
    'main_pipeline_inlet_pressure_method_a',
    'main_pipeline_inlet_pressure_method_b',
    'main_pipeline_inlet_pressure_method_c',
    'PIN_COEF_V1'
  );

-- 验证回滚
SELECT method_id, priority, updated_by
FROM calculation_method_registry
WHERE metric_key = 'main_pipeline_inlet_pressure'
ORDER BY priority DESC;
```
