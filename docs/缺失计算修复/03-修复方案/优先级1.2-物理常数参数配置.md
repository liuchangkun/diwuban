# 优先级1.2：物理常数参数配置不完整

## 📋 问题描述

### 具体表现
1. **数据库层面**：
   - `calculation_parameters` 表中缺少全局物理常数配置（P_atm, rho, g）
   - HEAD_COEF_V1 方法的系数参数（a0-a5）未配置
   - PIN_COEF_V1 方法的系数参数（b0-b3）未配置
   - 部分方法在代码中硬编码了物理常数值

2. **代码层面**：
   - 多个计算函数中重复定义物理常数（rho=1000.0, g=9.80665, P_atm=0.101325）
   - 缺乏统一的参数管理机制
   - 无法根据实际情况调整参数值

3. **运行时表现**：
   - 新增的 pump_inlet_pressure 方法无法从数据库加载参数
   - HEAD_COEF_V1 和 PIN_COEF_V1 方法因缺少系数参数而无法执行
   - 参数修改需要修改代码并重新部署

### 根本原因
- **初始化脚本不完整**：`scripts/sql/calculation/init_params.sql` 中缺少物理常数和高级方法的参数
- **参数管理不规范**：部分参数在代码中硬编码，部分在数据库中配置
- **文档缺失**：没有明确说明哪些参数应该在数据库中配置

### 影响范围

#### 直接影响
- pump_inlet_pressure 的3个方法无法正常执行（缺少 P_atm, rho, g）
- HEAD_COEF_V1 方法无法执行（缺少 a0-a5, rho, g, H_min, H_max）
- PIN_COEF_V1 方法无法执行（缺少 b0-b3, rho, g, P_in_min, P_in_max）

#### 间接影响
- 所有依赖这些方法的下游指标计算失败
- 无法通过数据库调整参数进行优化
- 参数修改需要修改代码并重新部署（运维成本高）

### 严重程度
🔴 **阻塞性**（阻止优先级1.1修复生效，必须立即修复）

### 遇到的问题和解决方案

#### 问题1：外键约束 - metric_key
**错误信息**：
```
insert or update on table "calculation_parameters" violates foreign key constraint
"calculation_parameters_metric_key_fkey"
DETAIL: Key (metric_key)=(global) is not present in table "dim_metric_config".
```

**原因**：
- 原计划使用 `metric_key='global'` 存储全局物理常数
- 但 `calculation_parameters` 表有外键约束，要求 `metric_key` 必须存在于 `dim_metric_config` 表中
- `'global'` 不是有效的指标键

**解决方案**：
- 放弃全局物理常数的概念
- 为每个需要物理常数的方法单独插入 rho 和 g 参数
- 虽然有数据冗余，但符合数据库约束

#### 问题2：外键约束 - method_id
**错误信息**：
```
insert or update on table "calculation_parameters" violates foreign key constraint
"calculation_parameters_method_id_fkey"
DETAIL: Key (method_id)=(pump_inlet_pressure_method_b) is not present in table
"calculation_method_registry".
```

**原因**：
- `pump_inlet_pressure_method_b` 和 `pump_inlet_pressure_method_c` 尚未注册到数据库

- 调整修复顺序（见下文）
- 先执行优先级1.1的方法注册步骤
- 再补充pump_inlet_pressure的参数配置
