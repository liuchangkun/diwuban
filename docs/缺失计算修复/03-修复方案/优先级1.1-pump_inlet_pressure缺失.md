# 优先级1.1：pump_inlet_pressure 缺少计算方法

## 📋 问题描述

### 具体表现
1. **数据库层面**：
   - `calculation_method_registry` 表中 pump_inlet_pressure 的记录数为 0
   - `metric_calculation_order` 表中 pump_inlet_pressure 的 depends_on=[]（被错误地认为是原始数据）
   - `fact_measurements` 表中 pump_inlet_pressure 的记录数为 0（无传感器数据）

2. **代码层面**：
   - `app/services/calculation/calculators.py` 中没有 pump_inlet_pressure 的计算函数
   - `CALCULATOR_REGISTRY` 中没有 pump_inlet_pressure 的注册

3. **运行时表现**：
   - 计算 pump_inlet_pressure 时，找不到任何可用方法
   - 所有依赖 pump_inlet_pressure 的方法全部失败

### 根本原因
- **设计假设错误**：设计时假设 pump_inlet_pressure 可以从传感器直接采集
- **数据缺失**：实际部署后发现没有 pump_inlet_pressure 传感器数据
- **补救措施缺失**：没有及时添加计算方法作为补救

### 影响范围

#### 直接影响
- pump_inlet_pressure 无法计算（100%失败）

#### 间接影响（依赖链断裂）
以下8个方法因依赖 pump_inlet_pressure 而失败：

| 方法ID | 指标 | 依赖关系 |
|--------|------|---------|
| pump_head_method_main | pump_head | 需要 pump_inlet_pressure 和 pump_outlet_pressure |
| HEAD_COEF_V1 | pump_head | 需要 pump_inlet_pressure 和 pump_outlet_pressure |
| pump_outlet_pressure_method_c | pump_outlet_pressure | 需要 pump_inlet_pressure 和 pump_head |
| main_pipeline_inlet_pressure_method_a | main_pipeline_inlet_pressure | 需要 pump_inlet_pressure |
| main_pipeline_inlet_pressure_method_c | main_pipeline_inlet_pressure | 需要多个泵的 pump_inlet_pressure |
| PIN_COEF_V1 | main_pipeline_inlet_pressure | 需要 pump_inlet_pressure |
| main_pipeline_outlet_pressure_method_b | main_pipeline_outlet_pressure | 需要 pump_inlet_pressure 和 pump_head |
| EFF_SIMPLE_V1 | pump_efficiency | 需要 pump_head（而 pump_head 依赖 pump_inlet_pressure） |

#### 最终影响
- **pump_head**：0% 成功率（2个方法全部失败）
- **pump_efficiency**：0% 成功率（依赖 pump_head）
- **pump_torque**：0% 成功率（依赖 pump_head）
- **main_pipeline_inlet_pressure**：25% 成功率（4个方法中3个失败）
- **整体计算成功率**：从 42.9% 降至 14.3%（device_id=123）

### 严重程度
🔴 **阻塞性**（影响85%的指标计算，必须立即修复）

### 步骤4：创建计算函数文件

创建文件：`app/services/calculation/methods/pump_inlet_pressure.py`

```python
# -*- coding: utf-8 -*-
"""
pump_inlet_pressure 计算方法
"""
from typing import Dict
import numpy as np


def calculate_pump_inlet_pressure_method_a(
    data: Dict[str, np.ndarray],
    params: Dict[str, float]
) -> np.ndarray:
    """
    方法A：使用总管进口压力代替泵进口压力
    
    假设：并联系统中，泵进口与总管进口压力相近
    
    公式:
        P_pump_in = P_main_in
    
    Args:
        data: 包含 main_pipeline_inlet_pressure
        params: 空（不需要参数）
    
    Returns:
        计算得到的泵进口压力数组（MPa）
    """
    if 'main_pipeline_inlet_pressure' not in data:
        return np.array([], dtype=float)
    
    P_main_in = data['main_pipeline_inlet_pressure']
    if P_main_in is None or len(P_main_in) == 0:
        return np.array([], dtype=float)
    
    return P_main_in.copy()


def calculate_pump_inlet_pressure_method_b(
    data: Dict[str, np.ndarray],
    params: Dict[str, float]
) -> np.ndarray:
    """
    方法B：从水池液位推算泵进口压力
    
    公式:
        P_in = P_atm + ρ × g × L / 1e6
    
    其中:
        - P_in: 泵进口压力（MPa）
        - P_atm: 大气压（MPa，默认0.101325）
        - L: 水池液位（m）
        - ρ: 水密度（kg/m³，默认1000）
        - g: 重力加速度（m/s²，默认9.80665）
    
    Args:
        data: 包含 pool_liquid_level
        params: 包含 P_atm, rho, g（从数据库读取）
    
    Returns:
        计算得到的泵进口压力数组（MPa）
    """
    if 'pool_liquid_level' not in data:
        return np.array([], dtype=float)
    
    L = data['pool_liquid_level']  # m
    if L is None or len(L) == 0:
        return np.array([], dtype=float)
    
    # 从 params 读取参数（由 orchestrator 从数据库加载）
    P_atm = params.get('P_atm', 0.101325)  # MPa
    rho = params.get('rho', 1000.0)  # kg/m³
    g = params.get('g', 9.80665)  # m/s²
    
    result = np.full_like(L, np.nan, dtype=float)
    mask = ~np.isnan(L)
    result[mask] = P_atm + rho * g * L[mask] / 1e6
    
    return result
```

## 📊 参数来源

| 参数名 | 值 | 来源表 | 说明 |
|--------|---|--------|------|
| P_atm | 0.101325 | calculation_parameters | 大气压（MPa），物理常数 |
| rho | 1000.0 | calculation_parameters | 水密度（kg/m³），物理常数 |
| g | 9.80665 | calculation_parameters | 重力加速度（m/s²），物理常数 |

**参数读取机制**：
1. orchestrator.py 的 `load_parameters(device_id, method_id)` 方法从数据库读取
2. 优先读取设备特定参数（device_id 匹配）
3. 如果没有，读取全局参数（device_id IS NULL）
4. 如果数据库中没有，使用代码中的默认值作为后备

**禁止硬编码**：✅ 所有参数都从数据库读取，代码中的默认值仅作为后备
