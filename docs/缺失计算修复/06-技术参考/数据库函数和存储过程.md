### 2.1 质量标注函数

#### sp_mark_quality_window (v2)
```sql
CALL sp_mark_quality_window(
    p_start timestamp with time zone,
    p_end timestamp with time zone,
    p_station_id bigint DEFAULT NULL,
    p_device_id bigint DEFAULT NULL
);
```

**用途**: 质量标注过程（v2版本）

**功能说明**:
- 修正指标映射、执行顺序与过滤
- 新增 751/702 质量码
- 101 仅物理边界
- 排除状态/累计量参与 111/121

**参数**:
- `p_start`: 开始时间（UTC）
- `p_end`: 结束时间（UTC）
- `p_station_id`: 泵站ID过滤（NULL则处理所有）
- `p_device_id`: 设备ID过滤（NULL则处理所有）

**示例**:
```sql
-- 标注2025-09-01全天数据
CALL sp_mark_quality_window(
    '2025-09-01T00:00:00Z',
    '2025-09-02T00:00:00Z',
    NULL,
    NULL
);
```

**用途**: 质量标注过程（vfast优化版）

### 2.2 运行状态判定函数

#### fn_running_state_1s
```sql
SELECT * FROM fn_running_state_1s(
    p_station_id bigint,
    p_device_id bigint,
    p_start_ts timestamp with time zone,
    p_end_ts timestamp with time zone
);
```

**用途**: 按阈值与滞回逐秒判定设备运行状态

**返回字段**:
- `ts_bucket`: 时间桶（UTC秒级）
- `is_running`: 运行状态（true/false）
- `max_i`: 最大电流
- `p`: 功率
- `f`: 频率
- `source`: 数据来源

**算法**:
- 使用 device_running_thresholds 表中的阈值
- 支持滞回（hysteresis）避免抖动
- 优先使用电流判断，其次功率，最后频率

**示例**:
```sql
SELECT * FROM fn_running_state_1s(
    1,  -- station_id
    101,  -- device_id
    '2025-09-01T00:00:00Z',
    '2025-09-01T01:00:00Z'
) LIMIT 10;
```

#### fn_startstop_windows
```sql
SELECT * FROM fn_startstop_windows(
    p_station_id bigint,
    p_device_id bigint,
    p_metric_ids bigint[],
    p_start_ts timestamp with time zone,
    p_end_ts timestamp with time zone,
    p_ramp_thr double precision,
    p_jitter_thr double precision,
    p_startup_cooldown_sec integer,
    p_shutdown_cooldown_sec integer,
    p_hysteresis_sec integer
);
```

**用途**: 综合多指标信号识别启停/非稳态窗口

**返回字段**:
- `win_id`: 窗口ID
- `win_type`: 窗口类型（startup/shutdown/transient）
- `win_start_ts`: 窗口开始时间
- `win_end_ts`: 窗口结束时间

**功能说明**:
- 支持软启/变频
- 综合多指标信号
- 返回窗口起止

### 2.3 阈值学习函数

#### sp_refresh_device_running_thresholds_current
```sql
CALL sp_refresh_device_running_thresholds_current(
    p_start_ts timestamp with time zone DEFAULT NULL,
    p_end_ts timestamp with time zone DEFAULT NULL,
    p_station_id bigint DEFAULT NULL,
    p_device_id bigint DEFAULT NULL
);
```

**用途**: 从 fact_measurements 表中学习设备运行电流阈值（i_on, i_off）

**算法**:
- 读取三相电流数据（pump_current_a/b/c），取最大值
- 使用 Otsu 双峰法（简化版：中位数）计算分割阈值
- 计算滞回带：2 * MAD（中位数绝对偏差）
- i_on = 阈值 + 滞回带
- i_off = 阈值 - 滞回带

**回退机制**:
1. 优先从设备自己的历史数据学习（需要 >= 50 个样本）
2. 如果样本不足，使用同类型设备的中位数
3. 如果同类型设备也没有，使用全局中位数
4. 如果全局也没有，保持 NULL（不启用电流判断）

**更新字段**:
- `enable_i`: 设置为 TRUE（如果成功学习到阈值）
- `i_on`: 电流开启阈值
- `i_off`: 电流关闭阈值
- `updated_at`: 更新时间
- `updated_by`: 更新者标识

**数据要求**:
- 只使用 quality=0 且稳态（phase=1 或 running=1）的数据
- 最小样本数: 50

**示例**:
```sql
-- 学习所有设备的电流阈值
CALL sp_refresh_device_running_thresholds_current(NULL, NULL, NULL, NULL);
```

#### sp_refresh_device_running_thresholds_power
**用途**: 学习功率阈值（p_on, p_off）

**说明**: 算法与电流阈值类似，但默认设置 enable_p = FALSE（不启用功率判断，因为电流判断已足够）

#### sp_refresh_device_running_thresholds_frequency
**用途**: 学习频率阈值（f_on, f_off）

**说明**: 算法与电流阈值类似，但默认设置 enable_f = FALSE（不启用频率判断）

#### sp_refresh_device_running_thresholds_timing
**用途**: 学习或设置设备运行时间参数

**时间参数说明**:
- `grace_hold_secs`: 数据缺失容忍时间（秒），默认30秒
- `min_run_secs`: 最小运行时间（秒），默认10秒
- `min_stop_secs`: 最小停止时间（秒），默认10秒
- `smoothing_secs`: 平滑窗口（秒），默认5秒

#### sp_refresh_device_running_thresholds_otsu
**用途**: 使用 Otsu 双峰法估计功率因数阈值

**说明**: 样本不足时回退到稳健分位数

### 2.4 数据查询函数

#### metrics_presence_per_second
```sql
SELECT * FROM metrics_presence_per_second(
    _start timestamp with time zone,
    _end timestamp with time zone,
    _station_name text DEFAULT NULL,
    _device_name text DEFAULT NULL
);
```

**用途**: 逐秒输出 站点/设备/时间点 的【需计算指标】与【已有指标】集合

**返回字段**:
- `station`: 站点名称
- `device`: 设备名称
- `ts_utc`: 时间点（UTC）
- `need_compute_metrics`: 需计算指标数组
- `available_metrics`: 已有指标数组

**功能说明**:
- 按策略表与设备能力推导
- 用于缺失指标计算的输入

**示例**:
```sql
SELECT * FROM metrics_presence_per_second(
    '2025-09-01T00:00:00Z',
    '2025-09-01T00:05:00Z',
    'S-01',
    'D-01'
);
```

#### metrics_availability_window
```sql
SELECT * FROM metrics_availability_window(
    _start timestamp with time zone,
    _end timestamp with time zone
);
```

**用途**: 任意时间窗内设备×指标的覆盖率与分类

**返回字段**:
- `station_id`, `device_id`, `metric_id`: 维度ID
- `metric_key`: 指标键
- `start_ts`, `end_ts`: 时间窗
- `present_secs`: 存在秒数
- `total_secs`: 总秒数
- `coverage_rate`: 覆盖率
- `acquisition_status`: 采集状态
- `compute_flag`: 计算标志
- `status`: 状态
- `method_hint`: 方法提示

**功能说明**:
- 结合策略表给出 status 与 method_hint
- 用于数据质量分析

### 2.5 数据写入函数

#### safe_upsert_measurement
```sql
SELECT safe_upsert_measurement(
    p_station_id bigint,
    p_device_id bigint,
    p_metric_id bigint,
    p_ts_raw timestamp with time zone,
    p_value numeric,
    p_source_hint text
);
```

**用途**: 安全写入（UTC/秒对齐/主键合并）

**功能说明**:
- 自动秒对齐
- 主键冲突时合并
- 返回 true/false 表示成功/失败

**示例**:
```sql
SELECT safe_upsert_measurement(
    1,  -- station_id
    101,  -- device_id
    301,  -- metric_id
    '2025-09-01T00:00:00.123Z',  -- 会对齐到 00:00:00
    123.45,  -- value
    'import'  -- source_hint
);
```

#### safe_upsert_measurement_local
**用途**: 本地时间写入（按站点 tz 转 UTC 并秒对齐）

**说明**: 与 safe_upsert_measurement 类似，但输入时间为本地时间

## 四、函数使用建议

### 4.1 质量标注

**推荐流程**:
1. 使用 `sp_mark_quality_window_vfast` 进行质量标注（性能更好）
2. 如果需要重新标注，先使用 `sp_reset_quality_window` 重置
3. 使用 `sp_generate_quality_eval_by_device_metric` 生成质量评价报告

### 4.2 阈值学习

**推荐流程**:
1. 先运行 `sp_refresh_device_running_thresholds_current` 学习电流阈值
2. 可选运行 `sp_refresh_device_running_thresholds_timing` 设置时间参数
3. 验证阈值是否合理（查询 device_running_thresholds 表）
4. 如需调整，可手动修改表中的值

### 4.3 数据查询

**性能建议**:
- 必须限定时间窗并结合站/设/指标过滤
- 大窗口请分批/分桶处理，避免全表扫描
- 使用物化视图（mv_*）加速聚合查询
