## 📚 使用指南

### 对于开发者
1. 先阅读 [代码架构说明](./代码架构说明.md) 了解整体架构
2. 查看 [计算方法注册表](./计算方法注册表.md) 了解现有方法
3. 参考 [参数配置规范](./参数配置规范.md) 配置参数
4. 查阅 [数据库表结构](./数据库表结构.md) 了解数据存储

### 对于DBA
1. 先阅读 [数据库表结构](./数据库表结构.md) 了解表设计
2. 查看表之间的关联关系
3. 了解索引和性能优化建议
4. 参考数据迁移和备份建议

### 对于测试人员
1. 查看 [计算方法注册表](./计算方法注册表.md) 了解测试范围
2. 参考 [参数配置规范](./参数配置规范.md) 准备测试数据
3. 使用 [数据库表结构](./数据库表结构.md) 验证数据正确性
