## 默认最小时间窗口说明（minimal_window_minutes）
- 含义：为测量/报表类查询设置“最小默认时间窗口”（分钟），避免无意的超大范围查询拖垮数据库。
- 配置来源：configs/web.yaml → api.minimal_window_minutes；代码对应 app/core/config/web.py: WebApiSettings.minimal_window_minutes。
- 默认值：60（分钟）。
- 生效范围：当请求未显式提供时间窗口（如 start/end 或 lookback）时，系统按 minimal_window_minutes 作为默认窗口进行限制。
- 覆盖方式：
  - 显式提供 start/end（半开区间 [start,end)）时，以请求为准；
  - 若提供 lookback（如 30m/24h），将按策略转换，仍需遵守服务端的上限/限流策略。
- 注意事项：
  - 目的在于保护系统资源；并不改变查询语义，仅限制默认查询跨度；
  - 若工作负载需要更大窗口，建议采用分段请求或离线任务（参见 程序工作流程.md）。
