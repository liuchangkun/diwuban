# 角色与提示词总览

本页列出仓库可用的 Persona（角色），用于在不同任务中“正确选人、正确用人、可追溯”。所有角色默认只读，严格遵守 docs/智能助手行为控制.md 与 docs/行为约束.md。

## 使用方法（标准流程）
1. 在本页选择角色 → 打开对应提示词/xxx.md
2. 按“输入模板”准备范围/证据/边界
3. 按 MCP 流程执行：一次高信号检索 → 任务分解（必要时 TaskManager）→ 最小只读验证 → PLAYBOOKS/Memory 留痕
4. 在 PR 勾选“已按 MCP 流程执行 + 使用的 Persona”，粘贴验证命令与关键日志

## 场景 → Persona 映射表
- 文档导航/断链/一致性 → 文档专家（docs-expert）
- 架构/模式评审/ADR → 架构师评审（arch-reviewer）
- 前端交互/可用性/性能 → 前端专家（fe-expert）
- Python 重构/规范/类型 → Python 专家（python-pro）
- 数据清洗/对齐/只读验证 → 数据处理专家（data-processing-expert）
- 领域口径/指标解释/单位换算 → 智慧水务专家（smart-water-expert）
- 算法方案/特征工程/小样评估 → 机器学习深度计算专家（ml-dl-expert）
- AI 集成/推理优化/评测方法 → 人工智能工程师（ai-engineer）
- 故障排障/日志取证/窗口定位 → DevOps 故障排除员（devops-troubleshooter）
- 测试体系/覆盖率/E2E → 测试自动化专家（test-automator）
- 性能剖析/瓶颈/缓存策略 → 性能工程师（performance-engineer）
- API 解释性文档/错误码/分页 → API 文档工程师（api-documenter）
- 代码/配置风险与质量审查 → 代码审查员（code-reviewer）

## Persona 使用 SOP（硬性）
1) 在本页选择 Persona → 打开 提示词/xxx.md
2) 按角色“输入模板”准备：范围/证据（文件/窗口/日志/样本）/边界
3) 按“步骤与工具配方”执行 MCP 流程：
   - 一次高信号检索（Context7）→ Sequential 拆 1–3 个小任务 →（按需）TaskManager 审批点
   - 最小只读验证：记录命令、cwd、退出码、关键日志
4) 按“输出模板”组织产出，必要时更新导航/规范/ADR/术语
5) 审计与留痕：
   - PR 勾选“已按 MCP 流程执行 + 使用的 Persona”
   - 在“如何验证/E2E 产物”粘贴最小命令与关键日志
   - 在 PLAYBOOKS 写入对应条目，并保存关键记忆（Memory）

## 常见任务 → 输入/输出示例表

- 文档专家（docs-expert）
  - 导航修复：
    - 输入：受影响文档路径列表、断链样例、需要的交叉引用
    - 输出：导航更新清单、断链修复清单、章节草案（如有）
  - 新增指南章节：
    - 输入：读者画像、范围、相关规范链接
    - 输出：章节草案（小目录+交叉链接）、需要更新的导航列表

- 架构师评审（arch-reviewer）
  - 新服务/边界调整评审：
    - 输入：设计/ADR 草案、影响面与替代方案、风险/回滚
    - 输出：架构影响评估（高/中/低）、一致性核对清单、最小改动建议

- 数据处理专家（data-processing-expert）
  - 数据只读体检：
    - 输入：数据样本路径/结构、时间窗口（UTC/本地）、目标表/指标、质量规则
    - 输出：体检问题→清洗策略草案、对齐/导入流程图（Mermaid）、只读 SQL 证据、文档补充点

- DevOps 故障排除员（devops-troubleshooter）
  - 合并/部署卡顿定位（只读）：
    - 输入：UTC 时间窗口、代表性日志片段、相关配置与变更列表
    - 输出：RCA+证据、最小修复与回滚建议、监控/告警改进

- API 文档工程师（api-documenter）
  - 解释性文档更新：
    - 输入：接口变更列表、自动扫描结果、规范链接
    - 输出：错误码/分页/示例段落、一致性校对清单、导航更新（禁止手写字段）

- Python 专家（python-pro）
  - 中小规模重构/规范对齐：
    - 输入：受影响路径、问题点、目标行为/约束
    - 输出：最小改动建议、ruff/mypy/black 对齐说明、单测样例

- 性能工程师（performance-engineer）
  - 瓶颈定位与优化：
    - 输入：受影响模块/端点、目标指标与基线、代表性时间窗口与日志
    - 输出：剖析/火焰图摘要、优化建议优先级清单、基准前后对比、风险与回滚
