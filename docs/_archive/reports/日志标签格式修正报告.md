## 📊 标准化格式规范

### 双标签格式规则

**格式**：`[类别-操作] [具体对象/流程]`

**示例**：

1. **流程控制**：
   - `[流程-开始] [自动基线生成]`
   - `[流程-阶段] [数据加载]`
   - `[流程-阶段] [数据分组]`
   - `[流程-完成] [自动基线生成]`
   - `[流程-跳过] [数据不足]`
   - `[流程-错误] [数据加载失败]`

2. **数据库操作**：
   - `[数据库-连接] [连接池获取]`
   - `[数据库-查询] [时间范围查询]`
   - `[数据库-执行] [存储过程调用]`
   - `[数据库-事务] [事务提交]`

3. **核心组件**：
   - `[核心-重试] [重试尝试]`
   - `[核心-重试] [重试成功]`
   - `[核心-熔断] [状态转换-开启]`
   - `[核心-熔断] [拒绝调用]`
   - `[核心-错误] [错误模式检测]`
   - `[核心-初始化] [组件初始化]`

4. **API接口**：
   - `[API-请求] [数据查询]`
   - `[API-验证] [参数验证]`
   - `[API-响应] [数据返回]`
   - `[API-错误] [请求失败]`

### extra_data 包装规则

**所有日志的 extra 参数必须包装在 extra_data 中**：

**错误格式**：
```python
extra={"station_id": station_id, "device_id": device_id}
```

**正确格式**：
```python
extra={"extra_data": {"station_id": station_id, "device_id": device_id}}
```
