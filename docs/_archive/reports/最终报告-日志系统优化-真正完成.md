4. **API接口**：`[API-请求]`、`[API-查询]`、`[API-响应]`
5. **任务调度**：`[任务-调度]`、`[任务-执行]`、`[任务-完成]`
6. **工具类**：`[工具-调用]`、`[工具-验证]`

所有日志都使用统一的 `extra` 格式：
```python

    extra={
        "extra_data": {
            "字段1": value1,
            "字段2": value2,
            ...
        }
    },
)
```
