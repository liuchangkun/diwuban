## 🔧 泵流量计算 - 方法A（功率频率权重法）

**公式**: Q_i = Q_total × (P_i^α × f_i^β) / Σ(P_j^α × f_j^β)

### 测试用例 A1: 标准双泵分流

**测试目标**：验证两个泵的流量分配是否符合功率频率权重

**前置条件**：
- 总管流量：100 m³/h
- 泵1：功率50kW，频率50Hz
- 泵2：功率50kW，频率50Hz
- 参数：α=1.0, β=1.0

**测试步骤**：
1. 准备输入数据
2. 调用计算函数
3. 验证结果

**预期结果**：
- 泵1流量：50 m³/h
- 泵2流量：50 m³/h
- 总流量：100 m³/h

**验证方法**：
```sql
-- 验证流量分配
SELECT 
    device_id, 
    pump_flow_rate,
    ROUND(pump_flow_rate::numeric, 2) as rounded_flow
FROM fact_measurements 
WHERE metric_key = 'pump_flow_rate' 
  AND timestamp BETWEEN '2025-01-01' AND '2025-01-02'
ORDER BY device_id;

-- 验证总流量守恒
SELECT 
    SUM(pump_flow_rate) as total_flow,
    CASE 
        WHEN ABS(SUM(pump_flow_rate) - 100) < 0.1 THEN 'PASS'
        ELSE 'FAIL'
    END as validation
FROM fact_measurements 
WHERE metric_key = 'pump_flow_rate';
```

**误差范围**：< 0.5%

### 测试用例 A12: 计算准确性对标

**测试步骤**：

```sql
-- 对比计算结果与历史数据
SELECT 
    fm.device_id,
    fm.pump_flow_rate as calculated,
    hd.pump_flow_rate as historical,
    ABS(fm.pump_flow_rate - hd.pump_flow_rate) / hd.pump_flow_rate * 100 as error_rate

JOIN historical_data hd ON fm.device_id = hd.device_id

WHERE fm.metric_key = 'pump_flow_rate'
  AND error_rate > 1.0;  -- 误差超过1%的记录
```

**误差范围**：< 1%

## 🔧 泵扬程计算

### 测试用例 B1: 标准压差法

**公式**: H = (P_out - P_in) / (ρ × g)

**前置条件**：
- 出口压力：0.5 MPa
- 进口压力：0.1 MPa
- 密度：1000 kg/m³
- 重力加速度：9.81 m/s²

**预期结果**：
- 扬程 = (0.5 - 0.1) × 10^6 / (1000 × 9.81) ≈ 40.8 m

**验证SQL**：
```sql
SELECT 
    pump_head,
    ROUND(pump_head::numeric, 1) as rounded,
    CASE 
        WHEN ABS(pump_head - 40.8) < 0.5 THEN 'PASS'
        ELSE 'FAIL'
    END as validation
FROM fact_measurements 
WHERE metric_key = 'pump_head';
```

### 1. 业务逻辑验证
```python
# 验证流量守恒
total_flow = sum(pump_flows)

# 验证扬程物理意义
assert pump_head >= 0, "扬程不能为负"

# 验证转速范围
assert 0 <= pump_speed <= 3000, f"转速超出范围：{pump_speed}"
```

### 2. 数据完整性验证
```sql
-- 验证计算覆盖率
SELECT 
    metric_key,
    COUNT(*) as total,
    COUNT(CASE WHEN value IS NOT NULL THEN 1 END) as calculated,
    ROUND(COUNT(CASE WHEN value IS NOT NULL THEN 1 END)::numeric / COUNT(*) * 100, 2) as coverage_rate
FROM fact_measurements 
GROUP BY metric_key;
```

### 3. 计算准确性验证
```sql
-- 验证误差范围
SELECT 
    device_id,
    metric_key,
    AVG(ABS(calculated - expected) / expected * 100) as avg_error_rate,
    MAX(ABS(calculated - expected) / expected * 100) as max_error_rate
FROM calculation_validation_view
GROUP BY device_id, metric_key
HAVING MAX(ABS(calculated - expected) / expected * 100) > 1.0;
```
