### 测试用例 DB1: upsert_measurement - 正常插入

**前置条件**：
- 泵站ID: 1, 设备ID: 101, 指标ID: 301
- 数据不存在

**测试步骤**：
```sql
SELECT api.upsert_measurement(
    p_station_id := 1,
    p_device_id := 101,
    p_metric_id := 301,
    p_ts_raw := '2025-01-01 10:00:00+00',
    p_value := 123.45,
    p_source_hint := 'csv_import'
);
```

**预期结果**：
- 返回值：true（成功插入）
- 数据库中新增1条记录

**验证SQL**：
```sql
SELECT COUNT(*) as cnt, value, source_hint
FROM fact_measurements
WHERE station_id = 1 AND device_id = 101 AND metric_id = 301
  AND ts_bucket = '2025-01-01 10:00:00+00'
GROUP BY value, source_hint;
-- 期望：cnt=1, value=123.45, source_hint='csv_import'
```

### 测试用例 DB5: upsert_measurement - 大数据量并发

**前置条件**：
- 并发插入1000条记录

**测试步骤**：
```python
import concurrent.futures

def insert_record(i):
    sql = "SELECT api.upsert_measurement(%s, %s, %s, %s, %s, %s)"
    cur.execute(sql, (1, 101+i%10, 301+i%5, 
                      f'2025-01-01 10:{i%60:02d}:00+00', 
                      100+i, 'concurrent'))
    return cur.fetchone()[0]

with concurrent.futures.ThreadPoolExecutor(max_workers=10) as executor:
    results = list(executor.map(insert_record, range(1000)))
```

**预期结果**：
- 所有1000条记录都成功插入
- 数据库中应有1000条新记录

**验证SQL**：
```sql
SELECT COUNT(*) as cnt
FROM fact_measurements
WHERE source_hint = 'concurrent';
-- 期望：cnt=1000
```

## 📊 验证方法总结

### 1. 数据正确性验证

### 2. 事务一致性验证
```sql
-- 验证事务回滚是否生效
BEGIN;
SELECT api.upsert_measurement(...);
ROLLBACK;
SELECT COUNT(*) FROM fact_measurements WHERE ...;
-- 期望：0
```

### 3. 性能验证
```python
import time
start = time.time()
# 执行操作
duration = time.time() - start
assert duration < threshold, f"性能不符合要求：{duration}秒"
```

### 4. 并发验证
```python
import concurrent.futures
with concurrent.futures.ThreadPoolExecutor(max_workers=10) as executor:
    results = list(executor.map(operation, range(1000)))
assert all(results), "并发操作失败"
```

### 5. 聚合准确性验证
```sql
-- 验证聚合结果是否准确
SELECT 
    COUNT(*) as cnt,
    AVG(value) as avg_value,
    MIN(value) as min_value,
    MAX(value) as max_value,
    SUM(value) as sum_value
FROM fact_measurements
WHERE station_id = %s AND device_id = %s AND metric_id = %s
  AND ts_bucket >= %s AND ts_bucket < %s;
```
