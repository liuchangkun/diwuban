## ✅ 修正规范

### 1. 双标签格式

**格式**: `[类别-操作] [具体对象/流程]`

**示例**:
- ✅ `[流程-开始] [自动基线生成B]`
- ✅ `[数据库-查询] [时间范围查询]`
- ✅ `[核心-重试] [重试尝试]`
- ✅ `[API-请求] [数据查询]`

**错误示例**:
- ❌ `[流程-开始] 自动基线生成（方案B）`
- ❌ `[数据库-查询] 查询实际数据时间范围`

---

### 2. extra_data包装

**正确格式**:
```python
_act.info(
    "[流程-开始] [自动基线生成B]",
    extra={
        "extra_data": {
            "station_id": station_id,
            "device_id": device_id,
        }
    },
)
```

**错误格式**:
```python
_act.info(
    "[流程-开始] 自动基线生成",
    extra={"station_id": station_id},  # ❌ 缺少extra_data包装
)
```
