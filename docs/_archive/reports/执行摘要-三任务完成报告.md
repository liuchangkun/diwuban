### 问题1：SQL脚本路径错误

**描述**: run-all 执行时报错 `FileNotFoundError: SQL脚本不存在`

**原因**: 代码中的路径计算错误
```python

# 实际路径应该是
adaptive_dir = _Path(__file__).parent.parent.parent.parent.parent / "scripts" / "sql" / "adaptive"
```

**修复**: 修改 `app/services/ingest/prepare_dim/__init__.py` 第385行
