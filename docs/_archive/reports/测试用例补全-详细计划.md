## 📝 验证标准

每个测试用例必须满足：

1. **日志验证**：
   - 读取 `logs/app.log`、`logs/error.log`
   - 确认无ERROR级别日志
   - 确认测试相关的INFO日志正确

2. **数据库验证**：
   - 查询相关表的记录数量
   - 验证数据的正确性
   - 对比预期值和实际值

3. **返回值验证**：
   - 验证函数返回值符合预期
   - 验证异常处理正确

4. **综合判断**：
   - 日志 + 数据库 + 返回值三重验证
   - 所有验证都通过才算成功
