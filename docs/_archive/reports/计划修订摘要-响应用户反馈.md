## 🔍 关键改进点

### 改进1：代码复用

**原计划**：
```python
# 重新实现时间窗口查询逻辑
with get_conn(settings) as conn:
    with conn.cursor() as cur:
        cur.execute("SELECT MIN(ts_bucket), MAX(ts_bucket) FROM public.fact_measurements")
        row = cur.fetchone()
        if row and row[0] and row[1]:
            actual_start = row[0]
            actual_end = row[1]
            end_ts = actual_end
            start_ts = max(actual_start, actual_end - _td(days=int(max(1, lookback_days))))
```

**修订后**：
```python
# 复用现有的自动窗口逻辑（与 running_thresholds_b.py 保持一致）
start = None
end = None

with get_conn(settings) as conn:
    with conn.cursor() as cur:
        # 自动窗口（复用现有逻辑）
        if not start or not end:
            cur.execute(
                "SELECT MIN(ts_bucket), MAX(ts_bucket) FROM public.fact_measurements"
            )
            row = cur.fetchone() or (None, None)
            if not start and row[0] is not None:
                start = row[0].isoformat()
            if not end and row[1] is not None:
                end = row[1].isoformat()
        if not start or not end:
            return result
        
        start_ts = _dt.fromisoformat(start.replace("Z", "+00:00"))
        end_ts = _dt.fromisoformat(end.replace("Z", "+00:00"))
```

**优势**：
- ✅ 与现有代码保持一致
- ✅ 避免重复实现
- ✅ 更容易维护
