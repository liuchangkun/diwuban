## 🔄 测试循环

### 持续集成
```bash
# 每次提交时运行
pytest tests/unit/ -v

# 每天运行
pytest tests/ -v --cov=app

# 每周运行
pytest tests/performance/ -v -m performance
```

### 回归测试
```bash
# 修复缺陷后运行
pytest tests/ -v --tb=short

# 发布前运行
pytest tests/ -v --cov=app --cov-report=html
```
