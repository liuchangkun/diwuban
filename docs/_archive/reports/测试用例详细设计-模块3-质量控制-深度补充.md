### 测试用例 Q12: 异常跳变 - 超过阈值

**前置条件**：
- 前一个值：100 m³/h
- 当前值：200 m³/h
- 跳变阈值：50 m³/h
- 变化量：100 m³/h（超过阈值）

**预期结果**：
- 质量码：111（异常跳变）
- 质量状态：1（SUSPECT）

**验证SQL**：
```sql
SELECT 
    timestamp,
    value,
    LAG(value) OVER (ORDER BY timestamp) as prev_value,
    ABS(value - LAG(value) OVER (ORDER BY timestamp)) as jump,
    quality_codes,
    CASE 
        WHEN ABS(value - LAG(value) OVER (ORDER BY timestamp)) > 50 
             AND quality_codes @> ARRAY[111] THEN 'PASS'
        ELSE 'FAIL'
    END as validation
FROM fact_measurements 
WHERE metric_key = 'pump_flow_rate'
ORDER BY timestamp;
```

### 测试用例 Q22: 平台期检测

**前置条件**：
- 数据序列：100, 100, 100, 100, 100, 100
- 平台期阈值：连续5个相同值

**预期结果**：
- 质量码：121（平台期）
- 质量状态：1（SUSPECT）

**验证SQL**：
```sql
WITH consecutive_same AS (
    SELECT 
        timestamp,
        value,
        COUNT(*) OVER (
            PARTITION BY value 
            ORDER BY timestamp 
            ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
        ) as consecutive_count
    FROM fact_measurements 
    WHERE metric_key = 'pump_flow_rate'
)
SELECT 
    timestamp,
    value,
    consecutive_count,
    CASE 
        WHEN consecutive_count >= 5 THEN 'PLATEAU'
        ELSE 'NORMAL'
    END as status
FROM consecutive_same
ORDER BY timestamp;
```

```sql

    END as status,
    quality_codes
FROM fact_measurements 
WHERE metric_key = 'pump_cumulative_flow'
```

## 📊 验证方法总结

### 1. 质量码标注准确性验证
```python
# 验证质量码是否正确标注
def verify_quality_codes(metric_key, value, expected_codes):
    actual_codes = get_quality_codes(metric_key, value)
    assert set(actual_codes) == set(expected_codes), \
        f"质量码不匹配：期望{expected_codes}，实际{actual_codes}"
```

### 2. 质量状态准确性验证
```sql
-- 验证质量状态与质量码的对应关系
SELECT 
    quality_codes,
    quality_status,
    CASE 
        WHEN quality_codes IS NULL AND quality_status = 0 THEN 'PASS'
        WHEN quality_codes @> ARRAY[101] AND quality_status = 2 THEN 'PASS'
        WHEN quality_codes @> ARRAY[111, 121, 401] AND quality_status = 1 THEN 'PASS'
        ELSE 'FAIL'
    END as validation
FROM fact_measurements;
```

### 3. 规则覆盖率验证
```sql
-- 验证所有质量规则都被应用
SELECT 
    metric_key,
    COUNT(DISTINCT quality_codes) as unique_codes,
    COUNT(*) as total_records
FROM fact_measurements 
GROUP BY metric_key;
```
