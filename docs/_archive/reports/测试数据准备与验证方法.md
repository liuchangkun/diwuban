## 📋 测试数据分类

### 1. 维度数据（Dimension Data）
**特点**: 相对稳定，变化不频繁  
**包含**:
- 泵站信息 (dim_stations)
- 设备信息 (dim_devices)
- 指标元数据 (dim_metric_config)
- 设备能力 (dim_device_capabilities)

**准备方法**: SQL脚本初始化

### 2. 事实数据（Fact Data）
**特点**: 大量、频繁变化  
**包含**:
- 测量数据 (fact_measurements)
- 质量标注 (fact_quality_marks)
- 计算结果 (fact_calculated_metrics)

**准备方法**: CSV导入或SQL脚本

### 3. 配置数据（Configuration Data）
**特点**: 需要版本管理  
**包含**:
- 计算参数 (calculation_parameters)
- 计算方法 (calculation_method_registry)
- 质量规则 (quality_rules)
- 运行阈值 (running_thresholds)

**准备方法**: SQL脚本或配置文件

## 🔧 数据准备方法

### 方法1: SQL脚本初始化

**文件**: `scripts/sql/test/init_test_data.sql`

```sql
-- 1. 清理旧数据
TRUNCATE TABLE fact_measurements CASCADE;
TRUNCATE TABLE dim_stations CASCADE;
TRUNCATE TABLE dim_devices CASCADE;

-- 2. 初始化维度数据
INSERT INTO dim_stations (station_id, station_name, location) VALUES
(1, '泵站A', '北京'),
(2, '泵站B', '上海'),
(3, '泵站C', '广州');

INSERT INTO dim_devices (device_id, station_id, device_name, device_type) VALUES
(1, 1, '设备1', 'pump'),
(2, 1, '设备2', 'pump'),
(3, 2, '设备3', 'pump');

-- 3. 初始化配置数据
INSERT INTO calculation_parameters (param_id, method_id, device_id, param_name, param_value) VALUES
(1, 1, 1, 'efficiency', '0.85'),
(2, 1, 2, 'efficiency', '0.82');
```

**优点**:
- 快速、可重复
- 易于版本控制
- 支持复杂的初始化逻辑

**缺点**:
- 需要维护SQL脚本
- 难以处理大量数据

### 方法3: Python Fixture

**文件**: `tests/conftest.py`

```python
@pytest.fixture
def test_data_with_measurements(test_data_manager):
    """创建包含测量数据的测试数据"""
    # 初始化维度数据
    test_data_manager.insert_stations([
        {'station_id': 1, 'station_name': '泵站A'},
        {'station_id': 2, 'station_name': '泵站B'},
    ])
    
    # 初始化设备数据
    test_data_manager.insert_devices([
        {'device_id': 1, 'station_id': 1, 'device_name': '设备1'},
        {'device_id': 2, 'station_id': 1, 'device_name': '设备2'},
    ])
    
    # 初始化测量数据
    test_data_manager.insert_measurements([
        {'timestamp': '2025-01-01 00:00:00', 'device_id': 1, 'metric_name': 'flow', 'value': 100.5},
        {'timestamp': '2025-01-01 00:01:00', 'device_id': 1, 'metric_name': 'flow', 'value': 101.2},
    ])
    
    yield test_data_manager
    
    # 清理
    test_data_manager.cleanup()
```

**优点**:
- 灵活、易于定制
- 支持动态数据生成
- 易于调试

**缺点**:
- 需要编写Python代码
- 执行速度较慢

    """验证数据完整性"""
    # 验证行数
    db_validator.verify_row_count("fact_measurements", 3)

## 🚀 快速开始

### 1. 初始化测试环境
```bash
# 创建测试数据库
python scripts/setup_test_db.py

# 初始化测试数据
psql -U postgres -d test_db -f scripts/sql/test/init_test_data.sql
```

### 2. 运行单个测试
```bash
pytest tests/test_data_import.py::TestDataImport::test_normal_scenario -v
```

### 3. 运行所有测试
```bash
pytest tests/ -v --cov=app
```

### 4. 查看覆盖率报告
```bash
open htmlcov/index.html
```
