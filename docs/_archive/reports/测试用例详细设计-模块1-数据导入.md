## 正常场景 (4个)

### TC-DI-001: CSV文件正常导入

**测试目标**: 验证单个CSV文件能够正常导入到数据库

**前置条件**:
- 数据库连接正常
- Staging表已创建
- 测试CSV文件存在: `tests/data/normal_measurements.csv`
- CSV文件格式正确，包含必要列: timestamp, station_id, device_id, metric_name, value

**测试步骤**:
1. 调用 `DataImporter.import_csv_file(file_path, station_id)`
2. 等待导入完成
3. 查询数据库验证数据

**预期结果**:
- 返回值包含: success=True, valid_rows>0, rejected_rows=0
- Staging表中有新增数据
- 数据完整性检查通过

**验证方法**:
```sql
-- 验证数据导入
SELECT COUNT(*) as total_rows FROM staging_raw 
WHERE station_id = ? AND created_at >= NOW() - INTERVAL '1 minute';

-- 验证数据完整性
SELECT COUNT(*) as invalid_rows FROM staging_raw 
WHERE station_id = ? AND (timestamp IS NULL OR value IS NULL);
```

**后置清理**:
```sql
DELETE FROM staging_raw WHERE station_id = ? AND created_at >= NOW() - INTERVAL '1 minute';
```

**备注**: 无

### TC-DI-002: 多个CSV文件批量导入

**测试目标**: 验证多个CSV文件能够顺序导入

**前置条件**:
- 数据库连接正常
- 3个测试CSV文件存在
- 每个文件包含不同的数据

**测试步骤**:
1. 循环调用 `DataImporter.import_csv_file()` 导入3个文件
2. 记录每次导入的结果
3. 查询数据库验证所有数据

**预期结果**:
- 所有3个文件都导入成功
- 总导入行数 = 3个文件的行数之和
- 数据库中没有重复数据

**验证方法**:
```sql
-- 验证总行数
SELECT COUNT(*) as total FROM staging_raw WHERE station_id = ?;

-- 验证无重复
SELECT COUNT(*) as duplicates FROM (
  SELECT timestamp, device_id, metric_name, COUNT(*) as cnt 
  FROM staging_raw 
  WHERE station_id = ? 
  GROUP BY timestamp, device_id, metric_name 
  HAVING cnt > 1
) t;
```

**后置清理**: 同TC-DI-001

**备注**: 无

### TC-DI-017: 大数据量导入性能测试

**测试目标**: 验证系统在大数据量导入时的性能表现

**前置条件**:
- 准备一个包含1000万行数据的CSV文件（约2GB）

**测试步骤**:
1. 记录导入开始时间
2. 调用 `DataImporter.import_csv_file()` 导入文件
3. 记录导入完成时间
4. 计算导入速率

**预期结果**:
- 导入成功完成
- 导入速率 ≥ 100,000 行/秒
- 内存使用不超过2GB
- CPU使用率 < 80%

**验证方法**:
```python
import time
start = time.time()
result = importer.import_csv_file(file_path, "station_1")
duration = time.time() - start
rows_per_second = result['total_rows_processed'] / duration
assert rows_per_second >= 100000
```

**后置清理**: 同TC-DI-001

**备注**: 需要监控系统资源使用情况
