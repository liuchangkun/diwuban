## 🏗️ 架构与设计

### 系统架构
- **技术栈**：Python 3.10+, PostgreSQL 16, FastAPI
- **架构模式**：Adapters/Services/Core 分层架构
- **数据规模**：秒级采集，多泵站并发处理

### 核心模块

#### 1. 适配器层 (`app/adapters/`)
- **[db/gateway.py](../app/adapters/db/gateway.py)** - 数据库网关（连接池管理）
- **职责**：外部系统集成、数据库访问、API适配

#### 2. 服务层 (`app/services/`)

**特性曲线服务** (`characteristic_curves/`)
- **[pipeline/curve_fitting_pipeline.py](../app/services/characteristic_curves/pipeline/curve_fitting_pipeline.py)** - 曲线拟合主流程
- **[pump_group/pump_group_processor.py](../app/services/characteristic_curves/pump_group/pump_group_processor.py)** - 泵组处理器
- **[methods/](../app/services/characteristic_curves/methods/)** - 拟合方法集
  - `mathematical/` - 数学方法（多项式、样条、核方法等）
  - `physical/` - 物理方法（泵特性方程等）
  - `machine_learning/` - 机器学习方法（随机森林、梯度提升等）

**数据摄取服务** (`ingest/`)
- **[merge_service.py](../app/services/ingest/merge_service.py)** - 数据合并服务
- **[copy_workers.py](../app/services/ingest/copy_workers.py)** - 数据复制工作进程
- **[prepare_dim/](../app/services/ingest/prepare_dim/)** - 维度表准备

**编排服务** (`run_all/`)
- **[orchestrator.py](../app/services/run_all/orchestrator.py)** - 任务编排器

#### 3. 核心层 (`app/core/`)
- **[config/loader_new.py](../app/core/config/loader_new.py)** - 配置加载器
- **[config/merge.py](../app/core/config/merge.py)** - 配置合并逻辑

#### 4. CLI层 (`app/cli/`)
- **[main.py](../app/cli/main.py)** - 命令行入口

### 配置文件
- **[configs/database.yaml](../configs/database.yaml)** - 数据库配置
- **[configs/ingest.yaml](../configs/ingest.yaml)** - 数据摄取配置
- **[configs/merge.yaml](../configs/merge.yaml)** - 数据合并配置

## 💼 业务领域

### 泵站数据分析
- **领域**：水泵站运行监控与优化
- **核心功能**：
  1. 特性曲线拟合（Q-H, Q-P, Q-η）
  2. 泵组运行效率分析
  3. 异常检测与预警
  4. 运行优化建议

### 数据流程
```
原始数据采集 → 数据清洗 → 特征提取 → 曲线拟合 → 结果存储 → 可视化展示
```

### 关键指标
- **流量（Q）**：m³/h
- **扬程（H）**：米
- **功率（P）**：kW
- **效率（η）**：百分比

## 🔍 问题排查

### 常见问题

#### 数据库连接问题
- 检查：`configs/database.yaml` 配置
- 日志：搜索 "database.connection" 事件

#### 曲线拟合失败
- 检查：数据质量（是否有足够样本点）
- 日志：搜索 "curve_fitting.error" 事件
- 参考：[特性曲线模块文档](../app/services/characteristic_curves/)

#### 性能问题
- 工具：使用 `/性能分析` 命令
- 检查：数据库索引、查询计划
- 参考：[性能分析命令](../.claude/commands/性能分析.md)

### 调试技巧
1. 启用DEBUG日志级别
2. 使用 Sequential Thinking MCP 进行推理
3. 查看 `个人记录_本次任务.md` 历史记录
