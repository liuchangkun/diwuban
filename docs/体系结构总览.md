# 体系结构总览

## 背景与目标
- 分层职责清晰：API / 服务编排 / 适配器 / 模型 / 数据库函数。
- 禁止跨层直连与 SQL/DSN 拼接（见 rules/rules.yml）。

## 分层与边界
- API 层：路由、入参校验、输出契约
- 服务层：参数校验与编排，调用 DB 函数
- 适配器层：连接池与网关
- 数据层：以过程/视图/物化为主

## 依赖与调用路径
- 仅通过网关访问数据库；服务不拼接 SQL。

## 接口与数据库对照
- 详见“应用接口说明.md”的自动块，以及“数据库设计文档.md”。

## 自动块（示例引用）
- API 路由概览：见 docs/_自动/API路由.md
- 数据库对象概览：见 docs/_自动/数据库对象清单.md

## 风险与反例
- 反例：services 内直接拼接 SQL；修复：迁移到 adapters.db.gateway。
