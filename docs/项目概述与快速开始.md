# 项目概述与快速开始

## 背景与目标
- 承载泵站数据的对齐、聚合与查询，应用层以“调用数据库函数”为唯一业务入口。
- 目标：形成“事实→文档→验证”的闭环，支撑后续功能迭代。

## 适用范围与边界
- 范围：本仓库应用与数据库脚本；不含外部可视化/BI。
- 非目标：复杂调度平台、跨集群部署。

## 快速开始
- 环境与依赖：Python 3.11+、PostgreSQL 16。
- 一键命令：见“CLI 帮助”与“配置快照”。

## 目录地图
- 代码与脚本：app/、scripts/、configs/
- 文档入口：docs/README.md（当前文档从此处出发）

## 配置与参数（摘要）
- 详见“配置说明.md”；自动块：docs/_自动/配置快照.md。
