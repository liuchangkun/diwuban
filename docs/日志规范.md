# 日志规范

> 本文档记录项目的日志设计、字段规范与采集策略。自动生成的配置快照与上下文字段将写入文末自动区块，请勿手动编辑自动区块。

## 1. 目标

- 统一日志格式（管道分隔 + extra_json）
- 统一上下文字段（request_id/trace_id 等）
- 支持慢 SQL、连接池、作业重试、出站 HTTP 等关键事件日志

## 2. 配置与初始化

- 配置文件：configs/logging.yaml
- 初始化入口：app/core/logging/setup.py 中 init_logging()
- 自动生成工具：scripts/tools/doc_gen/gen_logging_md.py

## 3. 日志字段（固定部分）

- timestamp, pid, processName, threadId, threadName, filename, module, funcName, lineno, level, message
- extra_json：严格 JSON（包含上下文与事件字段）

## 4. 使用建议（手写区）

- 业务关键路径使用 log_activity 上下文管理记录进入/退出/异常
- 数据库访问使用 log_sql/log_db_view/log_db_function 等辅助 API

## 5. 变更记录
