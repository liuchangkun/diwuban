### 8.4 迁移流程建议

**跨环境参数迁移步骤**：

1. **导出参数配置**（源环境）：
   ```sql
   -- 导出设备额定参数（使用名称标识）
   SELECT
       s.name as station_name,
       d.name as device_name,
       drp.param_key,
       drp.value_numeric,
       drp.unit,
       drp.source
   FROM device_rated_params drp
   JOIN dim_devices d ON d.id = drp.device_id
   JOIN dim_stations s ON s.id = d.station_id
   ORDER BY s.name, d.name, drp.param_key;
   ```

2. **生成自适应SQL**（目标环境）：
   ```sql
   -- 使用名称定位设备，自动适配ID
   INSERT INTO device_rated_params (device_id, param_key, value_numeric, unit, source)
   SELECT
       d.id,
       '参数名' as param_key,
       参数值 as value_numeric,
       '单位' as unit,
       'manual' as source
   FROM dim_devices d
   JOIN dim_stations s ON s.id = d.station_id
   WHERE s.name = '泵站名称' AND d.name = '设备名称';
   ```

3. **执行迁移**（目标环境）：
   - 在事务中执行自适应SQL
   - 验证参数数量和值
   - 提交事务
