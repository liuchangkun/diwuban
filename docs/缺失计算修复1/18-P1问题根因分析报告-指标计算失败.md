### 根本原因1：缺失原始数据 - pump_inlet_pressure

**问题描述**：
- pump_inlet_pressure（泵进口压力）是一个**原始指标**（不是计算指标）
- calculation_method_registry 表中**没有** pump_inlet_pressure 的计算方法
- fact_measurements 表中**没有** pump_inlet_pressure 的数据（所有设备的 non_null_count = 0）

**影响**：
- pump_head（泵扬程）的计算失败
  - 方法 HEAD_COEF_V1（优先级110）：依赖 pump_outlet_pressure, pump_inlet_pressure
  - 方法 pump_head_method_main（优先级100）：依赖 pump_outlet_pressure, pump_inlet_pressure
  - **所有方法都因缺少 pump_inlet_pressure 而失败**

- pump_flow_rate（泵流量）方法F 失败
  - 方法F（优先级50）：依赖 pump_active_power, pump_frequency, pump_inlet_pressure
  - **因缺少 pump_inlet_pressure 而失败**

**数据验证**：

```sql

FROM (查询结果)

-- 结果：
-- device_id | device_name | record_count | non_null_count
-- 177       | 二期供水泵房1#泵 | 1            | 0
-- 178       | 二期供水泵房2#泵 | 1            | 0
-- ...（所有设备都是 0）
```

### 根本原因2：数据分配错误 - main_pipeline_flow_rate

**问题描述**：
- main_pipeline_flow_rate（主管流量）是一个**总管级别的指标**
- fact_measurements 表中：
  - 设备 183（二期供水泵房总管）：✅ 有数据（7200条记录）
  - 设备 177-182（6个泵）：❌ 没有数据（record_count=1, non_null_count=0）

**影响**：
- pump_flow_rate（泵流量）的大部分计算方法失败
  - 方法A（优先级100）：依赖 main_pipeline_flow_rate, pump_active_power, pump_frequency
  - 方法C（优先级80）：依赖 main_pipeline_flow_rate
  - 方法D（优先级70）：依赖 main_pipeline_flow_rate, pump_active_power
  - 方法E（优先级60）：依赖 main_pipeline_flow_rate, pump_frequency
  - **4个方法都因缺少 main_pipeline_flow_rate 而失败**

**数据验证**：

```sql
-- 查询结果：main_pipeline_flow_rate 只有设备183（总管）有数据
SELECT device_id, device_name, record_count, non_null_count
FROM (查询结果)
WHERE metric_key = 'main_pipeline_flow_rate';

-- 结果：
-- device_id | device_name | record_count | non_null_count
-- 177       | 二期供水泵房1#泵 | 1            | 0
-- 178       | 二期供水泵房2#泵 | 1            | 0
-- ...
-- 183       | 二期供水泵房总管 | 7200         | 7200  ← 只有总管有数据
```

**逻辑分析**：
- main_pipeline_flow_rate 是总管流量，不应该分配给单个泵设备
- 但是 pump_flow_rate 的计算方法大部分都依赖 main_pipeline_flow_rate
- 这是一个**设计问题**：单个泵的流量不应该依赖总管流量

### 根本原因3：循环依赖问题 - pump_cumulative_flow

### 方案2：为 pump_flow_rate 添加新的计算方法（推荐 - 治本）

**优先级**：🔴 P0 - 必须立即修复

**新方法设计**：

```sql
-- 方法G：基于功率、频率、出口压力的流量估算
-- 优先级：95（高于方法B，低于方法A）
INSERT INTO calculation_method_registry (
    method_id,
    metric_key,
    method_code,
    method_name,
    dependencies,
    conditions,
    priority,
    accuracy_level,
    description
) VALUES (
    'pump_flow_rate_method_g',
    'pump_flow_rate',
    'G',
    '功率-频率-压力估算法',
    ARRAY['pump_active_power', 'pump_frequency', 'pump_outlet_pressure'],
    '{"description": "基于功率、频率、出口压力估算流量，适用于单泵运行"}',
    95,
    'medium',
    '使用功率、频率、出口压力估算流量，不依赖总管流量和进口压力'
);
```

**计算公式**（示例）：

```python
def calculate_pump_flow_rate_method_g(
    pump_active_power: np.ndarray,
    pump_frequency: np.ndarray,
    pump_outlet_pressure: np.ndarray,
    rated_flow: float,
    rated_power: float,
    rated_frequency: float
) -> np.ndarray:
    """
    基于功率、频率、出口压力估算流量
    
    公式：Q = Q_rated × (f / f_rated) × sqrt(P / P_rated)
    
    其中：
    - Q: 实际流量
    - Q_rated: 额定流量
    - f: 实际频率
    - f_rated: 额定频率
    - P: 实际功率
    - P_rated: 额定功率
    """
    frequency_ratio = pump_frequency / rated_frequency
    power_ratio = pump_active_power / rated_power
    flow_rate = rated_flow * frequency_ratio * np.sqrt(power_ratio)
    return flow_rate
```

**修复后的效果**：
- ✅ pump_flow_rate 有了新的计算方法，不依赖 main_pipeline_flow_rate 和 pump_inlet_pressure
- ✅ 其他依赖 pump_flow_rate 的指标（pump_cumulative_flow, pump_efficiency, pump_torque）可以正常工作
