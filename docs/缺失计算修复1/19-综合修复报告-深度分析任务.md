### 2. P1 问题深度分析：指标计算失败

**执行的分析**：
1. ✅ SQL 查询验证依赖数据是否存在
2. ✅ 检查 mv_device_running_1s 表的数据分布
3. ✅ 分析 calculation_method_registry 表的方法注册情况
4. ✅ 代码分析：MethodSelector 的依赖检查和条件检查逻辑
5. ✅ 代码分析：Orchestrator 的 running_count 查询逻辑

**根本原因**：

#### 原因1：缺失原始数据 - pump_inlet_pressure

- pump_inlet_pressure（泵进口压力）是原始指标，不是计算指标
- fact_measurements 表中**没有** pump_inlet_pressure 的数据
- 影响：
  - pump_head 的2个方法都失败（都依赖 pump_inlet_pressure）
  - pump_flow_rate 方法F 失败（依赖 pump_inlet_pressure）

#### 原因2：数据分配错误 - main_pipeline_flow_rate

- main_pipeline_flow_rate（主管流量）是总管级别的指标
- 只有设备183（总管）有数据，设备177-182（6个泵）没有数据
- 影响：
  - pump_flow_rate 的4个方法失败（方法A/C/D/E 都依赖 main_pipeline_flow_rate）

#### 原因3：循环依赖问题 - pump_cumulative_flow

- pump_flow_rate 方法B 依赖 pump_cumulative_flow
- pump_cumulative_flow 本身也依赖 pump_flow_rate
- 影响：
  - pump_flow_rate 方法B 无法使用（循环依赖）

**结论**：
- pump_flow_rate 的6个方法**全部失败**
- pump_head 的2个方法**全部失败**
- 其他依赖这些指标的计算也全部失败

**计算公式**（示例）：

```python
def calculate_pump_flow_rate_method_g(
    pump_active_power: np.ndarray,
    pump_frequency: np.ndarray,
    pump_outlet_pressure: np.ndarray,
    rated_flow: float,
    rated_power: float,
    rated_frequency: float
) -> np.ndarray:
    """
    基于功率、频率、出口压力估算流量
    
    公式：Q = Q_rated × (f / f_rated) × sqrt(P / P_rated)
    """
    frequency_ratio = pump_frequency / rated_frequency
    power_ratio = pump_active_power / rated_power
    flow_rate = rated_flow * frequency_ratio * np.sqrt(power_ratio)
    return flow_rate
```
