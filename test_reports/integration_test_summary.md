## ❌ 失败案例分析

### 案例1: pump_inlet_pressure - 设备1

**错误信息**:
```
没有找到合适的计算方法，所有方法的依赖或条件都不满足
```

**根本原因**:
- 设备1缺少 `pool_liquid_level` 参数（L_offset, pipe_diameter）
- 导致"静压法"方法的条件检查失败
- "等效损失系数法"也不可用

**解决方案**:
1. 为设备1添加 pool_liquid_level 参数
2. 或者为设备1配置其他可用的计算方法
