## 📊 注释内容详情

### 表级注释（更新后）

```sql
COMMENT ON TABLE public.quality_profile_log IS $DOC$
质量过程性能剖析日志（按窗口/阶段记录耗时与行数）

用途: 记录质量标注流程（sp_mark_quality_window_vfast）中每个执行阶段的性能指标，
包括窗口构建、各质量规则更新等阶段的耗时和影响行数。

使用场景:
- 性能监控: 分析质量标注流程的性能瓶颈
- 统计分析: 汇总各质量规则的命中数量（通过rows_affected聚合）
- 故障排查: 定位质量标注过程中的异常阶段

关联模块:
- 写入: sp_mark_quality_window_vfast 存储过程
- 读取: app/services/quality/mark_window.py（质量规则命中统计）
- 读取: scripts/verify_quality_counts.py（质量统计验证）

数据特征:
- 写入频率: 每次质量标注窗口执行时写入约15条记录（对应15个阶段）
- 数据增长: 持续增长，建议定期归档或清理历史数据
$DOC$;
```

**改进点**:
- ✅ 增加了详细的用途说明
- ✅ 增加了3个使用场景
- ✅ 增加了关联模块（写入和读取的代码文件）
- ✅ 增加了数据特征（写入频率、数据增长）

### 字段注释（更新后）

| 字段名 | 更新前状态 | 更新后注释 | 改进类型 |
|--------|-----------|-----------|---------|
| window_start | ❌ 无注释 | 时间窗口开始时间（UTC时区，质量标注的起始时间戳） | 新增 |
| window_end | ❌ 无注释 | 时间窗口结束时间（UTC时区，质量标注的结束时间戳） | 新增 |
| station_id | ❌ 无注释 | 泵站ID（外键，关联dim_stations表，标识质量标注所属的泵站） | 新增 |
| device_id | ⚠️ 不够详细 | 设备ID（外键，关联dim_devices表，标识质量标注所属的设备） | 优化 |
| stage | ❌ 无注释 | 执行阶段标识（如fwin_build表示窗口构建，update_XXX表示质量规则XXX的更新阶段） | 新增 |
| duration_ms | ❌ 无注释 | 执行耗时（毫秒，记录该阶段从开始到结束的时间消耗） | 新增 |
| rows_affected | ❌ 无注释 | 影响行数（该阶段操作影响的数据行数，如更新质量码的记录数） | 新增 |
| details | ❌ 无注释 | 详细信息（JSONB格式，预留字段，用于存储额外的执行细节，当前未使用） | 新增 |
| code | ❌ 无注释 | 质量规则代码（整数，如101、111、751等，由触发器从stage字段自动解析填充，用于优化查询） | 新增 |
