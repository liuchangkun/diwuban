## 🔍 测试修复过程

### 问题1：备份数据格式不匹配
**错误**：`ValueError: not enough values to unpack (expected 6, got 4)`

**原因**：测试数据字段数与实际实现不匹配
- 测试数据：4个字段
- 实际实现：capabilities 6个字段，metadata 7个字段

**修复**：更新测试数据格式
```python
# capabilities: (id, station_name, device_name, capability_key, capability_value, remark)
# metadata: (id, station_name, device_name, metric_key, override_key, override_value, remark)
```

### 问题2：表删除数量不匹配
**错误**：`assert 150 == 140` 和 `assert 15 == 14`

**原因**：测试期望14个表，实际删除15个操作
- 实际删除：9+1+1+1+2+1 = 15个操作

**修复**：更新测试断言
```python
assert total_deleted == 150  # 15 operations * 10 rows
assert mock_cur.execute.call_count == 15
```

### 问题3：Mock 路径错误
**错误**：`AttributeError: <module 'app.services.ingest.prepare_dim'> does not have the attribute 'DependencyAnalyzer'`

**原因**：Mock 路径不正确，函数在函数内部导入

**修复**：使用正确的 mock 路径
```python
@patch("app.services.calculation.dependency_analyzer.DependencyAnalyzer")
@patch("pathlib.Path.exists")
@patch("pathlib.Path.read_text")
```

### 问题4：TRUNCATE 返回值
**错误**：`assert 0 == 600`

**原因**：TRUNCATE 不更新 cursor.rowcount

**修复**：更新测试期望值
```python
assert total_deleted == 0  # TRUNCATE doesn't return rowcount
assert mock_cur.execute.call_count == 6
```

### 问题5：外部依赖缺失
**错误**：`ModuleNotFoundError: No module named 'statsmodels'`

**原因**：`_generate_rule_tables` 依赖外部库

def test_clear_deletion_order(self):
    """测试关键逻辑：验证删除顺序正确"""
    mock_cur = Mock()
    mock_cur.rowcount = 1
    
    _clear_dependent_tables(mock_cur)
    
    # 验证第1层表先删除（fact_measurements 应该在前面）
    calls = [str(call) for call in mock_cur.execute.call_args_list]
    fact_measurements_index = next(i for i, call in enumerate(calls) if "fact_measurements" in call)
    dim_devices_index = next(i for i, call in enumerate(calls) if "dim_devices" in call and "dim_device_capabilities" not in call)
    
    # fact_measurements 应该在 dim_devices 之前删除
    assert fact_measurements_index < dim_devices_index
