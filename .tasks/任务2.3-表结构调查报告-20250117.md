## 📊 **表1：dim_device_capabilities（设备能力表）**

### 实际数据库表结构

| 字段名 | 数据类型 | 可空 | 默认值 | 说明 |
|--------|---------|------|--------|------|
| `device_id` | bigint | NO | - | **主键**，外键引用 dim_devices.id |
| `vfd_enabled` | boolean | YES | - | 变频器是否启用 |
| `freq_min` | double precision | YES | - | 最小频率 |
| `freq_max` | double precision | YES | - | 最大频率 |
| `rated_power_kw` | double precision | YES | - | 额定功率（千瓦） |
| `rated_current_a` | double precision | YES | - | 额定电流（安培） |
| `remark` | text | YES | - | 备注 |
| `updated_at` | timestamp with time zone | NO | now() | 更新时间 |
| `updated_by` | text | YES | - | 更新人 |

**约束**：
- **主键**：`device_id`
- **外键**：`device_id` → `dim_devices.id`
- **唯一约束**：无

### 代码中的假设（错误）

**备份查询**（第317-329行）：
```sql
SELECT
    dc.id,                    -- ❌ 不存在
    ds.name AS station_name,
    dd.name AS device_name,
    dc.capability_key,        -- ❌ 不存在
    dc.capability_value,      -- ❌ 不存在
    dc.remark
FROM dim_device_capabilities dc
JOIN dim_devices dd ON dc.device_id = dd.id
JOIN dim_stations ds ON dd.station_id = ds.id
```

**恢复查询**（第361-370行）：
```sql
INSERT INTO dim_device_capabilities (device_id, capability_key, capability_value, remark)
SELECT dd.id, %s, %s, %s
FROM dim_devices dd
JOIN dim_stations ds ON dd.station_id = ds.id
WHERE ds.name = %s AND dd.name = %s
ON CONFLICT (device_id, capability_key) DO UPDATE  -- ❌ 错误的冲突键
SET capability_value = EXCLUDED.capability_value,
    remark = EXCLUDED.remark
```

### 问题分析

| 问题 | 代码假设 | 实际情况 | 影响 |
|------|---------|---------|------|
| 主键字段 | `id` | `device_id` | ❌ 查询失败 |
| 数据模型 | key-value 模式（`capability_key`, `capability_value`） | 具体字段模式（`vfd_enabled`, `freq_min`, 等） | ❌ 查询失败 |
| 冲突键 | `(device_id, capability_key)` | `device_id`（主键） | ❌ 恢复失败 |
| 审计字段 | 无 | `updated_at`, `updated_by` | ⚠️ 未使用 |
