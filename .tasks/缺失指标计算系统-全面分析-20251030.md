### RLS算法实现

**核心公式**:
```
K(k) = P(k-1) * φ(k) / [λ + φ(k)ᵀ * P(k-1) * φ(k)]  # 增益矩阵
θ(k) = θ(k-1) + K(k) * [y(k) - φ(k)ᵀ * θ(k-1)]      # 参数更新
P(k) = [P(k-1) - K(k) * φ(k)ᵀ * P(k-1)] / λ          # 协方差更新
```

**关键特性**:
- 遗忘因子 λ = 0.98
- 协方差矩阵递归更新
- 参数历史记录到 optimization_history 表
- 性能评分 (RMSE, MAE, R², MAPE)

## � 关键问题发现

### 问题1: pump_inlet_pressure未在数据库注册 ⚠️⚠️⚠️

**严重性**: 🔴 **极高** - 这是导致85%计算失败的根本原因!

**发现**:
- 代码中已实现2个pump_inlet_pressure计算方法 (method_a, method_b)
- CALCULATOR_REGISTRY中已注册这2个方法
- **但数据库calculation_method_registry表中没有pump_inlet_pressure的记录!**

**影响**:
- pump_head依赖pump_inlet_pressure (2个方法都需要)
- pump_outlet_pressure_method_c依赖pump_inlet_pressure
- main_pipeline_inlet_pressure依赖pump_inlet_pressure (4个方法中3个需要)
- main_pipeline_outlet_pressure_method_b依赖pump_inlet_pressure

**根因分析**:
- 代码实现与数据库注册不同步
- 可能是SQL初始化脚本遗漏
- 或者是数据库迁移未执行

**解决方案**:
1. 检查SQL初始化脚本是否包含pump_inlet_pressure
2. 如果包含,需要重新执行SQL脚本
3. 如果不包含,需要添加SQL注册语句

### 问题2: 数据库注册方法数量与代码不一致

**数据库统计** (26个启用方法):

### 问题3: 循环依赖风险

**当前处理**: ✅ 已有循环依赖求解器 (cyclic_solver.py)
