### 阶段1：当前设备的权重计算（本地计算）

**代码位置**：`orchestrator.py:1675-1692`

```python
# 获取当前设备的数据
power = np.asarray(data.get("pump_active_power"), dtype=float)
freq = np.asarray(data.get("pump_frequency"), dtype=float)

# 加载参数
params_cfg = self.load_parameters(device_id, method.method_id)
alpha = float(params_cfg.get("alpha", 1.0))
beta = float(params_cfg.get("beta", 1.0))
f_thr = float(params_cfg.get("f_thr", 3.0))
p_thr = float(params_cfg.get("p_thr", 0.5))

# 计算当前设备的权重
weight_i = np.zeros_like(power, dtype=float)
valid_mask = (
    ~np.isnan(power)
    & ~np.isnan(freq)
    & (freq >= f_thr)      # ← 阈值过滤
    & (power >= p_thr)     # ← 阈值过滤
)
if np.any(valid_mask):
    weight_i[valid_mask] = np.power(power[valid_mask], alpha) * np.power(freq[valid_mask], beta)

# 提前返回检查
if not np.any(weight_i > 0):
    data["__pump_flow_rate_share"] = share  # share = NaN
    return
```

**设备3的情况**：

- freq = 4.90 Hz ≥ 3.0 Hz ✅
- valid_mask = True ✅
- weight_i = 3.2^1.0 × 4.90^1.0 = 15.68 ✅

## 🚨 问题发现

### 问题：设备3的实际存储值是3344.907 m³/h，而不是2.38 m³/h

**可能的原因**：

#### 假设1：share值计算错误
- 如果 share = 1.0（100%），则流量 = 3344.907 × 1.0 = 3344.907 ✅ 符合实际
- 但根据代码逻辑，share应该 = 0.000713

#### 假设2：valid_mask[idx] 判断错误
- 如果 valid_mask[idx] = False，则 share[idx] 保持 NaN
- 但设备3的功率和频率都满足阈值，valid_mask应该 = True

#### 假设3：weight_totals 计算错误
- 如果 weight_totals = 15.68（只包含设备3），则 share = 15.68 / 15.68 = 1.0 ✅
- 这说明权重总和计算时，可能只计入了设备3，而没有计入设备2和设备6

#### 假设4：数据加载时间不一致
- 如果当前设备的数据时间点与权重总和查询的时间点不一致
- 可能导致 weight_totals.get(ts) 返回 None 或错误的值

## 🎯 最终结论

### 问题根源：设备3的pump_flow_rate值为什么是3344.907？

经过深入分析和验证，**假设3被否定**：
- mv_device_running_1s表的数据正确（所有设备running=1）
- 权重总和计算的SQL查询正确（返回设备1-6的数据）
- 权重总和应该是21,987.58（包含设备2、3、6）

**新的可能原因**：

#### 可能性1：计算时间点不一致
- 设备3计算pump_flow_rate时，mv_device_running_1s表的状态可能不同
- 如果当时只有设备3的running=1，则weight_totals=15.68，份额=100%

#### 可能性2：数据加载时间窗口问题
- 设备3的数据加载时间窗口与权重计算的时间窗口不一致
- 导致weight_totals.get(ts)返回错误的值

#### 可能性3：批处理顺序问题
- 设备3先于设备2和设备6计算
- 计算时设备2和设备6的数据尚未写入fact_measurements表
- 导致权重总和只包含设备3

#### 可能性4：缓存或状态问题
- _prepare_flow_rate_share方法可能使用了缓存的权重总和
- 缓存的值只包含设备3
