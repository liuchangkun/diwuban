### 问题1: 文件大小严重超标 ⚠️ 违反项目规则

**位置**: 多个核心文件

**问题描述**:
- `orchestrator.py`: **1405行**（超出600行限制805行，**超标134%**）
- `calculators.py`: **1180行**（超出580行，**超标97%**）
- `dependency_analyzer.py`: **783行**（超出183行，**超标31%**）
- `validator.py`: **961行**（超出361行，**超标60%**）

**违反规则**: 
- 项目规则明确要求：**单文件代码行数不超过600行**
- 编码规范要求：遵循SOLID原则（单一职责原则）

**影响**:
- ❌ 严重违反项目强制规则
- ❌ 代码可维护性极差
- ❌ 违反单一职责原则
- ❌ 难以理解、测试和调试
- ❌ 增加代码审查难度

**修复方案**:

**orchestrator.py 拆分方案**（1405行 → 4个文件）:
```
orchestrator_core.py      - 核心编排逻辑（300行）
orchestrator_data.py      - 数据加载逻辑（300行）
orchestrator_batch.py     - 批量计算逻辑（400行）
orchestrator_io.py        - 数据库读写逻辑（300行）
```

**calculators.py 拆分方案**（1180行 → 5个文件）:
```
calculators_flow.py       - 流量相关（6个函数，~300行）
calculators_pressure.py   - 压力相关（7个函数，~350行）
calculators_power.py      - 功率/效率/扭矩（6个函数，~300行）
calculators_speed.py      - 转速/累计流量（4个函数，~200行）
calculators_registry.py   - 注册表和工具函数（~50行）
```

**dependency_analyzer.py 拆分方案**（783行 → 2个文件）:
```
dependency_graph.py       - 图构建和分析（400行）
dependency_solver.py      - 拓扑排序和循环检测（300行）
```

**validator.py 拆分方案**（961行 → 3个文件）:
```
validator_basic.py        - 基础验证（300行）
validator_physics.py      - 物理规律验证（300行）
validator_curve.py        - 特性曲线验证（300行）
```
