## 📊 执行摘要

经过深度代码审查、数据库分析和架构评估，我对缺失指标计算功能有了**全面而深刻**的理解。这是一个**战略级核心功能**，技术复杂度极高，但价值巨大。

### 核心发现（Top 10）

1. **需要计算的指标是8个，不是6个**：pump_flow_rate, pump_head, pump_outlet_pressure, pump_efficiency, pump_speed, pump_torque, main_pipeline_outlet_pressure, pump_cumulative_flow

2. **存在循环依赖**：pump_head ↔ pump_outlet_pressure，需要通过优先级策略解决

3. **metric_key vs metric_id不一致**：metrics_presence使用metric_key（text），fact_measurements使用metric_id（bigint），需要高效映射机制

4. **数据规模惊人**：当前仅2小时数据，但年度数据量将达到40亿行，必须考虑性能优化

5. **已有presence_writer服务**：负责识别可用/缺失指标，我们的功能是其下游，需要紧密集成

6. **acquisition_status有三种状态**："可以"、"可能"、"不能"，需要运行时判断

7. **设备类型过滤**：pump设备只计算pump_开头的指标，main_pipeline设备只计算main_pipeline_开头的指标

8. **依赖链深度达4层**：pump_efficiency依赖pump_flow_rate和pump_head，而这两者又有各自的依赖

9. **验证机制需要两层**：物理定律验证 + 特性曲线验证，缺一不可

10. **性能优化是关键**：需要向量化计算、JIT编译、批量写入、并行处理等多种优化手段

### 建议2：建立metric_key ↔ metric_id高效映射机制（关键⭐⭐⭐⭐⭐）

**问题**：
- metrics_presence_per_second_device使用metric_key（text数组）
- fact_measurements使用metric_id（bigint）
- 每次计算都需要转换，频率极高

**解决方案**：
```python
class MetricMapper:
    """指标映射器（单例模式）"""
    
    def __init__(self):
        self._key_to_id: Dict[str, int] = {}
        self._id_to_key: Dict[int, str] = {}
        self._last_refresh: datetime = None
        self._refresh_interval: timedelta = timedelta(hours=1)
    
    def load_from_db(self, conn):
        """从数据库加载映射"""
        query = "SELECT id, metric_key FROM dim_metric_config"
        for row in conn.execute(query):
            self._key_to_id[row['metric_key']] = row['id']
            self._id_to_key[row['id']] = row['metric_key']
        self._last_refresh = datetime.now()
    
    def key_to_id(self, key: str) -> Optional[int]:
        """metric_key → metric_id"""
        self._check_refresh()
        return self._key_to_id.get(key)
    
    def id_to_key(self, id: int) -> Optional[str]:
        """metric_id → metric_key"""
        self._check_refresh()
        return self._id_to_key.get(id)
    
    def keys_to_ids(self, keys: List[str]) -> List[int]:
        """批量转换"""
        return [self.key_to_id(k) for k in keys if self.key_to_id(k) is not None]

# 全局单例
metric_mapper = MetricMapper()
```

**性能提升**：
- 查询数据库：~10ms/次
- 内存缓存：~0.001ms/次
- **提升10,000倍**

## 🏗️ 架构设计建议（详细版）

### 模块1：依赖分析器（DependencyAnalyzer）

**职责**：
- 解析计算方法的依赖关系
- 构建有向无环图（DAG）
- 检测循环依赖
- 生成拓扑排序的计算顺序

**核心算法**：
```python
class DependencyAnalyzer:
    def __init__(self, method_registry):
        self.method_registry = method_registry
        self.dependency_graph = {}
    
    def build_graph(self, metrics_to_compute: List[str]) -> Dict[str, List[str]]:
        """构建依赖图"""
        graph = {}
        for metric in metrics_to_compute:
            methods = self.method_registry.get_methods(metric)
            # 选择优先级最高的方法
            method = methods[0]
            # 获取依赖
            dependencies = method.get_dependencies()
            graph[metric] = dependencies
        return graph
    
    def topological_sort(self, graph: Dict[str, List[str]]) -> List[str]:
        """拓扑排序（Kahn算法）"""
        # 计算入度
        in_degree = {node: 0 for node in graph}
        for node in graph:
            for dep in graph[node]:
                if dep in in_degree:
                    in_degree[dep] += 1
        
        # 找到入度为0的节点
        queue = [node for node in in_degree if in_degree[node] == 0]
        result = []
        
        while queue:
            node = queue.pop(0)
            result.append(node)
            
            for neighbor in graph.get(node, []):
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)
        
        # 检查是否有循环
        if len(result) != len(graph):
            raise CircularDependencyError("检测到循环依赖")
        
        return result
    
    def detect_circular_dependency(self, graph: Dict[str, List[str]]) -> Optional[List[str]]:
        """检测循环依赖"""
        visited = set()
        rec_stack = set()
        
        def dfs(node, path):
            visited.add(node)
            rec_stack.add(node)
            path.append(node)
            
            for neighbor in graph.get(node, []):
                if neighbor not in visited:
                    cycle = dfs(neighbor, path.copy())
                    if cycle:
                        return cycle
                elif neighbor in rec_stack:
                    # 找到循环
                    cycle_start = path.index(neighbor)
                    return path[cycle_start:] + [neighbor]
            
            rec_stack.remove(node)
            return None
        
        for node in graph:
            if node not in visited:
                cycle = dfs(node, [])
                if cycle:
                    return cycle
        
        return None
```

**输入**：
- 需要计算的指标列表
- 计算方法注册表

**输出**：
- 排序后的计算顺序
- 循环依赖检测结果

### 模块2：方法选择器（MethodSelector）

**职责**：
- 根据可用指标选择最佳计算方法
- 根据运行状态过滤方法
- 支持优先级和条件匹配

**核心算法**：
```python
class MethodSelector:
    def __init__(self, method_registry):
        self.method_registry = method_registry
    
    def select_method(
        self,
        metric_key: str,
        available_metrics: Set[str],
        device_state: Dict
    ) -> Optional[CalculationMethod]:
        """选择最佳计算方法"""
        # 1. 获取所有可用方法
        methods = self.method_registry.get_methods(metric_key)
        
        # 2. 按优先级排序
        methods = sorted(methods, key=lambda m: m.priority, reverse=True)
        
        # 3. 逐个检查条件
        for method in methods:
            # 检查依赖指标是否可用
            if not self._check_dependencies(method, available_metrics):
                continue
            
            # 检查使用条件
            if not self._check_conditions(method, device_state):
                continue
            
            # 找到可用方法
            return method
        
        # 没有可用方法
        return None
    
    def _check_dependencies(
        self,
        method: CalculationMethod,
        available_metrics: Set[str]
    ) -> bool:
        """检查依赖指标是否可用"""
        required = set(method.get_dependencies())
        return required.issubset(available_metrics)
    
    def _check_conditions(
        self,
        method: CalculationMethod,
        device_state: Dict
    ) -> bool:
        """检查使用条件"""
        conditions = method.get_conditions()
        
        for condition in conditions:
            if condition['type'] == 'running_count':
                if device_state.get('running_count', 0) < condition['min']:
                    return False
            elif condition['type'] == 'device_type':
                if device_state.get('device_type') != condition['value']:
                    return False
            # ... 其他条件
        
        return True
```

**输入**：
- 目标指标
- 可用指标集合
- 设备状态

**输出**：
- 选中的计算方法
- 或None（无可用方法）

### 模块3：计算引擎（CalculationEngine）

**职责**：
- 实现所有计算函数
- 支持向量化计算
- 处理异常情况

**核心设计**：
```python
class CalculationEngine:
    """计算引擎（函数式设计）"""
    
    @staticmethod
    @vectorize_numpy
    def calc_pump_flow_rate_method_a(
        total_flow: np.ndarray,
        powers: np.ndarray,
        frequencies: np.ndarray,
        params: Dict
    ) -> np.ndarray:
        """方案A：功率×频率分摊"""
        alpha = params.get('alpha', 1.0)
        beta = params.get('beta', 1.0)
        f_thr = params.get('f_thr', 3.0)
        p_thr = params.get('p_thr', 0.5)
        
        # 识别运行泵
        running_mask = (frequencies > f_thr) & (powers > p_thr)
        
        # 计算权重
        weights = (powers ** alpha) * (frequencies ** beta)
        weights = weights * running_mask
        
        # 归一化
        weights_sum = weights.sum(axis=1, keepdims=True)
        weights_norm = np.where(weights_sum > 0, weights / weights_sum, 0)
        
        # 分摊流量
        pump_flows = total_flow[:, np.newaxis] * weights_norm
        
        return pump_flows
    
    @staticmethod
    @vectorize_numpy
    def calc_pump_head(
        outlet_pressure: np.ndarray,
        inlet_pressure: np.ndarray,
        params: Dict
    ) -> np.ndarray:
        """计算泵扬程"""
        rho = params.get('rho', 1000.0)
        g = params.get('g', 9.80665)
        b_H = params.get('b_H', 0.0)
        
        delta_p_MPa = outlet_pressure - inlet_pressure
        pump_head = (delta_p_MPa * 1e6) / (rho * g) + b_H
        
        return pump_head
    
    # ... 其他计算函数
```

**设计原则**：
1. **纯函数**：无副作用，便于测试
2. **向量化**：使用NumPy向量化操作
3. **参数化**：所有常量通过参数传入
4. **异常处理**：返回NaN而不是抛出异常

### 模块4：验证器（Validator）

**职责**：
- 物理定律验证
- 特性曲线验证
- 统计阈值验证

**核心设计**：
```python
class Validator:
    def __init__(self, curve_service):
        self.curve_service = curve_service
        self.physics_validator = PhysicsValidator()
        self.curve_validator = CurveValidator(curve_service)
        self.statistical_validator = StatisticalValidator()
    
    def validate(
        self,
        metric_key: str,
        values: np.ndarray,
        context: Dict
    ) -> Tuple[np.ndarray, np.ndarray, List[str]]:
        """
        验证计算结果
        
        返回:
            - valid_mask: 布尔数组，True表示验证通过
            - quality_codes: 质量码数组
            - failure_reasons: 失败原因列表
        """
        n = len(values)
        valid_mask = np.ones(n, dtype=bool)
        quality_codes = np.zeros(n, dtype=int)
        failure_reasons = []
        
        # 第一层：物理定律验证
        physics_valid, physics_codes, physics_reasons = \
            self.physics_validator.validate(metric_key, values, context)
        valid_mask &= physics_valid
        quality_codes |= physics_codes
        failure_reasons.extend(physics_reasons)
        
        # 第二层：特性曲线验证
        if self.curve_service.has_curve(context['device_id'], metric_key):
            curve_valid, curve_codes, curve_reasons = \
                self.curve_validator.validate(metric_key, values, context)
            valid_mask &= curve_valid
            quality_codes |= curve_codes
            failure_reasons.extend(curve_reasons)
        
        # 第三层：统计阈值验证
        stat_valid, stat_codes, stat_reasons = \
            self.statistical_validator.validate(metric_key, values, context)
        valid_mask &= stat_valid
        quality_codes |= stat_codes
        failure_reasons.extend(stat_reasons)
        
        return valid_mask, quality_codes, failure_reasons
```

```sql
    station_id BIGINT NOT NULL,
    device_id BIGINT NOT NULL,
    metric_key TEXT NOT NULL,
    ts_second TIMESTAMPTZ NOT NULL,
    method_id TEXT,
    error_type TEXT NOT NULL,                  -- missing_data/validation_failed/calculation_error/circular_dependency
    error_message TEXT NOT NULL,
    error_details JSONB,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_cfl_device_time ON calculation_failures_log(device_id, ts_second);
CREATE INDEX idx_cfl_metric ON calculation_failures_log(metric_key);
CREATE INDEX idx_cfl_error_type ON calculation_failures_log(error_type);

COMMENT ON TABLE calculation_failures_log IS '计算失败日志表：记录所有计算和验证失败的情况';
```
