**目标**: 执行完全自适应、零硬编码的物理常数和计算参数管理方案

---

## 📋 核心要求

### 1. 数据库配置要求
- ✅ 所有物理常数（P_atm, rho, g 等）必须存储在 `calculation_parameters` 表中
- ✅ 所有计算方法的参数必须存储在 `calculation_parameters` 表中
- ✅ 参数配置必须支持三级参数体系：
  - 全局级（station_id=NULL, device_id=NULL）
  - 泵站级（station_id=X, device_id=NULL）
  - 设备级（station_id=X, device_id=Y）

### 2. 代码实现要求
- ❌ **禁止**在代码中使用硬编码的默认值（如 `params.get('P_atm', 0.101325)`）
- ✅ **必须**从数据库读取参数，如果参数缺失则报错或记录警告
- ✅ **必须**使用 orchestrator 的参数加载机制统一管理参数

### 3. 自适应SQL脚本要求
- ✅ 将物理常数配置集成到 `scripts/sql/adaptive/03_calculation_parameters.sql`
- ✅ 确保每次 prepare-dim 流程自动重新生成所有参数配置
- ✅ 使用自适应关联（station_name + device_name）而不是硬编码ID

### 阶段3：修改代码移除硬编码默认值

**目标**: 修改所有计算方法代码，强制从数据库读取参数

**需要修改的文件**:
1. `app/services/calculation/calculators.py`
2. `app/services/calculation/methods/pump_inlet_pressure.py`
3. `app/services/calculation/methods/eff_simple_v1.py`
4. `app/services/calculation/methods/head_coef_v1.py`
5. `app/services/calculation/methods/pin_coef_v1.py`
6. `app/services/calculation/calculators/head_coef_v1.py`
7. `app/services/calculation/calculators/eff_simple_v1.py`
8. `app/services/calculation/validator.py`

**修改原则**:

#### 3.1 物理常数（必须从数据库读取，不允许默认值）

**修改前**:
```python
P_atm = float(params.get('P_atm', 0.101325))
rho = float(params.get('rho', 1000.0))
g = float(params.get('g', 9.80665))
```

**修改后**:
```python
# 物理常数必须从数据库读取，不允许默认值
try:
    P_atm = float(params['P_atm'])
    rho = float(params['rho'])
    g = float(params['g'])
except KeyError as e:
    raise ValueError(f"缺少必需的物理常数参数: {e}")
```

#### 3.2 可优化参数（允许默认值，但记录警告）

**修改前**:
```python
eta_motor = float(params.get('eta_motor', 0.92))
eta_max = float(params.get('eta_max', 0.85))
```

**修改后**:
```python
# 可优化参数允许默认值，但记录警告
eta_motor = float(params.get('eta_motor', 0.92))
if 'eta_motor' not in params:
    logger.warning(f"参数 eta_motor 未在数据库中配置，使用默认值 0.92")

eta_max = float(params.get('eta_max', 0.85))
if 'eta_max' not in params:
    logger.warning(f"参数 eta_max 未在数据库中配置，使用默认值 0.85")
```

#### 3.3 系数参数（必须从数据库读取）

**修改前**:
```python
a0 = float(params.get('a0', 0.0))
a1 = float(params.get('a1', 1.0))
```

**修改后**:
```python
# 系数参数必须从数据库读取
try:
    a0 = float(params['a0'])
    a1 = float(params['a1'])
except KeyError as e:
    raise ValueError(f"缺少必需的系数参数: {e}")
```
