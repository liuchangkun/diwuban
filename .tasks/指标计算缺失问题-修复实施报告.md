## 📋 执行摘要

### 问题回顾

**核心问题**：36个指标缺失，device_running 步骤从未成功运行

**根本原因**：
1. `device_running_thresholds` 表完全为空（系统性配置缺失）
2. `prepare-dim` 阶段2 的 `run_running_thresholds()` 函数只设置 pf_min/pf_max，不设置核心运行判断阈值（设计缺陷）
3. 设备从 89-94 更新到 105-110 后，阈值配置未自动迁移（数据迁移问题）
4. 缺少阈值完整性验证机制，导致静默失败（验证缺失）

### 解决方案

**方案名称**：完全数据驱动的自适应阈值学习方案

**核心设计**：
- 创建4个新的存储过程，从 `fact_measurements` 表自动学习设备运行阈值
- 扩展 `run_running_thresholds()` 函数调用新存储过程
- 添加验证函数检查阈值完整性
- 完全符合项目约束（自适应、零硬编码、数据驱动）

### 阶段1：创建存储过程（数据库层）

#### 1.1 电流阈值学习存储过程

**文件**：`scripts/sql/migrations/052_create_sp_refresh_device_running_thresholds_current.sql`

**功能**：
- 从 `fact_measurements` 表读取三相电流数据（pump_current_a/b/c）
- 计算三相电流最大值：max(Ia, Ib, Ic)
- 使用 Otsu 双峰法（简化版：中位数）计算分割阈值
- 计算滞回带：2 * MAD（中位数绝对偏差）
- i_on = 阈值 + 滞回带，i_off = 阈值 - 滞回带

**回退机制**：
1. 优先从设备自己的历史数据学习（需要 >= 50 个样本）
2. 如果样本不足，使用同类型设备的中位数
3. 如果同类型设备也没有，使用全局中位数
4. 如果全局也没有，保持 NULL（不启用电流判断）

**日志输出**：
```

[电流阈值学习] 使用全局时间窗口: ... 到 ...
[电流阈值学习] 电流指标ID: A=3, B=5, C=7
[电流阈值学习] 完成 - 总设备数: 6, 成功学习: 4, 需要回退: 2
[电流阈值学习] 开始回退机制 - 使用同类型设备中位数
[电流阈值学习] 回退机制（同类型）完成 - 更新设备数: 2
[电流阈值学习] 执行完成
```

**状态**：✅ 已创建并部署到数据库

#### 1.2 功率阈值学习存储过程

**文件**：`scripts/sql/migrations/053_create_sp_refresh_device_running_thresholds_power.sql`

**功能**：
- 从 `fact_measurements` 表读取有功功率数据（pump_active_power）
- 使用与电流阈值相同的算法（Otsu 双峰法 + 滞回带）
- 默认设置 enable_p = FALSE（不启用功率判断，因为电流判断已足够）
- 但仍然计算并存储 p_on, p_off 供未来使用

**状态**：✅ 已创建并部署到数据库

#### 1.3 频率阈值学习存储过程

**文件**：`scripts/sql/migrations/054_create_sp_refresh_device_running_thresholds_frequency.sql`

**功能**：
- 从 `fact_measurements` 表读取频率数据（pump_frequency）
- 使用与电流阈值相同的算法
- 默认设置 enable_f = FALSE（不启用频率判断）
- 但仍然计算并存储 f_on, f_off 供未来使用

**状态**：✅ 已创建并部署到数据库

#### 1.4 时间参数学习存储过程

**文件**：`scripts/sql/migrations/055_create_sp_refresh_device_running_thresholds_timing.sql`

**功能**：
- 设置时间参数：grace_hold_secs, min_run_secs, min_stop_secs, smoothing_secs
- 当前版本使用合理的默认值：
  - grace_hold_secs = 30（30秒数据缺失容忍）
  - min_run_secs = 10（最小运行10秒）
  - min_stop_secs = 10（最小停止10秒）
  - smoothing_secs = 5（5秒平滑窗口）
- 未来可以从 `mv_device_running_1s` 表分析历史运行状态持续时间

**状态**：✅ 已创建并部署到数据库
