## 📝 技术发现

### 数据库表结构

#### metric_calculation_order 表
```sql
列结构:
  - metric_key: text (NOT NULL)
  - depends_on: ARRAY (NOT NULL)
  - priority: integer (NOT NULL)
  - order_index: integer (NOT NULL)
  - is_circular: boolean (NOT NULL)
  - circular_group: text (NULLABLE)
  - created_at: timestamp with time zone (NOT NULL)
  - updated_at: timestamp with time zone (NOT NULL)
  - updated_by: text (NOT NULL)
```

**说明**: 该表只存储指标的计算顺序和依赖关系，不存储具体的计算方法。计算方法应该在其他表中（如 `calculation_methods` 或 `calculation_method_registry`）。

### 代码结构

#### CalculationOrchestrator 依赖
```
CalculationOrchestrator
  ├── DependencyAnalyzer
  ├── MethodSelector
  ├── PhysicsValidator
  │   └── CharacteristicCurveManager
  │       └── scipy.interpolate.interp1d  ← 需要scipy
  ├── PerformanceMonitor
  └── AdaptiveBatchManager
```

**关键依赖**: scipy用于特性曲线的插值计算，是必需的依赖。
