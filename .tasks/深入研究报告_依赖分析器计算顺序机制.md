### 1. 依赖图构建（build_graph）

**代码位置**：`dependency_analyzer.py:97-191`

```python
def build_graph(self, metrics: List[str]) -> Dict[str, List[str]]:
    """
    构建依赖图（自动扩展所有间接依赖）
    
    为每个指标选择优先级最高的方法，构建依赖关系图。
    自动递归扩展所有间接依赖，确保依赖链完整。
    """
    graph: Dict[str, List[str]] = {}
    visited: Set[str] = set()
    auto_expanded: Set[str] = set()
    user_requested = set(metrics)
    
    def expand_dependencies(metric: str) -> None:
        """递归扩展依赖"""
        if metric in visited:
            return
        visited.add(metric)
        
        # 选择优先级最高的方法（已按priority DESC排序）
        method = self._method_registry[metric][0]
        dependencies = method['dependencies']
        
        # 将依赖添加到图中
        graph[metric] = dependencies
        
        # 递归扩展所有依赖
        for dep in dependencies:
            expand_dependencies(dep)
    
    # 从用户请求的指标开始扩展
    for metric in metrics:
        expand_dependencies(metric)
    
    return graph
```

**关键特性**：
- ✅ 自动递归扩展所有间接依赖
- ✅ 每个指标选择优先级最高的方法
- ✅ 防止重复处理（visited集合）
- ✅ 区分用户请求和自动扩展的依赖

### 2. 拓扑排序（topological_sort）

**代码位置**：`dependency_analyzer.py:193-257`

**算法**：Kahn算法（基于入度的拓扑排序）

```python
def topological_sort(self, graph: Dict[str, List[str]]) -> List[str]:
    """
    拓扑排序（Kahn算法）
    
    注意：图的格式是 {node: [dependencies]}，表示 node 依赖 dependencies。
    所以我们需要先计算 dependencies，再计算 node。
    """
    # 步骤1：计算入度（有多少节点依赖我）
    in_degree: Dict[str, int] = {node: 0 for node in graph}
    
    # 步骤2：构建反向图（谁依赖我）
    reverse_graph: Dict[str, List[str]] = {node: [] for node in graph}
    for node in graph:
        for dep in graph[node]:
            if dep in graph:
                reverse_graph[dep].append(node)
                in_degree[node] += 1
    
    # 步骤3：找到入度为0的节点（没有依赖的节点，可以最先计算）
    queue = [node for node in in_degree if in_degree[node] == 0]
    result = []
    
    # 步骤4：逐个移除入度为0的节点
    while queue:
        node = queue.pop(0)
        result.append(node)
        
        # 遍历所有依赖当前节点的节点
        for dependent in reverse_graph[node]:
            in_degree[dependent] -= 1
            if in_degree[dependent] == 0:
                queue.append(dependent)
    
    # 步骤5：检查是否有循环依赖
    if len(result) != len(graph):
        raise CircularDependencyError(...)
    
    return result
```

**示例**：
```python
# 输入依赖图:
graph = {
    'pump_efficiency': ['pump_flow_rate', 'pump_head'],
    'pump_flow_rate': ['main_pipeline_flow_rate'],
    'pump_head': ['pump_outlet_pressure'],
    'main_pipeline_flow_rate': [],
    'pump_outlet_pressure': []
}

# 计算入度:
in_degree = {
    'pump_efficiency': 0,        # 没有人依赖我
    'pump_flow_rate': 1,         # pump_efficiency依赖我
    'pump_head': 1,              # pump_efficiency依赖我
    'main_pipeline_flow_rate': 1, # pump_flow_rate依赖我
    'pump_outlet_pressure': 1    # pump_head依赖我
}

# 拓扑排序结果:
['main_pipeline_flow_rate', 'pump_outlet_pressure', 'pump_flow_rate', 'pump_head', 'pump_efficiency']
```

**计算顺序解释**：
1. `main_pipeline_flow_rate` 和 `pump_outlet_pressure` 没有依赖，最先计算
2. `pump_flow_rate` 依赖 `main_pipeline_flow_rate`，在其之后计算
3. `pump_head` 依赖 `pump_outlet_pressure`，在其之后计算
4. `pump_efficiency` 依赖 `pump_flow_rate` 和 `pump_head`，最后计算

### 3. 循环依赖检测（detect_circular_dependency）

**代码位置**：`dependency_analyzer.py:259-305`

**算法**：深度优先搜索（DFS）

```python
def detect_circular_dependency(self, graph: Dict[str, List[str]]) -> List[str]:
    """
    检测循环依赖（DFS算法）
    
    使用深度优先搜索检测图中的环。
    """
    visited: Set[str] = set()
    rec_stack: Set[str] = set()  # 递归栈
    
    def dfs(node: str, path: List[str]) -> Optional[List[str]]:
        """深度优先搜索"""
        visited.add(node)
        rec_stack.add(node)
        path.append(node)
        
        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                cycle = dfs(neighbor, path.copy())
                if cycle:
                    return cycle
            elif neighbor in rec_stack:
                # 找到循环：neighbor已经在当前路径中
                cycle_start = path.index(neighbor)
                return path[cycle_start:]
        
        rec_stack.remove(node)
        return None
    
    for node in graph:
        if node not in visited:
            cycle = dfs(node, [])
            if cycle:
                return cycle
    
    return []
```

**示例**：
```python
# 循环依赖图:
graph = {
    'A': ['B'],
    'B': ['C'],
    'C': ['A']  # 循环！
}

# DFS过程:
# 访问A → 访问B → 访问C → 发现C依赖A（A在rec_stack中）
# 返回循环路径: ['A', 'B', 'C']
```

### 4. 循环依赖处理（find_strongly_connected_components）

**代码位置**：`dependency_analyzer.py:307-370`

**算法**：Tarjan算法（查找强连通分量）

```python
def find_strongly_connected_components(self, graph: Dict[str, List[str]]) -> List[List[str]]:
    """
    使用Tarjan算法查找强连通分量（SCC）

    强连通分量是图中的最大子图，其中任意两个节点都可以相互到达。
    循环依赖组就是大小>1的强连通分量。
    """
    index_counter = [0]
    stack = []
    lowlinks = {}
    index = {}
    on_stack = set()
    sccs = []

    def strongconnect(node: str):
        """Tarjan算法的递归函数"""
        # 设置节点的索引和lowlink
        index[node] = index_counter[0]
        lowlinks[node] = index_counter[0]
        index_counter[0] += 1
        stack.append(node)
        on_stack.add(node)

        # 遍历邻居节点
        for neighbor in graph.get(node, []):
            if neighbor not in index:
                strongconnect(neighbor)
                lowlinks[node] = min(lowlinks[node], lowlinks[neighbor])
            elif neighbor in on_stack:
                lowlinks[node] = min(lowlinks[node], index[neighbor])

        # 如果node是SCC的根节点
        if lowlinks[node] == index[node]:
            scc = []
            while True:
                w = stack.pop()
                on_stack.remove(w)
                scc.append(w)
                if w == node:
                    break
            sccs.append(scc)

    for node in graph:
        if node not in index:
            strongconnect(node)

    return sccs
```

**示例**：
```python
# 循环依赖图:

    'A': ['B'],
    'B': ['C'],
    'C': ['A'],  # A-B-C形成循环
    'D': ['E'],
    'E': []
}

# Tarjan算法结果:
sccs = [
    ['A', 'B', 'C'],  # 强连通分量（循环依赖组）
    ['D'],            # 单独的节点
    ['E']             # 单独的节点
]
```

### 5. 循环依赖组识别（identify_circular_groups）

**代码位置**：`dependency_analyzer.py:372-413`

```python
def identify_circular_groups(self, graph: Dict[str, List[str]]) -> Dict[str, Optional[str]]:
    """
    识别循环依赖组

    Returns:
        字典，键为指标名，值为组ID（如果不在循环中则为None）
    """
    sccs = self.find_strongly_connected_components(graph)

    circular_groups = {}
    group_id = 0

    for scc in sccs:
        if len(scc) > 1:
            # 大小>1的SCC是循环依赖组
            group_name = f"circular_{group_id}"
            for node in scc:
                circular_groups[node] = group_name
            group_id += 1

            logger.info(f"检测到循环依赖组 {group_name}: {' ↔ '.join(sorted(scc))}")
        else:
            # 大小=1的SCC不是循环依赖
            circular_groups[scc[0]] = None

    return circular_groups
```

**示例**：
```python
# 输入:

# 输出:
circular_groups = {
    'A': 'circular_0',
    'B': 'circular_0',
    'C': 'circular_0',
    'D': None,
    'E': None
}
```

### 6. 带循环依赖的计算顺序（_get_order_with_circular_groups）

**代码位置**：`dependency_analyzer.py:415-473`

**策略**：将循环依赖组视为单个节点，进行拓扑排序

```python
def _get_order_with_circular_groups(
    self,
    graph: Dict[str, List[str]],
    circular_groups: Dict[str, Optional[str]]
) -> List[str]:
    """
    获取包含循环依赖组的计算顺序

    策略：
    1. 将每个循环依赖组缩减为一个节点
    2. 对缩减图进行拓扑排序
    3. 展开循环依赖组
    """
    # 1. 构建组成员映射
    group_members: Dict[str, List[str]] = {}
    for metric, group in circular_groups.items():
        if group is not None:
            if group not in group_members:
                group_members[group] = []
            group_members[group].append(metric)

    # 2. 构建缩减图（将循环依赖组视为单个节点）
    reduced_graph: Dict[str, List[str]] = {}
    for metric, deps in graph.items():
        group = circular_groups[metric]
        node = group if group is not None else metric

        if node not in reduced_graph:
            reduced_graph[node] = []

        for dep in deps:
            dep_group = circular_groups.get(dep)
            dep_node = dep_group if dep_group is not None else dep

            # 跳过自环（组内依赖）
            if dep_node != node and dep_node not in reduced_graph[node]:
                reduced_graph[node].append(dep_node)

    # 3. 对缩减图进行拓扑排序
    reduced_order = self.topological_sort(reduced_graph)

    # 4. 展开循环依赖组
    final_order = []
    for node in reduced_order:
        if node in group_members:
            # 这是一个循环依赖组，添加所有成员
            final_order.extend(sorted(group_members[node]))
        else:
            # 这是一个单独的指标
            final_order.append(node)

    return final_order
```

**示例**：
```python
# 原始图（包含循环依赖）:
graph = {
    'A': ['B'],
    'B': ['C'],
    'C': ['A'],  # A-B-C循环
    'D': ['A']   # D依赖循环组
}

# 循环依赖组:
circular_groups = {'A': 'circular_0', 'B': 'circular_0', 'C': 'circular_0', 'D': None}

# 缩减图:
reduced_graph = {
    'circular_0': [],  # 循环组内部依赖被移除
    'D': ['circular_0']
}

# 缩减图的拓扑排序:
reduced_order = ['circular_0', 'D']

# 展开后的最终顺序:
final_order = ['A', 'B', 'C', 'D']  # A、B、C作为一组，D在其后
```

## 📌 关键发现

### 发现1：自动依赖扩展机制

**代码位置**：`dependency_analyzer.py:123-169`

**机制**：
- 从用户请求的指标开始
- 递归扩展所有间接依赖
- 每个指标选择优先级最高的方法
- 防止重复处理（visited集合）

**影响**：
- 用户只需请求顶层指标（如pump_efficiency）
- 系统自动计算所有需要的中间指标
- 确保依赖链完整

---

### 发现2：拓扑排序保证计算顺序

**算法**：Kahn算法（基于入度）

**保证**：
- 依赖的指标一定在被依赖的指标之前计算
- 无依赖的指标（原始测量值）最先计算
- 依赖链越长的指标越晚计算

**示例**：
```
pump_efficiency 依赖 pump_flow_rate, pump_head
pump_flow_rate 依赖 main_pipeline_flow_rate
pump_head 依赖 pump_outlet_pressure

计算顺序:
1. main_pipeline_flow_rate (无依赖)
2. pump_outlet_pressure (无依赖)
3. pump_flow_rate (依赖1)
4. pump_head (依赖2)
5. pump_efficiency (依赖3和4)
```

---

### 发现3：循环依赖的特殊处理

**检测算法**：Tarjan算法（查找强连通分量）

**处理策略**：
1. 识别循环依赖组（强连通分量）
2. 将循环组视为单个节点
3. 对缩减图进行拓扑排序
4. 展开循环组（组内指标按字母顺序排列）

**实际应用**：
- 循环组内的指标需要迭代求解
- orchestrator会对循环组使用特殊的迭代计算逻辑
- 最多迭代10次，直到收敛或达到最大迭代次数

## 📊 总结

### 核心算法

| 算法 | 用途 | 时间复杂度 |
|------|------|-----------|
| DFS递归扩展 | 构建完整依赖图 | O(V + E) |
| Kahn算法 | 拓扑排序 | O(V + E) |
| DFS | 循环依赖检测 | O(V + E) |
| Tarjan算法 | 查找强连通分量 | O(V + E) |

**V = 指标数量，E = 依赖关系数量**

---

### 计算顺序决定因素

1. **依赖关系**：依赖的指标必须先计算
2. **优先级**：每个指标选择优先级最高的方法
3. **循环依赖**：循环组视为整体，组内指标按字母顺序
4. **自动扩展**：所有间接依赖自动加入计算顺序

---

**研究完成时间**：2025-11-11
**结论**：DependencyAnalyzer使用Kahn算法进行拓扑排序，Tarjan算法处理循环依赖，自动扩展所有间接依赖，确保计算顺序正确
**关键洞察**：计算顺序由依赖关系决定，无依赖的指标最先计算，依赖链越长的指标越晚计算，循环依赖组需要迭代求解
