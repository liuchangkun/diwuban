```

```

### 解决目标

- ✅ 实现按需加载机制

## 🏗️ 实施方案

### 架构设计
采用**分层按需加载架构**：

```
规则/
├── 规则-主控.md (180行) ← 添加到 Augment Rules
├── 核心模块/ (2个文件)
├── 模式模块/ (5个文件)
└── 支持模块/ (3个文件)
```

### 核心机制
1. **主控文件**：轻量级（180行），包含强制加载机制
2. **详细模块**：按需加载，AI 通过 `view` 工具读取
3. **强制加载**：主控文件中明确要求 AI 在进入模式前读取详细规则

### 快速开始

1. **在 Augment Rules 中添加主控文件**
   ```
   文件路径：规则/规则-主控.md
   ```

2. **开始使用**
   - 开始一个新对话
   - AI 会自动读取核心原则和对应模式的详细规则
   - 享受完整的 RIPER-5 协议功能

3. **验证配置**

   - 检查是否包含上下文状态报告
