## 集成指南概述

### 文档目的

本文档是**5个缺失指标实施的核心集成指南**，提供：
- ✅ 完整的基类定义和接口规范
- ✅ 共享模块的使用方式
- ✅ 完整的实施示例（可直接复制）
- ✅ 集成检查清单（避免遗漏）
- ✅ 常见问题和最佳实践

### 适用范围

本指南适用于以下5个缺失指标的实施：
1. **pump_speed**（水泵转速，metric_id=19）
2. **main_pipeline_inlet_pressure**（总管进口压力，metric_id=61）
3. **pump_shaft_power**（水泵轴功率，metric_id=66）
4. **pump_hydraulic_power**（水泵水力功率，metric_id=67）
5. **pump_torque**（水泵扭矩，metric_id=20）

### 架构概述

每个指标的实施遵循**流水线（Pipeline）架构**，包含以下模块：

```
┌─────────────────────────────────────────────────────────────┐
│                  共享层（Shared Layer）                       │
│  - Scheduler（调度器）：任务分片、并行调度、进度跟踪          │
│  - DataWriter（数据写入）：批量写入、自适应批量管理           │
│  - ParameterManager（参数管理）：三级配置加载                │
│  - SharedServices（服务管理）：单例模式管理共用模块          │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│              指标专用层（Metric-Specific Layer）              │
│  pump_speed/                                                 │
│    - Pipeline（流水线编排）：阶段定义和执行                   │
│    - DataLoader（数据获取）：加载计算所需数据                │
│    - DataFilter（数据过滤）：运行状态、质量、阈值过滤         │
│    - MethodSelector（方法选择）：依赖检查、条件检查          │
│    - Calculator（计算执行）：调用计算方法                    │
│    - Validator（结果验证）：范围、非负、NaN/Inf验证          │
│    - methods/（计算方法）：具体计算方法实现                   │
└─────────────────────────────────────────────────────────────┘
```

### 核心原则

1. **基类继承**：所有指标专用模块必须继承对应的基类
2. **接口实现**：必须实现基类定义的所有抽象方法
3. **共享模块调用**：通过`shared_services`单例访问共享模块
4. **参数管理**：所有参数从数据库加载，禁止硬编码
5. **日志规范**：使用统一的日志格式和trace_id

### 1. Pipeline（流水线编排器）基类

**职责**：定义和执行指标的计算流程

**基类定义**：

```python
from abc import ABC, abstractmethod
from typing import Dict, Optional
from datetime import datetime
import logging

class MetricCalculationPipeline(ABC):
    """指标计算流水线基类"""

    def __init__(self, metric_key: str, trace_id: Optional[str] = None):
        """
        初始化流水线

        Args:
            metric_key: 指标键（如 'pump_speed'）
            trace_id: 追踪ID（用于日志关联）
        """
        self.metric_key = metric_key
        self.trace_id = trace_id
        self.logger = logging.getLogger(__name__)

        # 初始化各个阶段（子类必须实现）
        self.data_loader = self._create_data_loader()
        self.data_filter = self._create_data_filter()
        self.method_selector = self._create_method_selector()
        self.calculator = self._create_calculator()
        self.validator = self._create_validator()

    @abstractmethod
    def _create_data_loader(self) -> 'DataLoader':
        """创建数据加载器（子类必须实现）"""
        pass

    @abstractmethod
    def _create_data_filter(self) -> 'DataFilter':
        """创建数据过滤器（子类必须实现）"""
        pass

    @abstractmethod
    def _create_method_selector(self) -> 'MethodSelector':
        """创建方法选择器（子类必须实现）"""
        pass

    @abstractmethod
    def _create_calculator(self) -> 'Calculator':
        """创建计算执行器（子类必须实现）"""
        pass

    @abstractmethod

        """创建结果验证器（子类必须实现）"""

        Returns:
            计算结果DataFrame
```

### 3. DataFilter（数据过滤器）基类

**职责**：过滤无效、异常、不符合条件的数据

**基类定义**：

```python
from abc import ABC, abstractmethod
from typing import Optional
import pandas as pd
import logging

class DataFilter(ABC):
    """数据过滤器基类"""

    def __init__(self, trace_id: Optional[str] = None):
        """
        初始化数据过滤器

        Args:
            trace_id: 追踪ID（用于日志关联）
        """
        self.trace_id = trace_id
        self.logger = logging.getLogger(__name__)

    @abstractmethod
    def filter_data(self, data: pd.DataFrame) -> pd.DataFrame:
        """
        过滤数据（子类必须实现）

        Args:
            data: 原始数据

        Returns:
            过滤后的数据
        """
        pass
```

**继承示例**：

```python
class PumpSpeedDataFilter(DataFilter):
    """pump_speed 数据过滤器"""

    def filter_data(self, data: pd.DataFrame) -> pd.DataFrame:
        """过滤运行状态数据"""

        if data.empty:
            return data

        original_count = len(data)

        self.logger.info(
            f"[DataFilter] 开始过滤 - 原始行数: {original_count}",
            extra={'trace_id': self.trace_id}
        )

        # 过滤运行状态（仅保留 running=1 的数据）
        filtered_data = data[data['running'] == 1].copy()

        filtered_count = len(filtered_data)
        filter_rate = (original_count - filtered_count) / original_count * 100

        self.logger.info(
            f"[DataFilter] 过滤完成 - 过滤后行数: {filtered_count}, 过滤比例: {filter_rate:.2f}%",
            extra={'trace_id': self.trace_id}
        )

        return filtered_data
```

**关键要求**：
- ✅ 必须使用 `mv_device_running_1s.running` 字段过滤（禁止硬编码阈值）
- ✅ 过滤 NaN、Inf、负值、异常值
- ✅ 添加详细日志（原始行数、过滤后行数、过滤比例）
- ✅ 不修改原始数据（使用 `.copy()`）

### 4. MethodSelector（方法选择器）基类

**职责**：根据数据可用性和参数配置，选择最合适的计算方法

**基类定义**：

```python
from abc import ABC, abstractmethod
from typing import Optional, Dict, List
import pandas as pd
import logging

class MethodSelector(ABC):
    """方法选择器基类"""

    def __init__(
        self,
        device_params: Optional[Dict] = None,
        trace_id: Optional[str] = None
    ):
        """
        初始化方法选择器

        Args:
            device_params: 设备参数（从 device_rated_params 加载）
            trace_id: 追踪ID（用于日志关联）
        """
        self.device_params = device_params or {}
        self.trace_id = trace_id
        self.logger = logging.getLogger(__name__)

    @abstractmethod
    def select_method(self, data: pd.DataFrame) -> str:
        """
        选择计算方法（子类必须实现）

        Args:
            data: 过滤后的数据

        Returns:
            方法ID（如 'method_a'）
        """
        pass

    def _check_dependencies(self, data: pd.DataFrame, dependencies: List[str]) -> bool:
        """
        检查依赖指标是否可用

        Args:
            data: 数据
            dependencies: 依赖指标列表

        Returns:
            是否所有依赖都可用
        """
        for dep in dependencies:
            if dep not in data.columns:
                return False
            if data[dep].isna().all():
                return False
        return True

    def _check_conditions(self, conditions: Dict) -> bool:
        """
        检查使用条件是否满足

        Args:
            conditions: 条件字典

        Returns:
            是否满足条件
        """
        # 实现条件检查逻辑
        pass
```

**继承示例**：

```python
class PumpSpeedMethodSelector(MethodSelector):
    """pump_speed 方法选择器"""

    # 方法配置（按优先级排序）
    METHODS = [
        {
            'id': 'method_a',
            'name': '频率比例法',
            'priority': 100,
            'dependencies': ['pump_frequency'],
            'conditions': {}
        },
        {
            'id': 'method_b',
            'name': '极对数法',
            'priority': 90,
            'dependencies': ['pump_frequency'],
            'conditions': {'has_device_params': ['pole_pairs', 'slip']}
        },
        {
            'id': 'method_c',
            'name': '校准系数法',
            'priority': 80,
            'dependencies': ['pump_frequency'],
            'conditions': {'calibration_quality': ['medium', 'high']}
        }
    ]

    def select_method(self, data: pd.DataFrame) -> str:
        """选择最合适的计算方法"""

        self.logger.info(
            f"[MethodSelector] 开始选择方法",
            extra={'trace_id': self.trace_id}
        )

        # 按优先级遍历方法
        for method in self.METHODS:
            # 检查依赖
            if not self._check_dependencies(data, method['dependencies']):
                self.logger.debug(
                    f"[MethodSelector] {method['id']} 依赖不满足",
                    extra={'trace_id': self.trace_id}
                )
                continue

            # 检查条件
            if not self._check_conditions(method['conditions']):
                self.logger.debug(
                    f"[MethodSelector] {method['id']} 条件不满足",
                    extra={'trace_id': self.trace_id}
                )
                continue

            # 找到可用方法
            self.logger.info(
                f"[MethodSelector] 选择方法: {method['id']} ({method['name']})",
                extra={'trace_id': self.trace_id}
            )
            return method['id']

        # 无可用方法
        raise ValueError("无可用的计算方法")
```

**关键要求**：
- ✅ 必须定义 `METHODS` 列表（包含所有方法配置）
- ✅ 按优先级排序（priority从高到低）
- ✅ 实现依赖检查（`_check_dependencies`）
- ✅ 实现条件检查（`_check_conditions`）
- ✅ 添加详细日志（方法选择过程、失败原因）
- ✅ 无可用方法时抛出 `ValueError`

### 6. Validator（结果验证器）基类

**职责**：验证计算结果的合理性

**基类定义**：

```python
from abc import ABC, abstractmethod
from typing import Optional
import pandas as pd
import numpy as np
import logging

class Validator(ABC):
    """结果验证器基类"""

    def __init__(self, trace_id: Optional[str] = None):
        """
        初始化结果验证器

        Args:
            trace_id: 追踪ID（用于日志关联）
        """
        self.trace_id = trace_id
        self.logger = logging.getLogger(__name__)

    @abstractmethod
    def validate(self, data: pd.DataFrame) -> pd.DataFrame:
        """
        验证结果（子类必须实现）

        Args:
            data: 计算结果

        Returns:
            验证后的结果（标记无效值为NaN）
        """
        pass
```

**继承示例**：

```python
class PumpSpeedValidator(Validator):
    """pump_speed 结果验证器"""

    def validate(self, data: pd.DataFrame) -> pd.DataFrame:
        """验证 pump_speed 结果"""

        if data.empty:
            return data

        original_count = len(data)

        self.logger.info(
            f"[Validator] 开始验证 - 原始行数: {original_count}",
            extra={'trace_id': self.trace_id}
        )

        result = data.copy()

        # 验证1：范围检查（0-3000 rpm）
        invalid_range = (result['pump_speed'] < 0) | (result['pump_speed'] > 3000)
        result.loc[invalid_range, 'pump_speed'] = np.nan

        # 验证2：NaN/Inf检查
        invalid_nan = result['pump_speed'].isna() | np.isinf(result['pump_speed'])
        result.loc[invalid_nan, 'pump_speed'] = np.nan

        # 统计无效值
        invalid_count = result['pump_speed'].isna().sum()
        valid_count = original_count - invalid_count
        valid_rate = valid_count / original_count * 100

        self.logger.info(
            f"[Validator] 验证完成 - 有效行数: {valid_count}, 有效率: {valid_rate:.2f}%",
            extra={'trace_id': self.trace_id}
        )

        return result
```

**关键要求**：
- ✅ 实现范围检查（根据指标的物理约束）
- ✅ 实现 NaN/Inf 检查
- ✅ 无效值标记为 NaN（不删除行）
- ✅ 添加详细日志（原始行数、有效行数、有效率）
- ✅ 不修改原始数据（使用 `.copy()`）

#### 2. pipeline.py

```python
"""
pump_speed 流水线
"""

from typing import Optional
from datetime import datetime
import pandas as pd
import logging

from .data_loader import PumpSpeedDataLoader
from .data_filter import PumpSpeedDataFilter
from .method_selector import PumpSpeedMethodSelector
from .calculator import PumpSpeedCalculator
from .validator import PumpSpeedValidator
from app.services.calculation.shared_services import shared_services


class PumpSpeedPipeline:
    """pump_speed 计算流水线"""

    def __init__(self, trace_id: Optional[str] = None):
        """
        初始化流水线

        Args:
            trace_id: 追踪ID（用于日志关联）
        """
        self.metric_key = 'pump_speed'
        self.metric_id = 19
        self.trace_id = trace_id
        self.logger = logging.getLogger(__name__)

        # 初始化各个阶段
        self.data_loader = PumpSpeedDataLoader(trace_id=trace_id)
        self.data_filter = PumpSpeedDataFilter(trace_id=trace_id)
        self.method_selector = PumpSpeedMethodSelector(trace_id=trace_id)
        self.calculator = PumpSpeedCalculator(trace_id=trace_id)
        self.validator = PumpSpeedValidator(trace_id=trace_id)

    def run(
        self,
        device_ids: list[int],
        start_time: Optional[datetime] = None,
        end_time: Optional[datetime] = None
    ) -> pd.DataFrame:
        """
        执行计算流水线

        Args:
            device_ids: 设备ID列表
            start_time: 开始时间（可选）
            end_time: 结束时间（可选）

        Returns:
            计算结果DataFrame
        """
        self.logger.info(
            f"[Pipeline] 开始执行 - 指标: {self.metric_key}, 设备: {device_ids}",
            extra={'trace_id': self.trace_id}
        )

        try:
            # Stage 1: 数据获取
            raw_data = self.data_loader.load_data(device_ids, start_time, end_time)

            # Stage 2: 数据过滤
            filtered_data = self.data_filter.filter_data(raw_data)

            # Stage 3: 方法选择
            method_id = self.method_selector.select_method(filtered_data)

            # Stage 4: 加载参数
            params = shared_services.parameter_manager.get_calculation_params(
                metric_key=self.metric_key,
                method_id=method_id
            )

            # Stage 5: 计算执行
            results = self.calculator.calculate(filtered_data, method_id, params)

            # Stage 6: 结果验证
            validated_results = self.validator.validate(results)

            # Stage 7: 数据写入
            write_result = shared_services.data_writer.write_batch(
                metric_id=self.metric_id,
                metric_key=self.metric_key,
                data=validated_results,
                trace_id=self.trace_id
            )

            self.logger.info(
                f"[Pipeline] 执行完成 - 写入行数: {write_result['written_count']}",
                extra={'trace_id': self.trace_id}
            )

            return validated_results

        except Exception as e:
            self.logger.error(
                f"[Pipeline] 执行失败: {e}",
                extra={'trace_id': self.trace_id},
                exc_info=True
            )
            raise
```
