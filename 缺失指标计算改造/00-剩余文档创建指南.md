### pump_hydraulic_power（5个文档）

#### 01-pump_hydraulic_power详细设计.md

**关键信息**：
- **指标ID**：67
- **metric_key**：pump_hydraulic_power
- **中文名称**：泵水力功率
- **单位**：kW
- **设备类型**：pump（device_id=1-6）

**计算方法**：
- **method_a - 流量-扬程法**（优先级100）
  - 公式：`P_h = ρ × g × Q × H / 1000`
  - 依赖：pump_flow_rate, pump_head
  - 参数：rho=1000.0, g=9.81（从calculation_parameters获取）

**依赖指标**：
- pump_flow_rate（metric_id=18，已实现）
- pump_head（metric_id=17，已实现）

**验证规则**：
- 范围检查：0 <= P_h <= 400 kW
- 物理约束检查：P_h < P_shaft（水力功率应小于轴功率）
- 异常值检查：相邻时刻变化 < 40 kW/s

**参数配置**：
```json
// calculation_parameters表
{
  "metric_key": "pump_hydraulic_power",
  "method_id": "method_a",
  "param_key": "rho",
  "param_value": 1000.0,
  "param_unit": "kg/m³"
}
{
  "metric_key": "pump_hydraulic_power",
  "method_id": "method_a",
  "param_key": "g",
  "param_value": 9.81,
  "param_unit": "m/s²"
}
{
  "metric_key": "pump_hydraulic_power",
  "method_id": "validation",
  "param_key": "min_power",
  "param_value": 0.0,
  "param_unit": "kW"
}
{
  "metric_key": "pump_hydraulic_power",
  "method_id": "validation",
  "param_key": "max_power",
  "param_value": 400.0,
  "param_unit": "kW"
}
{
  "metric_key": "pump_hydraulic_power",
  "method_id": "validation",
  "param_key": "max_change_rate",
  "param_value": 40.0,
  "param_unit": "kW/s"
}
```

### pump_torque（5个文档）

#### 01-pump_torque详细设计.md

**关键信息**：
- **指标ID**：20
- **metric_key**：pump_torque
- **中文名称**：泵扭矩
- **单位**：N·m
- **设备类型**：pump（device_id=1-6）

**计算方法**：
- **method_a - 功率-转速法**（优先级100）
  - 公式：`T = P × 60 / (2π × n)`
  - 依赖：pump_active_power, pump_speed
  - 参数：无（使用常数π）

- **method_b - 水力功率法**（优先级90）
  - 公式：`T = ρ × g × Q × H / (2π × n)`
  - 依赖：pump_flow_rate, pump_head, pump_speed
  - 参数：rho=1000.0, g=9.81

**依赖指标**：
- pump_active_power（metric_id=2，原始测量）
- pump_speed（metric_id=19，新实现）
- pump_flow_rate（metric_id=18，已实现）
- pump_head（metric_id=17，已实现）

**验证规则**：
- 范围检查：0 <= T <= 10000 N·m
- 交叉验证：双方法差异 < 10%
- 异常值检查：相邻时刻变化 < 500 N·m/s

**参数配置**：
