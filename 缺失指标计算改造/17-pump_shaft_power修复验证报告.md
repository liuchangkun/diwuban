## 🔍 根本原因验证

### 问题链条

1. **数据库中参数缺失**：
   ```sql
   SELECT * FROM calculation_parameters 
   WHERE metric_key = 'pump_shaft_power' 
     AND param_name = 'max_power';
   -- 结果：0条记录
   ```

2. **ParameterManager 提供了硬编码默认值**：
   ```python
   # app/services/calculation/shared/parameter_manager.py 第57行
   'max_power': 200.0  # ⬅️ 硬编码的默认值
   ```

3. **DataFilter 使用了错误的阈值**：
   ```python
   # 过滤 pump_active_power > 200.0 的数据
   data = data[data['pump_active_power'] <= 200.0]
   ```

4. **导致大量有效数据被过滤**：
   - P_active > 200 kW 的数据全部被过滤
   - 损失了 119,580 条有效数据（71.5%）

### 修复方案

1. **添加正确的参数到数据库**：
   ```sql
   INSERT INTO calculation_parameters 
   (station_id, device_id, metric_key, param_name, param_value, param_type)
   VALUES 
     (1, 1, 'pump_shaft_power', 'max_power', 350.0, 'float'),
     (1, 1, 'pump_shaft_power', 'max_shaft_power', 312.0, 'float');
   -- 为设备2-6重复
   ```

2. **清除旧数据**：
   ```sql
   DELETE FROM fact_measurements
   WHERE metric_id = (SELECT id FROM dim_metric_config WHERE metric_key = 'pump_shaft_power')
     AND device_id IN (1,2,3,4,5,6)
     AND ts_bucket >= '2025-10-22 00:00:00+00'
     AND ts_bucket < '2025-10-23 08:00:00+00';
   -- 删除了 47,667 条旧数据
   ```

3. **重新运行计算**：
   ```bash
   python scripts/run_single_metric_pump_shaft_power.py
   # 成功写入 167,247 条新数据
   ```
