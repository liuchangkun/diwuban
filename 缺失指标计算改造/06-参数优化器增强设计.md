## 概述

### 设计目标

在现有物理自洽性优化框架的基础上，增强以下6个方面：

1. **自适应权重调整**：根据数据质量自动调整约束权重
2. **分层优化策略**：全局→泵站→设备的继承式优化
3. **增量优化**：只使用新增数据，提高优化效率
4. **多目标优化**：使用Pareto最优，平衡多个约束
5. **参数变化趋势监控**：智能触发优化
6. **跨指标联合优化**：利用指标间的物理关系

### 设计原则

- ✅ 尽量利用现有数据库表（calculation_parameters, optimization_history）
- ✅ 必要时改造现有表（添加字段）
- ✅ 避免创建不必要的新表
- ✅ 保持向后兼容性
- ✅ 所有增强功能可独立开关

## 建议1: 自适应权重调整

### 1.1 核心原理

**问题**：不同泵站的数据特点不同，固定权重不够灵活

**解决方案**：根据数据质量（方差、区分度）自动调整约束权重

### 1.2 权重计算逻辑

```python
def calculate_adaptive_weights(
    self,
    data: Dict,
    metric_key: str,
    base_weights: Dict[str, float]
) -> Dict[str, float]:
    """
    根据数据质量自动调整约束权重
    
    Args:
        data: 历史数据
        metric_key: 指标键
        base_weights: 基础权重配置
    
    Returns:
        adjusted_weights: 调整后的权重
    """
    adjusted_weights = base_weights.copy()
    
    # 1. 分析功率数据质量
    power_values = data['pump_active_power']
    power_cv = np.std(power_values) / np.mean(power_values)  # 变异系数
    
    if power_cv > 0.3:  # 功率差异大（变异系数>30%）
        adjusted_weights['power_correlation'] *= 1.5  # 增加权重50%
        logger.info(f"[自适应权重] 功率数据区分度高，权重增加: {base_weights['power_correlation']} → {adjusted_weights['power_correlation']}")
    elif power_cv < 0.1:  # 功率差异小
        adjusted_weights['power_correlation'] *= 0.5  # 降低权重50%
        logger.info(f"[自适应权重] 功率数据区分度低，权重降低: {base_weights['power_correlation']} → {adjusted_weights['power_correlation']}")
    
    # 2. 分析频率数据质量
    freq_values = data['pump_frequency']
    freq_cv = np.std(freq_values) / np.mean(freq_values)
    
    if freq_cv > 0.15:  # 频率差异大
        adjusted_weights['freq_correlation'] *= 1.5
        logger.info(f"[自适应权重] 频率数据区分度高，权重增加")
    elif freq_cv < 0.05:  # 频率差异小
        adjusted_weights['freq_correlation'] *= 0.5
        logger.info(f"[自适应权重] 频率数据区分度低，权重降低")
    
    # 3. 流量守恒权重始终最高（不调整）
    # adjusted_weights['flow_conservation'] = 10.0  # 保持不变
    
    # 4. 归一化权重（可选）
    # total_weight = sum(adjusted_weights.values())
    # adjusted_weights = {k: v/total_weight for k, v in adjusted_weights.items()}
    
    return adjusted_weights
```

## 建议2: 分层优化策略

### 2.1 核心原理

**问题**：全局、泵站、设备三级参数独立优化，没有继承关系

**解决方案**：从粗到细的继承式优化，下层参数以上层参数为起点

### 2.2 优化顺序

```
第1步: 全局优化（使用所有泵站数据）
  ↓
第2步: 泵站优化（以全局参数为起点，使用单个泵站数据）
  ↓
第3步: 设备优化（以泵站参数为起点，使用单个设备数据）
```

### 2.3 实现逻辑

```python
def hierarchical_optimize(
    self,
    metric_key: str,
    method_id: str,
    start_time: datetime,
    end_time: datetime
) -> Dict:
    """
    分层优化：全局 → 泵站 → 设备

    Returns:
        {
            'global_params': {...},
            'station_params': {14: {...}, 15: {...}},
            'device_params': {105: {...}, 106: {...}}
        }
    """
    results = {}

    # 第1步：全局优化
    logger.info("[分层优化] 开始全局优化")

    global_result = self.optimize(
        metric_key=metric_key,
        method_id=method_id,
        optimization_level='global',
        start_time=start_time,
        end_time=end_time
    )

    results['global_params'] = global_result['optimized_params']

    # 第2步：泵站优化（以全局参数为起点）
    logger.info("[分层优化] 开始泵站级优化")

    results['station_params'] = {}
    stations = self._get_all_stations()

    for station_id in stations:
        station_result = self.optimize(
            metric_key=metric_key,
            method_id=method_id,
            optimization_level='station',
            station_id=station_id,
            start_time=start_time,
            end_time=end_time,
            initial_params=results['global_params']  # 🔑 从全局参数开始
        )

        results['station_params'][station_id] = station_result['optimized_params']

    # 第3步：设备优化（以泵站参数为起点）
    logger.info("[分层优化] 开始设备级优化")

    results['device_params'] = {}
    devices = self._get_all_devices()

    for device_id, station_id in devices:
        station_params = results['station_params'].get(
            station_id,
            results['global_params']
        )

        device_result = self.optimize(
            metric_key=metric_key,
            method_id=method_id,
            optimization_level='device',
            station_id=station_id,
            device_id=device_id,
            start_time=start_time,
            end_time=end_time,
            initial_params=station_params  # 🔑 从泵站参数开始
        )

        results['device_params'][device_id] = device_result['optimized_params']

    return results
```

### 2.4 参数偏离限制

**问题**：设备级参数可能过度拟合，偏离全局参数太远

**解决方案**：设置参数偏离上限（默认±30%）

```python
def optimize(
    self,
    ...,
    initial_params: Optional[Dict] = None,
    max_deviation_pct: float = 30.0
) -> Dict:
    """执行优化，支持初始参数和偏离限制"""

    if initial_params:
        # 设置参数边界：允许偏离±30%
        bounds = []
        for key, value in initial_params.items():
            lower = value * (1 - max_deviation_pct / 100)
            upper = value * (1 + max_deviation_pct / 100)
            bounds.append((lower, upper))
    else:
        bounds = [(0.5, 2.0), (0.5, 2.0)]

    result = minimize(
        objective_function,
        x0=list(initial_params.values()) if initial_params else [1.0, 1.0],
        bounds=bounds,
        method='L-BFGS-B'
    )

    return result
```

## 建议3: 增量优化

### 3.1 核心原理

**问题**：每次优化都使用全部30天数据，计算量大

**解决方案**：只使用新增数据进行增量优化，提高效率

### 3.2 实现逻辑

```python
def incremental_optimize(
    self,
    metric_key: str,
    method_id: str,
    optimization_level: str,
    station_id: Optional[int] = None,
    device_id: Optional[int] = None,
    incremental_days: int = 7  # 使用最近7天数据
) -> Dict:
    """
    增量优化：只使用新增数据

    Args:
        incremental_days: 使用最近N天的数据

    Returns:
        优化结果
    """
    # 1. 获取上次优化时间
    last_optimize_time = self._get_last_optimize_time(
        metric_key, method_id, optimization_level,
        station_id, device_id
    )

    if last_optimize_time is None:
        # 首次优化，使用全量数据
        logger.info("[增量优化] 首次优化，使用全量数据（30天）")
        start_time = datetime.now() - timedelta(days=30)
    else:
        # 增量优化，使用新增数据
        start_time = max(
            last_optimize_time,
            datetime.now() - timedelta(days=incremental_days)
        )
        logger.info(
            "[增量优化] 增量优化",
            extra={'extra_data': {
                '上次优化时间': last_optimize_time,
                '数据起始时间': start_time,
                '数据天数': (datetime.now() - start_time).days
            }}
        )

    end_time = datetime.now()

    # 2. 加载当前参数作为起点
    current_params = self.parameter_manager.load_parameters(
        metric_key, method_id, optimization_level,
        station_id, device_id
    )

    # 3. 执行优化（从当前参数开始，减少迭代次数）
    result = self.optimize(
        metric_key=metric_key,
        method_id=method_id,
        optimization_level=optimization_level,
        station_id=station_id,
        device_id=device_id,
        start_time=start_time,
        end_time=end_time,
        initial_params=current_params,  # 从当前参数开始
        max_iterations=5  # 减少迭代次数（默认10次）
    )

    # 4. 判断是否应用新参数
    improvement = result['improvement']['total_error_reduction']

    if improvement < 0.05:  # 改进小于5%
        logger.info(
            "[增量优化] 改进不显著，保持当前参数",
            extra={'extra_data': {
                '改进幅度': f"{improvement:.2%}",
                '阈值': '5%'
            }}
        )
        return {
            'status': 'skipped',
            'reason': '改进不显著',
            'improvement': improvement,
            'current_params': current_params
        }
    else:
        logger.info(
            "[增量优化] 改进显著，应用新参数",
            extra={'extra_data': {
                '改进幅度': f"{improvement:.2%}",
                '当前参数': current_params,
                '优化参数': result['optimized_params']
            }}
        )
        return result
```

### 3.3 上次优化时间查询

```python
def _get_last_optimize_time(
    self,
    metric_key: str,
    method_id: str,
    optimization_level: str,
    station_id: Optional[int],
    device_id: Optional[int]
) -> Optional[datetime]:
    """
    从optimization_history表查询上次优化时间
    """
    query = """
        SELECT created_at
        FROM optimization_history
        WHERE metric_key = %s
          AND method_id = %s
          AND optimization_level = %s
          AND station_id IS NOT DISTINCT FROM %s
          AND device_id IS NOT DISTINCT FROM %s
        ORDER BY created_at DESC
        LIMIT 1
    """

    result = self.db.execute(
        query,
        (metric_key, method_id, optimization_level, station_id, device_id)
    )

    if result:
        return result[0]['created_at']
    else:
        return None
```

## 建议5: 多目标优化

### 5.1 核心原理

**问题**：所有约束加权求和，可能牺牲某些约束

**解决方案**：使用多目标优化，找到Pareto最优解

### 5.2 实现逻辑

```python
from scipy.optimize import differential_evolution

def multi_objective_optimize(
    self,
    metric_key: str,
    method_id: str,
    optimization_level: str,
    station_id: Optional[int] = None,
    device_id: Optional[int] = None,
    start_time: datetime = None,
    end_time: datetime = None
) -> Dict:
    """
    多目标优化：使用differential_evolution算法

    Returns:
        优化结果，包含Pareto最优解
    """
    # 1. 加载数据
    data = self._load_all_metrics_data(...)

    # 2. 检查可用约束
    available_constraints = self._check_available_constraints(metric_key, data)

    # 3. 定义多目标函数
    def multi_objectives(params):
        """
        返回多个目标值（不加权）

        Returns:
            [conservation_error, power_corr_error, freq_corr_error, consistency_error]
        """
        alpha, beta = params

        # 计算各个约束的误差
        errors = {}

        if 'flow_conservation' in available_constraints:
            errors['conservation'] = self._calculate_conservation_error(alpha, beta, data)

        if 'power_correlation' in available_constraints:
            errors['power_corr'] = self._calculate_power_corr_error(alpha, beta, data)

        if 'freq_correlation' in available_constraints:
            errors['freq_corr'] = self._calculate_freq_corr_error(alpha, beta, data)

        if 'consistency' in available_constraints:
            errors['consistency'] = self._calculate_consistency_error(alpha, beta, data)

        # 返回误差列表
        return list(errors.values())

    # 4. 定义聚合函数（用于differential_evolution）
    def aggregate_objectives(params):
        """
        聚合多个目标（使用自适应权重）
        """
        objectives = multi_objectives(params)
        weights = self.calculate_adaptive_weights(data, metric_key, base_weights)

        # 加权求和
        total_error = sum(w * obj for w, obj in zip(weights.values(), objectives))

        return total_error

    # 5. 执行优化
    result = differential_evolution(
        aggregate_objectives,
        bounds=[(0.5, 2.0), (0.5, 2.0)],
        strategy='best1bin',
        maxiter=100,
        popsize=15,
        tol=0.01,
        mutation=(0.5, 1),
        recombination=0.7
    )

    optimized_params = {
        'alpha': result.x[0],
        'beta': result.x[1]
    }

    # 6. 评估优化效果
    improvement = self._evaluate_improvement(
        current_params, optimized_params, data, available_constraints
    )

    return {
        'status': 'success',
        'optimized_params': optimized_params,
        'improvement': improvement,
        'available_constraints': available_constraints,
        'algorithm': 'differential_evolution'
    }
```

## 建议6: 参数变化趋势监控

### 6.1 核心原理

**问题**：不知道参数是否稳定，是否需要优化

**解决方案**：监控参数变化趋势和流量守恒误差，智能触发优化

### 6.2 触发条件

```python
def should_trigger_optimization(
    self,
    metric_key: str,
    method_id: str,
    optimization_level: str,
    station_id: Optional[int] = None,
    device_id: Optional[int] = None
) -> Tuple[bool, str]:
    """
    判断是否需要触发优化

    Returns:
        (should_optimize, reason)
    """
    # 条件1: 参数变化趋势
    history = self._load_optimization_history(
        metric_key, method_id, optimization_level,
        station_id, device_id,
        limit=3
    )

    if len(history) >= 3:
        # 计算参数方差
        alpha_values = [h['optimized_params']['alpha'] for h in history]
        beta_values = [h['optimized_params']['beta'] for h in history]

        alpha_variance = np.var(alpha_values)
        beta_variance = np.var(beta_values)

        if alpha_variance > 0.01 or beta_variance > 0.01:
            return True, f"参数变化趋势明显 (alpha方差:{alpha_variance:.4f}, beta方差:{beta_variance:.4f})"

    # 条件2: 流量守恒误差过大
    current_error = self._calculate_current_conservation_error(
        metric_key, method_id, optimization_level,
        station_id, device_id
    )

    if current_error > 0.05:  # 守恒误差>5%
        return True, f"流量守恒误差过大: {current_error:.2%}"

    # 条件3: 距离上次优化时间过长
    if history:
        last_optimize_time = history[0]['created_at']
        days_since_last = (datetime.now() - last_optimize_time).days

        if days_since_last > 30:
            return True, f"距离上次优化超过30天 ({days_since_last}天)"
    else:
        return True, "从未优化过"

    # 条件4: 数据量显著增加
    if history:
        last_sample_count = history[0].get('sample_count', 0)
        current_sample_count = self._get_current_sample_count(
            metric_key, optimization_level, station_id, device_id
        )

        if current_sample_count > last_sample_count * 1.5:
            return True, f"数据量显著增加 ({last_sample_count} → {current_sample_count})"

    return False, "参数稳定，无需优化"
```

### 6.3 当前流量守恒误差计算

```python
def _calculate_current_conservation_error(
    self,
    metric_key: str,
    method_id: str,
    optimization_level: str,
    station_id: Optional[int],
    device_id: Optional[int]
) -> float:
    """
    计算当前参数下的流量守恒误差（使用最近3天数据）
    """
    # 1. 加载最近3天数据
    end_time = datetime.now()
    start_time = end_time - timedelta(days=3)

    data = self._load_all_metrics_data(
        metric_key, optimization_level,
        station_id, device_id,
        start_time, end_time
    )

    # 2. 加载当前参数
    current_params = self.parameter_manager.load_parameters(
        metric_key, method_id, optimization_level,
        station_id, device_id
    )

    # 3. 计算流量守恒误差
    alpha = current_params['alpha']
    beta = current_params['beta']

    conservation_errors = []

    for timestamp, group in data.groupby('timestamp'):
        # 计算各设备流量
        weights = (group['power'] ** alpha) * (group['frequency'] ** beta)
        total_weight = weights.sum()

        if total_weight > 0:
            flows = group['total_flow'].iloc[0] * weights / total_weight
            flow_sum = flows.sum()
            total_flow = group['total_flow'].iloc[0]

            # 守恒误差
            error = abs(flow_sum - total_flow) / total_flow
            conservation_errors.append(error)

    # 返回平均误差
    return np.mean(conservation_errors) if conservation_errors else 0.0
```

## 建议7: 跨指标联合优化

### 7.1 核心原理

**问题**：9个指标独立优化，没有利用指标间的物理关系

**解决方案**：联合优化多个指标的参数，利用能量守恒等跨指标约束

### 7.2 物理关系

```python
# 跨指标物理关系

# 1. 能量守恒
P_hydraulic = ρ × g × Q × H
P_electric = P_hydraulic / η

# 2. 扬程-压力关系
H = (P_out - P_in) × 10^6 / (ρ × g)

# 3. 扭矩-功率关系
T = P_shaft / ω = P_shaft / (2π × n / 60)

# 4. 效率合理性
η = (ρ × g × Q × H) / P_electric
```

### 7.3 实现逻辑

```python
def joint_optimize_metrics(
    self,
    metrics: List[str] = ['pump_flow_rate', 'pump_head', 'pump_efficiency'],
    optimization_level: str = 'global',
    station_id: Optional[int] = None,
    device_id: Optional[int] = None,
    start_time: datetime = None,
    end_time: datetime = None
) -> Dict:
    """
    联合优化多个指标的参数

    Args:
        metrics: 要联合优化的指标列表

    Returns:
        {
            'pump_flow_rate': {'alpha': 1.265, 'beta': 0.935},
            'pump_head': {'rho': 1000, 'g': 9.81},
            'pump_efficiency': {'k1': 1.0, 'k2': 1.0}
        }
    """
    # 1. 加载所有指标的数据
    all_data = {}
    for metric_key in metrics:
        all_data[metric_key] = self._load_all_metrics_data(
            metric_key, optimization_level,
            station_id, device_id,
            start_time, end_time
        )

    # 2. 定义联合目标函数
    def joint_objective(all_params):
        """
        联合目标函数：考虑单个指标约束 + 跨指标约束

        Args:
            all_params: [alpha, beta, rho, g, k1, k2, ...]
        """
        # 解析参数
        param_idx = 0
        params_dict = {}

        if 'pump_flow_rate' in metrics:
            params_dict['pump_flow_rate'] = {
                'alpha': all_params[param_idx],
                'beta': all_params[param_idx + 1]
            }
            param_idx += 2

        if 'pump_head' in metrics:
            params_dict['pump_head'] = {
                'rho': all_params[param_idx],
                'g': all_params[param_idx + 1]
            }
            param_idx += 2

        if 'pump_efficiency' in metrics:
            params_dict['pump_efficiency'] = {
                'k1': all_params[param_idx],
                'k2': all_params[param_idx + 1]
            }
            param_idx += 2

        # 3. 计算各个指标的值
        calculated_values = {}

        if 'pump_flow_rate' in metrics:
            calculated_values['pump_flow_rate'] = self._calculate_flow(
                params_dict['pump_flow_rate'],
                all_data['pump_flow_rate']
            )

        if 'pump_head' in metrics:
            calculated_values['pump_head'] = self._calculate_head(
                params_dict['pump_head'],
                all_data['pump_head']
            )

        if 'pump_efficiency' in metrics:
            calculated_values['pump_efficiency'] = self._calculate_efficiency(
                params_dict['pump_efficiency'],
                all_data['pump_efficiency']
            )

        # 4. 计算单个指标的约束误差
        single_metric_errors = 0.0

        for metric_key in metrics:
            error = self._calculate_single_metric_error(
                metric_key,
                params_dict[metric_key],
                all_data[metric_key]
            )
            single_metric_errors += 5.0 * error  # 权重5.0

        # 5. 计算跨指标约束误差（关键！）
        cross_metric_errors = 0.0

        # 5.1 能量守恒约束
        if all(['pump_flow_rate', 'pump_head', 'pump_efficiency'] in metrics):
            energy_error = self._calculate_energy_conservation_error(
                calculated_values['pump_flow_rate'],
                calculated_values['pump_head'],
                calculated_values['pump_efficiency'],
                all_data
            )
            cross_metric_errors += 20.0 * energy_error  # 权重20.0（最高）

        # 5.2 扬程-压力关系约束
        if 'pump_head' in metrics:
            pressure_error = self._calculate_pressure_relation_error(
                calculated_values['pump_head'],
                all_data['pump_head']
            )
            cross_metric_errors += 10.0 * pressure_error

        # 6. 总误差
        total_error = single_metric_errors + cross_metric_errors

        return total_error

    # 3. 设置参数边界
    bounds = []
    if 'pump_flow_rate' in metrics:
        bounds.extend([(0.5, 2.0), (0.5, 2.0)])  # alpha, beta
    if 'pump_head' in metrics:
        bounds.extend([(900, 1100), (9.5, 10.0)])  # rho, g
    if 'pump_efficiency' in metrics:
        bounds.extend([(0.5, 2.0), (0.5, 2.0)])  # k1, k2

    # 4. 设置初始参数
    x0 = []
    if 'pump_flow_rate' in metrics:
        x0.extend([1.0, 1.0])
    if 'pump_head' in metrics:
        x0.extend([1000, 9.81])
    if 'pump_efficiency' in metrics:
        x0.extend([1.0, 1.0])

    # 5. 执行优化
    result = minimize(
        joint_objective,
        x0=x0,
        bounds=bounds,
        method='L-BFGS-B'
    )

    # 6. 解析优化结果
    param_idx = 0
    optimized_params = {}

    if 'pump_flow_rate' in metrics:
        optimized_params['pump_flow_rate'] = {
            'alpha': result.x[param_idx],
            'beta': result.x[param_idx + 1]
        }
        param_idx += 2

    if 'pump_head' in metrics:
        optimized_params['pump_head'] = {
            'rho': result.x[param_idx],
            'g': result.x[param_idx + 1]
        }
        param_idx += 2

    if 'pump_efficiency' in metrics:
        optimized_params['pump_efficiency'] = {
            'k1': result.x[param_idx],
            'k2': result.x[param_idx + 1]
        }
        param_idx += 2

    return {
        'status': 'success',
        'optimized_params': optimized_params,
        'metrics': metrics
    }
```

### 7.4 能量守恒误差计算

```python
def _calculate_energy_conservation_error(
    self,
    flows: np.ndarray,
    heads: np.ndarray,
    efficiencies: np.ndarray,
    all_data: Dict
) -> float:
    """
    计算能量守恒误差

    P_hydraulic = ρ × g × Q × H
    P_electric = P_hydraulic / η

    误差 = |P_electric_calculated - P_electric_measured| / P_electric_measured
    """
    rho = 1000  # kg/m³
    g = 9.81    # m/s²

    # 计算水力功率
    P_hydraulic = rho * g * flows * heads / 3600  # kW

    # 计算电功率
    P_electric_calculated = P_hydraulic / efficiencies

    # 实际测量的电功率
    P_electric_measured = all_data['pump_flow_rate']['power']

    # 计算误差
    errors = np.abs(P_electric_calculated - P_electric_measured) / P_electric_measured

    return np.mean(errors)
```

## UniversalOptimizer类完整设计

### 9.1 类结构

```python
# app/services/calculation_v2/shared/optimizer.py

from typing import Dict, List, Optional, Tuple
from datetime import datetime, timedelta
import numpy as np
from scipy.optimize import minimize, differential_evolution
import logging

logger = logging.getLogger(__name__)


class UniversalOptimizer:
    """
    通用参数优化器（增强版）

    功能：
    1. 基础物理自洽性优化
    2. 自适应权重调整
    3. 分层优化策略
    4. 增量优化
    5. 多目标优化
    6. 参数变化趋势监控
    7. 跨指标联合优化
    """

    def __init__(self, parameter_manager, db_connection):
        self.parameter_manager = parameter_manager
        self.db = db_connection

        # 加载配置
        self.config = self._load_config()

    # ============================================================
    # 核心优化方法
    # ============================================================

    def optimize(
        self,
        metric_key: str,
        method_id: str,
        optimization_level: str,
        station_id: Optional[int] = None,
        device_id: Optional[int] = None,
        start_time: datetime = None,
        end_time: datetime = None,
        task_id: str = None,
        initial_params: Optional[Dict] = None,
        max_deviation_pct: float = 30.0,
        max_iterations: int = 10
    ) -> Dict:
        """
        执行参数优化（支持所有增强功能）

        Returns:
            {
                'status': 'success' | 'failed' | 'skipped',
                'optimized_params': {...},
                'improvement': {...},
                'available_constraints': [...],
                'optimization_type': 'standard' | 'hierarchical' | ...,
                'execution_time_seconds': float
            }
        """
        start_exec_time = datetime.now()

        logger.info(
            "[参数优化] 开始优化",
            extra={'extra_data': {
                '指标': metric_key,
                '方法ID': method_id,
                '优化级别': optimization_level,
                '泵站ID': station_id,
                '设备ID': device_id,
                '时间范围': f"[{start_time}, {end_time})",
                '初始参数': initial_params
            }}
        )

        # 1. 加载数据
        data = self._load_all_metrics_data(
            metric_key, optimization_level,
            station_id, device_id,
            start_time, end_time
        )

        if len(data) == 0:
            return {
                'status': 'failed',
                'reason': '无可用数据'
            }

        # 2. 检查可用约束
        available_constraints = self._check_available_constraints(metric_key, data)

        if len(available_constraints) < 2:
            return {
                'status': 'failed',
                'reason': f'可用约束不足 ({len(available_constraints)}/2)'
            }

        # 3. 计算自适应权重（建议1）
        if self.config.get('adaptive_weight_enabled', True):
            base_weights = self._get_base_weights(metric_key, method_id)
            adaptive_weights = self.calculate_adaptive_weights(data, metric_key, base_weights)
        else:
            adaptive_weights = self._get_base_weights(metric_key, method_id)

        # 4. 加载当前参数
        current_params = self.parameter_manager.load_parameters(
            metric_key, method_id, optimization_level,
            station_id, device_id
        )

        # 5. 计算当前参数的误差
        current_error = self._calculate_physical_inconsistency(
            current_params, data, metric_key, available_constraints, adaptive_weights
        )

        # 6. 选择优化算法
        algorithm = self.config.get('optimization_algorithm', 'L-BFGS-B')

        # 7. 设置参数边界
        if initial_params:
            bounds = self._calculate_bounds(initial_params, max_deviation_pct)
            x0 = list(initial_params.values())
        else:
            bounds = [(0.5, 2.0), (0.5, 2.0)]
            x0 = [1.0, 1.0]

        # 8. 定义目标函数
        def objective(params):
            param_dict = self._params_array_to_dict(params, metric_key, method_id)
            return self._calculate_physical_inconsistency(
                param_dict, data, metric_key, available_constraints, adaptive_weights
            )

        # 9. 执行优化
        if algorithm == 'differential_evolution':
            result = differential_evolution(
                objective,
                bounds=bounds,
                maxiter=max_iterations,
                popsize=15
            )
        else:  # L-BFGS-B
            result = minimize(
                objective,
                x0=x0,
                bounds=bounds,
                method='L-BFGS-B',
                options={'maxiter': max_iterations}
            )

        optimized_params = self._params_array_to_dict(result.x, metric_key, method_id)
        optimized_error = result.fun

        # 10. 评估改进效果
        improvement = self._evaluate_improvement(
            current_params, optimized_params,
            current_error, optimized_error,
            data, available_constraints
        )

        # 11. 保存优化历史
        execution_time = (datetime.now() - start_exec_time).total_seconds()

        optimization_id = self._save_optimization_history(
            metric_key, method_id, optimization_level,
            station_id, device_id,
            current_params, optimized_params,
            available_constraints, adaptive_weights,
            current_error, optimized_error,
            improvement, algorithm,
            result.nit if hasattr(result, 'nit') else None,
            len(data), start_time, end_time,
            execution_time,
            optimization_type='standard'
        )

        # 12. 判断是否应用新参数
        min_improvement = self.config.get('min_improvement_threshold', 0.1)

        if improvement['total_error_reduction'] > min_improvement:
            # 保存新参数
            self.parameter_manager.save_parameters(
                metric_key, method_id, optimization_level,
                station_id, device_id,
                optimized_params
            )

            logger.info(
                "[参数优化] 优化完成，应用新参数",
                extra={'extra_data': {
                    '当前参数': current_params,
                    '优化参数': optimized_params,
                    '改进幅度': f"{improvement['total_error_reduction']:.2%}",
                    '执行耗时': f"{execution_time:.2f}秒"
                }}
            )

            return {
                'status': 'success',
                'optimized_params': optimized_params,
                'improvement': improvement,
                'available_constraints': available_constraints,
                'adaptive_weights': adaptive_weights,
                'optimization_type': 'standard',
                'optimization_id': optimization_id,
                'execution_time_seconds': execution_time
            }
        else:
            logger.info(
                "[参数优化] 改进不显著，保持当前参数",
                extra={'extra_data': {
                    '改进幅度': f"{improvement['total_error_reduction']:.2%}",
                    '阈值': f"{min_improvement:.2%}"
                }}
```

```python
import click

@click.group()

    result = optimizer.optimize(
```
