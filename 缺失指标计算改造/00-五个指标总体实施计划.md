## 📁 文档结构标准

### 每个指标必须创建的5个文档

所有指标的文档结构完全一致，参考 `pump_speed/` 目录：

```
缺失指标计算改造/{metric_key}/
├── 01-{metric_key}详细设计.md          # 计算公式、依赖关系、参数配置
├── 02-{metric_key}实施计划.md          # 分阶段实施步骤、时间估算
├── 03-{metric_key}重构任务跟踪.md      # 任务分解、责任人、状态跟踪
├── 04-{metric_key}重构完整检查清单.md  # 150+检查项
└── 05-任务完成追踪表.md                # 完成状态和验证结果
```

### 文档内容要求

**01-详细设计.md**（必须包含）：
- 指标概述（定义、业务背景、计算挑战）
- 依赖指标清单
- 计算方法详细设计（每个方法的公式、参数、适用条件）
- 数据获取模块设计（SQL查询、返回格式）
- 数据过滤模块设计（运行状态判断）
- 方法选择模块设计（方法配置、选择逻辑）
- 计算执行模块设计（方法实现）
- 结果验证模块设计（验证规则、质量标记）
- 参数配置清单（calculation_parameters + device_rated_params）

**02-实施计划.md**（必须包含）：
- 实施概述（目标、时间规划、人员配置）
- 分阶段实施计划（4个阶段，每个阶段的任务清单）
- 工作量统计（任务数、预计时间、占比）
- 风险评估（风险、影响、概率、缓解措施）
- 验收标准

**03-重构任务跟踪.md**（必须包含）：
- 任务总览（指标信息、实施周期、人员）
- 任务分解（按天分解，每个任务的责任人、状态、检查项）
- 进度统计（已完成、进行中、未开始）

**04-重构完整检查清单.md**（必须包含）：
- 检查清单总览（总计150+检查项）
- 第一阶段：数据库准备（15项）
- 第二阶段：代码实现（80项）
- 第三阶段：集成测试（30项）
- 第四阶段：质量验证（25项）
- 验收标准

**05-任务完成追踪表.md**（必须包含）：
- 任务完成状态总览（表格）
- 详细任务追踪（每个任务的状态、时间、验证结果）
- 进度图表
- 下一步行动
