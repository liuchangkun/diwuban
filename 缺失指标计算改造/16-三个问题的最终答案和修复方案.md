## 🎯 问题1：pump_inlet_pressure 为什么只有55.6%？

### ❌ 这是误解！

**实际情况**：
- **实际覆盖率**：**100.0%**（501,424/501,654条记录）
- **55.6%** 是"优秀指标占比"（5个优秀指标/9个总指标），**不是覆盖率**

**数据验证**：
```sql
-- 运行状态记录
SELECT COUNT(*) FROM mv_device_running_1s 
WHERE device_id IN (1,2,3,4,5,6) AND running = 1;
-- 结果：501,654

-- pump_inlet_pressure 写入记录
SELECT COUNT(*) FROM mv_calculated_metrics_1s 
WHERE metric_id = ? AND device_id IN (1,2,3,4,5,6);
-- 结果：501,424

-- 覆盖率 = 501,424 / 501,654 = 99.95% ≈ 100%
```

**结论**：✅ **pump_inlet_pressure 没有任何问题，数据质量优秀（⭐⭐⭐⭐⭐）**

## 🎯 问题3：pump_shaft_power 为什么只有9.4%？

### ⚠️ 这是真正的严重问题！

### 数据流分析

| 步骤 | 记录数 | 损失 | 损失率 | 原因 |
|------|--------|------|--------|------|
| 1. 运行状态 (running=1) | 83,609 | - | - | 初始数据 |
| 2. pump_active_power > 0 | 25,632 | 57,940 | 69.3% | ✅ **正常**（泵待机） |
| 3. **实际写入数据库** | **9,348** | **16,284** | **63.5%** | ❌ **异常**（错误过滤） |

### 根本原因链条

#### 1️⃣ 数据库中参数缺失

```sql
-- 查询 pump_shaft_power 的参数
SELECT * FROM calculation_parameters 
WHERE metric_key = 'pump_shaft_power' 
  AND device_id IN (1,2,3,4,5,6);

-- 结果：0条记录（参数完全缺失）
```

#### 2️⃣ ParameterManager 提供了硬编码默认值

**位置**：`app/services/calculation/shared/parameter_manager.py` 第47-61行

```python
self.default_params = {
    'pump_flow_rate': {
        'global': {
            'max_flow': 500.0,
            'max_power': 200.0,  # ⬅️ 问题所在！
            'max_freq': 50.0
        }
    }
}
```

**逻辑**：
- 当数据库中没有参数时，ParameterManager 返回 `default_params`
- pump_shaft_power 使用了 `max_power=200.0`（来自 pump_flow_rate 的默认值）

#### 3️⃣ DataFilter 使用了错误的阈值

**位置**：`app/services/calculation/metrics/pump_shaft_power/data_filter.py` 第99行

```python
# 过滤 pump_active_power > max_power 的数据
data = data[data['pump_active_power'] <= self.max_power]
# max_power = 200.0（来自 ParameterManager 的默认值）
```

**结果**：
- 所有 P_active > 200 kW 的数据被过滤
- 缺失的16,284条记录的 P_active 范围：**201.28 ~ 323.68 kW**
- 实际写入的9,348条记录的 P_active 最大值：**176.77 kW**

### 影响评估

| 项目 | 当前 | 修复后 | 提升 |
|------|------|--------|------|
| 覆盖率 | 9.4% | 30.7% | **+226%** |
| 记录数 | 9,348 | 25,632 | **+16,284条** |
| 数据完整性 | ⭐⭐ 较差 | ⭐⭐⭐⭐ 良好 | **+2星** |
