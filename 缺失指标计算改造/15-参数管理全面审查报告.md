### 3. 根本原因分析

#### 问题1：ParameterManager 提供了硬编码默认值

**位置**：`app/services/calculation/shared/parameter_manager.py` 第47-61行

```python
self.default_params = {
    'pump_flow_rate': {
        'method_a': {'alpha': 1.0, 'beta': 1.0},
        'method_b': {'smooth_window': 5},
        'global': {
            'max_flow': 500.0,
            'max_power': 200.0,  # ⬅️ 这就是问题所在！
            'max_freq': 50.0
        }
    }
}
```

**影响**：
- 当数据库中参数缺失时，ParameterManager 返回硬编码默认值
- 导致 pump_shaft_power 使用了 `max_power=200.0`
- 过滤掉了所有 P_active > 200 kW 的数据（16,284条记录）

#### 问题2：代码中大量使用 `params.get('xxx', default)`

**示例**：
```python
# ❌ 违规示例1：pump_shaft_power/validator.py 第69行
max_shaft_power = self.params.get('max_shaft_power', 500.0)

# ❌ 违规示例2：pump_shaft_power/methods/method_a.py 第50-51行
eta_motor = device_param.get('eta_motor', 0.92)
eta_vfd = device_param.get('eta_vfd', 0.97)

# ❌ 违规示例3：pump_inlet_pressure/data_filter.py 第47行
self.max_liquid_level = params.get('max_liquid_level', 10.0)
```

**问题**：
- 参数缺失时不报错，静默使用默认值
- 导致数据被错误过滤，但没有明确的错误提示
- 违反了"参数必须从数据库获取"的规范

#### 问题3：数据库中参数配置不完整

**原因**：
- 初期开发时使用硬编码默认值进行测试
- 测试通过后忘记将参数迁移到数据库
- 缺少参数初始化脚本和验证机制

### 方案1：立即修复 pump_shaft_power（P0优先级）

**步骤**：

- 恢复数据：+16,284条记录

### 方案2：移除 ParameterManager 中的硬编码默认值（P0优先级）

**目标**：确保参数缺失时立即报错

**修改文件**：`app/services/calculation/shared/parameter_manager.py`

**修改内容**：
```python
# ❌ 删除这段代码（第47-61行）
self.default_params = {
    'pump_flow_rate': {
        ...
    }
}

# ✅ 修改 get_parameters 方法（第106-123行）
if not params:
    # 不再使用默认值，直接抛出异常
    self.logger.error(
        f"[参数管理] 数据库中无参数配置",
        extra={'extra_data': {
            '指标键': metric_key,
            '泵站ID': station_id,
            '设备ID': device_id,
            '错误': '必须在calculation_parameters表中配置参数'
        }}
    )
    raise ValueError(
        f"数据库中无参数配置: metric_key={metric_key}, "
        f"station_id={station_id}, device_id={device_id}。"
        f"必须在calculation_parameters表中配置参数。"
    )
```

### 方案3：移除所有代码中的硬编码默认值（P1优先级）

**目标**：确保所有参数从数据库获取

**需要修改的文件**：约30个文件，78处违规代码

**修改原则**：
```python
# ❌ 错误示例
max_power = params.get('max_power', 500.0)

# ✅ 正确示例
max_power = params.get('max_power')
if max_power is None:
    raise ValueError(
        "缺少必需参数: max_power。"
        "必须在calculation_parameters表中配置该参数。"
        "请执行: INSERT INTO calculation_parameters "
        "(station_id, device_id, metric_key, param_name, param_value, param_type) "
        f"VALUES ({station_id}, {device_id}, '{metric_key}', 'max_power', '350.0', 'float');"
    )
```

**实施内容**：
