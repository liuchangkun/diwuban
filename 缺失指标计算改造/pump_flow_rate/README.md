## 🎯 重构目标

### 问题根因

**当前问题**: pump_flow_rate 计算失败，停机设备（freq=0, power=0）无法计算流量

**根因分析**:
- 数据加载阶段：使用 `mv_device_running_1s.running=1` 过滤（✅ 正确）
- 计算阶段：使用硬编码阈值 `freq>=3.0Hz, power>=0.5kW` 过滤（❌ 错误）
- 导致结果：停机设备权重为0，无法计算流量

### 解决方案

**核心改动**:
1. ✅ DataLoader: LEFT JOIN mv_device_running_1s（获取 running 字段）- **已完成**
2. ✅ DataFilter: 使用 `df[df['running'] == 1]` 过滤 - **已完成**
3. ✅ Calculator: 移除 f_thr 和 p_thr 参数，直接计算 - **已完成**
4. ✅ 日志输出：证明移除了硬编码阈值（完整日志追踪）- **已完成**

**后续发现的问题及解决**（2025-11-15）:
5. ✅ Scheduler: 修复硬编码 station_id=1 问题 - **已完成**
   - 从 dim_devices 表查询 station_id
   - 添加 LRU 缓存（maxsize=1000）
   - 添加错误处理
6. ✅ CalculationLogger: 删除未使用的 calculation_logs 表 - **已完成**
   - 执行回滚脚本删除表和所有分区

7. ✅ 代码质量: 运行 pylint/black/isort 清理代码 - **已完成**
   - 删除未使用的导入
   - 格式化代码
   - 评分提升：9.58/10 → 9.61/10
