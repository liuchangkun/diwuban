## 指标概述

### 指标定义

**指标键**: `pump_inlet_pressure`  
**指标名称**: 水泵入口压力  
**单位**: MPa  
**物理意义**: 水泵吸入口处的压力

### 业务背景

水泵入口压力是泵站运行的关键指标之一，用于：
- **汽蚀风险评估**：入口压力过低会导致汽蚀，损坏水泵
- **扬程计算基础**：扬程 = (出口压力 - 入口压力) / (ρ × g)
- **效率计算依赖**：效率计算需要准确的扬程值
- **系统性能监控**：反映水池液位和管路阻力状况

### 计算挑战

1. **缺失测量**：大部分水泵没有直接的入口压力传感器
2. **管路损失**：需要考虑从水池到泵入口的管路阻力损失
3. **参数配置**：需要现场测量或计算等效损失系数
4. **准确度要求**：±0.01 MPa（用于扬程计算）

### 依赖指标

| 指标键 | 指标名称 | 用途 | 数据来源 |
|--------|----------|------|----------|
| `pool_liquid_level` | 水池液位 | 静压计算 | 传感器测量 |
| `pump_flow_rate` | 泵流量 | 管路损失计算 | 已计算值 |

### 计算方法概览

| 方法ID | 方法名称 | 优先级 | 适用场景 | 准确度 |
|--------|----------|--------|----------|--------|
| EQUIV_COEF | 等效损失系数法 | 100 | 有K_eq参数，有流量数据 | 高 |
| STATIC_PRESSURE | 静压法 | 90 | K_eq缺失或流量很小 | 中等 |

## 计算方法详细设计

### 方法1：等效损失系数法（EQUIV_COEF）

#### 物理原理

基于伯努利方程和达西-魏斯巴赫公式，将所有管路损失（沿程损失 + 局部损失 + 动压损失）简化为一个等效损失系数 K_eq。

#### 计算公式

```
P_in = P_atm + ρ × g × (h_static - h_loss) / 1e6

其中：
h_static = pool_liquid_level - L_offset  # 静压头（m）
h_loss = K_eq × v² / (2g)                # 总损失（m）
v = Q / (3600 × π × D² / 4)              # 流速（m/s）

参数说明：
- P_in: 泵入口压力（MPa）
- P_atm: 大气压（MPa，默认0.101325）
- ρ: 水密度（kg/m³，默认1000.0）
- g: 重力加速度（m/s²，默认9.80665）
- pool_liquid_level: 水池液位（m）
- L_offset: 水池液位到泵入口的固定高度差（m）
- K_eq: 等效损失系数（无量纲）
- Q: 泵流量（m³/h）
- D: 管道直径（m）
```

#### 依赖数据

**测量数据**：
- `pool_liquid_level`：水池液位（m）
- `pump_flow_rate`：泵流量（m³/h）

**配置参数**（device_rated_params表）：
- `L_offset`：水池液位到泵入口的固定高度差（m）
- `pipe_diameter`：管道直径（m）

**配置参数**（calculation_parameters表）：
- `K_eq`：等效损失系数（无量纲）
- `v_max_warning`：流速警告阈值（m/s，默认3.0）

**物理常数**（calculation_parameters表，全局）：
- `P_atm`：大气压（MPa，默认0.101325）
- `rho`：水密度（kg/m³，默认1000.0）
- `g`：重力加速度（m/s²，默认9.80665）

#### 适用条件

1. ✅ `pool_liquid_level` 数据存在
2. ✅ `pump_flow_rate` 数据存在
3. ✅ `K_eq` 参数已配置
4. ✅ `L_offset` 和 `pipe_diameter` 参数已配置

#### 准确度

- **预期准确度**：±0.002 MPa
- **影响因素**：
  - K_eq 配置准确性（主要）
  - 流量测量误差（次要）
  - 液位测量误差（次要）

#### 特殊处理

**流速警告**：
```python
if v > v_max_warning:
    logger.warning(
        f"[计算执行] 流速过高: {v:.2f} m/s > {v_max_warning} m/s",
        extra={'extra_data': {
            '设备ID': device_id,
            '流量': Q,
            '管径': D,
            '流速': v
        }}
    )
    # 注意：只记录日志，不标记数据质量为warning
```

### 方法2：静压法（STATIC_PRESSURE）

#### 物理原理

忽略管路损失，仅考虑静压。适用于流量很小或K_eq参数缺失的情况。

#### 计算公式

```
P_in = P_atm + ρ × g × (pool_liquid_level - L_offset) / 1e6

参数说明：
- P_in: 泵入口压力（MPa）
- P_atm: 大气压（MPa，默认0.101325）
- ρ: 水密度（kg/m³，默认1000.0）
- g: 重力加速度（m/s²，默认9.80665）
- pool_liquid_level: 水池液位（m）
- L_offset: 水池液位到泵入口的固定高度差（m）
```

#### 依赖数据

**测量数据**：
- `pool_liquid_level`：水池液位（m）

**配置参数**（device_rated_params表）：
- `L_offset`：水池液位到泵入口的固定高度差（m）

**物理常数**（calculation_parameters表，全局）：
- `P_atm`：大气压（MPa，默认0.101325）
- `rho`：水密度（kg/m³，默认1000.0）
- `g`：重力加速度（m/s²，默认9.80665）

#### 适用条件

1. ✅ `pool_liquid_level` 数据存在
2. ✅ `L_offset` 参数已配置
3. ⚠️ `K_eq` 参数缺失 或 流量很小（< 100 m³/h）

#### 准确度

- **预期准确度**：±0.005 MPa（流量小时）→ ±0.02 MPa（流量大时）
- **影响因素**：
  - 忽略管路损失（主要误差来源）
  - 液位测量误差（次要）
