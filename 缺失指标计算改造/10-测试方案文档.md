## 🔄 回归测试

### 测试目标

确保新系统与现有系统的计算结果一致

### 测试方法

1. 选择历史数据（如2024年12月的数据）
2. 分别用现有系统和新系统计算
3. 对比结果差异

### 测试脚本

**测试文件**：`tests/regression/test_regression.py`

```python
import pytest
import pandas as pd
from datetime import datetime

class TestRegression:
    """回归测试"""

    def test_compare_with_existing_system(self):
        """测试：与现有系统对比"""
        # 1. 获取现有系统的计算结果
        from app.core.database.connection import query
        existing_results = query("""
            SELECT device_id, timestamp, value
            FROM fact_measurements
            WHERE metric_key = 'pump_flow_rate'
              AND timestamp BETWEEN '2024-12-01' AND '2024-12-02'
              AND device_id IN (105, 106, 107)
            ORDER BY device_id, timestamp
        """)

        # 2. 用新系统重新计算
        from app.services.calculation.metrics.pump_flow_rate import PumpFlowRatePipeline
        new_results = []
        for device_id in [105, 106, 107]:
            pipeline = PumpFlowRatePipeline(
                device_id=device_id,
                start_time=datetime(2024, 12, 1),
                end_time=datetime(2024, 12, 2)
            )
            results = pipeline.execute()
            new_results.extend(results)

        # 3. 对比结果
        df_existing = pd.DataFrame(existing_results)
        df_new = pd.DataFrame(new_results)

        # 合并
        df_merged = pd.merge(
            df_existing,
            df_new,
            on=['device_id', 'timestamp'],
            suffixes=('_old', '_new')
        )

        # 计算差异
        df_merged['diff'] = df_merged['value_new'] - df_merged['value_old']
        df_merged['diff_pct'] = (df_merged['diff'] / df_merged['value_old']) * 100

        # 统计
        mean_diff_pct = df_merged['diff_pct'].abs().mean()
        max_diff_pct = df_merged['diff_pct'].abs().max()

        print(f"\n回归测试结果：")
        print(f"  样本数: {len(df_merged)}")
        print(f"  平均差异: {mean_diff_pct:.2f}%")
        print(f"  最大差异: {max_diff_pct:.2f}%")

        # 断言：平均差异<5%
        assert mean_diff_pct < 5.0, f"平均差异{mean_diff_pct:.2f}%超过5%"
```
