## 集成测试概述

### 文档目的

本文档提供集成测试的完整指南，包括：
- 集成测试策略（单模块、跨模块、端到端）
- 集成测试用例模板（可直接复制使用）
- 集成测试脚本模板（pytest代码）
- 集成测试执行指南（如何运行测试）
- 集成测试验证清单（确保测试完整性）

### 适用范围

本指南适用于以下5个缺失指标的集成测试：
1. **pump_speed**（ID=19，rpm）- 泵转速，设备1-6
2. **main_pipeline_inlet_pressure**（ID=61，MPa）- 主管路入口压力，设备7
3. **pump_shaft_power**（ID=66，kW）- 泵轴功率，设备1-6
4. **pump_hydraulic_power**（ID=67，kW）- 泵水功率，设备1-6
5. **pump_torque**（ID=20，N·m）- 泵扭矩，设备1-6

### 集成测试目标

- ✅ 验证各模块之间的集成正确性
- ✅ 验证共享模块的调用正确性
- ✅ 验证端到端的计算流程
- ✅ 验证数据库操作的正确性
- ✅ 验证错误处理的完整性

## 集成测试策略

### 1. 单模块集成测试

**目标**：验证单个模块与其依赖模块的集成

**测试范围**：
- DataLoader + 数据库

- Validator + Calculator

**测试方法**：

**测试范围**：
- DataLoader → DataFilter → MethodSelector

**测试方法**：
- 模拟完整的数据流
- 验证中间结果的正确性

---

### 3. 端到端集成测试

**目标**：验证完整的计算流程

**测试范围**：
- Pipeline → Scheduler → DataWriter

**测试方法**：

### 模板3：Scheduler集成测试脚本

```python
"""
Scheduler 集成测试
"""

import pytest
from datetime import datetime
from app.services.calculation.shared_services import shared_services
from app.services.calculation.metrics.{metric_key}.pipeline import {MetricKey}Pipeline


class TestSchedulerIntegration:
    """Scheduler 集成测试"""

    def test_create_and_execute_tasks(self):
        """测试任务创建和执行"""
        # 创建任务
        tasks = shared_services.scheduler.create_tasks(
            metric_key='{metric_key}',
            device_ids=[1, 2, 3, 4, 5, 6],
            start_time=datetime(2025, 10, 22, 8, 0, 0),
            end_time=datetime(2025, 10, 22, 9, 0, 0),
            time_chunk_hours=1
        )

        # 验证任务创建
        assert len(tasks) > 0, "应该创建至少一个任务"

        # 执行任务
        pipeline = {MetricKey}Pipeline(trace_id='test_integration')
        results = shared_services.scheduler.execute_tasks(
            tasks=tasks,
            pipeline=pipeline,
            max_workers=2
        )

        # 验证执行结果
        assert len(results) == len(tasks), "所有任务应该执行"
        assert all(r['status'] == 'success' for r in results), "所有任务应该成功"
```

## 集成测试执行指南

### 1. 环境准备

**步骤1：安装依赖**

```bash
pip install pytest pytest-cov pytest-mock
```

**步骤2：配置数据库连接**

确保 `.env` 文件包含正确的数据库连接信息：

```
DB_HOST=localhost
DB_PORT=5432
DB_NAME=pump_station
DB_USER=postgres
DB_PASSWORD=your_password
```

**步骤3：准备测试数据**

确保数据库包含测试所需的数据：
- `fact_measurements` 表有历史数据
- `mv_device_running_1s` 表有运行状态数据
- `device_rated_params` 表有设备参数
- `calculation_parameters` 表有计算参数

---

### 2. 运行集成测试

**运行所有集成测试**：

```bash
pytest tests/integration/ -v
```

**运行特定指标的集成测试**：

```bash
pytest tests/integration/test_{metric_key}_integration.py -v
```

**运行特定测试用例**：

```bash
pytest tests/integration/test_{metric_key}_integration.py::TestPipelineIntegration::test_run_with_all_modules -v
```

**生成覆盖率报告**：

```bash
pytest tests/integration/ --cov=app/services/calculation/metrics/{metric_key} --cov-report=html
```

---

### 3. 测试结果验证

**成功标准**：
- ✅ 所有测试用例通过
- ✅ 覆盖率 ≥ 90%
- ✅ 无警告或错误日志
- ✅ 数据库操作正确

**失败处理**：
1. 查看测试日志，定位失败原因
2. 检查数据库连接和数据
3. 检查模块实现是否正确
4. 修复问题后重新运行测试
