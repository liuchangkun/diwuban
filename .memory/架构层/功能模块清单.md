## 一、数据导入模块

### 模块概述
**路径**：`app/services/ingest/`
**职责**：CSV文件导入到数据库
**核心组件**：
- prepare_dim/ - 维度表准备
- create_staging.py - 暂存表创建
- copy_workers.py - 数据复制
- merge_service.py - 数据合并
- check_mapping.py - 映射检查

### 主要功能
1. **维度表准备**：
   - 站点（dim_stations）
   - 设备（dim_devices）
   - 指标（dim_metric_config）

2. **数据导入**：
   - CSV文件读取（编码自动检测）
   - 数据验证（格式、范围）
   - 批量导入（COPY命令）

3. **数据合并**：
   - 暂存表到事实表
   - 去重和冲突解决
   - 分区管理

### 依赖
- 数据库：staging表、fact_measurements表
- 存储过程：api.upsert_measurement
- 配置：mapping.yaml

### 使用场景
- 手动数据导入
- 批量数据迁移
- 定时数据同步

## 三、特性曲线拟合模块

### 模块概述
**路径**：`app/services/curve_fitting.py`、`app/services/pump_group_curve_fitting.py`
**职责**：设备特性曲线拟合
**核心组件**：
- CurveFittingService - 单设备曲线拟合
- PumpGroupCurveFitter - 泵组曲线拟合

### 主要功能
1. **曲线类型**：
   - Q-H曲线（流量-扬程）
   - η-Q曲线（效率-流量）
   - P-Q曲线（功率-流量）
   - 泵组协调曲线

2. **拟合方法**：
   - 多项式拟合（POLYNOMIAL）
   - 线性拟合（LINEAR）
   - 指数拟合（EXPONENTIAL）
   - 对数拟合（LOGARITHMIC）
   - 幂函数拟合（POWER）

3. **质量评估**：
   - R²（拟合优度）
   - 残差分析
   - 数据点数量

### 依赖
- 数据库：fact_measurements、dim_curves
- 算法：numpy、scipy
- 物理模型：PhysicsBasedCalculator

### 使用场景
- 设备性能分析
- 运行优化
- 故障诊断

## 十、模块调用规范

### 10.1 模块初始化
所有模块必须通过配置对象初始化：
```python
from app.core.config import load_settings

settings = load_settings()
```

### 10.2 模块间调用
模块间调用必须通过服务层接口：
```python
# 正确：通过服务接口
from app.services.data_import import DataImportService

service = DataImportService(settings)
result = service.import_csv_file(file_path, station_id, source_hint)

# 错误：直接调用内部函数
from app.services.ingest.copy_workers import _valid_rows_for_file  # ❌
```

### 10.3 错误处理
所有模块必须包含错误处理：
```python
from app.core.exceptions import DataImportError

try:
    result = service.import_csv_file(file_path, station_id, source_hint)
except DataImportError as e:
    logger.error(f"数据导入失败: {e}")
    raise
```

## 十、缺失指标计算模块（新增）

### 模块概述
**路径**：`app/services/calculation/`
**职责**：对缺失指标进行识别、计算与入库，并维护指标可用性

**核心组件**：
- `orchestrator.py`：端到端编排
- `dependency_analyzer.py`：依赖/拓扑/循环分组
- `method_selector.py`：方法选择与数据有效性检查
- `calculators.py`：具体计算函数注册表
- `validator.py`：物理/范围/曲线校验
- `characteristic_curve.py`：泵特性曲线加载与插值
- `adaptive_batch.py`：自适应批量写入
- `performance_monitor.py`：批次性能监控与入库

### 主要流程
1. 依赖解析 → 计算顺序与循环组
2. 时间对齐数据加载（可选运行/质量过滤）
3. 方法选择（优先级/条件/依赖有效性）
4. 指标计算（向量化/物理关系/聚合）
5. 结果验证（掩码过滤）
6. 写入事实表与更新可用性
7. 记录性能并动态调整批量

### 依赖
- 数据库表：`calculation_method_registry`、`calculation_parameters`、`calculation_validation_config`、`metric_calculation_order`、`pump_characteristic_curves`、`fact_measurements`、`metrics_presence_per_second_device`
- 清理白名单：保留上述配置表

### 使用场景
- 单设备/多设备批量缺失指标计算
- 循环依赖场景的迭代求解
- 大窗口、高并发写入场景的自适应优化
