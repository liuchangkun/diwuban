## 一、数据处理服务（3个）

### 1. DataImportService（数据导入服务）
**文件路径**：`app/services/data_import.py`  
**职责**：CSV文件导入和数据验证  
**主要方法**：
- `import_csv_file(file_path, station_id, source_hint)` - 导入CSV文件
- `get_import_statistics(station_id, start_date, end_date)` - 获取导入统计
- `cleanup_old_staging_data(days_to_keep)` - 清理旧暂存数据

**依赖**：
- 数据库适配器（app/adapters/db/）
- 文件系统适配器（app/adapters/fs/）

**使用场景**：
- 手动上传CSV文件导入
- 批量数据导入
- 数据迁移

---

### 2. MergeService（数据合并服务）
**文件路径**：`app/services/ingest/merge_service.py`  
**职责**：将暂存表数据合并到事实表  
**主要方法**：
- `merge_window(settings, window_start_utc, window_end_utc, device_id)` - 合并时间窗口数据

**依赖**：
- 数据库适配器
- api schema存储过程

**使用场景**：
- 数据导入后的合并操作
- 定时批量合并
- 数据修复

---

### 3. PresenceWriterService（数据存在性服务）
**文件路径**：`app/services/reporting/presence_writer.py`  
**职责**：计算和记录数据存在性  
**主要方法**：
- `run_presence_compute(station_name, station_id, device_id, start, end, ...)` - 计算数据存在性

**依赖**：
- 数据库适配器
- reporting schema函数

**使用场景**：
- 数据质量报表
- 数据完整性检查

## 二、质量控制服务（2个）

## 七、服务调用规范

### 7.1 服务初始化
所有服务必须通过构造函数接收`settings`配置对象：
```python
service = DataImportService(settings)
```

### 7.2 错误处理
所有服务方法必须包含错误处理：
```python
try:
    result = service.import_csv_file(file_path, station_id, source_hint)
except DataImportError as e:
    logger.error(f"数据导入失败: {e}")
    raise
```

### 7.3 日志记录
所有服务必须使用结构化日志：
```python
from app.core.logging import log_activity

with log_activity("数据导入", file_path=file_path) as span:
    result = service.import_csv_file(file_path, station_id, source_hint)
    span.set_return(result)
```
