## 一、特性曲线拟合算法

### 1.1 Q-H曲线拟合（流量-扬程）
**用途**：描述泵在不同流量下的扬程特性
**方法**：多项式拟合（numpy.polyfit）
**公式**：H = a₀ + a₁Q + a₂Q² + a₃Q³
**阶数**：通常使用2-3阶多项式
**质量评估**：R² > 0.85

**实现**：
```python
# app/services/curve_fitting.py
def _fit_with_scipy(data, request):
    Q = data['flow_rate']
    H = data['head']
    coeffs = np.polyfit(Q, H, degree=2)
    H_pred = np.polyval(coeffs, Q)
    r_squared = calculate_r_squared(H, H_pred)
```

---

### 1.2 η-Q曲线拟合（效率-流量）
**用途**：描述泵在不同流量下的效率特性
**方法**：多项式拟合
**公式**：η = b₀ + b₁Q + b₂Q² + b₃Q³
**阶数**：通常使用2-3阶多项式
**质量评估**：R² > 0.80

---

### 1.3 P-Q曲线拟合（功率-流量）
**用途**：描述泵在不同流量下的功率特性
**方法**：多项式拟合
**公式**：P = c₀ + c₁Q + c₂Q² + c₃Q³
**阶数**：通常使用2-3阶多项式
**质量评估**：R² > 0.85

---

### 1.4 拟合方法对比

| 方法 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| POLYNOMIAL | 通用场景 | 拟合效果好 | 可能过拟合 |
| LINEAR | 简单线性关系 | 计算快速 | 精度较低 |
| EXPONENTIAL | 指数关系 | 适合特定曲线 | 适用范围窄 |
| LOGARITHMIC | 对数关系 | 适合特定曲线 | 适用范围窄 |
| POWER | 幂函数关系 | 适合特定曲线 | 适用范围窄 |

## 二、自动基线计算算法

### 2.1 方案A：Robust方法
**原理**：基于分位数和MAD（中位数绝对偏差）的稳健估计
**适用**：稳态数据、有异常值的数据

**步骤**：
1. 过滤质量=0且稳态(phase=1)的数据
2. 计算中位数（median）
3. 计算MAD：MAD = median(|x - median(x)|)
4. 计算稳健标准差：σ_robust = 1.4826 × MAD
5. 基线 = median ± k × σ_robust（k通常取2-3）

**实现**：
```python
# app/services/rules/auto_baseline.py
def calculate_robust_baseline(data):
    median = np.median(data)
    mad = np.median(np.abs(data - median))
    sigma_robust = 1.4826 * mad
    baseline_lower = median - 2 * sigma_robust
    baseline_upper = median + 2 * sigma_robust
```

---

### 2.2 方案B：STL方法
**原理**：基于STL（Seasonal and Trend decomposition using Loess）时间序列分解
**适用**：有周期性的数据、长时间序列数据

**步骤**：
1. STL分解：数据 = 趋势 + 季节 + 残差
2. 提取趋势分量作为基线
3. 计算残差的标准差
4. 基线 = 趋势 ± k × σ_residual

**实现**：
```python
# app/services/rules/auto_baseline.py
from statsmodels.tsa.seasonal import STL

def calculate_stl_baseline(data, period=24):
    stl = STL(data, period=period)
    result = stl.fit()
    trend = result.trend
    residual = result.resid
    sigma = np.std(residual)
```

## 三、运行状态判定算法

### 3.1 综合标准分数法
**原理**：基于电流、功率、频率的综合标准分数
**粒度**：1秒

**步骤**：
1. **计算电流分数**：
   - 电流最大值 = max(A相电流, B相电流, C相电流)
   - 电流分数 = 电流最大值 / 额定电流

2. **计算功率分数**：
   - 功率分数 = 有功功率 / 额定功率

3. **计算频率分数**：
   - 频率分数 = 频率 / 额定频率（50Hz）

4. **计算综合分数**：
   - 综合分数 = w₁×电流分数 + w₂×功率分数 + w₃×频率分数
   - 权重：w₁=0.4, w₂=0.4, w₃=0.2

5. **状态判定**：
   - 综合分数 > 运行阈值 → 运行（RUNNING）
   - 综合分数 < 停止阈值 → 停止（STOPPED）
   - 其他 → 待机（STANDBY）

6. **状态保持和回退**：
   - 状态保持：连续N个点（N=5）才切换状态
   - 状态回退：避免频繁切换

**实现**：
```python
# app/services/device_running_job.py
def calculate_composite_score(current_A, current_B, current_C, power, frequency):
    current_max = max(current_A, current_B, current_C)
    current_score = current_max / rated_current
    power_score = power / rated_power
    frequency_score = frequency / 50.0
    composite_score = 0.4 * current_score + 0.4 * power_score + 0.2 * frequency_score
    return composite_score
```

---

### 3.2 Otsu阈值算法
**原理**：自动计算最优运行阈值
**方法**：最大类间方差法

**步骤**：
1. 统计综合分数的直方图
2. 遍历所有可能的阈值
3. 计算每个阈值的类间方差
4. 选择类间方差最大的阈值作为运行阈值

**实现**：
```python
# app/services/rules/running_thresholds.py
from skimage.filters import threshold_otsu

def calculate_otsu_threshold(scores):
    threshold = threshold_otsu(scores)
    return threshold
```

## 四、物理计算算法

### 4.1 泵速计算
**公式**：n = (f / f₀) × n₀
**参数**：
- n：实际转速（rpm）
- f：实际频率（Hz）
- f₀：额定频率（50Hz）
- n₀：额定转速（rpm）

---

### 4.2 流速计算
**公式**：v = Q / A
**参数**：
- v：流速（m/s）
- Q：流量（m³/s）
- A：管道截面积（m²）

---

### 4.3 雷诺数计算
**公式**：Re = (ρ × v × D) / μ
**参数**：
- Re：雷诺数
- ρ：流体密度（kg/m³）
- v：流速（m/s）
- D：管道直径（m）
- μ：动力粘度（Pa·s）

---

### 4.4 摩擦系数计算
**公式**（Colebrook-White）：
1/√f = -2 × log₁₀((ε/D)/3.7 + 2.51/(Re×√f))
**参数**：
- f：摩擦系数
- ε：管道粗糙度（m）
- D：管道直径（m）
- Re：雷诺数

---

### 4.5 泵扬程计算
**公式**：H = (P₂ - P₁) / (ρ × g) + (v₂² - v₁²) / (2 × g) + (z₂ - z₁)
**参数**：
- H：扬程（m）
- P₁, P₂：进出口压力（Pa）
- v₁, v₂：进出口流速（m/s）
- z₁, z₂：进出口高度（m）
- ρ：流体密度（kg/m³）
- g：重力加速度（9.81 m/s²）

---

### 4.6 水力功率计算
**公式**：P_h = ρ × g × Q × H
**参数**：
- P_h：水力功率（W）
- ρ：流体密度（kg/m³）
- g：重力加速度（9.81 m/s²）
- Q：流量（m³/s）
- H：扬程（m）

---

### 4.7 泵效率计算
**公式**：η = P_h / P_shaft
**参数**：
- η：泵效率
- P_h：水力功率（W）
- P_shaft：轴功率（W）

## 五、质量检测算法

### 5.1 异常跳变检测
**方法**：基于阈值的跳变检测
**公式**：|x_t - x_{t-1}| > threshold
**阈值设置**：
- 动态阈值：threshold = k × σ（k=3）
- 静态阈值：根据指标类型设置

---

### 5.2 平台期检测
**方法**：连续相同值检测
**公式**：连续N个点值相同
**阈值**：N通常设置为10-20

---

### 5.3 物理越界检测
**方法**：基于物理有效范围检测
**公式**：x < valid_min OR x > valid_max
**范围设置**：根据指标类型和设备规格设置

## 六、缺失指标计算算法流程（新增 - 研究模式补充）

### 6.1 端到端流程概述
1. 依赖关系解析：从 `calculation_method_registry` 装载 → 构建依赖图 → 拓扑排序/循环分组
2. 对齐数据加载：以 `ts_bucket` 为基准对齐，可选运行状态与质量过滤（过滤质量状态≠0）
3. 方法选择：按优先级/条件/依赖数据有效性选择方法（必要时要求非NaN/非零）
4. 指标计算：调用 `calculators` 中方法向量化计算
5. 结果验证：`PhysicsValidator` 进行范围/物理/曲线校验并掩码无效点
6. 批量写入：`ON CONFLICT UPSERT` 写入 `fact_measurements`，质量码标记 `999`（CALCULATED）
7. 可用性维护：更新 `metrics_presence_per_second_device`（available/need_compute）
8. 性能与自适应：`PerformanceMonitor` 统计→`AdaptiveBatchManager` 动态调整批量
9. 并发：多设备并行执行（线程池）

### 6.2 研究阶段观察要点（仅事实记录）
