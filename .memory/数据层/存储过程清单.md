## API Schema 函数（api schema）

### api.upsert_measurement
**类型**：FUNCTION  
**参数**：p_station_id bigint, p_device_id bigint, p_metric_id bigint, p_ts_raw timestamptz, p_value numeric, p_source_hint text  
**返回值**：boolean  
**用途**：插入或更新单条测量数据  
**使用示例**：
```sql
SELECT api.upsert_measurement(1, 101, 301, '2025-09-30 10:00:00+00', 123.45, 'csv_import');
```

### api.get_measurements
**类型**：FUNCTION  
**参数**：p_station_ids bigint[], p_start_ts timestamptz, p_end_ts timestamptz, p_device_ids bigint[], p_metric_ids bigint[], p_limit integer, p_offset integer  
**返回值**：TABLE(station_id bigint, device_id bigint, metric_id bigint, ts_raw timestamptz, ts_bucket timestamptz, value numeric, source_hint text, inserted_at timestamptz)  
**用途**：查询测量数据  
**使用示例**：
```sql
SELECT * FROM api.get_measurements(
    ARRAY[1], 
    '2025-09-01'::timestamptz, 
    '2025-09-30'::timestamptz, 
    NULL, NULL, 1000, 0
);
```

### api.delete_measurement
**类型**：FUNCTION  
**参数**：p_station_id bigint, p_device_id bigint, p_metric_id bigint, p_ts_raw timestamptz  
**返回值**：integer  
**用途**：删除单条测量数据  
**使用示例**：
```sql
SELECT api.delete_measurement(1, 101, 301, '2025-09-30 10:00:00+00');
```

### api.update_measurement_value
**类型**：FUNCTION  
**参数**：p_station_id bigint, p_device_id bigint, p_metric_id bigint, p_ts_raw timestamptz, p_new_value numeric, p_source_hint text  
**返回值**：integer  
**用途**：更新测量数据的值  
**使用示例**：
```sql

```

### api.upsert_measurements_json
**类型**：FUNCTION  
**参数**：p_rows jsonb  
**返回值**：TABLE(processed integer, succeeded integer, failed integer)  
**用途**：批量插入或更新测量数据（JSON格式）  
**使用示例**：
```sql

    {"station_id": 1, "device_id": 101, "metric_id": 301, "ts_raw": "2025-09-30T10:00:00Z", "value": 123.45}
]'::jsonb);
```

### api.delete_measurements_by_filter

**返回值**：TABLE(total_deleted integer)

**使用示例**：
