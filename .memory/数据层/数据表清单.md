## 核心事实表

### fact_measurements
**用途**：核心事实表，存储时序测量数据
**表类型**：TimescaleDB Hypertable
**Schema**：public
**大小**：176 kB
**数据量**：约806,400行

#### 字段详细列表

| 字段名 | 数据类型 | 可空 | 默认值 | 约束 | 功能说明 |
|--------|---------|------|--------|------|---------|
| id | bigint | NO | - | - | 主键ID（非自增） |
| station_id | bigint | NO | - | 外键 → dim_stations.id | 泵站ID |
| device_id | bigint | NO | - | 外键 → dim_devices.id | 设备ID |
| metric_id | bigint | NO | - | 外键 → dim_metric_config.id | 指标ID |
| ts_raw | timestamptz | NO | - | - | 原始时间戳（未对齐） |
| ts_bucket | timestamptz | NO | - | - | 时间桶（对齐后的时间戳，用于分区和查询） |
| value | numeric | NO | - | - | 测量值（高精度数值） |
| source_hint | text | YES | NULL | - | 数据来源提示（如：csv_import、api、calculated） |
| inserted_at | timestamptz | YES | now() | - | 数据插入时间 |
| quality_status | smallint | NO | 0 | - | 质量状态码（0=正常，非0=有问题） |
| quality_type | text | YES | NULL | - | 质量类型（如：outlier、gap、invalid） |
| quality_meta | jsonb | YES | NULL | - | 质量元数据（JSON格式，存储详细质量信息） |
| quality_codes | integer[] | YES | '{}'::integer[] | - | 质量码数组（如：[101, 111]表示物理越界+异常跳变） |

#### 索引列表

| 索引名 | 索引类型 | 索引字段 | 说明 |
|--------|---------|---------|------|
| fact_measurements_new_pkey | UNIQUE BTREE | (station_id, device_id, metric_id, ts_bucket) | 主键索引，确保唯一性 |
| ux_fact_sdm_tb | UNIQUE BTREE | (station_id, device_id, metric_id, ts_bucket) | 唯一索引（备用） |
| fact_measurements_new_ts_bucket_idx | BRIN | (ts_bucket) | 时间范围索引，适合时序数据 |
| idx_fm_brin_ts | BRIN | (ts_bucket) | 时间范围索引（pages_per_range=128） |
| fact_measurements_new_device_id_ts_bucket_idx | BTREE | (device_id, ts_bucket) | 按设备查询时序数据 |
| fact_measurements_new_station_id_ts_bucket_idx | BTREE | (station_id, ts_bucket DESC) | 按泵站查询时序数据（降序） |
| fact_measurements_new_station_id_ts_bucket_device_id_metric_idx | BTREE | (station_id, ts_bucket, device_id, metric_id) INCLUDE (value) | 复合索引，包含value列 |
| idx_fm_s_d_m_t | BTREE | (station_id, device_id, metric_id, ts_bucket) | 完整复合索引 |
| ix_fact_sdm_tb | BTREE | (station_id, device_id, metric_id, ts_bucket) INCLUDE (value) | 复合索引，包含value列 |
| idx_fact_measurements_quality_codes_gin | GIN | (quality_codes) | 质量码数组索引，支持数组查询 |

#### 外键关系

- `station_id` → `dim_stations.id`
- `device_id` → `dim_devices.id`
- `metric_id` → `dim_metric_config.id`

#### 分区策略

- **分区类型**：TimescaleDB Hypertable自动分区
- **分区键**：ts_bucket（时间字段）
- **分区粒度**：自动管理
- **空间分区**：按 device_id 进行空间分区

#### 使用示例

```sql
-- 查询单个设备的时序数据
SELECT ts_bucket, value
FROM fact_measurements
WHERE device_id = 1
  AND metric_id = 10
  AND ts_bucket BETWEEN '2025-01-01' AND '2025-01-31'
ORDER BY ts_bucket;

-- 查询有质量问题的数据
SELECT *
FROM fact_measurements
WHERE quality_status != 0
  AND 101 = ANY(quality_codes);  -- 物理越界

-- 插入数据（应使用 api.upsert_measurement）
SELECT api.upsert_measurement(
    p_station_id := 1,
    p_device_id := 1,
    p_metric_id := 10,
    p_ts_raw := '2025-01-01 10:00:00+00',
    p_value := 123.45,
    p_source_hint := 'csv_import'
);
```

### quality_eval_by_device_metric
**用途**：按设备和指标的质量评估汇总表
**Schema**：public
**大小**：48 kB

#### 字段详细列表

| 字段名 | 数据类型 | 可空 | 默认值 | 约束 | 功能说明 |
|--------|---------|------|--------|------|---------|
| window_start | timestamptz | NO | - | 主键之一 | 统计窗口起始时间（UTC时区），定义统计时间范围的起点 |
| window_end | timestamptz | NO | - | 主键之一 | 统计窗口结束时间（UTC时区），定义统计时间范围的终点 |
| station_id | bigint | NO | 0 | 主键之一 | 泵站ID（外键，引用 dim_stations.id），支持按站点维度统计 |
| device_id | bigint | NO | 0 | 主键之一 | 设备ID（外键，引用 dim_devices.id），评估所属的设备ID |
| metric_id | bigint | NO | - | 主键之一 | 指标ID（外键，引用 dim_metric_config.id），评估所属的指标ID |
| quality_status | integer | NO | - | 主键之一 | 质量状态码（0=正常数据，>0=异常数据），标识数据质量类型 |
| rows_count | bigint | NO | - | - | 该质量码的行数，统计该质量码在窗口内的数据行数 |
| total_count | bigint | NO | - | - | 总行数，该设备×指标在窗口内所有质量码的行数之和 |
| ratio | numeric(9,6) | NO | - | - | 占比（rows_count/total_count），取值范围0.000000~1.000000 |
| created_at | timestamptz | NO | now() | - | 创建时间，记录创建的时间戳 |

#### 使用示例

```sql
-- 查询某设备在指定时间窗口的质量评估统计
SELECT
    window_start,
    window_end,
    device_id,
    metric_id,
    quality_status,
    rows_count,
    total_count,
    ratio
FROM quality_eval_by_device_metric
WHERE device_id = 1
  AND window_start >= '2025-01-01'
  AND window_end <= '2025-01-31'
ORDER BY window_start DESC, quality_status ASC;

-- 查询异常数据占比超过10%的评估记录
SELECT
    window_start,
    window_end,
    station_id,
    device_id,
    metric_id,
    quality_status,
    ratio
FROM quality_eval_by_device_metric
WHERE quality_status > 0  -- 只看异常数据
  AND ratio > 0.1         -- 占比超过10%
ORDER BY ratio DESC;

-- 按质量状态码统计某设备的数据分布
SELECT
    quality_status,
    SUM(rows_count) as total_rows,
    AVG(ratio) as avg_ratio
FROM quality_eval_by_device_metric
WHERE device_id = 1
  AND window_start >= '2025-01-01'
GROUP BY quality_status
ORDER BY quality_status;
```

**Schema**：public
**大小**：32 kB
**特性**：支持三层参数系统（全局→站点→设备）、时间有效性（参数历史追溯）

#### 字段详细列表

| 字段名 | 数据类型 | 可空 | 默认值 | 约束 | 功能说明 |
|--------|---------|------|--------|------|---------|

| device_id | bigint | YES | NULL | 外键 → dim_devices.id | 设备ID（设备级参数） |
| station_id | bigint | YES | NULL | 外键 → dim_stations.id | 站点ID（站点级参数） |
| param_key | text | NO | - | - | 参数键（如：rated_power、rated_current） |
| value_numeric | numeric | YES | NULL | - | 数值（numeric） |

| unit | text | YES | NULL | - | 单位 |

| effective_from | timestamptz | YES | NULL | - | 生效起（时间有效性） |

#### 三层参数系统

**参数级别**：
- **全局级**：`station_id IS NULL AND device_id IS NULL`（适用于所有设备的默认值）
- **站点级**：`station_id IS NOT NULL AND device_id IS NULL`（适用于同一站点所有设备）
- **设备级**：`device_id IS NOT NULL`（特定设备的参数，可覆盖全局/站点级）

**参数优先级**：设备级 > 站点级 > 全局级

#### 索引列表

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| device_rated_params_pkey | 主键 | id | 主键索引 |
| uq_device_rated_params_3tier | 唯一 | COALESCE(station_id, 0), COALESCE(device_id, 0), param_key, COALESCE(effective_from, '1970-01-01') | 三层参数唯一约束 |
| idx_device_rated_params_param_key | 普通 | param_key | 参数键索引 |
| idx_device_rated_params_device_param | 普通 | device_id, param_key | 设备+参数复合索引 |
| idx_device_rated_params_station | 普通 | station_id | 站点级参数索引 |
| idx_device_rated_params_effective | 普通 | effective_from, effective_to | 时间有效性索引 |
| idx_rated_params_device | 普通 | device_id | 设备索引 |

#### 相关视图

| 视图名 | 说明 |
|--------|------|
| v_device_rated_params_current | 当前有效参数（过滤历史版本） |
| v_device_params_with_metadata | 参数+元数据（关联 dim_device_param_metadata） |
| v_device_complete_info | 设备完整信息（设备+能力+参数） |
| v_device_params_quality_check | 参数质量检查（缺失值、异常值） |
| v_device_params_consistency_check | 参数一致性检查（同站点设备差异） |
| v_device_params_coverage_check | 参数覆盖率检查（必需参数缺失） |

#### 使用示例

```sql
-- 查询某设备的当前有效参数
SELECT param_key, value_numeric, unit, source
FROM v_device_rated_params_current
WHERE device_id = 1;

-- 查询全局级参数
SELECT param_key, value_numeric, unit, source
FROM device_rated_params
WHERE station_id IS NULL AND device_id IS NULL;

-- 查询站点级参数
SELECT s.name AS station_name, drp.param_key, drp.value_numeric, drp.unit
FROM device_rated_params drp
JOIN dim_stations s ON drp.station_id = s.id
WHERE drp.station_id IS NOT NULL AND drp.device_id IS NULL;

-- 查询参数历史版本
SELECT param_key, value_numeric, effective_from, effective_to,
       CASE WHEN effective_to IS NULL THEN '当前版本' ELSE '历史版本' END AS 版本状态
FROM device_rated_params
WHERE device_id = 1 AND param_key = 'rated_power'
ORDER BY effective_from;
```

## 缺失指标计算相关配置表（研究模式补充）

### calculation_method_registry
- 用途：缺失指标计算方法注册表（方法清单与优先级/依赖/条件）
- 主要字段：`method_id`，`metric_key`，`method_name`，`method_code`，`priority`，`dependencies text[]`，`conditions jsonb`，`accuracy_level`，`is_enabled`
- 关系：被 `DependencyAnalyzer` 与 `MethodSelector` 读取

### calculation_parameters
- 用途：计算参数表（设备级/全局级参数）
- 主要字段：`method_id`，`metric_key`，`param_name`，`param_value`，`is_optimizable`，`optimization_history jsonb`
- 关系：被 `orchestrator.load_parameters()` 读取

### calculation_validation_config
- 用途：验证配置（设备/站点/全局分层）
- 主要字段：`metric_key`，`validator_type`，`params jsonb`，`priority`，`is_enabled`
- 关系：被 `PhysicsValidator` 读取

### metric_calculation_order
- 用途：指标计算顺序缓存（含循环依赖分组）
- 主要字段：`metric_key`，`depends_on text[]`，`order_index`，`is_circular`，`circular_group`，`updated_by`
- 关系：由 `DependencyAnalyzer` 读写；系统清理白名单保留

### pump_characteristic_curves
- 用途：泵特性曲线点集（Q-H / Q-P / Q-η）
- 主要字段：`device_id`，`curve_type`，`speed/frequency`（可选），`flow_rate`，`value`
- 关系：被 `CharacteristicCurveManager` 与 `PhysicsValidator` 读取

> 注：上述配置表均在 `app/services/system/cleanup.py` 白名单中，清库操作不会清空。
