## public Schema 物化视图

### mv_device_running_1s
**用途**：设备运行状态物化视图（1秒粒度），预计算每秒每个设备的运行状态
**Schema**：public
**大小**：15 MB
**刷新策略**：手动刷新
**数据粒度**：1秒

#### 字段详细列表

| 字段名 | 数据类型 | 可空 | 功能说明 |
|--------|---------|------|---------|
| station_id | bigint | NO | 泵站ID（关联dim_stations.id） |
| device_id | bigint | NO | 设备ID（关联dim_devices.id） |
| ts_bucket | timestamptz | NO | 时间桶（1秒对齐） |
| running | smallint | NO | 运行状态（0=停机、1=运行） |
| phase | smallint | NO | 运行相位（数值编码） |
| phase_type | text | YES | 相位类型（文本描述） |

#### 使用方法

```sql
-- 查询某设备的运行状态时序
SELECT ts_bucket, running, phase, phase_type
FROM mv_device_running_1s
WHERE device_id = 1
  AND ts_bucket BETWEEN '2025-01-01' AND '2025-01-31'
ORDER BY ts_bucket;

-- 统计某设备的运行时长
SELECT
    running,
    COUNT(*) AS seconds,
    COUNT(*) / 3600.0 AS hours
FROM mv_device_running_1s
WHERE device_id = 1
  AND ts_bucket BETWEEN '2025-01-01' AND '2025-01-31'
GROUP BY running_state;

-- 刷新物化视图
REFRESH MATERIALIZED VIEW mv_device_running_1s;
```

#### 性能特征

- **查询性能**：高（预计算，直接读取）
- **存储开销**：中等（15 MB）
- **刷新成本**：中等
- **适用场景**：运行状态时序分析、启停事件检测、运行时长统计

### mv_metric_60s_stats
**用途**：指标60秒统计物化视图，预计算每60秒每个指标的统计值
**Schema**：public
**大小**：177 MB
**刷新策略**：手动刷新
**数据粒度**：60秒

#### 字段详细列表

| 字段名 | 数据类型 | 可空 | 功能说明 |
|--------|---------|------|---------|
| station_id | bigint | YES | 泵站ID（关联dim_stations.id） |
| device_id | bigint | YES | 设备ID（关联dim_devices.id） |
| metric_id | bigint | YES | 指标ID（关联dim_metric_config.id） |
| ts_bucket | timestamptz | YES | 时间桶（60秒对齐） |
| avg_value | numeric | YES | 平均值 |
| min_value | numeric | YES | 最小值 |
| max_value | numeric | YES | 最大值 |
| stddev_value | numeric | YES | 标准差 |
| count_points | bigint | YES | 数据点数（60秒内的实际数据点数量） |

#### 使用方法

```sql
-- 查询某指标的60秒统计时序
SELECT ts_bucket, avg_value, min_value, max_value, stddev_value
FROM mv_metric_60s_stats
WHERE device_id = 1
  AND metric_id = 10
  AND ts_bucket BETWEEN '2025-01-01' AND '2025-01-31'
ORDER BY ts_bucket;

-- 计算小时级聚合
SELECT
    date_trunc('hour', ts_bucket) AS hour,
    AVG(avg_value) AS hourly_avg,
    MIN(min_value) AS hourly_min,
    MAX(max_value) AS hourly_max
FROM mv_metric_60s_stats
WHERE device_id = 1
  AND metric_id = 10
  AND ts_bucket BETWEEN '2025-01-01' AND '2025-01-31'
GROUP BY date_trunc('hour', ts_bucket)
ORDER BY hour;

-- 刷新物化视图
REFRESH MATERIALIZED VIEW mv_metric_60s_stats;
```

#### 性能特征

- **查询性能**：极高（预计算，直接读取）
- **存储开销**：大（177 MB）
- **刷新成本**：高
- **适用场景**：长时间段趋势分析、小时/天级聚合计算、数据质量监控

### mv_presence_1s_any
**用途**：指标存在性视图（1秒粒度），提供每秒每个指标的存在性数据
**Schema**：public
**类型**：普通视图（VIEW）
**数据来源**：仅基于 metrics_presence_per_second_device 表
**数据粒度**：1秒

#### 字段详细列表

| 字段名 | 数据类型 | 可空 | 功能说明 |
|--------|---------|------|---------|
| station_id | bigint | YES | 泵站ID（关联dim_stations.id） |
| device_id | bigint | YES | 设备ID（关联dim_devices.id） |
| metric_id | bigint | YES | 指标ID（关联dim_metric_config.id） |
| ts_bucket | timestamptz | YES | 时间桶（1秒对齐） |
| present | smallint | YES | 存在性标记（1=存在数据） |

#### 使用方法

```sql
-- 统计数据覆盖率
SELECT
    COUNT(*) AS present_count,
    COUNT(DISTINCT device_id) AS device_count,
    COUNT(DISTINCT metric_id) AS metric_count
FROM mv_presence_1s_any
WHERE device_id = 1
  AND metric_id = 10
  AND ts_bucket BETWEEN '2025-01-01' AND '2025-01-31';

-- 查询某设备某指标的存在性时序
SELECT ts_bucket, present
FROM mv_presence_1s_any
WHERE device_id = 1
  AND metric_id = 10
  AND ts_bucket BETWEEN '2025-01-01' AND '2025-01-31'
ORDER BY ts_bucket;
```

#### 性能特征

- **查询性能**：高（基于 metrics_presence_per_second_device 表，带索引）
- **存储开销**：无（视图不占用额外存储）
- **刷新成本**：无（实时查询）
- **适用场景**：数据质量监控、数据覆盖率统计、数据缺失段检测

#### 注意事项

- 本视图已简化，仅基于 metrics_presence_per_second_device 表
- mv_presence_1s 物化视图已废弃并删除（2025-11-04）
- 视图通过 CROSS JOIN LATERAL unnest() 展开 available_metrics 数组
