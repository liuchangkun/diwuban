## 1️⃣ 额定运行参数

### 1.1 rated_frequency（额定频率）

**中文名称**：额定频率  
**英文名称**：Rated Frequency  
**单位**：Hz（赫兹）  
**典型范围**：50（中国）、60（美国）  
**示例值**：50.0  

**物理含义**：  
设备的额定运行频率，反映电网频率标准。在中国为50Hz，在美国为60Hz。用于计算电机的同步转速和实际转速。

**计算公式**：
```
n = (f / f_rated) × n_rated × (1 - slip)

其中：
  n = 转速 (rpm)
  f = 实际频率 (Hz)
  f_rated = 额定频率 (Hz)
  n_rated = 额定转速 (rpm)
  slip = 电机转差率 (无量纲)
```

**用途说明**：  
作为转速计算的参考频率，反映电网频率标准。用于计算电机的同步转速和实际转速。

**数据来源**：设备铭牌  
**代码位置**：`app/services/calculation/orchestrator.py`  
**备注**：中国电网标准频率为50Hz

---

### 1.2 poles_pair（极对数）

**中文名称**：极对数  
**英文名称**：Poles Pair  
**单位**：无量纲  
**典型范围**：2（1500rpm）、3（1000rpm）、4（750rpm）  
**示例值**：2  

**物理含义**：  
电机定子绕组的极对数，决定电机的同步转速。极对数越多，同步转速越低。常见的极对数有2（对应1500rpm@50Hz）、3（对应1000rpm@50Hz）。

**计算公式**：
```
n_sync = (60 × f) / p

其中：
  n_sync = 同步转速 (rpm)
  f = 频率 (Hz)
  p = 极对数 (无量纲)
```

**用途说明**：  
计算电机的同步转速，用于转速计算和效率分析。

**数据来源**：设备铭牌、技术文档  
**代码位置**：`app/services/calculation/orchestrator.py`  
**备注**：极对数 = 磁极数 / 2

---

### 1.3 rated_efficiency（额定效率）

**中文名称**：额定效率  
**英文名称**：Rated Efficiency  
**单位**：无量纲  
**典型范围**：0.60 ~ 0.85  
**示例值**：0.78  

**物理含义**：  
设备在额定工况（额定流量、额定扬程、额定频率）下的总效率，反映设备将电能转换为水力能的能力。效率越高，能耗越低。

**计算公式**：
```
eta = P_out / P_in = (rho × g × Q × H) / (P_e × 1000)

其中：
  eta = 效率 (无量纲)
  P_out = 输出功率 (W)
  P_in = 输入功率 (W)
  rho = 流体密度 (kg/m³)
  g = 重力加速度 (m/s²)
  Q = 流量 (m³/s)
  H = 扬程 (m)
  P_e = 电功率 (kW)
```

**用途说明**：  
作为效率计算的参考值，用于性能评估和能耗分析。

**数据来源**：设备铭牌、性能测试报告  
**代码位置**：`app/services/calculation/calculators/eff_simple_v1.py`  
**备注**：额定效率通常在额定工况点附近最高

---

### 1.4 rated_flow（额定流量）

**中文名称**：额定流量  
**英文名称**：Rated Flow  
**单位**：m³/h  
**典型范围**：100 ~ 1000（根据泵型号）  
**示例值**：400.0  

**物理含义**：  
设备在额定工况（额定扬程、额定频率）下的流量，是泵性能曲线上的设计工作点。流量反映泵的输送能力。

**计算公式**：
```
Q = A × v

其中：
  Q = 流量 (m³/s)
  A = 管道截面积 (m²)
  v = 流速 (m/s)
```

**用途说明**：  
作为流量计算的参考值，用于性能曲线拟合和工况点分析。

**数据来源**：设备铭牌、性能曲线  
**代码位置**：`app/services/calculation/orchestrator.py`  
**备注**：实际流量随频率和扬程变化

---

### 1.5 rated_head（额定扬程）

**中文名称**：额定扬程  
**英文名称**：Rated Head  
**单位**：m  
**典型范围**：20 ~ 100（根据泵型号）  
**示例值**：50.0  

**物理含义**：
设备在额定工况（额定流量、额定频率）下的扬程，反映泵将液体提升的高度。扬程包括实际提升高度和管道阻力损失。

**计算公式**：
```
H = (P2 - P1) / (rho × g) + (v2² - v1²) / (2 × g) + (z2 - z1)

其中：
  H = 扬程 (m)
  P1, P2 = 进出口压力 (Pa)
  v1, v2 = 进出口流速 (m/s)
  z1, z2 = 进出口高度 (m)
  rho = 流体密度 (kg/m³)
  g = 重力加速度 (m/s²)
```

**用途说明**：
作为扬程计算的参考值，用于性能曲线拟合和工况点分析。

**数据来源**：设备铭牌、性能曲线
**代码位置**：`app/services/calculation/orchestrator.py`
**备注**：实际扬程随流量和频率变化

---

### 1.6 rated_power（额定功率）

**中文名称**：额定功率
**英文名称**：Rated Power
**单位**：kW
**典型范围**：50 ~ 500（根据泵型号）
**示例值**：110.0

**物理含义**：
设备在额定工况下的电功率，反映设备的能耗水平。功率与流量、扬程、效率相关。

**计算公式**：
```
P = (rho × g × Q × H) / (eta × 1000)

其中：
  P = 功率 (kW)
  rho = 流体密度 (kg/m³)
  g = 重力加速度 (m/s²)
  Q = 流量 (m³/s)
  H = 扬程 (m)
  eta = 效率 (无量纲)
```

**用途说明**：
作为功率计算的参考值，用于能耗分析和成本计算。

**数据来源**：设备铭牌
**代码位置**：`app/services/calculation/orchestrator.py`
**备注**：实际功率随工况点变化

## 2️⃣ 效率参数

### 2.1 eta_motor（电机效率）

**中文名称**：电机效率
**英文名称**：Motor Efficiency
**单位**：无量纲
**典型范围**：0.85 ~ 0.95
**示例值**：0.92

**物理含义**：
电机将电能转换为机械能（轴功率）的效率。电机效率受负载率、转速、温度等因素影响。高效电机的效率通常在90%以上。

**计算公式**：
```
eta_pump = eta_measured / (eta_motor × eta_vfd)

其中：
  eta_pump = 泵效率 (无量纲)
  eta_measured = 测量效率 (无量纲)
  eta_motor = 电机效率 (无量纲)
  eta_vfd = 变频器效率 (无量纲)
```

**用途说明**：
用于效率计算，将电功率转换为轴功率。在效率分解中，将总效率分解为泵效率、电机效率和变频器效率。

**数据来源**：设备铭牌、技术文档
**代码位置**：`app/services/calculation/calculators/eff_simple_v1.py`
**备注**：电机效率随负载率变化，通常在75%-100%负载时效率最高

---

### 2.2 eta_vfd（变频器效率）

**中文名称**：变频器效率
**英文名称**：VFD Efficiency
**单位**：无量纲
**典型范围**：0.95 ~ 0.98（变频泵）、1.00（软启泵）
**示例值**：0.97

**物理含义**：
变频器（Variable Frequency Drive）将工频交流电转换为可调频率交流电的效率。变频器效率较高，通常在95%以上。软启动器不调频，效率为100%。

**计算公式**：
```
eta_total = eta_pump × eta_motor × eta_vfd

其中：
  eta_total = 总效率 (无量纲)
  eta_pump = 泵效率 (无量纲)
  eta_motor = 电机效率 (无量纲)
  eta_vfd = 变频器效率 (无量纲)
```

**用途说明**：
用于效率计算，考虑变频器的能量损耗。变频泵需要考虑变频器损耗，软启泵不需要（eta_vfd=1.0）。

**数据来源**：变频器技术文档
**代码位置**：`app/services/calculation/calculators/eff_simple_v1.py`
**备注**：软启动器不调频，效率为1.0；变频器效率随负载和频率变化

## 3️⃣ 管道参数

### 3.1 pipe_diameter（管道直径）

**中文名称**：管道直径
**英文名称**：Pipe Diameter
**单位**：m
**典型范围**：0.2 ~ 1.0
**示例值**：0.5

**物理含义**：
管道的内径，影响流速和水力损失。管道直径越大，流速越低，沿程损失越小。管道直径的选择需要平衡投资成本和运行成本。

**计算公式**：
```
v = Q / A = Q / (π × D² / 4)

其中：
  v = 流速 (m/s)
  Q = 流量 (m³/s)
  A = 管道截面积 (m²)
  D = 管道直径 (m)
```

**用途说明**：
用于流速计算和水力损失计算。流速影响沿程损失和局部损失。

**数据来源**：设计图纸、现场测量
**代码位置**：`app/services/calculation/orchestrator.py`
**备注**：通常指内径，不是外径

---

### 3.2 pipe_length（管道长度）

**中文名称**：管道长度
**英文名称**：Pipe Length
**单位**：m
**典型范围**：10 ~ 1000
**示例值**：100.0

**物理含义**：
管道的总长度，包括直管段和弯管段的等效长度。管道长度影响沿程损失，长度越长，沿程损失越大。

**计算公式**：
```
h_f = lambda × (L / D) × (v² / (2 × g))

其中：
  h_f = 沿程损失 (m)
  lambda = 摩擦系数 (无量纲)
  L = 管道长度 (m)
  D = 管道直径 (m)
  v = 流速 (m/s)
  g = 重力加速度 (m/s²)
```

**用途说明**：
用于沿程损失计算。沿程损失与管道长度成正比。

**数据来源**：设计图纸、现场测量
**代码位置**：`app/services/calculation/orchestrator.py`
**备注**：包括直管段和弯管段的等效长度

---

### 3.3 C_hazen（海曾-威廉系数）

**中文名称**：海曾-威廉系数
**英文名称**：Hazen-Williams Coefficient
**单位**：无量纲
**典型范围**：100 ~ 140（新管道140，旧管道100）
**示例值**：120

**物理含义**：
海曾-威廉系数（C值）反映管道内壁的光滑程度。C值越大，管道越光滑，沿程损失越小。新管道C值较高（140），旧管道C值较低（100）。

**计算公式**：
```
h_f = 10.67 × L × Q^1.852 / (C^1.852 × D^4.87)

其中：
  h_f = 沿程损失 (m)
  L = 管道长度 (m)
  Q = 流量 (m³/s)
  C = 海曾-威廉系数 (无量纲)
  D = 管道直径 (m)
```

**用途说明**：
用于海曾-威廉公式计算沿程损失。适用于水在常温下的流动。

**数据来源**：管道材质手册、经验值
**代码位置**：`app/services/calculation/orchestrator.py`
**备注**：常见材质C值：铸铁管100-130，钢管120-140，塑料管140-150

---

### 3.4 roughness_rel（相对粗糙度）

**中文名称**：相对粗糙度
**英文名称**：Relative Roughness
**单位**：无量纲
**典型范围**：0.0001 ~ 0.01
**示例值**：0.001

**物理含义**：
相对粗糙度是绝对粗糙度与管道直径的比值，反映管道内壁的粗糙程度。相对粗糙度越大，摩擦系数越大，沿程损失越大。

**计算公式**：
```
epsilon_rel = epsilon / D

其中：
  epsilon_rel = 相对粗糙度 (无量纲)
  epsilon = 绝对粗糙度 (m)
  D = 管道直径 (m)

摩擦系数计算（Colebrook-White公式）：
1 / sqrt(lambda) = -2 × log10(epsilon_rel / 3.7 + 2.51 / (Re × sqrt(lambda)))

其中：
  lambda = 摩擦系数 (无量纲)
  Re = 雷诺数 (无量纲)
```

**用途说明**：
用于达西-魏斯巴赫公式计算摩擦系数和沿程损失。适用于各种流体和流动状态。

**数据来源**：管道材质手册、经验值
**代码位置**：`app/services/calculation/orchestrator.py`
**备注**：常见材质绝对粗糙度：铸铁管0.25mm，钢管0.05mm，塑料管0.0015mm

## 4️⃣ 环境参数

### 4.1 ambient_temp（环境温度）

**中文名称**：环境温度
**英文名称**：Ambient Temperature
**单位**：°C
**典型范围**：-10 ~ 40
**示例值**：20.0

**物理含义**：
环境温度影响流体的物理性质（密度、粘度、饱和蒸汽压等），进而影响泵的性能和效率。温度升高，密度降低，粘度降低。

**计算公式**：
```
rho(T) = rho_0 × (1 - beta × (T - T_0))

其中：
  rho(T) = 温度T时的密度 (kg/m³)
  rho_0 = 参考温度T_0时的密度 (kg/m³)
  beta = 体积膨胀系数 (1/K)
  T = 温度 (°C)
  T_0 = 参考温度 (°C)
```

**用途说明**：
用于流体物性计算，影响密度、粘度等参数。在精确计算中需要考虑温度影响。

**数据来源**：现场测量、气象数据
**代码位置**：`app/services/calculation/orchestrator.py`
**备注**：水的密度在4°C时最大（1000 kg/m³）

---

### 4.2 ambient_pressure（环境压力）

**中文名称**：环境压力
**英文名称**：Ambient Pressure
**单位**：kPa
**典型范围**：80 ~ 105（随海拔变化）
**示例值**：101.325

**物理含义**：
环境大气压力影响泵的汽蚀余量（NPSH）计算。大气压力随海拔高度变化，海拔越高，大气压力越低，汽蚀风险越大。

**计算公式**：
```
NPSH_a = (P_atm / (rho × g)) + h_s - h_f - (P_v / (rho × g))

其中：
  NPSH_a = 有效汽蚀余量 (m)
  P_atm = 大气压力 (Pa)
  rho = 流体密度 (kg/m³)
  g = 重力加速度 (m/s²)
  h_s = 吸入液面高度 (m)
  h_f = 吸入管路损失 (m)
  P_v = 饱和蒸汽压 (Pa)
```

**用途说明**：
用于汽蚀余量计算，评估泵的汽蚀风险。海平面标准大气压为101.325 kPa。

**数据来源**：现场测量、气象数据
**代码位置**：`app/services/calculation/orchestrator.py`
**备注**：海拔每升高1000m，大气压降低约12 kPa
