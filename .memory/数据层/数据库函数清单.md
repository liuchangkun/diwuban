## api Schema 函数（数据CRUD操作）

### upsert_measurement
**用途**：插入或更新单条测量数据（如果已存在则更新）  
**Schema**：api  
**完整签名**：
```sql
api.upsert_measurement(
    p_station_id bigint,
    p_device_id bigint,
    p_metric_id bigint,
    p_ts_raw timestamptz,
    p_value numeric,
    p_source_hint text DEFAULT NULL
) RETURNS boolean
```

**参数说明**：
- `p_station_id`: 泵站ID
- `p_device_id`: 设备ID
- `p_metric_id`: 指标ID
- `p_ts_raw`: 原始时间戳（带时区）
- `p_value`: 测量值
- `p_source_hint`: 数据来源提示（可选，如：'csv_import'、'api'、'calculated'）

**返回值**：boolean（true=成功，false=失败）

**使用示例**：
```sql
SELECT api.upsert_measurement(
    p_station_id := 1,
    p_device_id := 1,
    p_metric_id := 10,
    p_ts_raw := '2025-01-01 10:00:00+00',
    p_value := 123.45,
    p_source_hint := 'csv_import'
);
```

**业务逻辑**：
1. 检查参数有效性
2. 计算 ts_bucket（时间对齐）
3. 尝试插入数据
4. 如果主键冲突，则更新 value 和 source_hint
5. 返回操作结果

### get_measurements
**用途**：查询测量数据（支持多泵站、多设备、多指标）  
**Schema**：api  
**完整签名**：
```sql
api.get_measurements(
    p_station_ids bigint[],
    p_start_ts timestamptz,
    p_end_ts timestamptz,
    p_device_ids bigint[] DEFAULT NULL,
    p_metric_ids bigint[] DEFAULT NULL,
    p_limit integer DEFAULT 1000,
    p_offset integer DEFAULT 0
) RETURNS TABLE(
    station_id bigint,
    device_id bigint,
    metric_id bigint,
    ts_raw timestamptz,
    ts_bucket timestamptz,
    value numeric,
    source_hint text,
    inserted_at timestamptz
)
```

**返回值结构**：
| 字段名 | 类型 | 说明 |
|--------|------|------|
| station_id | bigint | 泵站ID |
| device_id | bigint | 设备ID |
| metric_id | bigint | 指标ID |
| ts_raw | timestamptz | 原始时间戳 |
| ts_bucket | timestamptz | 时间桶 |
| value | numeric | 测量值 |
| source_hint | text | 数据来源 |
| inserted_at | timestamptz | 插入时间 |

**使用示例**：
```sql
SELECT *
FROM api.get_measurements(
    p_station_ids := ARRAY[1, 2],
    p_start_ts := '2025-01-01 00:00:00+00',
    p_end_ts := '2025-01-31 23:59:59+00',
    p_device_ids := ARRAY[1, 2, 3],
    p_metric_ids := ARRAY[10, 11, 12],
    p_limit := 5000,
    p_offset := 0
);
```

**使用示例**：

## reporting Schema 函数（数据查询和聚合）

### get_metrics_hourly
**用途**：获取小时级聚合数据（单泵站）  
**Schema**：reporting  
**完整签名**：
```sql
reporting.get_metrics_hourly(
    p_station_id bigint,
    p_start_ts timestamptz,
    p_end_ts timestamptz,
    p_metric_ids bigint[] DEFAULT NULL
) RETURNS TABLE(
    station_id bigint,
    device_id bigint,
    metric_id bigint,
    ts_hour timestamptz,
    cnt bigint,
    avg_value double precision,
    min_value double precision,
    max_value double precision,
    sum_value double precision
)
```

**返回值结构**：
| 字段名 | 类型 | 说明 |
|--------|------|------|
| station_id | bigint | 泵站ID |
| device_id | bigint | 设备ID |
| metric_id | bigint | 指标ID |
| ts_hour | timestamptz | 小时时间戳 |
| cnt | bigint | 数据点数量 |
| avg_value | double precision | 平均值 |
| min_value | double precision | 最小值 |
| max_value | double precision | 最大值 |
| sum_value | double precision | 总和 |

**使用示例**：
```sql
SELECT *
FROM reporting.get_metrics_hourly(
    p_station_id := 1,
    p_start_ts := '2025-01-01 00:00:00+00',
    p_end_ts := '2025-01-31 23:59:59+00',
    p_metric_ids := ARRAY[10, 11, 12]
)
ORDER BY ts_hour, device_id, metric_id;
```

### get_metrics_auto
**用途**：自动选择聚合粒度查询（根据时间跨度自动选择小时级或日级）  
**Schema**：reporting  
**完整签名**：
```sql
reporting.get_metrics_auto(
    p_station_id bigint,
    p_start_ts timestamptz,
    p_end_ts timestamptz,
    p_metric_ids bigint[] DEFAULT NULL,
    p_threshold_days integer DEFAULT 3
) RETURNS TABLE(
    station_id bigint,
    device_id bigint,
    metric_id bigint,
    ts timestamptz,
    cnt bigint,
    avg_value double precision,
    min_value double precision,
    max_value double precision,
    sum_value double precision
)
```

**业务逻辑**：
- 如果时间跨度 <= p_threshold_days，使用小时级聚合
- 如果时间跨度 > p_threshold_days，使用日级聚合
