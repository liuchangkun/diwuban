## reporting Schema 物化视图

### mv_measurements_hourly
**用途**：按小时聚合的测量数据
**Schema**：reporting
**基表**：public.fact_measurements
**聚合粒度**：1小时
**大小**：8192 bytes
**填充状态**：未填充 (ispopulated=false)

**聚合字段**：
- station_id, device_id, metric_id
- ts_hour (时间桶，按小时)
- cnt, avg_value, min_value, max_value, sum_value

**用途说明**：用于小时级别的数据查询，支持 reporting.get_metrics_hourly 函数

---

### mv_measurements_daily
**用途**：按日聚合的测量数据
**Schema**：reporting
**基表**：public.fact_measurements
**聚合粒度**：1天
**大小**：8192 bytes
**填充状态**：未填充 (ispopulated=false)

**聚合字段**：
- station_id, device_id, metric_id
- ts (日期)
- cnt, avg_value, min_value, max_value, sum_value

**用途说明**：用于日级别的数据查询，支持 reporting.get_metrics_daily 函数
