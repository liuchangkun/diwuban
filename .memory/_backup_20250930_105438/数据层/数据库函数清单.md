# 数据库函数清单

> 最后更新：2025-09-30
> 更新者：AI（已填充）

## api Schema 函数（数据CRUD操作）

### upsert_measurement
**用途**：插入或更新单条测量数据  
**返回**：boolean

### delete_measurement
**用途**：删除单条测量数据  
**返回**：integer

### get_measurements
**用途**：查询测量数据  
**返回**：TABLE

### delete_measurements_by_filter
**用途**：批量删除

### upsert_measurements_json
**用途**：批量插入或更新（JSON格式）

---

## reporting Schema 函数（数据查询和聚合）

### get_device_metrics_by_time_range
**用途**：获取单个设备的时序数据（透视格式）

### get_station_devices_metrics_by_time_range
**用途**：获取整个泵站所有设备的时序数据

### get_metrics_hourly / get_metrics_hourly_multi
**用途**：获取小时级聚合数据

### get_metrics_daily / get_metrics_daily_multi
**用途**：获取日级聚合数据

### get_metrics_auto / get_metrics_auto_multi
**用途**：自动选择聚合粒度查询

### refresh_mv_measurements
**用途**：刷新物化视图

---

## public Schema 核心业务函数

### sp_mark_quality_window
**用途**：数据质量标注存储过程  
**质量检查类型**：计数器单调性(751)、功率因数异常(701)、三相不平衡(702)、状态矛盾(401)、物理越界(101)、异常跳变(111)、平台期(121)

### fn_running_state_1s
**用途**：设备运行状态判定（1秒粒度）

### fn_startstop_windows
**用途**：启停窗口检测

### fn_detect_gaps_1s
**用途**：数据缺失检测（1秒粒度）

### fn_quality_stats_1d
**用途**：质量统计（日粒度）

### fn_training_timeseries_1s
**用途**：获取训练用时序数据

### safe_upsert_measurement
**用途**：安全的数据插入（带错误处理）

### metrics_presence_per_second
**用途**：按秒统计指标存在性

### metrics_availability_window
**用途**：指标可用性窗口统计

---

## 分区管理函数

### ensure_mpps_partitions
**用途**：确保分区表存在

### ensure_week_partition
**用途**：确保周分区表存在

### database_health_check

### check_data_consistency

### get_performance_metrics
