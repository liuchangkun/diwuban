# 类清单

> 最后更新：2025-09-30
> 更新者：AI（已填充）

## 核心类

### DatabasePool
**文件**：app/adapters/db/pool.py  
**用途**：数据库连接池管理  
**主要方法**：get_connection、close  
**配置**：最小1个，最大10个连接

### DataImporter
**文件**：app/services/data_import.py  
**用途**：数据导入器  
**主要方法**：import_csv、validate_data

### QualityChecker
**文件**：app/services/quality/  
**用途**：质量检查器  
**主要方法**：check_quality、mark_quality_window

### CurveFitter
**文件**：app/services/curve_fitting.py  
**用途**：曲线拟合器  
**主要方法**：fit_curve、evaluate_fit

## 模型类

### Station
**文件**：app/models/station.py  
**用途**：泵站模型  
**字段**：id、name、extra、created_at

### Device
**文件**：app/models/device.py  
**用途**：设备模型  
**字段**：id、station_id、name、type、pump_type、extra

### Metric
**文件**：app/models/metric.py  
**用途**：指标模型  
**字段**：id、metric_key、unit、value_type、valid_min、valid_max

### Measurement
**文件**：app/models/operation_data.py  
**用途**：测量数据模型  
**字段**：id、station_id、device_id、metric_id、ts_raw、ts_bucket、value
