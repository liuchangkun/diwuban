# 应用函数清单

> 最后更新：2025-09-30
> 更新者：AI（已填充）

## 数据导入相关

### import_csv
**文件**：app/services/data_import.py  
**签名**：async def import_csv(file_path: str, station_id: int) -> ImportResult  
**用途**：导入CSV文件到数据库  
**主要步骤**：编码检测  解析  验证  staging表  COPY命令  fact_measurements

### validate_data
**文件**：app/services/data_import.py  
**用途**：验证CSV数据的有效性  
**检查项**：必要字段、数值范围、布尔值规范化

## 质量控制相关

### check_quality
**文件**：app/services/quality/  
**用途**：执行数据质量检查  
**检查类型**：物理越界、异常跳变、平台期、噪声

### mark_quality_window
**文件**：app/services/quality/  
**用途**：标注质量问题时间窗口  
**调用**：sp_mark_quality_window 存储过程

## 曲线拟合相关

### fit_curve
**文件**：app/services/curve_fitting.py  
**用途**：拟合特性曲线  
**支持类型**：H-Q、η-Q、P-Q曲线

### evaluate_fit
**文件**：app/services/curve_fitting.py  
**用途**：评估拟合质量  
**返回**：R、RMSE等指标

## 数据查询相关

### get_timeseries
**文件**：app/services/reporting/  
**用途**：获取时序数据  
**调用**：reporting.get_device_metrics_by_time_range

### get_aggregated_data
**文件**：app/services/reporting/  
**用途**：获取聚合数据  
**调用**：reporting.get_metrics_hourly/daily/auto
