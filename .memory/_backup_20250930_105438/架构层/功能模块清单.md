# 功能模块清单

> 最后更新：2025-09-30
> 更新者：AI（已填充）

## 数据导入模块
**路径**：app/services/data_import.py  
**职责**：CSV文件导入到数据库  
**依赖**：DatabasePool、staging表  
**主要功能**：编码检测、数据验证、批量导入

## 质量控制模块
**路径**：app/services/quality/  
**职责**：数据质量检查和标注  
**依赖**：fact_measurements、质量规则  
**主要功能**：物理越界检查、异常跳变检测、平台期识别

## 特性曲线拟合模块
**路径**：app/services/curve_fitting.py  
**职责**：H-Q、η-Q、P-Q曲线拟合  
**依赖**：numpy、scipy  
**主要功能**：多项式拟合、拟合质量评估

## 数据完成模块
**路径**：app/services/data_completion.py  
**职责**：缺失指标计算和补全  
**依赖**：物理模型、特性曲线  
**主要功能**：基于物理模型推导缺失指标

## 数据查询模块
**路径**：app/services/reporting/  
**职责**：时序数据查询和聚合  
**依赖**：reporting schema、物化视图  
**主要功能**：多粒度数据查询、透视数据生成
