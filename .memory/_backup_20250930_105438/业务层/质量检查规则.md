# 质量检查规则

> 最后更新：2025-09-30
> 更新者：AI（已填充）

## 质量码定义

### 101 - 物理越界
**说明**：数值超出物理有效范围  
**检查**：value < valid_min OR value > valid_max  
**示例**：有功功率 < 0 或 > 10000kW

### 111 - 异常跳变
**说明**：相邻数据点变化过大  
**检查**：abs(value - prev_value) > threshold  
**阈值**：根据指标类型动态设置

### 121 - 平台期
**说明**：连续多个相同值  
**检查**：连续N个点值相同  
**阈值**：N通常设置为10-20

### 401 - 状态矛盾
**说明**：运行状态与指标值矛盾  
**检查**：运行状态=0但功率>0  
**示例**：设备显示停止但电流不为0

### 701 - 功率因数异常
**说明**：功率因数超出合理范围  
**检查**：power_factor < 0 OR power_factor > 1  
**合理范围**：0.7-1.0

### 702 - 三相不平衡
**说明**：三相电流不平衡度过大  
**检查**：max(A,B,C) - min(A,B,C) > threshold  
**阈值**：通常设置为平均值的20%

### 751 - 计数器单调性
**说明**：累计量出现回退  
**检查**：current_value < previous_value  
**适用**：累计电量、累计流量等

## 质量检查流程
1. 读取指定时间窗口的数据
2. 按质量规则逐项检查
3. 标注质量码到quality_codes数组
4. 更新quality_status字段
5. 记录诊断日志到quality_diagnosis_log
