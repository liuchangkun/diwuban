# 业务流程

> 最后更新：2025-09-30
> 更新者：AI（已填充）

## 数据导入流程
1. 用户上传CSV文件
2. 系统检测文件编码（UTF-8、GBK）
3. 解析CSV内容
4. 验证数据格式和范围
5. 写入staging表
6. 使用COPY命令批量导入fact_measurements
7. 返回导入结果

## 质量控制流程
1. 读取fact_measurements数据
2. 应用质量检查规则（物理越界、异常跳变、平台期等）
3. 标注质量问题
4. 更新quality_status和quality_codes字段
5. 记录质量诊断日志

## 数据完成流程
1. 识别缺失指标
2. 检查是否可通过物理模型计算
3. 获取必要的输入指标
4. 应用物理模型计算缺失指标
5. 验证计算结果的合理性
6. 写入计算结果到fact_measurements

## 特性曲线拟合流程
1. 获取设备的运行数据（稳态数据）
2. 数据清洗和异常值处理
3. 应用多项式拟合算法
4. 评估拟合质量（R、RMSE）
5. 存储拟合参数
6. 用于后续的数据验证和补全
