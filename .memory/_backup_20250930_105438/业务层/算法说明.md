# 算法说明

> 最后更新：2025-09-30

## 特性曲线拟合算法

### H-Q曲线拟合
**用途**：扬程-流量特性曲线  
**方法**：多项式拟合（numpy.polyfit）  
**阶数**：通常使用2-3阶多项式

### η-Q曲线拟合
**用途**：效率-流量特性曲线  
**方法**：多项式拟合  
**阶数**：通常使用2-3阶多项式

### P-Q曲线拟合
**用途**：功率-流量特性曲线  
**方法**：多项式拟合  
**阶数**：通常使用2-3阶多项式

## 自动基线计算

### 方案A (robust)
**方法**：基于分位数和MAD的稳健估计  
**适用**：稳态数据  
**步骤**：
1. 过滤质量=0且稳态(phase=1)的数据
2. 计算中位数和MAD
3. 使用稳健估计方法计算基线

### 方案B (STL)
**方法**：基于STL时间序列分解  
**适用**：有周期性的数据  
**步骤**：
1. STL分解（趋势+季节+残差）
2. 提取趋势分量作为基线
3. 写入影子表进行对比

## 运行状态判定算法
**方法**：基于电流、功率、频率的综合标准分数  
**粒度**：1秒  
**步骤**：
1. 计算电流A/B/C的最大值
2. 获取有功功率和频率
3. 计算综合标准分数
4. 与运行阈值比较
5. 应用状态保持和回退机制
