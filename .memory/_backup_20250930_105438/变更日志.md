## 变更日志格式说明

每次变更请按以下格式记录：

```markdown
## YYYY-MM-DD

### [变更类型]
- **创建者/更新者**：[AI/用户名]
- **变更类型**：[新增/更新/删除/重构]
- **影响范围**：[文件列表]
- **变更内容**：
  - [具体变更1]
  - [具体变更2]
- **原因**：[为什么做这个变更]
```

### 变更类型说明

- **新增**：创建新的实体、关系或文档
- **更新**：修改已有实体的观察或文档内容
- **删除**：删除过时或错误的信息
- **重构**：重新组织记忆结构
- **验证**：验证记忆准确性并修正
- **初始化**：系统或模块的初始化
