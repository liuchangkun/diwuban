## 1. 组合方法概述

### 1.1 为什么需要组合方法？

**单一方法的局限性**：
- 不同方法在不同区域表现不同
- 单一方法可能过拟合或欠拟合
- 难以同时满足精度、鲁棒性、可解释性

**组合方法的优势**：
- **精度提升**：通常比最好的单一方法提升2-5%
- **鲁棒性**：减少单一方法的偏差和方差
- **泛化能力**：在不同数据集上表现稳定

### 1.2 组合方法的三大类

**类别A：加权平均**
```
y_pred = Σ w_i × f_i(x)
```
- 简单、快速、可解释
- 权重可以是固定的或自适应的

**类别B：Stacking（堆叠）**
```
y_pred = g(f_1(x), f_2(x), ..., f_n(x))
```
- 使用元模型学习如何组合
- 精度最高，但复杂度高

**类别C：Boosting（提升）**
```
y_pred = Σ α_i × h_i(x)
```
- 迭代训练，每个模型纠正前面的错误
- 精度高，但容易过拟合

## 2. 基础组合方法（5种）

### 方法125：`ensemble_weighted_average` - 加权平均

**组合策略**：
```
y_pred = w_1×f_1(x) + w_2×f_2(x) + ... + w_n×f_n(x)

约束：Σ w_i = 1, w_i ≥ 0
```

**权重确定方法**：

**方法1：基于R²的权重**
```python
w_i = r2_i / Σ r2_j
```

**方法2：基于RMSE的权重**
```python
w_i = (1/rmse_i) / Σ (1/rmse_j)
```

**方法3：优化权重**
```python
# 最小化预测误差
min Σ (y_true - Σ w_i×f_i(x))²
s.t. Σ w_i = 1, w_i ≥ 0
```

**适用曲线**：所有曲线类型

**预期精度**：R² > 0.96（比最好的单一方法提升1-3%）

**优点**：
1. **简单直观**：易于理解和实现
2. **快速**：计算成本低
3. **稳定**：减少单一方法的偏差
4. **可解释**：权重有明确意义

**缺点**：
1. **精度提升有限**：通常只提升1-3%
2. **权重固定**：不能自适应不同区域

**代码示例**：
```python
import numpy as np
from scipy.optimize import minimize

class EnsembleWeightedAverage:
    """加权平均组合方法"""
    
    def __init__(self, base_methods, weight_method='r2'):
        """
        Parameters:
        -----------
        base_methods : list
            基础方法列表
        weight_method : str
            权重确定方法：'r2', 'rmse', 'optimize'
        """
        self.base_methods = base_methods
        self.weight_method = weight_method
        self.weights = None
        self.base_results = []
    
    def fit(self, X, y):
        """
        拟合组合方法
        
        Parameters:
        -----------
        X : np.ndarray
            自变量
        y : np.ndarray
            因变量
        
        Returns:
        --------
        result : dict
            拟合结果
        """
        # 1. 拟合所有基础方法
        self.base_results = []
        predictions = []
        
        for method in self.base_methods:
            result = method.fit(X, y)
            self.base_results.append(result)
            
            y_pred = method.predict(X)
            predictions.append(y_pred)
        
        predictions = np.array(predictions)  # shape: (n_methods, n_samples)
        
        # 2. 确定权重
        if self.weight_method == 'r2':
            # 基于R²的权重
            r2_values = np.array([r['r2'] for r in self.base_results])
            self.weights = r2_values / np.sum(r2_values)
        
        elif self.weight_method == 'rmse':
            # 基于RMSE的权重（倒数）
            rmse_values = np.array([r['rmse'] for r in self.base_results])
            inv_rmse = 1.0 / rmse_values
            self.weights = inv_rmse / np.sum(inv_rmse)
        
        elif self.weight_method == 'optimize':
            # 优化权重
            def objective(w):
                y_pred = np.dot(w, predictions)
                return np.sum((y - y_pred)**2)
            
            # 约束：权重和为1，权重非负
            constraints = [
                {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
            ]
            bounds = [(0, 1) for _ in range(len(self.base_methods))]
            
            # 初始权重：均匀分布
            w0 = np.ones(len(self.base_methods)) / len(self.base_methods)
            
            result_opt = minimize(objective, w0, 
                                 method='SLSQP',
                                 bounds=bounds,
                                 constraints=constraints)
            
            self.weights = result_opt.x
        
        # 3. 组合预测
        y_pred = np.dot(self.weights, predictions)
        
        # 4. 评估
        r2 = 1 - np.sum((y - y_pred)**2) / np.sum((y - np.mean(y))**2)
        rmse = np.sqrt(np.mean((y - y_pred)**2))
        mae = np.mean(np.abs(y - y_pred))
        
        # 计算精度提升
        best_base_r2 = max([r['r2'] for r in self.base_results])
        improvement = r2 - best_base_r2
        
        return {
            'params': {
                'weights': self.weights,
                'weight_method': self.weight_method
            },
            'r2': r2,
            'rmse': rmse,
            'mae': mae,
            'improvement': improvement,
            'base_results': self.base_results
        }
    
    def predict(self, X):
        """预测"""
        predictions = []
        for method in self.base_methods:
            y_pred = method.predict(X)
            predictions.append(y_pred)
        
        predictions = np.array(predictions)
        y_pred = np.dot(self.weights, predictions)
        
        return y_pred

# 使用示例
from sklearn.ensemble import GradientBoostingRegressor, RandomForestRegressor
from sklearn.neural_network import MLPRegressor

# 生成测试数据
Q = np.linspace(0, 300, 200).reshape(-1, 1)
H = 120 - 0.2*Q.flatten() - 0.001*Q.flatten()**2 + np.random.normal(0, 2, 200)

# 定义基础方法（简化示例，实际应使用自定义方法类）
class SimpleMethod:
    def __init__(self, model):
        self.model = model
    
    def fit(self, X, y):
        self.model.fit(X, y)
        y_pred = self.model.predict(X)
        r2 = 1 - np.sum((y - y_pred)**2) / np.sum((y - np.mean(y))**2)
        rmse = np.sqrt(np.mean((y - y_pred)**2))
        return {'r2': r2, 'rmse': rmse}
    
    def predict(self, X):
        return self.model.predict(X)

# 创建基础方法
base_methods = [
    SimpleMethod(GradientBoostingRegressor(n_estimators=50, random_state=42)),
    SimpleMethod(RandomForestRegressor(n_estimators=50, random_state=42)),
    SimpleMethod(MLPRegressor(hidden_layer_sizes=(20,), max_iter=1000, random_state=42))
]

# 组合方法
ensemble = EnsembleWeightedAverage(base_methods, weight_method='optimize')
result = ensemble.fit(Q, H)

print(f"组合方法 R² = {result['r2']:.4f}")
print(f"精度提升 = {result['improvement']:.4f}")
print(f"权重: {result['params']['weights']}")

# 打印各基础方法的性能
for i, base_result in enumerate(result['base_results']):
    print(f"方法{i+1} R² = {base_result['r2']:.4f}")
```

**使用场景**：
1. **多方法可用**：有多个候选方法
2. **需要稳定性**：减少单一方法的风险
3. **快速组合**：不需要复杂的元模型
4. **可解释性**：需要理解各方法的贡献

## 📊 组合方法选择建议

### 按精度选择
- **极高精度（R²>0.98）**：`ensemble_stacking_gbm`, `ensemble_stacking_rf`, `ensemble_boosting_xgboost`
- **高精度（R²>0.97）**：`ensemble_stacking_linear`, `ensemble_adaptive_weighted`
- **中等精度（R²>0.96）**：`ensemble_weighted_average`, `ensemble_bagging`

### 按速度选择
- **最快**：`ensemble_simple_average`, `ensemble_weighted_average`
- **快速**：`ensemble_blending`, `ensemble_bagging`
- **中速**：`ensemble_stacking_linear`, `ensemble_adaptive_weighted`
- **慢速**：`ensemble_stacking_gbm`, `ensemble_boosting_xgboost`

### 按场景选择
- **需要可解释性**：`ensemble_weighted_average`, `ensemble_simple_average`
- **需要鲁棒性**：`ensemble_median`, `ensemble_trimmed_mean`
- **需要极高精度**：`ensemble_stacking_gbm`, `ensemble_boosting_xgboost`
- **大数据集**：`ensemble_blending`, `ensemble_bagging`
