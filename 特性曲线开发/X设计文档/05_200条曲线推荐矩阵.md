## 1. 单泵基本特性曲线（6条）

### 1.1 Q-H曲线（流量-扬程）

**曲线特征**：单调递减，流量增加扬程下降

**数据要求**：>100点，覆盖0-Qmax全范围

#### 场景1：快速拟合（<5秒）

**推荐方法**（按优先级）：
1. `physics_pump_char` - 泵特性方程（H = H0 - K1×Q - K2×Q²）
2. `math_quadratic_decay` - 二次衰减
3. `math_linear_regression` - 线性回归（粗略估算）
4. `math_poly_2` - 2次多项式
5. `math_power_decay` - 幂律衰减

**组合策略**：
- 单一方法即可，推荐 `physics_pump_char`
- 如需验证：`physics_pump_char` + `math_quadratic_decay`（加权平均）

**预期精度**：R² > 0.93

**代码示例**：
```python
# 快速拟合
from curve_fitting import physics_pump_char
params, r2 = physics_pump_char.fit(Q_data, H_data)
H_pred = physics_pump_char.predict(Q_new, params)
```

---

#### 场景2：高精度拟合（R²>0.97）

**推荐方法**（按优先级）：
1. `ml_gradient_boost` - 梯度提升树
2. `hybrid_physics_decay` - 混合衰减方法（物理+数据驱动）
3. `ml_neural_network_deep` - 深层神经网络
4. `math_rational_decay_4_3` - 有理函数(4,3)
5. `math_cubic_decay` - 三次衰减

**组合策略**：
- **Stacking-GBM**：`ml_gradient_boost` + `ml_neural_network_deep` + `hybrid_physics_decay`（元模型：梯度提升）
- **加权平均**：`ml_gradient_boost`(0.4) + `hybrid_physics_decay`(0.4) + `ml_neural_network_deep`(0.2)

**预期精度**：R² > 0.97

**代码示例**：
```python
# 高精度组合拟合
from curve_fitting import ensemble_stacking_gbm

# 基模型
base_models = [
    'ml_gradient_boost',
    'ml_neural_network_deep',
    'hybrid_physics_decay'
]

# Stacking组合
params, r2 = ensemble_stacking_gbm.fit(Q_data, H_data, base_models)
H_pred = ensemble_stacking_gbm.predict(Q_new, params)
```

#### 场景3：物理约束拟合

**推荐方法**（按优先级）：
1. `physics_pump_char` - 泵特性方程
2. `physics_pump_char_extended` - 扩展泵特性
3. `ml_pinn` - 物理信息神经网络
4. `hybrid_physics_decay` - 混合衰减方法
5. `physics_euler_equation` - 欧拉方程（需要几何参数）

**物理约束**：
- H0 > 0（零流量扬程为正）
- dH/dQ < 0（扬程随流量单调递减）
- H(Qmax) > 0（最大流量时扬程仍为正）

**组合策略**：
- **加权平均**：`physics_pump_char`(0.5) + `ml_pinn`(0.5)
- **物理先验**：先用 `physics_pump_char` 拟合，再用 `ml_pinn` 精化

**预期精度**：R² > 0.95

---

#### 场景4：鲁棒性拟合（抗异常值）

**推荐方法**（按优先级）：
1. `math_local_lowess` - 局部加权回归
2. `ml_random_forest` - 随机森林
3. `math_piecewise_linear` - 分段线性
4. `math_linear_robust` - 鲁棒线性回归
5. `ml_gaussian_process` - 高斯过程回归

**组合策略**：
- **投票机制**：`math_local_lowess` + `ml_random_forest` + `math_piecewise_linear`（中位数投票）
- **加权中位数**：`math_local_lowess`(0.4) + `ml_random_forest`(0.4) + `math_piecewise_linear`(0.2)

**预期精度**：R² > 0.94

---

#### 场景5：数据量少（<100点）

**推荐方法**（按优先级）：
1. `physics_pump_char` - 泵特性方程
2. `math_quadratic_decay` - 二次衰减
3. `math_power_decay` - 幂律衰减
4. `math_rational_decay_2_1` - 有理函数(2,1)

**组合策略**：
- 单一方法即可，避免过拟合
- 如需组合：`physics_pump_char` + `math_quadratic_decay`（简单平均）

**预期精度**：R² > 0.92

---

#### 场景6：需要外推

**推荐方法**（按优先级）：
1. `physics_pump_char` - 泵特性方程
2. `math_rational_decay_3_2` - 有理函数(3,2)
3. `physics_euler_equation` - 欧拉方程
4. `math_power_decay` - 幂律衰减

**组合策略**：
- 单一物理模型最佳
- 如需组合：`physics_pump_char`(0.7) + `math_rational_decay_3_2`(0.3)

**预期精度**：R² > 0.93

### 1.2 Q-P曲线（流量-功率）

**曲线特征**：单调递增，流量增加功率增加

**数据要求**：>100点，覆盖0-Qmax全范围

#### 场景1：快速拟合

**推荐方法**：
1. `physics_power_eq` - 功率方程（P = ρgQH/η）
2. `math_quadratic_growth` - 二次增长
3. `math_linear_growth` - 线性增长
4. `math_poly_2` - 2次多项式

**组合策略**：单一方法即可

**预期精度**：R² > 0.92

---

#### 场景2：高精度拟合

**推荐方法**：
1. `ml_gradient_boost` - 梯度提升树
2. `ml_neural_network_deep` - 深层神经网络
3. `math_cubic_growth` - 三次增长
4. `physics_power_eq_cubic` - 三次功率方程
5. `hybrid_physics_growth` - 混合增长方法

**组合策略**：
- **Stacking-RF**：`ml_gradient_boost` + `physics_power_eq_cubic` + `ml_neural_network_deep`（元模型：随机森林）

**预期精度**：R² > 0.96

---

#### 场景3：物理约束拟合

**推荐方法**：
1. `physics_power_eq` - 功率方程
2. `physics_power_eq_extended` - 扩展功率方程
3. `hybrid_physics_growth` - 混合增长方法
4. `ml_pinn` - 物理信息神经网络

**物理约束**：
- P(0) ≈ P_mechanical（零流量时为机械损失功率）
- dP/dQ > 0（功率随流量单调递增）
- P = ρgQH/η（能量守恒）

**组合策略**：
- **加权平均**：`physics_power_eq`(0.6) + `ml_pinn`(0.4)

**预期精度**：R² > 0.94

### 1.3 Q-η曲线（流量-效率）

**曲线特征**：单峰，存在最佳效率点（BEP）

**数据要求**：>100点，覆盖0-Qmax全范围

#### 场景1：快速拟合

**推荐方法**：
1. `math_stat_gaussian` - 高斯函数
2. `math_poly_4_peak` - 4次多项式（单峰约束）
3. `math_lorentzian` - Lorentz峰

**组合策略**：单一方法即可

**预期精度**：R² > 0.94

---

#### 场景2：高精度拟合

**推荐方法**：
1. `math_stat_pearson` - Pearson分布族
2. `math_stat_skewnormal` - 偏态正态分布
3. `ml_gradient_boost` - 梯度提升树
4. `math_poly_6_peak` - 6次多项式（单峰约束）
5. `math_rational_peak_4_3` - 有理函数（单峰约束）
6. `physics_efficiency_extended` - 扩展效率模型

**组合策略**：
- **Stacking-Linear**：`math_stat_pearson` + `ml_gradient_boost` + `physics_efficiency_extended`（元模型：线性回归）

**预期精度**：R² > 0.97

---

#### 场景3：物理约束拟合

**推荐方法**：
1. `physics_efficiency_model` - 效率物理模型（η = 1 - k1/Q - k2×Q - k3×Q²）
2. `physics_efficiency_extended` - 扩展效率模型
3. `math_stat_beta` - Beta分布（自动满足[0,1]约束）
4. `ml_pinn` - 物理信息神经网络

**物理约束**：
- 0 ≤ η ≤ 1（效率在0-100%之间）
- 存在唯一最大值（BEP点）
- η(0) = 0, η(Qmax) → 0（边界条件）

**组合策略**：
- **加权平均**：`physics_efficiency_model`(0.5) + `math_stat_beta`(0.5)

**预期精度**：R² > 0.95

## 2. 变频泵特性曲线族（22条）

### 2.1 不同转速下的Q-H曲线族

**曲线特征**：多变量（Q, H, f），三维曲面

**数据要求**：>500点，覆盖多个频率

#### 场景1：快速拟合

**推荐方法**：
1. `physics_affinity_law` - 相似定律（Q2/Q1=f2/f1, H2/H1=(f2/f1)²）
2. `ml_multivariate_poly_2` - 2次多变量多项式
3. `math_bilinear_interp` - 双线性插值

**组合策略**：单一方法即可，推荐 `physics_affinity_law`

**预期精度**：R² > 0.94

---

#### 场景2：高精度拟合

**推荐方法**：
1. `physics_affinity_law_corrected` - 修正相似定律（考虑效率变化）
2. `ml_pinn_hard_constraint` - 硬约束物理信息神经网络
3. `ml_neural_network_deep` - 深层神经网络
4. `ml_multivariate_poly_4` - 4次多变量多项式
5. `ml_gpr_2d` - 二维高斯过程

**组合策略**：
- **Stacking-RF**：`physics_affinity_law_corrected` + `ml_pinn` + `ml_neural_network_deep`（元模型：随机森林）

**预期精度**：R² > 0.98

---

#### 场景3：物理约束拟合

**推荐方法**：
1. `physics_affinity_law_corrected` - 修正相似定律
2. `physics_affinity_law_extended` - 扩展相似定律
3. `ml_pinn_hard_constraint` - 硬约束PINN
4. `ml_pinn_soft_constraint` - 软约束PINN
5. `hybrid_physics_multivariate` - 混合多变量方法

**物理约束**：
- Q ∝ f（流量与频率成正比）
- H ∝ f²（扬程与频率平方成正比）
- P ∝ f³（功率与频率立方成正比）
- η ≈ 常数（效率近似不变）

**组合策略**：
- **加权平均**：`physics_affinity_law_corrected`(0.7) + `ml_pinn_hard_constraint`(0.3)

**预期精度**：R² > 0.99
