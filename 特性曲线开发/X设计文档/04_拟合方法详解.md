## 2. 数学方法（Math）

### 2.1 math_poly_2（2次多项式）

#### 2.1.1 数学公式

**Q-H曲线**：
```
H = a0 + a1*Q + a2*Q²
```

**Q-P曲线**：
```
P = a0 + a1*Q + a2*Q²
```

**Q-η曲线**（不推荐，建议用 math_stat_gaussian）：
```
η = a0 + a1*Q + a2*Q²
```

#### 2.1.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `degree` | int | 2 | 多项式次数（固定为2） |
| `regularization` | str | None | 正则化类型（'l1', 'l2', None） |
| `lambda` | float | 0.01 | 正则化系数 |

#### 2.1.3 物理约束集成

**集成模式**：模式1（后验验证）

**工作流程**：
1. 独立完成多项式拟合
2. 自动调用 PhysicsValidator 验证物理约束
3. 如果违反约束 → 标记警告或触发重拟合

**您需要做什么**：❌ 无需操作，完全自动

#### 2.1.4 实现代码

```python
import numpy as np
from scipy.optimize import curve_fit
from app.services.characteristic_curves.methods.base_method import BaseMethod, MethodResult

class MathPoly2Method(BaseMethod):
    """2次多项式拟合方法"""

    method_name = 'math_poly_2'

    def __init__(self, regularization: str = None, lambda_: float = 0.01):
        """
        初始化

        Args:
            regularization: 正则化类型（'l1', 'l2', None）
            lambda_: 正则化系数
        """
        super().__init__(regularization=regularization, lambda_=lambda_)
        self.degree = 2

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        拟合2次多项式

        Args:
            X: 流量数组
            y: 扬程/功率/效率数组

        Returns:
            result: 拟合结果
        """
        # 使用numpy.polyfit拟合
        if self.params['regularization'] is None:
            # 无正则化
            coeffs = np.polyfit(X, y, self.degree)
        else:
            # 带正则化（使用Ridge回归）
            from sklearn.linear_model import Ridge
            X_poly = np.column_stack([X**i for i in range(self.degree + 1)])
            model = Ridge(alpha=self.params['lambda_'])
            model.fit(X_poly, y)
            coeffs = model.coef_[::-1]  # 反转顺序

        # 预测
        y_pred = self.predict(X, {'a0': coeffs[2], 'a1': coeffs[1], 'a2': coeffs[0]})

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        return MethodResult(
            method_name=self.method_name,
            fit_params={'a0': float(coeffs[2]), 'a1': float(coeffs[1]), 'a2': float(coeffs[0])},
            **metrics,
            metadata={'degree': self.degree, 'regularization': self.params['regularization']}
        )

    def predict(self, X: np.ndarray, params: Dict[str, float]) -> np.ndarray:
        """
        预测

        Args:
            X: 流量数组
            params: 拟合参数 {'a0', 'a1', 'a2'}

        Returns:
            y_pred: 预测值数组
        """
        return params['a0'] + params['a1'] * X + params['a2'] * X**2
```

### 2.2 math_poly_3（3次多项式）

#### 2.2.1 数学公式

```
H = a0 + a1*Q + a2*Q² + a3*Q³
```

#### 2.2.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `degree` | int | 3 | 多项式次数（固定为3） |
| `regularization` | str | 'l2' | 正则化类型（建议使用，防止过拟合） |
| `lambda` | float | 0.05 | 正则化系数（比2次多项式更大） |

#### 2.2.3 物理约束集成

**集成模式**：模式1（后验验证）

**工作流程**：与 math_poly_2 相同，完全自动

#### 2.2.4 实现代码

```python
class MathPoly3Method(BaseMethod):
    """3次多项式拟合方法"""

    method_name = 'math_poly_3'

    def __init__(self, regularization: str = 'l2', lambda_: float = 0.05):
        super().__init__(regularization=regularization, lambda_=lambda_)
        self.degree = 3

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """拟合3次多项式"""
        # 类似 MathPoly2Method，但degree=3
        # 建议使用正则化防止过拟合
        if self.params['regularization'] is None:
            coeffs = np.polyfit(X, y, self.degree)
        else:
            from sklearn.linear_model import Ridge
            X_poly = np.column_stack([X**i for i in range(self.degree + 1)])
            model = Ridge(alpha=self.params['lambda_'])
            model.fit(X_poly, y)
            coeffs = model.coef_[::-1]

        y_pred = self.predict(X, {f'a{i}': coeffs[self.degree-i] for i in range(self.degree+1)})
        metrics = self._calculate_metrics(y, y_pred)

        return MethodResult(
            method_name=self.method_name,
            fit_params={f'a{i}': float(coeffs[self.degree-i]) for i in range(self.degree+1)},
            **metrics,
            metadata={'degree': self.degree, 'regularization': self.params['regularization']}
        )

    def predict(self, X: np.ndarray, params: Dict[str, float]) -> np.ndarray:
        """预测"""
        return params['a0'] + params['a1'] * X + params['a2'] * X**2 + params['a3'] * X**3
```

#### 2.2.5 适用场景

✅ **适用**：
- 曲线形状复杂（有拐点）
- 数据量充足（>200点）
- math_poly_2 拟合效果不佳

❌ **不适用**：
- 数据量少（<200点，容易过拟合）
- 需要外推（3次多项式外推不稳定）

### 2.3 math_stat_gaussian（高斯函数）

#### 2.3.1 数学公式

```
η = a * exp(-((Q - mu)² / (2 * sigma²)))
```

其中：
- `a`：峰值效率（最大效率）
- `mu`：BEP流量（最佳效率点流量）
- `sigma`：标准差（控制曲线宽度）

#### 2.3.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `a_initial` | float | 0.85 | 峰值效率初始猜测 |
| `mu_initial` | float | None | BEP流量初始猜测（None=自动计算） |
| `sigma_initial` | float | None | 标准差初始猜测（None=自动计算） |

#### 2.3.3 物理约束集成

**集成模式**：模式1（后验验证）

**特殊说明**：高斯函数天然符合Q-η曲线的单峰特性，物理约束验证主要检查：
- 峰值位置是否在合理范围内
- 峰值效率是否在0-1之间

#### 2.3.4 实现代码

```python
from scipy.optimize import curve_fit

class MathStatGaussianMethod(BaseMethod):
    """高斯函数拟合方法（用于Q-η曲线）"""

    method_name = 'math_stat_gaussian'

    def __init__(self, a_initial: float = 0.85, mu_initial: float = None, sigma_initial: float = None):
        super().__init__(a_initial=a_initial, mu_initial=mu_initial, sigma_initial=sigma_initial)

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        拟合高斯函数

        Args:
            X: 流量数组
            y: 效率数组

        Returns:
            result: 拟合结果
        """
        # 自动计算初始猜测
        a_init = self.params['a_initial'] if self.params['a_initial'] else np.max(y)
        mu_init = self.params['mu_initial'] if self.params['mu_initial'] else X[np.argmax(y)]
        sigma_init = self.params['sigma_initial'] if self.params['sigma_initial'] else (X.max() - X.min()) / 4

        # 定义高斯函数
        def gaussian_func(x, a, mu, sigma):
            return a * np.exp(-((x - mu)**2 / (2 * sigma**2)))

        # 拟合
        try:
            popt, pcov = curve_fit(
                gaussian_func,
                X, y,
                p0=[a_init, mu_init, sigma_init],
                bounds=([0, X.min(), 0], [1.0, X.max(), X.max() - X.min()])
            )
        except Exception as e:
            raise FitError(f"高斯函数拟合失败: {e}")

        # 预测
        y_pred = self.predict(X, {'a': popt[0], 'mu': popt[1], 'sigma': popt[2]})

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        return MethodResult(
            method_name=self.method_name,
            fit_params={'a': float(popt[0]), 'mu': float(popt[1]), 'sigma': float(popt[2])},
            **metrics,
            metadata={'BEP_flow': float(popt[1]), 'BEP_efficiency': float(popt[0])}
        )

    def predict(self, X: np.ndarray, params: Dict[str, float]) -> np.ndarray:
        """预测"""
        return params['a'] * np.exp(-((X - params['mu'])**2 / (2 * params['sigma']**2)))
```

### 2.4 math_spline_cubic（三次样条插值）✨新增

#### 2.4.1 数学公式

三次样条是分段三次多项式，在每个区间 [xᵢ, xᵢ₊₁] 上：

```
S(x) = aᵢ + bᵢ(x - xᵢ) + cᵢ(x - xᵢ)² + dᵢ(x - xᵢ)³
```

**约束条件**：
- 在节点处连续（C⁰连续）
- 一阶导数连续（C¹连续）
- 二阶导数连续（C²连续）

#### 2.4.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `bc_type` | str | 'natural' | 边界条件类型（'natural', 'clamped', 'not-a-knot'） |
| `extrapolate` | bool | False | 是否允许外推（不推荐） |

#### 2.4.3 物理约束集成

**集成模式**：模式1（后验验证）

**工作流程**：
1. 使用三次样条插值拟合数据
2. 自动验证单调性、边界条件
3. 如果违反约束 → 标记警告

**优势**：曲线非常平滑（C²连续），不会出现多项式的振荡问题

#### 2.4.4 实现代码

```python
from scipy.interpolate import CubicSpline

class MathSplineCubicMethod(BaseMethod):
    """三次样条插值方法"""

    method_name = 'math_spline_cubic'

    def __init__(self, bc_type: str = 'natural', extrapolate: bool = False):
        """
        初始化

        Args:
            bc_type: 边界条件类型
                - 'natural': 自然边界（二阶导数为0）
                - 'clamped': 固定边界（一阶导数为0）
                - 'not-a-knot': 非节点边界
            extrapolate: 是否允许外推
        """
        super().__init__(bc_type=bc_type, extrapolate=extrapolate)

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        拟合三次样条

        Args:
            X: 流量数组
            y: 扬程/功率/效率数组

        Returns:
            result: 拟合结果
        """
        # 创建三次样条插值
        self.spline = CubicSpline(
            X, y,
            bc_type=self.params['bc_type'],
            extrapolate=self.params['extrapolate']
        )

        # 预测
        y_pred = self.spline(X)

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        # 提取样条系数（用于存储）
        fit_params = {
            'knots': X.tolist(),
            'coefficients': self.spline.c.tolist(),
            'bc_type': self.params['bc_type']
        }

        return MethodResult(
            method_name=self.method_name,
            fit_params=fit_params,
            **metrics,
            metadata={'n_knots': len(X), 'bc_type': self.params['bc_type']}
        )

    def predict(self, X: np.ndarray, params: Dict[str, Any]) -> np.ndarray:
        """
        预测

        Args:
            X: 流量数组
            params: 拟合参数（包含knots和coefficients）

        Returns:
            y_pred: 预测值数组
        """
        # 重建样条
        spline = CubicSpline.construct_fast(
            params['coefficients'],
            params['knots'],
            extrapolate=False
        )
        return spline(X)
```

### 2.5 math_spline_bspline（B样条）✨新增

#### 2.5.1 数学公式

B样条是基函数的线性组合：

```
S(x) = Σ cᵢ * Bᵢ,ₖ(x)
```

其中：
- `cᵢ`：控制点系数
- `Bᵢ,ₖ(x)`：k阶B样条基函数
- `k`：样条阶数（通常为3或5）

#### 2.5.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `degree` | int | 3 | B样条阶数（3=三次，5=五次） |
| `n_knots` | int | None | 节点数量（None=自动选择，约为数据点数的1/10） |
| `smoothing` | float | None | 平滑参数（None=最小二乘拟合，>0=平滑样条） |

#### 2.5.3 物理约束集成

**集成模式**：模式2（约束优化）

**工作流程**：
1. 自动计算物理约束（H₀, K等）
2. 使用约束优化算法（SLSQP）拟合B样条
3. 拟合结果天然满足物理约束（单调性、边界条件）

**优势**：
- ✅ 支持约束拟合（单调性、凸性）
- ✅ 数值稳定性好
- ✅ 局部控制性强

#### 2.5.4 实现代码

```python
from scipy.interpolate import make_lsq_spline, BSpline
from scipy.optimize import minimize
import numpy as np

class MathSplineBSplineMethod(BaseMethod):
    """B样条拟合方法"""

    method_name = 'math_spline_bspline'

    def __init__(self, degree: int = 3, n_knots: int = None, smoothing: float = None):
        """
        初始化

        Args:
            degree: B样条阶数（3或5）
            n_knots: 节点数量（None=自动选择）
            smoothing: 平滑参数
        """
        super().__init__(degree=degree, n_knots=n_knots, smoothing=smoothing)

    def fit(self, X: np.ndarray, y: np.ndarray, constraints: Dict = None, **kwargs) -> MethodResult:
        """
        拟合B样条

        Args:
            X: 流量数组
            y: 扬程/功率/效率数组
            constraints: 物理约束（自动传入）

        Returns:
            result: 拟合结果
        """
        # 自动选择节点数量
        n_knots = self.params['n_knots'] if self.params['n_knots'] else max(10, len(X) // 10)

        # 生成节点
        knots = np.linspace(X.min(), X.max(), n_knots)

        # 扩展节点（B样条要求）
        t = np.r_[(X.min(),) * (self.params['degree'] + 1),
                  knots,
                  (X.max(),) * (self.params['degree'] + 1)]

        if constraints and 'monotonicity' in constraints:
            # 约束优化拟合
            y_pred, fit_params = self._fit_with_constraints(X, y, t, constraints)
        else:
            # 最小二乘拟合
            spline = make_lsq_spline(X, y, t, k=self.params['degree'])
            y_pred = spline(X)
            fit_params = {
                'knots': t.tolist(),
                'coefficients': spline.c.tolist(),
                'degree': self.params['degree']
            }

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        return MethodResult(
            method_name=self.method_name,
            fit_params=fit_params,
            **metrics,
            metadata={'n_knots': n_knots, 'degree': self.params['degree']}
        )

    def _fit_with_constraints(self, X, y, t, constraints):
        """约束优化拟合"""
        # 定义目标函数
        def objective(c):
            spline = BSpline(t, c, self.params['degree'])
            y_pred = spline(X)
            return np.sum((y - y_pred)**2)

        # 定义单调性约束
        def monotonicity_constraint(c):
            spline = BSpline(t, c, self.params['degree'])
            derivatives = spline.derivative()(X)
            if constraints['monotonicity'] == 'decreasing':
                return -derivatives  # 必须 < 0
            else:
                return derivatives  # 必须 > 0

        # 初始猜测
        spline_init = make_lsq_spline(X, y, t, k=self.params['degree'])
        c_init = spline_init.c

        # 约束优化
        result = minimize(
            objective,
            c_init,
            method='SLSQP',
            constraints=[{'type': 'ineq', 'fun': monotonicity_constraint}]
        )

        # 预测
        spline_final = BSpline(t, result.x, self.params['degree'])
        y_pred = spline_final(X)

        fit_params = {
            'knots': t.tolist(),
            'coefficients': result.x.tolist(),
            'degree': self.params['degree']
        }

        return y_pred, fit_params

    def predict(self, X: np.ndarray, params: Dict[str, Any]) -> np.ndarray:
        """预测"""
        spline = BSpline(params['knots'], params['coefficients'], params['degree'])
        return spline(X)
```

### 2.6 math_kernel_rbf（径向基函数插值）✨新增

#### 2.6.1 数学公式

径向基函数（RBF）插值：

```
f(x) = Σ wᵢ * φ(||x - xᵢ||)
```

其中：
- `wᵢ`：权重系数
- `φ`：径向基函数（Gaussian, Multiquadric, Thin-plate等）
- `||x - xᵢ||`：欧氏距离

**常用核函数**：
- **Gaussian**: φ(r) = exp(-(εr)²)
- **Multiquadric**: φ(r) = √(1 + (εr)²)
- **Thin-plate**: φ(r) = r² log(r)

#### 2.6.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `kernel` | str | 'thin_plate' | 核函数类型（'gaussian', 'multiquadric', 'thin_plate'） |
| `epsilon` | float | None | 核函数形状参数（None=自动选择） |
| `smoothing` | float | 0.0 | 平滑参数（0=精确插值，>0=平滑拟合） |

#### 2.6.3 物理约束集成

**集成模式**：模式1（后验验证）

**特点**：
- RBF可以精确插值所有数据点（smoothing=0时）
- 但精确插值可能不符合物理约束
- 建议使用 smoothing>0 进行平滑拟合

```python
class MathKernelRBFMethod(BaseMethod):

        """
        初始化

            epsilon=self.params['epsilon'],
            smoothing=self.params['smoothing']
        )

        # 预测
        y_pred = self.rbf(X.reshape(-1, 1))

        # 存储参数
        fit_params = {
            'X_train': X.tolist(),
            'y_train': y.tolist(),
            'kernel': self.params['kernel'],
            'epsilon': self.params['epsilon'],
            'smoothing': self.params['smoothing']
        }

        return MethodResult(
            method_name=self.method_name,
            fit_params=fit_params,
            **metrics,
            metadata={'kernel': self.params['kernel'], 'n_points': len(X)}
        )

    def predict(self, X: np.ndarray, params: Dict[str, Any]) -> np.ndarray:
        """预测"""
        # 重建RBF插值器
        rbf = RBFInterpolator(
            np.array(params['X_train']).reshape(-1, 1),
```

### 2.7 math_rational_pade（有理函数拟合）✨新增

#### 2.7.1 数学公式

有理函数（Padé近似）：

```
f(x) = (a₀ + a₁x + a₂x² + ... + aₘxᵐ) / (b₀ + b₁x + b₂x² + ... + bₙxⁿ)
```

**常用配置**：

- **[2/3]**: m=2, n=3（5个参数）

| `bounds` | tuple | None | 参数边界（避免奇点） |

**集成模式**：模式2（约束优化）

**优势**：

- ✅ 外推性能好于多项式

**约束**：

- 可以施加单调性约束

```python
from scipy.optimize import curve_fit, minimize

class MathRationalPadeMethod(BaseMethod):
    """有理函数拟合方法"""

    method_name = 'math_rational_pade'

    def __init__(self, m: int = 2, n: int = 2, bounds: tuple = None):
        """
        初始化

        Args:
            m: 分子多项式阶数
            n: 分母多项式阶数
            bounds: 参数边界
        """
        super().__init__(m=m, n=n, bounds=bounds)

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        拟合有理函数

        Args:
            X: 流量数组
            y: 扬程/功率/效率数组

        Returns:
            result: 拟合结果
        """
        m, n = self.params['m'], self.params['n']

        # 定义有理函数
        def rational_func(x, *params):
            a = params[:m+1]  # 分子系数
            b = params[m+1:]  # 分母系数
            numerator = sum(a[i] * x**i for i in range(m+1))
            denominator = 1 + sum(b[i] * x**(i+1) for i in range(n))  # b0=1固定
            return numerator / denominator

        # 初始猜测
        p0 = np.ones(m + n + 1)
        p0[0] = np.mean(y)  # a0初始值

        # 拟合
        try:
            popt, pcov = curve_fit(
                rational_func,
                X, y,
                p0=p0,
                maxfev=5000
            )
        except Exception as e:
            raise FitError(f"有理函数拟合失败: {e}")

        # 预测
        y_pred = rational_func(X, *popt)

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        # 存储参数
        fit_params = {
            'a': popt[:m+1].tolist(),  # 分子系数
            'b': [1.0] + popt[m+1:].tolist(),  # 分母系数（b0=1）
            'm': m,
            'n': n
        }

        return MethodResult(
            method_name=self.method_name,
            fit_params=fit_params,
            **metrics,
            metadata={'m': m, 'n': n, 'order': f'[{m}/{n}]'}
        )

    def predict(self, X: np.ndarray, params: Dict[str, Any]) -> np.ndarray:
        """预测"""
        a = np.array(params['a'])
        b = np.array(params['b'])
        m, n = params['m'], params['n']

        numerator = sum(a[i] * X**i for i in range(m+1))
        denominator = sum(b[i] * X**i for i in range(n+1))

        return numerator / denominator
```

### 2.8 math_local_lowess（局部加权回归）✨新增

#### 2.8.1 数学公式

LOWESS（Locally Weighted Scatterplot Smoothing）：

对于每个预测点 x₀，使用邻近数据点进行加权最小二乘拟合：

```
minimize Σ wᵢ(x₀) * (yᵢ - f(xᵢ))²
```

其中权重函数：
```
wᵢ(x₀) = W(|xᵢ - x₀| / d(x₀))
```

**权重函数**（三次权重）：
```
W(u) = (1 - u³)³  if u < 1, else 0
```

#### 2.8.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `frac` | float | 0.3 | 窗口大小（0-1之间，表示使用数据的比例） |
| `it` | int | 3 | 鲁棒迭代次数（处理异常值） |
| `delta` | float | 0.0 | 计算优化参数（加速计算） |

#### 2.8.3 物理约束集成

**集成模式**：模式1（后验验证）

**特点**：
- ✅ 非常鲁棒，对异常值不敏感
- ✅ 自动适应局部特征
- ❌ 不提供解析函数（只能插值）

#### 2.8.4 实现代码

```python
from statsmodels.nonparametric.smoothers_lowess import lowess

class MathLocalLowessMethod(BaseMethod):
    """局部加权回归方法"""

    method_name = 'math_local_lowess'

    def __init__(self, frac: float = 0.3, it: int = 3, delta: float = 0.0):
        """
        初始化

        Args:
            frac: 窗口大小（0-1）
            it: 鲁棒迭代次数
            delta: 计算优化参数
        """
        super().__init__(frac=frac, it=it, delta=delta)

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        拟合LOWESS

        Args:
            X: 流量数组
            y: 扬程/功率/效率数组

        Returns:
            result: 拟合结果
        """
        # 执行LOWESS平滑
        smoothed = lowess(
            y, X,
            frac=self.params['frac'],
            it=self.params['it'],
            delta=self.params['delta'],
            return_sorted=True
        )

        # 提取平滑后的值
        X_smooth = smoothed[:, 0]
        y_smooth = smoothed[:, 1]

        # 插值到原始X点
        from scipy.interpolate import interp1d
        interp_func = interp1d(X_smooth, y_smooth, kind='linear', fill_value='extrapolate')
        y_pred = interp_func(X)

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        # 存储参数
        fit_params = {
            'X_smooth': X_smooth.tolist(),
            'y_smooth': y_smooth.tolist(),
            'frac': self.params['frac'],
            'it': self.params['it']
        }

        return MethodResult(
            method_name=self.method_name,
            fit_params=fit_params,
            **metrics,
            metadata={'frac': self.params['frac'], 'n_points': len(X_smooth)}
        )

    def predict(self, X: np.ndarray, params: Dict[str, Any]) -> np.ndarray:
        """预测"""
        from scipy.interpolate import interp1d
        interp_func = interp1d(
            params['X_smooth'],
            params['y_smooth'],
            kind='linear',
            fill_value='extrapolate'
        )
        return interp_func(X)
```

### 3.1 physics_pump_char（泵特性方程）


#### 3.1.2 参数说明

- dH/dQ < 0（扬程随流量递减）

#### 3.1.4 实现代码

```python
from scipy.optimize import curve_fit

class PhysicsPumpCharMethod(BaseMethod):
    """泵特性方程拟合方法（用于Q-H曲线）"""

    method_name = 'physics_pump_char'

    def __init__(self, H0_initial_guess: float = None, K_initial_guess: float = None):
        super().__init__(H0_initial_guess=H0_initial_guess, K_initial_guess=K_initial_guess)

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        拟合泵特性方程

        Args:
            X: 流量数组
            y: 扬程数组

        Returns:
            result: 拟合结果
        """
        # 自动计算初始猜测
        H0_init = self.params['H0_initial_guess'] if self.params['H0_initial_guess'] else np.max(y)
        K_init = self.params['K_initial_guess'] if self.params['K_initial_guess'] else (H0_init - np.min(y)) / (np.max(X)**2)

        # 定义泵特性方程
        def pump_func(Q, H0, K):
            return H0 - K * Q**2

        # 拟合
        try:
            popt, pcov = curve_fit(
                pump_func,
                X, y,
                p0=[H0_init, K_init],
                bounds=([0, 0], [np.inf, np.inf])  # H0>0, K>0
            )
        except Exception as e:
            raise FitError(f"泵特性方程拟合失败: {e}")

        # 预测
        y_pred = self.predict(X, {'H0': popt[0], 'K': popt[1]})

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        return MethodResult(
            method_name=self.method_name,
            fit_params={'H0': float(popt[0]), 'K': float(popt[1])},
            **metrics,
            metadata={'physical_model': 'H = H0 - K*Q²'}
        )

    def predict(self, X: np.ndarray, params: Dict[str, float]) -> np.ndarray:
        """预测"""
        return params['H0'] - params['K'] * X**2
```

### 3.2 physics_power_eq（功率方程）

#### 3.2.1 物理公式

```
P = ρ * g * Q * H / η
```

其中：
- `ρ`：液体密度（kg/m³），默认1000（水）
- `g`：重力加速度（m/s²），默认9.81
- `Q`：流量（m³/h）
- `H`：扬程（m）
- `η`：效率（0-1）

**物理意义**：能量守恒定律，泵的输入功率等于有效功率除以效率

#### 3.2.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `rho` | float | 1000 | 液体密度（kg/m³） |
| `g` | float | 9.81 | 重力加速度（m/s²） |
| `qh_version` | str | None | Q-H曲线版本号（必需） |
| `qeta_version` | str | None | Q-η曲线版本号（必需） |

#### 3.2.3 物理约束集成

**集成模式**：模式3（物理嵌入）

**特点**：
- ✅ 基于能量守恒定律
- ✅ 天然满足物理约束
- ✅ 依赖Q-H和Q-η曲线

**依赖关系**：
1. 先拟合Q-H曲线
2. 再拟合Q-η曲线
3. 最后拟合Q-P曲线（使用前两个结果）

#### 3.2.4 实现代码

```python
class PhysicsPowerEqMethod(BaseMethod):
    """功率方程拟合方法（用于Q-P曲线）"""

    method_name = 'physics_power_eq'

    def __init__(self, rho: float = 1000, g: float = 9.81, qh_version: str = None, qeta_version: str = None):
        super().__init__(rho=rho, g=g, qh_version=qh_version, qeta_version=qeta_version)

    def fit(self, X: np.ndarray, y: np.ndarray, qh_result: FitResult, qeta_result: FitResult, **kwargs) -> MethodResult:
        """
        拟合功率方程

        Args:
            X: 流量数组
            y: 功率数组
            qh_result: Q-H曲线拟合结果
            qeta_result: Q-η曲线拟合结果

        Returns:
            result: 拟合结果
        """
        # 使用Q-H和Q-η曲线计算功率
        H_pred = qh_result.predict(X)
        eta_pred = qeta_result.predict(X)

        # 计算功率（注意单位转换）
        # Q: m³/h -> m³/s
        # P: W -> kW
        Q_m3s = X / 3600
        P_pred = (self.params['rho'] * self.params['g'] * Q_m3s * H_pred / eta_pred) / 1000

        # 计算指标
        metrics = self._calculate_metrics(y, P_pred)

        return MethodResult(
            method_name=self.method_name,
            fit_params={'rho': self.params['rho'], 'g': self.params['g']},
            **metrics,
            metadata={
                'physical_model': 'P = ρ*g*Q*H/η',
                'qh_version': self.params['qh_version'],
                'qeta_version': self.params['qeta_version']
            }
        )

    def predict(self, X: np.ndarray, params: Dict[str, float], qh_result: FitResult, qeta_result: FitResult) -> np.ndarray:
        """预测"""
        H_pred = qh_result.predict(X)
        eta_pred = qeta_result.predict(X)
        Q_m3s = X / 3600
        return (params['rho'] * params['g'] * Q_m3s * H_pred / eta_pred) / 1000
```

### 4.1 ml_gradient_boost（梯度提升回归）✨新增

#### 4.1.1 算法原理

梯度提升是集成多个弱学习器（决策树），逐步减少残差：

```
F(x) = F₀(x) + Σ γₘ * hₘ(x)
```

其中：
- `F₀(x)`：初始模型
- `hₘ(x)`：第m个弱学习器
- `γₘ`：学习率

#### 4.1.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `n_estimators` | int | 100 | 树的数量 |
| `learning_rate` | float | 0.1 | 学习率 |
| `max_depth` | int | 5 | 树的最大深度 |
| `subsample` | float | 0.8 | 子采样比例 |
| `monotonic_cst` | list | None | 单调性约束（自动设置） |

#### 4.1.3 物理约束集成

**集成模式**：模式1（后验验证）+ 内置单调性约束

**特殊优势**：
- ✅ 支持内置单调性约束（`HistGradientBoostingRegressor`）
- ✅ 根据曲线类型自动设置约束：
  - Q-H: monotonic_cst=[-1]（递减）
  - Q-P: monotonic_cst=[1]（递增）
  - Q-η: monotonic_cst=[0]（无约束）

#### 4.1.4 实现代码

```python
from sklearn.ensemble import HistGradientBoostingRegressor

class MLGradientBoostMethod(BaseMethod):
    """梯度提升回归方法"""

    method_name = 'ml_gradient_boost'

    def __init__(self, n_estimators: int = 100, learning_rate: float = 0.1,
                 max_depth: int = 5, subsample: float = 0.8):
        super().__init__(
            n_estimators=n_estimators,
            learning_rate=learning_rate,
            max_depth=max_depth,
            subsample=subsample
        )

    def fit(self, X: np.ndarray, y: np.ndarray, curve_type: str = None, **kwargs) -> MethodResult:
        """
        拟合梯度提升模型

        Args:
            X: 流量数组
            y: 扬程/功率/效率数组
            curve_type: 曲线类型（用于设置单调性约束）

        Returns:
            result: 拟合结果
        """
        # 根据曲线类型自动设置单调性约束
        if curve_type == 'qh':
            monotonic_cst = [-1]  # Q-H递减
        elif curve_type == 'qp':
            monotonic_cst = [1]   # Q-P递增
        else:  # qeta
            monotonic_cst = [0]   # Q-η无单调性（单峰）

        # 创建模型
        self.model = HistGradientBoostingRegressor(
            max_iter=self.params['n_estimators'],
            learning_rate=self.params['learning_rate'],
            max_depth=self.params['max_depth'],
            monotonic_cst=monotonic_cst,  # 自动应用单调性约束
            random_state=42
        )

        # 拟合
        self.model.fit(X.reshape(-1, 1), y)

        # 预测
        y_pred = self.model.predict(X.reshape(-1, 1))

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        # 存储参数（模型序列化）
        import joblib
        from io import BytesIO
        buffer = BytesIO()
        joblib.dump(self.model, buffer)
        model_bytes = buffer.getvalue()

        fit_params = {
            'model_bytes': model_bytes.hex(),  # 序列化为hex字符串
            'n_estimators': self.params['n_estimators'],
            'monotonic_cst': monotonic_cst
        }

        return MethodResult(
            method_name=self.method_name,
            fit_params=fit_params,
            **metrics,
            metadata={
                'n_estimators': self.params['n_estimators'],
                'monotonic_cst': monotonic_cst,
                'feature_importances': self.model.feature_importances_.tolist()
            }
        )

    def predict(self, X: np.ndarray, params: Dict[str, Any]) -> np.ndarray:
        """预测"""
        import joblib
        from io import BytesIO
        model_bytes = bytes.fromhex(params['model_bytes'])
        buffer = BytesIO(model_bytes)
        model = joblib.load(buffer)
        return model.predict(X.reshape(-1, 1))
```

### 4.3 ml_gaussian_process（高斯过程回归）✨新增

#### 4.3.1 算法原理

高斯过程是贝叶斯非参数方法，提供预测均值和不确定性：

```
f(x) ~ GP(μ(x), k(x, x'))
```

其中：
- `μ(x)`：均值函数
- `k(x, x')`：核函数（协方差函数）

#### 4.3.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `kernel` | str | 'RBF' | 核函数类型（'RBF', 'Matern', 'RationalQuadratic'） |
| `alpha` | float | 1e-10 | 噪声水平 |
| `n_restarts_optimizer` | int | 10 | 超参数优化重启次数 |

#### 4.3.3 物理约束集成

**集成模式**：模式1（后验验证）

**特殊优势**：
- ✅ 提供不确定性量化（置信区间）
- ✅ 贝叶斯框架，理论优雅
- ✅ 可以融合先验知识

#### 4.3.4 实现代码

```python
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import RBF, Matern, RationalQuadratic, ConstantKernel

class MLGaussianProcessMethod(BaseMethod):
    """高斯过程回归方法"""

    method_name = 'ml_gaussian_process'

    def __init__(self, kernel: str = 'RBF', alpha: float = 1e-10, n_restarts_optimizer: int = 10):
        super().__init__(kernel=kernel, alpha=alpha, n_restarts_optimizer=n_restarts_optimizer)

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """拟合高斯过程模型"""
        # 选择核函数
        if self.params['kernel'] == 'RBF':
            kernel = ConstantKernel(1.0) * RBF(length_scale=1.0)
        elif self.params['kernel'] == 'Matern':
            kernel = ConstantKernel(1.0) * Matern(length_scale=1.0, nu=1.5)
        else:  # RationalQuadratic
            kernel = ConstantKernel(1.0) * RationalQuadratic(length_scale=1.0, alpha=1.0)

        # 创建模型
        self.model = GaussianProcessRegressor(
            kernel=kernel,
            alpha=self.params['alpha'],
            n_restarts_optimizer=self.params['n_restarts_optimizer'],
            random_state=42
        )

        # 拟合
        self.model.fit(X.reshape(-1, 1), y)

        # 预测（包含不确定性）
        y_pred, y_std = self.model.predict(X.reshape(-1, 1), return_std=True)

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        # 存储参数
        import joblib
        from io import BytesIO
        buffer = BytesIO()
        joblib.dump(self.model, buffer)
        model_bytes = buffer.getvalue()

        fit_params = {
            'model_bytes': model_bytes.hex(),
            'kernel': self.params['kernel']
        }

        return MethodResult(
            method_name=self.method_name,
            fit_params=fit_params,
            **metrics,
            metadata={
                'kernel': self.params['kernel'],
                'uncertainty_mean': float(np.mean(y_std)),
                'uncertainty_max': float(np.max(y_std))
            }
        )

    def predict(self, X: np.ndarray, params: Dict[str, Any], return_std: bool = False) -> np.ndarray:
        """预测（可选返回不确定性）"""
        import joblib
        from io import BytesIO
        model_bytes = bytes.fromhex(params['model_bytes'])
        buffer = BytesIO(model_bytes)
        model = joblib.load(buffer)

        if return_std:
            return model.predict(X.reshape(-1, 1), return_std=True)
        else:
            return model.predict(X.reshape(-1, 1))
```

## 5. 混合方法（Hybrid）

### 5.1 hybrid_physics_poly（物理信息多项式）✨新增

#### 5.1.1 方法原理

物理信息多项式结合物理模型和数据拟合：

```
H = H_physical + H_residual
```

其中：
- `H_physical = H₀ - K*Q²`（物理模型，来自 physics_pump_char）
- `H_residual = a₁*Q + a₂*Q²`（残差多项式）

#### 5.1.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `residual_degree` | int | 2 | 残差多项式阶数（1或2） |
| `residual_weight` | float | 1.0 | 残差权重 |

#### 5.1.3 物理约束集成

**集成模式**：模式3（物理嵌入）

**工作流程**：
1. 先使用 physics_pump_char 拟合物理模型
2. 计算残差：residual = H_actual - H_physical
3. 用多项式拟合残差
4. 最终预测：H_pred = H_physical + H_residual

**优势**：
- ✅ 结合物理规律和数据拟合
- ✅ 精度高于单纯物理模型
- ✅ 符合物理约束
- ✅ 外推性能好

#### 5.1.4 实现代码

```python
class HybridPhysicsPolyMethod(BaseMethod):
    """物理信息多项式方法"""

    method_name = 'hybrid_physics_poly'

    def __init__(self, residual_degree: int = 2, residual_weight: float = 1.0):
        super().__init__(residual_degree=residual_degree, residual_weight=residual_weight)

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        拟合物理信息多项式

        Args:
            X: 流量数组
            y: 扬程数组

        Returns:
            result: 拟合结果
        """
        # 步骤1：拟合物理模型
        from app.services.characteristic_curves.methods.physics_pump_char import PhysicsPumpCharMethod
        physics_method = PhysicsPumpCharMethod()
        physics_result = physics_method.fit(X, y)

        # 步骤2：计算残差
        y_physical = physics_method.predict(X, physics_result.fit_params)
        residual = y - y_physical

        # 步骤3：拟合残差多项式
        degree = self.params['residual_degree']
        residual_coeffs = np.polyfit(X, residual, degree)

        # 步骤4：预测
        residual_pred = np.polyval(residual_coeffs, X)
        y_pred = y_physical + self.params['residual_weight'] * residual_pred

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        # 存储参数
        fit_params = {
            'H0': physics_result.fit_params['H0'],
            'K': physics_result.fit_params['K'],
            'residual_coeffs': residual_coeffs.tolist(),
            'residual_degree': degree,
            'residual_weight': self.params['residual_weight']
        }

        return MethodResult(
            method_name=self.method_name,
            fit_params=fit_params,
            **metrics,
            metadata={
                'physical_model': 'H = (H0 - K*Q²) + residual_poly',
                'residual_degree': degree,
                'residual_rmse': float(np.sqrt(np.mean(residual**2)))
            }
        )

    def predict(self, X: np.ndarray, params: Dict[str, Any]) -> np.ndarray:
        """预测"""
        # 物理部分
        H_physical = params['H0'] - params['K'] * X**2

        # 残差部分
        residual_pred = np.polyval(params['residual_coeffs'], X)

        # 组合
        return H_physical + params['residual_weight'] * residual_pred
```

#### 7.6.2 评分函数

系统使用以下评分函数选择最优方法：

```python
def calculate_method_score(fit_result):
    """
    计算方法得分（越高越好）

    评分权重：
    - 历史评估通过率：50%
    - R²：30%
    - 物理约束满足度：20%
    """
    score = 0.0

    # 1. 历史评估通过率（权重50%）
    if fit_result.historical_evaluation:
        pass_rate = fit_result.historical_evaluation.pass_rate
        score += 0.5 * pass_rate

    # 2. R²（权重30%）
    score += 0.3 * fit_result.r_squared

    # 3. 物理约束满足度（权重20%）
    if fit_result.validation_result:
        constraint_score = (
            int(fit_result.validation_result.monotonicity_passed) +
            int(fit_result.validation_result.boundary_passed) +
            int(fit_result.validation_result.curvature_passed)
        ) / 3.0
        score += 0.2 * constraint_score

    return score
```
