## 1. 样条方法（4种）

### 方法181：`math_spline_cubic` - 三次样条插值

**数学原理**：
三次样条是一种分段三次多项式插值方法，在每个区间内使用三次多项式，并保证在节点处的连续性和光滑性。

**数学公式**：
```
在区间 [x_i, x_{i+1}] 内：
S_i(x) = a_i + b_i(x-x_i) + c_i(x-x_i)² + d_i(x-x_i)³

约束条件：
1. 插值条件：S_i(x_i) = y_i, S_i(x_{i+1}) = y_{i+1}
2. 一阶导数连续：S'_i(x_{i+1}) = S'_{i+1}(x_{i+1})
3. 二阶导数连续：S''_i(x_{i+1}) = S''_{i+1}(x_{i+1})
4. 边界条件：自然边界（S''(x_0)=S''(x_n)=0）或其他
```

**适用曲线**：所有曲线类型

**预期精度**：R² > 0.95

**优点**：
1. **光滑性好**：二阶导数连续
2. **精确插值**：通过所有数据点
3. **局部性**：修改一个点只影响邻近区域
4. **稳定性**：不会出现龙格现象

**缺点**：
1. **过拟合风险**：对噪声敏感
2. **外推性差**：不适合外推
3. **计算成本**：比多项式高

**代码示例**：
```python
import numpy as np
from scipy.interpolate import CubicSpline, UnivariateSpline
import matplotlib.pyplot as plt

class MathSplineCubic:
    """三次样条插值方法"""
    
    def __init__(self, boundary_condition='natural', smoothing=False, smoothing_factor=None):
        """
        Parameters:
        -----------
        boundary_condition : str
            边界条件：'natural', 'clamped', 'not-a-knot'
        smoothing : bool
            是否使用平滑样条（减少过拟合）
        smoothing_factor : float
            平滑因子（仅当smoothing=True时有效）
        """
        self.boundary_condition = boundary_condition
        self.smoothing = smoothing
        self.smoothing_factor = smoothing_factor
        self.spline = None
    
    def fit(self, X, y):
        """
        拟合三次样条
        
        Parameters:
        -----------
        X : np.ndarray
            自变量，shape=(n_samples, 1)
        y : np.ndarray
            因变量，shape=(n_samples,)
        
        Returns:
        --------
        result : dict
            拟合结果
        """
        # 确保X是一维的
        if X.ndim > 1:
            X = X.flatten()
        
        # 排序（样条要求X单调）
        sort_idx = np.argsort(X)
        X_sorted = X[sort_idx]
        y_sorted = y[sort_idx]
        
        if self.smoothing:
            # 平滑样条（不精确通过所有点，减少过拟合）
            if self.smoothing_factor is None:
                # 自动确定平滑因子
                self.smoothing_factor = len(X)
            
            self.spline = UnivariateSpline(
                X_sorted, y_sorted,
                s=self.smoothing_factor,
                k=3  # 三次样条
            )
        else:
            # 插值样条（精确通过所有点）
            self.spline = CubicSpline(
                X_sorted, y_sorted,
                bc_type=self.boundary_condition
            )
        
        # 预测和评估
        y_pred = self.spline(X)
        r2 = 1 - np.sum((y - y_pred)**2) / np.sum((y - np.mean(y))**2)
        rmse = np.sqrt(np.mean((y - y_pred)**2))
        mae = np.mean(np.abs(y - y_pred))
        
        return {
            'params': {
                'boundary_condition': self.boundary_condition,
                'smoothing': self.smoothing,
                'smoothing_factor': self.smoothing_factor
            },
            'r2': r2,
            'rmse': rmse,
            'mae': mae
        }
    
    def predict(self, X):
        """预测"""
        if X.ndim > 1:
            X = X.flatten()
        return self.spline(X)
    
    def derivative(self, X, order=1):
        """计算导数"""
        if X.ndim > 1:
            X = X.flatten()
        return self.spline(X, nu=order)

# 使用示例
Q = np.linspace(0, 300, 50)
H = 120 - 0.2*Q - 0.001*Q**2 + np.random.normal(0, 2, 50)

# 插值样条（精确通过所有点）
method_interp = MathSplineCubic(boundary_condition='natural', smoothing=False)
result_interp = method_interp.fit(Q.reshape(-1, 1), H)
print(f"插值样条 R² = {result_interp['r2']:.4f}")

# 平滑样条（减少过拟合）
method_smooth = MathSplineCubic(smoothing=True, smoothing_factor=50)
result_smooth = method_smooth.fit(Q.reshape(-1, 1), H)
print(f"平滑样条 R² = {result_smooth['r2']:.4f}")

# 预测和导数
Q_new = np.linspace(0, 300, 200)
H_pred = method_smooth.predict(Q_new.reshape(-1, 1))
dH_dQ = method_smooth.derivative(Q_new.reshape(-1, 1), order=1)

# 可视化
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.scatter(Q, H, label='数据点', alpha=0.6)
plt.plot(Q_new, H_pred, label='平滑样条', linewidth=2)
plt.xlabel('流量 Q (m³/h)')
plt.ylabel('扬程 H (m)')
plt.legend()
plt.grid(True)
plt.title('三次样条拟合')

plt.subplot(1, 2, 2)
plt.plot(Q_new, dH_dQ, label='dH/dQ', linewidth=2)
plt.axhline(y=0, color='r', linestyle='--', alpha=0.5)
plt.xlabel('流量 Q (m³/h)')
plt.ylabel('dH/dQ')
plt.legend()
plt.grid(True)
plt.title('一阶导数（验证单调性）')

plt.tight_layout()
plt.show()
```

**使用场景**：
1. **光滑曲线**：需要光滑的拟合曲线
2. **精确插值**：需要精确通过数据点
3. **导数计算**：需要计算导数
4. **数据质量好**：数据噪声小

## 2. 核方法（3种）

### 方法185-187：核方法（简化说明）

| 编号 | 方法名称 | 核函数 | 精度 | 主要特点 | 适用场景 |
|-----|---------|--------|------|---------|---------|
| 185 | `math_kernel_rbf` | 径向基函数（RBF） | R²>0.95 | 精确插值 | 散点插值 |
| 186 | `math_kernel_gaussian` | 高斯核 | R²>0.94 | 光滑 | 光滑曲线 |
| 187 | `math_kernel_multiquadric` | 多二次核 | R²>0.94 | 鲁棒性好 | 不规则数据 |

**核方法原理**：
```
f(x) = Σ w_i × K(x, x_i)

其中：
- K(x, x_i): 核函数
- w_i: 权重
- x_i: 数据点

常用核函数：
- RBF: K(x, x_i) = exp(-||x - x_i||² / (2σ²))
- 高斯: K(x, x_i) = exp(-γ||x - x_i||²)
- 多二次: K(x, x_i) = sqrt(||x - x_i||² + c²)
```

## 3. 有理函数方法（3种）

### 方法188-190：有理函数方法（简化说明）

| 编号 | 方法名称 | 公式 | 精度 | 主要特点 | 适用场景 |
|-----|---------|------|------|---------|---------|
| 188 | `math_rational_pade` | Padé逼近 | R²>0.96 | 外推性好 | 需要外推 |
| 189 | `math_rational_general` | 一般有理函数 | R²>0.95 | 灵活 | 复杂曲线 |
| 190 | `math_rational_barycentric` | 重心有理插值 | R²>0.95 | 稳定 | 高精度插值 |

**有理函数原理**：
```
f(x) = P(x) / Q(x)

其中：
- P(x) = a_0 + a_1×x + ... + a_m×x^m（分子多项式）
- Q(x) = 1 + b_1×x + ... + b_n×x^n（分母多项式）

优点：
- 可以表示渐近线
- 外推性能好
- 可以用较低阶数达到高精度

缺点：
- 可能存在极点（分母为0）
- 拟合复杂度高
```

## 4. 局部方法（3种）

### 方法191-193：局部方法（简化说明）

| 编号 | 方法名称 | 说明 | 精度 | 主要特点 | 适用场景 |
|-----|---------|------|------|---------|---------|
| 191 | `math_local_lowess` | 局部加权回归 | R²>0.94 | 鲁棒性强 | 有异常值 |
| 192 | `math_local_loess` | 局部多项式回归 | R²>0.94 | 光滑 | 光滑曲线 |
| 193 | `math_local_kernel_regression` | 核回归 | R²>0.93 | 非参数 | 非参数拟合 |

**局部方法原理**：
```
对于预测点 x_0：
1. 选择邻近点：找到 x_0 附近的 k 个点
2. 加权：根据距离分配权重 w_i = K((x_i - x_0) / h)
3. 局部拟合：在邻近点上拟合简单模型（如线性）
4. 预测：使用局部模型预测 f(x_0)

优点：
- 鲁棒性强（对异常值不敏感）
- 自适应（不同区域使用不同模型）
- 无需全局假设

缺点：
- 计算成本高（每个点都要局部拟合）
- 边界效应（边界处精度下降）
```
