## 1. 时间序列方法概述

### 1.1 适用场景

时间序列方法适用于以下特性曲线：
- **运行特性曲线**：流量-时间、扬程-时间、功率-时间
- **负荷预测曲线**：未来流量预测、负荷变化趋势
- **故障诊断曲线**：振动-时间、温度-时间
- **效率衰减曲线**：效率随运行时间的变化

### 1.2 时间序列 vs 静态拟合

| 特性 | 静态拟合 | 时间序列 |
|-----|---------|---------|
| **输入** | (Q, f, ...) | (t, Q_history, ...) |
| **输出** | H, P, η | H_future, Q_future |
| **时间依赖** | 无 | 有 |
| **预测类型** | 插值/外推 | 时间序列预测 |

## 2. 统计时间序列方法（5种）

### 方法94：`timeseries_arima` - ARIMA模型

**模型全称**：AutoRegressive Integrated Moving Average（自回归积分滑动平均模型）

**模型结构**：
```
ARIMA(p, d, q)

其中：
- p: 自回归阶数（AR）
- d: 差分阶数（I）
- q: 滑动平均阶数（MA）
```

**数学公式**：
```
(1 - Σφ_i×L^i) × (1-L)^d × y_t = (1 + Σθ_j×L^j) × ε_t

其中：
- y_t: 时间序列值
- L: 滞后算子（L×y_t = y_{t-1}）
- φ_i: AR系数
- θ_j: MA系数
- ε_t: 白噪声
- d: 差分次数
```

**模型组成**：
1. **AR(p) - 自回归**：y_t = φ_1×y_{t-1} + φ_2×y_{t-2} + ... + φ_p×y_{t-p} + ε_t
2. **I(d) - 差分**：Δy_t = y_t - y_{t-1}（d次差分使序列平稳）
3. **MA(q) - 滑动平均**：y_t = ε_t + θ_1×ε_{t-1} + θ_2×ε_{t-2} + ... + θ_q×ε_{t-q}

**参数选择**：
- **p**: 通过PACF（偏自相关函数）确定
- **d**: 通过ADF检验（平稳性检验）确定
- **q**: 通过ACF（自相关函数）确定

**适用曲线**：
- 流量-时间曲线
- 扬程-时间曲线
- 功率-时间曲线
- 效率-时间曲线

**预期精度**：R² > 0.92（短期预测）

**优点**：
1. **理论成熟**：统计学基础扎实
2. **可解释性强**：参数有明确意义
3. **短期预测好**：1-10步预测精度高
4. **自动选参**：可使用auto_arima自动选择(p,d,q)

**缺点**：
1. **平稳性要求**：需要序列平稳
2. **线性假设**：无法捕捉复杂非线性
3. **长期预测差**：>10步预测精度下降
4. **季节性处理**：需要SARIMA扩展

**代码示例**：
```python
import numpy as np
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.stattools import adfuller, acf, pacf
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import matplotlib.pyplot as plt

class TimeseriesARIMA:
    """ARIMA时间序列拟合方法"""
    
    def __init__(self, order=None, auto_select=True):
        """
        Parameters:
        -----------
        order : tuple
            ARIMA阶数 (p, d, q)
        auto_select : bool
            是否自动选择阶数
        """
        self.order = order
        self.auto_select = auto_select
        self.model = None
        self.fitted_model = None
    
    def _check_stationarity(self, y):
        """检查平稳性（ADF检验）"""
        result = adfuller(y)
        is_stationary = result[1] < 0.05  # p-value < 0.05
        return is_stationary, result[1]
    
    def _determine_d(self, y):
        """确定差分阶数d"""
        d = 0
        y_diff = y.copy()
        
        while d < 3:  # 最多3阶差分
            is_stationary, p_value = self._check_stationarity(y_diff)
            if is_stationary:
                return d
            y_diff = np.diff(y_diff)
            d += 1
        
        return d
    
    def _determine_p_q(self, y, max_lag=20):
        """通过ACF和PACF确定p和q"""
        # 计算ACF和PACF
        acf_values = acf(y, nlags=max_lag)
        pacf_values = pacf(y, nlags=max_lag)
        
        # 找到第一个不显著的滞后（简化方法）
        threshold = 1.96 / np.sqrt(len(y))
        
        q = 0
        for i in range(1, len(acf_values)):
            if abs(acf_values[i]) < threshold:
                q = i - 1
                break
        
        p = 0
        for i in range(1, len(pacf_values)):
            if abs(pacf_values[i]) < threshold:
                p = i - 1
                break
        
        return max(1, p), max(1, q)
    
    def fit(self, y, timestamps=None):
        """
        拟合ARIMA模型
        
        Parameters:
        -----------
        y : np.ndarray
            时间序列数据，shape=(n_samples,)
        timestamps : np.ndarray, optional
            时间戳
        
        Returns:
        --------
        result : dict
            拟合结果
        """
        if self.auto_select:
            # 自动选择(p, d, q)
            d = self._determine_d(y)
            
            # 差分后的序列
            y_diff = y.copy()
            for _ in range(d):
                y_diff = np.diff(y_diff)
            
            p, q = self._determine_p_q(y_diff)
            self.order = (p, d, q)
        
        # 拟合ARIMA模型
        self.model = ARIMA(y, order=self.order)
        self.fitted_model = self.model.fit()
        
        # 预测（拟合值）
        y_pred = self.fitted_model.fittedvalues
        
        # 评估
        # 注意：fittedvalues可能比原始数据短（因为差分）
        y_true = y[-len(y_pred):]
        r2 = 1 - np.sum((y_true - y_pred)**2) / np.sum((y_true - np.mean(y_true))**2)
        rmse = np.sqrt(np.mean((y_true - y_pred)**2))
        mae = np.mean(np.abs(y_true - y_pred))
        
        return {
            'params': {
                'order': self.order,
                'aic': self.fitted_model.aic,
                'bic': self.fitted_model.bic
            },
            'r2': r2,
            'rmse': rmse,
            'mae': mae,
            'model_summary': self.fitted_model.summary()
        }
    
    def forecast(self, steps=10):
        """
        预测未来值
        
        Parameters:
        -----------
        steps : int
            预测步数
        
        Returns:
        --------
        forecast : np.ndarray
            预测值
        confidence_interval : tuple
            置信区间 (lower, upper)
        """
        forecast_result = self.fitted_model.forecast(steps=steps)
        
        # 获取置信区间
        forecast_df = self.fitted_model.get_forecast(steps=steps)
        confidence_interval = forecast_df.conf_int()
        
        return forecast_result, confidence_interval

# 使用示例
# 生成测试数据（带趋势和季节性的时间序列）
np.random.seed(42)
t = np.arange(0, 200)
trend = 0.5 * t
seasonal = 10 * np.sin(2 * np.pi * t / 24)
noise = np.random.normal(0, 2, 200)
y = 100 + trend + seasonal + noise

# 拟合ARIMA
method = TimeseriesARIMA(auto_select=True)
result = method.fit(y)

print(f"自动选择的阶数: {result['params']['order']}")
print(f"R² = {result['r2']:.4f}")
print(f"RMSE = {result['rmse']:.2f}")
print(f"AIC = {result['params']['aic']:.2f}")

# 预测未来10步
forecast, conf_int = method.forecast(steps=10)
print(f"\n未来10步预测:")
for i, (pred, (lower, upper)) in enumerate(zip(forecast, conf_int.values)):
    print(f"步{i+1}: {pred:.2f} [{lower:.2f}, {upper:.2f}]")

# 可视化
plt.figure(figsize=(12, 6))
plt.plot(t, y, label='实际值', alpha=0.7)
plt.plot(t[-len(method.fitted_model.fittedvalues):], 
         method.fitted_model.fittedvalues, 
         label='拟合值', linewidth=2)
plt.legend()
plt.title(f'ARIMA{result["params"]["order"]} 拟合结果')
plt.xlabel('时间')
plt.ylabel('值')
plt.grid(True)
plt.show()
```

**使用场景**：
1. **短期预测**：1-10步预测
2. **平稳序列**：或可通过差分变平稳
3. **线性趋势**：趋势和季节性相对简单
4. **需要置信区间**：提供预测不确定性
