## 1. 概述

### 1.1 设计目标

采用**三表分离设计**存储特性曲线拟合结果，支持：

1. **版本管理**：时间戳版本号，永久保存历史
2. **多方法支持**：存储不同拟合方法的结果
3. **完整评估**：存储拟合参数、评估指标、验证结果
4. **灵活扩展**：使用JSONB字段存储复杂结构
5. **规范化设计**：三表分离，便于查询和维护

### 1.2 三表分离架构

| 表名 | 说明 | 关系 |
|------|------|------|
| `curve_fit_results` | 拟合结果主表 | 主表 |
| `curve_fit_params` | 拟合参数表 | 1:N 关联主表 |
| `curve_fit_metrics` | 拟合指标表 | 1:1 关联主表 |

### 1.3 与现有表的关系

| 现有表 | 关系 | 说明 |
|-------|------|------|
| `pump_characteristic_curves` | 独立 | 现有表结构简单，不适合新需求，保持独立 |
| `fact_measurements` | 数据源 | 拟合数据来源 |
| `device_rated_params` | 参数源 | 物理约束参数来源 |
| `dim_devices` | 外键 | device_id关联 |

### 2.4 视图设计

```sql
-- 最新版本视图
CREATE OR REPLACE VIEW curve_fit_latest AS
WITH ranked AS (
    SELECT r.*, m.r_squared, m.rmse, m.mae, m.mape,
        ROW_NUMBER() OVER (PARTITION BY r.device_id, r.curve_type ORDER BY r.created_at DESC) as rn
    FROM curve_fit_results r
    LEFT JOIN curve_fit_metrics m ON r.id = m.result_id
    WHERE r.status = 'active'
)
SELECT id, device_id, curve_type, version, method_name,
    r_squared, rmse, mae, mape,
    physics_validation, historical_evaluation,
    normalization_params, created_at, status
FROM ranked WHERE rn = 1;

-- 完整拟合结果视图
CREATE OR REPLACE VIEW v_curve_fit_full AS
SELECT
    r.*, m.r_squared, m.rmse, m.mae, m.mape,
    (SELECT jsonb_object_agg(p.param_key, p.param_value)
     FROM curve_fit_params p WHERE p.result_id = r.id AND p.param_category = 'fit') AS fit_params,
    (SELECT jsonb_object_agg(p.param_key, COALESCE(p.param_value::text, p.param_text))
     FROM curve_fit_params p WHERE p.result_id = r.id AND p.param_category = 'method') AS method_params
FROM curve_fit_results r
LEFT JOIN curve_fit_metrics m ON r.id = m.result_id;
```

**data_coverage_rate计算公式**：

```python
# 覆盖率 = 实际流量范围 / 额定流量范围
Q_min_actual = data['Q'].min()
Q_max_actual = data['Q'].max()
Q_rated = device_params['rated_flow_rate']

coverage_rate = (Q_max_actual - Q_min_actual) / (1.2 * Q_rated)
# 理想情况：覆盖0-120%额定流量，coverage_rate = 1.0
```

### 4.2 索引使用场景

**场景1：查询设备的最新Q-H曲线（使用视图）**
```sql
SELECT * FROM curve_fit_latest
WHERE device_id = 1 AND curve_type = 'qh';
-- 视图内部使用：idx_results_device_curve, idx_results_created_at
```

**场景2：查询设备的所有历史版本（使用完整视图）**
```sql
SELECT version, method_name, r_squared, created_at
FROM v_curve_fit_full
WHERE device_id = 1 AND curve_type = 'qh'
ORDER BY version DESC;
-- 使用索引：idx_results_device_curve
```

**场景3：查询特定版本的曲线**
```sql
SELECT * FROM v_curve_fit_full
WHERE device_id = 1 AND curve_type = 'qh' AND version = '20250125_143022';
-- 使用索引：uq_results_device_curve_version
```

**场景4：对比不同方法的拟合效果**
```sql
SELECT method_name, AVG(r_squared) as avg_r2, COUNT(*) as count
FROM v_curve_fit_full
WHERE curve_type = 'qh' AND status = 'active'
GROUP BY method_name
ORDER BY avg_r2 DESC;
-- 使用索引：idx_results_method, idx_results_status
```

## 5. JSONB字段结构

### 5.1 method_params（方法参数）

**用途**：存储拟合方法的配置参数

**结构定义**：

```typescript
interface MethodParams {
  // 多项式方法
  degree?: number;                      // 多项式次数（2或3）
  regularization?: 'l1' | 'l2' | null;  // 正则化类型
  lambda?: number;                      // 正则化系数

  // 物理模型

  max_depth?: number;                   // 最大深度
  learning_rate?: number;               // 学习率

  // 深度学习
  hidden_layers?: number[];             // 隐藏层结构
  epochs?: number;                      // 训练轮数
  batch_size?: number;                  // 批大小
}
```

## 7. 查询示例

> **说明**：三表分离设计推荐使用视图进行查询，简化JOIN操作。

### 7.1 基础查询（使用视图）

**查询1：获取设备的最新活跃曲线**

```sql
SELECT curve_type, version, method_name, r_squared, created_at
FROM curve_fit_latest
WHERE device_id = 1;
```

**查询2：获取特定版本的完整信息（含参数）**

```sql
SELECT *
FROM v_curve_fit_full
WHERE device_id = 1 AND curve_type = 'qh' AND version = '20250125_143022';
```

**查询3：列出设备的所有历史版本**

```sql
SELECT version, method_name, r_squared, data_point_count, status, created_at
FROM v_curve_fit_full
WHERE device_id = 1 AND curve_type = 'qh'
ORDER BY version DESC;
```

### 7.2 参数查询

**查询4：查询R²>0.95的高质量拟合**

```sql
SELECT device_id, curve_type, version, method_name, r_squared
FROM v_curve_fit_full
WHERE r_squared > 0.95 AND status = 'active'
ORDER BY r_squared DESC;
```

**查询5：提取拟合参数（从参数表）**

```sql
SELECT r.device_id, r.curve_type, r.version,
    p.param_key, p.param_value
FROM curve_fit_results r
JOIN curve_fit_params p ON r.id = p.result_id
WHERE r.method_name = 'polynomial_2' AND p.param_category = 'fit'
ORDER BY r.device_id, p.param_key;
```

**查询6：查询物理约束验证失败的记录**

```sql
SELECT device_id, curve_type, version, method_name,
    physics_validation->'overall_passed' AS passed,
    physics_validation->'warnings' AS warnings
FROM curve_fit_results
WHERE (physics_validation->>'overall_passed')::boolean = false;
```

### 7.3 统计查询

**查询7：统计各方法的平均R²**

```sql
SELECT method_name, COUNT(*) AS count,
    AVG(r_squared) AS avg_r2, MIN(r_squared) AS min_r2, MAX(r_squared) AS max_r2
FROM v_curve_fit_full
WHERE status = 'active'
GROUP BY method_name
ORDER BY avg_r2 DESC;
```

**查询8：统计各曲线类型的拟合数量**

```sql
SELECT curve_type, COUNT(*) AS total_count,
    COUNT(CASE WHEN status = 'active' THEN 1 END) AS active_count
FROM curve_fit_results
GROUP BY curve_type;
```

### 7.4 版本对比查询

**查询9：查找R²提升最大的版本更新**

```sql
WITH ranked_versions AS (
    SELECT device_id, curve_type, version, r_squared,
        LAG(r_squared) OVER (PARTITION BY device_id, curve_type ORDER BY created_at) AS prev_r2,
        created_at
    FROM v_curve_fit_full
)
SELECT device_id, curve_type, version, r_squared, prev_r2,
    (r_squared - prev_r2) AS improvement
FROM ranked_versions
WHERE prev_r2 IS NOT NULL
ORDER BY improvement DESC
LIMIT 10;
```

## 8. 数据迁移

### 8.1 迁移脚本（三表分离）

**文件路径**：`migrations/create_curve_fit_tables.sql`

```sql
-- ============================================================
-- 迁移脚本：创建曲线拟合三表分离结构
-- 版本：v3.0
-- 创建日期：2025-01-28
-- 说明：curve_fit_results + curve_fit_params + curve_fit_metrics
-- ============================================================

BEGIN;

-- 1. 创建主表
CREATE TABLE IF NOT EXISTS curve_fit_results (
    id SERIAL PRIMARY KEY,
    device_id INTEGER NOT NULL,
    curve_type VARCHAR(50) NOT NULL,
    version VARCHAR(50) NOT NULL,
    method_name VARCHAR(100) NOT NULL,
    data_start_time TIMESTAMP WITH TIME ZONE,
    data_end_time TIMESTAMP WITH TIME ZONE,
    data_point_count INTEGER,
    data_coverage_rate DOUBLE PRECISION,
    physics_validation JSONB,
    historical_evaluation JSONB,
    normalization_params JSONB,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    created_by VARCHAR(100),
    status VARCHAR(20) DEFAULT 'active',
    tags TEXT[],
    notes TEXT,
    CONSTRAINT uq_results_device_curve_version UNIQUE(device_id, curve_type, version),
    CONSTRAINT chk_results_curve_type CHECK (curve_type IN ('qh', 'qp', 'qeta', 'heta', 'peta', 'qnpsh')),
    CONSTRAINT chk_results_status CHECK (status IN ('active', 'archived', 'deprecated'))
);

-- 2. 创建参数表
CREATE TABLE IF NOT EXISTS curve_fit_params (
    id SERIAL PRIMARY KEY,
    result_id INTEGER NOT NULL,
    param_category VARCHAR(50) NOT NULL,
    param_key VARCHAR(100) NOT NULL,
    param_value DOUBLE PRECISION,
    param_text TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    CONSTRAINT fk_params_result_id FOREIGN KEY (result_id) REFERENCES curve_fit_results(id) ON DELETE CASCADE,
    CONSTRAINT uq_params_result_category_key UNIQUE(result_id, param_category, param_key),
    CONSTRAINT chk_params_category CHECK (param_category IN ('fit', 'method'))
);

-- 3. 创建指标表
CREATE TABLE IF NOT EXISTS curve_fit_metrics (
    id SERIAL PRIMARY KEY,
    result_id INTEGER NOT NULL UNIQUE,
    r_squared DOUBLE PRECISION,
    rmse DOUBLE PRECISION,
    mae DOUBLE PRECISION,
    mape DOUBLE PRECISION,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    CONSTRAINT fk_metrics_result_id FOREIGN KEY (result_id) REFERENCES curve_fit_results(id) ON DELETE CASCADE,
    CONSTRAINT chk_metrics_r_squared CHECK (r_squared IS NULL OR (r_squared >= 0 AND r_squared <= 1))
);

-- 4. 创建索引
CREATE INDEX IF NOT EXISTS idx_results_device_curve ON curve_fit_results(device_id, curve_type);
CREATE INDEX IF NOT EXISTS idx_results_version ON curve_fit_results(version);
CREATE INDEX IF NOT EXISTS idx_results_created_at ON curve_fit_results(created_at DESC);
CREATE INDEX IF NOT EXISTS idx_results_status ON curve_fit_results(status);
CREATE INDEX IF NOT EXISTS idx_results_method ON curve_fit_results(method_name);
CREATE INDEX IF NOT EXISTS idx_params_result_id ON curve_fit_params(result_id);
CREATE INDEX IF NOT EXISTS idx_params_category ON curve_fit_params(param_category);
CREATE INDEX IF NOT EXISTS idx_metrics_result_id ON curve_fit_metrics(result_id);
CREATE INDEX IF NOT EXISTS idx_metrics_r_squared ON curve_fit_metrics(r_squared DESC);

-- 5. 创建视图
CREATE OR REPLACE VIEW curve_fit_latest AS
WITH ranked AS (
    SELECT r.*, m.r_squared, m.rmse, m.mae, m.mape,
        ROW_NUMBER() OVER (PARTITION BY r.device_id, r.curve_type ORDER BY r.created_at DESC) as rn
    FROM curve_fit_results r
    LEFT JOIN curve_fit_metrics m ON r.id = m.result_id
    WHERE r.status = 'active'
)
SELECT id, device_id, curve_type, version, method_name,
    r_squared, rmse, mae, mape, created_at, status
FROM ranked WHERE rn = 1;

CREATE OR REPLACE VIEW v_curve_fit_full AS
SELECT r.*, m.r_squared, m.rmse, m.mae, m.mape,
    (SELECT jsonb_object_agg(p.param_key, p.param_value)
     FROM curve_fit_params p WHERE p.result_id = r.id AND p.param_category = 'fit') AS fit_params,
    (SELECT jsonb_object_agg(p.param_key, COALESCE(p.param_value::text, p.param_text))
     FROM curve_fit_params p WHERE p.result_id = r.id AND p.param_category = 'method') AS method_params
FROM curve_fit_results r
LEFT JOIN curve_fit_metrics m ON r.id = m.result_id;

-- 6. 添加注释
COMMENT ON TABLE curve_fit_results IS '曲线拟合结果主表（三表分离设计）';
COMMENT ON TABLE curve_fit_params IS '曲线拟合参数表';
COMMENT ON TABLE curve_fit_metrics IS '曲线拟合指标表';

COMMIT;
```

## 9. 性能优化建议

### 9.1 查询优化

1. **使用复合索引**：查询`device_id + curve_type`时使用`idx_curve_fits_device_curve`
2. **避免全表扫描**：始终在WHERE子句中包含索引字段
3. **JSONB索引**：如果频繁查询JSONB字段，考虑创建GIN索引

```sql
-- 为JSONB字段创建GIN索引（可选）
CREATE INDEX idx_curve_fits_fit_params_gin ON characteristic_curve_fits USING GIN (fit_params);
CREATE INDEX idx_curve_fits_physics_validation_gin ON characteristic_curve_fits USING GIN (physics_validation);
```

### 9.2 存储优化

1. **定期归档**：将旧版本状态改为`archived`
2. **分区表**：如果数据量巨大（>100万行），考虑按`device_id`或`created_at`分区
3. **VACUUM**：定期执行`VACUUM ANALYZE characteristic_curve_fits`

### 9.3 数据清理策略

```sql
-- 归档6个月前的非活跃版本
UPDATE characteristic_curve_fits
SET status = 'archived'
WHERE status = 'active'
  AND created_at < NOW() - INTERVAL '6 months'
  AND (device_id, curve_type, version) NOT IN (
      SELECT device_id, curve_type, version
      FROM characteristic_curve_fits
      WHERE status = 'active'
      ORDER BY created_at DESC
      LIMIT 1
  );
```
