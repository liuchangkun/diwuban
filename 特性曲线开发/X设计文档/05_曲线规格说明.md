## 1. 概述

### 1.1 三条核心曲线

| 曲线类型 | 英文名称 | 物理意义 | 单位 |
|---------|---------|---------|------|
| **Q-H** | Flow-Head Curve | 流量与扬程的关系 | Q: m³/h, H: m |
| **Q-P** | Flow-Power Curve | 流量与功率的关系 | Q: m³/h, P: kW |
| **Q-η** | Flow-Efficiency Curve | 流量与效率的关系 | Q: m³/h, η: % |

### 1.2 曲线特性对比

| 特性 | Q-H | Q-P | Q-η |
|-----|-----|-----|-----|
| **单调性** | 递减 | 递增 | 单峰 |
| **物理约束** | H₀>0, dH/dQ<0 | P₀>0, dP/dQ>0 | 0<η<1, 单峰 |
| **推荐方法** | pump_characteristic | power_equation | gaussian |
| **预期R²** | >0.95 | >0.93 | >0.90 |
| **数据要求** | 100-1000点 | 100-1000点 | 100-1000点 |

## 2. Q-H曲线（流量-扬程）

### 2.1 物理定义

**扬程（H）**：泵对单位重量液体所做的功，单位：米（m）

**物理公式**：
```
H = (P_out - P_in) / (ρ * g) + (v_out² - v_in²) / (2 * g) + (z_out - z_in)
```

简化为：
```
H = H_static + H_dynamic
```

### 2.2 曲线特性

#### 2.2.1 典型形状

```
H (m)
│
50 ├─────╮
   │      ╲
40 │       ╲
   │        ╲
30 │         ╲
   │          ╲
20 │           ╲
   │            ╲
10 │             ╲___
   │
0  └─────────────────────> Q (m³/h)
   0   100  200  300  400
```

**特点**：
- 单调递减（dH/dQ < 0）
- Q=0时，H=H₀（零流量扬程）
- 凸函数（d²H/dQ² > 0）

#### 2.2.2 物理约束

| 约束类型 | 约束条件 | 物理意义 | 自动计算 |
|---------|---------|---------|---------|
| **单调性** | dH/dQ < 0 | 流量增加，扬程下降 | ✅ |
| **边界条件** | Q=0 → H=H₀ | 零流量扬程 | ✅ |
| **边界条件** | Q=Q_max → H>0 | 最大流量时扬程仍为正 | ✅ |
| **曲率** | d²H/dQ² > 0 | 凸函数 | ✅ |
| **H₀范围** | 0.8*H_rated < H₀ < 1.2*H_rated | H₀接近额定扬程 | ✅ |

#### 2.2.3 约束参数计算

**H₀（零流量扬程）**：
```python
# 方法1：使用Q=0附近的数据外推
data_near_zero = data[data['Q'] < 0.1 * Q_rated]
H0 = data_near_zero['H'].max()

# 方法2：使用额定参数估算
H0 = H_rated * 1.1  # 通常比额定扬程高10%

# 方法3：使用拟合结果
# 如果使用polynomial_2: H = a0 + a1*Q + a2*Q²
# 则 H0 = a0
```

**Q_max（最大流量）**：
```python
# 方法1：使用额定流量
Q_max = Q_rated * 1.2  # 通常为额定流量的120%

# 方法2：使用数据范围
Q_max = data['Q'].quantile(0.95)  # 95分位数
```

**K（阻力系数）**：
```python
# 对于泵特性方程 H = H0 - K*Q²
# K可以从两点计算
K = (H0 - H_rated) / (Q_rated ** 2)
```

### 2.3 数据提取

#### 2.3.1 数据源

**表**：`fact_measurements`

**指标**：
- `pump_flow_rate`（流量，m³/h）
- `pump_head`（扬程，m）

**SQL查询**：
```sql
SELECT 
    ts_bucket,
    MAX(CASE WHEN metric_id = (SELECT id FROM dim_metric_config WHERE metric_name = 'pump_flow_rate') THEN value END) AS Q,
    MAX(CASE WHEN metric_id = (SELECT id FROM dim_metric_config WHERE metric_name = 'pump_head') THEN value END) AS H
FROM fact_measurements
WHERE device_id = :device_id
  AND ts_bucket BETWEEN :start_time AND :end_time
  AND metric_id IN (
      SELECT id FROM dim_metric_config WHERE metric_name IN ('pump_flow_rate', 'pump_head')
  )
GROUP BY ts_bucket
HAVING MAX(CASE WHEN metric_id = (SELECT id FROM dim_metric_config WHERE metric_name = 'pump_flow_rate') THEN value END) IS NOT NULL
   AND MAX(CASE WHEN metric_id = (SELECT id FROM dim_metric_config WHERE metric_name = 'pump_head') THEN value END) IS NOT NULL
ORDER BY ts_bucket;
```

#### 2.3.2 数据清洗

**删除无效值**：
```python
# 删除Q<0或H<0的数据
data = data[(data['Q'] >= 0) & (data['H'] >= 0)]

# 删除异常值（3σ原则）
Q_mean, Q_std = data['Q'].mean(), data['Q'].std()
H_mean, H_std = data['H'].mean(), data['H'].std()
data = data[
    (data['Q'] >= Q_mean - 3*Q_std) & (data['Q'] <= Q_mean + 3*Q_std) &
    (data['H'] >= H_mean - 3*H_std) & (data['H'] <= H_mean + 3*H_std)
]

# 删除重复值
data = data.drop_duplicates(subset=['Q', 'H'])
```

### 2.4 推荐拟合方法

| 方法 | 优先级 | 预期R² | 说明 |
|-----|-------|-------|------|
| **pump_characteristic** | 1 | 0.95-0.98 | 物理模型，首选 |
| **polynomial_2** | 2 | 0.90-0.95 | 快速、简单 |
| **polynomial_3** | 3 | 0.92-0.96 | 更灵活 |
| **xgboost** | 4 | 0.95-0.98 | 高精度（后期） |

### 2.5 验证标准

| 指标 | 优秀 | 良好 | 一般 | 不合格 |
|-----|------|------|------|-------|
| **R²** | >0.95 | 0.90-0.95 | 0.85-0.90 | <0.85 |
| **RMSE** | <2m | 2-5m | 5-10m | >10m |
| **单调性** | 100%满足 | >95%满足 | >90%满足 | <90%满足 |
| **边界条件** | 偏差<2% | 偏差<5% | 偏差<10% | 偏差>10% |

## 3. Q-P曲线（流量-功率）

### 3.1 物理定义

**功率（P）**：泵的输入功率，单位：千瓦（kW）

**物理公式**：
```
P = ρ * g * Q * H / η
```

其中：
- ρ = 1000 kg/m³（水的密度）
- g = 9.81 m/s²（重力加速度）
- Q：流量（m³/s，注意单位转换）
- H：扬程（m）
- η：效率（0-1）

### 3.2 曲线特性

#### 3.2.1 典型形状

```
P (kW)
│
80 │              ╭────
   │            ╱
60 │          ╱
   │        ╱
40 │      ╱
   │    ╱
20 │  ╱
   │╱
0  └─────────────────────> Q (m³/h)
   0   100  200  300  400
```

**特点**：
- 单调递增（dP/dQ > 0）
- Q=0时，P=P₀（空载功率，通常为额定功率的10-20%）
- 近似线性或二次函数

#### 3.2.2 物理约束

| 约束类型 | 约束条件 | 物理意义 | 自动计算 |
|---------|---------|---------|---------|
| **单调性** | dP/dQ > 0 | 流量增加，功率增加 | ✅ |
| **边界条件** | Q=0 → P=P₀ | 空载功率 | ✅ |
| **能量守恒** | P = ρgQH/η | 功率方程 | ✅ |
| **P₀范围** | 0.1*P_rated < P₀ < 0.3*P_rated | 空载功率为额定功率的10-30% | ✅ |

#### 3.2.3 约束参数计算

**P₀（空载功率）**：
```python
# 方法1：使用Q=0附近的数据
data_near_zero = data[data['Q'] < 0.1 * Q_rated]
P0 = data_near_zero['P'].min()

# 方法2：使用额定参数估算
P0 = P_rated * 0.15  # 通常为额定功率的15%
```

**能量守恒验证**：
```python
# 计算理论功率
P_theory = (rho * g * Q * H / eta) / 1000  # kW

# 计算偏差
deviation = abs(P_measured - P_theory) / P_measured * 100  # %

# 验证标准：偏差<5%
assert deviation.mean() < 5.0, "能量守恒验证失败"
```

### 3.3 数据提取

**指标**：
- `pump_flow_rate`（流量，m³/h）
- `pump_power`（功率，kW）

**SQL查询**：类似Q-H曲线，替换metric_name

### 3.4 推荐拟合方法

| 方法 | 优先级 | 预期R² | 说明 |
|-----|-------|-------|------|
| **power_equation** | 1 | 0.93-0.96 | 物理模型，首选 |
| **polynomial_2** | 2 | 0.88-0.93 | 快速、简单 |
| **polynomial_3** | 3 | 0.90-0.94 | 更灵活 |

### 3.5 验证标准

| 指标 | 优秀 | 良好 | 一般 | 不合格 |
|-----|------|------|------|-------|
| **R²** | >0.93 | 0.88-0.93 | 0.83-0.88 | <0.83 |
| **RMSE** | <3kW | 3-8kW | 8-15kW | >15kW |
| **单调性** | 100%满足 | >95%满足 | >90%满足 | <90%满足 |

## 4. Q-η曲线（流量-效率）

### 4.1 物理定义

**效率（η）**：泵的有效功率与输入功率的比值，无量纲（0-1或0-100%）

**物理公式**：
```
η = (ρ * g * Q * H) / P
```

### 4.2 曲线特性

#### 4.2.1 典型形状

```
η (%)
│
85 │       ╭───╮
   │      ╱     ╲
75 │     ╱       ╲
   │    ╱         ╲
65 │   ╱           ╲
   │  ╱             ╲
55 │ ╱               ╲
   │╱                 ╲
45 └─────────────────────> Q (m³/h)
   0   100  200  300  400
        ↑
       BEP
```

**特点**：
- 单峰特性（有且仅有一个最大值）
- 最大值点称为BEP（Best Efficiency Point，最佳效率点）
- Q=0时，η=0
- 高斯函数拟合效果好

#### 4.2.2 物理约束

| 约束类型 | 约束条件 | 物理意义 | 自动计算 |
|---------|---------|---------|---------|
| **单峰性** | 有且仅有一个最大值 | BEP点唯一 | ✅ |
| **边界条件** | Q=0 → η=0 | 零流量效率为0 | ✅ |
| **边界条件** | Q→∞ → η→0 | 极大流量效率趋于0 | ✅ |
| **效率范围** | 0 < η < 1 | 效率在0-100%之间 | ✅ |
| **BEP范围** | 0.6*Q_rated < Q_BEP < 1.2*Q_rated | BEP点在额定流量附近 | ✅ |

#### 4.2.3 约束参数计算

**BEP点（最佳效率点）**：
```python
# 方法1：直接从数据找
idx_max = data['eta'].idxmax()
Q_BEP = data.loc[idx_max, 'Q']
eta_BEP = data.loc[idx_max, 'eta']

# 方法2：使用高斯拟合结果
# 高斯函数：η = a * exp(-((Q - mu)² / (2 * sigma²)))
# BEP点：Q_BEP = mu, eta_BEP = a
```

**效率范围验证**：
```python
# 验证效率在0-1之间
assert data['eta'].min() >= 0, "效率不能为负"
assert data['eta'].max() <= 1.0, "效率不能超过100%"

# 验证BEP点在合理范围
assert 0.6 * Q_rated < Q_BEP < 1.2 * Q_rated, "BEP点不在合理范围"
```

### 4.3 数据提取

**指标**：
- `pump_flow_rate`（流量，m³/h）
- `pump_efficiency`（效率，0-1或0-100）

**注意**：效率单位可能是0-1或0-100，需要统一

```python
# 统一为0-1
if data['eta'].max() > 1.5:
    data['eta'] = data['eta'] / 100
```

### 4.4 推荐拟合方法

| 方法 | 优先级 | 预期R² | 说明 |
|-----|-------|-------|------|
| **gaussian** | 1 | 0.90-0.95 | 单峰特性，首选 |
| **polynomial_2** | 2 | 0.75-0.85 | 不推荐（无法保证单峰） |
| **polynomial_3** | 3 | 0.80-0.90 | 可能有多个峰值 |

### 4.5 验证标准

| 指标 | 优秀 | 良好 | 一般 | 不合格 |
|-----|------|------|------|-------|
| **R²** | >0.90 | 0.85-0.90 | 0.80-0.85 | <0.80 |
| **RMSE** | <0.03 | 0.03-0.05 | 0.05-0.08 | >0.08 |
| **单峰性** | 有且仅有1个峰 | 1个主峰 | 多个峰 | 无峰 |
| **BEP位置** | 0.8-1.0*Q_rated | 0.6-1.2*Q_rated | 0.4-1.4*Q_rated | 其他 |

## 5. 数据要求

### 5.1 数据量要求

| 数据量 | 质量评级 | 适用方法 | 说明 |
|-------|---------|---------|------|
| <100点 | 差 | polynomial_2 | 数据不足，拟合不可靠 |
| 100-500点 | 一般 | polynomial_2, pump_characteristic | 基本满足 |
| 500-1000点 | 良好 | 所有数学方法和物理模型 | 推荐 |
| 1000-5000点 | 优秀 | 所有方法 | 可尝试机器学习 |
| >5000点 | 极好 | 所有方法 | 可尝试深度学习 |

### 5.2 时间跨度要求

| 时间跨度 | 质量评级 | 说明 |
|---------|---------|------|
| <1天 | 差 | 工况覆盖不足 |
| 1-7天 | 一般 | 基本覆盖 |
| 7-30天 | 良好 | 推荐 |
| 1-3个月 | 优秀 | 覆盖多种工况 |
| >3个月 | 极好 | 覆盖全年工况 |

### 5.3 流量覆盖率要求

**定义**：
```
覆盖率 = (Q_max_actual - Q_min_actual) / (1.2 * Q_rated)
```

| 覆盖率 | 质量评级 | 说明 |
|-------|---------|------|
| <40% | 差 | 覆盖不足 |
| 40-60% | 一般 | 基本覆盖 |
| 60-80% | 良好 | 推荐 |
| 80-100% | 优秀 | 覆盖充分 |
| >100% | 极好 | 覆盖超额定范围 |

### 5.4 数据质量要求

| 质量指标 | 要求 | 说明 |
|---------|------|------|
| **缺失率** | <5% | 缺失数据占比 |
| **异常值率** | <2% | 异常值占比（3σ原则） |
| **重复率** | <1% | 完全重复的数据点 |
| **噪声水平** | RMSE<10% | 数据波动程度 |

### 6.2 物理约束验证标准

#### 6.2.1 单调性验证

**Q-H曲线**：
```python
# 计算导数
dH_dQ = np.gradient(H_pred, Q)

# 验证递减
monotonicity_passed = np.all(dH_dQ < 0)
violation_rate = np.sum(dH_dQ >= 0) / len(dH_dQ)

# 标准：violation_rate < 5%
```

**Q-P曲线**：
```python
# 验证递增
dP_dQ = np.gradient(P_pred, Q)
monotonicity_passed = np.all(dP_dQ > 0)
```

#### 6.2.2 边界条件验证

**Q-H曲线**：
```python
# Q=0时的扬程
H_at_Q0 = predict(Q=0, params)

# 验证偏差
deviation = abs(H_at_Q0 - H0) / H0 * 100

# 标准：deviation < 5%
```
