## 2.1 单调递减曲线方法（15种）

### 方法1：`math_quadratic_decay` - 二次衰减

**数学公式**：
```
H = H0 - a×Q - b×Q²
```

**参数说明**：
- `H0`: 零流量扬程（关死点扬程），单位：m
- `a`: 一次项系数（线性衰减系数），单位：m/(m³/h)
- `b`: 二次项系数（二次衰减系数），单位：m/(m³/h)²

**物理意义**：
- `H0`: 泵的理论最大扬程，反映泵的设计能力
- `a×Q`: 线性水力损失，主要来自流道摩擦
- `b×Q²`: 二次水力损失，主要来自湍流和涡流

**适用曲线**：Q-H曲线（流量-扬程）

**预期精度**：R² > 0.95

**优点**：
1. 简单、快速，计算效率高
2. 符合泵的基本特性规律
3. 参数物理意义明确，易于解释
4. 拟合稳定，不易过拟合

**缺点**：
1. 可能无法捕捉复杂的非线性特性
2. 对驼峰型曲线拟合不佳
3. 外推能力有限

**物理约束集成**：
- **模式1（后验验证）**：拟合后验证 H0 > 0, a > 0, b > 0
- **模式2（约束优化）**：在优化过程中强制 H0 > 0, a > 0, b > 0
- **边界条件**：Q=0时H=H0，Q→∞时H→-∞（需要限制Q的范围）

**代码示例**（Python）：
```python
import numpy as np
from scipy.optimize import curve_fit

def math_quadratic_decay(Q, H0, a, b):
    """
    二次衰减模型
    
    Parameters:
    -----------
    Q : array-like
        流量，单位：m³/h
    H0 : float
        零流量扬程，单位：m
    a : float
        一次项系数
    b : float
        二次项系数
    
    Returns:
    --------
    H : array-like
        扬程，单位：m
    """
    return H0 - a * Q - b * Q**2

# 拟合示例
Q_data = np.array([0, 50, 100, 150, 200, 250, 300])  # m³/h
H_data = np.array([120, 115, 105, 90, 70, 45, 15])   # m

# 方法1：无约束拟合
params, covariance = curve_fit(math_quadratic_decay, Q_data, H_data)
H0, a, b = params

# 方法2：有约束拟合（推荐）
params, covariance = curve_fit(
    math_quadratic_decay, 
    Q_data, 
    H_data,
    bounds=([0, 0, 0], [np.inf, np.inf, np.inf])  # H0>0, a>0, b>0
)
H0, a, b = params

# 预测
Q_pred = np.linspace(0, 300, 100)
H_pred = math_quadratic_decay(Q_pred, H0, a, b)

# 计算R²
from sklearn.metrics import r2_score
H_fit = math_quadratic_decay(Q_data, H0, a, b)
r2 = r2_score(H_data, H_fit)
print(f"R² = {r2:.4f}")
```

**使用场景**：
1. **快速拟合**：数据量较少（50-200点），需要快速得到结果
2. **初步分析**：作为第一步分析，了解曲线基本特征
3. **实时计算**：需要在线计算，对速度要求高
4. **物理可解释性**：需要向非技术人员解释结果

**注意事项**：
1. 确保数据覆盖全流量范围（0到最大流量）
2. 对驼峰型曲线（中间有凸起）需要使用三次或更高阶方法
3. 外推时要谨慎，不要超出数据范围太多
4. 如果拟合结果出现负值，需要检查数据质量或使用其他方法

### 方法2：`math_cubic_decay` - 三次衰减

**数学公式**：
```
H = H0 - a×Q - b×Q² - c×Q³
```

**参数说明**：
- `H0`: 零流量扬程，单位：m
- `a`: 一次项系数
- `b`: 二次项系数
- `c`: 三次项系数

**物理意义**：
- 三次项可以捕捉更复杂的非线性特性
- 适合驼峰型曲线（中间有凸起的曲线）
- c>0: 扬程下降加速；c<0: 扬程下降减速（驼峰型）

**适用曲线**：Q-H曲线（特别是驼峰型）

**预期精度**：R² > 0.97

**优点**：
1. 更高精度，可以拟合驼峰型曲线
2. 灵活性强，适应性好
3. 仍然保持较好的计算效率

**缺点**：
1. 可能过拟合（数据量少时）
2. 参数物理意义不如二次明确
3. 外推性较差

**物理约束集成**：
- **模式1**：拟合后验证 H0 > 0
- **模式2**：约束优化 H0 > 0
- **驼峰约束**：如果需要驼峰型，约束 c < 0

**代码示例**：
```python
def math_cubic_decay(Q, H0, a, b, c):
    return H0 - a * Q - b * Q**2 - c * Q**3

# 拟合（无约束）
params, _ = curve_fit(math_cubic_decay, Q_data, H_data)

# 拟合（约束H0>0）
params, _ = curve_fit(
    math_cubic_decay, 
    Q_data, 
    H_data,
    bounds=([-np.inf, -np.inf, -np.inf, -np.inf], 
            [np.inf, np.inf, np.inf, np.inf])
)
```

**使用场景**：
1. 高精度拟合Q-H曲线
2. 驼峰型曲线
3. 数据量充足（>100点）
4. 对精度要求高的场景

### 方法16：`math_linear_growth` - 线性增长

**数学公式**：
```
P = a + b×Q
```

**参数说明**：
- `a`: 截距（零流量功率），单位：kW
- `b`: 斜率（功率增长率），单位：kW/(m³/h)

**物理意义**：
- `a`: 空载功率（机械损失、铁损等）
- `b`: 单位流量功率增量

**适用曲线**：Q-P曲线（流量-功率）

**预期精度**：R² > 0.90

**优点**：
1. 最简单，计算最快
2. 参数物理意义明确
3. 不会过拟合

**缺点**：
1. 精度较低
2. 无法捕捉非线性特性

**代码示例**：
```python
def math_linear_growth(Q, a, b):
    return a + b * Q

# 使用sklearn的线性回归（更快）
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(Q_data.reshape(-1, 1), P_data)
a, b = model.intercept_, model.coef_[0]

# 或使用curve_fit
params, _ = curve_fit(math_linear_growth, Q_data, P_data)
```

**使用场景**：
1. 快速估算
2. 线性关系明显的曲线
3. 数据量少
4. 实时计算

## 2.3 单峰曲线方法（18种）

### 方法28：`math_stat_gaussian` - 高斯函数

**数学公式**：
```
η = a × exp(-((Q - μ)² / (2σ²)))
```

**参数说明**：
- `a`: 峰值高度（最大效率），单位：%
- `μ`: 峰值位置（最佳效率点BEP对应的流量），单位：m³/h
- `σ`: 峰宽（标准差），单位：m³/h

**物理意义**：
- `a`: 泵的最大效率
- `μ`: 最佳效率点（BEP）的流量
- `σ`: 高效区的宽度

**适用曲线**：Q-η曲线（流量-效率）

**预期精度**：R² > 0.95

**优点**：
1. 符合效率曲线的单峰特性
2. 参数物理意义明确
3. 自动满足单峰约束

**缺点**：
1. 假设对称分布（实际可能偏态）
2. 无法处理多峰曲线

**代码示例**：
```python
def math_stat_gaussian(Q, a, mu, sigma):
    return a * np.exp(-((Q - mu)**2) / (2 * sigma**2))

# 拟合
params, _ = curve_fit(math_stat_gaussian, Q_data, eta_data,
                      bounds=([0, 0, 0], [100, np.inf, np.inf]))
a, mu, sigma = params

# BEP点
Q_BEP = mu
eta_max = a
```

**使用场景**：
1. 标准效率曲线拟合
2. 需要识别BEP点
3. 对称单峰曲线
