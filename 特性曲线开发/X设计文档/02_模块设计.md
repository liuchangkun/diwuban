#### 2.2.2 ValidationResult（验证结果）

```python
@dataclass
class ValidationResult:
    """物理约束验证结果"""

    # 单调性验证
    monotonicity_passed: bool
    monotonicity_details: Dict[str, Any]

    # 边界条件验证
    boundary_passed: bool
    boundary_details: Dict[str, Any]

    # 曲率验证（可选）
    curvature_passed: Optional[bool] = None
    curvature_details: Optional[Dict[str, Any]] = None

    # 物理一致性验证（可选）
    physics_consistency_passed: Optional[bool] = None
    physics_consistency_details: Optional[Dict[str, Any]] = None

    # 总体结果
    overall_passed: bool = True
    warnings: List[str] = field(default_factory=list)

    def to_dict(self) -> Dict[str, Any]:
        """转换为字典"""
        return {
            'monotonicity': {
                'passed': self.monotonicity_passed,
                **self.monotonicity_details
            },
            'boundary_conditions': {
                'passed': self.boundary_passed,
                **self.boundary_details
            },
            'curvature': {
                'passed': self.curvature_passed,
                **(self.curvature_details or {})
            } if self.curvature_passed is not None else None,
            'physical_consistency': {
                'passed': self.physics_consistency_passed,
                **(self.physics_consistency_details or {})
            } if self.physics_consistency_passed is not None else None,
            'overall_passed': self.overall_passed,
            'warnings': self.warnings
        }
```

## 3. 主管道层（Pipeline Layer）

### 3.1 CurveFittingPipeline（主管道）

**文件路径**：`app/services/characteristic_curves/pipeline.py`

**职责**：
- 作为整个拟合功能的总入口
- 协调所有模块的执行
- 管理依赖注入
- 处理异常和日志

**核心方法**：

| 方法名 | 参数 | 返回值 | 说明 |
|-------|------|-------|------|
| `__init__()` | 无 | 无 | 初始化所有模块 |
| `fit()` | device_id, curve_type, start_time, end_time, methods, normalize, optimize, force_fit | FitResult | 拟合曲线 |
| `validate()` | device_id, curve_type, version, test_start_time, test_end_time | ValidationResult | 验证拟合结果 |
| `compare_versions()` | device_id, curve_type, version1, version2 | Dict | 对比两个版本 |

**依赖关系**：
- 依赖所有共用层模块（ResultStorage, CacheManager, BatchProcessor等）
- 依赖所有曲线模块（QHCurve, QPCurve, QEtaCurve）

**初始化流程**：
```
1. 创建共用层模块实例（单例）
2. 创建曲线模块实例（依赖注入）
3. 记录日志
```

**拟合流程**：
```
1. 参数验证
2. 选择曲线模块
3. 调用曲线模块的fit()方法
4. 返回结果
```

### 4.2 ParameterOptimizer（参数优化器）

**文件路径**：`app/services/characteristic_curves/shared/parameter_optimizer.py`

**职责**：
- 使用网格搜索优化拟合参数
- 使用K折交叉验证评估
- 返回最优参数组合

**核心方法**：

| 方法名 | 参数 | 返回值 | 说明 |
|-------|------|-------|------|
| `__init__()` | n_folds=5 | 无 | 初始化 |
| `optimize()` | X, y, fit_func, param_grid | Dict[str, Any] | 优化参数 |
| `_generate_param_combinations()` | param_grid | List[Dict] | 生成参数组合 |

**使用示例**：
```python
optimizer = ParameterOptimizer(n_folds=5)

param_grid = {
    'degree': [2, 3],
    'lambda': [0.01, 0.05, 0.1]
}

best_params = optimizer.optimize(X, y, fit_func, param_grid)
```

## 5. 曲线特定层（Curve-Specific Layer）

### 5.1 模块结构

每个曲线类型（Q-H, Q-P, Q-η）都有独立的模块，包含7个子模块：

| 子模块 | 文件名 | 职责 |
|-------|-------|------|
| **DataExtractor** | `data_extractor.py` | 从数据库提取数据 |
| **Preprocessor** | `preprocessor.py` | 数据预处理 |
| **Constraints** | `constraints.py` | 物理约束计算 |
| **Normalizer** | `normalizer.py` | 归一化/反归一化 |
| **Validator** | `validator.py` | 验证拟合结果 |
| **CurveFitter** | `curve_fitter.py` | 执行拟合 |
| **Curve** | `qh_curve.py` / `qp_curve.py` / `qeta_curve.py` | 曲线主类 |

---

### 5.2 QHCurve（Q-H曲线）

**文件路径**：`app/services/characteristic_curves/curves/qh/qh_curve.py`

**职责**：
- Q-H曲线拟合的主类
- 协调7个子模块
- 接收共用层模块的依赖注入

**核心方法**：

| 方法名 | 参数 | 返回值 | 说明 |
|-------|------|-------|------|
| `__init__()` | storage, cache, batch_processor, parameter_optimizer, historical_evaluator | 无 | 初始化（依赖注入） |
| `fit()` | device_id, start_time, end_time, methods, normalize, optimize, force_fit | FitResult | 拟合Q-H曲线 |
| `validate()` | fit_result, test_start_time, test_end_time | ValidationResult | 验证拟合结果 |

**拟合流程**：
```
1. 数据提取（DataExtractor）
2. 数据预处理（Preprocessor）
3. 约束计算（Constraints）
4. 归一化（Normalizer，可选）
5. 拟合（CurveFitter）
6. 验证（Validator）
7. 历史数据评估（HistoricalDataEvaluator）
8. 存储（ResultStorage）
9. 返回结果
```

### 5.4 QHConstraints（Q-H约束）

**文件路径**：`app/services/characteristic_curves/curves/qh/constraints.py`

**职责**：
- 计算Q-H曲线的物理约束参数
- 验证拟合结果是否满足约束

**核心方法**：

| 方法名 | 参数 | 返回值 | 说明 |
|-------|------|-------|------|
| `calculate_constraints()` | data, device_id | Dict[str, Any] | 计算约束参数 |

**约束参数**：
- `H0_min`, `H0_max`：零流量扬程范围
- `Q_max`：最大流量
- `monotonicity_required`：是否要求单调递减

### 5.5 QPCurve和QEtaCurve

**QPCurve** 和 **QEtaCurve** 的结构与 **QHCurve** 类似，只是：
- 数据提取的指标不同（Q-P提取功率，Q-η提取效率）
- 物理约束不同（Q-P递增，Q-η单峰）
- 推荐方法不同（Q-P用power_equation，Q-η用gaussian）

|-------|------|-------|------|
| `validate()` | X, y_pred, curve_type | Dict[str, Any] | 验证单调性 |
