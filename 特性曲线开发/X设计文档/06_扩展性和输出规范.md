## 1. 结果输出增强规范

### 1.1 概述

拟合完成后，系统将自动生成以下输出：
1. **JSON拟合结果**（结构化数据）
2. **8K分辨率曲线图片**（PNG格式，7680×4320像素）
3. **Markdown拟合报告**（12模块完整报告）

所有输出文件保存在统一的版本目录下：`\reports\curves\{曲线名称}\{版本号}\`

---

### 1.2 输出目录结构

#### 1.2.1 路径结构规范

| 层级 | 说明 | 格式 | 示例 |
|------|------|------|------|
| 基础路径 | 固定前缀 | `\reports\curves\` | - |
| 曲线名称 | 中英混合格式 | `{英文缩写}_{中文名称}` | `qh_流量扬程` |
| 版本号 | 时间戳格式 | `YYYYMMDD_HHMMSS` | `20250128_143052` |

#### 1.2.2 曲线名称映射表

| 曲线类型代码 | 曲线名称（目录名） | 中文说明 |
|------------|------------------|---------|
| `qh` | `qh_流量扬程` | Q-H 流量-扬程曲线 |
| `qp` | `qp_流量功率` | Q-P 流量-功率曲线 |
| `qeta` | `qeta_流量效率` | Q-η 流量-效率曲线 |

### 1.3 文件命名规范

#### 1.3.1 统一命名格式

**格式**：`{曲线名称}_{拟合方法}_{版本号}_{文件类型}.{扩展名}`

| 组成部分 | 说明 | 示例 |

| 拟合方法 | 英文小写 | `polynomial_3`, `power_equation` |
| 版本号 | 时间戳 | `20250128_143052` |

#### 1.3.2 各类型文件命名

| 文件类型 | 文件名格式 | 示例 |

### 1.5 8K高清曲线图片输出（PNG）

#### 1.5.1 基本规格

| 配置项 | 规格 |
|-------|------|
| **分辨率** | 7680 × 4320（8K UHD） |
| **DPI** | 300 |
| **图像尺寸** | 25.6 × 14.4 英寸 |
| **格式** | PNG（无损压缩） |
| **中文字体** | SimHei（黑体），回退：Microsoft YaHei |
| **颜色方案** | 原始数据点（#3498db蓝）、拟合曲线（#e74c3c红）、置信区间（#fadbd8浅红） |

#### 1.5.2 图片类型说明

| 图片类型 | 文件后缀 | 内容说明 |
|---------|---------|---------|
| 主曲线图 | `_curve.png` | 原始数据散点 + 拟合曲线 + 95%置信带 |
| 残差分析图 | `_residuals.png` | 4子图：残差vs预测、残差vs流量、直方图、QQ图 |
| 置信区间图 | `_confidence.png` | 拟合曲线 + 95%/99%置信区间 + 预测区间 |
| 敏感性分析图 | `_sensitivity.png` | 各参数变化对曲线的影响 |
| 版本对比图 | `_comparison.png` | 当前版本与历史版本曲线对比 |

#### 1.5.3 主曲线图内容要求

**必须包含的元素**：

1. **标题**（中文）：
   - 格式：`设备{device_id} - {曲线中文名}特性曲线拟合结果`
   - 示例：`设备1 - 流量-扬程特性曲线拟合结果`

2. **坐标轴标签**（中文）：
   | 曲线类型 | X轴标签 | Y轴标签 |
   |---------|--------|--------|
   | Q-H | 流量 Q (m³/h) | 扬程 H (m) |
   | Q-P | 流量 Q (m³/h) | 功率 P (kW) |
   | Q-η | 流量 Q (m³/h) | 效率 η (%) |

3. **图例**（中文）：
   - 原始数据点
   - 拟合曲线
   - 95%置信区间

4. **统计信息标注框**：
   ```
   ┌─────────────────────────┐
   │ 拟合方法：三次多项式      │
   │ R² = 0.9876             │
   │ RMSE = 0.432 m          │
   │ 数据点数：15,234         │
   │ 时间范围：2024-01-01     │
   │         ~ 2024-12-31    │
   └─────────────────────────┘
   ```

5. **网格线**：浅灰色虚线（alpha=0.3）

#### 1.5.4 残差分析图布局

```
┌─────────────────────┬─────────────────────┐
│  残差 vs 预测值      │  残差 vs 流量        │
│  (散点图)           │  (散点图)            │
├─────────────────────┼─────────────────────┤
│  残差直方图          │  残差Q-Q图           │
│  (直方图+正态曲线)   │  (理论vs实际)        │
└─────────────────────┴─────────────────────┘
```

| 8 | 参数敏感性分析 | 敏感性系数、影响程度评估 |
| 9 | 分段性能评估 | 低/中/高流量段分别统计 |
| 10 | 历史对比分析 | 版本列表、曲线漂移分析、对比图 |
| 11 | 物理约束验证 | 单调性、边界条件、曲率验证详情 |

```python
from app.services.characteristic_curves.methods.base_method import BaseMethod
from app.services.characteristic_curves.core.data_structures import MethodResult
import numpy as np
import xgboost as xgb

class XGBoostMethod(BaseMethod):
    """XGBoost拟合方法（通用）"""

    def __init__(self):
        super().__init__()
        self.method_name = 'xgboost'

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        拟合方法（必须实现）

        Args:
            X: 自变量数组（流量Q）
            y: 因变量数组（H/P/η/NPSH等，任意曲线）
            **kwargs: 可选参数
                - n_estimators: 树的数量（默认100）
                - max_depth: 最大深度（默认6）
                - learning_rate: 学习率（默认0.1）

        Returns:
            result: 拟合结果
        """
        # 提取参数
        n_estimators = kwargs.get('n_estimators', 100)
        max_depth = kwargs.get('max_depth', 6)
        learning_rate = kwargs.get('learning_rate', 0.1)

        # 训练模型
        model = xgb.XGBRegressor(
            n_estimators=n_estimators,
            max_depth=max_depth,
            learning_rate=learning_rate,
            random_state=42
        )
        model.fit(X.reshape(-1, 1), y)

        # 预测
        y_pred = model.predict(X.reshape(-1, 1))

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        # 保存模型参数（序列化）
        import pickle
        model_bytes = pickle.dumps(model)

        return MethodResult(
            fit_params={'model': model_bytes.hex()},  # 十六进制字符串
            r_squared=metrics['r_squared'],
            rmse=metrics['rmse'],
            mae=metrics['mae'],
            mape=metrics['mape'],
            metadata={'n_estimators': n_estimators, 'max_depth': max_depth}
        )

    def predict(self, X: np.ndarray, params: Dict[str, Any]) -> np.ndarray:
        """
        预测方法（必须实现）

        Args:
            X: 自变量数组
            params: 拟合参数（包含序列化的模型）

        Returns:
            y_pred: 预测值数组
        """
        import pickle

        # 反序列化模型
        model_bytes = bytes.fromhex(params['model'])
        model = pickle.loads(model_bytes)

        # 预测
        y_pred = model.predict(X.reshape(-1, 1))

        return y_pred
```

**问题**：新方法是否需要为每种曲线类型单独适配？

**答案**：**不需要**。所有方法都是通用的，自动适用于所有曲线类型。

**原因**：
1. ✅ **数学本质相同**：所有曲线都是 y = f(x) 的关系
2. ✅ **接口统一**：所有方法接受 (X, y) 输入，返回 MethodResult
3. ✅ **物理约束分离**：物理约束由Constraints模块处理，不在方法内部
4. ✅ **归一化分离**：归一化由Normalizer模块处理，不在方法内部

**特殊情况**：
- 如果某个方法只适用于特定曲线（如PowerEquationModel只适用于Q-P），可以在方法内部添加检查：

```python
class PowerEquationModel(BaseMethod):
    def fit(self, X, y, **kwargs):
        # 检查曲线类型
        curve_type = kwargs.get('curve_type')
        if curve_type != 'qp':
            raise ValueError(f"PowerEquationModel只适用于Q-P曲线，当前曲线类型：{curve_type}")

        # 继续拟合
        pass
```
