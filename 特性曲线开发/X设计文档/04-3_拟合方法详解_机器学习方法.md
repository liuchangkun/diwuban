## 1. 多变量回归方法（20种）

### 方法54：`ml_gradient_boost` - 梯度提升树

**算法原理**：
梯度提升树（Gradient Boosting）是一种集成学习方法，通过迭代训练多个弱学习器（决策树），每个新树都试图纠正前面所有树的残差。

**数学公式**：
```
F_m(x) = F_{m-1}(x) + γ_m × h_m(x)

其中：
- F_m(x): 第m轮的模型
- h_m(x): 第m个弱学习器（决策树）
- γ_m: 学习率
- 目标：最小化损失函数 L(y, F_m(x))
```

**算法流程**：
1. 初始化：F_0(x) = argmin_γ Σ L(y_i, γ)
2. 对于 m = 1 到 M：
   - 计算残差：r_im = -[∂L(y_i, F(x_i))/∂F(x_i)]
   - 拟合决策树 h_m(x) 到残差 r_im
   - 计算最优步长 γ_m
   - 更新模型：F_m(x) = F_{m-1}(x) + γ_m × h_m(x)
3. 输出最终模型：F_M(x)

**超参数配置**：
```yaml
# 核心超参数
n_estimators: 100  # 树的数量
learning_rate: 0.1  # 学习率
max_depth: 5  # 树的最大深度
min_samples_split: 10  # 分裂所需的最小样本数
min_samples_leaf: 5  # 叶节点最小样本数
subsample: 0.8  # 子采样比例
max_features: 'sqrt'  # 最大特征数

# 正则化参数
alpha: 0.9  # 分位数损失的alpha值
loss: 'squared_error'  # 损失函数
```

**适用曲线**：
- 所有曲线类型（单变量和多变量）
- 特别适合：Q-H-f、Q-P-f、Q-η-f等多变量曲线

**预期精度**：R² > 0.97

**优点**：
1. **高精度**：通常能达到最高精度
2. **鲁棒性强**：对异常值不敏感
3. **特征重要性**：可以评估特征重要性
4. **非线性**：自动捕捉复杂非线性关系
5. **无需特征工程**：自动处理特征交互

**缺点**：
1. **训练时间长**：相比简单方法慢
2. **超参数敏感**：需要调参
3. **可解释性差**：黑箱模型
4. **外推性差**：不适合外推到训练范围外

**代码示例**：
```python
from sklearn.ensemble import GradientBoostingRegressor
from sklearn.model_selection import GridSearchCV
import numpy as np

class MLGradientBoost:
    """梯度提升树拟合方法"""
    
    def __init__(self, config=None):
        self.config = config or {
            'n_estimators': 100,
            'learning_rate': 0.1,
            'max_depth': 5,
            'min_samples_split': 10,
            'min_samples_leaf': 5,
            'subsample': 0.8,
            'max_features': 'sqrt',
            'random_state': 42
        }
        self.model = None
        self.feature_importance = None
    
    def fit(self, X, y, tune_hyperparams=False):
        """
        拟合方法
        
        Parameters:
        -----------
        X : np.ndarray
            自变量，shape=(n_samples, n_features)
            - 单变量：(Q,)
            - 多变量：(Q, f) 或 (Q, f, N)
        y : np.ndarray
            因变量，shape=(n_samples,)
        tune_hyperparams : bool
            是否进行超参数调优
        
        Returns:
        --------
        result : dict
            拟合结果
        """
        if tune_hyperparams:
            # 超参数调优
            param_grid = {
                'n_estimators': [50, 100, 200],
                'learning_rate': [0.05, 0.1, 0.2],
                'max_depth': [3, 5, 7],
                'min_samples_split': [5, 10, 20]
            }
            
            base_model = GradientBoostingRegressor(random_state=42)
            grid_search = GridSearchCV(
                base_model, param_grid, 
                cv=5, scoring='r2', n_jobs=-1
            )
            grid_search.fit(X, y)
            
            self.model = grid_search.best_estimator_
            self.config = grid_search.best_params_
        else:
            # 使用默认配置
            self.model = GradientBoostingRegressor(**self.config)
            self.model.fit(X, y)
        
        # 计算特征重要性
        self.feature_importance = self.model.feature_importances_
        
        # 预测和评估
        y_pred = self.model.predict(X)
        r2 = 1 - np.sum((y - y_pred)**2) / np.sum((y - np.mean(y))**2)
        rmse = np.sqrt(np.mean((y - y_pred)**2))
        mae = np.mean(np.abs(y - y_pred))
        
        return {
            'params': self.config,
            'r2': r2,
            'rmse': rmse,
            'mae': mae,
            'feature_importance': self.feature_importance,
            'model': self.model
        }
    
    def predict(self, X):
        """预测"""
        return self.model.predict(X)
    
    def get_feature_importance(self):
        """获取特征重要性"""
        return self.feature_importance

# 使用示例1：单变量Q-H曲线
Q = np.linspace(0, 300, 200).reshape(-1, 1)
H = 120 - 0.2*Q.flatten() - 0.001*Q.flatten()**2 + np.random.normal(0, 2, 200)

method = MLGradientBoost()
result = method.fit(Q, H)
print(f"R² = {result['r2']:.4f}")
print(f"RMSE = {result['rmse']:.2f}")

# 使用示例2：多变量Q-H-f曲线
Q = np.random.uniform(0, 300, 500)
f = np.random.uniform(30, 50, 500)
H = 120 * (f/50)**2 - 0.2*Q - 0.001*Q**2 + np.random.normal(0, 2, 500)
X = np.column_stack([Q, f])

method = MLGradientBoost()
result = method.fit(X, H, tune_hyperparams=True)
print(f"R² = {result['r2']:.4f}")
print(f"特征重要性: Q={result['feature_importance'][0]:.3f}, f={result['feature_importance'][1]:.3f}")

# 预测
Q_new = np.array([[100, 45], [200, 50]])
H_pred = method.predict(Q_new)
```

**使用场景**：
1. **高精度需求**：需要R²>0.97的场景
2. **多变量拟合**：Q-H-f、Q-P-f-N等多变量曲线
3. **复杂非线性**：曲线形状复杂，难以用简单函数描述
4. **数据量充足**：>500点
5. **不需要外推**：仅在训练范围内预测

**注意事项**：
1. **数据量要求**：建议>500点，否则容易过拟合
2. **特征缩放**：虽然树模型对特征缩放不敏感，但建议归一化以提高训练速度
3. **超参数调优**：首次使用建议进行网格搜索
4. **外推警告**：不要用于外推，外推精度很差
5. **计算资源**：大数据集（>10,000点）训练时间可能较长

## 📊 方法选择建议

### 按精度选择
- **极高精度（R²>0.98）**：`ml_xgboost`, `ml_lightgbm`, `ml_catboost`, `ml_pinn_hard_constraint`
- **高精度（R²>0.96）**：`ml_gradient_boost`, `ml_random_forest`, `ml_neural_network_deep`
- **中等精度（R²>0.93）**：`ml_neural_network_shallow`, `ml_gaussian_process`, `ml_multivariate_poly_3`

### 按速度选择
- **最快**：`ml_lightgbm`, `ml_multivariate_poly_2`
- **快速**：`ml_xgboost`, `ml_neural_network_shallow`
- **中速**：`ml_gradient_boost`, `ml_random_forest`
- **慢速**：`ml_gaussian_process`, `ml_neural_network_deep`

### 按数据量选择
- **小数据（<100点）**：`ml_kernel_ridge`, `ml_gaussian_process`, `ml_multivariate_poly_2`
- **中数据（100-1000点）**：`ml_gradient_boost`, `ml_random_forest`, `ml_neural_network_shallow`
- **大数据（>1000点）**：`ml_lightgbm`, `ml_xgboost`, `ml_catboost`

### 按场景选择
- **需要不确定性量化**：`ml_gaussian_process`, `ml_gpr_2d`
- **需要物理约束**：`ml_pinn_soft_constraint`, `ml_pinn_hard_constraint`
- **需要特征选择**：`ml_lasso`, `ml_elastic_net`
- **需要鲁棒性**：`ml_random_forest`, `ml_support_vector_regression`
