## 1. 混合方法概述

### 1.1 什么是混合方法？

混合方法（Hybrid Methods）结合了**物理模型**和**数据驱动方法**的优势：
- **物理模型**：提供可解释性、外推能力、物理约束
- **数据驱动**：提供高精度、自适应能力、残差修正

### 1.2 混合方法的优势

| 特性 | 纯物理模型 | 纯数据驱动 | 混合方法 |
|-----|----------|----------|---------|
| **精度** | 中等（R²~0.93） | 高（R²~0.97） | **极高（R²~0.98）** |
| **可解释性** | 强 | 弱 | **中等** |
| **外推能力** | 强 | 弱 | **中等** |
| **物理约束** | 自动满足 | 需要强制 | **自动满足** |
| **数据需求** | 少 | 多 | **中等** |

### 1.3 混合方法的三种模式

**模式A：物理先验 + 数据修正**
```
y_pred = f_physics(x, θ_physics) + f_data(x, θ_data)
```
- 先用物理模型拟合主要趋势
- 再用数据驱动方法拟合残差

**模式B：数据驱动 + 物理约束**
```
y_pred = f_data(x, θ_data)
subject to: 物理约束
```
- 用数据驱动方法拟合
- 通过损失函数或优化约束强制物理规律

**模式C：物理参数 + 数据学习**
```
y_pred = f_physics(x, θ_physics(x, θ_data))
```
- 物理模型的参数由数据驱动方法学习
- 保持物理模型结构，提高参数适应性

## 2. 混合方法详解（6种）

### 方法175：`hybrid_physics_decay` - 混合衰减方法

**方法类型**：模式A（物理先验 + 数据修正）

**物理模型**：
```
H_physics = H0 - K1×Q - K2×Q²
```

**数据修正**：
```
H_residual = f_data(Q)  # 使用神经网络或高斯过程
```

**最终预测**：
```
H_pred = H_physics + H_residual
```

**算法流程**：
1. **第一步：物理模型拟合**
   - 使用泵特性方程拟合：H = H0 - K1×Q - K2×Q²
   - 获得物理参数：H0, K1, K2
   - 计算残差：r = H_true - H_physics

2. **第二步：残差建模**
   - 使用神经网络或高斯过程拟合残差：r = f_data(Q)
   - 训练目标：最小化 ||r - f_data(Q)||²

3. **第三步：组合预测**
   - 最终预测：H_pred = H_physics + f_data(Q)
   - 物理约束自动满足（通过物理模型部分）

**适用曲线**：Q-H曲线（流量-扬程）

**预期精度**：R² > 0.98

**优点**：
1. **极高精度**：结合物理模型和数据驱动的优势
2. **可解释性**：物理部分可解释，残差部分捕捉未建模效应
3. **物理约束**：自动满足单调递减等约束
4. **外推能力**：比纯数据驱动方法好
5. **鲁棒性**：物理模型提供基础，数据驱动提供精化

**缺点**：
1. **复杂度高**：需要两步拟合
2. **计算成本**：比单一方法慢
3. **超参数多**：需要调整两个模型的参数

**代码示例**：
```python
import numpy as np
from scipy.optimize import curve_fit
from sklearn.neural_network import MLPRegressor
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import RBF, ConstantKernel

class HybridPhysicsDecay:
    """混合衰减方法：物理模型 + 数据驱动残差"""
    
    def __init__(self, residual_model='neural_network'):
        """
        Parameters:
        -----------
        residual_model : str
            残差模型类型：'neural_network' 或 'gaussian_process'
        """
        self.residual_model_type = residual_model
        self.physics_params = None
        self.residual_model = None
    
    def _physics_model(self, Q, H0, K1, K2):
        """物理模型：泵特性方程"""
        return H0 - K1 * Q - K2 * Q**2
    
    def fit(self, Q, H):
        """
        拟合方法
        
        Parameters:
        -----------
        Q : np.ndarray
            流量，shape=(n_samples,)
        H : np.ndarray
            扬程，shape=(n_samples,)
        
        Returns:
        --------
        result : dict
            拟合结果
        """
        # 第一步：拟合物理模型
        initial_guess = [H[0], 0.2, 0.001]
        bounds = ([0, 0, 0], [np.inf, np.inf, np.inf])
        
        self.physics_params, _ = curve_fit(
            self._physics_model, Q, H,
            p0=initial_guess,
            bounds=bounds
        )
        
        H0, K1, K2 = self.physics_params
        
        # 计算物理模型预测和残差
        H_physics = self._physics_model(Q, H0, K1, K2)
        residual = H - H_physics
        
        # 第二步：拟合残差模型
        Q_reshaped = Q.reshape(-1, 1)
        
        if self.residual_model_type == 'neural_network':
            # 使用神经网络拟合残差
            self.residual_model = MLPRegressor(
                hidden_layer_sizes=(20, 10),
                activation='relu',
                solver='adam',
                max_iter=1000,
                random_state=42
            )
            self.residual_model.fit(Q_reshaped, residual)
        
        elif self.residual_model_type == 'gaussian_process':
            # 使用高斯过程拟合残差
            kernel = ConstantKernel(1.0) * RBF(length_scale=50.0)
            self.residual_model = GaussianProcessRegressor(
                kernel=kernel,
                n_restarts_optimizer=10,
                random_state=42
            )
            self.residual_model.fit(Q_reshaped, residual)
        
        # 评估
        H_pred = self.predict(Q)
        r2 = 1 - np.sum((H - H_pred)**2) / np.sum((H - np.mean(H))**2)
        rmse = np.sqrt(np.mean((H - H_pred)**2))
        mae = np.mean(np.abs(H - H_pred))
        
        # 物理模型单独评估
        r2_physics = 1 - np.sum((H - H_physics)**2) / np.sum((H - np.mean(H))**2)
        
        return {
            'params': {
                'physics': {'H0': H0, 'K1': K1, 'K2': K2},
                'residual_model': self.residual_model_type
            },
            'r2': r2,
            'r2_physics': r2_physics,
            'r2_improvement': r2 - r2_physics,
            'rmse': rmse,
            'mae': mae
        }
    
    def predict(self, Q):
        """预测"""
        Q_reshaped = Q.reshape(-1, 1)
        
        # 物理模型预测
        H0, K1, K2 = self.physics_params
        H_physics = self._physics_model(Q, H0, K1, K2)
        
        # 残差预测
        H_residual = self.residual_model.predict(Q_reshaped)
        
        # 组合预测
        H_pred = H_physics + H_residual
        
        return H_pred
    
    def predict_with_components(self, Q):
        """预测并返回各组件"""
        Q_reshaped = Q.reshape(-1, 1)
        
        H0, K1, K2 = self.physics_params
        H_physics = self._physics_model(Q, H0, K1, K2)
        H_residual = self.residual_model.predict(Q_reshaped)
        H_pred = H_physics + H_residual
        
        return {
            'total': H_pred,
            'physics': H_physics,
            'residual': H_residual
        }

# 使用示例
# 生成测试数据（真实数据 = 物理模型 + 复杂残差）
Q = np.linspace(0, 300, 200)
H_physics = 120 - 0.2*Q - 0.001*Q**2
H_residual_true = 3 * np.sin(Q / 50) + 2 * np.exp(-Q / 200)
H = H_physics + H_residual_true + np.random.normal(0, 1, 200)

# 拟合
method = HybridPhysicsDecay(residual_model='neural_network')
result = method.fit(Q, H)

print(f"物理模型 R² = {result['r2_physics']:.4f}")
print(f"混合方法 R² = {result['r2']:.4f}")
print(f"精度提升 = {result['r2_improvement']:.4f}")
print(f"物理参数: H0={result['params']['physics']['H0']:.2f}, "
      f"K1={result['params']['physics']['K1']:.4f}, "
      f"K2={result['params']['physics']['K2']:.6f}")

# 预测并分解
Q_test = np.array([50, 100, 150, 200, 250])
components = method.predict_with_components(Q_test)
print("\n预测分解:")
for i, q in enumerate(Q_test):
    print(f"Q={q}: 总计={components['total'][i]:.2f}, "
          f"物理={components['physics'][i]:.2f}, "
          f"残差={components['residual'][i]:.2f}")
```

**使用场景**：
1. **高精度需求**：需要R²>0.98
2. **需要可解释性**：需要理解物理机制
3. **需要外推**：外推性能优于纯数据驱动
4. **复杂残差**：物理模型无法完全描述的复杂效应

**方法180：`ml_pinn` - 物理信息神经网络（PINN）**

**核心思想**：在神经网络的损失函数中加入物理约束项

**损失函数**：
```
Loss = Loss_data + λ × Loss_physics

其中：
- Loss_data = ||y_true - y_pred||²（数据拟合损失）
- Loss_physics = ||物理约束违反||²（物理约束损失）
- λ: 权重系数
```

**物理约束示例**（Q-H曲线）：
```python
# 单调递减约束
dH_dQ = gradient(H_pred, Q)
Loss_monotonic = ReLU(-dH_dQ)  # 惩罚 dH/dQ > 0

# 边界条件约束
Loss_boundary = (H_pred[Q=0] - H0)**2

# 相似定律约束（Q-H-f曲线）
Loss_affinity = (H2/H1 - (f2/f1)**2)**2
```
