## 3.1 泵水力学模型（12种）

### 方法145：`physics_euler_equation` - 欧拉方程（叶轮理论）

**物理机理**：
基于叶轮理论的欧拉方程，描述叶轮对流体做功的基本原理。

**数学公式**：
```
H_th = (u2×c2u - u1×c1u) / g

其中：
- H_th: 理论扬程，单位：m
- u: 叶轮圆周速度，u = π×D×n/60，单位：m/s
- c: 绝对速度，单位：m/s
- 下标1: 叶轮进口，下标2: 叶轮出口
- 下标u: 圆周分量
- g: 重力加速度，9.81 m/s²
```

**参数说明**：
- `D1, D2`: 叶轮进出口直径，单位：m
- `n`: 转速，单位：rpm
- `β1, β2`: 叶片进出口角度，单位：度
- `b1, b2`: 叶轮进出口宽度，单位：m

**物理意义**：
- 欧拉方程是泵理论的基础，描述了叶轮对流体做功的本质
- 理论扬程与叶轮几何参数和转速直接相关
- 实际扬程 = 理论扬程 - 水力损失

**适用曲线**：Q-H曲线

**预期精度**：R² > 0.96

**优点**：
1. 基于第一性原理，物理意义明确
2. 可以从设计参数预测性能
3. 适用于新设计的泵
4. 外推性好

**缺点**：
1. 需要详细的几何参数
2. 不考虑水力损失，需要修正
3. 计算复杂度较高

**代码示例**：
```python
def physics_euler_equation(Q, D1, D2, n, beta1, beta2, b1, b2):
    """
    欧拉方程计算理论扬程
    
    Parameters:
    -----------
    Q : float
        流量，单位：m³/h
    D1, D2 : float
        叶轮进出口直径，单位：m
    n : float
        转速，单位：rpm
    beta1, beta2 : float
        叶片进出口角度，单位：度
    b1, b2 : float
        叶轮进出口宽度，单位：m
    
    Returns:
    --------
    H_th : float
        理论扬程，单位：m
    """
    import numpy as np
    
    # 转换单位
    Q_m3s = Q / 3600  # m³/h → m³/s
    omega = 2 * np.pi * n / 60  # rpm → rad/s
    
    # 圆周速度
    u1 = omega * D1 / 2
    u2 = omega * D2 / 2
    
    # 径向速度
    c1r = Q_m3s / (np.pi * D1 * b1)
    c2r = Q_m3s / (np.pi * D2 * b2)
    
    # 圆周分量（根据速度三角形）
    c1u = u1 - c1r / np.tan(np.radians(beta1))
    c2u = u2 - c2r / np.tan(np.radians(beta2))
    
    # 理论扬程
    H_th = (u2 * c2u - u1 * c1u) / 9.81
    
    return H_th

# 实际应用中需要考虑水力损失
def physics_euler_with_loss(Q, D1, D2, n, beta1, beta2, b1, b2, k_loss):
    H_th = physics_euler_equation(Q, D1, D2, n, beta1, beta2, b1, b2)
    H_loss = k_loss * Q**2  # 水力损失
    H = H_th - H_loss
    return H
```

**使用场景**：
1. 新泵设计阶段的性能预测
2. 需要从几何参数推导性能
3. 理论分析和教学
4. 与实测数据对比，分析水力损失

**注意事项**：
1. 需要准确的几何参数
2. 实际应用中必须考虑水力损失
3. 对于复杂叶轮（如双吸、多级），需要修正公式

## 3.2 流体力学模型（8种）

### 方法155：`physics_bernoulli` - 伯努利方程

**物理机理**：
伯努利方程描述流体在流动过程中能量守恒的基本原理。

**数学公式**：
```
P1/ρg + v1²/(2g) + z1 = P2/ρg + v2²/(2g) + z2 + h_loss

其中：
- P: 压力，单位：Pa
- ρ: 流体密度，单位：kg/m³
- g: 重力加速度，9.81 m/s²
- v: 流速，单位：m/s
- z: 高程，单位：m
- h_loss: 水头损失，单位：m
```

**适用曲线**：系统特性曲线

**预期精度**：R² > 0.95
