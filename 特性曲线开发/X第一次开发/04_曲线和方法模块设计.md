## 1. 概述

### 1.1 曲线模块架构

本文档定义了3条核心特性曲线的详细设计，每条曲线包含完整的数据流和7个独立功能模块。

| 曲线类型 | 物理意义 | 单调性 | 推荐方法 |
|---------|---------|--------|---------|
| **QHCurve** | 流量-扬程关系 | 递减 | physics_pump_char |
| **QPCurve** | 流量-功率关系 | 递增 | physics_power_eq |
| **QEtaCurve** | 流量-效率关系 | 单峰 | math_stat_gaussian |

> 🔴 **S2 说明**：推荐方法ID使用 05 文档规范命名（如 `physics_pump_char` 而非 `pump_characteristic`）

**完整流程集成（关键数据流）**：

```
CurveFittingPipeline.fit(device_id, curve_type)
│
├── 阶段0: TimeWindowSplitter.split()
│   ├── 查询 fact_measurements 表获取数据时间范围
│   ├── 按 75%/25% 比例划分
│   └── 返回 fit_window + test_window
│
├── 阶段0.5: ScenarioDetector.detect_single_pump()  ← 场景识别
│   ├── 读取 dim_devices.pump_type
│   ├── 读取 device_rated_params
│   ├── 计算 freq_std（从历史数据）
│   ├── 识别场景：SOFT_START_SINGLE / VFD_SINGLE / QUASI_FIXED_FREQ_SINGLE
│   ├── 判断是否需要归一化
│   └── 返回 ScenarioDetectionResult
│   │
│   ├── IF scenario == NOT_SUPPORTED:
│   │   └── 抛出异常，终止流程
│   │
│   └── 继续后续处理...
│
├── 阶段1: DataExtractor.extract(fit_window)
│   └── FROM fact_measurements WHERE ts_bucket BETWEEN fit_start AND fit_end
│
├── 阶段2: DataCleaner.clean()
│   └── 删除无效值、异常值、重复值
│
├── 阶段2.5: SteadyStateDetector.filter()
│   ├── Layer 1: phase=1 过滤（复用 mv_device_running_1s）
│   ├── Layer 2: 变化率过滤（freq/pressure/flow）
│   └── Layer 3: 短段过滤（min 5分钟）
│
├── 阶段3: Constraints.calculate()
│   └── 计算物理约束参数
│
├── 阶段3.5: FrequencyNormalizer.normalize()  ← 根据场景决定是否执行
│   ├── IF scenario.need_normalization == False → 跳过
│   ├── IF scenario.need_normalization == True:
│   │   ├── 应用相似定律归一化
│   │   └── 新增列: pump_flow_rate_50, pump_head_50, pump_active_power_50
│   └── 返回归一化后数据
│
├── 阶段4-5: 标准化 → 方法选择
│
├── 阶段6: CurveFitter.fit()
│   └── 返回 fit_result + predict_func
│
├── 阶段7: Validator.validate()
│   └── 验证拟合质量 (R², RMSE, MAE, MAPE)
│
├── 阶段8: HistoricalDataEvaluator.evaluate_prediction_accuracy(test_window)
│   ├── 从 fact_measurements 加载 test_window 内的测试数据
│   ├── 用 predict_func 预测
│   └── 判断是否通过: within_5_percent ≥ 90%
│
└── 阶段9: ResultStorage.save()
    └── 存储到 curve_fit_results 表（包含 scenario 信息）
```

**P2阶段扩展（15阶段）**：

| 阶段 | 名称 | 模块 | 输入 | 输出 | 可选性 |
|------|------|------|------|------|--------|
| **阶段0-9** | P0单泵流程 | 同上 | 同上 | 同上 | 必需 |

**P2阶段数据流图**：

```
P2阶段泵组处理流程（在P0单泵流程之后）

阶段10: PumpGroupProcessor.identify_group_type()
│   ├── 输入: station_id, pump_combination
│   ├── 查询 dim_devices 获取各泵类型和额定参数
│   ├── 计算功率变异系数
│   └── 返回: GroupScenario (HOMOGENEOUS/HETEROGENEOUS/MIXED)
│
├── 阶段11: ParallelSynthesizer.synthesize()
│   ├── 同构泵组: synthesize_homogeneous(base_pump_id, n_pumps)
│   │   └── Q_group = N × Q_single（简化合成）
│   ├── 异构泵组: synthesize_heterogeneous(pump_ids, H_system)
│   │   └── 等扬程流量叠加（迭代求解）
│   └── 混合泵组: synthesize_mixed(vfd_ids, ss_ids, frequencies, H)
│       └── 分类处理后合成
│
└── 阶段12: SystemCorrectionModel.fit()
    ├── 收集理论合成数据和实际运行数据
    ├── 计算修正系数 α = H_actual / H_theoretical
    ├── 拟合修正模型（linear/polynomial/xgboost）
    ├── 验证修正效果（R² > 0.90）
    └── 存储到 curve_fit_results.correction_model
```

**P2阶段精度目标**：

| 场景 | 无修正精度 | 有修正精度 | 提升 |
|------|:----------:|:----------:|:----:|
| **同构泵组** | R² ≈ 0.90 | R² ≈ 0.96 | +6% |
| **异构泵组** | R² ≈ 0.85 | R² ≈ 0.94 | +9% |
| **混合泵组** | R² ≈ 0.82 | R² ≈ 0.92 | +10% |
| **综合曲线** | R² ≈ 0.88 | R² ≈ 0.95 | +7% |

**场景识别矩阵**：

| 场景 | 识别条件 | 处理策略 | P0支持 | P2支持 |
|------|---------|---------|:------:|:------:|
| `SOFT_START_SINGLE` | `pump_type='soft_start'` | 直接拟合 | ✅ | ✅ |
| `VFD_SINGLE` | `pump_type='variable_frequency'` 且 `freq_std>2` | 相似定律归一化 | ✅ | ✅ |
| `QUASI_FIXED_FREQ_SINGLE` | `pump_type='variable_frequency'` 且 `freq_std<2` | 直接拟合 | ✅ | ✅ |
| `HOMOGENEOUS_GROUP` | 所有泵功率差异<10% | 基准泵×N + 修正系数 | ❌ | ✅ |
| `HETEROGENEOUS_GROUP` | 各泵功率差异≥10% | 各泵独立曲线 + 并联合成 + 修正系数 | ❌ | ✅ |
| `MIXED_GROUP` | 同时存在变频泵和软启泵 | 分类处理 + 分类合成 + 修正系数 | ❌ | ✅ |
| `GROUP_COMPOSITE` | 请求泵组综合曲线 | 预计算多维曲面 | ❌ | ✅ |

> **阶段3.5条件执行**：仅当 `pump_type='variable_frequency'` 且 `freq_std > 2.0` 时执行相似定律归一化

**P2阶段泵组场景处理矩阵**：

| 泵组类型 | 处理策略 | 核心模块 | 精度目标 | 复用P0能力 |
|---------|---------|---------|:--------:|-----------|
| **同构泵组** | 基准泵曲线×N + 系统修正系数 | `PumpGroupProcessor` + `SystemCorrectionModel` | R² > 0.96 | 单泵拟合流程 |
| **异构泵组** | 各泵独立曲线 + 并联合成 + 修正系数 | `ParallelSynthesizer` + `SystemCorrectionModel` | R² > 0.94 | 单泵拟合流程 |
| **混合泵组** | 分类处理（变频/软启）+ 分类合成 + 修正系数 | `PumpGroupProcessor` + `ParallelSynthesizer` | R² > 0.92 | 单泵拟合 + 归一化 |
| **泵组综合曲线** | 预计算多维曲面（N, Q_total → H, P, η） | `GroupCompositeCurve` | R² > 0.95 | 所有P0模块 |

**P2阶段对拟合方法和参数的影响**：

| 流程环节 | P0行为 | P2变更 | 影响程度 |
|---------|--------|--------|:--------:|
| **方法选择** | 单泵选择 | 复用P0逻辑，泵组不改变方法选择 | ⚪ 无影响 |
| **拟合参数** | 单泵参数 | 复用P0逻辑，泵组不改变拟合参数 | ⚪ 无影响 |
| **数据提取** | device_id | 增加 station_id + pump_combination 入口 | 🔵 扩展 |
| **场景识别** | 单泵场景 | 增加泵组场景识别 | 🔵 扩展 |
| **曲线存储** | device_id 主键 | 增加泵组字段 | 🟡 表扩展 |
| **曲线查询** | 按 device_id | 增加按 pump_combination | 🔵 扩展 |

> **结论**：P2阶段**最大化复用P0能力**，拟合方法选择和拟合参数逻辑完全复用，仅在入口和存储层面进行扩展。

**阶段0详细说明（时间窗口划分与验证）**：

```
阶段0: 时间窗口划分与验证 [TimeWindowSplitter]
   ├─ 查询 fact_measurements 表获取数据时间范围
   │   └─ SELECT MIN(ts_bucket), MAX(ts_bucket)
   │       FROM fact_measurements fm
   │       JOIN dim_metric_config mc ON mc.id = fm.metric_id
   │       WHERE fm.device_id = ?
   │         AND mc.metric_key IN (...)  -- 根据 curve_type 确定
   ├─ 计算总天数
   ├─ 按 75%/25% 比例划分
   │   ├─ fit_window: 前75%天数（用于曲线拟合）
   │   └─ test_window: 后25%天数（用于预测评估）
   ├─ 验证测试数据量
   │   └─ IF test_point_count < min_test_points (100) → 标记低置信度
   └─ 返回 TimeWindowSplitResult
       ├─ fit_window: TimeWindow
       ├─ test_window: TimeWindow
       └─ can_evaluate: bool
   ↓
IF can_evaluate = False:
   └─ 跳过阶段8（历史评估），仅返回拟合质量指标
   ↓
IF can_evaluate = True:
   └─ 进入阶段1（数据提取），阶段8将执行历史评估
```

**时间窗口季节性考虑**：

> **⚠️ 当前限制**：75%/25%的简单时间划分**不考虑季节性因素**。

| 场景 | 问题 | 影响 | 建议 |
|------|------|------|------|
| **夏季高负荷** | 夏季用水量大，泵运行工况不同 | 拟合曲线可能偏向夏季工况 | 未来可考虑季节性加权 |
| **冬季低负荷** | 冬季用水量小，数据点稀疏 | 测试窗口可能落在低负荷期 | 未来可考虑分季节拟合 |
| **节假日异常** | 节假日用水模式异常 | 可能引入噪声数据 | 可考虑节假日数据过滤 |

**当前策略**：
- 使用简单的75%/25%时间划分
- 不区分季节或工况
- 适用于全年运行模式相对稳定的泵站

**阶段7详细说明（约束优化触发）**：

```
阶段7: 验证 [Validator]
   ├─ 验证拟合结果
   ├─ IF 验证失败:
   │   ├─ 记录失败原因
   │   ├─ 记录警告：建议检查约束参数学习结果
   │   └─ 不自动放宽约束（实事求是原则）
```

### 1.4.4 约束违反处理策略

> **重要**：约束违反不一定导致拟合失败，需要根据违反类型和严重程度决定处理方式。

#### 约束类型与处理方式

| 约束类型 | 违反示例 | 处理方式 | 结果标记 |
|---------|---------|---------|---------|
| **单调性约束** | Q-H曲线局部递增 | 记录违反区间，继续拟合 | `monotonicity_violation: true` |
| **边界约束** | H(0) < 0 或 H(Q_max) < 0 | 调整边界参数后重试 | `boundary_adjusted: true` |
| **物理约束** | 效率 > 1.0 | 截断到合理范围 | `physics_truncated: true` |
| **数据范围约束** | Q > 1.2 * Q_rated | 过滤超范围数据 | `data_filtered: true` |

#### 约束违反处理代码示例

```python
def handle_constraint_violation(
    self,
    violation: ConstraintViolationError,
    fit_result: FitResult
) -> FitResult:
    """
    处理约束违反

    Args:
        violation: 约束违反异常
        fit_result: 当前拟合结果

    Returns:
        FitResult: 处理后的拟合结果（可能带有警告标记）
    """
    # 记录违反详情
    self._logger.warning(
        f"约束违反: {violation.violated_constraints}",
        extra={"extra_data": {
            "device_id": violation.device_id,
            "curve_type": violation.curve_type,
            "violated_constraints": violation.violated_constraints
        }}
    )

    # 根据违反类型处理
    for constraint in violation.violated_constraints:
        if constraint['type'] == 'monotonicity':
            # 单调性违反：标记但不中断
            fit_result.warnings.append(f"单调性违反: {constraint['details']}")
            fit_result.confidence = 'low'
        elif constraint['type'] == 'boundary':
            # 边界违反：尝试调整
            fit_result = self._adjust_boundary(fit_result, constraint)
        elif constraint['type'] == 'physics':
            # 物理违反：截断到合理范围
            fit_result = self._truncate_physics(fit_result, constraint)

    return fit_result
```

### 1.4.5 批处理重试策略

> **重要**：批处理操作（如数据库写入、大数据量处理）需要完善的重试机制。

#### 重试配置参数

| 参数名称 | 默认值 | 说明 | 存储位置 |
|---------|--------|------|---------|
| `max_retries` | 3 | 最大重试次数 | `method_params.performance.max_retries` |
| `retry_delay_seconds` | 1.0 | 重试间隔（秒） | `method_params.performance.retry_delay_seconds` |
| `retry_backoff_factor` | 2.0 | 退避因子（指数退避） | `method_params.performance.retry_backoff_factor` |
| `retry_max_delay_seconds` | 30.0 | 最大重试间隔 | `method_params.performance.retry_max_delay_seconds` |

#### 可重试的异常类型

| 异常类型 | 是否重试 | 原因 |
|---------|---------|------|
| `DatabaseError` | ✅ | 可能是临时连接问题 |
| `TimeoutError` | ✅ | 可能是临时负载问题 |
| `ConnectionError` | ✅ | 可能是网络抖动 |
| `ParameterMissingError` | ❌ | 配置问题，重试无意义 |
| `DataNotFoundError` | ❌ | 数据不存在，重试无意义 |

#### 重试机制代码示例

```python
import time
from functools import wraps

def with_retry(max_retries: int = 3, delay: float = 1.0, backoff: float = 2.0):
    """重试装饰器"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            last_exception = None
            current_delay = delay

            for attempt in range(max_retries + 1):
                try:
                    return func(*args, **kwargs)
                except (DatabaseError, TimeoutError, ConnectionError) as e:
                    last_exception = e
                    if attempt < max_retries:
                        logger.warning(
                            f"操作失败，{current_delay}秒后重试 ({attempt + 1}/{max_retries})",
                            extra={"extra_data": {"error": str(e)}}
                        )
                        time.sleep(current_delay)
                        current_delay = min(current_delay * backoff, 30.0)
                    else:
                        logger.error(f"操作失败，已达最大重试次数: {e}")
                        raise

            raise last_exception
        return wrapper
    return decorator

# 使用示例
class BatchProcessor:
    @with_retry(max_retries=3, delay=1.0, backoff=2.0)
    def save_batch(self, batch_data):
        """保存批次数据（带重试）"""
        # 数据库操作
        pass
```

**核心职责**：

2. 管理子模块的依赖注入
3. 提供通用工具方法
4. 定义抽象方法接口

#### 2.1.2 核心接口

```python
from abc import ABC, abstractmethod
from typing import Dict, Any, Optional, List
from datetime import datetime
import pandas as pd
import logging

class BaseCurve(ABC):
    """曲线基类 - 所有曲线模块的抽象基类"""
    
    # 曲线类型（子类必须定义）
    curve_type: str = None
    
    # 物理约束类型
    monotonicity: str = None  # 'increasing', 'decreasing', 'unimodal'
    
    # 推荐方法
    recommended_methods: List[str] = []
    
    def __init__(
        self,
        storage: 'ResultStorage',
        cache: 'CacheManager',
        batch_processor: 'BatchProcessor',
        parameter_optimizer: 'ParameterOptimizer',
        historical_evaluator: 'HistoricalDataEvaluator'
    ):
        """
        初始化曲线模块（依赖注入）
        
        Args:
            storage: 结果存储器
            cache: 缓存管理器
            batch_processor: 批处理器
            parameter_optimizer: 参数优化器
            historical_evaluator: 历史数据评估器
        """
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")
        self._storage = storage
        self._cache = cache
        self._batch_processor = batch_processor
        self._parameter_optimizer = parameter_optimizer
        self._historical_evaluator = historical_evaluator
        
        # 初始化子模块（子类实现）
        self._init_submodules()

    @abstractmethod
    def _init_submodules(self) -> None:
        """初始化子模块（由子类实现）"""
        pass

    @abstractmethod
    def extract_data(
        self,
        device_id: int,
        start_time: datetime,
        end_time: datetime
    ) -> pd.DataFrame:
        """
        提取数据（由子类实现）

        Args:
            device_id: 设备ID
            start_time: 开始时间
            end_time: 结束时间

        Returns:
            DataFrame: 提取的原始数据
        """
        pass

    @abstractmethod
    def preprocess(self, data: pd.DataFrame) -> pd.DataFrame:
        """
        预处理数据（由子类实现）

        Args:
            data: 原始数据

        Returns:
            DataFrame: 预处理后的数据
        """
        pass

    @abstractmethod
    def calculate_constraints(
        self,
        data: pd.DataFrame,
        device_params: Dict[str, Any]
    ) -> Dict[str, Any]:
        """
        计算物理约束参数（由子类实现）

        Args:
            data: 预处理后的数据
            device_params: 设备参数

        Returns:
            Dict: 约束参数
        """
        pass

    def fit(
        self,
        device_id: int,
        start_time: datetime,
        end_time: datetime,
        methods: Optional[List[str]] = None,
        device_params: Optional[Dict[str, Any]] = None
    ) -> 'FitResult':
        """
        执行拟合（模板方法）

        Args:
            device_id: 设备ID
            start_time: 开始时间
            end_time: 结束时间
            methods: 指定方法列表（可选）
            device_params: 设备参数（可选）

        Returns:
            FitResult: 拟合结果
        """
        self._logger.info(
            f"开始拟合: device_id={device_id}, curve_type={self.curve_type}",
            extra={"extra_data": {
                "设备ID": device_id,
                "曲线类型": self.curve_type,
                "开始时间": str(start_time),
                "结束时间": str(end_time)
            }}
        )

        # 阶段1: 数据提取
        raw_data = self.extract_data(device_id, start_time, end_time)

        # 阶段2: 数据预处理
        clean_data = self.preprocess(raw_data)

        # 阶段3: 计算约束参数
        constraints = self.calculate_constraints(clean_data, device_params or {})

        # 阶段4: 归一化
        normalized_data, norm_params = self._normalizer.normalize(clean_data)

        # 阶段5: 方法选择
        selected_methods = methods or self._method_selector.select(
            data=normalized_data,
            constraints=constraints
        )

        # 阶段6: 拟合
        fit_result = self._fitter.fit(
            data=normalized_data,
            methods=selected_methods,
            constraints=constraints
        )

        # 阶段7: 验证
        validation_result = self._validator.validate(
            fit_result=fit_result,
            original_data=clean_data,
            constraints=constraints
        )

        # 阶段8: 历史评估
        evaluation = self._historical_evaluator.evaluate(
            device_id=device_id,
            curve_type=self.curve_type,
            current_result=fit_result
        )

        # 阶段9: 存储
        version = self._storage.save(
            device_id=device_id,
            curve_type=self.curve_type,
            fit_result=fit_result,
            validation_result=validation_result,
            evaluation=evaluation
        )

        self._logger.info(
            f"拟合完成: version={version}",
            extra={"extra_data": {
                "设备ID": device_id,
                "曲线类型": self.curve_type,
                "版本号": version,
                "最佳方法": fit_result.best_method,
                "R²": fit_result.metrics.get('r_squared')
            }}
        )

        return fit_result

    def predict(self, x: float, version: Optional[str] = None) -> float:
        """
        预测Y值

        Args:
            x: X值
            version: 版本号（可选，默认最新）

        Returns:
            float: 预测的Y值
        """
        pass

    def get_latest_result(self, device_id: int) -> Optional['FitResult']:
        """
        获取最新拟合结果

        Args:
            device_id: 设备ID

        Returns:
            FitResult: 最新拟合结果
        """
        return self._storage.load_latest(device_id, self.curve_type)
```

#### 3.3.2 BasePreprocessor（预处理基类）

```python
from typing import Dict, Any, Optional, Tuple, List
from abc import ABC, abstractmethod
import pandas as pd
import numpy as np
import logging

class BasePreprocessor(ABC):
    """
    🟢-08修复：预处理器基类

    提取公共的异常值检测逻辑，减少QHPreprocessor/QPPreprocessor/QEtaPreprocessor的代码重复。
    """

    # 🟢-03修复：将魔法数字提取为类常量（子类可覆盖）
    SIGMA_MULTIPLIER = 3.0
    IQR_MULTIPLIER = 1.5
    PHYSICS_UPPER_RATIO = 1.3
    PHYSICS_LOWER_RATIO = 0.5

    def __init__(self):
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

    @abstractmethod
    def get_column_names(self) -> Tuple[str, str]:
        """返回X和Y列名，子类实现"""
        pass

    @abstractmethod
    def get_physics_constraints(self, rated_params: Dict[str, float]) -> Dict[str, Tuple[float, float]]:
        """返回物理约束范围，子类实现"""
        pass

    def remove_outliers(
        self,
        data: pd.DataFrame,
        method: str = 'physics',
        rated_params: Optional[Dict[str, float]] = None
    ) -> pd.DataFrame:
        """
        🟢-08修复：统一的异常值删除方法

        Args:
            data: 输入数据
            method: 方法 ('physics', '3sigma', 'iqr')
            rated_params: 额定参数

        Returns:
            pd.DataFrame: 过滤后的数据
        """
        if method == 'physics':
            return self._remove_outliers_physics(data, rated_params)
        elif method == '3sigma':
            return self._remove_outliers_3sigma(data)
        elif method == 'iqr':
            return self._remove_outliers_iqr(data)
        else:
            raise ValueError(f"未知的异常值检测方法: {method}")

    def _remove_outliers_3sigma(self, data: pd.DataFrame) -> pd.DataFrame:
        """使用3σ原则删除异常值"""
        x_col, y_col = self.get_column_names()
        sigma = self.SIGMA_MULTIPLIER

        x_mean, x_std = data[x_col].mean(), data[x_col].std()
        y_mean, y_std = data[y_col].mean(), data[y_col].std()

        mask = (
            (data[x_col] >= x_mean - sigma*x_std) & (data[x_col] <= x_mean + sigma*x_std) &
            (data[y_col] >= y_mean - sigma*y_std) & (data[y_col] <= y_mean + sigma*y_std)
        )
        return data[mask]

    def _remove_outliers_iqr(self, data: pd.DataFrame) -> pd.DataFrame:
        """使用IQR方法删除异常值"""
        x_col, y_col = self.get_column_names()
        k = self.IQR_MULTIPLIER

        Q1_x, Q3_x = data[x_col].quantile(0.25), data[x_col].quantile(0.75)
        IQR_x = Q3_x - Q1_x

        Q1_y, Q3_y = data[y_col].quantile(0.25), data[y_col].quantile(0.75)
        IQR_y = Q3_y - Q1_y

        mask = (
            (data[x_col] >= Q1_x - k*IQR_x) & (data[x_col] <= Q3_x + k*IQR_x) &
            (data[y_col] >= Q1_y - k*IQR_y) & (data[y_col] <= Q3_y + k*IQR_y)
        )
        return data[mask]

    def _remove_outliers_physics(
        self,
        data: pd.DataFrame,
        rated_params: Optional[Dict[str, float]]
    ) -> pd.DataFrame:
        """使用物理约束删除异常值"""
        if rated_params is None:
            self._logger.warning("[预处理] physics方法需要额定参数，回退到IQR")
            return self._remove_outliers_iqr(data)

        x_col, y_col = self.get_column_names()
        constraints = self.get_physics_constraints(rated_params)

        x_min, x_max = constraints.get(x_col, (0, float('inf')))
        y_min, y_max = constraints.get(y_col, (0, float('inf')))

        mask = (
            (data[x_col] >= x_min) & (data[x_col] <= x_max) &
            (data[y_col] >= y_min) & (data[y_col] <= y_max)
        )
        return data[mask]
```

```python
from typing import Dict, Any, Optional, Tuple
import pandas as pd
import numpy as np
import logging

class QHPreprocessor(BasePreprocessor):
    """Q-H曲线数据预处理器（🟢-08修复：继承自BasePreprocessor）"""

    # 🟢-03修复：将魔法数字提取为类常量（覆盖基类常量）
    PHYSICS_FLOW_UPPER_RATIO = 1.3  # 物理约束：流量上限为额定的1.3倍
    PHYSICS_HEAD_LOWER_RATIO = 0.5  # 物理约束：扬程下限为额定的0.5倍
    PHYSICS_HEAD_UPPER_RATIO = 1.3  # 物理约束：扬程上限为额定的1.3倍

    def __init__(self):
        """初始化预处理器"""
        super().__init__()  # 🟢-08修复：调用基类构造函数

    def get_column_names(self) -> Tuple[str, str]:
        """🟢-08修复：实现基类抽象方法"""
        return ('Q', 'H')

    def get_physics_constraints(self, rated_params: Dict[str, float]) -> Dict[str, Tuple[float, float]]:
        """🟢-08修复：实现基类抽象方法"""
        rated_flow = rated_params.get('rated_flow', rated_params.get('Q_rated'))
        rated_head = rated_params.get('rated_head', rated_params.get('H_rated'))

        return {
            'Q': (0, rated_flow * self.PHYSICS_FLOW_UPPER_RATIO if rated_flow else float('inf')),
            'H': (
                rated_head * self.PHYSICS_HEAD_LOWER_RATIO if rated_head else 0,
                rated_head * self.PHYSICS_HEAD_UPPER_RATIO if rated_head else float('inf')
            )
        }

    def preprocess(
        self,
        data: pd.DataFrame,
        outlier_method: str = 'physics',  # 🟡-05修复：默认改为物理约束法
        min_Q: float = 0.0,
        min_H: float = 0.0,
        rated_params: Optional[Dict[str, float]] = None  # 🟡-05修复：添加额定参数
    ) -> Tuple[pd.DataFrame, Dict[str, Any]]:
        """
        预处理Q-H数据

        Args:
            data: 原始数据
            outlier_method: 异常值检测方法
                - 'physics': 基于物理约束（推荐，需要rated_params）🟡-05修复
                - '3sigma': 3σ原则（不推荐，对偏态分布不适用）
                - 'iqr': 四分位距法
                - 'isolation_forest': 孤立森林
            min_Q: 最小流量阈值
            min_H: 最小扬程阈值
            rated_params: 额定参数字典（physics方法必需）
                - rated_flow: 额定流量
                - rated_head: 额定扬程

        Returns:
            Tuple[DataFrame, Dict]: 清洗后的数据和清洗报告

        🟡-05修复说明:
            3σ原则假设数据服从正态分布，但流量数据通常右偏，
            可能误删大流量正常点。推荐使用physics方法，
            基于额定参数的物理范围进行过滤。
        """
        original_count = len(data)
        report = {'original_count': original_count}

        # 步骤1: 删除无效值
        data = data[(data['Q'] >= min_Q) & (data['H'] >= min_H)].copy()
        report['after_invalid_removal'] = len(data)

        # 步骤2: 删除异常值（🟢-08修复：使用基类统一方法）
        if outlier_method == '3sigma':
            # ⚠️ 警告：3σ对偏态分布不适用，可能误删大流量正常点
            self._logger.warning(
                "[预处理] 使用3σ方法，对偏态分布可能不适用",
                extra={"extra_data": {"建议": "使用physics方法"}}
            )
        data = self.remove_outliers(data, method=outlier_method, rated_params=rated_params)
        report['after_outlier_removal'] = len(data)

        # 步骤3: 删除重复值
        data = data.drop_duplicates(subset=['Q', 'H'])
        report['after_duplicate_removal'] = len(data)

        # 步骤4: 运行点筛选（只保留泵运行状态的数据）
        # Q > 0 表示泵在运行
        data = data[data['Q'] > 0]
        report['after_running_filter'] = len(data)

        report['final_count'] = len(data)
        report['retention_rate'] = len(data) / original_count if original_count > 0 else 0

        self._logger.info(
            f"数据预处理完成: {original_count} -> {len(data)}",
            extra={"extra_data": {
                "曲线类型": "qh",
                "原始数据量": original_count,
                "最终数据量": len(data),
                "保留率": f"{report['retention_rate']:.2%}"
            }}
        )

        return data, report

    # 🟢-08修复：异常值检测方法已移至BasePreprocessor基类
    # _remove_outliers_3sigma, _remove_outliers_iqr, _remove_outliers_physics
    # 现在通过 self.remove_outliers(data, method, rated_params) 统一调用
```

#### 3.3.3 QHConstraints（物理约束）

```python
from typing import Dict, Any, Optional
import pandas as pd
import numpy as np
import logging

class QHConstraints:
    """Q-H曲线物理约束计算器"""

    def __init__(self):
        """初始化约束计算器"""
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

    def calculate(
        self,
        data: pd.DataFrame,
        device_params: Dict[str, Any]
    ) -> Dict[str, Any]:
        """
        计算Q-H曲线的物理约束参数

        Args:
            data: 预处理后的数据
            device_params: 设备参数（包含Q_rated, H_rated等）

        Returns:
            Dict: 约束参数
        """
        Q = data['Q'].values
        H = data['H'].values

        # 从device_params中获取额定参数（应该已通过DeviceRatedParamsReader读取）
        if 'Q_rated' not in device_params or 'H_rated' not in device_params:
            missing_params = [p for p in ['Q_rated', 'H_rated'] if p not in device_params]
            raise ValueError(
                f"设备额定参数缺失，无法计算Q-H约束. "
                f"缺失参数: {missing_params}. "
                f"请确保已从device_rated_params表读取额定参数。"
            )
        Q_rated = device_params['Q_rated']
        H_rated = device_params['H_rated']

        # 计算H₀（零流量扬程）
        H0 = self._calculate_H0(Q, H, H_rated)

        # 计算Q_max（最大流量）
        Q_max = Q_rated * 1.2

        # 计算K（阻力系数）
        K = (H0 - H_rated) / (Q_rated ** 2) if Q_rated > 0 else 0

        # 验证单调性
        monotonicity = self._verify_monotonicity(Q, H)

        # 验证凸性
        convexity = self._verify_convexity(Q, H)

        constraints = {
            'H0': H0,
            'Q_max': Q_max,
            'K': K,
            'Q_rated': Q_rated,
            'H_rated': H_rated,
            'monotonicity': monotonicity,
            'convexity': convexity,
            'curve_type': 'qh',
            'expected_monotonicity': 'decreasing'
        }

        self._logger.info(
            f"约束参数计算完成",
            extra={"extra_data": {
                "曲线类型": "qh",
                "H0": f"{H0:.2f} m",
                "Q_max": f"{Q_max:.2f} m³/h",
                "K": f"{K:.6f}",
                "单调性验证": "通过" if monotonicity['is_valid'] else "失败"
            }}
        )

        return constraints

    def _calculate_H0(
        self,
        Q: np.ndarray,
        H: np.ndarray,
        H_rated: float
    ) -> float:
        """计算零流量扬程H₀"""
        # 方法1: 使用Q→0附近的数据外推
        mask = Q < 0.1 * Q.max()
        if mask.sum() >= 3:
            # 使用低流量数据拟合线性外推
            Q_low = Q[mask]
            H_low = H[mask]
            coeffs = np.polyfit(Q_low, H_low, 1)
            H0_extrapolated = coeffs[1]  # 截距

            # 验证合理性
            if 0.8 * H_rated < H0_extrapolated < 1.5 * H_rated:
                return H0_extrapolated

        # 方法2: 使用额定参数估算
        return H_rated * 1.1

    def _verify_monotonicity(
        self,
        Q: np.ndarray,
        H: np.ndarray
    ) -> Dict[str, Any]:
        """验证单调递减性"""
        # 按Q排序
        sorted_indices = np.argsort(Q)
        Q_sorted = Q[sorted_indices]
        H_sorted = H[sorted_indices]

        # 计算梯度
        dH = np.diff(H_sorted)
        dQ = np.diff(Q_sorted)

        # 避免除以零
        valid_mask = dQ > 0
        gradients = np.zeros_like(dH)
        gradients[valid_mask] = dH[valid_mask] / dQ[valid_mask]

        # 检查单调递减
        decreasing_count = np.sum(gradients < 0)
        total_count = len(gradients)
        ratio = decreasing_count / total_count if total_count > 0 else 0

        return {
            'is_valid': ratio > 0.95,
            'ratio': ratio,
            'expected': 'decreasing',
            'violations': total_count - decreasing_count
        }

    def _verify_convexity(
        self,
        Q: np.ndarray,
        H: np.ndarray
    ) -> Dict[str, Any]:
        """验证凸性（d²H/dQ² > 0）"""
        # 按Q排序
        sorted_indices = np.argsort(Q)
        Q_sorted = Q[sorted_indices]
        H_sorted = H[sorted_indices]

        # 拟合二次多项式
        coeffs = np.polyfit(Q_sorted, H_sorted, 2)
        a2 = coeffs[0]  # 二次项系数

        # d²H/dQ² = 2*a2，凸函数要求 a2 > 0
        is_convex = a2 > 0

        return {
            'is_valid': is_convex,
            'a2': a2,
            'curvature': 2 * a2
        }
```

```python
            missing_params = [p for p in ['Q_rated', 'H_rated'] if p not in constraints]
            raise ValueError(
                f"归一化失败：约束参数中缺少额定值. "
                f"缺失参数: {missing_params}. "
                f"请确保已从device_rated_params表读取额定参数并传入约束参数。"
            )
        Q_rated = constraints['Q_rated']
        H_rated = constraints['H_rated']

        normalized_data = data.copy()
        normalized_data['Q_norm'] = data['Q'] / Q_rated
        normalized_data['H_norm'] = data['H'] / H_rated

        norm_params = {
            'Q_scale': Q_rated,
            'H_scale': H_rated,
            'Q_min': data['Q'].min(),
            'Q_max': data['Q'].max(),
            'H_min': data['H'].min(),
            'H_max': data['H'].max()
        }

        self._logger.debug(
            f"归一化完成: Q_scale={Q_rated:.2f}, H_scale={H_rated:.2f}"
        )

        return normalized_data, norm_params

    def denormalize(
        self,
        Q_norm: float,
        H_norm: float,
        norm_params: Dict[str, float]
    ) -> Tuple[float, float]:
        """
        反归一化

        Args:
            Q_norm: 归一化的Q值
            H_norm: 归一化的H值
            norm_params: 归一化参数

        Returns:
            Tuple[float, float]: 原始的Q和H值
        """
        Q = Q_norm * norm_params['Q_scale']
        H = H_norm * norm_params['H_scale']
        return Q, H
```

#### 3.3.5 QHCurveFitter（拟合器）

```python
from typing import Dict, Any, List, Optional
import pandas as pd
import numpy as np
import logging
from concurrent.futures import ThreadPoolExecutor, as_completed

class QHCurveFitter:
    """Q-H曲线拟合器"""

    def __init__(
        self,
        method_registry: 'MethodRegistry',
        parallel_executor: Optional[ThreadPoolExecutor] = None
    ):
        """
        初始化拟合器

        Args:
            method_registry: 方法注册表
            parallel_executor: 并行执行器（可选）
        """
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")
        self._registry = method_registry
        self._executor = parallel_executor or ThreadPoolExecutor(max_workers=4)

    def fit(
        self,
        data: pd.DataFrame,
        methods: List[str],
        constraints: Dict[str, Any]
    ) -> 'FitResult':
        """
        执行拟合

        Args:
            data: 归一化后的数据
            methods: 方法ID列表
            constraints: 约束参数

        Returns:
            FitResult: 拟合结果
        """
        self._logger.info(
            f"开始拟合: {len(methods)}种方法",
            extra={"extra_data": {
                "曲线类型": "qh",
                "方法列表": methods,
                "数据量": len(data)
            }}
        )

        X = data['Q_norm'].values
        y = data['H_norm'].values

        # 并行执行所有方法
        futures = {}
        for method_id in methods:
            method = self._registry.get(method_id)
            if method:
                future = self._executor.submit(
                    self._fit_single_method,
                    method, X, y, constraints
                )
                futures[future] = method_id

        # 收集结果
        all_results = {}
        for future in as_completed(futures):
            method_id = futures[future]
            try:
                result = future.result()
                all_results[method_id] = result
                self._logger.debug(
                    f"方法 {method_id} 拟合完成: R²={result.metrics.get('r_squared', 0):.4f}"
                )
            except Exception as e:
                self._logger.warning(f"方法 {method_id} 拟合失败: {e}")
                all_results[method_id] = None

        # 选择最佳方法
        best_method, best_result = self._select_best(all_results, constraints)

        fit_result = FitResult(
            curve_type='qh',
            best_method=best_method,
            coefficients=best_result.coefficients if best_result else {},
            metrics=best_result.metrics if best_result else {},
            all_results=all_results,
            constraints=constraints
        )

        self._logger.info(
            f"拟合完成: 最佳方法={best_method}",
            extra={"extra_data": {
                "曲线类型": "qh",
                "最佳方法": best_method,
                "R²": fit_result.metrics.get('r_squared'),
                "RMSE": fit_result.metrics.get('rmse')
            }}
        )

        return fit_result

    def _fit_single_method(
        self,
        method: 'BaseMethod',
        X: np.ndarray,
        y: np.ndarray,
        constraints: Dict[str, Any]
    ) -> 'MethodResult':
        """执行单个方法的拟合"""
        return method.fit(X, y, constraints=constraints)

    def _select_best(
        self,
        all_results: Dict[str, 'MethodResult'],
        constraints: Dict[str, Any]
    ) -> Tuple[str, 'MethodResult']:
        """选择最佳方法"""
        best_method = None
        best_score = -float('inf')
        best_result = None

        for method_id, result in all_results.items():
            if result is None:
                continue

            # 计算综合评分
            # 从拟合结果中获取指标（某些方法可能不计算所有指标，使用默认值是合理的）
            r_squared = result.metrics.get('r_squared', 0)
            rmse = result.metrics.get('rmse', float('inf'))
            constraint_score = self._evaluate_constraint_satisfaction(
                result, constraints
            )

            # 综合评分 = 0.5*R² + 0.3*(1-RMSE/10) + 0.2*约束满足度
            score = 0.5 * r_squared + 0.3 * max(0, 1 - rmse/10) + 0.2 * constraint_score

            if score > best_score:
                best_score = score
                best_method = method_id
                best_result = result

        return best_method, best_result

    def _evaluate_constraint_satisfaction(
        self,
        result: 'MethodResult',
        constraints: Dict[str, Any]
    ) -> float:
        """评估约束满足度"""
        # 检查单调性
        monotonicity_score = 1.0 if result.is_monotonic_decreasing else 0.5

        # 检查边界条件
        boundary_score = 1.0

        return (monotonicity_score + boundary_score) / 2
```

#### 3.3.6 QHValidator（验证器）

```python
from typing import Dict, Any, List
import pandas as pd
import numpy as np
import logging

class QHValidator:
    """Q-H曲线验证器"""

    # 必需的验证阈值参数列表（必须从数据库读取，禁止硬编码默认值）
    REQUIRED_THRESHOLDS = [
        'r_squared_min',          # R² 最小阈值
        'rmse_max',               # RMSE 最大阈值（单位：m）
        'monotonicity_ratio_min', # 单调性比例最小阈值
        'boundary_deviation_max'  # 边界偏差最大阈值
    ]

    def __init__(self, thresholds: Dict[str, float]):
        """
        初始化验证器

        Args:
            thresholds: 验证阈值（必须从数据库 method_params JSONB 读取）
                        必需的键：r_squared_min, rmse_max, monotonicity_ratio_min, boundary_deviation_max

        Raises:
            ValueError: 如果缺失必需的阈值参数
        """
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

        # 验证必需参数是否存在（禁止使用默认值）
        missing_params = [p for p in self.REQUIRED_THRESHOLDS if p not in thresholds]
        if missing_params:
            self._logger.error(
                "[验证器] 缺失必需的验证阈值参数",
                extra={"extra_data": {
                    "组件": "QHValidator",
                    "缺失参数": missing_params,
                    "影响": "无法执行验证，拟合流程中止",
                    "解决方案": "请在数据库 method_params JSONB 字段中配置这些参数"
                }}
            )
            raise ValueError(f"数据库中缺失必需的验证阈值参数: {missing_params}")

        self._thresholds = thresholds

    def validate(
        self,
        fit_result: 'FitResult',
        original_data: pd.DataFrame,
        constraints: Dict[str, Any]
    ) -> 'ValidationResult':
        """
        验证拟合结果

        Args:
            fit_result: 拟合结果
            original_data: 原始数据
            constraints: 约束参数

        Returns:
            ValidationResult: 验证结果
        """
        issues = []
        warnings = []
        scores = {}

        # 1. 精度验证（使用数据库阈值或默认值）
        # 从拟合结果中获取指标（某些方法可能不计算所有指标，使用默认值是合理的）
        r_squared = fit_result.metrics.get('r_squared', 0)
        if r_squared < self._thresholds['r_squared_min']:
            issues.append(f"R²={r_squared:.4f} < {self._thresholds['r_squared_min']}")
        scores['r_squared'] = r_squared

        rmse = fit_result.metrics.get('rmse', float('inf'))
        if rmse > self._thresholds['rmse_max']:
            warnings.append(f"RMSE={rmse:.4f}m > {self._thresholds['rmse_max']}m")
        scores['rmse'] = rmse

        # 2. 单调性验证
        monotonicity = self._verify_monotonicity(fit_result, original_data)
        if not monotonicity['is_valid']:
            issues.append(f"单调性验证失败: {monotonicity['ratio']:.2%}")
        scores['monotonicity'] = monotonicity['ratio']

        # 3. 边界条件验证
        boundary = self._verify_boundary_conditions(fit_result, constraints)
        if not boundary['H0_valid']:
            warnings.append(f"H₀偏差过大: {boundary['H0_deviation']:.2%}")
        scores['boundary'] = 1.0 if boundary['is_valid'] else 0.5

        # 4. 凸性验证
        convexity = self._verify_convexity(fit_result)
        if not convexity['is_valid']:
            warnings.append(f"凸性验证失败")
        scores['convexity'] = 1.0 if convexity['is_valid'] else 0.5

        # 综合判断
        is_valid = len(issues) == 0

        result = ValidationResult(
            is_valid=is_valid,
            issues=issues,
            warnings=warnings,
            scores=scores
        )

        self._logger.info(
            f"验证完成: {'通过' if is_valid else '失败'}",
            extra={"extra_data": {
                "曲线类型": "qh",
                "验证结果": "通过" if is_valid else "失败",
                "问题数": len(issues),
                "警告数": len(warnings),
                "R²": r_squared
            }}
        )

        return result

    def _verify_monotonicity(
        self,
        fit_result: 'FitResult',
        original_data: pd.DataFrame
    ) -> Dict[str, Any]:
        """验证单调递减性"""
        Q = original_data['Q'].values
        Q_sorted = np.sort(Q)

        # 使用拟合函数计算预测值
        H_pred = fit_result.predict(Q_sorted)

        # 计算梯度
        dH = np.diff(H_pred)
        decreasing_count = np.sum(dH < 0)
        ratio = decreasing_count / len(dH) if len(dH) > 0 else 0

        return {
            'is_valid': ratio >= self._thresholds['monotonicity_ratio_min'],
            'ratio': ratio,
            'violations': len(dH) - decreasing_count
        }

    def _verify_boundary_conditions(
        self,
        fit_result: 'FitResult',
        constraints: Dict[str, Any]
    ) -> Dict[str, Any]:
        """验证边界条件"""
        # H0应该在约束参数中（从device_rated_params计算得出）
        if 'H0' not in constraints:
            raise ValueError(
                f"边界验证失败：约束参数中缺少H0. "
                f"请确保约束计算器已正确计算H0参数。"
            )
        H0_expected = constraints['H0']

        # 预测Q=0时的H值
        H0_predicted = fit_result.predict(0)

        # 计算偏差
        H0_deviation = abs(H0_predicted - H0_expected) / H0_expected if H0_expected > 0 else 0
        H0_valid = H0_deviation <= self._thresholds['boundary_deviation_max']

        # 预测Q_max时H>0
        if 'Q_max' not in constraints:
            raise ValueError(
                f"边界验证失败：约束参数中缺少Q_max. "
                f"请确保约束计算器已正确计算Q_max参数。"
            )
        Q_max = constraints['Q_max']
        H_max_predicted = fit_result.predict(Q_max)
        H_max_valid = H_max_predicted > 0

        return {
            'is_valid': H0_valid and H_max_valid,
            'H0_valid': H0_valid,
            'H0_deviation': H0_deviation,
            'H_max_valid': H_max_valid,
            'H_max_predicted': H_max_predicted
        }

    def _verify_convexity(
        self,
        fit_result: 'FitResult'
    ) -> Dict[str, Any]:
        """验证凸性"""
        coefficients = fit_result.coefficients

        # 对于多项式: H = a0 + a1*Q + a2*Q²
        # 凸性要求 a2 > 0
        # 如果不是多项式方法，跳过凸性检查
        if 'a2' not in coefficients:
            return {
                'is_valid': True,
                'message': '非多项式方法，跳过凸性检查'
            }

        a2 = coefficients['a2']

        return {
            'is_valid': a2 > 0,
            'a2': a2
        }
```

```python
class QPDataExtractor:

    """

    def extract(

            end_time: 结束时间
            min_points: 最小数据点数

        Returns:
            DataFrame: 包含ts_bucket, Q, P列的数据
        """
        self._logger.info(

            extra={"extra_data": {
                "设备ID": device_id,
                "曲线类型": "qp",
                "开始时间": str(start_time),
                "结束时间": str(end_time)
            }}
        )

        # 使用 get_connection() 上下文管理器获取连接
        sql = """
            SELECT
                ts_bucket,
                MAX(CASE WHEN metric_id = (
                    SELECT id FROM dim_metric_config
                    WHERE metric_key = 'pump_flow_rate'
                ) THEN value END) AS Q,
                MAX(CASE WHEN metric_id = (
                    SELECT id FROM dim_metric_config
                    WHERE metric_key = 'pump_active_power'
                ) THEN value END) AS P
            FROM fact_measurements
            WHERE device_id = %(device_id)s
              AND ts_bucket BETWEEN %(start_time)s AND %(end_time)s
              AND metric_id IN (
                  SELECT id FROM dim_metric_config
                  WHERE metric_key IN ('pump_flow_rate', 'pump_active_power')
              )
            GROUP BY ts_bucket
            HAVING MAX(CASE WHEN metric_id = (
                SELECT id FROM dim_metric_config
                WHERE metric_key = 'pump_flow_rate'
            ) THEN value END) IS NOT NULL
               AND MAX(CASE WHEN metric_id = (
                SELECT id FROM dim_metric_config
                WHERE metric_key = 'pump_active_power'
            ) THEN value END) IS NOT NULL
            ORDER BY ts_bucket
        """

        with get_connection() as conn:
            with conn.cursor() as cursor:
                cursor.execute(sql, {
                    'device_id': device_id,
                    'start_time': start_time,
                    'end_time': end_time
                })
                rows = cursor.fetchall()
                columns = [desc[0] for desc in cursor.description]

        data = pd.DataFrame(rows, columns=columns)

        self._logger.info(
            f"数据提取完成: {len(data)}条记录",
            extra={"extra_data": {
                "设备ID": device_id,
                "曲线类型": "qp",
                "数据量": len(data)
            }}
        )

        return data
```

#### 4.3.2 QPPreprocessor（预处理器）

```python
from typing import Dict, Any, Tuple
import pandas as pd
import numpy as np
import logging

class QPPreprocessor:
    """Q-P曲线数据预处理器"""

    def __init__(self):
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

    def preprocess(
        self,
        data: pd.DataFrame,
        outlier_method: str = '3sigma',
        min_Q: float = 0.0,
        min_P: float = 0.0
    ) -> Tuple[pd.DataFrame, Dict[str, Any]]:
        """
        预处理Q-P数据

        Args:
            data: 原始数据
            outlier_method: 异常值检测方法
            min_Q: 最小流量阈值
            min_P: 最小功率阈值

        Returns:
            Tuple[DataFrame, Dict]: 清洗后的数据和清洗报告
        """
        original_count = len(data)
        report = {'original_count': original_count}

        # 步骤1: 删除无效值
        data = data[(data['Q'] >= min_Q) & (data['P'] >= min_P)].copy()
        report['after_invalid_removal'] = len(data)

        # 步骤2: 删除异常值
        if outlier_method == '3sigma':
            Q_mean, Q_std = data['Q'].mean(), data['Q'].std()
            P_mean, P_std = data['P'].mean(), data['P'].std()
            data = data[
                (data['Q'] >= Q_mean - 3*Q_std) & (data['Q'] <= Q_mean + 3*Q_std) &
                (data['P'] >= P_mean - 3*P_std) & (data['P'] <= P_mean + 3*P_std)
            ]
        report['after_outlier_removal'] = len(data)

        # 步骤3: 删除重复值
        data = data.drop_duplicates(subset=['Q', 'P'])
        report['after_duplicate_removal'] = len(data)

        # 步骤4: 运行点筛选
        data = data[data['Q'] > 0]
        report['final_count'] = len(data)

        self._logger.info(
            f"Q-P数据预处理完成: {original_count} -> {len(data)}",
            extra={"extra_data": {"曲线类型": "qp", "保留率": f"{len(data)/original_count:.2%}"}}
        )

        return data, report
```

#### 4.3.3 QPConstraints（物理约束）

```python
from typing import Dict, Any
import pandas as pd
import numpy as np
import logging

class QPConstraints:
    """Q-P曲线物理约束计算器"""

    # 物理常数
    RHO = 1000  # kg/m³ 水的密度
    G = 9.81    # m/s² 重力加速度

    def __init__(self):
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

    def calculate(
        self,
        data: pd.DataFrame,
        device_params: Dict[str, Any]
    ) -> Dict[str, Any]:
        """
        计算Q-P曲线的物理约束参数

        Args:
            data: 预处理后的数据
            device_params: 设备参数

        Returns:
            Dict: 约束参数
        """
        Q = data['Q'].values
        P = data['P'].values

        # 从device_params中获取额定参数（应该已通过DeviceRatedParamsReader读取）
        if 'Q_rated' not in device_params or 'P_rated' not in device_params:
            missing_params = [p for p in ['Q_rated', 'P_rated'] if p not in device_params]
            raise ValueError(
                f"设备额定参数缺失，无法计算Q-P约束. "
                f"缺失参数: {missing_params}. "
                f"请确保已从device_rated_params表读取额定参数。"
            )
        Q_rated = device_params['Q_rated']
        P_rated = device_params['P_rated']

        # 计算P₀（空载功率）
        P0 = self._calculate_P0(Q, P, P_rated)

        # 计算P_max
        P_max = P_rated * 1.2

        # 验证单调性
        monotonicity = self._verify_monotonicity(Q, P)

        # 验证能量守恒（需要H和η数据）
        energy_balance = {'is_valid': True, 'deviation': 0.0}

        constraints = {
            'P0': P0,
            'P_max': P_max,
            'Q_rated': Q_rated,
            'P_rated': P_rated,
            'monotonicity': monotonicity,
            'energy_balance': energy_balance,
            'curve_type': 'qp',
            'expected_monotonicity': 'increasing'
        }

        self._logger.info(
            f"Q-P约束参数计算完成",
            extra={"extra_data": {
                "曲线类型": "qp",
                "P0": f"{P0:.2f} kW",
                "P_max": f"{P_max:.2f} kW"
            }}
        )

        return constraints

    def _calculate_P0(self, Q: np.ndarray, P: np.ndarray, P_rated: float) -> float:
        """计算空载功率P₀"""
        mask = Q < 0.1 * Q.max()
        if mask.sum() >= 3:
            P0 = P[mask].min()
            if 0.05 * P_rated < P0 < 0.4 * P_rated:
                return P0
        return P_rated * 0.15

    def _verify_monotonicity(self, Q: np.ndarray, P: np.ndarray) -> Dict[str, Any]:
        """验证单调递增性"""
        sorted_indices = np.argsort(Q)
        Q_sorted = Q[sorted_indices]
        P_sorted = P[sorted_indices]

        dP = np.diff(P_sorted)
        dQ = np.diff(Q_sorted)

        valid_mask = dQ > 0
        gradients = np.zeros_like(dP)
        gradients[valid_mask] = dP[valid_mask] / dQ[valid_mask]

        increasing_count = np.sum(gradients > 0)
        ratio = increasing_count / len(gradients) if len(gradients) > 0 else 0

        return {
            'is_valid': ratio > 0.95,
            'ratio': ratio,
            'expected': 'increasing'
        }
```

#### 4.3.4 QPValidator（验证器）

```python
from typing import Dict, Any, List
import pandas as pd
import numpy as np
import logging

class QPValidator:
    """Q-P曲线验证器"""

    # 必需的验证阈值参数列表（必须从数据库读取，禁止硬编码默认值）
    REQUIRED_THRESHOLDS = [
        'r_squared_min',          # R² 最小阈值
        'rmse_max',               # RMSE 最大阈值（单位：kW）
        'monotonicity_ratio_min', # 单调性比例最小阈值
        'energy_deviation_max'    # 能量偏差最大阈值
    ]

    def __init__(self, thresholds: Dict[str, float]):
        """
        初始化验证器

        Args:
            thresholds: 验证阈值（必须从数据库 method_params JSONB 读取）

        Raises:
            ValueError: 如果缺失必需的阈值参数
        """
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

        # 验证必需参数是否存在（禁止使用默认值）
        missing_params = [p for p in self.REQUIRED_THRESHOLDS if p not in thresholds]
        if missing_params:
            self._logger.error(
                "[验证器] 缺失必需的验证阈值参数",
                extra={"extra_data": {
                    "组件": "QPValidator",
                    "缺失参数": missing_params,
                    "影响": "无法执行验证，拟合流程中止"
                }}
            )
            raise ValueError(f"数据库中缺失必需的验证阈值参数: {missing_params}")

        self._thresholds = thresholds

    def validate(
        self,
        fit_result: 'FitResult',
        original_data: pd.DataFrame,
        constraints: Dict[str, Any]
    ) -> 'ValidationResult':
        """验证拟合结果"""
        issues = []
        warnings = []
        scores = {}

        # 1. 精度验证（使用数据库阈值，无默认值）
        # 从拟合结果中获取指标（某些方法可能不计算所有指标，使用默认值是合理的）
        r_squared = fit_result.metrics.get('r_squared', 0)
        if r_squared < self._thresholds['r_squared_min']:
            issues.append(f"R²={r_squared:.4f} < {self._thresholds['r_squared_min']}")
        scores['r_squared'] = r_squared

        # 2. 单调性验证（递增）
        monotonicity = self._verify_monotonicity(fit_result, original_data)
        if not monotonicity['is_valid']:
            issues.append(f"单调性验证失败: {monotonicity['ratio']:.2%}")
        scores['monotonicity'] = monotonicity['ratio']

        # 3. 边界条件验证
        boundary = self._verify_boundary_conditions(fit_result, constraints)
        if not boundary['P0_valid']:
            warnings.append(f"P₀偏差过大: {boundary['P0_deviation']:.2%}")

        is_valid = len(issues) == 0

        return ValidationResult(
            is_valid=is_valid,
            issues=issues,
            warnings=warnings,
            scores=scores
        )

    def _verify_monotonicity(self, fit_result, original_data) -> Dict[str, Any]:
        """验证单调递增性"""
        Q = original_data['Q'].values
        Q_sorted = np.sort(Q)
        P_pred = fit_result.predict(Q_sorted)

        dP = np.diff(P_pred)
        increasing_count = np.sum(dP > 0)
        ratio = increasing_count / len(dP) if len(dP) > 0 else 0

        return {'is_valid': ratio >= 0.95, 'ratio': ratio}

    def _verify_boundary_conditions(self, fit_result, constraints) -> Dict[str, Any]:
        """验证边界条件"""
        # P0应该在约束参数中（从device_rated_params计算得出）
        if 'P0' not in constraints:
            raise ValueError(
                f"边界验证失败：约束参数中缺少P0. "
                f"请确保约束计算器已正确计算P0参数。"
            )
        P0_expected = constraints['P0']
        P0_predicted = fit_result.predict(0)
        P0_deviation = abs(P0_predicted - P0_expected) / P0_expected if P0_expected > 0 else 0

        return {
            'is_valid': P0_deviation <= 0.1,
            'P0_valid': P0_deviation <= 0.1,
            'P0_deviation': P0_deviation
        }
```

## 5. QEtaCurve（Q-η曲线模块）

### 5.1 模块概述

| 属性 | 说明 |
|------|------|
| **文件路径** | `app/services/characteristic_curves/curves/qeta_curve.py` |
| **物理意义** | 流量-效率关系曲线 |
| **单调性** | 单峰（有且仅有一个最大值） |
| **推荐方法** | math_stat_gaussian, math_poly_3, math_poly_4 |

**物理公式**：
```
η = (ρ * g * Q * H) / P

其中：
- ρ = 1000 kg/m³（水的密度）
- g = 9.81 m/s²（重力加速度）
- Q：流量（m³/s，注意单位转换）
- H：扬程（m）
- P：功率（W）
```

**典型曲线形状**：
```
η (%)
│
85 │       ╭───╮
   │      ╱     ╲
75 │     ╱       ╲
   │    ╱         ╲
65 │   ╱           ╲
   │  ╱             ╲
55 │ ╱               ╲
   │╱                 ╲
45 └─────────────────────> Q (m³/h)
   0   100  200  300  400
        ↑
       BEP (最佳效率点)
```

```python
from typing import Dict, Any
from datetime import datetime
import pandas as pd
import numpy as np
import logging
from app.adapters.db.pool import get_connection  # 使用项目统一的连接池

class QEtaDataExtractor:
    """Q-η曲线数据提取器

    直接从 fact_measurements 读取 pump_efficiency 数据，无需现场计算。
    使用 get_connection() 上下文管理器获取数据库连接，而非 SQLAlchemy ORM。
    """

    REQUIRED_METRICS = ['pump_flow_rate', 'pump_efficiency']

    def __init__(self):
        """初始化数据提取器（不需要传入db_session）"""
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

    def extract(
        self,
        device_id: int,
        start_time: datetime,
        end_time: datetime,
        min_points: int = 100
    ) -> pd.DataFrame:
        """
        提取Q-η数据

        直接读取 pump_efficiency，无需计算

        Args:
            device_id: 设备ID
            start_time: 开始时间
            end_time: 结束时间
            min_points: 最小数据点数

        Returns:
            DataFrame: 包含ts_bucket, Q, eta列的数据
        """
        self._logger.info(
            f"提取Q-η数据: device_id={device_id}",
            extra={"extra_data": {
                "设备ID": device_id,
                "曲线类型": "qeta",
                "开始时间": str(start_time),
                "结束时间": str(end_time)
            }}
        )

        # 使用 get_connection() 上下文管理器获取连接
        sql = """
            SELECT
                ts_bucket,
                MAX(CASE WHEN metric_id = (
                    SELECT id FROM dim_metric_config
                    WHERE metric_key = 'pump_flow_rate'
                ) THEN value END) AS Q,
                MAX(CASE WHEN metric_id = (
                    SELECT id FROM dim_metric_config
                    WHERE metric_key = 'pump_efficiency'
                ) THEN value END) AS eta
            FROM fact_measurements
            WHERE device_id = %(device_id)s
              AND ts_bucket BETWEEN %(start_time)s AND %(end_time)s
              AND metric_id IN (
                  SELECT id FROM dim_metric_config
                  WHERE metric_key IN ('pump_flow_rate', 'pump_efficiency')
              )
            GROUP BY ts_bucket
            HAVING MAX(CASE WHEN metric_id = (
                SELECT id FROM dim_metric_config
                WHERE metric_key = 'pump_flow_rate'
            ) THEN value END) IS NOT NULL
               AND MAX(CASE WHEN metric_id = (
                SELECT id FROM dim_metric_config
                WHERE metric_key = 'pump_efficiency'
            ) THEN value END) IS NOT NULL
            ORDER BY ts_bucket
        """

        with get_connection() as conn:
            with conn.cursor() as cursor:
                cursor.execute(sql, {
                    'device_id': device_id,
                    'start_time': start_time,
                    'end_time': end_time
                })
                rows = cursor.fetchall()
                columns = [desc[0] for desc in cursor.description]

        data = pd.DataFrame(rows, columns=columns)

        # pump_efficiency 存储为百分比 (0-100)，转换为小数 (0-1)
        data['eta'] = data['eta'] / 100.0

        self._logger.info(
            f"数据提取完成: {len(data)}条记录",
            extra={"extra_data": {
                "设备ID": device_id,
                "曲线类型": "qeta",
                "数据量": len(data),
                "效率范围": f"[{data['eta'].min():.2%}, {data['eta'].max():.2%}]" if len(data) > 0 else "无数据"
            }}
        )

        return data
```

#### 5.3.2 QEtaPreprocessor（预处理器）

```python
from typing import Dict, Any, Tuple
import pandas as pd
import numpy as np
import logging

class QEtaPreprocessor:
    """Q-η曲线数据预处理器"""

    def __init__(self):
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

    def preprocess(
        self,
        data: pd.DataFrame,
        outlier_method: str = '3sigma',
        min_Q: float = 0.0,
        min_eta: float = 0.0,
        max_eta: float = 1.0
    ) -> Tuple[pd.DataFrame, Dict[str, Any]]:
        """
        预处理Q-η数据

        Args:
            data: 原始数据
            outlier_method: 异常值检测方法
            min_Q: 最小流量阈值
            min_eta: 最小效率阈值
            max_eta: 最大效率阈值

        Returns:
            Tuple[DataFrame, Dict]: 清洗后的数据和清洗报告
        """
        original_count = len(data)
        report = {'original_count': original_count}

        # 步骤1: 删除无效值（效率必须在0-1之间）
        data = data[
            (data['Q'] >= min_Q) &
            (data['eta'] >= min_eta) &
            (data['eta'] <= max_eta)
        ].copy()
        report['after_invalid_removal'] = len(data)

        # 步骤2: 删除异常值（效率数据噪声较大，使用更宽松的阈值）
        if outlier_method == '3sigma':
            Q_mean, Q_std = data['Q'].mean(), data['Q'].std()
            eta_mean, eta_std = data['eta'].mean(), data['eta'].std()
            data = data[
                (data['Q'] >= Q_mean - 3*Q_std) & (data['Q'] <= Q_mean + 3*Q_std) &
                (data['eta'] >= eta_mean - 3*eta_std) & (data['eta'] <= eta_mean + 3*eta_std)
            ]
        report['after_outlier_removal'] = len(data)

        # 步骤3: 删除重复值
        data = data.drop_duplicates(subset=['Q', 'eta'])
        report['after_duplicate_removal'] = len(data)

        # 步骤4: 运行点筛选
        data = data[data['Q'] > 0]
        report['final_count'] = len(data)
        report['retention_rate'] = len(data) / original_count if original_count > 0 else 0

        self._logger.info(
            f"Q-η数据预处理完成: {original_count} -> {len(data)}",
            extra={"extra_data": {"曲线类型": "qeta", "保留率": f"{report['retention_rate']:.2%}"}}
        )

        return data, report
```

#### 5.3.3 QEtaConstraints（物理约束）

```python
from typing import Dict, Any
import pandas as pd
import numpy as np
import logging
from scipy.signal import find_peaks

class QEtaConstraints:
    """Q-η曲线物理约束计算器"""

    def __init__(self):
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

    def calculate(
        self,
        data: pd.DataFrame,
        device_params: Dict[str, Any]
    ) -> Dict[str, Any]:
        """
        计算Q-η曲线的物理约束参数

        Args:
            data: 预处理后的数据
            device_params: 设备参数

        Returns:
            Dict: 约束参数
        """
        Q = data['Q'].values
        eta = data['eta'].values

        # 从device_params中获取额定参数（应该已通过DeviceRatedParamsReader读取）
        if 'Q_rated' not in device_params or 'eta_rated' not in device_params:
            missing_params = [p for p in ['Q_rated', 'eta_rated'] if p not in device_params]
            raise ValueError(
                f"设备额定参数缺失，无法计算Q-η约束. "
                f"缺失参数: {missing_params}. "
                f"请确保已从device_rated_params表读取额定参数。"
            )
        Q_rated = device_params['Q_rated']
        eta_rated = device_params['eta_rated']

        # 计算BEP点（最佳效率点）
        Q_BEP, eta_max = self._find_BEP(Q, eta)

        # 验证单峰性
        unimodal = self._verify_unimodal(Q, eta)

        # 验证效率范围
        efficiency_range = self._verify_efficiency_range(eta)

        # 验证BEP位置
        bep_position = self._verify_BEP_position(Q_BEP, Q_rated)

        constraints = {
            'Q_BEP': Q_BEP,
            'eta_max': eta_max,
            'Q_rated': Q_rated,
            'eta_rated': eta_rated,
            'unimodal': unimodal,
            'efficiency_range': efficiency_range,
            'bep_position': bep_position,
            'curve_type': 'qeta',
            'expected_monotonicity': 'unimodal'
        }

        self._logger.info(
            f"Q-η约束参数计算完成",
            extra={"extra_data": {
                "曲线类型": "qeta",
                "Q_BEP": f"{Q_BEP:.2f} m³/h",
                "eta_max": f"{eta_max:.2%}",
                "单峰性验证": "通过" if unimodal['is_valid'] else "失败"
            }}
        )

        return constraints

    def _find_BEP(self, Q: np.ndarray, eta: np.ndarray) -> tuple:
        """找到最佳效率点"""
        # 按Q排序并平滑
        sorted_indices = np.argsort(Q)
        Q_sorted = Q[sorted_indices]
        eta_sorted = eta[sorted_indices]

        # 使用滑动窗口平滑
        window_size = min(10, len(eta_sorted) // 10)
        if window_size > 0:
            eta_smooth = np.convolve(eta_sorted, np.ones(window_size)/window_size, mode='valid')
            Q_smooth = Q_sorted[window_size//2:-(window_size//2)] if window_size > 1 else Q_sorted
        else:
            eta_smooth = eta_sorted
            Q_smooth = Q_sorted

        # 找到最大值
        max_idx = np.argmax(eta_smooth)
        Q_BEP = Q_smooth[max_idx] if len(Q_smooth) > max_idx else Q.mean()
        eta_max = eta_smooth[max_idx] if len(eta_smooth) > max_idx else eta.max()

        return Q_BEP, eta_max

    def _verify_unimodal(self, Q: np.ndarray, eta: np.ndarray) -> Dict[str, Any]:
        """验证单峰性"""
        sorted_indices = np.argsort(Q)
        eta_sorted = eta[sorted_indices]

        # 平滑后找峰值
        window_size = min(10, len(eta_sorted) // 10)
        if window_size > 0:
            eta_smooth = np.convolve(eta_sorted, np.ones(window_size)/window_size, mode='valid')
        else:
            eta_smooth = eta_sorted

        # 使用scipy找峰值
        peaks, _ = find_peaks(eta_smooth, prominence=0.02)

        return {
            'is_valid': len(peaks) <= 1,
            'peak_count': len(peaks),
            'expected': 1
        }

    def _verify_efficiency_range(self, eta: np.ndarray) -> Dict[str, Any]:
        """验证效率范围"""
        min_eta = eta.min()
        max_eta = eta.max()

        return {
            'is_valid': min_eta >= 0 and max_eta <= 1,
            'min': min_eta,
            'max': max_eta
        }

    def _verify_BEP_position(self, Q_BEP: float, Q_rated: float) -> Dict[str, Any]:
        """验证BEP位置"""
        ratio = Q_BEP / Q_rated if Q_rated > 0 else 0

        return {
            'is_valid': 0.6 <= ratio <= 1.2,
            'ratio': ratio,
            'Q_BEP': Q_BEP,
            'Q_rated': Q_rated
        }
```

#### 5.3.4 QEtaValidator（验证器）

```python
from typing import Dict, Any, List
import pandas as pd
import numpy as np
import logging

class QEtaValidator:
    """Q-η曲线验证器"""

    # 必需的验证阈值参数列表（必须从数据库读取，禁止硬编码默认值）
    REQUIRED_THRESHOLDS = [
        'r_squared_min',      # R² 最小阈值
        'rmse_max',           # RMSE 最大阈值
        'unimodal_required',  # 是否要求单峰
        'bep_position_valid'  # BEP位置是否需要验证
    ]

    def __init__(self, thresholds: Dict[str, Any]):
        """
        初始化验证器

        Args:
            thresholds: 验证阈值（必须从数据库 method_params JSONB 读取）

        Raises:
            ValueError: 如果缺失必需的阈值参数
        """
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

        # 验证必需参数是否存在（禁止使用默认值）
        missing_params = [p for p in self.REQUIRED_THRESHOLDS if p not in thresholds]
        if missing_params:
            self._logger.error(
                "[验证器] 缺失必需的验证阈值参数",
                extra={"extra_data": {
                    "组件": "QEtaValidator",
                    "缺失参数": missing_params,
                    "影响": "无法执行验证，拟合流程中止"
                }}
            )
            raise ValueError(f"数据库中缺失必需的验证阈值参数: {missing_params}")

        self._thresholds = thresholds

    def validate(
        self,
        fit_result: 'FitResult',
        original_data: pd.DataFrame,
        constraints: Dict[str, Any]
    ) -> 'ValidationResult':
        """验证拟合结果"""
        issues = []
        warnings = []
        scores = {}

        # 1. 精度验证（使用数据库阈值，无默认值）
        # 从拟合结果中获取指标（某些方法可能不计算所有指标，使用默认值是合理的）
        r_squared = fit_result.metrics.get('r_squared', 0)
        if r_squared < self._thresholds['r_squared_min']:
            issues.append(f"R²={r_squared:.4f} < {self._thresholds['r_squared_min']}")
        scores['r_squared'] = r_squared

        # 2. 单峰性验证
        unimodal = self._verify_unimodal(fit_result, original_data)
        if not unimodal['is_valid']:
            issues.append(f"单峰性验证失败: 检测到{unimodal['peak_count']}个峰")
        scores['unimodal'] = 1.0 if unimodal['is_valid'] else 0.0

        # 3. 效率范围验证
        efficiency_range = self._verify_efficiency_range(fit_result, original_data)
        if not efficiency_range['is_valid']:
            warnings.append(f"效率超出范围: [{efficiency_range['min']:.2%}, {efficiency_range['max']:.2%}]")

        # 4. BEP位置验证（可选参数）
        if 'bep_position' in constraints:
            bep = constraints['bep_position']
            if not bep.get('is_valid', True):
                warnings.append(f"BEP位置偏离: Q_BEP/Q_rated = {bep.get('ratio', 0):.2f}")

        is_valid = len(issues) == 0

        return ValidationResult(
            is_valid=is_valid,
            issues=issues,
            warnings=warnings,
            scores=scores
        )

    def _verify_unimodal(self, fit_result, original_data) -> Dict[str, Any]:
        """验证单峰性"""
        Q = original_data['Q'].values
        Q_range = np.linspace(Q.min(), Q.max(), 100)
        eta_pred = fit_result.predict(Q_range)

        # 找峰值
        from scipy.signal import find_peaks
        peaks, _ = find_peaks(eta_pred, prominence=0.02)

        return {
            'is_valid': len(peaks) == 1,
            'peak_count': len(peaks)
        }

    def _verify_efficiency_range(self, fit_result, original_data) -> Dict[str, Any]:
        """验证效率范围"""
        Q = original_data['Q'].values
        Q_range = np.linspace(Q.min(), Q.max(), 100)
        eta_pred = fit_result.predict(Q_range)

        return {
            'is_valid': eta_pred.min() >= 0 and eta_pred.max() <= 1,
            'min': eta_pred.min(),
            'max': eta_pred.max()
        }
```

#### 6.3.1 MathPoly2Method（2次多项式）

```python
import numpy as np
from typing import Dict, Any
from app.services.characteristic_curves.methods.base_method import BaseMethod, MethodResult

class MathPoly2Method(BaseMethod):
    """2次多项式拟合方法

    数学公式:
        Q-H曲线: H = a0 + a1*Q + a2*Q²
        Q-P曲线: P = a0 + a1*Q + a2*Q²
    """

    method_id = 'math_poly_2'
    method_name = '2次多项式'
    applicable_curves = ['qh', 'qp']

    def __init__(self, regularization: str = None, lambda_: float = 0.01):
        """
        初始化

        Args:
            regularization: 正则化类型（'l1', 'l2', None）
            lambda_: 正则化系数
        """
        super().__init__()
        self.regularization = regularization
        self.lambda_ = lambda_
        self.degree = 2

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        执行拟合

        Args:
            X: 自变量数组
            y: 因变量数组
            **kwargs: 额外参数

        Returns:
            MethodResult: 拟合结果
        """
        # 多项式拟合
        coefficients = np.polyfit(X, y, self.degree)

        # 计算预测值
        y_pred = np.polyval(coefficients, X)

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        # 创建预测函数
        predict_func = lambda x: np.polyval(coefficients, x)

        return MethodResult(
            method_id=self.method_id,
            coefficients={
                'a0': coefficients[2],
                'a1': coefficients[1],
                'a2': coefficients[0]
            },
            metrics=metrics,
            predict_func=predict_func,
            formula=f"y = {coefficients[2]:.4f} + {coefficients[1]:.4f}*x + {coefficients[0]:.4f}*x²"
        )

    def _calculate_metrics(self, y_true: np.ndarray, y_pred: np.ndarray) -> Dict[str, float]:
        """计算拟合指标"""
        ss_res = np.sum((y_true - y_pred) ** 2)
        ss_tot = np.sum((y_true - np.mean(y_true)) ** 2)
        r_squared = 1 - (ss_res / ss_tot) if ss_tot > 0 else 0

        rmse = np.sqrt(np.mean((y_true - y_pred) ** 2))
        mae = np.mean(np.abs(y_true - y_pred))

        return {
            'r_squared': r_squared,
            'rmse': rmse,
            'mae': mae
        }
```

#### 6.3.2 MathStatGaussianMethod（高斯函数）

```python
import numpy as np
from scipy.optimize import curve_fit
from typing import Dict, Any
from app.services.characteristic_curves.methods.base_method import BaseMethod, MethodResult

class MathStatGaussianMethod(BaseMethod):
    """高斯函数拟合方法

    数学公式:
        η = A * exp(-((Q - μ)² / (2 * σ²)))

    适用曲线: Q-η（效率曲线的单峰特性）
    """

    method_id = 'math_stat_gaussian'
    method_name = '高斯函数'
    applicable_curves = ['qeta']

    def __init__(self):
        super().__init__()

    @staticmethod
    def _gaussian(x, A, mu, sigma):
        """高斯函数"""
        return A * np.exp(-((x - mu) ** 2) / (2 * sigma ** 2))

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        执行拟合

        Args:
            X: 流量数组
            y: 效率数组
            **kwargs: 额外参数（包含constraints）

        Returns:
            MethodResult: 拟合结果
        """
        constraints = kwargs.get('constraints', {})

        # 初始猜测
        A_init = y.max()
        mu_init = X[np.argmax(y)]
        sigma_init = (X.max() - X.min()) / 4

        # 参数边界
        bounds = (
            [0, X.min(), 0],           # 下界
            [1.5, X.max(), X.max()]    # 上界
        )

        try:
            popt, pcov = curve_fit(
                self._gaussian, X, y,
                p0=[A_init, mu_init, sigma_init],
                bounds=bounds,
                maxfev=5000
            )

            A, mu, sigma = popt

            # 计算预测值
            y_pred = self._gaussian(X, A, mu, sigma)

            # 计算指标
            metrics = self._calculate_metrics(y, y_pred)

            # 创建预测函数
            predict_func = lambda x: self._gaussian(x, A, mu, sigma)

            return MethodResult(
                method_id=self.method_id,
                coefficients={'A': A, 'mu': mu, 'sigma': sigma},
                metrics=metrics,
                predict_func=predict_func,
                formula=f"η = {A:.4f} * exp(-((Q - {mu:.2f})² / (2 * {sigma:.2f}²)))"
            )

        except Exception as e:
            self._logger.warning(f"高斯拟合失败: {e}")
            return MethodResult(
                method_id=self.method_id,
                coefficients={},
                metrics={'r_squared': 0, 'rmse': float('inf')},
                predict_func=None,
                error=str(e)
            )
```

### 6.4 物理模型（Physics）

#### 6.4.1 PhysicsPumpCharMethod（泵特性方程）

```python
import numpy as np
from scipy.optimize import curve_fit
from typing import Dict, Any
from app.services.characteristic_curves.methods.base_method import BaseMethod, MethodResult

class PhysicsPumpCharMethod(BaseMethod):
    """泵特性方程拟合方法

    物理公式:
        H = H0 - K * Q²

    物理意义:
        H0: 零流量扬程（截止扬程）
        K: 阻力系数

    适用曲线: Q-H
    """

    method_id = 'physics_pump_char'
    method_name = '泵特性方程'
    applicable_curves = ['qh']

    def __init__(self):
        super().__init__()

    @staticmethod
    def _pump_curve(Q, H0, K):
        """泵特性方程: H = H0 - K*Q²"""
        return H0 - K * Q ** 2

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        执行拟合

        Args:
            X: 流量数组（归一化后）
            y: 扬程数组（归一化后）
            **kwargs: 额外参数（包含constraints）

        Returns:
            MethodResult: 拟合结果
        """
        # 从kwargs中获取约束参数（可选参数，默认为空字典）
        constraints = kwargs.get('constraints', {})

        # 使用约束参数作为初始猜测
        if 'H0' not in constraints:
            H0_init = y.max()
            self._logger.warning(
                f"约束参数中缺少H0，使用数据最大值作为初始估计: {H0_init:.2f}"
            )
        else:
            H0_init = constraints['H0']

        if 'K' not in constraints:
            K_init = (H0_init - y.min()) / (X.max() ** 2) if X.max() > 0 else 0.001
            self._logger.warning(
                f"约束参数中缺少K，使用数据估算: {K_init:.6f}"
            )
        else:
            K_init = constraints['K']

        # 参数边界
        bounds = (
            [0, 0],                    # 下界: H0 > 0, K > 0
            [H0_init * 2, K_init * 5]  # 上界
        )

        try:
            popt, pcov = curve_fit(
                self._pump_curve, X, y,
                p0=[H0_init, K_init],
                bounds=bounds,
                maxfev=5000
            )

            H0, K = popt

            # 计算预测值
            y_pred = self._pump_curve(X, H0, K)

            # 计算指标
            metrics = self._calculate_metrics(y, y_pred)

            # 验证物理约束
            # 1. 单调递减: dH/dQ = -2KQ < 0 对于Q>0恒成立
            # 2. H0 > 0
            # 3. H(Q_max) > 0
            physics_valid = H0 > 0 and K > 0

            # 创建预测函数
            predict_func = lambda x: self._pump_curve(x, H0, K)

            return MethodResult(
                method_id=self.method_id,
                coefficients={'H0': H0, 'K': K},
                metrics=metrics,
                predict_func=predict_func,
                formula=f"H = {H0:.4f} - {K:.6f} * Q²",
                physics_valid=physics_valid
            )

        except Exception as e:
            self._logger.warning(f"泵特性方程拟合失败: {e}")
            return MethodResult(
                method_id=self.method_id,
                coefficients={},
                metrics={'r_squared': 0, 'rmse': float('inf')},
                predict_func=None,
                error=str(e)
            )
```

```python
import numpy as np
from scipy.optimize import curve_fit
from typing import Dict, Any
from app.services.characteristic_curves.methods.base_method import BaseMethod, MethodResult

class PhysicsPowerEqMethod(BaseMethod):
    """功率方程拟合方法

    物理公式:
        P = P0 + K * Q^n

    物理意义:
        P0: 空载功率
        K: 功率系数
        n: 指数（通常为1-2）

    适用曲线: Q-P
    """

    method_id = 'physics_power_eq'
    method_name = '功率方程'
    applicable_curves = ['qp']

    def __init__(self):
        super().__init__()

    @staticmethod
    def _power_curve(Q, P0, K, n):
        """功率方程: P = P0 + K*Q^n"""
        return P0 + K * np.power(Q, n)

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        执行拟合

        Args:
            X: 流量数组
            y: 功率数组
            **kwargs: 额外参数

        Returns:
            MethodResult: 拟合结果
        """
        # 从kwargs中获取约束参数（可选参数，默认为空字典）
        constraints = kwargs.get('constraints', {})

        # 初始猜测
        if 'P0' not in constraints:
            P0_init = y.min()
            self._logger.warning(
                f"约束参数中缺少P0，使用数据最小值作为初始估计: {P0_init:.2f}"
            )
        else:
            P0_init = constraints['P0']

        K_init = (y.max() - P0_init) / (X.max() ** 1.5) if X.max() > 0 else 0.001
        n_init = 1.5

        # 参数边界
        bounds = (
            [0, 0, 0.5],      # 下界
            [y.max(), 10, 3]  # 上界
        )

        try:
            popt, pcov = curve_fit(
                self._power_curve, X, y,
                p0=[P0_init, K_init, n_init],
                bounds=bounds,
                maxfev=5000
            )

            P0, K, n = popt

            # 计算预测值
            y_pred = self._power_curve(X, P0, K, n)

            # 计算指标
            metrics = self._calculate_metrics(y, y_pred)

            # 验证物理约束
            physics_valid = P0 > 0 and K > 0 and 0.5 < n < 3

            # 创建预测函数
            predict_func = lambda x: self._power_curve(x, P0, K, n)

            return MethodResult(
                method_id=self.method_id,
                coefficients={'P0': P0, 'K': K, 'n': n},
                metrics=metrics,
                predict_func=predict_func,
                formula=f"P = {P0:.4f} + {K:.6f} * Q^{n:.2f}",
                physics_valid=physics_valid

                error=str(e)
```

#### 6.5.1 MLGradientBoostMethod（梯度提升）

```python
import numpy as np
from typing import Dict, Any
from sklearn.ensemble import GradientBoostingRegressor
from app.services.characteristic_curves.methods.base_method import BaseMethod, MethodResult

class MLGradientBoostMethod(BaseMethod):
    """梯度提升拟合方法

    适用场景: 大数据量（>1000点）、复杂非线性关系

    适用曲线: 所有
    """

    method_id = 'ml_gradient_boost'
    method_name = '梯度提升'
    applicable_curves = ['qh', 'qp', 'qeta']
    min_data_points = 1000

    def __init__(
        self,
        n_estimators: int = 100,
        max_depth: int = 3,
        learning_rate: float = 0.1
    ):
        """
        初始化

        Args:
            n_estimators: 树的数量
            max_depth: 树的最大深度
            learning_rate: 学习率
        """
        super().__init__()
        self.n_estimators = n_estimators
        self.max_depth = max_depth
        self.learning_rate = learning_rate
        self._model = None

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """
        执行拟合

        Args:
            X: 自变量数组
            y: 因变量数组
            **kwargs: 额外参数

        Returns:
            MethodResult: 拟合结果
        """
        # 检查数据量
        if len(X) < self.min_data_points:
            self._logger.warning(f"数据量不足: {len(X)} < {self.min_data_points}")

        # 重塑数据
        X_reshaped = X.reshape(-1, 1)

        # 创建并训练模型
        self._model = GradientBoostingRegressor(
            n_estimators=self.n_estimators,
            max_depth=self.max_depth,
            learning_rate=self.learning_rate,
            random_state=42
        )
        self._model.fit(X_reshaped, y)

        # 计算预测值
        y_pred = self._model.predict(X_reshaped)

        # 计算指标
        metrics = self._calculate_metrics(y, y_pred)

        # 创建预测函数
        def predict_func(x):
            x_arr = np.atleast_1d(x).reshape(-1, 1)
            return self._model.predict(x_arr)

        return MethodResult(
            method_id=self.method_id,
            coefficients={'n_estimators': self.n_estimators, 'max_depth': self.max_depth},
            metrics=metrics,
            predict_func=predict_func,
            formula="Gradient Boosting Model",
            model=self._model
        )
```

### 6.6 方法注册表

```python
from typing import Dict, Type, Optional, List
from app.services.characteristic_curves.methods.base_method import BaseMethod

class MethodRegistry:
    """方法注册表 - 管理所有拟合方法"""

    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._methods: Dict[str, Type[BaseMethod]] = {}
            cls._instance._initialize_builtin_methods()
        return cls._instance

    def _initialize_builtin_methods(self):
        """初始化内置方法"""
        # 数学方法
        self.register('math_poly_2', MathPoly2Method)
        self.register('math_poly_3', MathPoly3Method)
        self.register('math_stat_gaussian', MathStatGaussianMethod)
        self.register('math_spline_cubic', MathSplineCubicMethod)
        self.register('math_spline_bspline', MathSplineBSplineMethod)
        self.register('math_kernel_rbf', MathKernelRBFMethod)
        self.register('math_rational_pade', MathRationalPadeMethod)
        self.register('math_local_lowess', MathLocalLowessMethod)

        # 物理模型
        self.register('physics_pump_char', PhysicsPumpCharMethod)
        self.register('physics_power_eq', PhysicsPowerEqMethod)

        # 机器学习
        self.register('ml_gradient_boost', MLGradientBoostMethod)
        self.register('ml_random_forest', MLRandomForestMethod)
        self.register('ml_gaussian_process', MLGaussianProcessMethod)

        # 混合方法
        self.register('hybrid_physics_poly', HybridPhysicsPolyMethod)

    def register(self, method_id: str, method_class: Type[BaseMethod]) -> None:
        """注册方法"""
        self._methods[method_id] = method_class

    def get(self, method_id: str) -> Optional[BaseMethod]:
        """获取方法实例"""
        method_class = self._methods.get(method_id)
        return method_class() if method_class else None

    def list_methods(self, curve_type: Optional[str] = None) -> List[str]:
        """列出方法"""
        if curve_type is None:
            return list(self._methods.keys())

        return [
            method_id for method_id, method_class in self._methods.items()
            if curve_type in method_class.applicable_curves
        ]

    def get_recommended(self, curve_type: str) -> List[str]:
        """获取推荐方法"""
        recommendations = {
            'qh': ['physics_pump_char', 'math_poly_2', 'math_poly_3'],
            'qp': ['physics_power_eq', 'math_poly_2', 'math_poly_3'],
            'qeta': ['math_stat_gaussian', 'math_poly_3', 'math_poly_4']
        }
        return recommendations.get(curve_type, [])
```
