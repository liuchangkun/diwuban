## 1. 项目概述

### 1.1 项目目标

开发一套完整的泵特性曲线拟合系统，支持：
- **188种拟合方法**：数学方法（75）、物理模型（39）、机器学习（20）、混合（6）、时间序列（15）、组合（20）、其他（13）
- **完整的质量保障**：物理约束验证、历史数据评估、版本管理
- **高性能处理**：批处理、内存LRU缓存、参数优化
- **规范的数据管理**：业务参数存储在数据库JSONB字段，禁止硬编码

### 1.2 功能范围

**第一期（核心功能）**：
- ✅ 3条核心特性曲线（Q-H、Q-P、Q-η）+ 3条扩展曲线（H-η、P-η、Q-NPSH）
- ✅ 14种核心拟合方法（数学8种 + 物理2种 + 机器学习3种 + 混合1种）
- ✅ 完整的基础设施（数据库、共用层、方法层、约束层、预处理层）
- ✅ 主管道和CLI集成
- ✅ 业务参数（验证阈值、方法推荐等）存储在数据库JSONB字段

**第二期（扩展功能）**：
- ⏳ 30种P1优先级方法
- ⏳ 监控层（曲线退化检测、自动重拟合）
- ⏳ 变频泵特性曲线族

**第三期（高级功能）**：
- ⏳ 50种P2优先级方法
- ⏳ 可视化层
- ⏳ 实时拟合和在线更新

**第四期（完整覆盖）**：
- ⏳ 剩余94种方法（时间序列、组合方法等）
- ⏳ 其他特性曲线（泵组、系统、电气等）

### 1.3 开发周期估算

#### 2.3.2 文件命名规范

**规则1：使用蛇形命名法（snake_case）**
- ✅ 正确：`constraint_optimizer.py`
- ❌ 错误：`ConstraintOptimizer.py`、`constraint-optimizer.py`

**规则2：文件名与类名对应**
- 文件名：`constraint_parameter_manager.py`
- 类名：`ConstraintParameterManager`
- 转换规则：蛇形命名 → 驼峰命名

**规则3：方法文件命名格式**
- 格式：`{category}_{name}.py`
- 示例：
  - `math_quadratic_decay.py` → `MathQuadraticDecay`
  - `physics_affinity_law.py` → `PhysicsAffinityLaw`
  - `ml_random_forest.py` → `MLRandomForest`

**规则4：曲线子模块命名格式**
- 格式：`{curve}_{module}.py`
- 示例：
  - `qh_data_extractor.py` → `QHDataExtractor`
  - `qp_preprocessor.py` → `QPPreprocessor`
  - `qeta_validator.py` → `QEtaValidator`

```python
class TestMathQuadraticDecay:

        Q = np.linspace(0, 300, 100)
        H = 120 - 0.2*Q - 0.001*Q**2

        # 验证参数约束

        assert result.fit_params['a'] > 0
```

```python
            for method in ['math_quadratic_decay', 'math_cubic_decay', 'physics_pump_char']:  # 3种方法
                tasks.append({
                    'device_id': device_id,
                    'curve_type': curve_type,
                    'method': method
                })

    # 批处理
    start_time = time.time()
    batch_processor = BatchProcessor()
    results = batch_processor.process_batch(tasks)
    elapsed_time = time.time() - start_time

    # 验证性能
    assert len(results) == len(tasks), "批处理结果数量不匹配"
    assert elapsed_time < 300, f"批处理耗时{elapsed_time:.2f}秒，超过5分钟"
    print(f"批处理完成：{len(tasks)}个任务，耗时{elapsed_time:.2f}秒，平均{elapsed_time/len(tasks):.2f}秒/任务")
```

```python
    cache_stats = cache_manager.get_stats()

    assert hit_rate > 0.8, f"缓存命中率{hit_rate:.2%}，低于80%"
```
