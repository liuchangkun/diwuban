## 2. 功能验收标准

### 2.1 拟合精度标准

| 曲线类型 | 最低R² | 目标R² | 优秀R² |
|---------|--------|--------|--------|
| Q-H | 0.92 | 0.95 | 0.98 |
| Q-P | 0.92 | 0.95 | 0.98 |
| Q-η | 0.85 | 0.90 | 0.95 |

### 2.2 物理约束验证标准

| 曲线类型 | 约束条件 | 验证方法 |
|---------|---------|---------|
| Q-H | 单调递减 | dH/dQ < 0 (Q>0) |
| Q-H | H₀ > 0 | 关阀扬程为正 |
| Q-P | 单调递增 | dP/dQ > 0 (Q>0) |
| Q-P | P₀ > 0 | 空载功率为正 |
| Q-η | 单峰特性 | 存在唯一最大值 |
| Q-η | 0 < η ≤ 1 | 效率在合理范围 |

### 2.3 数据处理标准

| 处理项 | 标准 |
|--------|------|
| 最小数据点数 | ≥ 50点（对应MIN_VALIDATION_POINTS，v2.6统一修复） |
| 推荐数据点数 | ≥ 200点 |
| 异常值比例 | ≤ 5% |
| 数据覆盖率 | ≥ 70%流量范围 |

**说明**：最小数据点数50点与系统常量MIN_DATA_POINTS保持一致，确保验收标准与拟合要求对齐。

## 4. 质量指标定义

### 4.1 拟合质量指标

| 指标 | 公式 | 说明 |
|------|------|------|
| R² (决定系数) | 1 - SS_res/SS_tot | 拟合优度 |
| RMSE (均方根误差) | √(Σ(y-ŷ)²/n) | 预测误差 |
| MAE (平均绝对误差) | Σ\|y-ŷ\|/n | 绝对误差 |
| MAPE (平均百分比误差) | Σ\|y-ŷ\|/y/n×100% | 相对误差 |

### 4.2 代码质量指标

| 指标 | 标准 |
|------|------|
| 单元测试覆盖率 | ≥ 80% |
| 圈复杂度 | ≤ 10 |
| 函数行数 | ≤ 50行 |
| 类行数 | ≤ 300行 |
| 代码重复率 | ≤ 5% |
