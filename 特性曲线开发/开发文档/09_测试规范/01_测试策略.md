## 1. 测试目标

### 1.1 质量目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 单元测试覆盖率 | ≥ 80% | 核心模块必须达到90% |
| 集成测试通过率 | 100% | 所有集成测试必须通过 |
| 拟合精度 | R² ≥ 0.95 | P0方法标准测试数据 |
| 性能基准 | ≤ 5s/曲线 | 单条曲线拟合时间 |

### 1.2 测试范围

| 模块 | 优先级 | 测试类型 |
|------|--------|---------|
| 主管道层 (CurveFittingPipeline) | P0 | 单元 + 集成 |
| 方法层 (BaseMethod, MethodRegistry) | P0 | 单元 |
| 约束层 (Constraints) | P0 | 单元 |
| 预处理层 (DataCleaner, Normalizer) | P0 | 单元 |
| 共用层 (ResultStorage, CacheManager) | P0 | 单元 + 集成 |
| 曲线模块 (QH, QP, QEta) | P0 | 单元 + 集成 |

## 2. 测试分层策略

### 2.1 单元测试

**目的**: 验证单个函数/类的正确性

**工具**: pytest

**命名规范**:
```
test_<模块名>_<功能>_<场景>.py
```

**示例**:
```python

def test_monotonicity_constraint_qh_valid():

    pass

    """测试Q-H曲线单调递减验证-无效数据"""
    pass
```

### 2.2 集成测试

**目的**: 验证模块间协作的正确性

**关注点**:
- 数据流正确性（13阶段流程）
- 模块间接口兼容性
- 异常传播和处理

### 2.3 端到端测试

**目的**: 验证完整业务流程

**场景**:
1. 从数据提取到结果存储的完整拟合流程
2. 批量设备拟合
3. 历史评估和版本对比

## 3. 测试覆盖率标准

### 3.1 覆盖率要求

| 模块类型 | 行覆盖率 | 分支覆盖率 |

### 5.2 数据生成规则

```python
# 标准Q-H测试数据生成【v3.11修复：问题141】
def generate_qh_test_data(n_points=200, noise_level=0.02, seed=42):
    """生成标准Q-H曲线测试数据

    Args:
        n_points: 数据点数（默认200）
        noise_level: 噪声水平（默认0.02，即2%）
        seed: 随机种子（默认42，确保可重复性）

    Returns:
        Q: 流量数组 (m³/h)
        H: 扬程数组 (m)，包含噪声

    示例：
        >>> Q, H = generate_qh_test_data(n_points=100, noise_level=0.01)
        >>> assert len(Q) == 100
        >>> assert 0 <= Q.min() and Q.max() <= 300
    """
    np.random.seed(seed)
    Q = np.linspace(0, 300, n_points)
    H = 120 - 0.001 * Q**2  # 理论曲线: H = H0 - a*Q²
    H_noisy = H * (1 + np.random.normal(0, noise_level, n_points))
    return Q, H_noisy

def generate_qp_test_data(n_points=200, noise_level=0.02, seed=42):
    """生成标准Q-P曲线测试数据

    Args:
        n_points: 数据点数
        noise_level: 噪声水平
        seed: 随机种子

    Returns:
        Q: 流量数组 (m³/h)
        P: 功率数组 (kW)，包含噪声
    """
    np.random.seed(seed)
    Q = np.linspace(0, 300, n_points)
    P = 15 + 0.05 * Q + 0.0001 * Q**2  # 理论曲线: P = P0 + a*Q + b*Q²
    P_noisy = P * (1 + np.random.normal(0, noise_level, n_points))
    return Q, P_noisy

def generate_qeta_test_data(n_points=200, noise_level=0.02, seed=42):
    """生成标准Q-η曲线测试数据

    Args:
        n_points: 数据点数
        noise_level: 噪声水平
        seed: 随机种子

    Returns:
        Q: 流量数组 (m³/h)
        eta: 效率数组 (0-1)，包含噪声
    """
    np.random.seed(seed)
    Q = np.linspace(10, 300, n_points)  # 避免Q=0时效率未定义
    Q_opt = 150  # 最优流量点
    eta_max = 0.85  # 最大效率
    # 高斯型效率曲线
    eta = eta_max * np.exp(-((Q - Q_opt) / 100)**2)
    eta_noisy = eta * (1 + np.random.normal(0, noise_level, n_points))
    eta_noisy = np.clip(eta_noisy, 0, 1)  # 限制在[0,1]范围
    return Q, eta_noisy
```
