| 用例ID | 用例名称 | 输入 | 预期结果 |
|--------|---------|------|---------|
| UC-CON-001 | Q-H曲线单调递减验证-有效 | 递减的H数据 | is_valid=True |
| UC-CON-002 | Q-H曲线单调递减验证-无效 | 递增的H数据 | is_valid=False |
| UC-CON-003 | Q-P曲线单调递增验证-有效 | 递增的P数据 | is_valid=True |
| UC-CON-004 | Q-P曲线单调递增验证-无效 | 递减的P数据 | is_valid=False |
| UC-CON-005 | Q-η曲线单峰验证-有效 | 单峰η数据 | is_valid=True |
| UC-CON-006 | Q-η曲线单峰验证-无效 | 多峰η数据 | is_valid=False |

**测试代码示例**:
```python
class TestMonotonicityConstraint:
    def test_qh_monotonic_decreasing_valid(self):
        """UC-CON-001: Q-H曲线单调递减验证-有效"""
        Q = np.array([0, 100, 200, 300])
        H = np.array([120, 100, 70, 30])  # 单调递减
        constraint = MonotonicityConstraint(curve_type='qh')
        result = constraint.validate(Q, H)
        assert result.is_valid == True
        
    def test_qh_monotonic_decreasing_invalid(self):
        """UC-CON-002: Q-H曲线单调递减验证-无效"""
        Q = np.array([0, 100, 200, 300])
        H = np.array([120, 130, 70, 30])  # 非单调
        constraint = MonotonicityConstraint(curve_type='qh')
        result = constraint.validate(Q, H)
        assert result.is_valid == False
```
