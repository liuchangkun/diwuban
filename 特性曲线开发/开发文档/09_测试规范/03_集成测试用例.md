### 1.1 单泵拟合流程

| 用例ID | 用例名称 | 前置条件 | 测试步骤 | 预期结果 |
|--------|---------|---------|---------|---------|
| IT-FIT-001 | Q-H曲线完整拟合 | 设备1有效数据 | 调用pipeline.fit() | 返回FitResult, R²>0.95 |
| IT-FIT-002 | Q-P曲线完整拟合 | 设备1有效数据 | 调用pipeline.fit() | 返回FitResult, R²>0.95 |
| IT-FIT-003 | Q-η曲线完整拟合 | 设备1有效数据 | 调用pipeline.fit() | 返回FitResult, R²>0.90 |
| IT-FIT-004 | 多方法自动选择 | methods='all' | 尝试所有方法 | 返回最佳方法结果 |

**测试代码示例**:
```python
class TestFullFitPipeline:
    @pytest.fixture
    def pipeline(self):
        return CurveFittingPipeline(
            method_registry=MethodRegistry(),
            result_storage=ResultStorage()
        )
    
    def test_qh_curve_full_fit(self, pipeline, test_data):
        """IT-FIT-001: Q-H曲线完整拟合"""
        result = pipeline.fit(
            device_id=1,
            curve_type='qh',
            start_time=datetime(2025, 10, 22),
            end_time=datetime(2025, 10, 23),
            methods='all'
        )
        assert isinstance(result, FitResult)
        assert result.r_squared >= 0.95
        assert result.validation_result.is_valid == True
```
