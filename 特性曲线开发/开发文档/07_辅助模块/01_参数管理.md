## 1. 模块概述

### 1.1 模块定位

参数管理模块负责设备参数和方法参数的管理：

| 组件 | 职责 | 优先级 |
|------|------|--------|
| `ParameterManager` | 设备参数加载、缓存 | P2 |
| `MethodParameterManager` | 方法参数优化、历史记录 | P2 |
| `ParameterLearner` | 从历史数据学习参数 | P2 |
| `ParameterValidator` | 参数验证 | P2 |

### 1.2 架构分层

```
MethodParameterManager (管理层)
    ↓ 调用
ParameterOptimizer (算法层)
    ↓ 使用
ResultStorage (存储层)
    ↓ 访问
Database (数据层)
```

### 1.3 设计原则

> **重要**：移除所有 `DEFAULT_*` 常量和默认值参数，所有业务参数必须从数据库读取，缺失时抛出异常。

### 2.2 核心接口

```python
from typing import Dict, Any, Optional
import logging

class ParameterManager:
    """参数管理器 - 管理设备参数的加载、保存和缓存"""

    _instance: Optional['ParameterManager'] = None

    def __new__(cls) -> 'ParameterManager':
        """单例模式"""
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

    def __init__(self):
        if hasattr(self, '_initialized') and self._initialized:
            return
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")
        self._cache: Dict[int, Dict[str, Any]] = {}
        self._initialized = True

    def get_device_params(
        self,
        device_id: int,
        use_cache: bool = True
    ) -> Dict[str, Any]:
        """
        获取设备参数

        Args:
            device_id: 设备ID
            use_cache: 是否使用缓存

        Returns:
            Dict: 设备参数字典，包含：
                - rated_flow: 额定流量 (m³/h)
                - rated_head: 额定扬程 (m)
                - rated_power: 额定功率 (kW)
                - rated_efficiency: 额定效率
                - rated_speed: 额定转速 (rpm)
                - max_flow: 最大流量 (m³/h)
                - min_flow: 最小流量 (m³/h)
                - shutoff_head: 关死点扬程 (m)
        """
        pass

    def set_device_params(
        self,
        device_id: int,
        params: Dict[str, Any],
        source: str = 'manual'
    ) -> bool:
        """
        设置设备参数

        Args:
            device_id: 设备ID
            params: 参数字典
            source: 参数来源 ('manual', 'learned', 'imported')

        Returns:
            bool: 是否成功
        """
        pass

    def get_curve_constraints(
        self,
        device_id: int,
        curve_type: str
    ) -> Dict[str, Any]:
        """获取曲线约束参数"""
        pass

    def invalidate_cache(
        self,
        device_id: Optional[int] = None

        pass
```

### 2.3 使用示例

```python
from app.services.characteristic_curves.params import ParameterManager

# 初始化
param_manager = ParameterManager()

# 场景1: 获取设备参数
device_params = param_manager.get_device_params(device_id=1)
print(f"额定流量: {device_params['rated_flow']} m³/h")
print(f"额定扬程: {device_params['rated_head']} m")

# 场景2: 获取曲线约束
qh_constraints = param_manager.get_curve_constraints(device_id=1, curve_type='qh')
print(f"关死点扬程范围: {qh_constraints['H0_min']} - {qh_constraints['H0_max']} m")

# 场景3: 更新设备参数
param_manager.set_device_params(
    device_id=1,
    params={'rated_flow': 520, 'rated_head': 52},
    source='learned'
)
```
