## 2. HighResPlotter

> **重要更新**：v2.0版本升级为8K高分辨率绘图器，支持7680×4320像素输出，全中文标签。

### 2.1 功能概述

| 属性 | 说明 |
|------|------|
| **文件路径** | `app/services/characteristic_curves/output/high_res_plotter.py` |
| **职责** | 生成8K高清拟合曲线图（全中文标签） |
| **设计模式** | 策略模式 |
| **依赖** | matplotlib, numpy, scipy.stats |

### 2.2 图片规格

| 配置项 | 规格 |
|-------|------|
| **分辨率** | 7680 × 4320（8K UHD） |
| **DPI** | 300 |
| **图像尺寸** | 25.6 × 14.4 英寸 |
| **格式** | PNG（无损压缩） |
| **中文字体** | SimHei（黑体），回退：Microsoft YaHei |

### 2.3 图片类型

| 图片类型 | 文件后缀 | 内容说明 |
|---------|---------|---------|
| 主曲线图 | `_curve.png` | 原始数据散点 + 拟合曲线 + 95%置信带 + 统计信息框 |
| 残差分析图 | `_residuals.png` | 4子图：残差vs预测、残差vs流量、直方图、QQ图 |
| 置信区间图 | `_confidence.png` | 拟合曲线 + 95%/99%置信区间 + 预测区间 |
| 敏感性分析图 | `_sensitivity.png` | 各参数变化±10%对曲线的影响 |
| 版本对比图 | `_comparison.png` | 当前版本与历史版本曲线对比 |

### 2.5 使用示例

```python

from pathlib import Path

# 初始化

plotter = HighResPlotter(path_manager, font_family='SimHei')

# 绘制8K主曲线图
curve_path = plotter.plot_curve(
    x_data=Q,
    y_data=H,
    fit_result=fit_result,
    predict_func=method.predict,
    output_path=Path(r'\reports\curves\qh\..._curve.png')
)

# 绘制残差分析图
residuals_path = plotter.plot_residuals(
    x_data=Q,
    y_actual=H,
    y_fitted=H_fitted,
    output_path=Path(r'\reports\curves\qh\..._residuals.png')
)

# 绘制置信区间图

    x_data=Q,
    y_data=H,
    fit_result=fit_result,
    predict_func=method.predict,
    output_path=Path(r'\reports\curves\qh\..._confidence.png'),
    confidence_levels=[0.95, 0.99]
)
```

## 5. 性能与资源

### 5.1 资源消耗

| 图片类型 | 文件大小 | 生成时间 | 内存峰值 |
|---------|---------|---------|---------|
| 主曲线图 | 5-10 MB | 3-5秒 | 500 MB |
| 残差分析图 | 4-8 MB | 3-5秒 | 500 MB |
| 置信区间图 | 4-7 MB | 2-4秒 | 400 MB |
| 敏感性分析图 | 3-6 MB | 2-4秒 | 400 MB |
| 版本对比图 | 4-7 MB | 2-4秒 | 400 MB |

### 5.2 性能建议

| 配置项 | 建议值 | 说明 |
|-------|-------|------|
| matplotlib后端 | `Agg` | 非交互式，节省内存 |
| PNG压缩级别 | 6 | 平衡文件大小和压缩时间 |
| 及时关闭Figure | ✅ | 使用 `plt.close(fig)` 释放内存 |
| 分批处理 | ✅ | 逐个生成图片，不并行 |

### 5.3 降级策略

- 内存不足时自动降级到4K分辨率（3840×2160）
- 记录警告日志，不中断流程
