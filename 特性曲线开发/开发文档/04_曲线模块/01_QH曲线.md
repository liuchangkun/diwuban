## 1. 曲线概述

### 1.1 基本信息

| 属性 | 值 |
|------|-----|
| **曲线类型** | `qh` |
| **物理意义** | 流量-扬程关系 |
| **单调性** | 递减 (dH/dQ < 0) |
| **推荐方法** | `physics_pump_char`, `math_poly_2`, `math_poly_3` |
| **文件路径** | `app/services/characteristic_curves/curves/qh_curve.py` |

### 1.2 物理特性

| 特性 | 描述 |
|------|------|
| **单调性** | 全范围单调递减 |
| **凸性** | 下凸 (d²H/dQ² > 0) |
| **零流量点** | H₀ ≈ 1.1~1.3 × H_rated |
| **最大流量点** | H(Q_max) > 0 |

**物理公式**：
```
H = H_static + H_dynamic
H = (P_out - P_in) / (ρ * g) + (v_out² - v_in²) / (2 * g) + (z_out - z_in)
```

**典型曲线形状**：
```
H (m)
│
50 ├─────╮
   │      ╲
40 │       ╲
   │        ╲
30 │         ╲
   │          ╲
20 │           ╲
   │            ╲
10 │             ╲___
   │
0  └─────────────────────> Q (m³/h)
   0   100  200  300  400
```

### 1.3 数学模型

**标准二次多项式**：
```
H = a₀ + a₁Q + a₂Q²
```

**约束条件**：
- a₂ < 0 (保证递减)
- a₀ > 0 (零流量扬程为正)

### 2.2 QHDataExtractor 数据提取器

| 属性 | 说明 |
|------|------|
| **职责** | 从 fact_measurements 提取 Q-H 数据 |
| **必需指标** | `pump_flow_rate`, `pump_head` |

```python
from datetime import datetime
import pandas as pd
import logging
from app.adapters.db.pool import get_connection
from app.services.characteristic_curves.shared.exceptions import DataExtractionError  # v2.6新增

class QHDataExtractor:
    """Q-H曲线数据提取器"""

    REQUIRED_METRICS = ['pump_flow_rate', 'pump_head']

    def __init__(self):
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

    def extract(
        self,
        device_id: int,
        start_time: datetime,
        end_time: datetime,
        min_points: int = 100  # 数据提取建议点数（v2.6统一修复）
    ) -> pd.DataFrame:
        """
        提取Q-H数据

        Args:
            device_id: 设备ID
            start_time: 开始时间
            end_time: 结束时间
            min_points: 最小数据点数（默认100，对应MIN_EXTRACTION_POINTS）
                       这是数据提取阶段的建议值，确保有足够数据进行筛选
                       实际拟合时会使用MIN_DATA_POINTS(50)进行验证

        Returns:
            DataFrame: 包含ts_bucket, Q, H列的数据

        Raises:
            DataExtractionError: 数据提取失败
        """
        sql = """
            SELECT
                ts_bucket,
                MAX(CASE WHEN metric_id = (
                    SELECT id FROM dim_metric_config
                    WHERE metric_key = 'pump_flow_rate'
                ) THEN value END) AS Q,
                MAX(CASE WHEN metric_id = (
                    SELECT id FROM dim_metric_config
                    WHERE metric_key = 'pump_head'
                ) THEN value END) AS H
            FROM fact_measurements
            WHERE device_id = %(device_id)s
              AND ts_bucket BETWEEN %(start_time)s AND %(end_time)s
            GROUP BY ts_bucket
            HAVING Q IS NOT NULL AND H IS NOT NULL
            ORDER BY ts_bucket
        """

        with get_connection() as conn:
            with conn.cursor() as cursor:
                cursor.execute(sql, {
                    'device_id': device_id,
                    'start_time': start_time,
                    'end_time': end_time
                })
                rows = cursor.fetchall()
                columns = [desc[0] for desc in cursor.description]

        data = pd.DataFrame(rows, columns=columns)

        if len(data) < min_points:
            raise DataExtractionError(f"数据点不足: {len(data)} < {min_points}")

        return data
```

### 2.3 QHConstraints 物理约束

| 约束类型 | 条件 | 说明 |
|---------|------|------|
| **单调性** | dH/dQ < 0 | 全范围递减 |
| **边界-零流量** | H(0) ≈ 1.1~1.3 × H_rated | 关阀扬程 |
| **边界-最大流量** | H(Q_max) > 0 | 扬程为正 |
| **凸性** | d²H/dQ² > 0 | 下凸曲线 |

**约束计算**：
```python
class QHConstraints:
    def calculate(self, data: pd.DataFrame, device_params: Dict) -> Dict:
        """
        计算约束参数

        输出: Dict{H0, Q_max, K, H_rated, Q_rated, monotonicity, convexity}
        """
        H_rated = device_params['rated_head']
        Q_rated = device_params['rated_flow']

        return {
            'H0': H_rated * 1.2,           # 零流量扬程估算
            'Q_max': Q_rated * 1.2,        # 最大流量
            'K': (H_rated * 1.2 - H_rated) / (Q_rated ** 2),  # 阻力系数
            'H_rated': H_rated,
            'Q_rated': Q_rated,
            'monotonicity': 'decreasing',
            'convexity': 'convex'
        }
```

### 2.4 QHValidator 验证器

| 验证项 | 标准 | 说明 |
|--------|------|------|
| **精度** | R² > 0.95 | 拟合优度 |
| **误差** | RMSE < 2m | 均方根误差 |
| **单调性** | 全范围 dH/dQ < 0 | 物理约束 |
| **边界** | H(0) ≈ H₀ | 零流量点 |
| **凸性** | d²H/dQ² > 0 | 下凸曲线 |
| **交叉验证** | K-fold | 稳定性验证 |

## 3. 数据流详细

### 3.1 Q-H曲线拟合流程（权威13阶段）

> **📋 说明**：本节描述Q-H曲线拟合的核心阶段，遵循权威13阶段定义。
> 完整的13阶段定义请参见 [02_数据流定义.md](../02_架构设计/02_数据流定义.md)。
>
> Q-H曲线拟合涉及以下核心阶段：
> - 阶段3：数据提取
> - 阶段4：数据清洗
> - 阶段6：约束计算
> - 阶段8：归一化
> - 阶段9：方法选择
> - 阶段10：拟合
> - 阶段11：验证
> - 阶段12：历史评估
> - 阶段13：存储

```

┌─────────────────────────────────────────────────────────────────────────────┐
│ 输入: device_id, start_time, end_time                                       │
│ 处理:                                                                       │
│   1. 查询 fact_measurements 表                                              │
│   2. 提取 pump_flow_rate (Q) 和 pump_head (H) 指标                          │
│   3. 按时间戳聚合数据                                                        │

                                    │
                                    ▼
阶段4: 数据清洗 [QHPreprocessor]
┌─────────────────────────────────────────────────────────────────────────────┐
│ 输入: DataFrame[ts_bucket, Q, H]                                            │
│ 处理:                                                                       │
│   1. 删除无效值（Q<0 或 H<0）                                                │
│   2. 删除异常值（物理约束法推荐）                                              │
│   3. 删除重复值                                                              │
│   4. 运行点筛选（只保留泵运行状态的数据）                                      │

                                    │
                                    ▼
阶段6: 约束计算 [QHConstraints]
┌─────────────────────────────────────────────────────────────────────────────┐
│ 输入: DataFrame[Q, H], device_params                                        │
│ 处理:                                                                       │
│   1. 计算 H₀（零流量扬程）: 使用Q→0外推或额定参数估算                          │

┌─────────────────────────────────────────────────────────────────────────────┐
│ 输入: DataFrame[Q, H], constraints                                          │
│ 处理:                                                                       │
│   1. Q归一化: Q_norm = Q / Q_rated                                          │
```

## 4. 使用示例

```python
from app.services.characteristic_curves.curves import QHCurve
from datetime import datetime

# 创建曲线实例
qh_curve = QHCurve(
    storage=result_storage,
    cache=cache_manager,
    batch_processor=batch_processor,
    parameter_optimizer=parameter_optimizer,
    historical_evaluator=historical_evaluator
)

# 执行拟合
result = qh_curve.fit(
    device_id=12345,
    start_time=datetime(2025, 1, 1),
    end_time=datetime(2025, 6, 30),
    methods=['physics_pump_char', 'math_poly_2']
)

print(f"最佳方法: {result.method_name}")
print(f"R²: {result.r_squared:.4f}")
print(f"系数: {result.coefficients}")

# 预测
H = qh_curve.predict(x=300)  # Q=300时的扬程
print(f"Q=300 m³/h 时, H={H:.2f} m")
```
