## 1. BaseCurve 曲线基类

### 1.1 功能概述

| 属性 | 说明 |
|------|------|
| **文件路径** | `app/services/characteristic_curves/curves/base_curve.py` |
| **职责** | 所有曲线模块的抽象基类 |
| **设计模式** | 模板方法模式 |
| **依赖** | 共用层所有模块 |

**核心职责**：
1. 定义统一的拟合流程（模板方法）
2. 管理子模块的依赖注入
3. 提供通用工具方法
4. 定义抽象方法接口

### 1.2 核心接口

```python
from abc import ABC, abstractmethod
from typing import Dict, Any, Optional, List
from datetime import datetime
import pandas as pd
import logging

class BaseCurve(ABC):
    """曲线基类 - 所有曲线模块的抽象基类"""

    # 曲线类型（子类必须定义）
    curve_type: str = None

    # 物理约束类型
    monotonicity: str = None  # 'increasing', 'decreasing', 'unimodal'

    # 推荐方法
    recommended_methods: List[str] = []

    def __init__(
        self,
        storage: 'ResultStorage',
        cache: 'CacheManager',
        batch_processor: 'BatchProcessor',
        parameter_optimizer: 'ParameterOptimizer',
        historical_evaluator: 'HistoricalDataEvaluator'
    ):
        """
        初始化曲线模块（依赖注入）

        Args:
            storage: 结果存储器
            cache: 缓存管理器
            batch_processor: 批处理器
            parameter_optimizer: 参数优化器
            historical_evaluator: 历史数据评估器
        """
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")
        self._storage = storage
        self._cache = cache
        self._batch_processor = batch_processor
        self._parameter_optimizer = parameter_optimizer
        self._historical_evaluator = historical_evaluator

        # 初始化子模块（子类实现）
        self._init_submodules()

    @abstractmethod
    def _init_submodules(self) -> None:
        """初始化子模块（由子类实现）"""
        pass

    @abstractmethod
    def extract_data(
        self,
        device_id: int,
        start_time: datetime,
        end_time: datetime
    ) -> pd.DataFrame:
        """提取数据（由子类实现）"""
        pass

    @abstractmethod
    def preprocess(self, data: pd.DataFrame) -> pd.DataFrame:
        """预处理数据（由子类实现）"""
        pass

    @abstractmethod
    def calculate_constraints(
        self,
        data: pd.DataFrame,
        device_params: Dict[str, Any]
    ) -> Dict[str, Any]:
        """计算物理约束参数（由子类实现）"""
        pass

    def fit(
        self,
        device_id: int,
        start_time: datetime,
        end_time: datetime,
        methods: Optional[List[str]] = None,
        device_params: Optional[Dict[str, Any]] = None
    ) -> 'FitResult':
        """
        执行拟合（模板方法）

        Args:
            device_id: 设备ID
            start_time: 开始时间
            end_time: 结束时间
            methods: 指定方法列表（可选）
            device_params: 设备参数（可选）

        Returns:
            FitResult: 拟合结果
        """
        self._logger.info(
            f"开始拟合: device_id={device_id}, curve_type={self.curve_type}",
            extra={"extra_data": {
                "设备ID": device_id,
                "曲线类型": self.curve_type,
                "开始时间": str(start_time),
                "结束时间": str(end_time)
            }}
        )

        # ═══════════════════════════════════════════════════════════════════
        # 📋 阶段映射说明（简化版9阶段 → 权威13阶段）
        # ───────────────────────────────────────────────────────────────────
        # 本方法实现简化版9阶段流程，与权威13阶段的映射关系如下：
        # 简化阶段1 (数据提取)    → 权威阶段3 (数据提取)
        # 简化阶段2 (数据预处理)  → 权威阶段4 (数据清洗)
        # 简化阶段3 (约束计算)    → 权威阶段6 (约束计算)
        # 简化阶段4 (归一化)      → 权威阶段8 (标准化)
        # 简化阶段5 (方法选择)    → 权威阶段9 (方法选择)
        # 简化阶段6 (拟合)        → 权威阶段10 (拟合)
        # 简化阶段7 (验证)        → 权威阶段11 (验证)
        # 简化阶段8 (历史评估)    → 权威阶段12 (历史评估)
        # 简化阶段9 (存储)        → 权威阶段13 (存储)
        #
        # 权威阶段1 (时间窗口划分)、阶段2 (场景识别)、阶段5 (稳态识别)、
        # 阶段7 (频率归一化) 在 CurveFittingPipeline 中处理
        # 详见: ../02_架构设计/02_数据流定义.md
        # ═══════════════════════════════════════════════════════════════════

        # 简化阶段1: 数据提取 (对应权威阶段3)
        raw_data = self.extract_data(device_id, start_time, end_time)

        # 简化阶段2: 数据预处理 (对应权威阶段4)
        clean_data = self.preprocess(raw_data)

        # 简化阶段3: 计算约束参数 (对应权威阶段6)
        constraints = self.calculate_constraints(clean_data, device_params or {})

        # 简化阶段4: 归一化 (对应权威阶段8)
        normalized_data, norm_params = self._normalizer.normalize(clean_data)

        # 简化阶段5: 方法选择 (对应权威阶段9)
        selected_methods = methods or self._method_selector.select(
            data=normalized_data,
            constraints=constraints
        )

        # 简化阶段6: 拟合 (对应权威阶段10)
        fit_result = self._fitter.fit(
            data=normalized_data,
            methods=selected_methods,
            constraints=constraints
        )

        # 简化阶段7: 验证 (对应权威阶段11)
        validation_result = self._validator.validate(
            fit_result=fit_result,
            original_data=clean_data,
            constraints=constraints
        )

        # 简化阶段8: 历史评估 (对应权威阶段12)
        evaluation = self._historical_evaluator.evaluate(
            device_id=device_id,
            curve_type=self.curve_type,
            current_result=fit_result
        )

        # 简化阶段9: 存储 (对应权威阶段13)
        version = self._storage.save(
            device_id=device_id,
            curve_type=self.curve_type,
            fit_result=fit_result,
            validation_result=validation_result,
            evaluation=evaluation
        )

        return fit_result

    def predict(self, x: float, version: Optional[str] = None) -> float:
        """预测Y值"""
        pass

    def get_latest_result(self, device_id: int) -> Optional['FitResult']:
        """获取最新拟合结果"""
        return self._storage.load_latest(device_id, self.curve_type)
```

## 2. 异常体系

### 2.1 异常类定义

> **权威来源**: 完整异常体系定义见 [03_核心模块/03_共用层.md](../03_核心模块/03_共用层.md#异常类)

```python
# 文件路径: app/services/characteristic_curves/shared/exceptions.py
# 注意：与 03_共用层.md 中的定义保持一致

class CurveFittingError(Exception):
    """特性曲线拟合系统基础异常类"""
    def __init__(self, message: str, device_id: int = None, curve_type: str = None):
        self.message = message
        self.device_id = device_id
        self.curve_type = curve_type
        super().__init__(self.message)


class DataError(CurveFittingError):
    """数据相关异常"""
    pass


class DataNotFoundError(DataError):
    """数据不存在异常"""
    pass


class DataInsufficientError(DataError):
    """数据量不足异常"""
    def __init__(self, message: str, required: int, actual: int, **kwargs):
        self.required = required
        self.actual = actual
        super().__init__(message, **kwargs)


class DataQualityError(DataError):
    """数据质量异常（异常值过多、缺失率过高等）"""
    pass


class ParameterError(CurveFittingError):
    """参数相关异常"""
    pass


class ParameterMissingError(ParameterError):
    """参数缺失异常（设备额定参数缺失）"""
    def __init__(self, message: str, missing_params: list, **kwargs):
        self.missing_params = missing_params
        super().__init__(message, **kwargs)


class FittingError(CurveFittingError):
    """拟合相关异常"""
    pass


class FittingFailedError(FittingError):
    """拟合失败异常（所有方法都失败）"""
    pass


class ValidationError(CurveFittingError):
    """验证相关异常"""
    pass


class ConstraintViolationError(ValidationError):
    """约束违反异常"""
    def __init__(self, message: str, violated_constraints: list, **kwargs):
        self.violated_constraints = violated_constraints
        super().__init__(message, **kwargs)
```

### 2.2 异常层次图

```
CurveFittingError (基础异常)
├── DataError (数据异常)
│   ├── DataNotFoundError (数据不存在)
│   ├── DataInsufficientError (数据量不足)
│   └── DataQualityError (数据质量问题)
├── ParameterError (参数异常)
│   ├── ParameterMissingError (参数缺失)
│   └── ParameterInvalidError (参数无效)
├── FittingError (拟合异常)
│   ├── FittingFailedError (拟合失败)
│   └── FittingTimeoutError (拟合超时)
├── ValidationError (验证异常)
│   ├── ConstraintViolationError (约束违反)
│   └── PhysicsViolationError (物理约束违反)
└── StorageError (存储异常)
    ├── DatabaseError (数据库异常)
    └── CacheError (缓存异常)
```

### 2.3 异常处理策略

| 异常类型 | 处理策略 | 是否重试 | 日志级别 |
|---------|---------|---------|---------|
| `DataNotFoundError` | 跳过该设备/曲线 | ❌ | WARNING |
| `DataInsufficientError` | 跳过该设备/曲线 | ❌ | WARNING |
| `DataQualityError` | 尝试数据清洗后重试 | ✅ 1次 | WARNING |
| `ParameterMissingError` | 中断拟合，输出错误日志 | ❌ | ERROR |
| `ParameterInvalidError` | 中断拟合，输出错误日志 | ❌ | ERROR |
| `FittingFailedError` | 尝试下一个方法 | ✅ 按方法列表 | WARNING |
| `FittingTimeoutError` | 尝试下一个方法 | ✅ 按方法列表 | WARNING |
| `ConstraintViolationError` | 记录违反详情，继续拟合 | ✅ | INFO |
| `PhysicsViolationError` | 标记结果为低置信度 | ❌ | WARNING |
| `DatabaseError` | 重试3次后中断 | ✅ 3次 | ERROR |
| `CacheError` | 忽略缓存，继续执行 | ❌ | WARNING |

## 4. 约束违反处理

### 4.1 约束类型与处理方式

| 约束类型 | 违反示例 | 处理方式 | 结果标记 |
|---------|---------|---------|---------|
| **单调性约束** | Q-H曲线局部递增 | 记录违反区间，继续拟合 | `monotonicity_violation: true` |
| **边界约束** | H(0) < 0 或 H(Q_max) < 0 | 调整边界参数后重试 | `boundary_adjusted: true` |
| **物理约束** | 效率 > 1.0 | 截断到合理范围 | `physics_truncated: true` |
| **数据范围约束** | Q > 1.2 * Q_rated | 过滤超范围数据 | `data_filtered: true` |

### 4.2 处理代码示例

```python
def handle_constraint_violation(
    self,
    violation: ConstraintViolationError,
    fit_result: FitResult
) -> FitResult:
    """处理约束违反"""
    for constraint in violation.violated_constraints:
        if constraint['type'] == 'monotonicity':
            fit_result.warnings.append(f"单调性违反: {constraint['details']}")
            fit_result.confidence = 'low'
        elif constraint['type'] == 'boundary':
            fit_result = self._adjust_boundary(fit_result, constraint)
        elif constraint['type'] == 'physics':
            fit_result = self._truncate_physics(fit_result, constraint)
    return fit_result
```

## 5. 重试机制

### 5.1 重试配置参数

| 参数名称 | 默认值 | 说明 |
|---------|--------|------|
| `max_retries` | 3 | 最大重试次数 |
| `retry_delay_seconds` | 1.0 | 重试间隔（秒） |
| `retry_backoff_factor` | 2.0 | 退避因子（指数退避） |
| `retry_max_delay_seconds` | 30.0 | 最大重试间隔 |

### 5.2 重试装饰器

```python
import time
from functools import wraps

def with_retry(max_retries: int = 3, delay: float = 1.0, backoff: float = 2.0):
    """重试装饰器"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            last_exception = None
            current_delay = delay

            for attempt in range(max_retries + 1):
                try:
                    return func(*args, **kwargs)
                except (DatabaseError, TimeoutError, ConnectionError) as e:
                    last_exception = e
                    if attempt < max_retries:
                        time.sleep(current_delay)
                        current_delay = min(current_delay * backoff, 30.0)
                    else:
                        raise
            raise last_exception
        return wrapper
    return decorator
```
