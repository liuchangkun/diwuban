## 1. 概述

### 1.1 并联特性核心原理

```
并联泵组核心特性：
- 扬程相同：H₁ = H₂ = ... = H_N = H_system
- 流量叠加：Q_total = Q₁ + Q₂ + ... + Q_N
- 功率叠加：P_total = P₁ + P₂ + ... + P_N
- 效率计算：η_total = (ρgQ_total·H_system) / P_total
```

### 1.2 适用范围

| 泵组类型 | 适用曲线 | 处理策略 |
|---------|---------|---------|
| 同构泵组（相同型号） | 全部15条 | 基准泵 × N + 修正 |
| 异构泵组（不同型号） | 全部15条 | 各泵独立 + 合成 + 修正 |
| 混合泵组（VFD+SS） | 全部15条 | 分类处理 + 合成 + 修正 |

## 2. 核心曲线（曲线1-3）

### 2.1 第1条：N台并联Q-H曲线

**物理原理**：
```
Q_total = Q₁ + Q₂ + ... + Q_N  （在相同H下）
H_group(Q_total) = H_single(Q_total / N)  （同构泵组简化）
```

**技术实现**：
```python
# 同构泵组
group_curve = synthesizer.synthesize_homogeneous(base_pump_id=1, n_pumps=3)
H = group_curve(Q_total=1500)  # Q_single = 500

# 异构泵组
result = synthesizer.synthesize_heterogeneous(pump_ids=[1,2,3], H_system=35.0)
Q_total = result.Q_total
```

**应用价值**：
- 泵站扬程-流量特性分析
- 系统设计和选型
- 运行工况预测

### 2.2 第2条：N台并联Q-P曲线

**物理原理**：
```
P_total = P₁ + P₂ + ... + P_N
P_i = f_i(Q_i, H_system)  （各泵功率由其工况决定）
```

**技术实现**：
```python
# 需要注册功率曲线
synthesizer.register_pump_curve(
    pump_id=1,
    curve_func=qh_func,
    inverse_func=hq_func,
    power_func=qp_func  # 可选：Q → P 函数
)

# 计算总功率
result = synthesizer.synthesize_heterogeneous(pump_ids, H_system)
P_total = result.P_total
```

**应用价值**：
- 能耗预测
- 电费估算
- 节能分析

### 2.3 第3条：N台并联Q-η曲线

**物理原理**：
```
η_total = (ρg × Q_total × H_system) / P_total
       = 有效功率 / 轴功率
```

**技术实现**：
```python
# 效率计算
result = synthesizer.synthesize_heterogeneous(pump_ids, H_system)
rho = 1000  # kg/m³
g = 9.81    # m/s²
Q_m3s = result.Q_total / 3600  # m³/h → m³/s
eta_total = (rho * g * Q_m3s * result.H_system) / (result.P_total * 1000)
```

**应用价值**：
- 运行效率评估
- 最佳工况确定
- 优化调度

def get_load_distribution(

    Args:

                      如未传入，使用实例化时的_rated_powers

    Returns:
        Dict[int, float]: 各泵负荷率 {pump_id: load_ratio}

### 5.1 第10条：泵组启停策略曲线

**定义**：根据流量需求和效率优化，确定泵组的启停顺序和时机。

**物理原理**：
```
启动条件：当Q_demand > Q_current_max × 启动裕度(0.9)时，启动下一台泵
停止条件：当Q_demand < Q_reduced_max × 停止裕度(0.8)时，停止一台泵
```

**技术实现**：
```python
class StartStopStrategy:
    """泵组启停策略生成器【v3.3更新：完整变频支持】"""

    def __init__(
        self,
        synthesizer: ParallelSynthesizer,
        pump_infos: Optional[Dict[int, Dict]] = None,      # v3.3新增
        pump_frequencies: Optional[Dict[int, float]] = None  # v3.3新增
    ):
        self._synthesizer = synthesizer
        self._pump_infos = pump_infos          # v3.3新增：泵信息
        self._pump_frequencies = pump_frequencies  # v3.3新增：运行频率
        self._start_margin = 0.90  # 启动裕度
        self._stop_margin = 0.80   # 停止裕度
        self._min_run_time = 300   # 最小运行时间(秒)

    @staticmethod
    def _ordinal(n: int) -> str:
        """
        生成序数词后缀：1st, 2nd, 3rd, 4th...

        用于生成正确的JSONB键名，如 'start_2nd', 'stop_3rd'
        """
        if 11 <= n <= 13:
            return f"{n}th"
        suffix = {1: "st", 2: "nd", 3: "rd"}.get(n % 10, "th")
        return f"{n}{suffix}"

    def generate_strategy(
        self,
        pump_ids: List[int],
        H_system: float,
        Q_range: Tuple[float, float] = (0, 5000)
    ) -> Dict[str, Any]:
        """
        生成启停策略曲线【v3.3增强：支持变频泵】

        Returns:
            {
                'thresholds': {
                    'start_2nd': 600.0,   # 启动第2台的流量阈值
                    'start_3rd': 1100.0,  # 启动第3台的流量阈值
                    'stop_3rd': 900.0,    # 停止第3台的流量阈值
                    'stop_2nd': 400.0     # 停止第2台的流量阈值
                },
                'priority_sequence': [101, 102, 103],  # 启动优先级
                'curve_data': [...]  # 详细曲线数据
            }

        Note:
            v3.3修复P14：使用构造函数中的pump_infos和pump_frequencies
        """
        # v3.3：传递pump_infos和pump_frequencies参数
        n_q_result = self._synthesizer.generate_n_q_curve(
            pump_ids, H_system,
            pump_infos=self._pump_infos,
            pump_frequencies=self._pump_frequencies
        )

        # v3.2修复P2: 从新返回格式中提取数据，使用大写'N'
        n_q_data = n_q_result['data']
        n_q_map = {item['N']: item['Q_total'] for item in n_q_data}

        thresholds = {}
        curve_data = []
        max_pumps = len(pump_ids)

        for n in range(1, max_pumps):
            Q_n = n_q_map[n]
            Q_n_plus_1 = n_q_map.get(n + 1, Q_n)

            # 启动阈值：当前台数最大流量 × 启动裕度
            start_threshold = Q_n * self._start_margin
            # 停止阈值：减少一台后的最大流量 × 停止裕度
            stop_threshold = n_q_map.get(n, Q_n) * self._stop_margin if n > 1 else 0

            thresholds[f'start_{self._ordinal(n+1)}'] = start_threshold
            if n > 1:
                thresholds[f'stop_{self._ordinal(n)}'] = stop_threshold

            curve_data.append({
                'N': n,
                'Q_max': Q_n,
                'start_next_at': start_threshold,
                'stop_current_at': stop_threshold if n > 1 else None
            })

        # v3.3：传递pump_frequencies参数
        priority_sequence = self._determine_priority_sequence(
            pump_ids, H_system, self._pump_frequencies
        )

        return {
            'thresholds': thresholds,
            'priority_sequence': priority_sequence,
            'curve_data': curve_data,
            'config': {
                'start_margin': self._start_margin,
                'stop_margin': self._stop_margin,
                'min_run_time': self._min_run_time
            },
            'generated_at': datetime.now().isoformat()
        }

    def recommend_action(
        self,
        Q_demand: float,
        running_pumps: List[int],
        available_pumps: List[int],
        strategy: Dict[str, Any]
    ) -> Dict[str, Any]:
        """
        根据策略推荐启停动作

        Returns:
            {
                'action': 'start' | 'stop' | 'none',
                'pump_id': int | None,
                'reason': str,
                'expected_efficiency': float
            }
        """
        n_running = len(running_pumps)
        thresholds = strategy['thresholds']
        priority = strategy['priority_sequence']

        # 检查是否需要启动
        start_key = f'start_{self._ordinal(n_running + 1)}'
        if start_key in thresholds and Q_demand >= thresholds[start_key]:
            for pump_id in priority:
                if pump_id not in running_pumps and pump_id in available_pumps:
                    return {
                        'action': 'start',
                        'pump_id': pump_id,
                        'reason': f'Q_demand={Q_demand:.0f} >= 启动阈值{thresholds[start_key]:.0f}',
                        'expected_efficiency': None
                    }

        # 检查是否需要停止
        stop_key = f'stop_{self._ordinal(n_running)}'
        if stop_key in thresholds and Q_demand <= thresholds[stop_key]:
            for pump_id in reversed(priority):
                if pump_id in running_pumps:
                    return {
                        'action': 'stop',
                        'pump_id': pump_id,
                        'reason': f'Q_demand={Q_demand:.0f} <= 停止阈值{thresholds[stop_key]:.0f}',
                        'expected_efficiency': None
                    }

        return {'action': 'none', 'pump_id': None, 'reason': '当前台数合适', 'expected_efficiency': None}

    def _determine_priority_sequence(
        self,
        pump_ids: List[int],
        H_system: float,
        pump_frequencies: Optional[Dict[int, float]] = None  # v3.3新增
    ) -> List[int]:
        """确定泵启动优先级（效率高的优先）【v3.3增强：支持变频泵】"""
        efficiencies = {}
        for pump_id in pump_ids:
            try:
                # v3.3：传递pump_frequencies参数
                result = self._synthesizer.synthesize_heterogeneous(
                    [pump_id], H_system, pump_frequencies
                )
                efficiencies[pump_id] = result.eta_total
            except Exception:
                efficiencies[pump_id] = 0.0

        return sorted(pump_ids, key=lambda x: efficiencies.get(x, 0), reverse=True)
```

**应用价值**：
- 自动化泵组调度
- 减少人工干预
- 优化能耗

### 5.2 第11条：泵组切换时机曲线

**定义**：确定从N台运行切换到N±1台运行的最佳时机，避免频繁切换。

**物理原理**：
```
效率交叉点：η(N, Q) = η(N+1, Q) 的流量Q_crossover
滞回区间：[Q_crossover - Δ, Q_crossover + Δ]，防止频繁切换
```

**技术实现**：
```python
class SwitchingTimingAnalyzer:
    """泵组切换时机分析器【v3.3更新：完整变频支持】"""

    def __init__(
        self,
        synthesizer: ParallelSynthesizer,
        system_curve_func: Optional[Callable[[float], float]] = None,
        pump_frequencies: Optional[Dict[int, float]] = None  # v3.3新增
    ):
        """
        Args:
            synthesizer: 并联合成器
            system_curve_func: 系统曲线函数 H = f(Q)，用于给定Q求H
                如果不提供，将使用二分法在扬程范围内查找
            pump_frequencies: 各泵运行频率【v3.3新增】

        Note:
            v3.3修复P13：添加pump_frequencies参数支持变频泵
        """
        self._synthesizer = synthesizer
        self._system_curve_func = system_curve_func
        self._pump_frequencies = pump_frequencies  # v3.3新增
        self._hysteresis = 50.0  # 滞回宽度 (m³/h)

    def analyze(
        self,
        pump_ids: List[int],
        H_range: Tuple[float, float] = (20.0, 60.0),
        Q_range: Tuple[float, float] = (100, 3000),
        step: float = 10.0
    ) -> Dict[str, Any]:
        """
        分析切换时机【v3.1修复】

        物理原理：
        1. 给定目标流量Q_target
        2. 反向求解对应的系统扬程H（通过系统曲线或二分法）
        3. 在该工作点计算泵组效率
        4. 比较不同台数在同一流量下的效率

        Args:
            pump_ids: 候选泵ID列表
            H_range: 扬程搜索范围 (m)，用于二分法求解
            Q_range: 流量分析范围 (m³/h)
            step: 流量步长 (m³/h)

        Returns:
            {
                'crossover_points': [
                    {'from_N': 1, 'to_N': 2, 'Q_crossover': 550.0, 'eta_at_crossover': 0.78},
                    {'from_N': 2, 'to_N': 3, 'Q_crossover': 1050.0, 'eta_at_crossover': 0.76}
                ],
                'switching_zones': [
                    {'from_N': 1, 'to_N': 2, 'Q_min': 500.0, 'Q_max': 600.0},
                    ...
                ],
                'efficiency_curves': {...}
            }
        """
        import numpy as np

        Q_values = np.arange(Q_range[0], Q_range[1] + step, step)
        max_pumps = len(pump_ids)

        # 计算各台数下的效率曲线
        efficiency_curves = {n: [] for n in range(1, max_pumps + 1)}

        for n in range(1, max_pumps + 1):
            selected = pump_ids[:n]
            for Q_target in Q_values:
                try:
                    # v3.1修复：给定Q_target，反向求解工作点
                    point = self._find_operating_point(selected, Q_target, H_range)
                    if point is not None:
                        efficiency_curves[n].append({
                            'Q': float(Q_target),
                            'H': point['H'],
                            'eta': point['eta']
                        })
                    else:
                        # 该台数无法达到目标流量
                        efficiency_curves[n].append({'Q': float(Q_target), 'H': None, 'eta': None})
                except Exception:
                    efficiency_curves[n].append({'Q': float(Q_target), 'H': None, 'eta': None})

        # 找效率交叉点
        crossover_points = []
        for n in range(1, max_pumps):
            crossover = self._find_crossover(
                efficiency_curves[n],
                efficiency_curves[n + 1],
                n, n + 1
            )
            if crossover:
                crossover_points.append(crossover)

        # 生成切换区间（含滞回）
        switching_zones = [
            {
                'from_N': cp['from_N'],
                'to_N': cp['to_N'],
                'Q_min': cp['Q_crossover'] - self._hysteresis,
                'Q_max': cp['Q_crossover'] + self._hysteresis
            }
            for cp in crossover_points
        ]

        return {
            'crossover_points': crossover_points,
            'switching_zones': switching_zones,
            'efficiency_curves': efficiency_curves,
            'hysteresis': self._hysteresis,
            'generated_at': datetime.now().isoformat()
        }

    def _find_crossover(
        self,
        curve_n: List[Dict],
        curve_n_plus_1: List[Dict],
        n: int,
        n_plus_1: int
    ) -> Optional[Dict]:
        """找两条效率曲线的交叉点"""
        for i in range(len(curve_n) - 1):
            eta_n_curr = curve_n[i].get('eta')
            eta_n_next = curve_n[i + 1].get('eta')
            eta_np1_curr = curve_n_plus_1[i].get('eta') if i < len(curve_n_plus_1) else None
            eta_np1_next = curve_n_plus_1[i + 1].get('eta') if i + 1 < len(curve_n_plus_1) else None

            if all(v is not None for v in [eta_n_curr, eta_n_next, eta_np1_curr, eta_np1_next]):
                # 检查是否交叉
                if (eta_n_curr - eta_np1_curr) * (eta_n_next - eta_np1_next) < 0:
                    Q_crossover = (curve_n[i]['Q'] + curve_n[i + 1]['Q']) / 2
                    eta_at_crossover = (eta_n_curr + eta_np1_curr) / 2
                    return {
                        'from_N': n,
                        'to_N': n_plus_1,
                        'Q_crossover': Q_crossover,
                        'eta_at_crossover': eta_at_crossover
                    }

        return None

    def _find_operating_point(
        self,
        pump_ids: List[int],
        Q_target: float,
        H_range: Tuple[float, float],
        tolerance: float = 1.0
    ) -> Optional[Dict]:
        """
        给定目标流量，反向求解工作点【v3.3增强：支持变频泵】

        物理原理：
        - 并联泵组在给定扬程H下产生总流量Q
        - 使用二分法找到使 Q_total ≈ Q_target 的 H

        Args:
            pump_ids: 运行泵ID列表
            Q_target: 目标流量 (m³/h)
            H_range: 扬程搜索范围 (m)
            tolerance: 流量容差 (m³/h)

        Returns:
            {'H': float, 'Q': float, 'eta': float} 或 None（无法达到）

        Note:
            v3.3修复P13：使用构造函数中的_pump_frequencies
        """
        # 如果提供了系统曲线函数，直接使用
        if self._system_curve_func is not None:
            H = self._system_curve_func(Q_target)
            # v3.3：传递pump_frequencies参数
            result = self._synthesizer.synthesize_heterogeneous(
                pump_ids, H, self._pump_frequencies
            )
            return {
                'H': H,
                'Q': result.Q_total,
                'eta': result.eta_total
            }

        # 否则使用二分法在H_range内搜索
        H_low, H_high = H_range
        max_iterations = 50

        for _ in range(max_iterations):
            H_mid = (H_low + H_high) / 2
            # v3.3：传递pump_frequencies参数
            result = self._synthesizer.synthesize_heterogeneous(
                pump_ids, H_mid, self._pump_frequencies
            )
            Q_actual = result.Q_total

            if abs(Q_actual - Q_target) < tolerance:
                return {
                    'H': H_mid,
                    'Q': Q_actual,
                    'eta': result.eta_total
                }

            # 扬程越高，流量越低（并联泵组特性）
            if Q_actual > Q_target:
                H_low = H_mid  # 需要更高扬程来减少流量
            else:
                H_high = H_mid  # 需要更低扬程来增加流量

        # 二分法未收敛，返回最后一次结果
        # v3.3：传递pump_frequencies参数
        result = self._synthesizer.synthesize_heterogeneous(
            pump_ids, H_mid, self._pump_frequencies
        )
        if result.Q_total >= Q_target * 0.9:  # 允许10%误差
            return {
                'H': H_mid,
                'Q': result.Q_total,
                'eta': result.eta_total
            }

        return None  # 无法达到目标流量
```

**应用价值**：
- 确定最优切换点
- 减少频繁切换
- 提高运行稳定性

### 5.3 第12条：泵组切换过程曲线

**定义**：描述切换过程中的流量、压力变化轨迹，用于预测水力冲击。

**物理原理**：
```
切换过程建模：
- 停泵：流量逐渐下降，压力先升后降
- 启泵：流量逐渐上升，压力先降后升
- 过渡时间取决于管网惯性和泵启动特性
```

**技术实现**：
```python
class SwitchingProcessSimulator:
    """泵组切换过程模拟器"""

    def __init__(self, synthesizer: ParallelSynthesizer):
        self._synthesizer = synthesizer
        self._transition_time = 30.0  # 过渡时间(秒)
        self._time_step = 1.0  # 时间步长(秒)

    def simulate(
        self,
        pump_ids_before: List[int],
        pump_ids_after: List[int],
        H_system: float,
        action: str = 'stop',  # 'start' or 'stop'
        pump_frequencies: Optional[Dict[int, float]] = None  # v3.2新增P10修复
    ) -> Dict[str, Any]:
        """
        模拟切换过程【v3.2增强：支持变频泵】

        Args:
            pump_ids_before: 切换前运行的泵
            pump_ids_after: 切换后运行的泵
            H_system: 系统扬程
            action: 'start'启动 或 'stop'停止
            pump_frequencies: 运行频率字典【v3.2新增】
                格式: {pump_id: freq_Hz}

        Returns:
            {
                'trajectory': [
                    {'t': 0, 'Q': 1200, 'H': 35.0, 'P': 120, 'status': 'before'},
                    {'t': 5, 'Q': 1150, 'H': 35.5, 'status': 'transitioning'},
                    ...
                ],
                'max_pressure_surge': 2.5,  # 最大压力波动(m)
                'min_flow_dip': 50.0,  # 最小流量下降(m³/h)
                'stabilization_time': 25.0  # 稳定时间(秒)
            }
        """
        import numpy as np

        # v3.2修复P10：计算切换前后的稳态点，传递pump_frequencies参数
        result_before = self._synthesizer.synthesize_heterogeneous(pump_ids_before, H_system, pump_frequencies)
        result_after = self._synthesizer.synthesize_heterogeneous(pump_ids_after, H_system, pump_frequencies)

        Q_before = result_before.Q_total
        Q_after = result_after.Q_total
        P_before = result_before.P_total
        P_after = result_after.P_total

        # 生成过渡轨迹（使用S形曲线）
        trajectory = []
        t_values = np.arange(0, self._transition_time + self._time_step, self._time_step)

        for t in t_values:
            # S形过渡函数
            progress = self._sigmoid_transition(t / self._transition_time)

            Q_t = Q_before + (Q_after - Q_before) * progress
            P_t = P_before + (P_after - P_before) * progress

            # 压力波动模拟（在过渡中间有峰值）
            H_surge = H_system + self._pressure_surge_model(t, self._transition_time, action)

            status = 'before' if t == 0 else ('after' if t >= self._transition_time else 'transitioning')

            trajectory.append({
                't': float(t),
                'Q': float(Q_t),
                'H': float(H_surge),
                'P': float(P_t),
                'status': status
            })

        # 计算特征值
        H_values = [p['H'] for p in trajectory]
        Q_values = [p['Q'] for p in trajectory]

        return {
            'trajectory': trajectory,
            'max_pressure_surge': max(H_values) - H_system,
            'min_flow_dip': Q_before - min(Q_values) if action == 'stop' else 0,
            'stabilization_time': self._transition_time,
            'action': action,
            'pump_changed': list(set(pump_ids_before) ^ set(pump_ids_after)),
            'generated_at': datetime.now().isoformat()
        }

    def _sigmoid_transition(self, x: float) -> float:
        """S形过渡函数"""
        import math
        return 1 / (1 + math.exp(-10 * (x - 0.5)))

    def _pressure_surge_model(self, t: float, T: float, action: str) -> float:
        """压力波动模型"""
        import math
        # 在过渡中间有压力峰值/谷值
        peak_time = T * 0.3
        if action == 'stop':
            # 停泵时压力先升后降
            return 2.0 * math.exp(-((t - peak_time) / 5) ** 2)
        else:
            # 启泵时压力先降后升
            return -1.5 * math.exp(-((t - peak_time) / 5) ** 2)
```

**应用价值**：
- 预测水锤风险
- 优化切换速度
- 保护管网设备

### 5.4 第15条：泵组协调控制曲线

**定义**：多台变频泵的频率协调控制策略，实现流量分配和效率优化。

**物理原理**：
```
协调控制目标：
- 等效率控制：各泵工作在相同效率点
- 等负荷控制：各泵负荷率相同
- 主从控制：一台领跑，其他跟随
```

**技术实现**：
```python
class CoordinationController:
    """泵组协调控制器【v3.1更新：修复硬编码参数】"""

    def __init__(
        self,
        synthesizer: ParallelSynthesizer,
        pump_registry: Optional[Dict[int, Dict]] = None
    ):
        """
        Args:
            synthesizer: 并联合成器
            pump_registry: 泵参数注册表，可选
                格式: {pump_id: {'Q_rated': float, 'eta_bep': float, 'freq_bep': float, ...}}
                如果不提供，将从synthesizer的_pump_rated_powers中获取额定功率

        Note:
            v3.2修复P3：ParallelSynthesizer没有_entries属性，改用_pump_rated_powers
        """
        self._synthesizer = synthesizer
        self._pump_registry = pump_registry or {}
        # v3.2修复P3：使用_pump_rated_powers替代不存在的_entries
        self._pump_rated_powers = synthesizer._pump_rated_powers if hasattr(synthesizer, '_pump_rated_powers') else {}

    def generate_control_curve(
        self,
        pump_ids: List[int],
        Q_target: float,
        H_system: float,
        strategy: str = 'equal_efficiency'
    ) -> Dict[str, Any]:
        """
        生成协调控制曲线

        Args:
            pump_ids: 运行泵ID列表
            Q_target: 目标总流量 (m³/h)
            H_system: 系统扬程 (m)
            strategy: 控制策略
                - 'equal_efficiency': 等效率控制
                - 'equal_load': 等负荷控制
                - 'master_slave': 主从控制

        Returns:
            {
                'frequency_allocation': {
                    101: {'frequency': 45.0, 'Q': 400.0, 'eta': 0.78},
                    102: {'frequency': 47.0, 'Q': 420.0, 'eta': 0.78}
                },
                'total_efficiency': 0.78,
                'total_power': 85.0,
                'strategy': 'equal_efficiency'
            }
        """
        if strategy == 'equal_efficiency':
            return self._equal_efficiency_control(pump_ids, Q_target, H_system)
        elif strategy == 'equal_load':
            return self._equal_load_control(pump_ids, Q_target, H_system)
        elif strategy == 'master_slave':
            return self._master_slave_control(pump_ids, Q_target, H_system)
        else:
            raise ValueError(f"未知控制策略: {strategy}")

    def _equal_efficiency_control(
        self,
        pump_ids: List[int],
        Q_target: float,
        H_system: float
    ) -> Dict[str, Any]:
        """等效率控制：各泵工作在相同效率点"""
        import numpy as np
        from scipy.optimize import minimize

        n_pumps = len(pump_ids)

        def objective(freqs):
            """目标函数：最小化效率方差"""
            etas = []
            for i, pump_id in enumerate(pump_ids):
                freq = freqs[i]
                # 使用相似定律计算该频率下的效率
                eta = self._estimate_efficiency_at_freq(pump_id, freq, H_system)
                etas.append(eta)
            return np.var(etas) - np.mean(etas) * 0.01  # 同时最大化平均效率

        def constraint_flow(freqs):
            """约束：总流量等于目标"""
            Q_total = 0
            for i, pump_id in enumerate(pump_ids):
                freq = freqs[i]
                Q_total += self._estimate_flow_at_freq(pump_id, freq, H_system)
            return Q_total - Q_target

        # 初始值：所有泵相同频率
        initial_freq = 45.0
        x0 = [initial_freq] * n_pumps

        # 频率范围约束
        bounds = [(30.0, 50.0)] * n_pumps

        # 优化
        result = minimize(
            objective,
            x0,
            method='SLSQP',
            bounds=bounds,
            constraints={'type': 'eq', 'fun': constraint_flow}
        )

        # 构建结果
        frequency_allocation = {}
        total_power = 0
        etas = []

        for i, pump_id in enumerate(pump_ids):
            freq = result.x[i]
            Q_i = self._estimate_flow_at_freq(pump_id, freq, H_system)
            eta_i = self._estimate_efficiency_at_freq(pump_id, freq, H_system)
            P_i = self._estimate_power_at_freq(pump_id, freq, Q_i, H_system, eta_i)

            frequency_allocation[pump_id] = {
                'frequency': float(freq),
                'Q': float(Q_i),
                'eta': float(eta_i),
                'P': float(P_i)
            }
            total_power += P_i
            etas.append(eta_i)

        return {
            'frequency_allocation': frequency_allocation,
            'total_efficiency': float(np.mean(etas)),
            'total_power': float(total_power),
            'Q_achieved': float(sum(fa['Q'] for fa in frequency_allocation.values())),
            'strategy': 'equal_efficiency',
            'optimization_success': result.success,
            'generated_at': datetime.now().isoformat()
        }

    def _equal_load_control(
        self,
        pump_ids: List[int],
        Q_target: float,
        H_system: float
    ) -> Dict[str, Any]:
        """等负荷控制：各泵负荷率相同【v3.3修复：使用_pump_rated_powers，v3.5修复P16：添加numpy导入】"""
        import numpy as np  # v3.5修复P16：添加numpy导入

        # v3.3修复P19：使用_pump_rated_powers替代不存在的_entries
        rated_powers = {}
        for pump_id in pump_ids:
            # 优先从_pump_rated_powers获取，否则使用默认值55.0kW
            rated_powers[pump_id] = self._pump_rated_powers.get(pump_id, 55.0)

        # 按额定功率比例分配流量
        total_rated = sum(rated_powers.values())
        frequency_allocation = {}

        for pump_id in pump_ids:
            ratio = rated_powers[pump_id] / total_rated
            Q_i = Q_target * ratio

            # 反算所需频率
            freq = self._calculate_required_frequency(pump_id, Q_i, H_system)
            eta_i = self._estimate_efficiency_at_freq(pump_id, freq, H_system)
            P_i = self._estimate_power_at_freq(pump_id, freq, Q_i, H_system, eta_i)

            frequency_allocation[pump_id] = {
                'frequency': float(freq),
                'Q': float(Q_i),
                'eta': float(eta_i),
                'P': float(P_i),
                'load_ratio': float(P_i / rated_powers[pump_id])
            }

        etas = [fa['eta'] for fa in frequency_allocation.values()]
        total_power = sum(fa['P'] for fa in frequency_allocation.values())

        return {
            'frequency_allocation': frequency_allocation,
            'total_efficiency': float(np.mean(etas)),
            'total_power': float(total_power),
            'Q_achieved': float(Q_target),
            'strategy': 'equal_load',
            'generated_at': datetime.now().isoformat()
        }

    def _master_slave_control(
        self,
        pump_ids: List[int],
        Q_target: float,
        H_system: float
    ) -> Dict[str, Any]:
        """主从控制：主泵满载运行，从泵调节【v3.6修复P21：添加numpy导入】"""
        import numpy as np  # v3.6修复P21：添加numpy导入

        if len(pump_ids) < 2:
            raise ValueError("主从控制需要至少2台泵")

        master_id = pump_ids[0]
        slave_ids = pump_ids[1:]

        # 主泵满载（50Hz）
        master_freq = 50.0
        Q_master = self._estimate_flow_at_freq(master_id, master_freq, H_system)
        eta_master = self._estimate_efficiency_at_freq(master_id, master_freq, H_system)
        P_master = self._estimate_power_at_freq(master_id, master_freq, Q_master, H_system, eta_master)

        # 剩余流量由从泵分担
        Q_remaining = Q_target - Q_master
        Q_per_slave = Q_remaining / len(slave_ids) if slave_ids else 0

        frequency_allocation = {
            master_id: {
                'frequency': master_freq,
                'Q': float(Q_master),
                'eta': float(eta_master),
                'P': float(P_master),
                'role': 'master'
            }
        }

        total_power = P_master
        etas = [eta_master]

        for slave_id in slave_ids:
            freq = self._calculate_required_frequency(slave_id, Q_per_slave, H_system)
            freq = max(30.0, min(50.0, freq))  # 限制频率范围
            eta_i = self._estimate_efficiency_at_freq(slave_id, freq, H_system)
            P_i = self._estimate_power_at_freq(slave_id, freq, Q_per_slave, H_system, eta_i)

            frequency_allocation[slave_id] = {
                'frequency': float(freq),
                'Q': float(Q_per_slave),
                'eta': float(eta_i),
                'P': float(P_i),
                'role': 'slave'
            }
            total_power += P_i
            etas.append(eta_i)

        return {
            'frequency_allocation': frequency_allocation,
            'total_efficiency': float(np.mean(etas)),
            'total_power': float(total_power),
            'Q_achieved': float(sum(fa['Q'] for fa in frequency_allocation.values())),
            'strategy': 'master_slave',
            'generated_at': datetime.now().isoformat()
        }

    def _get_pump_params(self, pump_id: int) -> Dict[str, float]:
        """
        获取泵参数【v3.4修复P26：使用_pump_registry和_pump_rated_powers】

        获取顺序：
        1. 从pump_registry获取（完整参数）
        2. 从_pump_rated_powers获取额定功率，其他参数使用默认值
        3. 使用默认值
        """
        # 1. 优先从pump_registry获取（完整参数）
        if pump_id in self._pump_registry:
            return self._pump_registry[pump_id]

        # 2. 从_pump_rated_powers获取额定功率，构建参数
        if pump_id in self._pump_rated_powers:
            rated_power = self._pump_rated_powers[pump_id]
            # 根据额定功率估算其他参数（经验公式）
            # Q_rated ≈ P_rated × 10 (m³/h per kW for typical centrifugal pumps)
            return {
                'Q_rated': rated_power * 10.0,  # 估算值
                'eta_bep': 0.80,                # 典型BEP效率
                'freq_bep': 45.0,               # 典型BEP频率
                'rated_power': rated_power
            }

        # 3. 默认值（警告）
        self._synthesizer._logger.warning(
            f"[协调控制] 泵{pump_id}参数未找到，使用默认值"
        )
        return {
            'Q_rated': 500.0,
            'eta_bep': 0.80,
            'freq_bep': 45.0,
            'rated_power': 55.0
        }

    def _estimate_efficiency_at_freq(self, pump_id: int, freq: float, H: float) -> float:
        """
        估算指定频率下的效率【v3.1修复：从实际参数获取】

        使用相似定律：效率在BEP附近最高，偏离BEP下降
        """
        params = self._get_pump_params(pump_id)
        freq_bep = params.get('freq_bep', 45.0)
        eta_bep = params.get('eta_bep', 0.80)

        # 效率偏离模型：偏离BEP越远，效率下降越多
        deviation = abs(freq - freq_bep) / 20.0
        return eta_bep * (1 - 0.1 * deviation)

    def _estimate_flow_at_freq(self, pump_id: int, freq: float, H: float) -> float:
        """
        估算指定频率下的流量【v3.1修复：从实际参数获取】

        使用相似定律：Q ∝ f
        """
        params = self._get_pump_params(pump_id)
        Q_rated = params.get('Q_rated', 500.0)
        freq_ratio = freq / 50.0
        return Q_rated * freq_ratio

    def _estimate_power_at_freq(
        self, pump_id: int, freq: float, Q: float, H: float, eta: float
    ) -> float:
        """
        估算指定频率下的功率

        使用水力功率公式：P = ρgQH/η
        注意：Q单位为m³/h，需转换为m³/s
        """
        rho = 1000  # 水密度 kg/m³
        g = 9.81    # 重力加速度 m/s²
        Q_m3s = Q / 3600
        P_watts = rho * g * Q_m3s * H / eta if eta > 0 else 0
        return P_watts / 1000  # kW

    def _calculate_required_frequency(self, pump_id: int, Q_target: float, H: float) -> float:
        """
        反算达到目标流量所需的频率【v3.1修复：从实际参数获取】

        使用相似定律：f = 50 × (Q_target / Q_rated)
        """
        params = self._get_pump_params(pump_id)
        Q_rated = params.get('Q_rated', 500.0)
        freq = 50.0 * Q_target / Q_rated
        return max(30.0, min(50.0, freq))  # 限制在30-50Hz范围
```

**应用价值**：
- 多泵协调运行
- 效率最大化
- 负荷均衡

### 6.1 第13条：泵组最优运行区域

**定义**：在H-Q平面上标识泵组高效运行的区域。

> **注意**：此方法的权威实现位于 `07_泵组处理层.md` `ParallelSynthesizer.find_optimal_region()`方法。
> 本节为接口规格说明，实际开发请以07文档为准。【v3.6修复P23，v3.10修复P65】

**技术实现**：
```python
# v3.6修复P24：顶层需要导入datetime
from datetime import datetime

def find_optimal_region(
    self,
    pump_ids: List[int],
    H_range: Tuple[float, float] = (25, 50),
    Q_range: Tuple[float, float] = (500, 2000),
    efficiency_threshold: float = 0.75,  # v3.5修复P13/P15：统一参数名
    step: float = 1.0,
    pump_frequencies: Optional[Dict[int, float]] = None  # v3.6新增：与07文档一致
) -> Dict[str, Any]:
    """
    扫描并标识高效运行区域【v3.6增强：支持变频泵】

    Args:
        pump_ids: 泵ID列表
        H_range: 扬程扫描范围 (H_min, H_max)
        Q_range: 流量扫描范围 (Q_min, Q_max)，用于结果过滤
        efficiency_threshold: 效率阈值，高于此值的点被标记为高效区域
            ✅ v3.5修复P13/P15：参数名从eta_threshold改为efficiency_threshold
            与07_泵组处理层.md保持一致
        step: 扫描步长
        pump_frequencies: 各泵运行频率【v3.6新增】

    Returns:
        {
            'region_points': [{'H': 30, 'Q': 1200, 'eta': 0.78, 'N': 3}, ...],
            'bep': {'H': 35, 'Q': 1050, 'eta': 0.82, 'N': 2},
            'boundary': {'H_min': 28, 'H_max': 42, 'Q_min': 800, 'Q_max': 1600}
        }
    """
    import numpy as np

    region_points = []
    best_point = None
    best_eta = 0.0

    for H in np.arange(H_range[0], H_range[1] + step, step):
        for n in range(1, len(pump_ids) + 1):
            selected = pump_ids[:n]
            try:
                # v3.6：传递pump_frequencies参数
                result = self.synthesize_heterogeneous(selected, H, pump_frequencies)
                if result.eta_total >= efficiency_threshold:
                    point = {
                        'H': float(H),
                        'Q': result.Q_total,
                        'eta': result.eta_total,
                        'N': n
                    }
                    region_points.append(point)

                    if result.eta_total > best_eta:
                        best_eta = result.eta_total
                        best_point = point
            except Exception:
                continue

    # 计算边界
    if region_points:
        boundary = {
            'H_min': min(p['H'] for p in region_points),
            'H_max': max(p['H'] for p in region_points),
            'Q_min': min(p['Q'] for p in region_points),
            'Q_max': max(p['Q'] for p in region_points)
        }
    else:
        boundary = None

    # v3.7修复P28：返回值结构与07文档保持一致
    return {
        'region_points': region_points,
        'bep': best_point,
        'boundary': boundary,
        'efficiency_threshold': efficiency_threshold,
        'pump_ids': pump_ids,           # v3.7修复P28：与07文档一致
        'H_range': list(H_range),       # v3.7修复P28：与07文档一致
        'generated_at': datetime.now().isoformat()
    }
```

**应用价值**：
- 可视化高效区域
- 指导运行调度
- 避免低效运行

### 6.2 第14条：泵组比能耗曲线

**定义**：单位流量的能耗（kWh/m³）随系统扬程变化的曲线。

> **注意**：此方法的权威实现位于 `07_泵组处理层.md` `ParallelSynthesizer.generate_specific_energy_curve()`方法。【v3.10修复P65】

**技术实现**：
```python
def generate_specific_energy_curve(
    self,
    pump_ids: List[int],
    H_range: Tuple[float, float] = (20, 60),
    step: float = 2.0,
    pump_frequencies: Optional[Dict[int, float]] = None  # v3.6修复P22：与07文档一致
) -> Dict[str, Any]:
    """
    生成比能耗曲线（SEC vs H）【v3.6增强：支持变频泵】

    Args:
        pump_ids: 运行泵ID列表
        H_range: 扬程扫描范围 (m)
        step: 扫描步长 (m)
        pump_frequencies: 各泵运行频率【v3.6修复P22】

    Returns:
        {
            'curve_data': [{'H': 20, 'Q': 1800, 'P': 180, 'SEC': 0.100}, ...],
            'min_sec': {'H': 35, 'Q': 1200, 'P': 155, 'SEC': 0.129},
            'avg_sec': 0.125
        }
    """
    import numpy as np

    curve_data = []
    H_values = np.arange(H_range[0], H_range[1] + step, step)

    for H in H_values:
        try:
            # v3.6修复P22：传递pump_frequencies参数
            result = self.synthesize_heterogeneous(pump_ids, H, pump_frequencies)
            Q = result.Q_total
            P = result.P_total

            if Q > 0:
                sec = P / Q  # kWh/m³
                curve_data.append({
                    'H': float(H),
                    'Q': Q,
                    'P': P,
                    'SEC': sec
                })
        except Exception:
            continue

    if not curve_data:
        return {'curve_data': [], 'min_sec': None, 'avg_sec': None}

    min_point = min(curve_data, key=lambda x: x['SEC'])
    avg_sec = sum(p['SEC'] for p in curve_data) / len(curve_data)

    return {
        'curve_data': curve_data,
        'min_sec': min_point,
        'avg_sec': avg_sec,
        'pump_ids': pump_ids,
        'H_range': list(H_range),
        'unit_sec': 'kWh/m³',
        'generated_at': datetime.now().isoformat()
    }
```

**应用价值**：
- 能效评估
- 节能分析
- 最优工况确定
