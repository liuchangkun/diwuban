## 1. 曲线概述

### 1.1 基本信息

| 属性 | 值 |
|------|-----|
| **曲线类型** | `qp` |
| **物理意义** | 流量-功率关系 |
| **单调性** | 递增 (dP/dQ > 0) |
| **推荐方法** | `physics_power_eq`, `math_poly_2`, `math_poly_3` |
| **文件路径** | `app/services/characteristic_curves/curves/qp_curve.py` |

### 1.2 物理特性

| 特性 | 描述 |
|------|------|
| **单调性** | 全范围单调递增 |
| **凸性** | 上凸 (d²P/dQ² < 0) |
| **零流量点** | P₀ ≈ 0.3~0.5 × P_rated |
| **最大功率** | P_max ≤ 1.2 × P_rated |

**物理公式**：
```
P = ρ * g * Q * H / η

其中：
- ρ = 1000 kg/m³（水的密度）
- g = 9.81 m/s²（重力加速度）
- Q：流量（m³/s，注意单位转换）
- H：扬程（m）
- η：效率（0-1）
```

**典型曲线形状**：
```
P (kW)
│
80 │              ╭────
   │            ╱
60 │          ╱
   │        ╱
40 │      ╱
   │    ╱
20 │  ╱
   │╱
0  └─────────────────────> Q (m³/h)
   0   100  200  300  400
```

### 1.3 数学模型

**标准二次多项式**：
```
P = b₀ + b₁Q + b₂Q²
```

**约束条件**：
- b₁ > 0 (保证递增)
- b₀ > 0 (空载功率为正)
- b₂ < 0 (上凸曲线)

### 2.2 QPDataExtractor 数据提取器

| 属性 | 说明 |
|------|------|
| **职责** | 从 fact_measurements 提取 Q-P 数据 |
| **必需指标** | `pump_flow_rate`, `pump_active_power` |

```python
from datetime import datetime
import pandas as pd
import logging
from app.adapters.db.pool import get_connection
from app.services.characteristic_curves.shared.exceptions import DataExtractionError  # v2.6新增

class QPDataExtractor:
    """Q-P曲线数据提取器"""

    REQUIRED_METRICS = ['pump_flow_rate', 'pump_active_power']

    def __init__(self):
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

    def extract(
        self,
        device_id: int,
        start_time: datetime,
        end_time: datetime,
        min_points: int = 100  # 数据提取建议点数（v2.6统一修复）
    ) -> pd.DataFrame:
        """
        提取Q-P数据

        Args:
            device_id: 设备ID
            start_time: 开始时间
            end_time: 结束时间
            min_points: 最小数据点数（默认100，对应MIN_EXTRACTION_POINTS）
                       这是数据提取阶段的建议值，确保有足够数据进行筛选
                       实际拟合时会使用MIN_DATA_POINTS(50)进行验证

        Returns:
            DataFrame: 包含ts_bucket, Q, P列的数据
        """
        sql = """
            SELECT
                ts_bucket,
                MAX(CASE WHEN metric_id = (
                    SELECT id FROM dim_metric_config
                    WHERE metric_key = 'pump_flow_rate'
                ) THEN value END) AS Q,
                MAX(CASE WHEN metric_id = (
                    SELECT id FROM dim_metric_config
                    WHERE metric_key = 'pump_active_power'
                ) THEN value END) AS P
            FROM fact_measurements
            WHERE device_id = %(device_id)s
              AND ts_bucket BETWEEN %(start_time)s AND %(end_time)s
            GROUP BY ts_bucket
            HAVING Q IS NOT NULL AND P IS NOT NULL
            ORDER BY ts_bucket
        """

        with get_connection() as conn:
            with conn.cursor() as cursor:
                cursor.execute(sql, {
                    'device_id': device_id,
                    'start_time': start_time,
                    'end_time': end_time
                })
                rows = cursor.fetchall()
                columns = [desc[0] for desc in cursor.description]

        data = pd.DataFrame(rows, columns=columns)
        return data
```

### 2.3 QPConstraints 物理约束

| 约束类型 | 条件 | 说明 |
|---------|------|------|
| **单调性** | dP/dQ > 0 | 全范围递增 |
| **边界-零流量** | P(0) ≈ 0.3~0.5 × P_rated | 空载功率 |
| **边界-最大功率** | P_max ≤ 1.2 × P_rated | 功率上限 |
| **能量守恒** | P ≈ ρgQH/η | 物理一致性 |

**约束计算**：
```python
class QPConstraints:
    def calculate(self, data: pd.DataFrame, device_params: Dict) -> Dict:
        """
        计算约束参数

        输出: Dict{P0, P_max, P_rated, Q_rated, monotonicity, energy_balance}
        """
        P_rated = device_params['rated_power']
        Q_rated = device_params['rated_flow']

        return {
            'P0': P_rated * 0.15,           # 空载功率估算
            'P_max': P_rated * 1.2,         # 最大功率
            'P_rated': P_rated,
            'Q_rated': Q_rated,
            'monotonicity': 'increasing',
            'energy_balance': True
        }
```

### 2.4 QPValidator 验证器

| 验证项 | 标准 | 说明 |
|--------|------|------|
| **精度** | R² > 0.95 | 拟合优度 |
| **误差** | RMSE < 5kW | 均方根误差 |
| **单调性** | 全范围 dP/dQ > 0 | 物理约束 |
| **边界** | P(0) ≈ P₀ | 零流量点 |

## 3. 数据流详细

### 3.1 简化版9阶段流程

> **📋 阶段映射说明**：本节描述的是简化版9阶段流程，对应权威13阶段的核心步骤。
> 权威13阶段定义请参见 [02_数据流定义.md](../02_架构设计/02_数据流定义.md)。
>
> | 简化阶段 | 对应权威阶段 | 说明 |
> |:--------:|:------------:|------|
> | 阶段1 | 阶段3 | 数据提取 |
> | 阶段2 | 阶段4 | 数据清洗 |
> | 阶段3 | 阶段6 | 约束计算 |
> | 阶段4 | 阶段8 | 标准化 |
> | 阶段5 | 阶段9 | 方法选择 |
> | 阶段6 | 阶段10 | 拟合 |
> | 阶段7 | 阶段11 | 验证 |
> | 阶段8 | 阶段12 | 历史评估 |
> | 阶段9 | 阶段13 | 存储 |

```
阶段1: 数据提取 [QPDataExtractor] (对应权威阶段3)
┌─────────────────────────────────────────────────────────────────────────────┐
│ 输入: device_id, start_time, end_time                                       │
│ 处理:                                                                       │
│   1. 查询 fact_measurements 表                                              │
│   2. 提取 pump_flow_rate (Q) 和 pump_active_power (P) 指标                  │
│   3. 按时间戳聚合数据                                                        │
│ 输出: DataFrame[ts_bucket, Q, P]                                            │
│ 预期数据量: 100-10000行                                                      │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
阶段2: 数据清洗 [QPPreprocessor]
┌─────────────────────────────────────────────────────────────────────────────┐
│ 输入: DataFrame[ts_bucket, Q, P]                                            │
│ 处理:                                                                       │
│   1. 删除无效值（Q<0 或 P<0）                                                │
│   2. 删除异常值（物理约束法推荐）                                              │
│   3. 删除重复值                                                              │
│   4. 运行点筛选（只保留泵运行状态的数据）                                      │
│ 输出: DataFrame[Q, P]（清洗后）                                              │
│ 预期数据保留率: 80-95%                                                       │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
阶段3: 约束计算 [QPConstraints]
┌─────────────────────────────────────────────────────────────────────────────┐
│ 输入: DataFrame[Q, P], device_params                                        │
│ 处理:                                                                       │
│   1. 计算 P₀（空载功率）: 使用Q→0外推或额定参数估算 (P_rated * 0.15)          │
│   2. 计算 P_max（最大功率）: P_rated * 1.2                                   │
│   3. 验证单调性约束: dP/dQ > 0                                               │
│   4. 验证能量守恒: P ≈ ρgQH/η                                               │
│ 输出: Dict{P0, P_max, P_rated, Q_rated, monotonicity, energy_balance}       │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
阶段4: 归一化 [QPNormalizer]
┌─────────────────────────────────────────────────────────────────────────────┐
│ 输入: DataFrame[Q, P], constraints                                          │
│ 处理:                                                                       │
│   1. Q归一化: Q_norm = Q / Q_rated                                          │
│   2. P归一化: P_norm = P / P_rated                                          │
│   3. 记录归一化参数                                                          │
│ 输出: DataFrame[Q_norm, P_norm], norm_params                                │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
阶段5-9: 与QHCurve相同（方法选择、拟合、验证、历史评估、存储）

**重要说明（v2.6修复）**：
- 阶段6拟合采用**顺序执行**策略，与QH曲线保持一致
- 详细流程见 `01_QH曲线.md` 阶段6定义
- 执行策略：顺序执行所有选定方法，按优先级顺序，找到满足条件的方法即可停止
```

## 4. 主类实现

```python
from typing import Dict, Any, Optional, List
from datetime import datetime
import pandas as pd
import logging

class QPCurve(BaseCurve):
    """Q-P曲线（流量-功率）模块"""

    curve_type = 'qp'
    monotonicity = 'increasing'
    recommended_methods = ['physics_power_eq', 'math_poly_2', 'math_poly_3']

    def _init_submodules(self) -> None:
        """初始化Q-P曲线专用子模块"""
        self._extractor = QPDataExtractor()
        self._preprocessor = QPPreprocessor()
        self._constraints = QPConstraints()
        self._normalizer = QPNormalizer()
        self._fitter = QPCurveFitter(method_registry=self._get_method_registry())
        self._validator = QPValidator()
        self._method_selector = MethodSelector(
            curve_type='qp',
            recommended_methods=self.recommended_methods
        )

    def extract_data(self, device_id: int, start_time: datetime, end_time: datetime) -> pd.DataFrame:
        return self._extractor.extract(device_id, start_time, end_time)

    def preprocess(self, data: pd.DataFrame) -> pd.DataFrame:
        clean_data, _ = self._preprocessor.preprocess(data)
        return clean_data

    def calculate_constraints(self, data: pd.DataFrame, device_params: Dict[str, Any]) -> Dict[str, Any]:
        return self._constraints.calculate(data, device_params)
```

## 5. 使用示例

```python
from app.services.characteristic_curves.curves import QPCurve
from datetime import datetime

# 创建曲线实例
qp_curve = QPCurve(
    storage=result_storage,
    cache=cache_manager,
    batch_processor=batch_processor,
    parameter_optimizer=parameter_optimizer,
    historical_evaluator=historical_evaluator
)

# 执行拟合
result = qp_curve.fit(
    device_id=1,
    start_time=datetime(2025, 1, 1),
    end_time=datetime(2025, 1, 25),
    methods=['physics_power_eq', 'math_poly_2']
)

print(f"最佳方法: {result.method_name}")
print(f"R²: {result.r_squared:.4f}")

# 预测功率
Q_values = [100, 200, 300, 400]
for Q in Q_values:
    P = qp_curve.predict(Q)
    print(f"Q={Q} m³/h → P={P:.2f} kW")
```
