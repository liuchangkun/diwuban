## 1. 概述与背景

准确拟合泵组特性曲线，支撑：
- **预测能力**：给定泵组合和目标流量，预测系统扬程和功耗

#### 1.4.2 方法B：合成+修正

**支持的曲线类型**：

| 曲线类型 | 标识 | 合成策略 | 当前状态 |
|:------:|:----:|---------|:------:|
| 流量-扬程 | `qh` | 并联时H相同，Q叠加；给定Q_total反推H | ✅ 核心支持 |
| 流量-功率 | `qp` | P_total=ΣP_i，按流量分配计算 | ✅ 物理公式推导 |
| 流量-效率 | `qeta` | η_total=ρgQH/P_total | ✅ 由Q-H和Q-P计算 |

**合成原理**：

```
Q-H曲线合成（核心）
├─ 同构泵组：Q_single = Q_total / N, H = base_curve(Q_single)
└─ 异构泵组：给定H_system, Q_i = inverse_curve_i(H_system), Q_total = ΣQ_i

Q-P曲线合成
├─ 方法1：使用单泵Q-P曲线，P_i = power_curve_i(Q_i)
└─ 方法2：使用物理公式，P_i = ρgQ_iH / η_i

Q-η曲线合成
└─ 由Q-H和Q-P计算：η_total = ρgQ_totalH_system / P_total
```

**扩展能力**：✅ 支持新增曲线类型（通过扩展ParallelSynthesizer的synthesize方法）

## 2. 问题分析与解决思路

### 2.1 核心物理原理

**泵组并联特性**：
- 并联时扬程相同：H₁ = H₂ = ... = Hₙ = H_system
- 流量叠加：Q_total = Q₁ + Q₂ + ... + Qₙ
- 功率叠加：P_total = P₁ + P₂ + ... + Pₙ

**关键洞察**：
泵组Q-H曲线**不是单一的二维曲线**，而是**与运行台数N和泵组合相关的曲线族**。

```
例：3台同型号泵的泵站
├─ 1台运行时：曲线C₁（Q范围0-500，H范围30-50）
├─ 2台运行时：曲线C₂（Q范围0-1000，H范围30-50）
└─ 3台运行时：曲线C₃（Q范围0-1500，H范围30-50）

同样Q=600 m³/h：
- 2台运行时：每台300，H≈40m
- 3台运行时：每台200，H≈45m（单泵负荷更低，扬程更高）
```

### 2.2 P1问题根因分析

**错误做法（当前代码）**：
```python
# ❌ 将所有数据混合拟合
Q_total = [600, 600, 900, 900, 1200, 1200]  # 不同台数混在一起
H_system = [40,  45,  38,  42,  35,  40]    # 同Q不同H
model.fit(Q_total, H_system)  # 混乱的数据，无物理意义
```

**正确做法**：
```python
# ✅ 按泵组合分组，每组独立拟合
data_n2 = {"Q": [600, 900, 1000], "H": [40, 38, 36]}  # 2台运行
data_n3 = {"Q": [600, 900, 1200], "H": [45, 42, 40]}  # 3台运行

curve_n2 = fit(data_n2)  # 拟合2台曲线
curve_n3 = fit(data_n3)  # 拟合3台曲线
```

#### 2.4.3 拟合流程修复

```python
def fit(self, points: List[GroupOperatingPoint]) -> DirectFitResult:
    Q = np.array([p.Q_total for p in points])
    H = np.array([p.H_system for p in points])

def fit(self, points: List[GroupOperatingPoint]) -> Dict[str, DirectFitResult]:
    # 步骤1：按泵组合分组
    grouped = self._group_by_combination(points)
    
    # 步骤2：每组独立拟合
    results = {}
    for combination_key, group_points in grouped.items():
        if len(group_points) < self._min_points:
            continue
        Q = np.array([p.Q_total for p in group_points])
        H = np.array([p.H_system for p in group_points])
        results[combination_key] = self._fit_single(combination_key, Q, H)
    return results
```

```python
        self,
```

```python
class PressureMatchStrategy(SynthesisStrategy):
    """
    压力匹配策略（串联泵组）
    
    物理原理：
    - 串联时流量相同：Q₁ = Q₂ = ... = Q
    - 扬程叠加：H_total = ΣHᵢ
    
    适用场景：多级串联泵组
    """
    
    def synthesize(
        self,
        pump_curves: Dict[int, Callable],
        pump_ids: List[int],
        Q: float
    ) -> float:
        """给定流量，返回总扬程"""
        H_total = sum(
            pump_curves[pid](Q) for pid in pump_ids
        )
        return H_total


class WeightedAverageStrategy(SynthesisStrategy):
    """
    加权平均策略（混合泵组）
    
    适用场景：复杂泵组配置（部分并联、部分串联）
    """
    
    def __init__(self, weights: Dict[int, float]):
        self.weights = weights
    
    def synthesize(
        self,
        pump_curves: Dict[int, Callable],
        pump_ids: List[int],
        x_value: float
    ) -> float:
        """根据权重计算加权结果"""
        weighted_sum = sum(
            self.weights.get(pid, 1.0) * pump_curves[pid](x_value)
            for pid in pump_ids
        )
        total_weight = sum(self.weights.get(pid, 1.0) for pid in pump_ids)
        return weighted_sum / total_weight if total_weight > 0 else 0
```

## 3. 方法A：分组直接拟合

### 3.1 核心思想

对于每一种**泵组合**（如"1,2,3"表示1、2、3号泵同时运行），从历史数据中提取该组合的所有运行工况点，拟合一条独立的Q-H曲线。

```
泵组合分组策略
├─ 同构泵组（3台相同型号VFD泵）
│   ├─ 组合"1": 仅1号泵运行 → 曲线C_1
│   ├─ 组合"1,2": 1、2号泵运行 → 曲线C_12
│   ├─ 组合"1,3": 1、3号泵运行 → 曲线C_13
│   ├─ 组合"2,3": 2、3号泵运行 → 曲线C_23
│   └─ 组合"1,2,3": 全部运行 → 曲线C_123
│
└─ 异构泵组（不同型号泵）
    └─ 每种实际运行过的组合，都拟合一条曲线
```

### 3.2 数据提取与分组

#### 3.2.1 数据源

从`fact_measurements`表提取：
- **Q_total**：`main_pipeline_flow_rate`指标
- **H_system**：`main_pipeline_outlet_pressure × 10.2`（MPa转换为m）
- **running_pumps**：各泵running状态聚合得到的运行泵ID数组

#### 3.2.2 SQL查询（改进版）

```sql
WITH pump_status AS (
    -- 步骤1：获取每个时间桶每台泵的运行状态
    SELECT
        ts_bucket,
        device_id,
        MAX(CASE WHEN metric_key = 'running' THEN value END) AS running
    FROM fact_measurements fm
    JOIN dim_metric_config dmc ON fm.metric_id = dmc.id
    WHERE ts_bucket >= :start_time AND ts_bucket < :end_time
      AND fm.station_id = :station_id
    GROUP BY ts_bucket, device_id
),
station_flow AS (
    -- 步骤2：获取总管流量
    SELECT ts_bucket, value AS Q_total
    FROM fact_measurements fm
    JOIN dim_metric_config dmc ON fm.metric_id = dmc.id
    WHERE dmc.metric_key = 'main_pipeline_flow_rate'
      AND ts_bucket >= :start_time AND ts_bucket < :end_time
      AND station_id = :station_id
),
station_pressure AS (
    -- 步骤3：获取出口压力并转换为扬程
    SELECT ts_bucket, value * 10.2 AS H_system
    FROM fact_measurements fm
    JOIN dim_metric_config dmc ON fm.metric_id = dmc.id
    WHERE dmc.metric_key = 'main_pipeline_outlet_pressure'
      AND ts_bucket >= :start_time AND ts_bucket < :end_time
      AND station_id = :station_id
),
aggregated AS (
    -- 步骤4：聚合运行泵列表
    SELECT
        ps.ts_bucket,
        array_agg(ps.device_id ORDER BY ps.device_id) 
            FILTER (WHERE ps.running = 1) AS running_pump_ids,
        array_length(
            array_agg(ps.device_id) FILTER (WHERE ps.running = 1), 1
        ) AS n_running,
        sf.Q_total,
        sp.H_system
    FROM pump_status ps
    JOIN station_flow sf ON ps.ts_bucket = sf.ts_bucket
    JOIN station_pressure sp ON ps.ts_bucket = sp.ts_bucket
    GROUP BY ps.ts_bucket, sf.Q_total, sp.H_system
)
SELECT
    ts_bucket,
    running_pump_ids,
    n_running,
    Q_total,
    H_system,
    -- 生成组合键：如 "1,2,3"
    array_to_string(running_pump_ids, ',') AS pump_combination_key
FROM aggregated
WHERE n_running >= :min_running_pumps
  AND Q_total > 0
  AND H_system > 0
ORDER BY pump_combination_key, ts_bucket;
```

### 3.3 分组拟合算法

#### 3.3.1 拟合流程

```python
def fit_by_combination(
    station_id: int,
    grouped_points: Dict[str, List[GroupOperatingPoint]],
    curve_type: str = "qh",
    min_points: int = 50
) -> Dict[str, DirectFitResult]:
    """
    按泵组合分组拟合
    
    Args:
        station_id: 泵站ID
        grouped_points: 分组后的工况点 {combination_key: [points]}
        curve_type: 曲线类型
        min_points: 每组最少数据点数
    
    Returns:
        Dict[combination_key, DirectFitResult]
    """
    results = {}
    
    for combination_key, points in grouped_points.items():
        # 数据量检查
        if len(points) < min_points:
            logger.warning(
                f"组合 {combination_key} 数据点不足: {len(points)} < {min_points}，跳过"
            )
            continue
        
        # 提取Q-H数组
        Q = np.array([p.Q_total for p in points])
        H = np.array([p.H_system for p in points])
        
        # 选择拟合方法（根据数据量）
        method_id = select_method(len(points), curve_type)
        
        # 执行拟合
        result = fit_single_combination(
            station_id=station_id,
            combination_key=combination_key,
            Q=Q,
            H=H,
            curve_type=curve_type,
            method_id=method_id
        )
        
        # 物理约束验证
        if not validate_physics(result, curve_type):
            logger.warning(f"组合 {combination_key} 物理验证失败")
            continue
        
        results[combination_key] = result
    
    return results
```

```python
def fit_single_combination(

    method_result = method.fit(X=Q, y=H)

    return DirectFitResult(
        station_id=station_id,
        pump_combination_key=combination_key,
        n_pumps=len(combination_key.split(',')),
        curve_type=curve_type,
        fit_method="direct_fit",
        
        coefficients=list(method_result.coefficients.values()),
        r_squared=method_result.r_squared,
        rmse=method_result.rmse,
        mae=method_result.mae,

        method_name=method.method_name,
        fitted_at=datetime.now()
    )
```

### 3.4 物理约束验证

```python
def validate_physics(
    result: DirectFitResult,
    curve_type: str
) -> bool:
    """
    验证拟合结果是否满足物理约束
    
    Q-H曲线约束：
    1. 单调递减：dH/dQ < 0（流量增加，扬程下降）
    2. H(0) > 0：零流量时扬程为正（截止扬程）
    3. H(Q_max) > 0：最大流量时扬程仍为正
    
    Q-P曲线约束：
    1. P(Q) > 0：功率恒为正
    2. 通常单调递增
    
    Q-η曲线约束：
    1. 0 < η < 1：效率在0-100%之间
    2. 存在最高效率点（BEP）
    """
    if curve_type == "qh":
        coeffs = result.coefficients
        
        # 对于 H = a₀ + a₁Q + a₂Q²
        # dH/dQ = a₁ + 2a₂Q
        # 要求在整个Q范围内 dH/dQ < 0
        
        if len(coeffs) >= 3:
            a0, a1, a2 = coeffs[0], coeffs[1], coeffs[2]
            Q_max = result.valid_q_range[1]
            
            # 检查截止扬程
            H0 = a0
            if H0 <= 0:
                return False
            
            # 检查最大流量处扬程
            H_max = a0 + a1 * Q_max + a2 * Q_max**2
            if H_max <= 0:
                return False
            
            # 检查单调性（在Q范围内dH/dQ应小于0）
            # a₁ + 2a₂Q < 0 for all Q in [0, Q_max]
            # 通常a₂ < 0（开口向下），a₁接近0或为负
            if a2 >= 0:
                # 开口向上，物理不合理
                return False
        
        return True
    
    # 其他曲线类型的验证...
    return True
```

## 4. 方法B：合成+修正

### 4.1 核心思想

基于**单泵特性曲线**，通过**并联合成算法**生成泵组理论曲线，然后从历史数据中**学习修正系数α**来弥补理论与实际的差异。

```
合成+修正步骤
├─ 步骤1：从数据库加载单泵Q-H曲线
│   ├─ 数据源：curve_fit_results + curve_fit_params 表
│   ├─ 加载方式：ResultStorage.load(device_id, curve_type)
│   └─ 返回：FitResult（包含coefficients系数）
├─ 步骤2：并联合成（理论曲线）
│   ├─ 同构泵组：Q_total = N × Q_single，H不变
│   └─ 异构泵组：等扬程流量叠加
├─ 步骤3：从历史数据学习修正系数
│   ├─ 理论扬程：H_theo = synthesis(Q_total, N)
│   ├─ 实际扬程：H_actual（从fact_measurements）
│   ├─ 修正系数：α = H_actual / H_theo
│   └─ 拟合模型：α = f(N, Q_total)
└─ 步骤4：最终曲线
    └─ H_corrected = H_theo × α(N, Q_total)
```

### 4.2 并联合成算法

#### 4.2.1 同构泵组合成

**物理原理**：N台相同型号泵并联，每台分担相同流量。

```python
def synthesize_homogeneous(
    base_pump_curve: Callable[[float], float],  # Q_single → H
    n_pumps: int,
    Q_total: float
) -> float:
    """
    同构泵组合成
    
    物理公式：
        Q_single = Q_total / N
        H_group = base_curve(Q_single)
    
    示例：
        3台泵并联，单泵曲线 H = 50 - 0.0001 × Q²
        Q_total = 1500 m³/h
        Q_single = 1500 / 3 = 500 m³/h
        H_group = 50 - 0.0001 × 500² = 50 - 25 = 25m
    """
    Q_single = Q_total / n_pumps
    return base_pump_curve(Q_single)
```

#### 4.2.2 异构泵组合成

**物理原理**：并联时扬程相同，在给定系统扬程下，各泵按各自曲线提供流量，总流量为各泵流量之和。

```python
def synthesize_heterogeneous(
    pump_inverse_curves: Dict[int, Callable[[float], float]],  # pump_id → (H → Q)
    pump_ids: List[int],
    H_system: float
) -> SynthesisResult:
    """
    异构泵组合成（给定扬程，计算总流量）
    
    物理公式：
        并联时：H₁ = H₂ = ... = H_system
        各泵流量：Qᵢ = inverse_curveᵢ(H_system)
        总流量：Q_total = Σ Qᵢ
    
    示例：
        泵1：H = 50 - 0.00012×Q²（小泵）
        泵2：H = 55 - 0.00010×Q²（大泵）
        H_system = 35m
        
        泵1流量：Q₁ = sqrt((50-35)/0.00012) = 354 m³/h
        泵2流量：Q₂ = sqrt((55-35)/0.00010) = 447 m³/h
        总流量：Q_total = 354 + 447 = 801 m³/h
    """
    pump_flows = {}
    Q_total = 0.0
    
    for pump_id in pump_ids:
        inverse_func = pump_inverse_curves[pump_id]
        Q_i = inverse_func(H_system)
        pump_flows[pump_id] = max(0, Q_i)
        Q_total += pump_flows[pump_id]
    
    return SynthesisResult(
        Q_total=Q_total,
        H_system=H_system,
        pump_flows=pump_flows,
        n_pumps=len(pump_ids)
    )
```

### 4.3 系统修正模型

#### 4.3.1 修正模型原理

**为什么需要修正**：
理论合成曲线忽略了：
- 并联管路损失
- 流量分配不均
- 管网阻力影响
- 设备老化

**修正模型**：
```
H_actual = H_theoretical × α(N, Q_total)

其中：
    α = 修正系数，通常在0.85-1.05之间
    N = 运行台数
    Q_total = 总流量
```

#### 4.3.2 修正模型训练

```python
def train_correction_model(
    training_data: List[Tuple[int, float, float]],  # [(N, Q_total, H_actual), ...]
    synthesizer: ParallelSynthesizer,
    model_type: str = "polynomial"
) -> CorrectionModel:
    """
    训练系统修正模型
    
    步骤：
        1. 对每个数据点(N, Q_total, H_actual)：
           - 计算理论扬程: H_theo = synthesizer.synthesize(N, Q_total)
           - 计算修正系数: α = H_actual / H_theo
        2. 构建特征矩阵 X = [N, Q_total]
        3. 拟合修正模型 α = f(N, Q_total)
    
    模型类型：
        - linear: α = a₀ + a₁×N + a₂×Q
        - polynomial: α = a₀ + a₁N + a₂Q + a₃N² + a₄Q² + a₅NQ
        - xgboost: 用于复杂混合泵组
    """
    X_data = []
    y_alpha = []
    
    for N, Q_total, H_actual in training_data:
        H_theo = synthesizer.synthesize(n_pumps=N, Q_total=Q_total)
        
        if H_theo > 0:
            alpha = H_actual / H_theo
            if 0.5 <= alpha <= 1.5:  # 过滤异常值
                X_data.append([N, Q_total])
                y_alpha.append(alpha)
    
    X = np.array(X_data)
    y = np.array(y_alpha)
    
    # 根据model_type训练模型
    if model_type == "polynomial":
        from sklearn.preprocessing import PolynomialFeatures
        from sklearn.linear_model import Ridge
        from sklearn.pipeline import Pipeline
        
        model = Pipeline([
            ('poly', PolynomialFeatures(degree=2)),
            ('ridge', Ridge(alpha=1.0))
        ])
        model.fit(X, y)
    
    return CorrectionModel(model=model, r_squared=..., ...)
```

## 6. 核心算法详解

### 6.1 拟合方法选择策略

```
| 数据量 | 曲线类型 | 推荐方法 | 理由 |
|--------|---------|---------|------|
| <100 | 任意 | math_poly_2 | 数据少，用简单模型避免过拟合 |
| 100-500 | qh | physics_pump_char | 物理模型有约束，更稳定 |
| 100-500 | qp | math_poly_3 | 功率曲线通常需要3阶 |
| 100-500 | qeta | math_stat_gaussian | 效率曲线符合高斯分布 |
| >500 | 任意 | ml_gradient_boost | 大数据量下机器学习更精确 |
```

### 6.2 Q-H曲线物理模型（完善版）

#### 6.2.1 完整物理模型

**基础模型**（工频泵）：
```
H = H₀ - A×Q - B×Q²

其中：
- H₀: 零流量扬程（截止扬程），单位m
- A: 一次项系数（流量线性损失），通常A≥0
- B: 二次项系数（流量平方损失），B>0
```

**变频泵模型**（基于仿射律）：
```
H = (n/n₀)² × H₀ - (n/n₀) × A × Q - B × Q²

其中：
- n: 实际转速 (rpm)
- n₀: 额定转速 (rpm)
- n/n₀ 通常用频率比 f/f₀ 近似
```

**物理约束**：
```
├─ H₀ > 0（截止扬程为正）
├─ 20m < H₀ < 100m（典型泵站范围，可配置）
├─ A ≥ 0, B > 0
├─ dH/dQ = -A - 2BQ < 0（单调递减）
└─ H(Q_max) > 0（最大流量时扬程仍为正）
```

#### 6.2.2 拟合实现

```python
def physics_pump_char_fit_v2(
    Q: np.ndarray, 
    H: np.ndarray,
    include_linear_term: bool = True
) -> Dict:
    """
    完善的泵特性方程拟合
    
    模型选择：
    - include_linear_term=True:  H = H₀ - A×Q - B×Q²（推荐）
    - include_linear_term=False: H = H₀ - B×Q²（简化版）
    
    物理意义:
        H₀: 零流量扬程（截止扬程）
        A: 一次项系数（流量线性损失）
        B: 二次项系数（流量平方损失）
    
    约束:
        H₀ > 0, A >= 0, B > 0
        dH/dQ < 0（单调递减）
    """
    from scipy.optimize import curve_fit
    
    if include_linear_term:
        def pump_curve(Q, H0, A, B):
            return H0 - A * Q - B * Q**2
        
        H0_init = H.max()
        A_init = 0.001
        B_init = (H.max() - H.min()) / (Q.max()**2)
        
        popt, pcov = curve_fit(
            pump_curve, Q, H,
            p0=[H0_init, A_init, B_init],
            bounds=([10, 0, 0], [H0_init*2, 0.1, B_init*10])
        )
        
        return {
            'H0': popt[0], 
            'A': popt[1], 
            'B': popt[2],
            'model_type': 'quadratic_with_linear'
        }
    else:
        def pump_curve(Q, H0, B):
            return H0 - B * Q**2
        
        H0_init = H.max()
        B_init = (H.max() - H.min()) / (Q.max()**2)
        
        popt, pcov = curve_fit(
            pump_curve, Q, H,
            p0=[H0_init, B_init],
            bounds=([10, 0], [H0_init*2, B_init*10])
        )
        
        return {
            'H0': popt[0], 
            'A': 0, 
            'B': popt[1],
            'model_type': 'quadratic_only'
        }
```

### 6.3 Q-P曲线物理模型

#### 6.3.1 物理方程推导

```
轴功率物理公式：
P = ρ × g × Q × H / (η × 1000)  [kW]

其中：
- ρ = 水密度 (1000 kg/m³)
- g = 重力加速度 (9.81 m/s²)
- Q = 流量 (m³/s) = Q_m³h / 3600
- H = 扬程 (m)
- η = 泵效率 (0.6-0.85)

代入Q-H曲线和Q-η曲线，可推导得：
P = C₀ + C₁×Q + C₂×Q² + C₃×Q³

物理约束：
├─ P(Q) > 0（功率恒为正）
├─ P(0) = P_idle > 0（空载功率，通常为额定功率的5-15%）
├─ P(Q_max) < P_rated（不超过电机额定功率）
└─ 通常dP/dQ > 0（功率随流量增加，但某些特殊泵可能例外）
```

#### 6.3.2 拟合实现

```python
def physics_power_fit(
    Q: np.ndarray, 
    P: np.ndarray,
    P_rated: float = None
) -> Dict:
    """
    Q-P曲线拟合
    
    模型: P = C₀ + C₁×Q + C₂×Q² + C₃×Q³
    
    Args:
        Q: 流量数组 (m³/h)
        P: 功率数组 (kW)
        P_rated: 电机额定功率（用于约束上界）
    """
    # 使用3阶多项式拟合
    coeffs = np.polyfit(Q, P, 3)
    
    # 验证物理约束
    C3, C2, C1, C0 = coeffs
    
    # 空载功率应为正
    if C0 <= 0:
        # 强制修正：使用带约束的优化
        from scipy.optimize import minimize
        def objective(c):
            pred = c[0] + c[1]*Q + c[2]*Q**2 + c[3]*Q**3
            return np.sum((P - pred)**2)
        
        result = minimize(
            objective,
            x0=[P.min() * 0.5, 0, 0, 0],
            bounds=[(0.1, None), (None, None), (None, None), (None, None)]
        )
        C0, C1, C2, C3 = result.x
    
    return {
        'C0': C0, 'C1': C1, 'C2': C2, 'C3': C3,
        'model_type': 'cubic_polynomial'
    }
```

### 6.4 Q-η曲线物理模型

#### 6.4.1 效率曲线特征

```
效率曲线特征：
├─ 呈抛物线形，存在唯一极大值点（最佳效率点BEP）
├─ η(Q=0) ≈ 0（零流量时效率为0）
├─ η(Q→∞) → 0（极大流量时效率趋近0）
└─ 0 < η < 1（效率在0-100%之间）

推荐模型（高斯型）：
η = η_max × exp(-((Q - Q_bep) / W)²)

或简化抛物线模型：
η = η_max × [1 - ((Q - Q_bep) / W)²]

其中：
- η_max: 最高效率点效率（BEP效率），通常0.6-0.85
- Q_bep: 最佳效率点流量
- W: 曲线宽度参数（高效区范围）
```

#### 6.4.2 拟合实现

```python
def physics_efficiency_fit(
    Q: np.ndarray, 
    eta: np.ndarray
) -> Dict:
    """
    Q-η曲线拟合
    
    模型: η = η_max × [1 - ((Q - Q_bep) / W)²]
    
    物理约束：
    - 0.5 < η_max < 0.95
    - Q_min < Q_bep < Q_max
    - W > (Q_max - Q_min) / 4
    """
    from scipy.optimize import curve_fit
    
    def efficiency_curve(Q, eta_max, Q_bep, W):
        return eta_max * (1 - ((Q - Q_bep) / W)**2)
    
    # 初始猜测
    eta_max_init = eta.max()
    Q_bep_init = Q[np.argmax(eta)]
    W_init = (Q.max() - Q.min()) / 2
    
    popt, pcov = curve_fit(
        efficiency_curve, Q, eta,
        p0=[eta_max_init, Q_bep_init, W_init],
        bounds=(
            [0.5, Q.min(), (Q.max()-Q.min())/4],
            [0.95, Q.max(), (Q.max()-Q.min())*2]
        )
    )
    
    return {
        'eta_max': popt[0],
        'Q_bep': popt[1],
        'W': popt[2],
        'model_type': 'parabolic_efficiency'
    }
```

### 6.5 变频泵相似律处理

#### 6.5.1 相似律（仿射律）原理

```
泵相似律（Affinity Laws）：

当泵转速从n₁变为n₂时：
├─ 流量比例：Q₂/Q₁ = n₂/n₁
├─ 扬程比例：H₂/H₁ = (n₂/n₁)²
├─ 功率比例：P₂/P₁ = (n₂/n₁)³
└─ 效率近似不变：η₂ ≈ η₁（小范围调速）

变频器频率与转速关系：
n/n₀ ≈ f/f₀（异步电机在工频附近）

其中：
- f₀ = 50Hz（工频）
- f = 实际运行频率
```

#### 6.5.2 数据归一化处理

```python
    f_rated: float = 50.0
) -> Tuple[np.ndarray, np.ndarray, np.ndarray]:

    将不同频率下的运行数据归一化到额定频率
    
    应用场景：
    1. 单泵曲线拟合前，统一到额定频率

    # 应用相似律归一化
    Q_normalized = Q / speed_ratio
    H_normalized = H / (speed_ratio ** 2)
    P_normalized = P / (speed_ratio ** 3)

    """

    Q_target = Q_rated * ratio
```

### 6.7 性能衰减建模

#### 6.7.1 性能衰减因子

```
性能衰减因子δ：
H_actual = H_new × δ(t)

其中：
- H_new: 新泵的理论扬程
- δ(t): 衰减因子，通常0.8 < δ < 1.0
- t: 运行时长或运行周期

衰减建模方法：
├─ 方法1：按运行时长建模
│   δ = 1 - k × running_hours
│   k为经验衰减系数，通常k ≈ 0.00001/h
│
├─ 方法2：按拟合结果趋势追踪
│   对比不同时期拟合的曲线系数变化
│
└─ 应用：故障诊断预警
    当δ < 0.85时，提示设备可能需要维护
```

#### 6.7.2 衰减追踪实现

```python
@dataclass
class PerformanceTrend:
    """性能趋势追踪"""
    pump_id: int
    fitted_at: datetime
    H0: float  # 截止扬程
    degradation_factor: float  # 衰减因子
    running_hours: float  # 累计运行时长
    

def track_performance_degradation(
    pump_id: int,
    historical_fits: List[DirectFitResult]
) -> List[PerformanceTrend]:
    """
    追踪泵性能衰减趋势
    
    通过对比不同时期的拟合结果，计算衰减因子
    """
    if len(historical_fits) < 2:
        return []
    
    # 以第一次拟合为基准
    baseline = historical_fits[0]
    H0_baseline = baseline.coefficients[0]  # 截止扬程
    
    trends = []
    for fit_result in historical_fits:
        H0_current = fit_result.coefficients[0]
        degradation = H0_current / H0_baseline
        
        trends.append(PerformanceTrend(
            pump_id=pump_id,
            fitted_at=fit_result.fitted_at,
            H0=H0_current,
            degradation_factor=degradation,
            running_hours=0  # 需从外部获取
        ))
    
    return trends


def predict_remaining_life(
    trends: List[PerformanceTrend],
    threshold: float = 0.85
) -> Optional[datetime]:
    """
    预测剩余使用寿命（何时衰减到阈值）
    """
    if len(trends) < 3:
        return None
    
    # 线性外推
    times = [(t.fitted_at - trends[0].fitted_at).days for t in trends]
    factors = [t.degradation_factor for t in trends]
    
    slope, intercept = np.polyfit(times, factors, 1)
    
    if slope >= 0:
        return None  # 没有衰减趋势
    
    # 预测何时达到阈值
    days_to_threshold = (threshold - intercept) / slope
    
    return trends[0].fitted_at + timedelta(days=days_to_threshold)
```

### 6.8 逆函数构造（增强版）

#### 6.8.1 基础逆函数

```python
def build_inverse_function(
    coefficients: List[float],
    H_max: float
) -> Callable[[float], float]:
    """
    根据Q-H曲线系数构造逆函数 H → Q
    
    对于 H = a₀ + a₁Q + a₂Q²：
        a₂Q² + a₁Q + (a₀ - H) = 0
        
    解: Q = (-a₁ ± sqrt(a₁² - 4a₂(a₀-H))) / (2a₂)
    """
    a0, a1, a2 = coefficients[:3]
    
    def inverse_func(H: float) -> float:
        if H > H_max:
            return 0.0
        
        discriminant = a1**2 - 4 * a2 * (a0 - H)
        if discriminant < 0:
            return 0.0
        
        sqrt_d = np.sqrt(discriminant)
        q1 = (-a1 + sqrt_d) / (2 * a2)
        q2 = (-a1 - sqrt_d) / (2 * a2)
        
        return max(0, q1) if q1 > 0 else max(0, q2)
    
    return inverse_func
```

#### 6.8.2 异构泵组合成稳定算法

```python
def synthesize_heterogeneous_robust(
    pump_curves: Dict[int, Callable[[float], float]],  # pump_id → (Q → H)
    pump_ids: List[int],
    Q_total: float,
    tolerance: float = 0.1,
    max_iterations: int = 50
) -> Tuple[float, Dict[int, float]]:
    """
    稳定的异构泵组合成算法（二分法）
    
    问题：给定Q_total，求解满足 ΣQᵢ(H) = Q_total 的H值
    
    优势：
    - 避免判别式接近0时的数值不稳定
    - 保证收敛性
    
    Args:
        pump_curves: 各泵的Q-H曲线函数 pump_id → (Q → H)
        pump_ids: 运行的泵ID列表
        Q_total: 目标总流量
        tolerance: 收敛容差 (m³/h)
        max_iterations: 最大迭代次数
    
    Returns:
        (H_system, {pump_id: Q_i})
    """
    # 计算扬程范围
    H_min = 0
    H_max = min(
        pump_curves[pid](0) for pid in pump_ids
    )  # 各泵截止扬程的最小值
    
    # 构造逆函数
    inverse_curves = {}
    for pid in pump_ids:
        inverse_curves[pid] = build_inverse_from_curve(pump_curves[pid])
    
    # 二分法求解
    H_low, H_high = H_min, H_max
    
    for iteration in range(max_iterations):
        H_mid = (H_low + H_high) / 2
        
        # 计算在H_mid下各泵流量
        pump_flows = {}
        Q_sum = 0.0
        for pid in pump_ids:
            Q_i = inverse_curves[pid](H_mid)
            pump_flows[pid] = max(0, Q_i)
            Q_sum += pump_flows[pid]
        
        # 检查收敛
        if abs(Q_sum - Q_total) < tolerance:
            return H_mid, pump_flows
        
        # 调整边界
        if Q_sum > Q_total:
            H_low = H_mid  # 总流量过大，需要提高扬程
        else:
            H_high = H_mid  # 总流量过小，需要降低扬程
    
    logger.warning(f"异构泵组合成未完全收敛，误差={abs(Q_sum - Q_total):.2f}")
    return H_mid, pump_flows


def build_inverse_from_curve(
    curve_func: Callable[[float], float],
    Q_range: Tuple[float, float] = (0, 10000),
    resolution: int = 1000
) -> Callable[[float], float]:
    """
    从任意曲线函数构造逆函数（查表法 + 插值）
    
    用于处理无解析逆函数的复杂曲线
    """
    from scipy.interpolate import interp1d
    
    # 构建查找表
    Q_values = np.linspace(Q_range[0], Q_range[1], resolution)
    H_values = np.array([curve_func(q) for q in Q_values])
    
    # 反转数组以使用插值（H→Q）
    valid_mask = np.diff(H_values) < 0  # 只保留单调递减部分
    valid_mask = np.append(valid_mask, False)
    
    H_valid = H_values[valid_mask]
    Q_valid = Q_values[valid_mask]
    
    if len(H_valid) < 2:
        return lambda H: 0.0
    
    # 构造插值函数
    interp_func = interp1d(
        H_valid[::-1], Q_valid[::-1],
        kind='linear',
        bounds_error=False,
        fill_value=(Q_valid[-1], Q_valid[0])
    )
    
    return interp_func
```

### 7.2 稳态检测算法（增强版）

#### 7.2.1 稳态检测原理

```
稳态工况判定条件：
├─ 条件1：时间窗口内Q和H的变异系数 < 5%
├─ 条件2：运行台数稳定（无启停操作）
├─ 条件3：流量方向正常（Q > 0）
└─ 条件4：启动锁定期外（泵启动后3分钟内不采用）

需排除的非稳态工况：
├─ 启停过渡期：泵启动/停止前后2分钟
├─ 切泵过程：运行台数变化前后2分钟
├─ 压力波动：dP/dt > 阈值
└─ 逆流工况：Q < 0
```

#### 7.2.2 增强版实现

```python
def detect_steady_state_enhanced(
    points: List[GroupOperatingPoint],
    window_minutes: int = 5,
    threshold_pct: float = 0.05,
    startup_lockout_minutes: int = 3,
    transition_lockout_minutes: int = 2
) -> List[GroupOperatingPoint]:
    """
    增强的稳态检测算法
    
    新增检测项：
    1. 运行台数变化检测
    2. 流量方向检测
    3. 启动锁定期
    4. 压力波动检测
    
    参数：
        points: 按时间排序的工况点
        window_minutes: 滑动窗口大小（分钟）
        threshold_pct: 变化阈值百分比
        startup_lockout_minutes: 启动锁定时间
        transition_lockout_minutes: 切换锁定时间
    """
    if len(points) < 3:
        return points
    
    window_size = window_minutes * 12  # 假设5秒采样间隔
    startup_lockout = startup_lockout_minutes * 12
    transition_lockout = transition_lockout_minutes * 12
    
    # 标记运行台数变化点
    transition_indices = set()
    for i in range(1, len(points)):
        if points[i].n_running != points[i-1].n_running:
            # 标记前后过渡期
            for j in range(max(0, i - transition_lockout), 
                          min(len(points), i + transition_lockout)):
                transition_indices.add(j)
    
    # 标记启动锁定期（从停止到运行）
    startup_indices = set()
    for i in range(1, len(points)):
        if points[i-1].n_running == 0 and points[i].n_running > 0:
            for j in range(i, min(len(points), i + startup_lockout)):
                startup_indices.add(j)
    
    for i, point in enumerate(points):
        # 初始化为非稳态
        point.is_steady_state = False
        
        # 检查1：流量方向
        if point.Q_total <= 0:
            continue
        
        # 检查2：运行台数变化锁定期
        if i in transition_indices:
            continue
        
        # 检查3：启动锁定期
        if i in startup_indices:
            continue
        
        # 检查4：窗口内变异系数
        start_idx = max(0, i - window_size // 2)
        end_idx = min(len(points), i + window_size // 2 + 1)
        window_points = points[start_idx:end_idx]
        
        if len(window_points) < 3:
            continue
        
        # 窗口内运行台数应一致
        if len(set(p.n_running for p in window_points)) > 1:
            continue
        
        # 计算窗口内Q和H的变异系数
        Q_values = [p.Q_total for p in window_points]
        H_values = [p.H_system for p in window_points]
        
        Q_mean = np.mean(Q_values)
        H_mean = np.mean(H_values)
        
        Q_cv = np.std(Q_values) / Q_mean if Q_mean > 0 else 1.0
        H_cv = np.std(H_values) / H_mean if H_mean > 0 else 1.0
        
        # 判断是否稳态
        if Q_cv < threshold_pct and H_cv < threshold_pct:
            point.is_steady_state = True
    
    # 返回稳态点
    steady_points = [p for p in points if p.is_steady_state]
    
    logger.info(
        f"稳态检测完成: 总点数={len(points)}, "
        f"稳态点={len(steady_points)}, "
        f"过渡期排除={len(transition_indices)}, "
        f"启动锁定排除={len(startup_indices)}"
    )
    
    return steady_points
```

### 7.3 异常值过滤

```python
def filter_outliers(
    points: List[GroupOperatingPoint],
    q_min: float = 10.0,
    q_max: float = 10000.0,
    h_min: float = 1.0,
    h_max: float = 200.0,
    iqr_multiplier: float = 1.5
) -> List[GroupOperatingPoint]:
    """
    过滤异常工况点
    
    策略：
    1. 硬边界过滤：超出物理合理范围
    2. IQR法过滤：统计异常点
    """
    # 硬边界过滤
    points = [
        p for p in points
        if q_min <= p.Q_total <= q_max
        and h_min <= p.H_system <= h_max
    ]
    
    if len(points) < 10:
        return points
    
    # IQR法过滤（基于残差）
    Q = np.array([p.Q_total for p in points])
    H = np.array([p.H_system for p in points])
    
    # 先做初步拟合
    coeffs = np.polyfit(Q, H, 2)
    H_pred = np.polyval(coeffs, Q)
    residuals = np.abs(H - H_pred)
    
    q1, q3 = np.percentile(residuals, [25, 75])
    iqr = q3 - q1
    upper_bound = q3 + iqr_multiplier * iqr
    
    # 保留残差在合理范围内的点
    valid_indices = np.where(residuals <= upper_bound)[0]
    return [points[i] for i in valid_indices]
```

```python
def calculate_physics_score_enhanced(
    result: DirectFitResult,
    curve_type: str = "qh",
    config: Optional[Dict] = None
) -> Tuple[float, Dict[str, bool]]:
    """
    增强的物理合理性评分
    
    Args:
        result: 拟合结果
        curve_type: 曲线类型 ("qh", "qp", "qeta")
        config: 可配置参数
    
    Returns:
        (score, {check_name: passed})
    """
    if config is None:
        config = {
            'H0_min': 20.0,   # 最小截止扬程
            'H0_max': 100.0,  # 最大截止扬程
            'slope_min': -0.1,
            'slope_max': 0.0,
            'confidence_width_max': 5.0,
            'eta_max_min': 0.6,
            'eta_max_max': 0.9,
        }
    
    coeffs = result.coefficients
    Q_min, Q_max = result.valid_q_range
    
    # 构造预测函数
    predict = lambda Q: sum(c * Q**i for i, c in enumerate(coeffs))
    
    checks = {}
    
    if curve_type == "qh":
        return _validate_qh_curve(result, coeffs, Q_min, Q_max, predict, config)
    elif curve_type == "qp":
        return _validate_qp_curve(result, coeffs, Q_min, Q_max, predict, config)
    elif curve_type == "qeta":
        return _validate_qeta_curve(result, coeffs, Q_min, Q_max, predict, config)
    else:
        return 50.0, {}  # 未知曲线类型


def _validate_qh_curve(
    result: DirectFitResult,
    coeffs: List[float],
    Q_min: float,
    Q_max: float,
    predict: Callable,
    config: Dict
) -> Tuple[float, Dict[str, bool]]:
    """验证Q-H曲线"""
    score = 0.0
    checks = {}
    
    # 1. 单调性检查 (20分)
    Q_test = np.linspace(Q_min, Q_max, 100)
    H_test = [predict(q) for q in Q_test]
    is_monotonic = all(H_test[i] >= H_test[i+1] for i in range(len(H_test)-1))
    checks['monotonic_decrease'] = is_monotonic
    if is_monotonic:
        score += 20
    
    # 2. 截止扬程为正 (10分)
    H_zero = predict(0)
    checks['shutoff_head_positive'] = H_zero > 0
    if H_zero > 0:
        score += 10
    
    # 3. 截止扬程范围 (10分)
    in_range = config['H0_min'] <= H_zero <= config['H0_max']
    checks['shutoff_head_range'] = in_range
    if in_range:
        score += 10
    
    # 4. 最大流量点扬程为正 (10分)
    H_max_flow = predict(Q_max)
    checks['max_flow_head_positive'] = H_max_flow > 0
    if H_max_flow > 0:
        score += 10
    
    # 5. 曲线斜率范围 (10分)
    if len(coeffs) >= 2:
        # dH/dQ = a1 + 2*a2*Q
        slopes = [coeffs[1] + 2*coeffs[2]*q if len(coeffs)>=3 else coeffs[1] 
                  for q in Q_test]
        slope_valid = all(config['slope_min'] <= s <= config['slope_max'] for s in slopes)
        checks['slope_range'] = slope_valid
        if slope_valid:
            score += 10
    
    # 6. 二次项系数检查 (10分)
    if len(coeffs) >= 3:
        checks['quadratic_negative'] = coeffs[2] < 0
        if coeffs[2] < 0:
            score += 10
    
    # 7. 并联横移验证 (10分) - 需要多曲线对比，此处简化
    checks['parallel_shift'] = True
    score += 10
    
    # 8. 曲线平滑性 (5分)
    diffs = np.diff(H_test)
    is_smooth = np.std(diffs) < np.abs(np.mean(diffs)) * 0.5
    checks['curve_smooth'] = is_smooth
    if is_smooth:
        score += 5
    
    # 9. 残差正态性 (10分)
    if hasattr(result, 'residuals') and result.residuals is not None:
        from scipy.stats import shapiro
        _, p_value = shapiro(result.residuals[:50])  # 取前50个
        checks['residuals_normal'] = p_value > 0.05
        if p_value > 0.05:
            score += 10
    else:
        checks['residuals_normal'] = None
        score += 5  # 无数据时给一半分
    
    # 10. 置信区间 (5分)
    if hasattr(result, 'confidence_interval_width'):
        ci_ok = result.confidence_interval_width < config['confidence_width_max']
        checks['confidence_interval'] = ci_ok
        if ci_ok:
            score += 5
    else:
        checks['confidence_interval'] = None
        score += 2.5
    
    return score, checks


def _validate_qp_curve(
    result: DirectFitResult,
    coeffs: List[float],
    Q_min: float,
    Q_max: float,
    predict: Callable,
    config: Dict
) -> Tuple[float, Dict[str, bool]]:
    """验证Q-P曲线"""
    score = 0.0
    checks = {}
    
    Q_test = np.linspace(Q_min, Q_max, 100)
    P_test = [predict(q) for q in Q_test]
    
    # 1. 功率恒正 (30分)
    all_positive = all(p > 0 for p in P_test)
    checks['power_positive'] = all_positive
    if all_positive:
        score += 30
    
    # 2. 空载功率范围 (20分)
    P_zero = predict(0)
    if hasattr(result, 'P_rated') and result.P_rated:
        idle_ratio = P_zero / result.P_rated
        checks['idle_power_range'] = 0.05 < idle_ratio < 0.15
        if 0.05 < idle_ratio < 0.15:
            score += 20
    else:
        checks['idle_power_range'] = P_zero > 0
        if P_zero > 0:
            score += 10
    
    # 3. 满载功率 (20分)
    P_max = predict(Q_max)
    if hasattr(result, 'P_rated') and result.P_rated:
        checks['max_power_limit'] = P_max < result.P_rated
        if P_max < result.P_rated:
            score += 20
    else:
        checks['max_power_limit'] = True
        score += 20
    
    # 4. 功率增长趋势 (15分)
    is_increasing = all(P_test[i] <= P_test[i+1] for i in range(len(P_test)-1))
    checks['power_increasing'] = is_increasing
    if is_increasing:
        score += 15
    
    # 5. 曲线平滑性 (15分)
    diffs = np.diff(P_test)
    is_smooth = np.std(diffs) < np.abs(np.mean(diffs)) * 0.5 if np.mean(diffs) != 0 else True
    checks['curve_smooth'] = is_smooth
    if is_smooth:
        score += 15
    
    return score, checks


def _validate_qeta_curve(
    result: DirectFitResult,
    coeffs: List[float],
    Q_min: float,
    Q_max: float,
    predict: Callable,
    config: Dict
) -> Tuple[float, Dict[str, bool]]:
    """验证Q-η曲线"""
    score = 0.0
    checks = {}
    
    Q_test = np.linspace(Q_min, Q_max, 100)
    eta_test = [predict(q) for q in Q_test]
    
    # 1. 效率范围 (30分)
    in_range = all(0 < e < 1 for e in eta_test)
    checks['efficiency_range'] = in_range
    if in_range:
        score += 30
    
    # 2. 存在极大值 (25分)
    eta_max_idx = np.argmax(eta_test)
    has_peak = 0 < eta_max_idx < len(eta_test) - 1
    checks['has_peak'] = has_peak
    if has_peak:
        score += 25
    
    # 3. BEP效率范围 (20分)
    eta_max = max(eta_test)
    bep_range_ok = config['eta_max_min'] < eta_max < config['eta_max_max']
    checks['bep_efficiency_range'] = bep_range_ok
    if bep_range_ok:
        score += 20
    
    # 4. 零流量效率 (15分)
    eta_zero = predict(0)
    near_zero = abs(eta_zero) < 0.1
    checks['zero_flow_efficiency'] = near_zero
    if near_zero:
        score += 15
    
    # 5. 曲线对称性 (10分)
    # 检查曲线在BEP两侧是否大致对称
    left_part = eta_test[:eta_max_idx]
    right_part = eta_test[eta_max_idx:]
    if len(left_part) > 0 and len(right_part) > 0:
        left_slope = np.mean(np.diff(left_part)) if len(left_part) > 1 else 0
        right_slope = np.mean(np.diff(right_part)) if len(right_part) > 1 else 0
        is_symmetric = abs(left_slope + right_slope) < abs(left_slope) * 0.5
        checks['curve_symmetric'] = is_symmetric
        if is_symmetric:
            score += 10
    else:
        checks['curve_symmetric'] = None
    
    return score, checks
```

```python
def recommend_method(
    direct_result: Optional[DirectFitResult],
    synthesis_result: Optional[SynthesisFitResult],
    weights: Dict[str, float] = None
) -> Tuple[str, str]:
    """
    推荐最优方法
    
    Args:
        direct_result: 方法A结果
        synthesis_result: 方法B结果
        weights: 指标权重
    
    Returns:
        (recommended_method, reason)
    """
    if weights is None:
        weights = {
            'r_squared': 0.35,
            'rmse': 0.25,
            'mae': 0.15,
            'mape': 0.15,
            'physics': 0.10
        }
    
    # 计算方法A综合得分
    if direct_result and direct_result.r_squared > 0:
        physics_a = calculate_physics_score(direct_result)
        score_a = (
            weights['r_squared'] * direct_result.r_squared * 100 +
            weights['rmse'] * max(0, 100 - direct_result.rmse * 5) +
            weights['mae'] * max(0, 100 - direct_result.mae * 5) +
            weights['mape'] * max(0, 100 - direct_result.mape * 100) +
            weights['physics'] * physics_a
        )
    else:
        score_a = 0
    
    # 计算方法B综合得分
    if synthesis_result and synthesis_result.overall_r_squared > 0:
        # 方法B的物理性天然较好（基于单泵曲线合成）
        physics_b = 85  # 基础分
        score_b = (
            weights['r_squared'] * synthesis_result.overall_r_squared * 100 +
            weights['rmse'] * max(0, 100 - synthesis_result.overall_rmse * 5) +
            weights['mae'] * 80 +  # 假设中等
            weights['mape'] * 80 +
            weights['physics'] * physics_b
        )
    else:
        score_b = 0
    
    # 推荐决策
    if score_a > score_b * 1.05:  # 方法A显著优于B
        return "direct_fit", f"直接拟合得分({score_a:.1f})显著优于合成法({score_b:.1f})，数据充足时直接拟合更准确"
    elif score_b > score_a * 1.05:  # 方法B显著优于A
        return "synthesis", f"合成法得分({score_b:.1f})优于直接拟合({score_a:.1f})，可能数据不足或分布不均"
    else:
        # 相近时优先选择直接拟合（更准确）
        return "direct_fit", f"两种方法得分相近(A:{score_a:.1f}, B:{score_b:.1f})，优先使用直接拟合"
```

**修复内容**:
```python
def extract_data(
    self,
    device_id: int,
    start_time: datetime,
    end_time: datetime,
    min_points: int = 100
) -> pd.DataFrame:
    """提取Q-P数据
    
    从 fact_measurements 表提取 pump_flow_rate (Q) 和 pump_shaft_power (P) 指标。
    
    Args:
        device_id: 设备ID
        start_time: 开始时间
        end_time: 结束时间
        min_points: 最小数据点数
    
    Returns:
        DataFrame: 包含 ts_bucket, Q, P 列的数据
    """
    sql = """
        SELECT
            ts_bucket,
            MAX(CASE WHEN metric_id = (
                SELECT id FROM dim_metric_config
                WHERE metric_key = 'pump_flow_rate'
            ) THEN value END) AS Q,
            MAX(CASE WHEN metric_id = (
                SELECT id FROM dim_metric_config
                WHERE metric_key = 'pump_shaft_power'
            ) THEN value END) AS P
        FROM fact_measurements
        WHERE device_id = %(device_id)s
          AND ts_bucket BETWEEN %(start_time)s AND %(end_time)s
        GROUP BY ts_bucket
        HAVING Q IS NOT NULL AND P IS NOT NULL
        ORDER BY ts_bucket
    """
    
    with get_connection() as conn:
        with conn.cursor() as cursor:
            cursor.execute(sql, {
                'device_id': device_id,
                'start_time': start_time,
                'end_time': end_time
            })
            rows = cursor.fetchall()
            columns = [desc[0] for desc in cursor.description]
    
    data = pd.DataFrame(rows, columns=columns)
    
    if len(data) < min_points:
        raise DataExtractionError(
            f"数据点不足: {len(data)} < {min_points}",
            device_id=device_id,
            curve_type=self.curve_type.value
        )
    
    self._logger.info(f"[QP提取] 成功提取 {len(data)} 条数据")
    return data
```

#### 13.2.3 泵组场景识别实现

**文件**: `app/services/characteristic_curves/preprocessing/scenario_detector.py`

```python
def detect_group_scenario(
    self,
    station_id: int,
    pump_configs: List[Dict]
) -> FittingScenario:
    """识别泵组场景
    
    5种泵组场景识别规则：
    1. 同构泵组(HOMOGENEOUS_GROUP): 
       - 所有泵型号相同
       - 功率差异<10%
       - 可变频或全软起
    
    2. 异构泵组(HETEROGENEOUS_GROUP):
       - 功率差异≥10%
       - 全VFD或全软起
    
    3. VFD异频泵组(VFD_HETEROGENEOUS_FREQ):
       - 全VFD
       - 运行频率差异≥2Hz
    
    4. 混合泵组(MIXED_GROUP):
       - VFD+软起混合
       - 功率差异<10%
    
    5. 混合异构泵组(MIXED_HETEROGENEOUS):
       - VFD+软起混合
       - 功率差异≥10%
    
    排除场景：全软起泵组（不支持特性曲线拟合）
    """
    # 1. 获取泵类型统计
    pump_types = [p.get('pump_type') for p in pump_configs]
    vfd_count = sum(1 for t in pump_types if t == 'variable_frequency')
    ss_count = sum(1 for t in pump_types if t == 'soft_start')
    total_count = len(pump_configs)
    
    # 2. 计算功率差异
    powers = [p.get('rated_power', 0) for p in pump_configs]
    max_power = max(powers) if powers else 0
    min_power = min(powers) if powers else 0
    power_diff_ratio = (max_power - min_power) / max_power if max_power > 0 else 0
    is_heterogeneous = power_diff_ratio >= 0.10
    
    # 3. 排除全软起
    if ss_count == total_count:
        return FittingScenario.NOT_SUPPORTED
    
    # 4. 识别场景
    if vfd_count == total_count:
        # 全VFD
        if is_heterogeneous:
            return FittingScenario.HETEROGENEOUS_GROUP
        else:
            # 检查频率差异（需要运行数据）
            # 这里简化为返回同构
            return FittingScenario.HOMOGENEOUS_GROUP
    elif vfd_count > 0 and ss_count > 0:
        # VFD+软起混合
        if is_heterogeneous:
            return FittingScenario.MIXED_HETEROGENEOUS
        else:
            return FittingScenario.MIXED_GROUP
    else:
        # 其他情况
        return FittingScenario.HOMOGENEOUS_GROUP
```

```python
@dataclass
class GroupOperatingPoint:
    """泵组运行工况点（完整版）
    
    支持5种曲线类型的拟合：qh, qp, qeta, heta, peta
    """
    # 必需字段
    ts_bucket: datetime               # 时间戳
    station_id: int                   # 泵站ID
    Q_total: float                    # 总流量 (m³/h)
    H_system: float                   # 系统扬程 (m)
    n_running: int                    # 运行台数
    running_pump_ids: Tuple[int, ...] # 运行泵ID元组
    pump_combination_key: str         # 泵组合键，如"1,2,3"
    
    # qp曲线所需
    P_total: Optional[float] = None   # 总功率 (kW)
    
    # qeta曲线所需（可从Q_total, H_system, P_total计算）
    eta_total: Optional[float] = None # 总效率 (0-1)
    
    # VFD异频场景所需
    pump_frequencies: Optional[Dict[int, float]] = None  # 各泵频率 {pump_id: freq_hz}
    
    # 稳态标识
    is_steady_state: bool = True      # 是否稳态工况
    
    def __post_init__(self):
        """计算派生字段"""
        # 自动计算总效率
        if self.eta_total is None and self.P_total and self.P_total > 0:
            rho = 1000  # 水密度 kg/m³
            g = 9.81    # 重力加速度 m/s²
            Q_m3s = self.Q_total / 3600  # 转换为 m³/s
            self.eta_total = (rho * g * Q_m3s * self.H_system) / (self.P_total * 1000)
```

```sql
-- 完善版SQL：支持qh, qp, qeta曲线
WITH pump_metrics AS (
    -- 获取每台泵的运行状态、功率、频率
    SELECT
        ts_bucket,
        device_id,
        MAX(CASE WHEN metric_key = 'running' THEN value END) AS running,
        MAX(CASE WHEN metric_key = 'pump_shaft_power' THEN value END) AS power,
        MAX(CASE WHEN metric_key = 'frequency' THEN value END) AS frequency
    FROM fact_measurements fm
    JOIN dim_metric_config dmc ON fm.metric_id = dmc.id
    WHERE ts_bucket >= :start_time AND ts_bucket < :end_time
      AND fm.station_id = :station_id
    GROUP BY ts_bucket, device_id
),
station_metrics AS (
    -- 获取泵站总管流量和出口压力
    SELECT
        ts_bucket,
        MAX(CASE WHEN metric_key = 'main_pipeline_flow_rate' THEN value END) AS Q_total,
        MAX(CASE WHEN metric_key = 'main_pipeline_outlet_pressure' THEN value END) * 10.2 AS H_system
    FROM fact_measurements fm
    JOIN dim_metric_config dmc ON fm.metric_id = dmc.id
    WHERE ts_bucket >= :start_time AND ts_bucket < :end_time
      AND station_id = :station_id
    GROUP BY ts_bucket
),
aggregated AS (
    SELECT
        pm.ts_bucket,
        :station_id AS station_id,
        sm.Q_total,
        sm.H_system,
        array_agg(pm.device_id ORDER BY pm.device_id) 
            FILTER (WHERE pm.running = 1) AS running_pump_ids,
        array_length(
            array_agg(pm.device_id) FILTER (WHERE pm.running = 1), 1
        ) AS n_running,
        SUM(pm.power) FILTER (WHERE pm.running = 1) AS P_total,
        -- 各泵频率（JSON格式）
        jsonb_object_agg(
            pm.device_id::text, pm.frequency
        ) FILTER (WHERE pm.running = 1) AS pump_frequencies
    FROM pump_metrics pm
    JOIN station_metrics sm ON pm.ts_bucket = sm.ts_bucket
    GROUP BY pm.ts_bucket, sm.Q_total, sm.H_system
)
SELECT
    ts_bucket,
    station_id,
    Q_total,
    H_system,
    running_pump_ids,
    n_running,
    P_total,
    pump_frequencies,
    array_to_string(running_pump_ids, ',') AS pump_combination_key
FROM aggregated
WHERE n_running >= :min_running_pumps
  AND Q_total > 0
  AND H_system > 0
ORDER BY pump_combination_key, ts_bucket;
```

## 18. 目标压力/流量变化对拟合的影响处理

### 18.1 问题描述

泵站运行中，**目标压力**或**目标流量**可能因以下原因发生变化：
- 用水高峰期提高目标压力
- 节能调度降低目标流量
- 供水区域调整导致目标值变化
- 管网改造后压力需求改变

**影响分析**：
```
目标值变化对拟合的影响：
├─ 目标压力↑ → 运行点右移（流量↑、扬程↑）→ 数据分布变化
├─ 目标压力↓ → 运行点左移（流量↓、扬程↓）→ 数据分布变化
└─ 结果：混合不同目标值下的数据拟合，会导致曲线失真
```

### 18.2 处理策略

#### 18.2.1 策略选择

| 策略 | 适用场景 | 实现方式 |
|------|---------|----------|
| **忽略差异** | 目标值变化<5%，影响可忽略 | 直接混合拟合 |
| **按目标值分组** | 目标值变化>10%，且有足够数据 | 每个目标值区间独立拟合 |
| **归一化处理** | 目标值频繁变化，数据分散 | 将运行点归一化到标准目标值 |

#### 18.2.2 归一化处理算法

```python
def normalize_operating_point(
    Q_actual: float,
    H_actual: float,
    P_target_actual: float,  # 实际目标压力
    P_target_standard: float = 0.35  # 标准目标压力 (MPa)
) -> Tuple[float, float]:
    """
    将运行点归一化到标准目标压力
    
    原理：假设管网阻力曲线H = k*Q²，目标压力变化导致运行点沿曲线移动
    归一化公式：Q_norm = Q_actual * sqrt(P_target_standard / P_target_actual)
    
    Args:
        Q_actual: 实际流量 (m³/h)
        H_actual: 实际扬程 (m)
        P_target_actual: 实际目标压力 (MPa)
        P_target_standard: 标准目标压力 (MPa)
    
    Returns:
        (Q_normalized, H_normalized): 归一化后的流量和扬程
    """
    # 压力比
    pressure_ratio = P_target_standard / P_target_actual
    
    # 流量归一化（根据相似律）
    Q_normalized = Q_actual * np.sqrt(pressure_ratio)
    
    # 扬程归一化（转换为标准目标压力对应的扬程）
    H_normalized = H_actual * pressure_ratio
    
    return Q_normalized, H_normalized
```

### 19.1 应排除的异常工况

| 异常类型 | 识别规则 | 过滤方式 |

| **启停过渡期** | 泵启动/停止前后2分钟 | 排除 |
| **切泵过程** | 运行台数变化前后2分钟 | 排除 |
| **压力异常** | H_system < 0 或 H_system > H_max_rated × 1.5 | 排除 |
| **功率异常** | P_total < 0 或 P_total > P_rated × 1.2 | 排除 |

### 19.2 过滤实现

```python
def filter_operating_points(
    points: List[GroupOperatingPoint],
    config: DataFilterConfig
) -> List[GroupOperatingPoint]:
    """
    过滤异常工况点
    
    Args:
        points: 原始工况点列表
        config: 过滤配置
    
    Returns:
        List[GroupOperatingPoint]: 过滤后的有效工况点
    """
    filtered = []
    
    for i, point in enumerate(points):
        # 1. 流量检查
        if point.Q_total < config.q_min_threshold:
            continue
        if point.Q_total < 0:  # 逆流
            continue
        
        # 2. 扬程检查
        if point.H_system < 0 or point.H_system > config.h_max_threshold:
            continue
        
        # 3. 功率检查（如果有）
        if point.P_total is not None:
            if point.P_total < 0 or point.P_total > config.p_max_threshold:
                continue
        
        # 4. 稳态检查
        if not point.is_steady_state:
            continue
        
        # 5. 启停锁定检查（需要上下文）
        # 在预处理阶段已标记
        
        filtered.append(point)
    
    return filtered
```

## 20. 变频泵组频率归一化处理

### 20.1 问题描述

当泵组中各泵运行频率不同时（VFD异频泵组场景），直接合成会导致物理意义错误。

### 20.2 归一化原理（基于仿射律）

```
仿射律（Affinity Laws）：
├─ 流量: Q₁/Q₂ = n₁/n₂ = f₁/f₂
├─ 扬程: H₁/H₂ = (n₁/n₂)² = (f₁/f₂)²
└─ 功率: P₁/P₂ = (n₁/n₂)³ = (f₁/f₂)³

归一化到额定频率(50Hz)：
├─ Q_norm = Q_actual × (50 / f_actual)
├─ H_norm = H_actual × (50 / f_actual)²
└─ P_norm = P_actual × (50 / f_actual)³
```

### 20.3 归一化实现

```python
def normalize_to_rated_frequency(
    Q: float,
    H: float,
    P: float,
    f_actual: float,
    f_rated: float = 50.0
) -> Tuple[float, float, float]:
    """
    将变频泵运行点归一化到额定频率
    
    Args:
        Q: 实际流量 (m³/h)
        H: 实际扬程 (m)
        P: 实际功率 (kW)
        f_actual: 实际运行频率 (Hz)
        f_rated: 额定频率 (Hz), 默认50Hz
    
    Returns:
        (Q_norm, H_norm, P_norm): 归一化后的流量、扬程、功率
    """
    ratio = f_rated / f_actual
    
    Q_norm = Q * ratio
    H_norm = H * (ratio ** 2)
    P_norm = P * (ratio ** 3)
    
    return Q_norm, H_norm, P_norm
```

### 20.4 VFD异频泵组合成策略

```python
def synthesize_vfd_heterogeneous_freq(
    pump_curves: Dict[int, Callable],  # 额定频率下的单泵曲线
    pump_frequencies: Dict[int, float],  # 各泵实际频率
    H_target: float  # 目标扬程
) -> Tuple[float, Dict[int, float]]:
    """
    VFD异频泵组合成
    
    步骤：
    1. 根据各泵频率，将额定曲线修正到实际频率
    2. 在修正后的曲线上，按H_target求各泵流量
    3. 流量叠加得到Q_total
    
    Args:
        pump_curves: {pump_id: curve_func}，额定频率曲线
        pump_frequencies: {pump_id: frequency}，各泵实际频率
        H_target: 目标系统扬程
    
    Returns:
        (Q_total, {pump_id: Q_i}): 总流量和各泵流量分配
    """
    Q_total = 0.0
    Q_distribution = {}
    
    for pump_id, curve_func in pump_curves.items():
        f_actual = pump_frequencies.get(pump_id, 50.0)
        f_ratio = f_actual / 50.0
        
        # 将目标扬程转换到额定频率下的等效扬程
        H_equiv = H_target / (f_ratio ** 2)
        
        # 在额定曲线上反查流量
        Q_rated = inverse_curve(curve_func, H_equiv)
        
        # 转换回实际频率下的流量
        Q_actual = Q_rated * f_ratio
        
        Q_distribution[pump_id] = Q_actual
        Q_total += Q_actual
    
    return Q_total, Q_distribution
```

#### 21.3.1 工况覆盖度评估

拟合前应评估各流量区间的数据分布，避免某段数据稀疏导致外推误差：

```python
def evaluate_coverage(
    points: List[GroupOperatingPoint],
    n_bins: int = 10
) -> Dict[str, Any]:
    """
    评估流量范围覆盖度
    
    Returns:
        {
            'q_min': 100.0,
            'q_max': 1500.0,
            'bins': [150, 230, 180, ...],  # 各bin数据点数
            'sparse_bins': [3, 8],          # 数据稀疏的bin索引
            'coverage_score': 0.85,         # 覆盖度评分(0-1)
            'extrapolation_warning': True   # 是否有外推风险
        }
    """
    Q_values = [p.Q_total for p in points]
    q_min, q_max = min(Q_values), max(Q_values)
    
    # 分bin统计
    bin_edges = np.linspace(q_min, q_max, n_bins + 1)
    hist, _ = np.histogram(Q_values, bins=bin_edges)
    
    # 识别稀疏bin（<10%平均值）
    avg_count = len(points) / n_bins
    sparse_bins = [i for i, count in enumerate(hist) if count < avg_count * 0.1]
    
    return {
        'q_min': q_min,
        'q_max': q_max,
        'bins': hist.tolist(),
        'sparse_bins': sparse_bins,
        'coverage_score': 1 - len(sparse_bins) / n_bins,
        'extrapolation_warning': len(sparse_bins) > 2
    }
```

#### 21.3.3 并联损失系数

文档附录提到2-5%并联损失，应在合成算法中体现：

```python
def apply_parallel_loss(
    Q_theoretical: float,
    n_pumps: int,
    loss_coefficient: float = 0.02  # 默认2%每台
) -> float:
    """
    应用并联损失系数
    
    物理原理:
    - 多泵并联时，管路阻力增加导致实际流量低于理论值
    - 损失系数通常为2-5%/台
    
    Args:
        Q_theoretical: 理论流量
        n_pumps: 运行泵数
        loss_coefficient: 每台泵的损失系数
    
    Returns:
        考虑损失后的实际流量
    """
    total_loss = 1 - loss_coefficient * (n_pumps - 1)
    return Q_theoretical * max(total_loss, 0.8)  # 最大损失不超过20%
```
