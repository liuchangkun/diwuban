## 1. MonotonicityConstraint 单调性约束

### 1.1 功能概述

| 属性 | 说明 |
|------|------|
| **文件路径** | `app/services/characteristic_curves/constraints/monotonicity.py` |
| **职责** | 验证曲线的单调性约束 |
| **设计模式** | 策略模式 |
| **依赖** | numpy |

**核心职责**：
1. 验证Q-H曲线单调递减
2. 验证Q-P曲线单调递增
3. 验证Q-η曲线先增后减（单峰）
4. 计算单调性违反程度

### 1.2 曲线单调性规则

| 曲线类型 | 单调性要求 | 物理含义 | 验证方法 |
|---------|-----------|---------|---------|
| **Q-H** | 单调递减 | 流量增加，扬程下降 | `_validate_decreasing()` |
| **Q-P** | 单调递增 | 流量增加，功率增加 | `_validate_increasing()` |
| **Q-η** | 单峰（先增后减） | 存在最高效率点 | `_validate_unimodal()` |

### 1.3 核心接口

```python
from typing import Dict, Any, Optional
import numpy as np
import logging

class MonotonicityConstraint:
    """单调性约束验证器"""

    def __init__(self):
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

    def validate(
        self,
        curve_type: str,
        x_values: np.ndarray,
        y_values: np.ndarray,
        tolerance: float = 0.01
    ) -> Dict[str, Any]:
        """
        验证单调性约束

        Args:
            curve_type: 曲线类型 ('qh', 'qp', 'qeta')
            x_values: X轴值（流量）
            y_values: Y轴值（扬程/功率/效率）
            tolerance: 容差（允许的微小违反，相对于y值范围的比例）

        Returns:
            Dict: {
                'is_valid': bool,           # 是否通过验证
                'violation_ratio': float,   # 违反比例 (0-1)
                'violation_points': List[int],  # 违反点的索引
                'peak_x': float,            # 峰值X坐标（仅qeta）
                'peak_y': float             # 峰值Y坐标（仅qeta）
            }
        """
        if curve_type == 'qh':
            return self._validate_decreasing(x_values, y_values, tolerance)
        elif curve_type == 'qp':
            return self._validate_increasing(x_values, y_values, tolerance)
        elif curve_type == 'qeta':
            return self._validate_unimodal(x_values, y_values, tolerance)
        else:
            raise ValueError(f"不支持的曲线类型: {curve_type}")

    def _validate_decreasing(
        self,
        x_values: np.ndarray,
        y_values: np.ndarray,
        tolerance: float
    ) -> Dict[str, Any]:
        """验证单调递减（Q-H曲线）"""
        diff = np.diff(y_values)
        y_range = np.max(y_values) - np.min(y_values)
        threshold = tolerance * y_range

        # 找出违反点（y值增加超过容差）
        violation_mask = diff > threshold
        violation_points = np.where(violation_mask)[0].tolist()
        violation_ratio = len(violation_points) / len(diff) if len(diff) > 0 else 0

        return {
            'is_valid': len(violation_points) == 0,
            'violation_ratio': violation_ratio,
            'violation_points': violation_points
        }

    def _validate_increasing(
        self,
        x_values: np.ndarray,
        y_values: np.ndarray,
        tolerance: float
    ) -> Dict[str, Any]:
        """验证单调递增（Q-P曲线）"""
        diff = np.diff(y_values)
        y_range = np.max(y_values) - np.min(y_values)
        threshold = tolerance * y_range

        # 找出违反点（y值减少超过容差）
        violation_mask = diff < -threshold
        violation_points = np.where(violation_mask)[0].tolist()
        violation_ratio = len(violation_points) / len(diff) if len(diff) > 0 else 0

        return {
            'is_valid': len(violation_points) == 0,
            'violation_ratio': violation_ratio,
            'violation_points': violation_points
        }

    def _validate_unimodal(
        self,
        x_values: np.ndarray,
        y_values: np.ndarray,
        tolerance: float
    ) -> Dict[str, Any]:
        """验证单峰（Q-η曲线）"""
        # 找到峰值位置
        peak_idx = np.argmax(y_values)
        peak_x = x_values[peak_idx]
        peak_y = y_values[peak_idx]

        # 峰值前应单调递增
        left_result = self._validate_increasing(
            x_values[:peak_idx+1], y_values[:peak_idx+1], tolerance
        )

        # 峰值后应单调递减
        right_result = self._validate_decreasing(
            x_values[peak_idx:], y_values[peak_idx:], tolerance
        )

        # 合并违反点
        violation_points = left_result['violation_points'] + \
            [p + peak_idx for p in right_result['violation_points']]

        return {
            'is_valid': left_result['is_valid'] and right_result['is_valid'],
            'violation_ratio': (left_result['violation_ratio'] + right_result['violation_ratio']) / 2,
            'violation_points': violation_points,
            'peak_x': float(peak_x),
            'peak_y': float(peak_y)
        }
```

### 1.4 使用示例

```python
from app.services.characteristic_curves.constraints import MonotonicityConstraint
import numpy as np

constraint = MonotonicityConstraint()

# 场景1: 验证Q-H曲线单调递减
Q = np.array([0, 100, 200, 300, 400, 500])
H = np.array([50, 48, 44, 38, 30, 20])  # 单调递减

result = constraint.validate(
    curve_type='qh',
    x_values=Q,
    y_values=H,
    tolerance=0.01
)

if result['is_valid']:
    print("Q-H曲线满足单调递减约束")
else:
    print(f"违反比例: {result['violation_ratio']:.2%}")
    print(f"违反点索引: {result['violation_points']}")

# 场景2: 验证Q-η曲线单峰
Q = np.array([0, 100, 200, 300, 400, 500])
eta = np.array([0, 0.6, 0.8, 0.85, 0.7, 0.5])  # 单峰

result = constraint.validate(
    curve_type='qeta',
    x_values=Q,
    y_values=eta,
    tolerance=0.01
)

print(f"单峰验证: {'通过' if result['is_valid'] else '失败'}")
print(f"峰值位置: Q={result['peak_x']}, η={result['peak_y']}")
```

## 2. BoundaryConstraint 边界约束

### 2.1 功能概述

| 属性 | 说明 |
|------|------|
| **文件路径** | `app/services/characteristic_curves/constraints/boundary.py` |
| **职责** | 验证曲线的边界条件约束 |
| **设计模式** | 策略模式 |
| **依赖** | numpy |

**核心职责**：
1. 验证零流量点（Q=0时的H₀、P₀、η₀）
2. 验证最大流量点
3. 验证值域范围
4. 验证物理边界

### 2.2 边界条件定义

| 曲线类型 | 零流量点 | 最大流量点 | 值域范围 |
|---------|---------|-----------|---------|
| **Q-H** | H₀ ≈ 1.1~1.3 × H_rated | H → 0 | H ≥ 0 |
| **Q-P** | P₀ ≈ 0.3~0.5 × P_rated | P_max ≤ 1.2 × P_rated | P > 0 |
| **Q-η** | η₀ = 0 | η → 0 | 0 ≤ η ≤ 1 |

### 2.3 核心接口

```python
from typing import Dict, Any, Optional
import numpy as np
import logging

class BoundaryConstraint:
    """边界约束验证器"""

    def __init__(self):
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

    def validate(
        self,
        curve_type: str,
        fit_params: Dict[str, Any],
        device_params: Dict[str, float],
        tolerance: float = 0.05
    ) -> Dict[str, Any]:
        """
        验证边界约束

        Args:
            curve_type: 曲线类型
            fit_params: 拟合参数（包含coefficients）
            device_params: 设备参数（从device_rated_params表读取）
            tolerance: 容差（相对偏差）

        Returns:
            Dict: {
                'is_valid': bool,
                'boundary_checks': List[Dict],  # 每项检查的详情
                'violations': List[str]         # 违反项描述
            }
        """
        pass

    def get_boundary_conditions(
        self,
        curve_type: str,
        device_params: Dict[str, float]
    ) -> Dict[str, Dict[str, float]]:
        """
        获取边界条件

        Args:
            curve_type: 曲线类型
            device_params: 设备参数

        Returns:
            Dict: 边界条件字典
        """
        if curve_type == 'qh':
            # 从device_params中获取额定参数
            if 'rated_head' not in device_params or 'rated_flow' not in device_params:
                missing = [p for p in ['rated_head', 'rated_flow'] if p not in device_params]
                raise ValueError(f"设备额定参数缺失: {missing}")

            rated_head = device_params['rated_head']
            rated_flow = device_params['rated_flow']

            return {
                'zero_flow': {
                    'name': '零流量扬程',
                    'min': 1.1 * rated_head,
                    'max': 1.3 * rated_head
                },
                'rated_point': {
                    'name': '额定工况点',
                    'Q': rated_flow,
                    'H_min': 0.95 * rated_head,
                    'H_max': 1.05 * rated_head
                },
                'value_range': {
                    'name': '值域范围',
                    'H_min': 0,
                    'H_max': 1.5 * rated_head
                }
            }

        elif curve_type == 'qp':
            rated_power = device_params.get('rated_power')
            if not rated_power:
                raise ValueError("设备额定参数缺失: rated_power")

            return {
                'zero_flow': {
                    'name': '零流量功率',
                    'min': 0.3 * rated_power,
                    'max': 0.5 * rated_power
                },
                'max_power': {
                    'name': '最大功率',
                    'max': 1.2 * rated_power
                },
                'value_range': {
                    'name': '值域范围',
                    'P_min': 0
                }
            }

        elif curve_type == 'qeta':
            return {
                'zero_flow': {
                    'name': '零流量效率',
                    'expected': 0,
                    'tolerance': 0.05
                },
                'value_range': {
                    'name': '值域范围',
                    'eta_min': 0,
                    'eta_max': 1.0
                }
            }

        else:
            raise ValueError(f"不支持的曲线类型: {curve_type}")
```

## 3. PhysicsValidator 物理验证器

### 3.1 功能概述

| 属性 | 说明 |
|------|------|
| **文件路径** | `app/services/characteristic_curves/constraints/physics_validator.py` |
| **职责** | 综合验证拟合结果的物理合理性 |
| **设计模式** | 组合模式 |
| **依赖** | MonotonicityConstraint, BoundaryConstraint |

**核心职责**：
1. 组合多种约束验证
2. 计算综合物理得分
3. 生成验证报告
4. 提供修复建议

### 3.2 核心接口

```python
from typing import Dict, Any, List
import numpy as np
import logging
import time
from app.core.logging.setup import log_activity

class PhysicsValidator:
    """物理验证器（组合多种约束）"""

    def __init__(self):
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")
        self._monotonicity = MonotonicityConstraint()
        self._boundary = BoundaryConstraint()

        self._logger.info(
            "[物理验证] 初始化",
            extra={"extra_data": {
                "组件": "PhysicsValidator",
                "子组件": ["MonotonicityConstraint", "BoundaryConstraint"]
            }}
        )

    def validate(
        self,
        device_id: int,
        curve_type: str,
        fit_result: 'FitResult',
        device_params: Dict[str, float]
    ) -> 'ValidationResult':
        """
        执行完整物理验证

        Args:
            device_id: 设备ID
            curve_type: 曲线类型
            fit_result: 拟合结果
            device_params: 设备参数

        Returns:
            ValidationResult: 验证结果
        """
        start_time = time.time()

        with log_activity("物理验证", params={
            "device_id": device_id, "curve_type": curve_type
        }):
            # 单调性验证
            mono_result = self._monotonicity.validate(
                curve_type=curve_type,
                x_values=fit_result.x_values,
                y_values=fit_result.y_fitted
            )

            # 边界验证
            # v2.4修复P79：使用coefficients而非fit_params（术语统一）
            bound_result = self._boundary.validate(
                curve_type=curve_type,
                fit_params={'coefficients': fit_result.coefficients},  # 包装为字典
                device_params=device_params
            )

            # 综合结果
            overall_passed = mono_result['is_valid'] and bound_result['is_valid']
            physics_score = self.calculate_physics_score(mono_result, bound_result)

            duration = (time.time() - start_time) * 1000

            self._logger.info(
                "[物理验证] 验证完成",
                extra={"extra_data": {
                    "设备ID": device_id,
                    "曲线类型": curve_type,
                    "总体结果": "通过" if overall_passed else "失败",
                    "单调性": "通过" if mono_result['is_valid'] else "失败",
                    "边界": "通过" if bound_result['is_valid'] else "失败",
                    "物理得分": physics_score,
                    "耗时ms": duration
                }}
            )

            return ValidationResult(
                overall_passed=overall_passed,
                monotonicity_passed=mono_result['is_valid'],
                boundary_passed=bound_result['is_valid'],
                physics_score=physics_score,
                monotonicity_details=mono_result,
                boundary_details=bound_result
            )

    def calculate_physics_score(
        self,
        mono_result: Dict[str, Any],
        bound_result: Dict[str, Any]
    ) -> float:
        """
        计算物理得分（0-100）

        评分规则：
        - 单调性权重: 40%
        - 边界条件权重: 60%
        """
        mono_score = 100 * (1 - mono_result.get('violation_ratio', 0))

        # 边界得分：通过的检查项比例
        checks = bound_result.get('boundary_checks', [])
        if checks:
            passed_count = sum(1 for c in checks if c.get('passed', False))
            bound_score = 100 * passed_count / len(checks)
        else:
            bound_score = 100 if bound_result.get('is_valid', True) else 0

        return 0.4 * mono_score + 0.6 * bound_score

    def suggest_fixes(
        self,
        validation_result: 'ValidationResult'
    ) -> List[str]:
        """
        提供修复建议

        Args:
            validation_result: 验证结果

        Returns:
            List[str]: 修复建议列表
        """
        suggestions = []

        if not validation_result.monotonicity_passed:
            suggestions.append("单调性违反：考虑使用带单调性约束的拟合方法")
            suggestions.append("检查数据是否存在异常点或噪声")

        if not validation_result.boundary_passed:
            suggestions.append("边界条件违反：检查设备额定参数是否正确")
            suggestions.append("考虑调整拟合参数或使用物理约束拟合")

        return suggestions
```
