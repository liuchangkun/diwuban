## 1. CurveFittingPipeline 概述

| 属性 | 说明 |
|------|------|
| **文件路径** | `app/services/characteristic_curves/pipeline.py` |
| **职责** | 整个拟合功能的总入口，协调所有模块的执行 |
| **设计模式** | 单例模式 + 依赖注入 |
| **依赖** | 所有共用层模块、所有曲线模块 |
| **数据来源** | `fact_measurements` 表 |

**核心职责**：
1. 作为整个拟合功能的统一入口
2. 管理依赖注入（将共用组件注入到曲线实例）
3. 协调所有模块的执行顺序
4. 处理异常和日志记录
5. 提供统一的错误处理机制

```python
class CurveFittingPipeline:
    """曲线拟合主管道"""

    def __init__(
        self,
        method_registry: 'MethodRegistry',                              # 必需参数
        result_storage: 'ResultStorage',                                # 必需参数
        cache_manager: Optional['CacheManager'] = None,
        batch_processor: Optional['BatchProcessor'] = None,
        parameter_optimizer: Optional['ParameterOptimizer'] = None,
        historical_evaluator: Optional['HistoricalDataEvaluator'] = None,
        time_window_splitter: Optional['TimeWindowSplitter'] = None,
        result_output: Optional['EnhancedResultOutput'] = None
    ) -> None:
        """
        初始化主管道

        Args:
            method_registry: 方法注册器实例（必需）
            result_storage: 结果存储器实例（必需）
            cache_manager: 缓存管理器实例（可选）
            batch_processor: 批处理器实例（可选）
            parameter_optimizer: 参数优化器实例（可选）
            historical_evaluator: 历史数据评估器实例（可选）
            time_window_splitter: 时间窗口划分器实例（可选）
            result_output: 结果输出器实例（可选）

        注意：不需要传入 db_session，各组件内部使用 get_connection()
        """
        pass

    def fit(
        self,
        device_id: int,
        curve_type: str,
        start_time: datetime,
        end_time: datetime,
        methods: Optional[Union[str, List[str]]] = 'all',
        normalize: bool = True,
        optimize: bool = False,
        force_fit: bool = False
    ) -> FitResult:
        """
        执行曲线拟合

        Args:
            device_id: 设备ID
            curve_type: 曲线类型 ('qh', 'qp', 'qeta')
            start_time: 数据开始时间
            end_time: 数据结束时间
            methods: 拟合方法
                - 'all': 尝试所有已注册方法，选择最佳
                - None: 使用默认推荐方法
                - List[str]: 指定方法列表
            normalize: 是否归一化数据
            optimize: 是否优化参数
            force_fit: 是否强制拟合（忽略物理约束警告）

        Returns:
            FitResult: 拟合结果对象

        Raises:
            ValueError: 参数无效
            DataNotFoundError: 数据不存在
            FittingError: 拟合失败
        """
        pass

    def validate(
        self,
        device_id: int,
        curve_type: str,
        version: str,
        test_start_time: datetime,
        test_end_time: datetime
    ) -> ValidationResult:
        """验证拟合结果"""
        pass

    def compare_versions(
        self,
        device_id: int,
        curve_type: str,
        version1: str,
        version2: str
    ) -> Dict[str, Any]:
        """对比两个版本的拟合结果"""
        pass
```

```
└─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
  │ 阶段1   │ →  │ 阶段2   │ →  │ 阶段3   │ →  │ 阶段4   │ →  │ 阶段5   │
  │时间窗口 │    │场景识别 │    │数据提取 │    │数据清洗 │    │稳态检测 │
  │Splitter │    │[条件]   │    │Extractor│    │Cleaner  │    │[条件]   │
  └─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
       │              │              │              │              │
       ▼              ▼              ▼              ▼              ▼
  [fit_window]   [场景类型]     [原始数据]    [清洗后数据]   [稳态数据]
  [test_window]

  ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
  │ 阶段6   │ →  │ 阶段7   │ →  │ 阶段8   │ →  │ 阶段9   │ →  │ 阶段10  │
  │约束计算 │    │频率归一 │    │ 归一化  │    │方法选择 │    │  拟合   │
  │Constraints│  │[条件]   │    │Normalizer│   │Registry │    │ Fitter  │

       │              │              │              │              │
       ▼              ▼              ▼              ▼              ▼
  [约束参数]    [工频数据]    [归一化数据]    [方法列表]    [拟合结果]
               [*_50列]                                    [predict_func]

  ┌─────────┐    ┌─────────┐    ┌─────────┐
  │ 阶段11  │ →  │ 阶段12  │ →  │ 阶段13  │
  │  验证   │    │历史评估 │    │  存储   │
  │Validator│    │[条件]   │    │ Storage │
  └─────────┘    └─────────┘    └─────────┘
       │              │              │
       ▼              ▼              ▼

```

### 3.2 详细流程说明

```
用户调用 pipeline.fit(device_id, curve_type)
    ↓
[阶段1] 时间窗口划分（TimeWindowSplitter）
    │   - 查询 fact_measurements 表获取数据时间范围
    │   - 按 75%/25% 比例划分拟合窗口和测试窗口
    │   - 返回 fit_window + test_window
    ↓
[阶段2] 场景识别（ScenarioDetector）[条件执行]
    │   - 识别泵类型场景（软启/变频/类工频）
    │   - 根据场景调整后续处理策略
    ↓
[阶段3] 数据提取（DataExtractor）
    │   - 从 fact_measurements 表提取 fit_window 内的拟合数据
    │   - 应用批处理（如果数据量>25,000点）
    ↓
[阶段4] 数据清洗（DataCleaner）
    │   - 删除无效值、重复值
    │   - 异常值检测和处理
    ↓
[阶段5] 稳态检测（SteadyStateDetector）[条件执行]
    │   - 识别稳态工况点
    │   - 过滤瞬态数据
    ↓
[阶段6] 约束计算（Constraints）
    │   - 从 device_rated_params 表读取额定参数
    │   - 计算物理约束参数（H₀、K、Q_max等）
    │   - 验证单调性和凸性约束
    ↓
[阶段7] 频率归一化（FrequencyNormalizer）[条件执行]
    │   - 仅变频泵且freq_std > 2.0时执行
    │   - 将变频数据归一化到工频（50Hz）
    │   - 应用相似定律
    ↓
[阶段8] 数据归一化（Normalizer）
    │   - 使用额定参数进行归一化（Q/Q_rated, H/H_rated等）
    │   - 记录归一化参数用于反归一化
    ↓
[阶段9] 方法选择（MethodRegistry）
    │   - 如果methods='all'：遍历所有方法
    │   - 如果methods=None：使用曲线默认推荐方法
    │   - 如果methods=List：使用指定方法列表
    │   - 检查方法依赖是否满足
    ↓
[阶段10] 执行拟合（BaseMethod.fit()）
    │   - 调用曲线模块的CurveFitter
    │   - 应用物理约束
    │   - 参数优化（如果optimize=True）
    │   - 计算评估指标（R², RMSE, MAE, MAPE）
    │   - 选择最佳结果，返回 predict_func
    ↓
[阶段11] 结果验证（Validator）
    │   - 单调性验证（PhysicsValidator）
    │   - 边界条件验证
    │   - 物理一致性验证
    │   - 如果验证失败且force_fit=False，抛出异常
    ↓
[阶段12] 历史评估（HistoricalDataEvaluator）[条件执行]
    │   - 仅当 time_split.can_evaluate=True 时执行
    │   - 使用 test_window 数据评估 predict_func
    │   - 生成预测评估报告
    ↓
[阶段13] 结果保存（ResultStorage）
    │   - 生成版本号（时间戳格式）
    │   - 保存到数据库（三表分离：curve_fit_results + curve_fit_params + curve_fit_metrics）
    │   - 更新缓存（CacheManager）
    │   - 返回FitResult
    ↓
返回结果
```

## 4. 阶段详细说明

| 阶段 | 名称 | 模块 | 输入 | 输出 | 执行类型 |
|:----:|------|------|------|------|:--------:|
| **阶段1** | 时间窗口划分 | TimeWindowSplitter | device_id, curve_type | fit_window, test_window | 必须 |
| **阶段2** | 场景识别 | ScenarioDetector | device_id, time_range | scenario_type | **条件** |
| **阶段3** | 数据提取 | DataExtractor | device_id, fit_window | 原始数据 | 必须 |
| **阶段4** | 数据清洗 | DataCleaner | 原始数据 | 清洗后数据 | 必须 |
| **阶段5** | 稳态检测 | SteadyStateDetector | 清洗后数据 | 稳态数据 | **条件** |
| **阶段6** | 约束计算 | Constraints | 稳态数据, 额定参数 | 约束参数 | 必须 |
| **阶段7** | 频率归一化 | FrequencyNormalizer | 稳态数据 | 工频数据 | **条件** |
| **阶段8** | 数据归一化 | Normalizer | 工频数据, 额定参数 | 归一化数据 | 必须 |
| **阶段9** | 方法选择 | MethodRegistry | 数据质量, 历史评估 | 方法列表 | 必须 |
| **阶段10** | 拟合 | BaseMethod.fit() | 归一化数据, 约束参数 | 拟合结果, predict_func | 必须 |
| **阶段11** | 验证 | Validator | 拟合结果, 约束参数 | 验证结果 | 必须 |
| **阶段12** | 历史评估 | HistoricalDataEvaluator | predict_func, test_window | 预测评估报告 | **条件** |
| **阶段13** | 存储 | ResultStorage | 拟合结果, 评估报告 | 持久化 | 必须 |

## 5. 使用示例

```python
from datetime import datetime
from app.services.characteristic_curves import CurveFittingPipeline
from app.services.characteristic_curves.methods import MethodRegistry
from app.services.characteristic_curves.shared import (
    ResultStorage, CacheManager, BatchProcessor,
    ParameterOptimizer, HistoricalDataEvaluator,
    TimeWindowSplitter, EnhancedResultOutput
)

# ==================== 场景1: 基础拟合 ====================
# 初始化共用组件（组件内部使用get_connection()）
registry = MethodRegistry()  # 方法注册器（必需）
storage = ResultStorage()    # 结果存储（必需）

# 可选组件
cache = CacheManager(max_size=1000, ttl_seconds=3600)
batch_processor = BatchProcessor(max_workers=4, batch_size=5000)
optimizer = ParameterOptimizer(n_folds=5)
evaluator = HistoricalDataEvaluator()
time_splitter = TimeWindowSplitter()
output = EnhancedResultOutput()

# 创建主管道（method_registry 和 result_storage 为必需参数）
pipeline = CurveFittingPipeline(
    method_registry=registry,           # 必需
    result_storage=storage,             # 必需
    cache_manager=cache,                # 可选
    batch_processor=batch_processor,    # 可选
    parameter_optimizer=optimizer,      # 可选
    historical_evaluator=evaluator,     # 可选
    time_window_splitter=time_splitter, # 可选
    result_output=output                # 可选
)

# 执行Q-H曲线拟合（使用所有方法，选择最佳）
result = pipeline.fit(
    device_id=1,
    curve_type='qh',
    start_time=datetime(2025, 1, 1),
    end_time=datetime(2025, 1, 31),
    methods='all',      # 尝试所有方法
    normalize=True,     # 启用归一化
    optimize=False,     # 不优化参数
    force_fit=False     # 不强制拟合
)

print(f"拟合完成: R²={result.r_squared:.4f}, 方法={result.method_name}")

# ==================== 场景2: 指定方法拟合 ====================
result = pipeline.fit(
    device_id=1,
    curve_type='qh',
    start_time=datetime(2025, 1, 1),
    end_time=datetime(2025, 1, 31),
    methods=['math_poly_2', 'math_poly_3', 'physics_pump_char'],
    normalize=True,
    optimize=True,      # 启用参数优化
    force_fit=False
)

# ==================== 场景3: 使用默认推荐方法 ====================
result = pipeline.fit(
    device_id=1,
    curve_type='qeta',  # Q-η曲线
    start_time=datetime(2025, 1, 1),
    end_time=datetime(2025, 1, 31),
    methods=None,       # 使用曲线默认推荐方法（math_stat_gaussian）
    normalize=True,
    optimize=False,
    force_fit=False
)

# ==================== 场景4: 强制拟合（忽略约束警告） ====================
result = pipeline.fit(
    device_id=1,
    curve_type='qh',
    start_time=datetime(2025, 1, 1),
    end_time=datetime(2025, 1, 31),
    methods=['math_poly_2'],
    normalize=True,
    optimize=False,
    force_fit=True      # 即使约束验证失败也继续保存
)

# ==================== 场景5: 验证拟合结果 ====================
validation = pipeline.validate(
    device_id=1,
    curve_type='qh',
    version='20250127_143052',
    test_start_time=datetime(2025, 2, 1),
    test_end_time=datetime(2025, 2, 7)
)

print(f"验证结果: 通过={validation.overall_passed}")
print(f"单调性: {validation.monotonicity_passed}")
print(f"边界条件: {validation.boundary_passed}")

# ==================== 场景6: 版本对比 ====================
comparison = pipeline.compare_versions(
    device_id=1,
    curve_type='qh',
    version1='20250101_100000',
    version2='20250127_143052'
)

print(f"R²变化: {comparison['r_squared_diff']:.4f}")
print(f"RMSE变化: {comparison['rmse_diff']:.4f}")
```

### 8.2 流程日志示例

```python
def fit(self, device_id: int, curve_type: str, start_time, end_time,
        methods='all', normalize=True, optimize=False, force_fit=False):
    """执行拟合流程"""

    pipeline_start = time.time()
    trace_id = f"pipeline-{device_id}-{curve_type}-{int(time.time()*1000)}"
    set_context(trace_id=trace_id, device_id=device_id, curve_type=curve_type)

    with log_activity("拟合流程", params={
        "device_id": device_id, "curve_type": curve_type, "methods": str(methods)
    }):
        # ==================== 流程开始日志 ====================
        self._logger.info(
            "[管道] 流程开始",
            extra={"extra_data": {
                "设备ID": device_id,
                "曲线类型": curve_type,
                "追踪ID": trace_id,
                "时间范围": {
                    "开始": start_time.isoformat(),
                    "结束": end_time.isoformat()
                },
                "配置": {
                    "拟合方法": str(methods),
                    "归一化": normalize,
                    "参数优化": optimize,
                    "强制拟合": force_fit
                }
            }}
        )

        try:
            # ==================== 缓存检查日志 ====================
            if not force_fit:
                cache_key = f"{device_id}:{curve_type}:{methods or 'auto'}"
                cached_result = self._cache.get(cache_key)

                if cached_result:
                    self._logger.info(
                        "[管道] 缓存命中，返回缓存结果",
                        extra={"extra_data": {
                            "设备ID": device_id,
                            "曲线类型": curve_type,
                            "缓存键": cache_key
                        }}
                    )
                    return cached_result

            # ==================== 数据加载日志 ====================
            load_start = time.time()
            curve = self._get_curve_instance(curve_type)
            raw_data = curve.data_extractor.extract(device_id, start_time, end_time)
            load_duration = (time.time() - load_start) * 1000

            self._logger.info(
                "[管道] 阶段3-数据加载完成",
                extra={"extra_data": {
                    "设备ID": device_id,
                    "加载耗时ms": load_duration,
                    "加载结果": {
                        "行数": len(raw_data),
                        "列数": len(raw_data.columns)
                    }
                }}
            )

            # ... 后续阶段类似日志模式 ...

            # ==================== 流程完成汇总 ====================
            total_duration = (time.time() - pipeline_start) * 1000

            self._logger.info(
                "[管道] 流程完成",
                extra={"extra_data": {
                    "设备ID": device_id,
                    "曲线类型": curve_type,
                    "拟合方法ID": result.method_id,
                    "执行结果": "成功",
                    "总耗时ms": total_duration,
                    "最终结果": {
                        "R²": result.r_squared,
                        "RMSE": result.rmse,
                        "版本": result.version
                    }
                }}
            )

            # 业务日志
            log_biz(
                action="拟合流程",
                status="成功",
                detail={
                    "设备ID": device_id,
                    "曲线类型": curve_type,
                    "方法": result.method_name,
                    "R²": result.r_squared,
                    "耗时ms": total_duration
                }
            )

            return result

        except Exception as e:
            total_duration = (time.time() - pipeline_start) * 1000
            self._logger.error(
                "[管道] 流程失败",
                extra={"extra_data": {
                    "设备ID": device_id,
                    "曲线类型": curve_type,
                    "执行结果": "失败",
                    "总耗时ms": total_duration,
                    "错误类型": type(e).__name__,
                    "错误信息": str(e)
                }},
                exc_info=True
            )
            raise
        finally:
            clear_context()
```

## 9. 私有方法

### 9.1 _get_curve_instance

```python
def _get_curve_instance(self, curve_type: str) -> 'BaseCurve':
    """
    获取曲线实例

    Args:
        curve_type: 曲线类型 ('qh', 'qp', 'qeta' 等)

    Returns:
        BaseCurve: 对应的曲线实例

    Raises:
        ValueError: 未知的曲线类型
    """
    from app.services.characteristic_curves.curves import (
        QHCurve, QPCurve, QEtaCurve
    )

    curve_map = {
        'qh': QHCurve,
        'qp': QPCurve,
        'qeta': QEtaCurve,
    }

    if curve_type not in curve_map:
        raise ValueError(f"未知的曲线类型: {curve_type}")

    return curve_map[curve_type]()
```

## 10. 关键设计决策

| 决策项 | 选择 | 理由 |
|-------|------|------|
| **依赖注入 vs 硬编码** | 依赖注入 | 便于单元测试（Mock注入）、解耦、可替换实现 |
| **单例模式** | 是 | 避免重复创建共用组件，节省资源 |
| **methods参数设计** | 'all'/None/List | 灵活性：自动选择/默认推荐/精确控制 |
| **force_fit参数** | 支持 | 允许在约束不满足时继续保存（带警告） |
| **缓存策略** | 先查缓存 | 提高重复请求响应速度 |
| **数据库访问** | get_connection() | 统一使用上下文管理器，不传入db_pool |
