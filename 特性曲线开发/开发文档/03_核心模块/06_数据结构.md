## 1. FitResult 拟合结果

### 1.1 类定义

```python
from dataclasses import dataclass, field
from typing import Dict, Any, Optional, List, Tuple
from datetime import datetime
import numpy as np

@dataclass
class FitResult:
    """拟合结果数据类

    🔴 术语统一：使用 coefficients 而非 fit_params/params

    v2.4更新（P43修复）：添加device_id、curve_type、fitted_at、valid_q_range、valid_h_range字段
    与07_泵组处理层.md中_get_pump_fit_result()返回值对齐
    """

    # 基本信息【v2.4增强】
    device_id: Optional[int] = None         # 设备ID【v2.4新增 P43修复】
    curve_type: Optional[str] = None        # 曲线类型【v2.4新增 P43修复】
    method_id: str = ""                     # 方法ID
    method_name: str = ""                   # 方法名称
    version: str = ""                       # 版本号（YYYYMMDD_HHMMSS）

    # 拟合系数
    coefficients: Dict[str, Any] = field(default_factory=dict)  # 🔴 拟合系数（术语统一）

    # 评估指标
    r_squared: float = 0.0                  # R²
    rmse: float = 0.0                       # 均方根误差
    mae: float = 0.0                        # 平均绝对误差
    mape: float = 0.0                       # 平均绝对百分比误差

    # 数据信息
    data_points: int = 0                    # 数据点数
    time_range: Dict[str, str] = field(default_factory=dict)  # 时间范围

    # 有效范围【v2.4新增 P43修复】
    valid_q_range: Tuple[float, float] = (0, 5000)  # 有效流量范围 (m³/h)
    valid_h_range: Tuple[float, float] = (0, 100)   # 有效扬程范围 (m)

    # 归一化参数
    normalization_params: Dict[str, Dict[str, float]] = field(default_factory=dict)

    # 元数据
    created_at: datetime = field(default_factory=datetime.now)
    fitted_at: Optional[datetime] = None    # 拟合完成时间【v2.4新增 P43修复】
    metadata: Dict[str, Any] = field(default_factory=dict)

    # 可选：原始数据和拟合值（用于可视化）
    x_values: Optional[np.ndarray] = None   # X轴值
    y_actual: Optional[np.ndarray] = None   # 实际Y值
    y_fitted: Optional[np.ndarray] = None   # 拟合Y值

    def to_dict(self) -> Dict[str, Any]:
        """转换为字典"""
        return {
            'method_id': self.method_id,
            'method_name': self.method_name,
            'version': self.version,
            'coefficients': self.coefficients,  # 🔴 术语统一
            'r_squared': self.r_squared,
            'rmse': self.rmse,
            'mae': self.mae,
            'mape': self.mape,
            'data_points': self.data_points,
            'time_range': self.time_range,
            'normalization_params': self.normalization_params,
            'created_at': self.created_at.isoformat(),
            'metadata': self.metadata
        }

    @classmethod
    def from_dict(cls, data: Dict[str, Any]) -> 'FitResult':
        """从字典创建"""
        data = data.copy()
        if isinstance(data.get('created_at'), str):
            data['created_at'] = datetime.fromisoformat(data['created_at'])
        return cls(**data)
```

### 1.2 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `method_id` | str | 方法唯一标识 | `"poly_2"` |
| `method_name` | str | 方法显示名称 | `"二次多项式"` |
| `version` | str | 版本号 | `"20251203_143052"` |
| `coefficients` | Dict | 拟合系数 | `{"a": 0.001, "b": -0.5, "c": 50}` |
| `r_squared` | float | 决定系数 | `0.9876` |
| `rmse` | float | 均方根误差 | `0.234` |
| `data_points` | int | 数据点数 | `1500` |
| `normalization_params` | Dict | 归一化参数 | `{"flow": {"min": 0, "max": 500}}` |

## 3. MethodResult 方法结果

> **⚠️ 权威定义**：本数据类与 `03_核心模块/02_方法层.md` 中的定义保持一致。
>
> **与 FitResult 的关系**：
> - `MethodResult`：单个拟合方法的直接输出（由 `BaseMethod.fit()` 返回）
> - `FitResult`：完整拟合流程的最终输出（包含版本、时间范围等附加信息，由 Pipeline 生成）

```python
from dataclasses import dataclass, field
from typing import Dict, Any, Optional, Callable
import numpy as np

@dataclass
class MethodResult:
    """单个拟合方法的结果

    🔴 术语统一：使用 coefficients 而非 fit_params/params
    """

    # 基本信息
    method_id: str                                              # 方法ID（必需）

    # 拟合系数
    coefficients: Dict[str, float] = field(default_factory=dict)  # 🔴 术语统一

    # 评估指标
    r_squared: float = 0.0                  # R²
    rmse: float = 0.0                       # 均方根误差
    mae: float = 0.0                        # 平均绝对误差
    mape: float = 0.0                       # 平均绝对百分比误差

    # 预测函数（核心）
    predict_func: Optional[Callable[[np.ndarray], np.ndarray]] = None  # 预测函数闭包

    # 公式表达式
    formula: str = ""                       # 数学公式字符串

    # 元数据
    metadata: Dict[str, Any] = field(default_factory=dict)

    def to_dict(self) -> Dict[str, Any]:
        """转换为字典"""
        return {
            'method_id': self.method_id,
            'coefficients': self.coefficients,  # 🔴 术语统一
            'r_squared': self.r_squared,
            'rmse': self.rmse,
            'mae': self.mae,
            'mape': self.mape,
            'formula': self.formula,
            'metadata': self.metadata
            # 注意：predict_func 不可序列化，不包含在字典中
        }

    @classmethod
    def from_dict(cls, data: Dict[str, Any]) -> 'MethodResult':
        """从字典创建（不含 predict_func）"""
        return cls(
            method_id=data.get('method_id', ''),
            coefficients=data.get('coefficients', {}),
            r_squared=data.get('r_squared', 0.0),
            rmse=data.get('rmse', 0.0),
            mae=data.get('mae', 0.0),
            mape=data.get('mape', 0.0),
            formula=data.get('formula', ''),
            metadata=data.get('metadata', {}),
            predict_func=None  # 需要重建
        )
```

## 6. ScenarioDetectionResult 场景识别结果

```python
from dataclasses import dataclass
from typing import Dict, Optional, List
from enum import Enum

class FittingScenario(Enum):
    """拟合场景枚举【v2.5修复P80：补齐5种泵组场景】

    ⚠️ 注意：此枚举用于场景检测阶段，枚举值带 _group 后缀。
    与 GroupProcessingStrategy（用于处理阶段，枚举值不带后缀）不同。
    """
    # P0阶段支持的场景（单泵）
    SOFT_START_SINGLE = "soft_start_single"
    VFD_SINGLE = "vfd_single"
    QUASI_FIXED_FREQ_SINGLE = "quasi_fixed_freq_single"

    # P2阶段支持的场景（泵组）- 与GroupProcessingStrategy一一对应
    HOMOGENEOUS_GROUP = "homogeneous_group"              # 同构泵组（功率差异<10%，频率差异<2%）
    HETEROGENEOUS_GROUP = "heterogeneous_group"          # 异构泵组（功率差异≥10%）
    VFD_HETEROGENEOUS_FREQ = "vfd_hetero_freq_group"     # VFD频率异构（全VFD，频率差异≥2%）【v2.5新增】
    MIXED_GROUP = "mixed_group"                          # 混合泵组（VFD+SS，功率差异<10%）
    MIXED_HETEROGENEOUS = "mixed_heterogeneous_group"    # 混合异构泵组（VFD+SS，功率差异≥10%）【v2.5新增】

    # 特殊场景
    UNKNOWN = "unknown"
    NOT_SUPPORTED = "not_supported"

    @staticmethod
    def to_processing_strategy(scenario: 'FittingScenario') -> 'GroupProcessingStrategy':
        """将场景枚举转换为处理策略枚举【v2.5新增P80】"""
        mapping = {
            FittingScenario.HOMOGENEOUS_GROUP: GroupProcessingStrategy.HOMOGENEOUS_GROUP,
            FittingScenario.HETEROGENEOUS_GROUP: GroupProcessingStrategy.HETEROGENEOUS_GROUP,
            FittingScenario.VFD_HETEROGENEOUS_FREQ: GroupProcessingStrategy.VFD_HETEROGENEOUS_FREQ,
            FittingScenario.MIXED_GROUP: GroupProcessingStrategy.MIXED_GROUP,
            FittingScenario.MIXED_HETEROGENEOUS: GroupProcessingStrategy.MIXED_HETEROGENEOUS,
        }
        return mapping.get(scenario)


@dataclass
class ScenarioDetectionResult:
    """场景识别结果"""

    # 识别结果
    scenario: FittingScenario           # 场景类型
    supported: bool                      # 当前版本是否支持

    # 设备信息
    device_id: Optional[int] = None     # 单泵时的设备ID
    station_id: Optional[int] = None    # 泵组时的泵站ID
    device_ids: Optional[List[int]] = None  # 泵组时的设备ID列表

    # 泵类型信息
    pump_type: Optional[str] = None     # 泵类型
    pump_types: Optional[Dict[str, int]] = None  # 泵组时各类型数量

    # 频率统计
    freq_std: Optional[float] = None    # 频率标准差
    freq_range: Optional[tuple] = None  # 频率范围 (min, max)

    # 额定参数差异（泵组）
    power_variation: Optional[float] = None  # 功率变异系数

    # 处理建议
    need_normalization: bool = False    # 是否需要频率归一化
    normalization_strategy: Optional[str] = None  # 归一化策略

    # 不支持时的原因
    not_supported_reason: Optional[str] = None
```

### 6.1 场景识别矩阵

| 场景 | 识别条件 | 处理策略 | P0支持 |
|------|---------|---------|:------:|
| **软启泵单泵** | `pump_type='soft_start'` | 直接拟合 | ✅ |
| **变频泵单泵** | `pump_type='variable_frequency'` 且 `freq_std>2` | 相似定律归一化 | ✅ |
| **类工频变频泵** | `pump_type='variable_frequency'` 且 `freq_std<2` | 直接拟合 | ✅ |
| **同构泵组** | 功率差异<10% | 基准泵曲线×N | ❌ P2 |
| **异构泵组** | 功率差异≥10% | 分别拟合后合成 | ❌ P2 |
| **混合泵组** | 变频泵+软启泵混合 | 分类型处理 | ❌ P2 |

```python
from dataclasses import dataclass
from typing import Dict, Optional


@dataclass
class SynthesisResult:
    """并联合成结果【v2.4更新：标记为权威定义】

    存储在给定系统扬程下，各泵的流量分配和总流量计算结果。

    ⚠️ 本定义为权威版本，07_泵组处理层.md中的实现应引用此定义。

    v2.4更新（P39/P46修复）：
    - 标记为权威定义
    - eta_total单位统一为小数(0-1)而非百分比
    - 移除复杂业务逻辑方法（如_auto_get_rated_powers），保持dataclass简洁
    """

    # 合成结果
    Q_total: float                      # 总流量 (m³/h)
    H_system: float                     # 系统扬程 (m)

    # 各泵分配
    pump_flows: Dict[int, float]        # 各泵流量 {pump_id: Q_i}
    pump_heads: Dict[int, float]        # 各泵扬程 {pump_id: H_i}（并联时应相同）

    # 可选：功率和效率
    pump_powers: Optional[Dict[int, float]] = None  # 各泵功率 {pump_id: P_i}
    P_total: float = 0.0                # 总功率 (kW)
    eta_total: float = 0.0              # 总效率 (0-1)【v2.4修复P46：小数而非百分比】

    # v2.2新增：额定功率字典，用于负荷分配计算
    # 由ParallelSynthesizer在合成时设置
    _rated_powers: Optional[Dict[int, float]] = None

    def get_flow_distribution(self) -> Dict[int, float]:
        """获取流量分配比例"""
        if self.Q_total <= 0:
            return {pid: 0.0 for pid in self.pump_flows}
        return {pid: Q / self.Q_total for pid, Q in self.pump_flows.items()}

    def get_load_distribution(
        self,
        rated_powers: Optional[Dict[int, float]] = None
    ) -> Dict[int, float]:
        """
        获取负荷分配比例【v2.4简化：移除复杂自动获取逻辑】

        Args:
            rated_powers: 额定功率字典 {pump_id: rated_power_kW}
                - 如果不提供，使用内部存储的_rated_powers
                - 如果都没有，返回空字典

        Returns:
            负荷分配比例 {pump_id: load_ratio}
            load_ratio = 实际功率 / 额定功率

        Note:
            负荷率超过1.0表示过载，低于0.3可能表示运行不经济

            ⚠️ v2.4修复P40：移除了_auto_get_rated_powers()调用。
            如需自动获取额定功率，应在调用方（ParallelSynthesizer）中处理，
            并通过_rated_powers字段传入。
        """
        # 优先使用传入的rated_powers
        powers = rated_powers or self._rated_powers

        if not powers or self.pump_powers is None:
            return {}

        return {
            pump_id: (self.pump_powers.get(pump_id, 0) / powers.get(pump_id, 1))
            for pump_id in self.pump_powers.keys()
            if powers.get(pump_id, 0) > 0
        }

    def get_power_distribution(self) -> Dict[int, float]:
        """
        获取功率分配比例【v2.3新增，修复P32】

        Returns:
            功率分配比例 {pump_id: power_ratio}
            power_ratio = 单泵功率 / 总功率

        Note:
            与get_flow_distribution()类似，但基于功率计算
            用于分析各泵的能耗贡献
        """
        if self.P_total <= 0 or self.pump_powers is None:
            return {pid: 0.0 for pid in (self.pump_powers or {})}
        return {pid: P / self.P_total for pid, P in self.pump_powers.items()}
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `Q_total` | float | 泵组总流量 (m³/h) |
| `H_system` | float | 系统扬程，并联泵扬程相同 (m) |
| `pump_flows` | Dict[int, float] | 各泵流量分配 |
| `pump_heads` | Dict[int, float] | 各泵扬程（验证用，应相同） |
| `pump_powers` | Dict[int, float] | 各泵功率（可选） |
| `P_total` | float | 泵组总功率 (kW) |
| `eta_total` | float | 泵组综合效率 (0-1)【v2.4修复：小数而非百分比】 |
| `_rated_powers` | Dict[int, float] | 额定功率字典，用于负荷分配计算【v2.2新增】 |

**方法说明**：

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `get_flow_distribution()` | Dict[int, float] | 获取流量分配比例（各泵流量/总流量） |
| `get_load_distribution()` | Dict[int, float] | 获取负荷分配比例（实际功率/额定功率）【v2.2新增】 |
| `get_power_distribution()` | Dict[int, float] | 获取功率分配比例（各泵功率/总功率）【v2.3新增】 |

## 9. CorrectionModelConfig（修正模型配置）【P2阶段】

> **来源**：`第一次开发/02_核心模块详细设计.md` 8.9节
> **用途**：配置系统修正系数模型参数

```python
from dataclasses import dataclass, field
from typing import Literal


@dataclass
class CorrectionModelConfig:
    """系统修正系数模型配置

    用于配置 SystemCorrectionModel 的训练和预测参数。
    修正公式：H_actual = H_theoretical × α(N, Q_total)
    """

    # 模型类型
    model_type: Literal['linear', 'polynomial', 'xgboost'] = 'polynomial'

    # 多项式模型参数
    polynomial_degree: int = 2                    # 多项式阶数
    regularization_alpha: float = 1.0             # 正则化系数

    # 训练参数
    min_training_points: int = 100                # 最小训练数据点数
    validation_ratio: float = 0.2                 # 验证集比例

    # XGBoost参数（仅model_type='xgboost'时使用）
    xgb_n_estimators: int = 100                   # 树数量
    xgb_max_depth: int = 6                        # 最大深度
    xgb_learning_rate: float = 0.1                # 学习率

    # 有效范围约束
    valid_n_range: tuple = (1, 10)                # 有效台数范围
    valid_q_range: tuple = (0, 10000)             # 有效流量范围 (m³/h)

    # 输出配置
    save_model: bool = True                       # 是否保存模型
    model_save_path: str = './models/correction'  # 模型保存路径
```

**配置示例**：

```python
# 线性模型配置（简单场景）
linear_config = CorrectionModelConfig(
    model_type='linear',
    min_training_points=50,
    validation_ratio=0.2
)

# 多项式模型配置（推荐，平衡精度和泛化）
poly_config = CorrectionModelConfig(
    model_type='polynomial',
    polynomial_degree=2,
    regularization_alpha=1.0,
    min_training_points=100
)

# XGBoost模型配置（高精度场景）
xgb_config = CorrectionModelConfig(
    model_type='xgboost',
    xgb_n_estimators=200,
    xgb_max_depth=8,
    xgb_learning_rate=0.05,
    min_training_points=500
)
```
