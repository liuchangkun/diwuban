## 1. 概述

### 1.1 P2阶段目标

P2阶段（泵组曲线）的核心目标是将多台单泵曲线合成为泵组曲线，支持：
- **同构泵组**：相同型号泵并联
- **异构泵组**：不同型号泵并联
- **混合泵组**：变频泵+软启泵混合并联

### 1.2 C+D综合策略

```
C+D策略 = 单泵曲线合成(C) + 系统修正系数(D)

其中：
- C: 基于单泵曲线的理论合成（ParallelSynthesizer）
- D: 基于运行数据学习的修正系数（SystemCorrectionModel）

最终曲线：H_actual = H_theoretical × α(N, Q_total)
```

#### 1.2.1 双轨策略说明（v3.16新增）

```
泵组曲线获取支持两种方法：

┌────────────────────────────────────────────────────────────┐
│               泵组曲线双轨策略                            │
├─────────────────────────────┬──────────────────────────────┤
│   方法A：合成+修正              │   方法B：直接拟合             │
│   （本文档定义）                │   （详见08_泵组直接拟合.md）   │
├─────────────────────────────┼──────────────────────────────┤
│ - 单泵曲线 → 并联合成       │ - 泵组运行数据 → 直接拟合    │
│ - 理论曲线 → 修正模型       │ - 按泵组合分组拟合          │
│ - 得到修正后曲线             │ - 得到实测曲线                │
├─────────────────────────────┼──────────────────────────────┤
│ 优点：可预测任意组合         │ 优点：真实反映系统特性      │
│ 缺点：依赖单泵拟合精度       │ 缺点：需足够历史数据          │
└─────────────────────────────┴──────────────────────────────┘

执行策略：
- 每次拟合同时执行两种方法
- 自动对比分析并推荐最优方法
- 详见 DualMethodExecutor（08_泵组直接拟合.md）
```

> **注意**：本文档专注于“合成+修正”方法的实现。
> “直接拟合”方法的完整设计请参考 [08_泵组直接拟合.md](./08_泵组直接拟合.md)。

### 1.3 精度目标（v2.5更新）

| 泵组类型 | 适用泵类型 | 识别条件 | 处理策略 | R² 目标 | 修正模型 |
|---------|-----------|---------|---------|:-------:|:--------:|
| `HOMOGENEOUS_GROUP` | 纯VFD | 功率差异<10% 且 **频率差异<2%** | 基准泵曲线 × N + 修正 | > 0.96 | polynomial |
| `HETEROGENEOUS_GROUP` | 纯VFD | 功率差异 **≥** 10% | 各泵独立曲线 + 合成 + 修正 | > 0.94 | polynomial |
| `VFD_HETEROGENEOUS_FREQ` | 纯VFD | **频率差异 ≥ 2%** | 各泵反归一化 + 流量叠加 + 修正 | > 0.96 | polynomial |
| `MIXED_GROUP` | VFD+SS | 功率差异<10% | 分类处理 + 分类合成 + 修正 | > 0.92 | **XGBoost** |
| `MIXED_HETEROGENEOUS` | VFD+SS | 功率差异 **≥** 10% | 分类处理 + 加权合成 + 修正 | > 0.90 | **XGBoost** |

> **v2.0修复问题#4**: 新增`MIXED_HETEROGENEOUS`子类型，降低精度目标
> **v2.0修复问题#7**: 混合泵组默认使用XGBoost提升精度
> **v2.3新增**: `VFD_HETEROGENEOUS_FREQ`处理全VFD但频率不同的泵组
> **v2.4说明**: ⚠️ **纯SS泵组不支持**（软启泵必须与变频泵混合使用才能调节流量）
> **v2.5说明**: ⚠️ **边界值判断规则**：功率差异和频率差异的阈值判断均使用 **≥**（大于等于），即边界值归入较复杂场景

class PumpGroupProcessor:
    """
    泵组处理器
    
    职责：
    1. 识别泵组类型（同构/异构/混合）
    2. 根据策略选择处理方法
    3. 调用 ParallelSynthesizer 合成曲线
    4. 调用 SystemCorrectionModel 学习修正系数
    """
    
    def __init__(
        self,
        parallel_synthesizer: 'ParallelSynthesizer',
        correction_model: 'SystemCorrectionModel',
        power_diff_threshold: float = 0.1
    ):
        """
        初始化泵组处理器
        
        Args:
            parallel_synthesizer: 并联合成器实例
            correction_model: 系统修正模型实例
            power_diff_threshold: 功率差异阈值（默认10%）
        """
        self._synthesizer = parallel_synthesizer
        self._correction = correction_model
        self._power_diff_threshold = power_diff_threshold
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")
    
    def identify_group_type(
        self,
        pump_infos: List[Dict[str, Any]]
    ) -> GroupProcessingStrategy:
        """
        识别泵组类型（v2.3更新: 新增VFD频率差异检查，v3.5修复P2: 边界值处理）

        Args:
            pump_infos: 泵信息列表，每个包含 {'pump_id', 'rated_power', 'control_type'}

        Returns:
            GroupProcessingStrategy: 泵组类型

        Note:
            ✅ v2.0修复问题#4: 新增MIXED_HETEROGENEOUS子类型
            ✅ v2.3新增: 全VFD泵组检查频率差异
            ✅ v2.4说明: 纯SS泵组不存在（软启泵必须与变频泵混合使用）
            ✅ v3.5修复P2: 边界值处理说明

            决策树:
            1. 检查控制类型 → 纯SS时抛异常（不支持）
            2. 混合(VFD+SS)时进入混合分支
            3. 混合分支内检查功率差异 → 差异≥10%返回MIXED_HETEROGENEOUS
            4. 纯VFD时，先检查频率差异 → 差异≥2%返回VFD_HETEROGENEOUS_FREQ
            5. 纯VFD功率差异≥10%返回HETEROGENEOUS_GROUP
            6. 纯VFD功率差异<10%返回HOMOGENEOUS_GROUP

            **业务约束**：
            - 软启泵(SS)只能与变频泵(VFD)混合使用
            - 纯SS泵组无法进行流量调节，不在本系统支持范围内

            **边界值处理（v3.5修复P2）**：
            - 功率差异阈值10%：使用 >= 判断，即10%恰好属于异构
            - 频率差异阈值2%：使用 >= 判断，即2%恰好属于频率异构
            - 边界值归属原则：边界值归入"更复杂"的处理策略，确保安全
        """
        # 步骤1: 检查是否有混合控制类型
        control_types = set(p.get('control_type', 'VFD') for p in pump_infos)
        is_mixed = len(control_types) > 1

        # ✅ v2.4: 纯SS泵组不支持
        if control_types == {'SS'}:
            raise ValueError(
                f"不支持纯软启泵组：软启泵必须与变频泵混合使用。"
                f"泵组成员: {[p['pump_id'] for p in pump_infos]}"
            )

        # 步骤2: 计算功率差异
        powers = [p.get('rated_power', 0) for p in pump_infos]
        if not powers or max(powers) == 0:
            power_diff = 0.0
        else:
            power_diff = (max(powers) - min(powers)) / max(powers)

        is_heterogeneous = power_diff >= self._power_diff_threshold

        # 步骤3: 决策
        if is_mixed:
            # VFD + SS 混合
            if is_heterogeneous:
                self._logger.info(
                    f"[泵组识别] 混合控制类型 + 功率差异{power_diff:.1%}≥10%，"
                    f"判定为 MIXED_HETEROGENEOUS"
                )
                return GroupProcessingStrategy.MIXED_HETEROGENEOUS
            else:
                self._logger.info("[泵组识别] 混合控制类型 + 功率相近，判定为 MIXED_GROUP")
                return GroupProcessingStrategy.MIXED_GROUP
        else:
            # 纯VFD泵组（纯SS已在上方拦截）
            pump_ids = [p['pump_id'] for p in pump_infos]
            frequencies = self._freq_provider.get_latest_frequencies(pump_ids)
            freq_values = list(frequencies.values())
            freq_diff = (max(freq_values) - min(freq_values)) / max(freq_values)

            if freq_diff >= 0.02:  # 频率差异 ≥ 2%
                self._logger.info(
                    f"[泵组识别] 全VFD泵组频率差异 {freq_diff:.1%} ≥ 2%，"
                    f"判定为 VFD_HETEROGENEOUS_FREQ"
                )
                return GroupProcessingStrategy.VFD_HETEROGENEOUS_FREQ

            if is_heterogeneous:
                self._logger.info(
                    f"[泵组识别] 功率差异 {power_diff:.1%} ≥ {self._power_diff_threshold:.0%}，"
                    f"判定为 HETEROGENEOUS_GROUP"
                )
                return GroupProcessingStrategy.HETEROGENEOUS_GROUP
            else:
                self._logger.info(
                    f"[泵组识别] 功率差异 {power_diff:.1%} < {self._power_diff_threshold:.0%}，"
                    f"判定为 HOMOGENEOUS_GROUP"
                )
                return GroupProcessingStrategy.HOMOGENEOUS_GROUP

    def _check_single_pump_curves(
        self,
        pump_ids: List[int],
        curve_type: str
    ) -> List[int]:
        """
        检查单泵曲线是否已注册

        Args:
            pump_ids: 泵ID列表
            curve_type: 曲线类型

        Returns:
            List[int]: 未注册的泵ID列表（空列表表示全部已注册）
        """
        from app.services.characteristic_curves.shared.curve_registry import CurveRegistry

        registry = CurveRegistry()
        missing = []

        for pump_id in pump_ids:
            if not registry.has_curve(pump_id, curve_type):
                missing.append(pump_id)
                self._logger.warning(f"[前置检查] 泵 {pump_id} 的 {curve_type} 曲线未注册")

        if missing:
            self._logger.error(f"[前置检查] 失败: {len(missing)}/{len(pump_ids)} 泵曲线未注册")
        else:
            self._logger.info(f"[前置检查] 通过: 所有 {len(pump_ids)} 泵曲线已注册")

        return missing

    def _trigger_p0_fitting(
        self,
        pump_ids: List[int],
        curve_type: str,
        max_retries: int = 3
    ) -> Dict[int, bool]:
        """
        自动触发P0单泵拟合（v2.0: 添加重试限制，防止死循环）

        Args:
            pump_ids: 需要拟合的泵ID列表
            curve_type: 曲线类型
            max_retries: 每台泵的最大重试次数（默认3次）

        Returns:
            Dict[int, bool]: {pump_id: success} 拟合结果

        Raises:
            P0FittingRetryExhaustedError: 当某台泵重试次数耗尽仍失败时抛出

        Note:
            ✅ v2.0修复问题#10：添加重试限制防止死循环
        """
        from app.services.characteristic_curves.pipeline import CurveFittingPipeline

        self._logger.info(f"[自动P0] 开始触发 {len(pump_ids)} 台泵的P0拟合 (max_retries={max_retries})")

        pipeline = CurveFittingPipeline()
        results: Dict[int, bool] = {}
        failed_pumps: List[Dict] = []

        for pump_id in pump_ids:
            success = False
            last_error = None

            for retry in range(max_retries):
                try:
                    result = pipeline.run(device_id=pump_id, curve_type=curve_type)
                    self._logger.info(
                        f"[自动P0] 泵 {pump_id} 拟合完成 (尝试 {retry + 1}/{max_retries}): "
                        f"R²={result.r_squared:.4f}"
                    )
                    results[pump_id] = True
                    success = True
                    break

                except InsufficientDataError as e:
                    # 数据不足：不重试，直接失败
                    self._logger.error(
                        f"[自动P0] 泵 {pump_id} 数据不足，无法拟合: {e.to_log_format()}"
                    )
                    last_error = str(e)
                    break

                except Exception as e:
                    last_error = str(e)
                    self._logger.warning(
                        f"[自动P0] 泵 {pump_id} 拟合失败 (尝试 {retry + 1}/{max_retries}): {e}"
                    )
                    if retry < max_retries - 1:
                        self._logger.info(f"[自动P0] 准备重试泵 {pump_id}...")

            if not success:
                results[pump_id] = False
                failed_pumps.append({
                    "pump_id": pump_id,
                    "retry_count": max_retries,
                    "last_error": last_error
                })

        # ✅ 如果有任何泵失败，抛出异常（不使用降级）
        if failed_pumps:
            error = P0FittingRetryExhaustedError(
                message=f"P0拟合失败: {len(failed_pumps)}/{len(pump_ids)} 台泵重试耗尽",
                pump_id=failed_pumps[0]["pump_id"],
                retry_count=max_retries,
                max_retries=max_retries,
                last_error=failed_pumps[0]["last_error"]
            )
            self._logger.error(error.to_log_format())
            raise error

        return results

    def process(
        self,
        station_id: int,
        pump_infos: List[Dict[str, Any]],
        curve_type: str = 'qh',
        auto_trigger_p0: bool = False,
        max_p0_retries: int = 3
    ) -> GroupFitResult:
        """
        处理泵组曲线（v2.0: 增强异常处理）

        Args:
            station_id: 泵站ID
            pump_infos: 泵信息列表
            curve_type: 曲线类型
            auto_trigger_p0: 单泵曲线缺失时是否自动触发P0拟合
            max_p0_retries: P0拟合最大重试次数（v2.0新增）

        Returns:
            GroupFitResult: 泵组拟合结果

        Raises:
            MissingCurveError: 单泵曲线未注册且auto_trigger_p0=False
            P0FittingRetryExhaustedError: P0拟合重试次数耗尽
            InsufficientDataError: 数据不足
            CorrectionModelTrainingError: 修正模型训练失败
        """
        pump_ids = [p['pump_id'] for p in pump_infos]

        # ✅ 前置检查：验证所有单泵曲线是否已完成P0拟合
        missing_curves = self._check_single_pump_curves(pump_ids, curve_type)
        if missing_curves:
            if auto_trigger_p0:
                # v2.0: 传入max_retries防止死循环
                self._trigger_p0_fitting(missing_curves, curve_type, max_retries=max_p0_retries)
            else:
                raise MissingCurveError(
                    f"以下泵的{curve_type}曲线未完成P0拟合: {missing_curves}。"
                    f"请先完成单泵拟合，或设置auto_trigger_p0=True自动触发。",
                    missing_pump_ids=missing_curves
                )

        # 1. 识别泵组类型
        group_type = self.identify_group_type(pump_infos)

        self._logger.info(f"[泵组处理] station={station_id}, pumps={pump_ids}, type={group_type.value}")

        # 2. 根据策略处理（v2.3更新: 新增VFD_HETEROGENEOUS_FREQ分支）
        if group_type == GroupProcessingStrategy.HOMOGENEOUS_GROUP:
            return self._process_homogeneous_group(station_id, pump_infos, curve_type)
        elif group_type == GroupProcessingStrategy.HETEROGENEOUS_GROUP:
            return self._process_heterogeneous_group(station_id, pump_infos, curve_type)
        elif group_type == GroupProcessingStrategy.VFD_HETEROGENEOUS_FREQ:
            # ✅ v2.3新增: VFD频率异构处理
            return self._process_vfd_heterogeneous_freq(station_id, pump_infos, curve_type)
        elif group_type == GroupProcessingStrategy.MIXED_HETEROGENEOUS:
            # v2.0: 混合异构使用加权合成+XGBoost修正
            return self._process_mixed_heterogeneous_group(station_id, pump_infos, curve_type)
        else:  # MIXED_GROUP
            return self._process_mixed_group(station_id, pump_infos, curve_type)

    def _get_pump_fit_result(
        self,
        pump_id: int,
        curve_type: str
    ) -> Optional['FitResult']:
        """
        获取单泵拟合结果（v2.5新增，解决问题#3）

        Args:
            pump_id: 泵ID
            curve_type: 曲线类型 ('qh' | 'qp' | 'qe')

        Returns:
            FitResult: 拟合结果对象，包含coefficients, r_squared, data_points等
            None: 如果未找到拟合结果

        Note:
            从CurveRegistry获取已存储的单泵曲线拟合结果。
            此方法在_select_base_pump()和_validate_curve_consistency()中调用。
        """
        from app.services.characteristic_curves.shared.curve_registry import CurveRegistry
        from app.services.characteristic_curves.models import FitResult  # v3.11修复P63：统一导入路径

        registry = CurveRegistry()
        entry = registry.get_entry(pump_id, curve_type)

        if entry is None:
            self._logger.warning(f"[获取拟合结果] pump_id={pump_id}, curve_type={curve_type} 未找到")
            return None

        # 从CurveEntry转换为FitResult
        return FitResult(
            device_id=pump_id,
            curve_type=curve_type,
            method_name=entry.method_name,
            coefficients=entry.coefficients,
            r_squared=entry.r_squared,
            rmse=entry.rmse if hasattr(entry, 'rmse') else 0.0,
            data_points=entry.data_points if hasattr(entry, 'data_points') else 0,
            fitted_at=entry.fitted_at if hasattr(entry, 'fitted_at') else None,
            valid_q_range=entry.Q_range if hasattr(entry, 'Q_range') else (0, 0),
            valid_h_range=entry.H_range if hasattr(entry, 'H_range') else (0, 0)
        )

    def _select_base_pump(
        self,
        pump_ids: List[int],
        pump_infos: List[Dict[str, Any]],
        curve_type: str
    ) -> int:
        """
        选择最优基准泵（v2.3新增）

        选择标准（优先级从高到低）：
        1. 运行频率最接近50Hz（额定频率）
        2. 曲线拟合R²最高
        3. 数据点数量最多

        Returns:
            最优基准泵ID

        Raises:
            ValueError: 无法确定基准泵
        """
        candidates = []

        for pump_id in pump_ids:
            # 获取拟合结果
            fit_result = self._get_pump_fit_result(pump_id, curve_type)
            if fit_result is None:
                self._logger.warning(f"泵 {pump_id} 无拟合结果，排除")
                continue

            # 获取当前频率
            freq = self._freq_provider.get_latest_frequencies([pump_id]).get(pump_id, 50.0)

            # 计算评分（频率偏离度权重0.4，R²权重0.4，数据点权重0.2）
            freq_score = 1 - abs(freq - 50) / 50  # 频率越接近50Hz越好
            r2_score = fit_result.r_squared
            # ✅ v2.5修复问题#4: 统一使用data_points字段名（与FitResult一致）
            data_score = min(fit_result.data_points / 10000, 1.0)  # 归一化

            total_score = 0.4 * freq_score + 0.4 * r2_score + 0.2 * data_score

            candidates.append({
                'pump_id': pump_id,
                'score': total_score,
                'freq': freq,
                'r2': fit_result.r_squared
            })

        if not candidates:
            raise ValueError("无可用的基准泵候选")

        # 按评分排序，选择最高分
        candidates.sort(key=lambda x: x['score'], reverse=True)
        best = candidates[0]

        self._logger.info(
            f"[基准泵选择] 选定 pump_id={best['pump_id']}，"
            f"freq={best['freq']}Hz, R²={best['r2']:.4f}, score={best['score']:.3f}"
        )

        return best['pump_id']

    def _validate_curve_consistency(
        self,
        pump_ids: List[int],
        curve_type: str,
        max_h0_deviation: float = 0.05,
        max_k_deviation: float = 0.10
    ) -> bool:
        """
        验证同构泵组曲线一致性（v2.3新增）

        Args:
            pump_ids: 泵ID列表
            curve_type: 曲线类型
            max_h0_deviation: H0最大允许偏差（相对值，默认5%）
            max_k_deviation: K最大允许偏差（相对值，默认10%）

        Returns:
            True: 一致性验证通过

        Raises:
            CurveInconsistencyError: 曲线参数差异超出阈值
        """
        # v3.12修复P67：CurveInconsistencyError已在顶层导入，此处移除冗余导入
        import numpy as np

        coefficients_list = []

        for pump_id in pump_ids:
            result = self._get_pump_fit_result(pump_id, curve_type)
            if result is None:
                raise MissingCurveError(f"泵 {pump_id} 缺少曲线数据", [pump_id])
            coefficients_list.append({
                'pump_id': pump_id,
                'H0': result.coefficients.get('H0'),
                'K': result.coefficients.get('K')
            })

        # 计算H0和K的统计值
        h0_values = [c['H0'] for c in coefficients_list]
        k_values = [c['K'] for c in coefficients_list]

        h0_mean = np.mean(h0_values)
        k_mean = np.mean(k_values)

        # 计算相对偏差
        h0_max_dev = max(abs(h0 - h0_mean) / h0_mean for h0 in h0_values)
        k_max_dev = max(abs(k - k_mean) / abs(k_mean) for k in k_values)

        self._logger.info(
            f"[曲线一致性] pumps={pump_ids}, H0偏差={h0_max_dev:.2%}, K偏差={k_max_dev:.2%}"
        )

        # 验证
        if h0_max_dev > max_h0_deviation:
            raise CurveInconsistencyError(
                message=f"同构泵组H0偏差 {h0_max_dev:.2%} 超出阈值 {max_h0_deviation:.0%}",
                pump_ids=pump_ids,
                parameter='H0',
                deviation=h0_max_dev,
                threshold=max_h0_deviation
            )

        if k_max_dev > max_k_deviation:
            raise CurveInconsistencyError(
                message=f"同构泵组K偏差 {k_max_dev:.2%} 超出阈值 {max_k_deviation:.0%}",
                pump_ids=pump_ids,
                parameter='K',
                deviation=k_max_dev,
                threshold=max_k_deviation
            )

        return True

    def _process_homogeneous_group(
        self,
        station_id: int,
        pump_infos: List[Dict[str, Any]],
        curve_type: str
    ) -> GroupFitResult:
        """
        处理同构泵组（v2.3更新：添加一致性验证和基准泵选择，v2.5修复fit调用）

        策略：选择基准泵，Q_group = N × Q_base

        Note:
            ✅ v2.5修复问题#5: 添加training_data参数到fit()调用
        """
        pump_ids = [p['pump_id'] for p in pump_infos]
        n_pumps = len(pump_ids)

        # ✅ v2.3新增: 曲线一致性验证
        self._validate_curve_consistency(pump_ids, curve_type)

        # ✅ v2.3更新: 使用优化的基准泵选择
        base_pump_id = self._select_base_pump(pump_ids, pump_infos, curve_type)

        # 1. 合成同构泵组曲线
        group_curve = self._synthesizer.synthesize_homogeneous(
            base_pump_id=base_pump_id,
            n_pumps=n_pumps
        )

        # 2. ✅ v2.5修复: 提取训练数据并学习修正系数
        training_data = self._extract_training_data(station_id, pump_ids)
        self._correction.fit(station_id, pump_ids, training_data=training_data)

        return GroupFitResult(
            station_id=station_id,
            pump_combination=pump_ids,
            group_type=GroupProcessingStrategy.HOMOGENEOUS_GROUP,
            curve_type=curve_type,
            base_pump_id=base_pump_id,
            pump_count=n_pumps,
            valid_n_range=(1, n_pumps),
            correction_model=self._correction.to_dict(),
            vfd_pump_ids=pump_ids,  # 同构泵组全是VFD
            ss_pump_ids=[]
        )

    def _process_vfd_heterogeneous_freq(
        self,
        station_id: int,
        pump_infos: List[Dict[str, Any]],
        curve_type: str
    ) -> GroupFitResult:
        """
        处理VFD频率异构泵组（v2.3新增，v2.5修复fit调用）

        场景：全VFD泵组，但各泵实际运行频率不同（差异≥2%）

        策略：
        1. 获取各泵当前运行频率
        2. 使用考虑频率的合成方法（synthesize_vfd_with_freq）
        3. 训练修正系数
        4. 精度目标保持R²>0.96（与同构相同）

        物理原理：
        - 各泵运行频率不同，需要分别反归一化
        - Q_total = Σ Q_i_actual = Σ (Q_i_50Hz × f_i/50)

        Note:
            ✅ v2.5修复问题#5: 添加training_data参数到fit()调用
        """
        pump_ids = [p['pump_id'] for p in pump_infos]
        n_pumps = len(pump_ids)

        # 1. 获取各泵当前频率
        frequencies = self._freq_provider.get_latest_frequencies(pump_ids)
        self._logger.info(f"[VFD频率异构] 各泵频率: {frequencies}")

        # 2. 使用考虑频率的合成方法
        group_curve = self._synthesizer.synthesize_vfd_with_freq(
            pump_ids=pump_ids,
            frequencies=frequencies
        )

        # 3. ✅ v2.5修复: 提取训练数据并学习修正系数
        training_data = self._extract_training_data(station_id, pump_ids)
        self._correction.fit(station_id, pump_ids, training_data=training_data)

        return GroupFitResult(
            station_id=station_id,
            pump_combination=pump_ids,
            group_type=GroupProcessingStrategy.VFD_HETEROGENEOUS_FREQ,
            curve_type=curve_type,
            pump_count=n_pumps,
            valid_n_range=(1, n_pumps),
            correction_model=self._correction.to_dict(),
            vfd_pump_ids=pump_ids,  # 全部是VFD
            ss_pump_ids=[]
        )

    def _process_heterogeneous_group(
        self,
        station_id: int,
        pump_infos: List[Dict[str, Any]],
        curve_type: str
    ) -> GroupFitResult:
        """
        处理异构泵组（v2.5更新，解决问题#7）

        策略：各泵独立曲线 + 并联合成

        Note:
            ✅ v2.5修复问题#7: 添加synthesize_heterogeneous()调用
        """
        pump_ids = [p['pump_id'] for p in pump_infos]
        n_pumps = len(pump_ids)

        # 1. 确保所有单泵曲线已注册
        missing_curves = []
        for pump_id in pump_ids:
            if pump_id not in self._synthesizer._pump_curves:
                missing_curves.append(pump_id)

        if missing_curves:
            raise ValueError(f"[异构处理] 泵曲线未注册: {missing_curves}")

        # ✅ v2.5新增: 记录异构泵组的频率差异情况（解决问题#6）
        frequencies = self._freq_provider.get_latest_frequencies(pump_ids)
        freq_values = list(frequencies.values())
        if len(freq_values) > 1:
            freq_diff = (max(freq_values) - min(freq_values)) / max(freq_values)
            self._logger.info(
                f"[异构处理] 频率差异 {freq_diff:.1%}, 各泵频率: {frequencies}"
            )

        # ✅ v2.5新增（解决问题#7）: 调用异构合成方法
        # ✅ v3.5修复P3：传递pump_frequencies参数，确保异构泵组频率差异正确处理
        # 使用系统扬程进行合成计算
        H_system = self._get_system_head(station_id)
        synthesis_result = self._synthesizer.synthesize_heterogeneous(
            pump_ids=pump_ids,
            H_system=H_system,
            pump_frequencies=frequencies  # v3.5: 传递各泵实际频率
        )

        self._logger.info(
            f"[异构处理] 合成结果: Q_total={synthesis_result.Q_total:.1f}, "
            f"H_system={synthesis_result.H_system:.1f}"
        )

        # 3. 提取训练数据并学习修正系数
        training_data = self._extract_training_data(station_id, pump_ids)
        self._correction.fit(station_id, pump_ids, training_data=training_data)

        return GroupFitResult(
            station_id=station_id,
            pump_combination=pump_ids,
            group_type=GroupProcessingStrategy.HETEROGENEOUS_GROUP,
            curve_type=curve_type,
            pump_count=n_pumps,
            valid_n_range=(1, n_pumps),
            correction_model=self._correction.to_dict(),
            vfd_pump_ids=pump_ids,  # 纯VFD泵组
            ss_pump_ids=[]
        )

    def _process_mixed_group(
        self,
        station_id: int,
        pump_infos: List[Dict[str, Any]],
        curve_type: str
    ) -> GroupFitResult:
        """
        处理混合泵组（VFD + 软启）（v2.5更新，解决问题#9）

        策略：分类处理 + 分类合成

        Note:
            ✅ v2.5修复问题#9: 添加synthesize_mixed()调用
        """
        pump_ids = [p['pump_id'] for p in pump_infos]
        n_pumps = len(pump_ids)

        # 1. 分类泵
        vfd_pumps = [p['pump_id'] for p in pump_infos if p.get('control_type') == 'VFD']
        ss_pumps = [p['pump_id'] for p in pump_infos if p.get('control_type') == 'SS']

        # ✅ v3.5修复P6：添加纯SS泵组检查断言
        # 混合泵组必须包含至少一台VFD泵，否则应使用synthesize_heterogeneous()处理
        assert len(vfd_pumps) > 0, (
            f"混合泵组必须包含至少一台VFD泵，当前VFD={len(vfd_pumps)}, SS={len(ss_pumps)}。"
            f"纯SS泵组应使用HETEROGENEOUS_GROUP策略处理。"
        )

        self._logger.info(f"[混合处理] VFD泵: {vfd_pumps}, 软启泵: {ss_pumps}")

        # 2. 获取VFD泵的当前频率
        pump_frequencies = self._freq_provider.get_latest_frequencies(vfd_pumps)

        # ✅ v2.5新增（解决问题#9）: 调用混合合成方法
        H_system = self._get_system_head(station_id)
        synthesis_result = self._synthesizer.synthesize_mixed(
            vfd_pump_ids=vfd_pumps,
            ss_pump_ids=ss_pumps,
            pump_frequencies=pump_frequencies,
            H_system=H_system
        )

        self._logger.info(
            f"[混合处理] 合成结果: Q_total={synthesis_result.Q_total:.1f}, "
            f"H_system={synthesis_result.H_system:.1f}, "
            f"流量分配: {synthesis_result.pump_flows}"
        )

        # 3. 提取训练数据并学习修正系数（使用XGBoost）
        training_data = self._extract_training_data(station_id, pump_ids)
        self._correction.set_model_type('xgboost')
        self._correction.fit(station_id, pump_ids, training_data=training_data)

        return GroupFitResult(
            station_id=station_id,
            pump_combination=pump_ids,
            group_type=GroupProcessingStrategy.MIXED_GROUP,
            curve_type=curve_type,
            pump_count=n_pumps,
            valid_n_range=(1, n_pumps),
            correction_model=self._correction.to_dict(),
            vfd_pump_ids=vfd_pumps,   # 记录变频泵列表
            ss_pump_ids=ss_pumps      # 记录软启泵列表
        )

    def _process_mixed_heterogeneous_group(
        self,
        station_id: int,
        pump_infos: List[Dict[str, Any]],
        curve_type: str
    ) -> GroupFitResult:
        """
        处理混合异构泵组（v2.4新增，v2.5更新解决问题#12）

        场景：VFD+SS混合 且 功率差异≥10%

        策略：
        1. 分类泵（VFD/SS）
        2. 检查VFD子组内部的功率差异和频率差异
        3. 计算功率权重
        4. 使用加权合成方法
        5. 训练XGBoost修正模型（扩展特征）

        Note:
            ✅ v2.4解决问题#19: 实现缺失的方法
            ✅ v2.4解决问题#20: 使用加权合成
            ✅ v2.4解决问题#21-22: 处理VFD子组的功率/频率差异
            ✅ v2.5修复问题#12: 添加synthesize_mixed_weighted()调用
        """
        pump_ids = [p['pump_id'] for p in pump_infos]
        n_pumps = len(pump_ids)

        # 1. 分类泵
        vfd_infos = [p for p in pump_infos if p.get('control_type') == 'VFD']
        ss_infos = [p for p in pump_infos if p.get('control_type') == 'SS']

        vfd_pump_ids = [p['pump_id'] for p in vfd_infos]
        ss_pump_ids = [p['pump_id'] for p in ss_infos]

        # 2. 计算功率权重
        powers = {p['pump_id']: p['rated_power'] for p in pump_infos}
        total_power = sum(powers.values())
        power_weights = {pid: pwr / total_power for pid, pwr in powers.items()}

        # 3. 检查VFD子组内部的功率差异
        vfd_power_diff = 0.0
        if len(vfd_infos) > 1:
            vfd_powers = [p['rated_power'] for p in vfd_infos]
            vfd_power_diff = (max(vfd_powers) - min(vfd_powers)) / max(vfd_powers)

        # 4. 检查VFD子组内部的频率差异
        vfd_freq_diff = 0.0
        pump_frequencies = {}
        if len(vfd_pump_ids) >= 1:
            pump_frequencies = self._freq_provider.get_latest_frequencies(vfd_pump_ids)
            if len(vfd_pump_ids) > 1:
                freq_values = list(pump_frequencies.values())
                vfd_freq_diff = (max(freq_values) - min(freq_values)) / max(freq_values)

        self._logger.info(
            f"[混合异构处理] VFD泵: {vfd_pump_ids}, SS泵: {ss_pump_ids}, "
            f"功率权重: {power_weights}, "
            f"VFD子组功率差异: {vfd_power_diff:.1%}, VFD子组频率差异: {vfd_freq_diff:.1%}"
        )

        # ✅ v2.5新增（解决问题#12）: 调用加权混合合成方法
        H_system = self._get_system_head(station_id)
        synthesis_result = self._synthesizer.synthesize_mixed_weighted(
            pump_infos=pump_infos,
            pump_frequencies=pump_frequencies,
            H_system=H_system
        )

        self._logger.info(
            f"[混合异构处理] 合成结果: Q_total={synthesis_result.Q_total:.1f}, "
            f"H_system={synthesis_result.H_system:.1f}, "
            f"功率权重: {synthesis_result.power_weights}, "
            f"流量权重: {synthesis_result.flow_weights}"
        )

        # 5. 准备扩展特征用于XGBoost训练
        extended_features = {
            'power_weights': power_weights,
            'vfd_power_diff': vfd_power_diff,
            'vfd_freq_diff': vfd_freq_diff,
            'power_max': max(powers.values()),
            'power_min': min(powers.values()),
            'power_ratio': max(powers.values()) / min(powers.values())
        }

        # 6. 提取训练数据并学习修正系数（使用XGBoost + 扩展特征）
        training_data = self._extract_training_data(station_id, pump_ids)
        self._correction.set_model_type('xgboost')
        self._correction.fit(
            station_id,
            pump_ids,
            training_data=training_data,
            extra_features=extended_features
        )

        return GroupFitResult(
            station_id=station_id,
            pump_combination=pump_ids,
            group_type=GroupProcessingStrategy.MIXED_HETEROGENEOUS,
            curve_type=curve_type,
            pump_count=n_pumps,
            valid_n_range=(1, n_pumps),
            correction_model=self._correction.to_dict(),
            vfd_pump_ids=vfd_pump_ids,
            ss_pump_ids=ss_pump_ids
        )

    def _get_system_head(self, station_id: int) -> float:
        """
        获取泵站的系统扬程（v2.5新增，v3.13修复数据源）

        Args:
            station_id: 泵站ID

        Returns:
            float: 系统扬程值（米）

        Note:
            ✅ v3.13修复：从fact_measurements表获取总管出口压力，转换为扬程。
            使用 metric_key='main_pipeline_outlet_pressure' 指标。
            H_system = outlet_pressure × 10.2 (MPa → m)
        """
        from app.adapters.db.pool import get_connection

        sql = """
            SELECT fm.value * 10.2 AS H_system
            FROM fact_measurements fm
            JOIN dim_devices dd ON fm.device_id = dd.id
            WHERE dd.station_id = %(station_id)s
              AND fm.metric_id = (
                  SELECT id FROM dim_metric_config
                  WHERE metric_key = 'main_pipeline_outlet_pressure'
              )
              AND fm.value IS NOT NULL
            ORDER BY fm.ts_raw DESC
            LIMIT 1
        """
        with get_connection() as conn:
            result = conn.execute(sql, {'station_id': station_id}).fetchone()
            if result:
                return float(result['H_system'])

        # 无数据时抛出异常（v2.0原则：不使用默认值）
        raise DataNotFoundError(
            f"泵站 {station_id} 无出口压力数据（metric_key='main_pipeline_outlet_pressure'）"
        )

    def _extract_training_data(
        self,
        station_id: int,
        pump_ids: List[int]
    ) -> np.ndarray:
        """
        提取修正模型训练数据（v2.5新增，v3.13修复数据源）

        Args:
            station_id: 泵站ID
            pump_ids: 泵ID列表

        Returns:
            np.ndarray: 训练数据矩阵 [N, Q_total, H_theoretical, H_actual]
                - N: 运行台数
                - Q_total: 总流量
                - H_theoretical: 理论扬程（通过合成计算）
                - H_actual: 实际扬程（传感器测量）

        Note:
            ✅ v3.13修复：从fact_measurements表获取历史数据，该表存储时间对齐后的数据。
            使用以下指标（metric_key）：
            - device_running: 设备运行状态
            - pump_flow_rate: 泵瞬时流量
            - main_pipeline_outlet_pressure: 总管出口压力

            覆盖泵组中任意子集组合的运行数据（详见4.3节）。
            ✅ v3.5修复P1：H_theoretical通过synthesize方法计算
        """
        import numpy as np
        from app.adapters.db.pool import get_connection

        # ✅ v3.13修复：使用fact_measurements表聚合泵组运行数据
        sql = """
            WITH pump_group AS (
                SELECT %(pump_ids)s::int[] AS group_pumps
            ),
            -- 获取指标ID
            metric_ids AS (
                SELECT
                    MAX(CASE WHEN metric_key = 'device_running' THEN id END) AS running_id,
                    MAX(CASE WHEN metric_key = 'pump_flow_rate' THEN id END) AS flow_id,
                    MAX(CASE WHEN metric_key = 'main_pipeline_outlet_pressure' THEN id END) AS pressure_id
                FROM dim_metric_config
            ),
            -- 获取每个时间桶内各泵的运行状态和流量
            pump_metrics AS (
                SELECT
                    fm.ts_bucket,
                    fm.device_id,
                    MAX(CASE WHEN fm.metric_id = mi.running_id THEN fm.value END) AS running,
                    MAX(CASE WHEN fm.metric_id = mi.flow_id THEN fm.value END) AS flow
                FROM fact_measurements fm
                CROSS JOIN metric_ids mi
                JOIN dim_devices dd ON fm.device_id = dd.id
                WHERE dd.station_id = %(station_id)s
                  AND fm.device_id = ANY(%(pump_ids)s)
                  AND fm.ts_bucket >= NOW() - INTERVAL '90 days'
                  AND fm.metric_id IN (mi.running_id, mi.flow_id)
                GROUP BY fm.ts_bucket, fm.device_id
            ),
            -- 获取总管出口压力
            station_pressure AS (
                SELECT
                    fm.ts_bucket,
                    fm.value * 10.2 AS H_actual  -- MPa → m
                FROM fact_measurements fm
                CROSS JOIN metric_ids mi
                JOIN dim_devices dd ON fm.device_id = dd.id
                WHERE dd.station_id = %(station_id)s
                  AND fm.metric_id = mi.pressure_id
                  AND fm.ts_bucket >= NOW() - INTERVAL '90 days'
                  AND fm.value > 0
            ),
            -- 聚合：按时间桶汇总运行泵列表和总流量
            aggregated AS (
                SELECT
                    pm.ts_bucket,
                    array_agg(pm.device_id ORDER BY pm.device_id)
                        FILTER (WHERE pm.running = 1) AS running_pumps,
                    COUNT(*) FILTER (WHERE pm.running = 1) AS N,
                    COALESCE(SUM(pm.flow) FILTER (WHERE pm.running = 1), 0) AS Q_total,
                    sp.H_actual
                FROM pump_metrics pm
                JOIN station_pressure sp ON pm.ts_bucket = sp.ts_bucket
                GROUP BY pm.ts_bucket, sp.H_actual
                HAVING COUNT(*) FILTER (WHERE pm.running = 1) >= 1
            ),
            -- 筛选：运行泵是目标泵组的子集
            valid_records AS (
                SELECT running_pumps, N, Q_total, H_actual
                FROM aggregated ag
                CROSS JOIN pump_group pg
                WHERE ag.running_pumps <@ pg.group_pumps  -- 运行泵是泵组子集
                  AND ag.running_pumps && pg.group_pumps  -- 至少有1台泵在运行
                  AND ag.Q_total > 0
            )
            SELECT running_pumps, N, Q_total, H_actual
            FROM valid_records
            ORDER BY Q_total
        """
        with get_connection() as conn:
            rows = conn.execute(sql, {
                'station_id': station_id,
                'pump_ids': pump_ids
            }).fetchall()

        if not rows:
            self._logger.warning(f"[训练数据] 泵站 {station_id} 无历史数据")
            return np.array([])

        # 构建训练数据矩阵
        data = []
        for row in rows:
            running_pumps = row['running_pumps']
            N = row['N']
            Q_total = row['Q_total']
            H_actual = row['H_actual']

            # ✅ v3.5修复P1：通过合成方法计算H_theoretical
            # 使用实际H_actual作为系统扬程，计算理论流量Q_theoretical
            # 然后通过Q_total反算H_theoretical
            try:
                # 使用synthesize_heterogeneous计算理论值
                synthesis_result = self._synthesizer.synthesize_heterogeneous(
                    pump_ids=running_pumps,
                    H_system=H_actual  # 以实际扬程为参考
                )
                # 理论扬程 = 合成计算得到的扬程
                H_theoretical = synthesis_result.H_system
            except Exception as e:
                # 合成失败时使用H_actual作为回退
                self._logger.debug(f"[训练数据] 合成计算失败: {e}，使用H_actual作为H_theoretical")
                H_theoretical = H_actual

            data.append([N, Q_total, H_theoretical, H_actual])

        self._logger.info(f"[训练数据] 提取 {len(data)} 条记录，用于泵站 {station_id}")
        return np.array(data)

from typing import Dict, List, Optional
from datetime import datetime

class FrequencyDataProvider:
    """
    变频泵频率数据提供器

    职责：
    1. 从数据库查询历史频率数据（用于离线分析）

        self,
        pump_ids: List[int],

            FrequencyQueryError: 当无法获取某泵频率时抛出

                                  SELECT id FROM dim_metric_config
                                  WHERE metric_key = 'pump_frequency'
                              )
                              AND fm.ts_raw <= %s
                            ORDER BY fm.ts_raw DESC LIMIT 1
                        """
                        cursor.execute(sql, (pump_id, timestamp))
                    else:
                        sql = """
                            SELECT fm.value AS freq
                            FROM fact_measurements fm
                            WHERE fm.device_id = %s
                              AND fm.metric_id = (
                                  SELECT id FROM dim_metric_config
                                  WHERE metric_key = 'pump_frequency'
                              )

                            pump_id=pump_id,
                            timestamp=str(timestamp) if timestamp else "latest"

                        self._logger.error(error.to_log_format())
                        raise error

                    freq = float(row[0])

                    # 验证频率范围（超范围也抛异常）

                            pump_id=pump_id,
                            timestamp=str(timestamp) if timestamp else "latest"

                        raise error

        self._logger.info(f"[频率] 成功获取 {len(frequencies)} 台泵的频率: {frequencies}")

            >>> freq_std = provider.calculate_freq_std([101, 102, 103])
            >>> if freq_std > 2.0:  # 频率变化超过2Hz
            ...     # 执行相似定律归一化
            ...     pass

        freq_values = list(frequencies.values())

        freq_std = float(np.std(freq_values))

        self._logger.debug(
            f"[频率标准差] pumps={pump_ids}, "
            f"frequencies={freq_values}, std={freq_std:.2f}Hz"

        return freq_std

    def get_frequency_history(
        self,
        pump_id: int,
        start_time: datetime,
        end_time: datetime

        获取泵的频率历史数据（v3.13修复：使用metric_key查询）

                      )
                      AND fm.ts_raw BETWEEN %s AND %s
                    ORDER BY fm.ts_raw
                """
                cursor.execute(sql, (pump_id, start_time, end_time))
                return [{"ts": row[0], "freq": row[1]} for row in cursor.fetchall()]

class ParallelSynthesizer:

## 3. ParallelSynthesizer（并联合成器）

### 3.1 并联合成物理原理

```
并联特性：
- 扬程相同：H₁ = H₂ = ... = H_N = H_system
- 流量叠加：Q_total = Q₁ + Q₂ + ... + Q_N
- 功率叠加：P_total = P₁ + P₂ + ... + P_N
- 效率计算：η_total = (ρgQ_total·H_system) / P_total
```

#### 3.1.1 效率计算变频影响说明【v3.17新增 P6修复】

> ⚠️ **关键问题**：变频泵组的效率计算需要特别注意频率修正

**变频对效率的影响**：

1. **效率-流量曲线的偏移**：
   - 变频运行时，效率曲线整体向左偏移（低频）或向右偏移（高频）
   - 最佳效率点（BEP）对应的流量也按比例变化：Q_BEP_f = Q_BEP_50 × (f/50)

2. **效率值的变化规律**：
   - 在相似工况下，效率基本不变：η(Q_f, H_f) ≈ η(Q_50, H_50)
   - 偏离相似工况时，效率会下降
   - 低频运行（f < 30Hz）时，机械损失占比增加，效率明显降低

3. **泵组效率计算公式**：
   ```python
   # 泵组总效率计算（v3.17增强：考虑变频影响）
   def calculate_group_efficiency(
       Q_total: float,     # 总流量 m³/h
       H_system: float,    # 系统扬程 m
       P_total: float,     # 总功率 kW
       pump_freqs: Dict[int, float]  # 各泵运行频率
   ) -> float:
       """
       η_total = (ρ × g × Q × H) / P
       
       注意：
       - 此公式在变频工况下仍然有效
       - P_total已经包含了各泵的变频功率修正：P_i = P_50 × (f/50)³
       - Q和H是实际测量值或合成计算值
       """
       if P_total <= 0 or Q_total <= 0:
           return 0.0
       
       Q_m3s = Q_total / 3600
       P_watts = P_total * 1000
       
       eta = (1000 * 9.81 * Q_m3s * H_system) / P_watts
       
       # 低频惩罚：频率低于30Hz时效率降低
       min_freq = min(pump_freqs.values()) if pump_freqs else 50.0
       if min_freq < 30.0:
           penalty = 1 - 0.02 * (30 - min_freq)  # 每低1Hz效率降2%
           eta *= max(penalty, 0.8)  # 最多降20%
       
       return max(0.0, min(1.0, eta))
   ```

4. **变频对各泵效率的影响**：
   | 频率范围 | 效率变化 | 说明 |
   |---------|----------|------|
   | 45-55 Hz | ±1-2% | 基本无影响 |
   | 35-45 Hz | -3-5% | 轻微下降 |
   | 25-35 Hz | -8-15% | 明显下降 |
   | <25 Hz | 不建议运行 | 机械效率急剧降低 |

class ParallelSynthesizer:
    """
    并联合成器

    职责：
    1. 同构泵组：Q_group = N × Q_single（简化合成）
    2. 异构泵组：等扬程流量叠加（迭代求解）
    3. 混合泵组：分类合成后再叠加
    4. 功率计算：基于Q-P曲线或物理公式
    5. 效率计算：η = ρgQH / P

    物理常数：
        RHO = 1000  # 水密度 kg/m³
        G = 9.81    # 重力加速度 m/s²
    """

    # 物理常数（v3.0新增）
    RHO = 1000.0  # 水密度 kg/m³
    G = 9.81      # 重力加速度 m/s²

    def __init__(self):
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")
        self._pump_curves: Dict[int, Callable] = {}         # pump_id → Q→H 函数
        self._pump_inverse_curves: Dict[int, Callable] = {} # pump_id → H→Q 函数
        self._pump_power_curves: Dict[int, Callable] = {}   # pump_id → Q→P 函数（v3.0新增）
        self._pump_rated_powers: Dict[int, float] = {}      # pump_id → 额定功率（v3.0新增）
        self._pump_H_ranges: Dict[int, Tuple[float, float]] = {}  # pump_id → (H_min, H_max)【v3.8新增 P48修复】

    # ══════════════════════════════════════════════════════════════════════════
    # 📋 软启泵(SS)处理规则【v3.12新增】
    # ──────────────────────────────────────────────────────────────────────────
    # 相似律（Q∝f, H∝f², P∝f³）仅适用于变频泵(VFD)。软启泵的处理规则如下：
    #
    # 1. **固定频率**：软启泵始终使用50Hz额定频率运行，不进行频率归一化
    #
    # 2. **曲线使用**：直接使用P0阶段拟合的50Hz额定曲线，无需反归一化
    #
    # 3. **流量分配**：在混合泵组中，软启泵流量由系统扬程决定
    #    Q_ss = inverse_func_ss(H_system)  # 使用50Hz曲线的逆函数
    #
    # 4. **不参与频率调节**：流量调节完全由变频泵完成
    #    - 变频泵通过调频改变流量：Q_vfd = f(H_system, freq)
    #    - 软启泵流量固定：Q_ss = f(H_system)（仅与扬程相关）
    #
    # 5. **启停控制**：软启泵只能开/关，不能调节
    #    - 增加流量：开启更多软启泵 或 提高变频泵频率
    #    - 减少流量：关闭软启泵 或 降低变频泵频率
    #
    # 6. **功率计算**：软启泵功率使用50Hz额定曲线
    #    P_ss = power_func_ss(Q_ss)  # 或使用物理公式估算
    #
    # 7. **纯SS泵组**：不支持。软启泵组无法调节流量，必须与变频泵混合使用
    # ══════════════════════════════════════════════════════════════════════════

    def register_pump_curve(
        self,
        pump_id: int,
        curve_func: Callable[[float], float],
        inverse_func: Optional[Callable[[float], float]] = None,
        power_func: Optional[Callable[[float], float]] = None,
        rated_power: Optional[float] = None,
        H_range: Optional[Tuple[float, float]] = None  # v3.8新增【P48修复】
    ):
        """
        注册单泵曲线（v3.8扩展：添加扬程范围支持）

        Args:
            pump_id: 泵ID
            curve_func: Q → H 函数
            inverse_func: H → Q 函数（可选，用于并联计算）
            power_func: Q → P 函数（可选，用于功率计算）【v3.0新增，解决问题P1】
            rated_power: 额定功率 kW（可选，用于负荷分配和效率估算）【v3.0新增】
            H_range: 有效扬程范围 (H_min, H_max)【v3.8新增 P48修复】

        Note:
            ✅ v3.0解决问题P1: 添加power_func参数
            ✅ v3.0解决问题P3: 与04_并联泵组曲线.md描述保持一致
            ✅ v3.8修复P48: 添加H_range参数用于扬程范围检查

            如果未提供power_func，将使用物理公式估算功率：
            P = ρ × g × Q × H / η_estimated
            其中η_estimated取0.75（典型水泵效率）
        """
        self._pump_curves[pump_id] = curve_func
        if inverse_func:
            self._pump_inverse_curves[pump_id] = inverse_func
        if power_func:
            self._pump_power_curves[pump_id] = power_func
        if rated_power:
            self._pump_rated_powers[pump_id] = rated_power
        if H_range:
            self._pump_H_ranges[pump_id] = H_range

    def _calculate_pump_power(
        self,
        pump_id: int,
        Q: float,
        H: float,
        default_efficiency: Optional[float] = None,
        frequency: Optional[float] = None
    ) -> float:
        """
        计算单泵功率【v3.1增强：支持变频泵功率修正】

        Args:
            pump_id: 泵ID
            Q: 流量 m³/h
            H: 扬程 m
            default_efficiency: 默认效率（可选，None时自动获取）
            frequency: 运行频率Hz【v3.1新增】
                - None或50: 不修正（工频运行）
                - 其他值: 应用相似定律修正 P ∝ f³

        Returns:
            功率 kW

        v3.1增强：
        - 新增frequency参数支持变频泵功率修正
        - 相似定律：P_f = P_50 × (f/50)³
        """
        if pump_id in self._pump_power_curves:
            # 使用注册的功率曲线
            P_50 = self._pump_power_curves[pump_id](Q)
            # v3.1: 变频修正
            if frequency and frequency != 50.0:
                P_f = P_50 * (frequency / 50.0) ** 3
                self._logger.debug(f"[功率修正] pump={pump_id}, f={frequency}Hz, P={P_50:.2f}→{P_f:.2f}kW")
                return P_f
            return P_50

        # v3.0新增：智能效率获取
        if default_efficiency is None:
            default_efficiency = self._get_estimated_efficiency(pump_id, Q, H)

        # 使用物理公式估算
        Q_m3s = Q / 3600  # m³/h → m³/s
        P_watts = self.RHO * self.G * Q_m3s * H / default_efficiency
        P_kw = P_watts / 1000

        # v3.1: 变频修正
        if frequency and frequency != 50.0:
            P_kw = P_kw * (frequency / 50.0) ** 3
            self._logger.debug(
                f"[功率估算] pump={pump_id}, Q={Q:.1f}m³/h, H={H:.1f}m, f={frequency}Hz, "
                f"η_est={default_efficiency:.2f} → P={P_kw:.2f}kW (变频修正后)"
            )
        else:
            self._logger.debug(
                f"[功率估算] pump={pump_id}, Q={Q:.1f}m³/h, H={H:.1f}m, "
                f"η_est={default_efficiency:.2f} → P={P_kw:.2f}kW"
            )
        return P_kw

    def _get_estimated_efficiency(self, pump_id: int, Q: float, H: float) -> float:
        """
        获取估算效率【v3.0新增，解决问题N4】

        优先级：
        1. 从efficiency_func获取（如果已注册）
        2. 从fact_measurements获取历史平均效率
        3. 使用默认值0.75
        """
        # 尝试从已注册的效率曲线获取
        if hasattr(self, '_pump_efficiency_curves') and pump_id in self._pump_efficiency_curves:
            try:
                return self._pump_efficiency_curves[pump_id](Q)
            except Exception:
                pass

        # 尝试从历史数据获取
        avg_eta = self._query_historical_avg_efficiency(pump_id)
        if avg_eta and 0.5 <= avg_eta <= 0.95:
            self._logger.info(f"[功率计算] 泵{pump_id}使用历史平均效率η={avg_eta:.2f}")
            return avg_eta

        # 回退到默认值
        self._logger.warning(f"[功率计算] 泵{pump_id}无历史效率数据，使用默认η=0.75")
        return 0.75

    def _query_historical_avg_efficiency(self, pump_id: int) -> Optional[float]:
        """从历史数据查询平均效率【v3.0新增, v3.15修复P82】"""
        try:
            from app.db.connection import get_connection
            with get_connection() as conn:
                cursor = conn.cursor()
                # v3.15修复P82: fact_measurements表无pump_efficiency字段
                # 需通过metric_id关联dim_metric_config表查询
                cursor.execute("""
                    SELECT AVG(fm.value)
                    FROM fact_measurements fm
                    WHERE fm.device_id = %s
                      AND fm.metric_id = (
                          SELECT id FROM dim_metric_config
                          WHERE metric_key = 'pump_efficiency'
                      )
                      AND fm.value BETWEEN 0.5 AND 0.95
                      AND fm.ts_raw > NOW() - INTERVAL '30 days'
                """, (pump_id,))
                result = cursor.fetchone()
                return float(result[0]) if result and result[0] else None
        except Exception as e:
            self._logger.debug(f"[历史效率查询] 泵{pump_id}查询失败: {e}")
            return None

    def _calculate_total_efficiency(
        self,
        Q_total: float,
        H_system: float,
        P_total: float
    ) -> float:
        """
        计算泵组总效率（v3.0新增，解决问题P4）

        Args:
            Q_total: 总流量 m³/h
            H_system: 系统扬程 m
            P_total: 总功率 kW

        Returns:
            总效率 (0-1)

        公式：
            η = (ρ × g × Q × H) / P
            其中Q需要从m³/h转换为m³/s，P从kW转换为W
        """
        if P_total <= 0 or Q_total <= 0:
            return 0.0

        Q_m3s = Q_total / 3600  # m³/h → m³/s
        P_watts = P_total * 1000  # kW → W

        # η = ρgQH / P
        eta = (self.RHO * self.G * Q_m3s * H_system) / P_watts

        # 限制在合理范围内
        eta = max(0.0, min(1.0, eta))

        self._logger.debug(
            f"[效率计算] Q={Q_total:.1f}m³/h, H={H_system:.1f}m, "
            f"P={P_total:.2f}kW → η={eta:.2%}"
        )
        return eta

    def synthesize_homogeneous(
        self,
        base_pump_id: int,
        n_pumps: int,
        Q_range: Tuple[float, float] = (0, 3000)
    ) -> Callable[[float], float]:
        """
        同构泵组合成（返回曲线函数）

        Args:
            base_pump_id: 基准泵ID
            n_pumps: 泵数量
            Q_range: 流量范围

        Returns:
            Q_total → H_group 函数
        """
        if base_pump_id not in self._pump_curves:
            raise ValueError(f"未注册泵曲线: pump_id={base_pump_id}")

        base_curve = self._pump_curves[base_pump_id]

        def group_curve(Q_total: float) -> float:
            """同构泵组曲线：Q_single = Q_total / N"""
            Q_single = Q_total / n_pumps
            return base_curve(Q_single)

        return group_curve

    def synthesize_homogeneous_with_power(
        self,
        base_pump_id: int,
        pump_ids: List[int],
        H_system: float
    ) -> 'SynthesisResult':
        """
        同构泵组合成（含功率和效率计算）【v3.0新增，解决问题P2/P4】

        Args:
            base_pump_id: 基准泵ID
            pump_ids: 所有运行泵的ID列表
            H_system: 系统扬程

        Returns:
            SynthesisResult: 包含流量、功率、效率的完整合成结果

        Note:
            ✅ v3.0解决问题P2: 计算pump_powers和P_total
            ✅ v3.0解决问题P4: 计算eta_total
            ✅ v3.0解决问题P5: 效率计算使用标准公式
        """
        n_pumps = len(pump_ids)

        if base_pump_id not in self._pump_inverse_curves:
            raise ValueError(f"泵 {base_pump_id} 未注册逆函数")

        # 1. 计算各泵流量（同构泵组，流量平均分配）
        inverse_func = self._pump_inverse_curves[base_pump_id]
        Q_single = inverse_func(H_system)
        Q_total = Q_single * n_pumps

        pump_flows = {pid: Q_single for pid in pump_ids}
        pump_heads = {pid: H_system for pid in pump_ids}

        # 2. 计算各泵功率【v3.0新增，解决问题P2】
        pump_powers = {}
        P_total = 0.0
        for pid in pump_ids:
            P_i = self._calculate_pump_power(pid, Q_single, H_system)
            pump_powers[pid] = P_i
            P_total += P_i

        # 3. 计算总效率【v3.0新增，解决问题P4】
        eta_total = self._calculate_total_efficiency(Q_total, H_system, P_total)

        self._logger.info(
            f"[同构合成] base_pump={base_pump_id}, n={n_pumps}, "
            f"H={H_system:.1f}m → Q_total={Q_total:.1f}m³/h, "
            f"P_total={P_total:.2f}kW, η={eta_total:.2%}"
        )

        # v3.3新增：创建结果并设置_rated_powers（与synthesize_heterogeneous保持一致）
        result = SynthesisResult(
            Q_total=Q_total,
            H_system=H_system,
            pump_flows=pump_flows,
            pump_heads=pump_heads,
            pump_powers=pump_powers,
            P_total=P_total,
            eta_total=eta_total
        )
        # v3.3解决P21：设置_rated_powers用于负荷分配
        result._rated_powers = {pid: self._pump_rated_powers.get(pid, 0) for pid in pump_ids}
        return result

    def synthesize_vfd_with_freq(
        self,
        pump_ids: List[int],
        frequencies: Dict[int, float]
    ) -> Callable[[float], float]:
        """
        考虑频率差异的VFD泵组合成（v2.3新增）

        Args:
            pump_ids: 泵ID列表
            frequencies: 各泵当前运行频率 {pump_id: freq_Hz}

        Returns:
            H_system → Q_total 的计算函数

        物理原理：
            1. 各泵Q-H曲线已归一化到50Hz
            2. 给定系统扬程H_system，需要归一化到50Hz后查曲线
            3. 得到的Q_50Hz再反归一化到实际频率
            4. 各泵实际流量相加得到总流量

        公式：
            H_50 = H_system × (50 / f_actual)²
            Q_50 = inverse_func(H_50)
            Q_actual = Q_50 × (f_actual / 50)
            Q_total = Σ Q_actual

        Note:
            这是一个逆向计算：给定H计算Q，而非给定Q计算H
        """
        import logging
        logger = logging.getLogger(__name__)

        def calculate_total_flow(H_system: float) -> float:
            """给定系统扬程，计算总流量"""
            Q_total = 0.0

            for pump_id in pump_ids:
                if pump_id not in self._pump_inverse_curves:
                    raise ValueError(f"泵 {pump_id} 未注册逆函数")

                freq = frequencies.get(pump_id, 50.0)
                inverse_func = self._pump_inverse_curves[pump_id]

                # 1. 将实际扬程归一化到50Hz
                # H_50 = H_actual × (50/f)²
                H_50 = H_system * (50 / freq) ** 2

                # 2. 使用50Hz逆函数计算Q_50
                Q_50 = inverse_func(H_50)

                # 3. 反归一化到实际频率
                # Q_actual = Q_50 × (f/50)
                Q_actual = Q_50 * (freq / 50)

                Q_total += Q_actual

                logger.debug(
                    f"[VFD合成] pump={pump_id}, freq={freq}Hz, "
                    f"H_system={H_system:.1f}m → H_50={H_50:.1f}m → "
                    f"Q_50={Q_50:.1f} → Q_actual={Q_actual:.1f}"
                )

            logger.info(
                f"[VFD合成] H_system={H_system:.1f}m, "
                f"pumps={pump_ids}, Q_total={Q_total:.1f}m³/h"
            )

            return Q_total

        return calculate_total_flow

    def synthesize_heterogeneous(
        self,
        pump_ids: List[int],
        H_system: float,
        pump_frequencies: Optional[Dict[int, float]] = None  # v3.2新增：支持变频泵
    ) -> SynthesisResult:
        """
        异构泵组合成（给定系统扬程，计算各泵流量、功率、效率）【v3.2增强】

        Args:
            pump_ids: 运行中的泵ID列表
            H_system: 系统扬程
            pump_frequencies: 各泵运行频率 {pump_id: freq_Hz}【v3.2新增】
                - 如果不提供或泵不在字典中，默认50Hz（工频）
                - 非50Hz时应用相似定律：Q∝f, H∝f², P∝f³

        Returns:
            SynthesisResult: 合成结果（含功率和效率，以及_rated_powers）

        Raises:
            HeadOutOfRangeError: 系统扬程超出泵的有效范围时抛出
            ValueError: 泵曲线未注册

        Note:
            ✅ v2.2修复问题#11：添加系统扬程范围检查
            ✅ v3.0解决问题P2：计算pump_powers和P_total
            ✅ v3.0解决问题P4：计算eta_total
            ✅ v3.2解决问题P11：添加pump_frequencies参数支持变频泵
            ✅ v3.2解决问题P1：返回时设置_rated_powers字段
            ✅ v3.5修复P4：默认频率行为说明

            **默认频率行为（v3.5修复P4）**：
            当pump_frequencies参数为None或某泵不在字典中时：
            1. 默认使用50Hz（工频）进行计算
            2. 此时不应用相似定律变换，直接使用50Hz曲线
            3. 适用场景：软启泵、工频运行的变频泵、历史数据无频率记录
            4. 调用方应尽量提供实际频率以获得准确结果
        """
        pump_flows = {}
        pump_powers = {}
        Q_total = 0.0
        P_total = 0.0

        for pump_id in pump_ids:
            if pump_id not in self._pump_inverse_curves:
                raise ValueError(f"泵 {pump_id} 未注册逆函数")

            inverse_func = self._pump_inverse_curves[pump_id]
            # v3.2新增：获取泵的运行频率
            f_actual = pump_frequencies.get(pump_id, 50.0) if pump_frequencies else 50.0

            try:
                if f_actual != 50.0:
                    # 变频泵：应用相似定律
                    # 将系统扬程归一化到50Hz：H_50 = H_system × (50/f)²
                    H_50hz = H_system * (50.0 / f_actual) ** 2
                    Q_50hz = inverse_func(H_50hz)
                    # 反归一化到实际频率：Q_actual = Q_50 × (f/50)
                    Q_i = Q_50hz * (f_actual / 50.0)
                else:
                    # 工频泵：直接使用曲线
                    Q_i = inverse_func(H_system)

                # v3.6修复P17/P20：使用正确的HeadOutOfRangeError签名（已在文件头部导入）
                if Q_i <= 0:
                    H_max = self._get_pump_h_max(pump_id)
                    raise HeadOutOfRangeError(
                        message=f"系统扬程 H={H_system}m 超出泵 {pump_id} 的有效范围",
                        H_system=H_system,
                        H_min=0.0,
                        H_max=H_max,
                        pump_id=pump_id
                    )
            except (ValueError, RuntimeError) as e:
                # v3.6修复P17/P20：使用正确的HeadOutOfRangeError签名
                raise HeadOutOfRangeError(
                    message=f"系统扬程 H={H_system}m 超出泵 {pump_id} 的有效范围: {e}",
                    H_system=H_system,
                    H_min=0.0,
                    H_max=float('inf'),
                    pump_id=pump_id
                )

            pump_flows[pump_id] = Q_i
            Q_total += Q_i

            # 【v3.2增强】计算各泵功率，传递frequency参数
            P_i = self._calculate_pump_power(pump_id, Q_i, H_system, frequency=f_actual)
            pump_powers[pump_id] = P_i
            P_total += P_i

        # 【v3.0新增】计算总效率
        eta_total = self._calculate_total_efficiency(Q_total, H_system, P_total)

        self._logger.info(
            f"[异构合成] pumps={pump_ids}, H={H_system:.1f}m, freqs={pump_frequencies} → "
            f"Q_total={Q_total:.1f}m³/h, P_total={P_total:.2f}kW, η={eta_total:.2%}"
        )

        # v3.2新增：创建结果并设置_rated_powers
        result = SynthesisResult(
            Q_total=Q_total,
            H_system=H_system,
            pump_flows=pump_flows,
            pump_heads={pid: H_system for pid in pump_ids},
            pump_powers=pump_powers,
            P_total=P_total,
            eta_total=eta_total
        )
        # v3.2解决P1：设置_rated_powers用于负荷分配
        result._rated_powers = {pid: self._pump_rated_powers.get(pid, 0) for pid in pump_ids}
        return result

    def _get_pump_h_max(self, pump_id: int) -> float:

    def find_operating_point(
        self,
        pump_ids: List[int],
        system_curve: Callable[[float], float],
        Q_range: Tuple[float, float] = (100, 5000),
        pump_frequencies: Optional[Dict[int, float]] = None  # v3.3新增
    ) -> SynthesisResult:
        """
        求解泵组与管网的交点（工作点）【v3.3增强：支持变频泵】

        Args:
            pump_ids: 运行中的泵ID列表
            system_curve: 管网曲线 Q → H_system
            Q_range: 流量搜索范围
            pump_frequencies: 各泵运行频率【v3.3新增】

        Returns:
            SynthesisResult: 工作点

        Note:
            v3.3解决P20：添加pump_frequencies参数支持变频泵
        """
        def residual(Q_total: float) -> float:
            """残差函数：泵组流量 - 假设流量"""
            H_system = system_curve(Q_total)
            # v3.3：传递pump_frequencies参数
            result = self.synthesize_heterogeneous(pump_ids, H_system, pump_frequencies)
            return result.Q_total - Q_total

        try:
            Q_op = brentq(residual, Q_range[0], Q_range[1])
            H_op = system_curve(Q_op)
            # v3.3：传递pump_frequencies参数
            return self.synthesize_heterogeneous(pump_ids, H_op, pump_frequencies)
        except ValueError as e:
            self._logger.error(f"[并联合成] 无法找到工作点: {e}")
            raise

    def synthesize_mixed(
        self,
        vfd_pump_ids: List[int],
        ss_pump_ids: List[int],
        pump_frequencies: Dict[int, float],
        H_system: float
    ) -> SynthesisResult:
        """
        混合泵组合成（变频泵+软启泵）【v3.0扩展：含功率和效率计算】

        Args:
            vfd_pump_ids: 变频泵ID列表
            ss_pump_ids: 软启泵ID列表
            pump_frequencies: 各变频泵的实际频率
            H_system: 系统扬程

        Returns:
            SynthesisResult: 合成结果（含功率和效率）

        Raises:
            HeadOutOfRangeError: 当H_system超出所有泵的有效扬程范围时抛出

        Note:
            ✅ v2.2说明问题#5：变频泵反归一化叠加的物理原理
            ✅ v3.0解决问题P2：计算pump_powers和P_total
            ✅ v3.0解决问题P4：计算eta_total
            ✅ v3.5修复P5：添加HeadOutOfRangeError扬程范围检查
        """
        # ✅ v3.5修复P5：扬程范围检查
        all_pump_ids = vfd_pump_ids + ss_pump_ids
        for pump_id in all_pump_ids:
            if pump_id in self._pump_H_ranges:
                H_min, H_max = self._pump_H_ranges[pump_id]
                # 对于变频泵，需要根据频率调整有效范围
                if pump_id in vfd_pump_ids:
                    f_actual = pump_frequencies.get(pump_id, 50.0)
                    # H ∝ f²，调整范围
                    H_min_adj = H_min * (f_actual / 50.0) ** 2
                    H_max_adj = H_max * (f_actual / 50.0) ** 2
                else:
                    H_min_adj, H_max_adj = H_min, H_max

                # v3.6修复P17：使用正确的HeadOutOfRangeError签名
                if not (H_min_adj <= H_system <= H_max_adj):
                    raise HeadOutOfRangeError(
                        message=f"泵{pump_id}扬程范围[{H_min_adj:.1f}, {H_max_adj:.1f}]m，系统扬程{H_system:.1f}m超出范围",
                        H_system=H_system,
                        H_min=H_min_adj,
                        H_max=H_max_adj,
                        pump_id=pump_id
                    )

        pump_flows = {}
        pump_powers = {}
        Q_total = 0.0
        P_total = 0.0

        # 处理变频泵（需要频率反归一化）
        for pump_id in vfd_pump_ids:
            f_actual = pump_frequencies.get(pump_id, 50.0)

            # 将系统扬程归一化到50Hz
            H_50hz = H_system * (50.0 / f_actual) ** 2

            # 在50Hz曲线上求流量
            inverse_func = self._pump_inverse_curves[pump_id]
            Q_50hz = inverse_func(H_50hz)

            # 反归一化到实际频率
            Q_actual = Q_50hz * (f_actual / 50.0)
            pump_flows[pump_id] = Q_actual
            Q_total += Q_actual

            # 【v3.2修复P5】计算功率，传递frequency参数（P ∝ f³）
            P_i = self._calculate_pump_power(pump_id, Q_actual, H_system, frequency=f_actual)
            pump_powers[pump_id] = P_i
            P_total += P_i

        # 处理软启泵（直接使用曲线，工频50Hz）
        for pump_id in ss_pump_ids:
            inverse_func = self._pump_inverse_curves[pump_id]
            Q_i = inverse_func(H_system)
            pump_flows[pump_id] = Q_i
            Q_total += Q_i

            # 【v3.0新增】计算功率（软启泵固定50Hz）
            P_i = self._calculate_pump_power(pump_id, Q_i, H_system, frequency=50.0)
            pump_powers[pump_id] = P_i
            P_total += P_i

        # 【v3.0新增】计算总效率
        eta_total = self._calculate_total_efficiency(Q_total, H_system, P_total)

        all_pump_ids = vfd_pump_ids + ss_pump_ids
        self._logger.info(
            f"[混合合成] VFD={vfd_pump_ids}, SS={ss_pump_ids}, H={H_system:.1f}m → "
            f"Q_total={Q_total:.1f}m³/h, P_total={P_total:.2f}kW, η={eta_total:.2%}"
        )

        # v3.2新增：创建结果并设置_rated_powers
        result = SynthesisResult(
            Q_total=Q_total,
            H_system=H_system,
            pump_flows=pump_flows,
            pump_heads={pid: H_system for pid in all_pump_ids},
            pump_powers=pump_powers,
            P_total=P_total,
            eta_total=eta_total
        )
        # v3.2解决P1：设置_rated_powers用于负荷分配
        result._rated_powers = {pid: self._pump_rated_powers.get(pid, 0) for pid in all_pump_ids}
        return result

    def synthesize_mixed_weighted(

            WeightedSynthesisResult: 包含功率权重信息的合成结果（含P_total和eta_total）

        Raises:
            HeadOutOfRangeError: 当H_system超出所有泵的有效扬程范围时抛出

            ✅ v3.0解决问题P2: 计算pump_powers和P_total
            ✅ v3.0解决问题P4: 计算eta_total

        rated_powers = {p['pump_id']: p['rated_power'] for p in pump_infos}

        # 2. 分类泵

        ss_infos = [p for p in pump_infos if p.get('control_type') == 'SS']

        vfd_pump_ids = [p['pump_id'] for p in vfd_infos]
        ss_pump_ids = [p['pump_id'] for p in ss_infos]

        # ✅ v3.5修复P8：扬程范围检查
        all_pump_ids = vfd_pump_ids + ss_pump_ids
        for pump_id in all_pump_ids:
            if pump_id in self._pump_H_ranges:
                H_min, H_max = self._pump_H_ranges[pump_id]
                # 对于变频泵，需要根据频率调整有效范围
                if pump_id in vfd_pump_ids:
                    f_actual = pump_frequencies.get(pump_id, 50.0)
                    # H ∝ f²，调整范围
                    H_min_adj = H_min * (f_actual / 50.0) ** 2
                    H_max_adj = H_max * (f_actual / 50.0) ** 2
                else:
                    H_min_adj, H_max_adj = H_min, H_max

                # v3.6修复P17：使用正确的HeadOutOfRangeError签名
                if not (H_min_adj <= H_system <= H_max_adj):
                    raise HeadOutOfRangeError(
                        message=f"泵{pump_id}扬程范围[{H_min_adj:.1f}, {H_max_adj:.1f}]m，系统扬程{H_system:.1f}m超出范围",
                        H_system=H_system,
                        H_min=H_min_adj,
                        H_max=H_max_adj,
                        pump_id=pump_id
                    )

        # 3. 计算各泵流量和功率
        pump_flows = {}
        pump_powers = {}
        Q_total = 0.0
        P_total = 0.0

        # 处理变频泵
        for pump_id in vfd_pump_ids:
            f_actual = pump_frequencies.get(pump_id, 50.0)
            H_50hz = H_system * (50.0 / f_actual) ** 2
            inverse_func = self._pump_inverse_curves[pump_id]
            Q_50hz = inverse_func(H_50hz)
            Q_actual = Q_50hz * (f_actual / 50.0)
            pump_flows[pump_id] = Q_actual
            Q_total += Q_actual

            # 【v3.2修复P5】计算功率，传递frequency参数
            P_i = self._calculate_pump_power(pump_id, Q_actual, H_system, frequency=f_actual)
            pump_powers[pump_id] = P_i

            inverse_func = self._pump_inverse_curves[pump_id]
            Q_i = inverse_func(H_system)
            pump_flows[pump_id] = Q_i
            Q_total += Q_i

            # 【v3.0新增】计算功率（软启泵固定50Hz）
            P_i = self._calculate_pump_power(pump_id, Q_i, H_system, frequency=50.0)
            pump_powers[pump_id] = P_i
            P_total += P_i

        # 4. 计算流量权重
        flow_weights = {pid: flow / Q_total for pid, flow in pump_flows.items()} if Q_total > 0 else {}

        # 5. 计算功率-流量比例差异
        power_flow_ratios = {}
        for pid in pump_flows.keys():
            if flow_weights.get(pid, 0) > 0:
                power_flow_ratios[pid] = power_weights[pid] / flow_weights[pid]

        # 6. 计算VFD子组统计信息
        vfd_stats = {}
        if len(vfd_infos) > 1:
            vfd_powers = [p['rated_power'] for p in vfd_infos]
            vfd_freqs = [pump_frequencies.get(p['pump_id'], 50.0) for p in vfd_infos]
            vfd_stats = {
                'power_std': float(np.std(vfd_powers)),
                'power_ratio': max(vfd_powers) / min(vfd_powers),
                'freq_std': float(np.std(vfd_freqs)),
                'freq_range': max(vfd_freqs) - min(vfd_freqs)
            }

        # 7. 【v3.0新增】计算总效率
        eta_total = self._calculate_total_efficiency(Q_total, H_system, P_total)

        self._logger.info(
            f"[加权混合合成] VFD={vfd_pump_ids}, SS={ss_pump_ids}, H={H_system:.1f}m → "
            f"Q_total={Q_total:.1f}m³/h, P_total={P_total:.2f}kW, η={eta_total:.2%}"
        )

        # v3.4修复P29：设置_rated_powers用于负荷分配计算
        result = WeightedSynthesisResult(
            Q_total=Q_total,
            H_system=H_system,
            pump_flows=pump_flows,
            pump_heads={pid: H_system for pid in pump_flows.keys()},
            pump_powers=pump_powers,
            P_total=P_total,
            eta_total=eta_total,
            power_weights=power_weights,
            flow_weights=flow_weights,
            power_flow_ratios=power_flow_ratios,
            vfd_stats=vfd_stats
        )
        result._rated_powers = rated_powers
        return result

        """获取流量分配比例"""
        return self.flow_weights.copy()

    def get_power_distribution(self) -> Dict[int, float]:
        """获取功率分配比例【v3.0新增，解决问题P14】"""
        if self.P_total <= 0:
            return {pid: 0.0 for pid in self.pump_powers}
        return {pid: P / self.P_total for pid, P in self.pump_powers.items()}

    def get_load_distribution(
        self,
        rated_powers: Optional[Dict[int, float]] = None
    ) -> Dict[int, float]:
        """
        获取负荷分配比例【v3.12修复P66：与SynthesisResult实现完全一致】

        负荷率 = 实际功率 / 额定功率

        Args:
            rated_powers: 各泵额定功率 {pump_id: P_rated}
                          如果不提供，使用内部存储的_rated_powers

        Returns:
            Dict[int, float]: 各泵负荷率 {pump_id: load_ratio}
            load_ratio = 实际功率 / 额定功率

        Note:
            v3.12修复P66：移除归一化逻辑，与SynthesisResult.get_load_distribution()保持一致
            负荷率超过1.0表示过载，低于0.3可能表示运行不经济
        """
        # v3.12修复P66：与06_数据结构.md SynthesisResult实现保持一致
        powers = rated_powers or self._rated_powers

        if powers is None or self.pump_powers is None:
            return {}

        return {
            pump_id: (self.pump_powers.get(pump_id, 0) / powers.get(pump_id, 1))
            for pump_id in self.pump_powers.keys()
            if powers.get(pump_id, 0) > 0
        }
```

    def _synthesize_for_curve(
        self,
        pump_ids: List[int],
        H_system: float,
        pump_infos: Optional[Dict[int, Dict]] = None,
        pump_frequencies: Optional[Dict[int, float]] = None
    ) -> Tuple['SynthesisResult', str]:
        """
        根据泵类型选择合适的合成方法【v3.2修复P6】

        自动判断泵组类型并选择：
        - 全VFD泵：synthesize_heterogeneous（传递pump_frequencies）
        - 全SS泵：synthesize_heterogeneous（无需频率）
        - 混合泵组：synthesize_mixed 或 synthesize_mixed_weighted

        Returns:
            Tuple[SynthesisResult, str]: (合成结果, 使用的方法名)

        Note:
            v3.2修复P6：修正synthesize_mixed和synthesize_mixed_weighted的调用参数
            v3.2修复P11：全VFD泵组传递pump_frequencies参数
        """
        if pump_infos is None:
            # 无泵信息，默认使用synthesize_heterogeneous
            return self.synthesize_heterogeneous(pump_ids, H_system, pump_frequencies), "heterogeneous"

        # 分析泵类型
        vfd_pumps = [pid for pid in pump_ids if pump_infos.get(pid, {}).get('control_type') == 'VFD']
        ss_pumps = [pid for pid in pump_ids if pump_infos.get(pid, {}).get('control_type') == 'SS']

        if len(ss_pumps) == 0:
            # 全部VFD泵：传递pump_frequencies
            return self.synthesize_heterogeneous(pump_ids, H_system, pump_frequencies), "heterogeneous_vfd"
        elif len(vfd_pumps) == 0:
            # 全部SS泵：无需频率参数
            return self.synthesize_heterogeneous(pump_ids, H_system), "heterogeneous_ss"
        else:
            # 混合泵组
            # 检查功率差异决定使用哪种混合合成方法
            rated_powers = {pid: pump_infos.get(pid, {}).get('rated_power', 55.0) for pid in pump_ids}
            power_values = list(rated_powers.values())
            power_diff = (max(power_values) - min(power_values)) / max(power_values) if max(power_values) > 0 else 0

            # 构建变频泵的频率字典
            vfd_frequencies = {pid: pump_frequencies.get(pid, 50.0) for pid in vfd_pumps} if pump_frequencies else {}

            if power_diff < 0.10:  # 功率差异<10%
                # v3.2修复P6：synthesize_mixed签名是(vfd_ids, ss_ids, frequencies, H_system)
                result = self.synthesize_mixed(vfd_pumps, ss_pumps, vfd_frequencies, H_system)
                return result, "mixed"
            else:
                # v3.2修复P6：synthesize_mixed_weighted签名是(pump_infos, frequencies, H_system)
                pump_info_list = [
                    {'pump_id': pid, 'rated_power': rated_powers[pid],
                     'control_type': 'VFD' if pid in vfd_pumps else 'SS'}
                    for pid in pump_ids
                ]
                result = self.synthesize_mixed_weighted(pump_info_list, vfd_frequencies, H_system)
                return result, "mixed_weighted"

    # ✅ v3.5修复P12：组合数量限制，防止组合爆炸
    MAX_COMBINATIONS = 100

    def _select_pumps(
        self,
        pump_ids: List[int],
        n: int,
        H_system: float,
        strategy: str,
        pump_infos: Optional[Dict[int, Dict]] = None,      # v3.3新增
        pump_frequencies: Optional[Dict[int, float]] = None  # v3.3新增
    ) -> List[int]:
        """
        根据策略选择n台泵【v3.3增强：支持变频泵，v3.5修复P12：组合数限制】

        Args:
            pump_ids: 可用泵ID列表
            n: 需要选择的泵数量
            H_system: 系统扬程
            strategy: 选择策略
            pump_infos: 泵信息字典【v3.3新增】
            pump_frequencies: 运行频率字典【v3.3新增】

        Returns:
            选中的泵ID列表

        Note:
            ✅ v3.5修复P12：当组合数超过MAX_COMBINATIONS时，
            使用启发式方法（按额定功率排序）而非遍历所有组合
        """
        if strategy == "sequential" or n >= len(pump_ids):
            return pump_ids[:n]

        # ✅ v3.5修复P12：检查组合数量，避免组合爆炸
        from itertools import combinations
        from math import comb

        total_combinations = comb(len(pump_ids), n)
        if total_combinations > self.MAX_COMBINATIONS:
            self._logger.warning(
                f"[泵选择] 组合数{total_combinations}超过限制{self.MAX_COMBINATIONS}，"
                f"使用启发式选择策略"
            )
            # 启发式：按额定功率排序，选择最优n台
            if strategy == "best_efficiency":
                # 效率最高通常是额定功率较大的泵
                sorted_pumps = sorted(
                    pump_ids,
                    key=lambda pid: self._pump_rated_powers.get(pid, 0),
                    reverse=True
                )
            else:  # lowest_power
                # 功率最低通常是额定功率较小的泵
                sorted_pumps = sorted(
                    pump_ids,
                    key=lambda pid: self._pump_rated_powers.get(pid, 0)
                )
            return sorted_pumps[:n]

        if strategy == "best_efficiency":
            # 遍历所有n泵组合，选择效率最高的
            best_combo = None
            best_eta = -1
            for combo in combinations(pump_ids, n):
                try:
                    # v3.3：使用_synthesize_for_curve支持混合泵组
                    result, _ = self._synthesize_for_curve(
                        list(combo), H_system, pump_infos, pump_frequencies
                    )
                    if result.eta_total > best_eta:
                        best_eta = result.eta_total
                        best_combo = list(combo)
                except Exception:
                    continue
            return best_combo if best_combo else pump_ids[:n]

        if strategy == "lowest_power":
            # 遍历所有n泵组合，选择功率最低的
            best_combo = None
            best_power = float('inf')
            for combo in combinations(pump_ids, n):
                try:
                    # v3.3：使用_synthesize_for_curve支持混合泵组
                    result, _ = self._synthesize_for_curve(
                        list(combo), H_system, pump_infos, pump_frequencies
                    )
                    if result.P_total < best_power:
                        best_power = result.P_total
                        best_combo = list(combo)
                except Exception:
                    continue
            return best_combo if best_combo else pump_ids[:n]

        # 未知策略，回退到顺序选择
        return pump_ids[:n]
```

### 3.7 分析方法【v3.0增强：比能耗曲线生成】

```python
    def calculate_specific_energy(
        self,
        pump_ids: List[int],
        H_system: float
    ) -> float:
        """
        计算比能耗（Specific Energy Consumption）

        Args:
            pump_ids: 运行泵ID列表
            H_system: 系统扬程 (m)

        Returns:
            比能耗 (kWh/m³)

        公式:
            SEC = P_total / Q_total
            其中P单位为kW，Q单位为m³/h
            结果单位：kW / (m³/h) = kWh / m³
        """
        result = self.synthesize_heterogeneous(pump_ids, H_system)

        if result.Q_total <= 0:
            self._logger.warning("[比能耗] Q_total=0，无法计算比能耗")
            return float('inf')

        sec = result.P_total / result.Q_total
        self._logger.info(
            f"[比能耗] pumps={pump_ids}, H={H_system:.1f}m, "
            f"P={result.P_total:.2f}kW, Q={result.Q_total:.1f}m³/h → "
            f"SEC={sec:.4f} kWh/m³"
        )
        return sec

    def generate_specific_energy_curve(
        self,
        pump_ids: List[int],
        H_range: Tuple[float, float] = (20, 60),
        step: float = 2.0,
        pump_frequencies: Optional[Dict[int, float]] = None  # v3.3新增
    ) -> Dict[str, Any]:
        """
        生成比能耗曲线【v3.3增强：支持变频泵】

        扫描扬程范围，生成SEC随H变化的曲线。

        Args:
            pump_ids: 运行泵ID列表
            H_range: 扬程扫描范围 (m)

            Dict: {
                "curve_data": [{H, Q, P, SEC}, ...],
                "min_sec": {H, Q, P, SEC},

                "pump_ids": List[int]
            }

        Note:
            v3.3解决P23：添加pump_frequencies参数支持变频泵
        """
        import numpy as np

        curve_data = []
        H_values = np.arange(H_range[0], H_range[1] + step, step)

        for H in H_values:
            try:
                # v3.3：传递pump_frequencies参数
                result = self.synthesize_heterogeneous(pump_ids, float(H), pump_frequencies)
                if result.Q_total > 0:
                    sec = result.P_total / result.Q_total
                    curve_data.append({
                        "H": float(H),
                        "Q": result.Q_total,
                        "P": result.P_total,
                        "SEC": sec
                    })
            except Exception as e:
                self._logger.debug(f"[比能耗曲线] H={H:.1f}m 计算失败: {e}")
                continue

        if not curve_data:
            return {"curve_data": [], "min_sec": None, "avg_sec": None, "pump_ids": pump_ids}

        # 找到最低比能耗点
        min_sec_point = min(curve_data, key=lambda x: x["SEC"])
        avg_sec = sum(p["SEC"] for p in curve_data) / len(curve_data)

        self._logger.info(
            f"[比能耗曲线] pumps={pump_ids}, "
            f"min_SEC={min_sec_point['SEC']:.4f}@H={min_sec_point['H']:.1f}m, "
            f"avg_SEC={avg_sec:.4f}"
        )

        # v3.7修复P30：添加generated_at字段与04文档一致
        from datetime import datetime
        return {
            "curve_data": curve_data,
            "min_sec": min_sec_point,
            "avg_sec": avg_sec,
            "pump_ids": pump_ids,
            "H_range": list(H_range),
            "unit_sec": "kWh/m³",
            "generated_at": datetime.now().isoformat()  # v3.7修复P30
        }

            >>> result = synthesizer.find_optimal_region([1,2,3], (25,50), 0.75)
            >>> for pt in result['region_points']:
            ...     print(f"H={pt['H']:.1f}m, Q={pt['Q']:.1f}m³/h, η={pt['eta']:.2%}")
        """
        import numpy as np

        region_points = []
        H_values = np.arange(H_range[0], H_range[1] + step, step)
        bep = {'H': 0.0, 'Q': 0.0, 'eta': 0.0}

        for H in H_values:
            try:
                # v3.3：传递pump_frequencies参数
                result = self.synthesize_heterogeneous(pump_ids, H, pump_frequencies)
                if result.eta_total >= efficiency_threshold:
                    region_points.append({
                        'H': float(H),
                        'Q': result.Q_total,
                        'eta': result.eta_total
                    })
                # 同时追踪BEP
                if result.eta_total > bep['eta']:
                    bep = {'H': float(H), 'Q': result.Q_total, 'eta': result.eta_total}
            except Exception as e:
                self._logger.debug(f"[最优区域] H={H:.1f}m 计算失败: {e}")
                continue

        # 计算边界
        boundary = {'H_min': 0.0, 'H_max': 0.0, 'Q_min': 0.0, 'Q_max': 0.0}
        if region_points:
            boundary = {
                'H_min': min(pt['H'] for pt in region_points),
                'H_max': max(pt['H'] for pt in region_points),
                'Q_min': min(pt['Q'] for pt in region_points),
                'Q_max': max(pt['Q'] for pt in region_points)
            }

        self._logger.info(
            f"[最优区域] pumps={pump_ids}, η≥{efficiency_threshold:.0%}, "
            f"找到 {len(region_points)} 个高效运行点"
        )

        # v3.7修复P28：添加generated_at字段与04文档一致
        from datetime import datetime
        return {
            'region_points': region_points,
            'bep': bep,
            'boundary': boundary,
            'efficiency_threshold': efficiency_threshold,
            'pump_ids': pump_ids,
            'H_range': list(H_range),
            'generated_at': datetime.now().isoformat()  # v3.7修复P28
        }

    def find_best_efficiency_point(
        self,
        pump_ids: List[int],
        H_range: Tuple[float, float] = (20, 60),
        step: float = 0.5,
        pump_frequencies: Optional[Dict[int, float]] = None  # v3.3新增
    ) -> Tuple[float, float, float]:
        """
        找到泵组最佳效率点（BEP）【v3.3增强：支持变频泵】

        Args:
            pump_ids: 运行泵ID列表
            H_range: 扬程扫描范围 (m)
            step: 扫描步长 (m)
            pump_frequencies: 各泵运行频率【v3.3新增】

        Returns:
            (H_bep, Q_bep, η_max): 最佳效率点
        """
        import numpy as np

        best_point = (0.0, 0.0, 0.0)
        H_values = np.arange(H_range[0], H_range[1] + step, step)

        for H in H_values:
            try:
                # v3.3：传递pump_frequencies参数
                result = self.synthesize_heterogeneous(pump_ids, H, pump_frequencies)
                if result.eta_total > best_point[2]:
                    best_point = (H, result.Q_total, result.eta_total)
            except Exception:
                continue

        self._logger.info(
            f"[最佳效率点] pumps={pump_ids}, "
            f"BEP: H={best_point[0]:.1f}m, Q={best_point[1]:.1f}m³/h, η={best_point[2]:.2%}"
        )
        return best_point
```

## 4. SystemCorrectionModel（系统修正模型）

### 4.1 修正原理

```
修正公式：H_actual = H_theoretical × α(N, Q_total)

其中：
- H_actual: 实际扬程
- H_theoretical: 理论合成扬程
- α: 修正系数（依赖台数N和流量Q_total）

模型类型：
- linear: α = a₀ + a₁N + a₂Q
- polynomial: α = a₀ + a₁N + a₂Q + a₃N² + a₄Q² + a₅NQ
- xgboost: XGBoost回归
```

### 4.2 类设计

```python
from dataclasses import dataclass, field
from typing import Literal, List, Dict, Any, Optional, Tuple
import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import Ridge
import logging


@dataclass
class CorrectionModelConfig:
    """修正模型配置"""
    model_type: Literal['linear', 'polynomial', 'xgboost'] = 'polynomial'
    polynomial_degree: int = 2
    regularization_alpha: float = 1.0
    min_training_points: int = 100
    validation_ratio: float = 0.2


class SystemCorrectionModel:
    """
    系统修正系数模型

    职责：
    1. 从历史数据学习修正系数
    2. 预测给定(N, Q_total)下的修正系数
    3. 应用修正系数到理论扬程
    """

    def __init__(self, config: Optional[CorrectionModelConfig] = None):
        self._config = config or CorrectionModelConfig()
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")

        # 模型状态
        self._is_fitted = False
        self._model = None
        self._poly_features = None
        self._training_info: Dict[str, Any] = {}
        self._coefficients: Dict[str, Any] = {}
        self._valid_range: Dict[str, Tuple[float, float]] = {}
        self._extra_features: Optional[Dict[str, Any]] = None  # v2.5新增

    # ══════════════════════════════════════════════════════════════════════════
    # 📋 训练数据获取规则【v3.12新增】
    # ──────────────────────────────────────────────────────────────────────────
    # 修正模型需要从历史运行数据中学习，训练数据获取规则如下：
    #
    # 1. **数据来源**：public.fact_measurements 表
    #    - 该表存储所有设备的实时运行数据
    #    - 通过 station_id 和 pump_ids 筛选泵组数据
    #
    # 2. **时间范围**：
    #    - 默认使用最近30天的数据
    #    - 可通过 training_start_time 和 training_end_time 参数自定义
    #    - 建议至少包含7天数据以覆盖不同工况
    #
    # 3. **所需字段**：
    #    - ts_bucket: 时间戳
    #    - device_id: 设备ID（用于识别泵）
    #    - flow_rate: 流量 (m³/h)
    #    - outlet_pressure / inlet_pressure: 出口/进口压力（计算扬程）
    #    - frequency: 运行频率（变频泵）
    #    - power: 实际功率 (kW)
    #
    # 4. **数据处理**：
    #    - 按时间戳分组，计算每个时刻的泵组工况：
    #      - N: 运行泵台数（flow_rate > 0 的泵数量）
    #      - Q_total: 总流量 = Σ flow_rate
    #      - H_actual: 实际扬程 = (outlet_pressure - inlet_pressure) / (ρg)
    #    - 通过 ParallelSynthesizer 计算理论扬程 H_theoretical
    #
    # 5. **最小数据量**：
    #    - 默认要求至少 100 个有效数据点（min_training_points）
    #    - 数据不足时抛出 CorrectionModelTrainingError
    #
    # 6. **数据质量要求**：
    #    - 过滤异常值（扬程 < 0 或 > 100m）
    #    - 过滤流量为0的停机状态
    #    - 过滤频率过低的启动/停止过渡态
    # ══════════════════════════════════════════════════════════════════════════

    def set_model_type(self, model_type: Literal['linear', 'polynomial', 'xgboost']) -> None:
        """
        动态设置模型类型（v2.5新增，解决问题#10）

        Args:
            model_type: 模型类型 ('linear' | 'polynomial' | 'xgboost')

        Note:
            允许在运行时切换模型类型，用于混合泵组场景需要使用XGBoost的情况。
            调用此方法会重置模型状态。
        """
        if model_type not in ('linear', 'polynomial', 'xgboost'):
            raise ValueError(f"不支持的模型类型: {model_type}")

        self._config.model_type = model_type
        self._is_fitted = False
        self._model = None
        self._poly_features = None
        self._logger.info(f"[修正模型] 模型类型切换为: {model_type}")

    def fit(
        self,
        station_id: int,
        pump_ids: List[int],
        training_data: Optional[np.ndarray] = None,
        extra_features: Optional[Dict[str, Any]] = None
    ) -> 'SystemCorrectionModel':
        """
        训练修正模型（v2.0: 不使用默认值，直接抛异常；v2.5: 新增extra_features参数）

        Args:
            station_id: 泵站ID
            pump_ids: 泵ID列表
            training_data: 训练数据 [N, Q_total, H_theoretical, H_actual]
            extra_features: 扩展特征字典（v2.5新增，解决问题#11）
                用于MIXED_HETEROGENEOUS场景，传入功率权重、频率差异等特征

        Returns:
            self: 支持链式调用

        Raises:
            CorrectionModelTrainingError: 训练数据不足或训练失败时抛出

        Note:
            ✅ v2.0修复问题#12: 不使用默认α=1.0，直接抛异常
            ✅ v2.5修复问题#11: 添加extra_features参数支持
        """
        # 存储扩展特征用于后续分析
        self._extra_features = extra_features
        # ✅ v2.0: 无数据直接抛异常
        if training_data is None or len(training_data) == 0:
            error = CorrectionModelTrainingError(
                message=f"修正模型训练失败：无训练数据",
                station_id=station_id,
                pump_ids=pump_ids,
                reason="no_training_data",
                actual_points=0,
                min_points=self._config.min_training_points
            )
            self._logger.error(error.to_log_format())
            raise error

        # ✅ v2.0: 数据不足直接抛异常（不使用警告+继续）
        if len(training_data) < self._config.min_training_points:
            error = CorrectionModelTrainingError(
                message=f"修正模型训练失败：数据不足",
                station_id=station_id,
                pump_ids=pump_ids,
                reason="insufficient_data",
                actual_points=len(training_data),
                min_points=self._config.min_training_points
            )
            self._logger.error(error.to_log_format())
            raise error

        # 提取特征和目标
        N = training_data[:, 0]
        Q = training_data[:, 1]
        H_theo = training_data[:, 2]
        H_actual = training_data[:, 3]

        # 计算修正系数 α = H_actual / H_theoretical
        alpha = H_actual / np.maximum(H_theo, 1e-6)

        # 构建特征矩阵
        X = np.column_stack([N, Q])

        if self._config.model_type == 'polynomial':
            self._poly_features = PolynomialFeatures(
                degree=self._config.polynomial_degree,
                include_bias=True
            )
            X_poly = self._poly_features.fit_transform(X)

            # 岭回归
            self._model = Ridge(alpha=self._config.regularization_alpha)
            self._model.fit(X_poly, alpha)

            self._coefficients = {
                "intercept": float(self._model.intercept_),
                "coef": self._model.coef_.tolist()
            }

        # 记录训练信息
        self._valid_range = {
            "N_min": int(N.min()),
            "N_max": int(N.max()),
            "Q_min": float(Q.min()),
            "Q_max": float(Q.max())
        }

        alpha_pred = self.predict(N, Q)
        r2 = 1 - np.sum((alpha - alpha_pred)**2) / np.sum((alpha - alpha.mean())**2)

        self._training_info = {
            "data_points": len(training_data),
            "train_r2": float(r2),
            "trained_at": str(np.datetime64('now'))
        }

        self._is_fitted = True
        self._logger.info(f"[修正模型] 训练完成，R²={r2:.4f}")
        return self

    def predict(self, N: np.ndarray, Q: np.ndarray) -> np.ndarray:
        """
        预测修正系数

        Args:
            N: 运行台数数组
            Q: 总流量数组

        Returns:
            alpha: 修正系数数组
        """
        if not self._is_fitted:
            return np.ones_like(N, dtype=float)

        X = np.column_stack([N, Q])

        if self._config.model_type == 'polynomial' and self._poly_features:
            X_poly = self._poly_features.transform(X)
            return self._model.predict(X_poly)

        # 默认返回1.0
        return np.ones_like(N, dtype=float)

    def apply_correction(
        self,
        H_theoretical: float,
        N: int,
        Q_total: float
    ) -> float:
        """
        应用修正系数

        Args:
            H_theoretical: 理论扬程
            N: 运行台数
            Q_total: 总流量

        Returns:
            H_actual: 修正后扬程
        """
        alpha = self.predict(np.array([N]), np.array([Q_total]))[0]
        return H_theoretical * alpha

    def to_dict(self) -> Dict[str, Any]:
        """转换为字典（用于数据库存储）"""
        return {
            "model_type": self._config.model_type,
            "is_fitted": self._is_fitted,
            "training_info": self._training_info,
            "coefficients": self._coefficients,
            "valid_range": self._valid_range,
            "config": {
                "polynomial_degree": self._config.polynomial_degree,
                "regularization_alpha": self._config.regularization_alpha,
                "min_training_points": self._config.min_training_points,
                "validation_ratio": self._config.validation_ratio
            }
        }
```

-- 覆盖泵组中任意子集组合的运行数据

WITH pump_group AS (
    -- 定义泵组组成
    SELECT ARRAY[101, 102, 201]::int[] AS group_pumps
),
-- 获取指标ID（避免硬编码）
metric_ids AS (
    SELECT
        MAX(CASE WHEN metric_key = 'device_running' THEN id END) AS running_id,
        MAX(CASE WHEN metric_key = 'pump_flow_rate' THEN id END) AS flow_id,
        MAX(CASE WHEN metric_key = 'main_pipeline_outlet_pressure' THEN id END) AS pressure_id
    FROM dim_metric_config
),
-- 获取每个时间桶内各泵的运行状态和流量
pump_metrics AS (
    SELECT
        fm.ts_bucket,
        fm.device_id,
        MAX(CASE WHEN fm.metric_id = mi.running_id THEN fm.value END) AS running,
        MAX(CASE WHEN fm.metric_id = mi.flow_id THEN fm.value END) AS flow
    FROM fact_measurements fm
    CROSS JOIN metric_ids mi
    JOIN dim_devices dd ON fm.device_id = dd.id
    WHERE dd.station_id = 1
      AND fm.device_id = ANY(ARRAY[101, 102, 201])
      AND fm.ts_bucket BETWEEN '2025-01-01' AND '2025-12-01'
      AND fm.metric_id IN (mi.running_id, mi.flow_id)
    GROUP BY fm.ts_bucket, fm.device_id
),
-- 获取总管出口压力（泵站级别指标）
station_pressure AS (
    SELECT
        fm.ts_bucket,
        fm.value * 10.2 AS H_actual  -- MPa → m
    FROM fact_measurements fm
    CROSS JOIN metric_ids mi
    JOIN dim_devices dd ON fm.device_id = dd.id
    WHERE dd.station_id = 1
      AND fm.metric_id = mi.pressure_id
      AND fm.ts_bucket BETWEEN '2025-01-01' AND '2025-12-01'
      AND fm.value > 0
),
-- 聚合：按时间桶汇总运行泵列表和总流量
aggregated AS (
    SELECT
        pm.ts_bucket,
        array_agg(pm.device_id ORDER BY pm.device_id)
            FILTER (WHERE pm.running = 1) AS running_pumps,
        COUNT(*) FILTER (WHERE pm.running = 1) AS N,
        COALESCE(SUM(pm.flow) FILTER (WHERE pm.running = 1), 0) AS Q_total,
        sp.H_actual
    FROM pump_metrics pm
    JOIN station_pressure sp ON pm.ts_bucket = sp.ts_bucket
    GROUP BY pm.ts_bucket, sp.H_actual
    HAVING COUNT(*) FILTER (WHERE pm.running = 1) >= 1
),
-- 筛选：运行泵是目标泵组的子集
valid_records AS (
    SELECT running_pumps, N, Q_total, H_actual
    FROM aggregated ag
    CROSS JOIN pump_group pg
    WHERE ag.running_pumps <@ pg.group_pumps  -- ✅ 关键：运行泵是泵组子集
      AND ag.running_pumps && pg.group_pumps  -- 至少有1台泵在运行
      AND ag.Q_total > 0
)
SELECT running_pumps, N, Q_total, H_actual
FROM valid_records
ORDER BY Q_total;

### 4.4 MIXED_HETEROGENEOUS场景训练数据要求（v2.4新增）

> **✅ v2.4解决问题#5**：明确MIXED_HETEROGENEOUS场景的训练数据覆盖要求

#### 4.4.1 组合爆炸问题

对于N台泵的MIXED_HETEROGENEOUS泵组，需要覆盖的组合数为 **2^N - 1** 种：

| 泵组规模 | 组合数 | 示例（3台泵：VFD1, VFD2, SS1） |
|:-------:|:------:|------------------------------|
| N=2 | 3 | {VFD1}, {SS1}, {VFD1,SS1} |
| N=3 | 7 | {VFD1}, {VFD2}, {SS1}, {VFD1,VFD2}, {VFD1,SS1}, {VFD2,SS1}, {VFD1,VFD2,SS1} |
| N=4 | 15 | ... |
| N=5 | 31 | ... |

#### 4.4.2 最低数据要求

```python
# MIXED_HETEROGENEOUS场景的训练数据要求
MIN_POINTS_PER_COMBINATION = 50   # 每种组合最少50条记录
MIN_TOTAL_POINTS = 500            # 总数据量最少500条
RECOMMENDED_POINTS = 1000         # 推荐数据量

def validate_training_data_coverage(
    pump_ids: List[int],
    training_data: pd.DataFrame
) -> Dict[str, Any]:
    """
    验证训练数据覆盖率

    Returns:
        {
            'is_valid': bool,
            'coverage_ratio': float,
            'missing_combinations': List[Set[int]],
            'low_count_combinations': List[Tuple[Set[int], int]]
        }
    """
    from itertools import combinations

    # 生成所有可能的组合
    all_combinations = []
    for r in range(1, len(pump_ids) + 1):
        all_combinations.extend(combinations(pump_ids, r))

    # 统计每种组合的数据量
    combination_counts = {}
    for comb in all_combinations:
        comb_set = frozenset(comb)
        count = len(training_data[
            training_data['running_pumps'].apply(lambda x: set(x) == comb_set)
        ])
        combination_counts[comb_set] = count

    # 检查覆盖率
    covered = sum(1 for c in combination_counts.values() if c >= MIN_POINTS_PER_COMBINATION)
    coverage_ratio = covered / len(all_combinations)

    missing = [c for c, cnt in combination_counts.items() if cnt == 0]
    low_count = [(c, cnt) for c, cnt in combination_counts.items()
                 if 0 < cnt < MIN_POINTS_PER_COMBINATION]

    return {
        'is_valid': coverage_ratio >= 0.8 and len(missing) == 0,
        'coverage_ratio': coverage_ratio,
        'missing_combinations': missing,
        'low_count_combinations': low_count
    }
```

### 4.5 XGBoost扩展特征（v2.4新增）

> **✅ v2.4解决问题#6**：为MIXED_HETEROGENEOUS场景扩展XGBoost特征

#### 4.5.1 标准特征 vs 扩展特征

| 特征类别 | 标准特征（MIXED_GROUP） | 扩展特征（MIXED_HETEROGENEOUS） |
|---------|------------------------|--------------------------------|
| 基础 | `n_pumps`, `Q_total` | ✅ 相同 |
| 分类 | `vfd_count`, `ss_count` | ✅ 相同 |
| 功率差异 | - | `power_max`, `power_min`, `power_ratio`, `power_std` |
| VFD频率 | `avg_freq` | `vfd_freq_mean`, `vfd_freq_std`, `vfd_freq_range` |
| VFD功率 | - | `vfd_power_ratio`, `vfd_power_std` |
| 交互项 | - | `power_freq_interaction` |

#### 4.5.2 特征工程实现

```python
def prepare_features_mixed_heterogeneous(
    pump_infos: List[Dict[str, Any]],
    frequencies: Dict[int, float],
    Q_total: float
) -> Dict[str, float]:
    """
    为MIXED_HETEROGENEOUS场景准备XGBoost特征（v2.4新增）

    解决问题#6：扩展特征以捕捉功率差异对修正系数的影响
    """
    import numpy as np

    powers = [p['rated_power'] for p in pump_infos]
    vfd_infos = [p for p in pump_infos if p['control_type'] == 'VFD']
    ss_infos = [p for p in pump_infos if p['control_type'] == 'SS']

    # 基础特征
    features = {
        'n_pumps': len(pump_infos),
        'Q_total': Q_total,
        'vfd_count': len(vfd_infos),
        'ss_count': len(ss_infos),
    }

    # ✅ 功率差异特征（问题#6核心）
    features.update({
        'power_max': max(powers),
        'power_min': min(powers),
        'power_ratio': max(powers) / min(powers),
        'power_std': float(np.std(powers)),
        'power_range': max(powers) - min(powers),
    })

    # ✅ VFD频率特征
    if vfd_infos:
        vfd_freqs = [frequencies.get(p['pump_id'], 50.0) for p in vfd_infos]
        features.update({
            'vfd_freq_mean': float(np.mean(vfd_freqs)),
            'vfd_freq_std': float(np.std(vfd_freqs)) if len(vfd_freqs) > 1 else 0.0,
            'vfd_freq_range': max(vfd_freqs) - min(vfd_freqs) if len(vfd_freqs) > 1 else 0.0,
            'vfd_freq_min': min(vfd_freqs),
            'vfd_freq_max': max(vfd_freqs),
        })
    else:
        features.update({
            'vfd_freq_mean': 50.0,
            'vfd_freq_std': 0.0,
            'vfd_freq_range': 0.0,
            'vfd_freq_min': 50.0,
            'vfd_freq_max': 50.0,
        })

    # ✅ VFD功率特征（问题#3相关）
    if len(vfd_infos) > 1:
        vfd_powers = [p['rated_power'] for p in vfd_infos]
        features.update({
            'vfd_power_ratio': max(vfd_powers) / min(vfd_powers),
            'vfd_power_std': float(np.std(vfd_powers)),
        })
    else:
        features.update({
            'vfd_power_ratio': 1.0,
            'vfd_power_std': 0.0,
        })

    # ✅ 交互特征
    features['power_freq_interaction'] = features['power_ratio'] * features['vfd_freq_std']

    return features

### 3.8 NPSH检查与气蚀防护【v3.17新增 P9修复】

> ⚠️ **重要警告**：泵组运行必须确保各泵NPSH安全，否则可能发生气蚀损坏

#### 3.8.1 NPSH基本概念

```
NPSH（Net Positive Suction Head）有效吸入压头

- NPSH_available（装置有效吸入压头）：系统提供的吸入压头
  NPSH_a = (P_atm - P_vapor) / (ρg) + H_geo - h_loss
  
- NPSH_required（必需吸入压头）：泵运行所需的最小吸入压头
  由泵制造商提供，一般随流量变化

安全条件：NPSH_a > NPSH_r + 0.5m（安全余量）
```

#### 3.8.2 并联泵组的NPSH问题

**问题场景**：
1. **多泵启动瞬间**：吸入管压力降低，NPSH_a减小
2. **流量增加时**：每台泵的NPSH_r随流量增加
3. **异构泵组**：大功率泵的NPSH_r通常更高
4. **变频运行**：低频时NPSH_r降低，但吸入管流速也降低

#### 3.8.3 NPSH检查实现

```python
from typing import Dict, List, Tuple, Optional
from dataclasses import dataclass
import logging


@dataclass
class NPSHCheckResult:
    """
    NPSH检查结果
    
    字段：
        is_safe: 是否安全
        pump_npsh_status: 各泵NPSH状态
        min_margin: 最小安全余量
        warning_pumps: 告警泵列表
    """
    is_safe: bool
    pump_npsh_status: Dict[int, Dict[str, float]]
    min_margin: float
    warning_pumps: List[int]


class NPSHChecker:
    """
    NPSH检查器
    
    职责：
    1. 计算装置NPSH_a
    2. 查询各泵NPSH_r曲线
    3. 检查安全余量
    4. 变频运行NPSH_r修正
    """
    
    # 物理常数
    P_ATM = 101325  # 标准大气压 Pa
    RHO = 1000      # 水密度 kg/m³
    G = 9.81        # 重力加速度 m/s²
    
    def __init__(self, safety_margin: float = 0.5):
        """
        Args:
            safety_margin: NPSH安全余量 (m)，默认0.5m
        """
        self._safety_margin = safety_margin
        self._npsh_r_curves: Dict[int, callable] = {}  # pump_id → NPSH_r(Q)
        self._logger = logging.getLogger(f"{__name__}.{self.__class__.__name__}")
    
    def register_npsh_curve(
        self,
        pump_id: int,
        npsh_r_func: callable
    ):
        """
        注册NPSH_r曲线
        
        Args:
            pump_id: 泵ID
            npsh_r_func: Q → NPSH_r 函数
        """
        self._npsh_r_curves[pump_id] = npsh_r_func
    
    def calculate_npsh_available(
        self,
        station_id: int,
        water_temp: float = 20.0,
        suction_level: Optional[float] = None
    ) -> float:
        """
        计算装置NPSH_a
        
        Args:
            station_id: 泵站ID
            water_temp: 水温 ℃（影响饱和蒸气压）
            suction_level: 吸入液位 (m)，None时从数据库查询
        
        Returns:
            NPSH_a (m)
        """
        # 水的饱和蒸气压（简化计算）
        P_vapor = self._get_vapor_pressure(water_temp)
        
        # 从数据库查询吸入液位
        if suction_level is None:
            suction_level = self._query_suction_level(station_id)
        
        # 简化计算：忽略吸入管损失
        # 实际工程中应考虑管道摩擦损失和局部损失
        NPSH_a = (self.P_ATM - P_vapor) / (self.RHO * self.G) + suction_level
        
        self._logger.debug(
            f"[NPSH] station={station_id}, T={water_temp}℃, "
            f"P_vapor={P_vapor}Pa, suction={suction_level}m → NPSH_a={NPSH_a:.2f}m"
        )
        
        return NPSH_a
    
    def check_pump_group(
        self,
        pump_flows: Dict[int, float],
        npsh_available: float,
        pump_frequencies: Optional[Dict[int, float]] = None
    ) -> NPSHCheckResult:
        """
        检查泵组NPSH安全性
        
        Args:
            pump_flows: 各泵流量 {pump_id: Q}
            npsh_available: 装置NPSH_a
            pump_frequencies: 各泵运行频率（用于变频泵NPSH_r修正）
        
        Returns:
            NPSHCheckResult: 检查结果
        """
        pump_status = {}
        warning_pumps = []
        min_margin = float('inf')
        
        for pump_id, Q in pump_flows.items():
            if pump_id not in self._npsh_r_curves:
                self._logger.warning(f"[NPSH] 泵{pump_id}未注册NPSH_r曲线，跳过检查")
                continue
            
            # 获徖基准NPSH_r
            npsh_r_base = self._npsh_r_curves[pump_id](Q)
            
            # 变频修正：NPSH_r ∝ (f/50)²
            freq = pump_frequencies.get(pump_id, 50.0) if pump_frequencies else 50.0
            npsh_r = npsh_r_base * (freq / 50.0) ** 2
            
            # 计算安全余量
            margin = npsh_available - npsh_r
            is_safe = margin >= self._safety_margin
            
            pump_status[pump_id] = {
                'Q': Q,
                'freq': freq,
                'NPSH_r': npsh_r,
                'NPSH_a': npsh_available,
                'margin': margin,
                'is_safe': is_safe
            }
            
            if margin < min_margin:
                min_margin = margin
            
            if not is_safe:
                warning_pumps.append(pump_id)
                self._logger.warning(
                    f"[NPSH告警] 泵{pump_id} NPSH余量不足: "
                    f"margin={margin:.2f}m < {self._safety_margin}m"
                )
        
        return NPSHCheckResult(
            is_safe=len(warning_pumps) == 0,
            pump_npsh_status=pump_status,
            min_margin=min_margin,
            warning_pumps=warning_pumps
        )
    
    def _get_vapor_pressure(self, temp_c: float) -> float:
        """获取水的饱和蒸气压 (Pa)"""
        # 简化公式（Antoine方程近似）
        # 温度范围: 0-100℃
        if temp_c < 0:
            temp_c = 0
        elif temp_c > 100:
            temp_c = 100
        
        # 查表法简化（常用温度点）
        vapor_table = {
            0: 611, 10: 1228, 20: 2338, 30: 4242, 
            40: 7375, 50: 12335, 60: 19920, 70: 31160
        }
        
        # 线性插值
        lower_temp = int(temp_c // 10) * 10
        upper_temp = min(lower_temp + 10, 70)
        
        if lower_temp >= 70:
            return vapor_table[70]
        
        ratio = (temp_c - lower_temp) / 10
        return vapor_table[lower_temp] + ratio * (vapor_table[upper_temp] - vapor_table[lower_temp])
    
    def _query_suction_level(self, station_id: int) -> float:
        """从数据库查询吸入液位"""
        from app.adapters.db.pool import get_connection
        
        sql = """
            SELECT fm.value AS level
            FROM fact_measurements fm
            WHERE fm.device_id IN (
                SELECT id FROM dim_devices WHERE station_id = %(station_id)s
            )
            AND fm.metric_id = (
                SELECT id FROM dim_metric_config 
                WHERE metric_key = 'pool_liquid_level'
            )
            ORDER BY fm.ts_raw DESC
            LIMIT 1
        """
        
        with get_connection() as conn:
            result = conn.execute(sql, {'station_id': station_id}).fetchone()
            if result:
                return float(result['level'])
        
        # 默认值：假设正压吸入
        self._logger.warning(f"[NPSH] 泵站{station_id}无吸入液位数据，使用默认值5m")
        return 5.0
```

#### 3.8.4 在ParallelSynthesizer中集成NPSH检查

```python
class ParallelSynthesizer:
    def __init__(self):
        # ... 现有初始化 ...
        self._npsh_checker = NPSHChecker(safety_margin=0.5)
    
    def synthesize_with_npsh_check(
        self,
        pump_ids: List[int],
        H_system: float,
        station_id: int,
        pump_frequencies: Optional[Dict[int, float]] = None
    ) -> Tuple['SynthesisResult', NPSHCheckResult]:
        """
        并联合成并检查NPSH安全性
        
        Returns:
            (SynthesisResult, NPSHCheckResult)
        """
        # 1. 执行标准合成
        result = self.synthesize_heterogeneous(
            pump_ids, H_system, pump_frequencies
        )
        
        # 2. 计算NPSH_a
        npsh_a = self._npsh_checker.calculate_npsh_available(station_id)
        
        # 3. 检查各泵NPSH
        npsh_result = self._npsh_checker.check_pump_group(
            pump_flows=result.pump_flows,
            npsh_available=npsh_a,
            pump_frequencies=pump_frequencies
        )
        
        if not npsh_result.is_safe:
            self._logger.warning(
                f"[NPSH告警] 泵组NPSH不安全，"
                f"告警泵: {npsh_result.warning_pumps}"
            )
        
        return result, npsh_result
```

## 附录1：XGBoost修正模型实现（v2.1新增）

> 用于MIXED_GROUP和MIXED_HETEROGENEOUS场景，提升复杂泵组的修正精度

```python
class XGBoostCorrectionModel:
    """
    XGBoost修正模型
    
    适用场景：
    - MIXED_GROUP: VFD+SS混合泵组
    - MIXED_HETEROGENEOUS: VFD+SS混合且功率差异大
    
    优势：
    - 支持非线性关系
    - 可纳入扩展特征（功率权重、频率差异等）
    - 拗异常值
    """
    
    def __init__(self, config: Optional[Dict] = None):
        self._config = config or {
            'n_estimators': 100,
            'max_depth': 4,
            'learning_rate': 0.1,
            'min_child_weight': 5,
            'reg_alpha': 0.1,
            'reg_lambda': 1.0
        }
        self._model = None
        self._feature_names = []
        self._is_fitted = False
    
    def fit(
        self,
        training_data: np.ndarray,
        extra_features: Optional[Dict[str, Any]] = None
    ) -> 'XGBoostCorrectionModel':
        """
        训练XGBoost修正模型
        
        Args:
            training_data: [N, Q_total, H_theoretical, H_actual]
            extra_features: 扩展特征字典
                - power_weights: 功率权重
                - vfd_power_diff: VFD子组功率差异
                - vfd_freq_diff: VFD子组频率差异
        """
        import xgboost as xgb
        
        N = training_data[:, 0]
        Q = training_data[:, 1]
        H_theo = training_data[:, 2]
        H_actual = training_data[:, 3]
        
        # 计算修正系数
        alpha = H_actual / np.maximum(H_theo, 1e-6)
        
        # 构建特征矩阵
        features = [N, Q, H_theo]
        self._feature_names = ['N', 'Q_total', 'H_theo']
        
        if extra_features:
            if 'vfd_power_diff' in extra_features:
                features.append(np.full_like(N, extra_features['vfd_power_diff']))
                self._feature_names.append('vfd_power_diff')
            if 'vfd_freq_diff' in extra_features:
                features.append(np.full_like(N, extra_features['vfd_freq_diff']))
                self._feature_names.append('vfd_freq_diff')
        
        X = np.column_stack(features)
        
        # 训练
        self._model = xgb.XGBRegressor(**self._config)
        self._model.fit(X, alpha)
        self._is_fitted = True
        
        return self
    
    def predict(self, N, Q, H_theo, extra_features=None) -> np.ndarray:
        """预测修正系数"""
        if not self._is_fitted:
            return np.ones_like(N, dtype=float)
        
        features = [N, Q, H_theo]
        
        if extra_features and 'vfd_power_diff' in extra_features:
            features.append(np.full_like(N, extra_features['vfd_power_diff']))
        if extra_features and 'vfd_freq_diff' in extra_features:
            features.append(np.full_like(N, extra_features['vfd_freq_diff']))
        
        X = np.column_stack(features)
        return self._model.predict(X)
```

修正器工作流程：

1. 训练阶段：
   ─ 提取历史运行数据 [N, Q, H_theo, H_actual]
   ─ 计算修正系数 α = H_actual / H_theo
   ─ 拟合 α = f(N, Q) 关系

2. 预测阶段：
   ─ 输入: 运行台数N, 目标流量Q
   ─ 输出: 修正系数 α

3. 应用阶段：
   ─ H_actual = H_theo × α
   ─ 修正后扬程更接近实际值
```
