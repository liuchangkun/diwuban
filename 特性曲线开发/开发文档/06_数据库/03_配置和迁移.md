## 1. 配置设计原则

### 1.1 参数存储策略

**核心原则**：曲线拟合的**业务参数**存储在数据库中，**系统配置**复用项目现有配置文件。

| 参数类型 | 存储位置 | 说明 |
|---------|---------|------|
| **拟合业务参数** | 数据库三表 | 可按设备/曲线/方法版本化管理 |
| **系统通用配置** | `configs/*.yaml` | 复用项目现有配置 |
| **模块特有配置** | `configs/curve_fitting.yaml` | 仅曲线拟合模块独有配置 |

### 1.2 禁止在配置文件中定义的内容

```yaml
# ❌ 错误：这些参数不应出现在配置文件中
curve_fitting:
  qh:
    validation:
      r_squared_min: 0.95      # ❌ 应存储在数据库
    constraints:
      H0_min: 0                # ❌ 应存储在数据库
```

**正确存储位置**：

| 参数 | 存储字段 |
|------|---------|
| `r_squared_min`, `rmse_max` | `curve_fit_params` 表 |
| `H0_min/max`, `K_min/max` | `curve_fit_params` 表 |
| `monotonicity`, `convexity` | `physics_validation` JSONB |

### 2.5 统一配置访问类（v2.2新增，问题#15）

> **问题**：各模块使用不同方式访问配置，导致代码风格不一致。
> **解决**：提供统一的配置访问类 `CurveFittingConfig`。

```python
from dataclasses import dataclass
from typing import Dict, Any
from functools import lru_cache


@dataclass(frozen=True)
class FrequencyNormalizationConfig:
    """频率归一化配置（不可变）"""
    reference_freq: float = 50.0
    min_freq: float = 25.0
    max_freq: float = 60.0
    default_freq: float = 50.0
    std_threshold: float = 2.0


@dataclass(frozen=True)
class CorrectionModelConfig:
    """修正模型配置（不可变）"""
    model_type: str = "polynomial"
    polynomial_degree: int = 2
    regularization_alpha: float = 1.0
    min_training_points: int = 100
    validation_ratio: float = 0.2


@dataclass(frozen=True)
class PumpGroupConfig:
    """泵组处理配置（不可变）"""
    power_diff_threshold: float = 0.10
    correction_model: CorrectionModelConfig = None

    def __post_init__(self):
        if self.correction_model is None:
            object.__setattr__(self, 'correction_model', CorrectionModelConfig())


class CurveFittingConfig:
    """
    曲线拟合配置统一访问类（单例模式）

    ✅ v2.2解决问题#15：统一配置访问路径

    使用示例:
        config = CurveFittingConfig()
        ref_freq = config.frequency.reference_freq  # 50.0
        power_threshold = config.pump_group.power_diff_threshold  # 0.10
    """

    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._load_config()
        return cls._instance

    def _load_config(self):
        """加载配置文件"""
        raw = load_curve_fitting_config()

        # 解析频率归一化配置
        freq_raw = raw.get('frequency_normalization', {})
        self._frequency = FrequencyNormalizationConfig(
            reference_freq=freq_raw.get('reference_freq', 50.0),
            min_freq=freq_raw.get('min_freq', 25.0),
            max_freq=freq_raw.get('max_freq', 60.0),
            default_freq=freq_raw.get('default_freq', 50.0),
            std_threshold=freq_raw.get('std_threshold', 2.0)
        )

        # 解析泵组配置
        group_raw = raw.get('pump_group', {})
        correction_raw = group_raw.get('correction_model', {})
        self._pump_group = PumpGroupConfig(
            power_diff_threshold=group_raw.get('power_diff_threshold', 0.10),
            correction_model=CorrectionModelConfig(
                model_type=correction_raw.get('model_type', 'polynomial'),
                polynomial_degree=correction_raw.get('polynomial_degree', 2),
                regularization_alpha=correction_raw.get('regularization_alpha', 1.0),
                min_training_points=correction_raw.get('min_training_points', 100),
                validation_ratio=correction_raw.get('validation_ratio', 0.2)
            )
        )

    @property
    def frequency(self) -> FrequencyNormalizationConfig:
        """频率归一化配置"""
        return self._frequency

    @property
    def pump_group(self) -> PumpGroupConfig:
        """泵组处理配置"""
        return self._pump_group


# ========== 推荐使用方式 ==========
# 旧方式（不推荐）：
# config = load_curve_fitting_config()
# ref_freq = config.get('frequency_normalization', {}).get('reference_freq', 50.0)

# 新方式（推荐）：
# config = CurveFittingConfig()
# ref_freq = config.frequency.reference_freq
```

**统一访问优势**：

| 对比项 | 旧方式 | 新方式 |
|-------|-------|-------|
| 类型安全 | ❌ 无类型提示 | ✅ 完整类型注解 |
| IDE支持 | ❌ 无自动补全 | ✅ 属性自动补全 |
| 默认值处理 | ❌ 需要多层.get() | ✅ 自动回退默认值 |
| 代码一致性 | ❌ 风格不统一 | ✅ 统一访问模式 |

### 4.1.1 迁移并发执行保护【v3.11修复：问题297】

**问题**：多个实例同时启动时，可能并发执行数据库迁移，导致迁移失败或数据损坏。

**解决方案**：使用PostgreSQL advisory lock确保迁移串行执行

**实现方式**：
```sql
-- 在每个迁移脚本开头添加advisory lock
BEGIN;

-- 获取迁移锁（锁ID：999999，迁移编号：48）
SELECT pg_advisory_xact_lock(999999, 48);

-- 检查迁移是否已执行（假设有migration_history表）
DO $$
BEGIN
    IF EXISTS (
        SELECT 1 FROM migration_history
        WHERE migration_id = '048_create_curve_fit_results'
    ) THEN
        RAISE NOTICE '迁移048已执行，跳过';
        RETURN;
    END IF;
END $$;

-- 执行迁移SQL
CREATE TABLE IF NOT EXISTS curve_fit_results (...);

-- 记录迁移历史
INSERT INTO migration_history (migration_id, executed_at)
VALUES ('048_create_curve_fit_results', NOW());

COMMIT;
```

**关键点**：
1. **Advisory Lock**：`pg_advisory_xact_lock(999999, 迁移编号)` 确保同一时刻只有一个实例执行迁移
2. **幂等性检查**：检查 `migration_history` 表，避免重复执行
3. **事务保护**：整个迁移在一个事务中，失败时自动回滚
4. **锁自动释放**：事务结束时advisory lock自动释放

**migration_history表结构**：
```sql
CREATE TABLE IF NOT EXISTS migration_history (
    id SERIAL PRIMARY KEY,
    migration_id VARCHAR(100) UNIQUE NOT NULL,
    executed_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    executed_by VARCHAR(100)
);
```

-- 4. 添加泵组类型约束（与GroupProcessingStrategy枚举保持一致）
ALTER TABLE curve_fit_results
    ADD CONSTRAINT chk_results_group_type
        CHECK (group_type IS NULL OR group_type IN (
            'homogeneous',          -- 同构泵组
            'heterogeneous',        -- 异构泵组
            'vfd_hetero_freq',      -- 全变频异构
            'mixed',                -- 混合泵组
            'mixed_heterogeneous'   -- 异构混合泵组

### 6.4 配置验证机制

#### 6.4.1 配置Schema定义

```python
from pydantic import BaseModel, Field, validator
from typing import Literal, Optional

class CacheConfig(BaseModel):
    enabled: bool = True
    backend: Literal["memory"] = "memory"
    lru: dict = Field(default_factory=lambda: {"max_size": 1000, "max_memory_mb": 512})
    ttl: dict = Field(default_factory=lambda: {"curve_result": 3600, "device_params": 86400})

class ParallelConfig(BaseModel):
    enabled: bool = True
    max_workers: int = Field(ge=1, le=32, default=4)
    batch_size: int = Field(ge=1, le=1000, default=100)
    timeout_seconds: int = Field(ge=10, le=3600, default=300)

class PreprocessingConfig(BaseModel):
    min_data_points: int = Field(ge=10, le=1000, default=50)
    min_extraction_points: int = Field(ge=10, le=10000, default=100)
    max_data_points: int = Field(ge=1000, le=1000000, default=100000)
    outlier_detection: Literal["3sigma", "iqr", "none"] = "3sigma"
    normalization_enabled: bool = True

    @validator('min_extraction_points')
    def validate_extraction_points(cls, v, values):
        if 'min_data_points' in values and v < values['min_data_points']:
            raise ValueError('min_extraction_points must be >= min_data_points')
        return v

class CurveFittingConfig(BaseModel):
    """曲线拟合完整配置Schema"""
    cache: CacheConfig = Field(default_factory=CacheConfig)
    parallel: ParallelConfig = Field(default_factory=ParallelConfig)
    preprocessing: PreprocessingConfig = Field(default_factory=PreprocessingConfig)
    frequency_normalization: dict = Field(default_factory=dict)
    pump_group: dict = Field(default_factory=dict)
    monitoring: dict = Field(default_factory=dict)
```
