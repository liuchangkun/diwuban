## 2. 物理+数学混合方法（3种）

### 2.1 P0 方法

| 方法ID | 方法名称 | 适用曲线 | 说明 |
|--------|---------|---------|------|
| `hybrid_physics_poly` | 物理约束多项式 | Q-H, Q-P | **推荐** |

### 2.2 HybridPhysicsPolyMethod 设计

**算法说明**：
1. 使用物理模型确定约束条件
2. 在约束条件下进行多项式拟合
3. 保证物理一致性的同时提高拟合精度

**数学公式**（Q-H曲线）：
```
H = H₀ - k₁Q - k₂Q²

约束条件：
- H₀ = 1.1~1.3 × H_rated (物理约束)
- k₁ ≥ 0, k₂ > 0 (单调递减约束)
```

### 2.3 HybridPhysicsPolyMethod 完整实现

```python
import numpy as np
from scipy.optimize import minimize
from typing import Dict, Any
from app.services.characteristic_curves.methods.base_method import BaseMethod
from app.services.characteristic_curves.models import MethodResult  # v2.2修复P69

class HybridPhysicsPolyMethod(BaseMethod):
    """物理约束多项式拟合方法

    算法原理:
        在物理约束条件下进行多项式拟合，保证:
        1. 物理边界条件满足（如H0在合理范围）
        2. 单调性约束满足（如Q-H递减）
        3. 拟合精度最大化

    数学公式（Q-H曲线）:
        H = H₀ - k₁Q - k₂Q²

    约束条件:
        - H₀ ∈ [1.1 × H_rated, 1.3 × H_rated]
        - k₁ ≥ 0, k₂ > 0（保证单调递减）

    适用曲线: Q-H, Q-P
    """

    method_id = 'hybrid_physics_poly'
    method_name = '物理约束多项式'
    applicable_curves = ['qh', 'qp']

    def __init__(self, curve_type: str = 'qh'):
        """
        初始化

        Args:
            curve_type: 曲线类型 ('qh' 或 'qp')
        """
        super().__init__(method_name='物理约束多项式', method_id='hybrid_physics_poly')
        self.curve_type = curve_type

    def fit(self, X: np.ndarray, y: np.ndarray, **kwargs) -> MethodResult:
        """执行拟合"""
        constraints = kwargs.get('constraints', {})

        if self.curve_type == 'qh':
            return self._fit_qh(X, y, constraints)
        elif self.curve_type == 'qp':
            return self._fit_qp(X, y, constraints)
        else:
            raise ValueError(f"不支持的曲线类型: {self.curve_type}")

    def _fit_qh(self, X: np.ndarray, y: np.ndarray, constraints: Dict) -> MethodResult:
        """Q-H曲线拟合"""
        # 从约束获取边界
        H0_min = constraints.get('H0_min', y.max() * 1.05)
        H0_max = constraints.get('H0_max', y.max() * 1.3)

        def objective(params):
            H0, k1, k2 = params
            y_pred = H0 - k1 * X - k2 * X**2
            return np.sum((y - y_pred)**2)

        # v2.6修复：使用bounds参数替代Lambda约束（避免序列化问题）
        bounds = [
            (H0_min, H0_max),  # H0范围
            (0, None),         # K1 >= 0
            (1e-6, None)       # K2 >= 1e-6
        ]

        result = minimize(
            objective,
            x0=[y.max() * 1.1, 0.01, 0.001],
            bounds=bounds,
            method='L-BFGS-B'  # 支持bounds的方法
        )

        # 检查优化是否成功【v3.11修复：问题034】
        if not result.success:
            logger.error(f"[{self.method_id}] 优化失败: {result.message}")
            raise FittingError(
                f"混合物理-多项式方法优化失败: {result.message}",
                method_id=self.method_id,
                error_code="CF034"
            )

        H0, k1, k2 = result.x
        y_pred = H0 - k1 * X - k2 * X**2
        metrics = self._calculate_metrics(y, y_pred)

        predict_func = lambda x: H0 - k1 * x - k2 * x**2

        return MethodResult(
            method_id=self.method_id,
            coefficients={'H0': H0, 'k1': k1, 'k2': k2},
            r_squared=metrics['r_squared'],
            rmse=metrics['rmse'],
            mae=metrics['mae'],
            mape=metrics['mape'],
            predict_func=predict_func,
            formula=f"H = {H0:.4f} - {k1:.6f}Q - {k2:.8f}Q²",
            metadata={'physics_valid': True}
        )

    def _fit_qp(self, X: np.ndarray, y: np.ndarray, constraints: Dict) -> MethodResult:
        """Q-P曲线拟合"""
        P0_min = constraints.get('P0_min', y.min() * 0.8)
        P0_max = constraints.get('P0_max', y.min() * 1.2)

        def objective(params):
            P0, k1, k2 = params
            y_pred = P0 + k1 * X + k2 * X**2
            return np.sum((y - y_pred)**2)

        cons = [
            {'type': 'ineq', 'fun': lambda p: p[0] - P0_min},
            {'type': 'ineq', 'fun': lambda p: P0_max - p[0]},
            {'type': 'ineq', 'fun': lambda p: p[1]},
            {'type': 'ineq', 'fun': lambda p: p[2]},
        ]

        result = minimize(
            objective,
            x0=[y.min(), 0.01, 0.0001],
            constraints=cons,
            method='SLSQP'
        )

        P0, k1, k2 = result.x
        y_pred = P0 + k1 * X + k2 * X**2
        metrics = self._calculate_metrics(y, y_pred)

        predict_func = lambda x: P0 + k1 * x + k2 * x**2

        return MethodResult(
            method_id=self.method_id,
            coefficients={'P0': P0, 'k1': k1, 'k2': k2},
            r_squared=metrics['r_squared'],
            rmse=metrics['rmse'],
            mae=metrics['mae'],
            mape=metrics['mape'],
            predict_func=predict_func,
            formula=f"P = {P0:.4f} + {k1:.6f}Q + {k2:.8f}Q²",
            metadata={'physics_valid': True}
        )
```

**优势**：
- 结合物理模型的可解释性
- 结合多项式的拟合灵活性
- 保证物理约束满足
- 预期精度 R² > 0.98

## 3. 物理+ML混合方法（2种）

| 方法ID | 方法名称 | 适用曲线 | 阶段 |
|--------|---------|---------|------|
| `hybrid_physics_nn` | 物理约束神经网络 | 所有 | P2 |
| `hybrid_physics_gp` | 物理约束高斯过程 | 所有 | P2 |

### 3.1 hybrid_physics_nn 设计思路

**算法说明**：
1. 物理模型提供基础预测
2. 神经网络学习残差（物理模型无法捕捉的部分）
3. 最终预测 = 物理预测 + 神经网络残差

```
y_pred = f_physics(x) + f_nn(x)

其中：
- f_physics: 物理模型预测（如 H = H0 - K*Q²）
- f_nn: 神经网络学习的残差
```

**优势**：
- 保留物理模型的可解释性
- 神经网络补偿物理模型的误差
- 外推性能优于纯ML方法

## 6. 方法注册表

```python
from typing import Dict, Type, Optional, List
from app.services.characteristic_curves.methods.base_method import BaseMethod

# 导入所有方法类【v3.11修复：问题036】
from app.services.characteristic_curves.methods.math_methods import (
    MathPoly2Method,
    MathPoly3Method,
    MathStatGaussianMethod
)
from app.services.characteristic_curves.methods.physics_methods import (
    PhysicsPumpCharMethod,
    PhysicsPowerEqMethod
)
from app.services.characteristic_curves.methods.ml_methods import (
    MLGradientBoostMethod,
    MLRandomForestMethod,
    MLGaussianProcessMethod
)
from app.services.characteristic_curves.methods.hybrid_methods import (
    HybridPhysicsPolyMethod
)

class MethodRegistry:
    """方法注册表 - 管理所有拟合方法"""

    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._methods: Dict[str, Type[BaseMethod]] = {}
            cls._instance._initialize_builtin_methods()
        return cls._instance

    def _initialize_builtin_methods(self):
        """初始化内置方法"""
        # 数学方法
        self.register('math_poly_2', MathPoly2Method)
        self.register('math_poly_3', MathPoly3Method)
        self.register('math_stat_gaussian', MathStatGaussianMethod)

        # 物理模型
        self.register('physics_pump_char', PhysicsPumpCharMethod)
        self.register('physics_power_eq', PhysicsPowerEqMethod)

        # 机器学习
        self.register('ml_gradient_boost', MLGradientBoostMethod)
        self.register('ml_random_forest', MLRandomForestMethod)
        self.register('ml_gaussian_process', MLGaussianProcessMethod)

        # 混合方法
        self.register('hybrid_physics_poly', HybridPhysicsPolyMethod)

    def get_recommended(self, curve_type: str) -> List[str]:
        """获取推荐方法"""
        recommendations = {
            'qh': ['physics_pump_char', 'math_poly_2', 'math_poly_3'],
            'qp': ['physics_power_eq', 'math_poly_2', 'math_poly_3'],
            'qeta': ['math_stat_gaussian', 'math_poly_3', 'math_poly_4']
        }
        return recommendations.get(curve_type, [])
```

## 7. 使用建议

### 7.1 方法选择指南

| 场景 | 推荐方法 | 说明 |
|------|---------|------|
| 高精度需求 | `hybrid_physics_poly` | 物理+数学 |
| 复杂非线性 | `hybrid_physics_nn` | 物理+ML |
| 不确定性量化 | `hybrid_physics_gp` | 高斯过程 |

### 7.2 注意事项

1. **计算复杂度**：混合方法通常计算量较大
2. **参数调优**：需要同时调优多个模型的参数
3. **过拟合风险**：模型复杂度高，需要充足数据
