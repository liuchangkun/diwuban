## 🎯 设计原则

### 核心理念

1. **数据驱动**：基于实际数据库状态设计特性曲线
2. **分阶段实施**：
   - **第一阶段**：基于当前数据（6台变频泵）可拟合的曲线
   - **第二阶段**：未来数据补充后可拟合的曲线（软启泵、混合泵组）
3. **灵活性**：支持任意数量的泵组合，不固定泵组数量和类型
4. **可扩展性**：支持未来增加新泵或改变泵类型
5. **实用性**：每条曲线都有明确的应用价值和拟合方法

### 拟合可行性评估标准

**✅ 可拟合**：
- 所需指标数据完全可用
- 数据量充足（>100个数据点）
- 数据覆盖合理的运行范围
- 有明确的拟合方法

**⚠️ 拟合困难**：
- 数据量不足（<100个数据点）
- 数据覆盖不全（只覆盖部分运行范围）
- 需要额外参数（设备额定参数、设计参数等）
- 模型复杂（需要复杂的非线性模型）

**❌ 无法拟合**：
- 缺少关键指标数据
- 物理上不可行（当前设备配置无法产生这种特性）
- 数据完全缺失

### 一、单泵基本特性曲线（6条）⭐⭐⭐⭐⭐

#### 1. Q-H曲线（流量-扬程）

**说明**: 单泵在不同流量下的扬程特性，是泵最基本、最重要的特性曲线

**依赖指标**:
- pump_flow_rate（泵流量，m³/h）
- pump_head（泵扬程，m）

**拟合可行性**: ✅ 可拟合
- 数据完全可用：pump_flow_rate和pump_head数据充足
- 数据量：设备1,2,4,6数据点>25,000，设备3数据点>5,000，设备5数据点>100
- 数据质量：pump_head一致性良好（315,934 = 157,967 + 157,967）
- 覆盖范围：流量范围0.01~3,012 m³/h，覆盖从低负荷到高负荷

**拟合方法**:
1. **数学方法**：
   - 2次多项式回归：H = a₀ + a₁Q + a₂Q²（最常用）
   - 3次多项式回归：H = a₀ + a₁Q + a₂Q² + a₃Q³（更精确）
   - 分段线性拟合：在不同流量区间使用不同的线性模型
2. **物理机理模型**：
   - 泵特性方程：基于流体力学理论，H = H₀ - KQ²（H₀为关阀扬程，K为阻力系数）
3. **机器学习方法**：
   - 随机森林回归：处理非线性关系
   - 梯度提升树（XGBoost）：高精度拟合
   - 支持向量回归（SVR）：处理小样本数据（设备5）
4. **深度学习方法**：
   - 多层感知机（MLP）：拟合复杂非线性关系
   - 物理信息神经网络（PINN）：结合物理约束（H随Q单调递减）

**应用价值**:
- **用途**：泵性能评估、泵选型、运行优化
- **功能**：
  - 预测不同流量下的扬程
  - 确定泵的工作范围
  - 识别最佳效率点（BEP）
  - 评估泵性能衰减
- **解决的问题**：
  - 如何选择合适的泵？（泵选型）
  - 泵能否满足系统需求？（性能评估）
  - 泵性能是否下降？（性能监测）
  - 如何优化运行工况？（运行优化）
- **应用示例**：
  - 实时监测：将实际工况点与Q-H曲线对比，判断是否偏离正常范围
  - 性能衰减：定期拟合Q-H曲线，对比历史曲线，评估性能衰减程度
  - 泵选型：根据系统需求（流量、扬程），在Q-H曲线上找到工作点，选择合适的泵
  - 故障诊断：工况点严重偏离Q-H曲线时，可能存在叶轮磨损、汽蚀等故障
- **量化收益**：
  - 性能监测：及时发现性能衰减5-10%，避免能耗增加
  - 泵选型优化：选择合适的泵，避免"大马拉小车"，节能10-30%
  - 故障预警：提前1-3个月发现叶轮磨损，减少停机损失
  - 运行优化：将泵运行在高效区，提高效率3-8%

**数据要求**:
- **数据类型**：pump_flow_rate（泵流量，m³/h）、pump_head（泵扬程，m）
- **数据量要求**：
  - 最小数据点数：100个（可拟合基本曲线）
  - 推荐数据点数：500-1000个（获得较好精度）
  - 理想数据点数：>5000个（高精度拟合，覆盖各种工况）
- **数据时间跨度**：
  - 最小：1天（覆盖日常运行工况）
  - 推荐：1周（覆盖不同负荷模式）
  - 理想：1个月（覆盖季节性变化、各种运行模式）
- **数据覆盖范围**：
  - 必须覆盖：正常运行工况（流量20%-100%额定流量）
  - 推荐覆盖：低负荷工况（流量10%-20%额定流量）、高负荷工况（流量100%-120%额定流量）
  - 理想覆盖：全范围工况（流量0%-120%额定流量），包括启动、停止、变频调节过程
- **数据质量要求**：
  - 数据完整性：缺失率<5%（推荐<2%）
  - 数据准确性：异常值率<3%（推荐<1%）
  - 采样频率：每分钟1次（推荐每30秒1次，理想每10秒1次）
- **数据分布要求**：
  - 流量分布：在20%-100%额定流量范围内均匀分布
  - 特定工况密集采样：在BEP附近（最佳效率点）密集采样，提高该区域拟合精度

**精度提升方法**:
- **物理约束**：
  - 单调性约束：H随Q单调递减（dH/dQ < 0）
  - 边界条件：Q=0时H=H₀（关阀扬程），H≥0（扬程非负）
  - 曲率约束：d²H/dQ² > 0（曲线向下凸）
- **机理特性**：
  - 泵特性曲线形状：典型的抛物线形状，H = H₀ - KQ²
  - 相似定律：不同转速下的Q-H曲线满足相似定律（H₁/H₂ = (n₁/n₂)²）
  - 能量守恒：P = ρgQH/η（功率、流量、扬程、效率之间的关系）
- **边界条件**：
  - 最大流量：Q_max ≤ 1.2 × Q_rated（额定流量的120%）
  - 最小扬程：H_min ≥ 0.5 × H_rated（额定扬程的50%）
  - 关阀扬程：H₀ ≈ 1.1-1.3 × H_rated（关阀扬程约为额定扬程的110%-130%）
- **多变量关联**：
  - Q-H-P关联：结合Q-P曲线，利用P = ρgQH/η验证拟合结果
  - Q-H-η关联：结合Q-η曲线，确保三者之间的物理一致性
  - 相似定律关联：利用不同转速下的数据，通过相似定律扩展数据集
- **数据预处理**：
  - 异常值检测：使用3σ原则、箱线图、Isolation Forest检测异常值
  - 数据清洗：删除明显错误的数据点（如H<0、Q<0）
  - 数据归一化：将Q和H归一化到[0,1]区间，提高数值稳定性
  - 特征工程：添加Q²、Q³等特征，提高多项式拟合效果
- **模型融合**：
  - 物理信息神经网络（PINN）：在损失函数中加入物理约束（dH/dQ < 0、H = H₀ - KQ²）
  - 混合建模：先用物理模型H = H₀ - KQ²拟合，再用机器学习模型拟合残差
  - 集成学习：结合多项式回归、随机森林、XGBoost的预测结果，加权平均
- **正则化技术**：
  - L2正则化：防止多项式系数过大，避免过拟合
  - 交叉验证：使用5折或10折交叉验证，选择最优模型参数
  - 早停法：在验证集误差不再下降时停止训练（深度学习）
- **集成学习**：
  - Bagging：训练多个多项式回归模型，对预测结果取平均
  - Boosting：使用XGBoost、LightGBM等梯度提升方法
  - Stacking：将多项式回归、随机森林、XGBoost的预测结果作为特征，训练元模型

#### 2. Q-P曲线（流量-功率）

**说明**: 单泵在不同流量下的功率特性，用于能耗分析和效率评估

**依赖指标**:
- pump_flow_rate（泵流量，m³/h）
- pump_active_power（泵有功功率，kW）

**拟合可行性**: ✅ 可拟合
- 数据完全可用：pump_flow_rate和pump_active_power数据充足
- 数据量：与Q-H曲线相同
- 数据质量：良好
- 覆盖范围：功率范围覆盖从空载到满载

**拟合方法**:
1. **数学方法**：
   - 2次多项式回归：P = b₀ + b₁Q + b₂Q²
   - 3次多项式回归：P = b₀ + b₁Q + b₂Q² + b₃Q³（更符合实际）
2. **物理机理模型**：
   - 功率方程：P = ρgQH/η（ρ为密度，g为重力加速度，η为效率）
   - 结合Q-H曲线和Q-η曲线推导
3. **机器学习方法**：
   - 梯度提升树（XGBoost）：高精度拟合
   - 随机森林回归：处理非线性关系
4. **深度学习方法**：
   - 多层感知机（MLP）：拟合复杂非线性关系

**应用价值**:
- **用途**：能耗预测、效率分析、成本评估
- **功能**：
  - 预测不同流量下的功率需求
  - 计算运行成本
  - 评估能耗分布
  - 识别高能耗工况
- **解决的问题**：
  - 泵运行需要多少功率？（功率预测）
  - 运行成本是多少？（成本评估）
  - 如何降低能耗？（节能优化）
  - 功率是否异常？（异常检测）
- **应用示例**：
  - 能耗预测：根据流量需求，预测所需功率和电费
  - 节能评估：对比不同运行方案的功率，选择低能耗方案
  - 异常检测：实际功率严重偏离Q-P曲线时，可能存在效率下降、机械故障等问题
  - 成本分析：结合分时电价，计算不同时段的运行成本
- **量化收益**：
  - 能耗预测：预测精度达到±5%，准确评估运行成本
  - 节能优化：选择低能耗运行方案，节能5-15%
  - 异常检测：提前发现效率下降，避免能耗增加10-20%
  - 成本优化：结合分时电价，降低电费成本8-12%

**数据要求**:
- **数据类型**：pump_flow_rate（泵流量，m³/h）、pump_active_power（泵有功功率，kW）
- **数据量要求**：
  - 最小数据点数：100个
  - 推荐数据点数：500-1000个
  - 理想数据点数：>5000个
- **数据时间跨度**：
  - 最小：1天
  - 推荐：1周
  - 理想：1个月
- **数据覆盖范围**：
  - 必须覆盖：正常运行工况（流量20%-100%额定流量）
  - 推荐覆盖：低负荷工况（流量10%-20%）、高负荷工况（流量100%-120%）
  - 理想覆盖：全范围工况（流量0%-120%），包括空载、轻载、满载
- **数据质量要求**：
  - 数据完整性：缺失率<5%
  - 数据准确性：异常值率<3%
  - 采样频率：每分钟1次（推荐每30秒1次）
- **数据分布要求**：
  - 流量分布：在20%-100%额定流量范围内均匀分布
  - 功率分布：覆盖从空载功率到满载功率的全范围

**精度提升方法**:
- **物理约束**：
  - 单调性约束：P随Q单调递增（dP/dQ > 0）
  - 边界条件：Q=0时P=P₀（空载功率），P≥P₀
  - 曲率约束：d²P/dQ² > 0（曲线向上凸）
- **机理特性**：
  - 功率方程：P = ρgQH/η，结合Q-H曲线和Q-η曲线
  - 相似定律：P₁/P₂ = (n₁/n₂)³（功率与转速的三次方成正比）
  - 空载功率：P₀ ≈ 0.1-0.3 × P_rated（空载功率约为额定功率的10%-30%）

#### 6. Q-NPSH曲线（流量-汽蚀余量）

**说明**: 单泵在不同流量下的可用汽蚀余量，用于汽蚀预防

**依赖指标**:
- pump_flow_rate（泵流量，m³/h）
- pump_inlet_pressure（泵入口压力，MPa）
- pool_liquid_level（水池液位，m）

**拟合可行性**: ✅ 可拟合
- 数据完全可用：pump_inlet_pressure覆盖率100%
- 数据量：充足
- 数据质量：良好（pump_inlet_pressure修复后无效值仅4.2%，且是物理上合理的）

**拟合方法**:
1. **数学方法**：
   - 线性回归：NPSHA = a + bQ（简单快速）
   - 2次多项式回归：NPSHA = a₀ + a₁Q + a₂Q²（更精确）
   - 分段线性拟合：在不同流量区间使用不同模型
2. **物理机理模型**：
   - NPSHA公式：NPSHA = (P_inlet/ρg) + (v²/2g) + z - P_v/ρg
     - P_inlet：泵入口压力（pump_inlet_pressure）
     - v：流速（v = Q/A，A为管道截面积）
     - z：高程（pool_liquid_level - 泵入口高程）
     - P_v：饱和蒸汽压（水温20°C时约为0.0023 MPa）
   - 简化公式：NPSHA ≈ (P_inlet/ρg) + z（忽略流速水头和蒸汽压）
3. **机器学习方法**：
   - 梯度提升树（XGBoost）：考虑多变量影响（流量、液位、入口压力）
   - 随机森林回归：处理非线性关系
4. **深度学习方法**：
   - 多层感知机（MLP）：拟合复杂非线性关系

**应用价值**:
- **用途**：汽蚀预防、安全运行、水池液位监测
- **功能**：
  - 计算可用汽蚀余量（NPSHA）
  - 对比必需汽蚀余量（NPSHR）
  - 识别汽蚀风险
  - 确定安全运行区间
  - 监测水池液位对汽蚀的影响
- **解决的问题**：
  - 泵是否会发生汽蚀？（汽蚀风险评估）
  - 如何避免汽蚀？（汽蚀预防）
  - 安全运行范围是多少？（安全区间确定）
  - 水池液位多低会导致汽蚀？（液位监测）
- **应用示例**：
  - 汽蚀预警：NPSHA < NPSHR时报警，避免汽蚀损坏叶轮
  - 安全运行：限制流量在NPSHA > NPSHR + 0.5m的范围内（留有安全裕度）
  - 水池液位监测：液位过低时，NPSHA下降，汽蚀风险增加，自动降低流量或停泵
  - 流量限制：根据当前液位和NPSHA，动态调整最大允许流量
- **量化收益**：
  - 汽蚀预防：避免汽蚀损坏叶轮，延长叶轮寿命2-5倍
  - 安全运行：减少汽蚀故障，降低维修成本50-80%

**数据要求**:
- **数据类型**：
  - pump_flow_rate（泵流量，m³/h）

  - pool_liquid_level（水池液位，m）
- **数据量要求**：
  - 最小数据点数：100个

  - 理想数据点数：>5000个
- **数据时间跨度**：
  - 最小：1天

  - 静压水头：z = pool_liquid_level - 泵入口高程

- **数据预处理**：

- **模型融合**：
  - 物理模型：NPSHA = (P_inlet/ρg) + z，先用物理模型计算
  - 机器学习修正：用XGBoost拟合物理模型的残差
  - 分组拟合：按液位分组，每组单独拟合Q-NPSHA曲线
- **正则化技术**：
  - L2正则化：防止系数过大
  - 物理约束正则化：在损失函数中加入NPSHA≥0、dNPSHA/dQ<0约束
  - 交叉验证：选择最优参数
- **集成学习**：

  - 加速度约束：d²f/dt² ≤ a_max（最大加速度）
- **边界条件**：
  - 启动时间：t_start ≥ 5秒（避免启动过快）
  - 最大加速度：df/dt ≤ 10 Hz/s
  - 目标频率：f_target ∈ [20, 50] Hz
- **多变量关联**：
  - f-I关联：电流随频率增加而增加
  - f-P关联：功率随频率增加而增加（P ∝ f³）
  - f-Q关联：流量随频率增加而增加（Q ∝ f）
- **数据预处理**：
  - 启动过程提取：识别启动过程（频率从0增加到目标频率）
  - 时间归一化：将启动时间归一化到[0,1]
  - 数据平滑：使用Savitzky-Golay滤波平滑频率曲线
  - 特征工程：添加df/dt、d²f/dt²等特征
- **模型融合**：
  - S曲线拟合：f(t) = f_max / (1 + exp(-k(t-t₀)))
  - 指数函数拟合：f(t) = f_max(1 - exp(-t/τ))
  - LSTM：学习启动过程的时序特性
- **正则化技术**：
  - 单调性正则化：在损失函数中加入df/dt > 0约束
  - S曲线正则化：在损失函数中加入S曲线形状约束
  - 交叉验证：选择最优参数
- **集成学习**：
  - S曲线 + LSTM：先用S曲线拟合，再用LSTM拟合残差
  - 多次启动平均：对多次启动过程取平均
  - Stacking：元模型集成
