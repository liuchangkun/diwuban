#### 2.2.1 数据生成工具类
**文件路径**: `tests/fixtures/e2e_data_generator.py`

#### 2.2.2 数据生成参数

**时间参数**:
- 开始时间: 2025-10-22 08:00:00
- 结束时间: 2025-11-21 08:00:00
- 采样间隔: 1秒
- 总数据点: 30天 × 24小时 × 3600秒 = 2,592,000点/设备

**流量参数**（QH曲线）:
- 流量范围: 0.2 × rated_flow ~ 1.0 × rated_flow
- 流量变化: 正弦波 + 随机噪声（±5%）
- 扬程计算: H = H0 - K × Q²（二次多项式）
- H0 = rated_head × 1.2（零流量扬程）
- K = (H0 - rated_head) / rated_flow²

**功率参数**（QP曲线）:
- 功率范围: 0.3 × rated_power ~ 1.1 × rated_power
- 功率计算: P = P0 + K1 × Q + K2 × Q²
- P0 = rated_power × 0.2（空载功率）

**效率参数**（QEta曲线）:
- 效率范围: 0.5 ~ 0.9
- 效率计算: η = η_max × (1 - ((Q - Q_opt) / Q_opt)²)
- Q_opt = rated_flow × 0.8（最优工况点）
- η_max = 0.88（最大效率）

**频率参数**（变频泵）:
- 频率范围: 35Hz ~ 50Hz
- 频率变化: 正弦波 + 随机噪声（±2Hz）

**频率参数**（软启泵）:
- 频率固定: 50Hz

**噪声参数**:
- 流量噪声: ±2%
- 扬程噪声: ±1%
- 功率噪声: ±3%
- 效率噪声: ±2%

```python
                    row['metric_id'],
                    row['ts_raw'],
                    row['ts_bucket'],
                    row['value']
                ))

            cursor.executemany("""
                INSERT INTO fact_measurements
                (station_id, device_id, metric_id, ts_raw, ts_bucket, value)
                VALUES (%s, %s, %s, %s, %s, %s)
                ON CONFLICT DO NOTHING
            """, values)
        conn.commit()
```

### 7.6 执行顺序和依赖关系

**执行顺序**:

```
阶段1: 数据准备
├─ 1.1 创建数据生成工具类
├─ 1.2 插入测试设备
├─ 1.3 生成模拟数据（设备7-18）
└─ 1.4 扩展真实数据（设备1-3）

阶段2: 单泵场景测试
├─ 2.1 S1: 单泵-变频（设备1）× 3曲线
└─ 2.2 S2: 单泵-软启（设备7）× 3曲线

阶段3: 泵组场景测试
├─ 3.1 S3: 同构泵组-变频（设备1-3）× 3曲线
├─ 3.2 S4: 同构泵组-软启（设备7-9）× 3曲线
├─ 3.3 S5: 异构泵组-变频（设备10-12）× 3曲线
├─ 3.4 S6: 异构泵组-软启（设备13-15）× 3曲线
└─ 3.5 S7: 混合泵组（设备16-18）× 3曲线

阶段4: 验证和报告
├─ 4.1 验证数据库记录
├─ 4.2 验证拟合精度
├─ 4.3 验证物理约束
├─ 4.4 生成汇总报告
└─ 4.5 整理输出文件
```

**依赖关系**:
- 阶段2依赖阶段1完成
- 阶段3依赖阶段1完成（可与阶段2并行）
- 阶段4依赖阶段2和阶段3完成

### 7.7 错误处理策略

**错误分类**:

| 错误类型 | 处理策略 | 是否继续 |
|---------|---------|---------|
| 数据生成失败 | 记录错误，跳过该设备 | 是 |
| 拟合失败（R²<0.85） | 记录警告，标记为失败 | 是 |
| 数据库写入失败 | 记录错误，回滚事务 | 否 |
| 报告生成失败 | 记录警告，继续下一个 | 是 |
| 图片生成失败 | 记录警告，继续下一个 | 是 |

**错误记录格式**:

```python
error_log = {
    "timestamp": datetime.now().isoformat(),
    "scenario_id": "S1",
    "curve_type": "qh",
    "device_id": 1,
    "error_type": "FittingError",
    "error_message": "R² = 0.82 < 0.85",
    "stack_trace": "...",
    "action_taken": "标记为失败，继续下一个场景"
}
```
