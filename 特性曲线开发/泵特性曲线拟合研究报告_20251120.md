## 🎯 可以拟合的特性曲线

### 1. Q-H曲线（流量-扬程曲线）⭐⭐⭐⭐⭐

**物理意义**: 泵在不同流量下的扬程变化规律

**拟合公式**:
```
H = a₀ + a₁Q + a₂Q²
或
H = a₀ + a₁Q + a₂Q² + a₃Q³
```

**依赖数据**:
- pump_flow_rate（流量，m³/h）
- pump_head（扬程，m）

**拟合方法**:
- 多项式回归（2次或3次）
- 最小二乘法

**应用场景**:
- ✅ 预测不同流量下的扬程
- ✅ 验证泵性能是否符合设计要求
- ✅ 优化泵组运行工况

**数据可用性**: ✅ 100%（所有设备都有pump_flow_rate和pump_head数据）

**拟合难度**: ⭐ 简单

**推荐优先级**: ⭐⭐⭐⭐⭐ 最高

---

### 2. Q-P曲线（流量-功率曲线）⭐⭐⭐⭐⭐

**物理意义**: 泵在不同流量下的功率消耗规律

**拟合公式**:
```
P = b₀ + b₁Q + b₂Q² + b₃Q³
```

**依赖数据**:
- pump_flow_rate（流量，m³/h）
- pump_active_power（有功功率，kW）

**拟合方法**:
- 多项式回归（3次）
- 最小二乘法

**应用场景**:
- ✅ 预测不同流量下的功率消耗
- ✅ 能耗优化
- ✅ 成本核算

**数据可用性**: ✅ 100%

**拟合难度**: ⭐ 简单

**推荐优先级**: ⭐⭐⭐⭐⭐ 最高

---

### 3. Q-η曲线（流量-效率曲线）⭐⭐⭐⭐⭐

**物理意义**: 泵在不同流量下的效率变化规律，用于找到最佳效率点（BEP）

**拟合公式**:
```
η = c₀ + c₁Q + c₂Q² + c₃Q³
```

**依赖数据**:
- pump_flow_rate（流量，m³/h）
- pump_efficiency（效率，%）

**拟合方法**:
- 多项式回归（3次）
- 最小二乘法

**应用场景**:
- ✅ 找到最佳效率点（BEP）
- ✅ 优化运行工况
- ✅ 评估泵性能衰减

**数据可用性**: ✅ 100%

**拟合难度**: ⭐ 简单

**推荐优先级**: ⭐⭐⭐⭐⭐ 最高

---

### 4. 相似定律曲线（变频泵特有）⭐⭐⭐⭐⭐

**物理意义**: 泵在不同转速（频率）下的性能变化规律

**相似定律公式**:
```
Q₁/Q₂ = n₁/n₂
H₁/H₂ = (n₁/n₂)²
P₁/P₂ = (n₁/n₂)³
```

**依赖数据**:
- pump_flow_rate（流量，m³/h）
- pump_head（扬程，m）
- pump_active_power（有功功率，kW）
- pump_frequency（频率，Hz）

**拟合方法**:
1. 将不同频率下的数据归一化到额定频率（50 Hz）
2. 拟合额定频率下的Q-H曲线
3. 使用相似定律推导其他频率下的曲线

**应用场景**:
- ✅ 预测不同转速下的性能
- ✅ 变频调速优化
- ✅ 节能分析

**数据可用性**: ✅ 100%（所有设备都是变频泵）

**拟合难度**: ⭐⭐ 中等

**推荐优先级**: ⭐⭐⭐⭐⭐ 最高（变频泵特有）

---

### 5. 并联泵组特性曲线⭐⭐⭐⭐

**物理意义**: 多台泵并联运行时的综合性能曲线

**并联规律**:
```
Q_total = Q₁ + Q₂ + ... + Qₙ（相同扬程下）
H_total = H（所有泵扬程相同）
```

**依赖数据**:
- 各台泵的pump_flow_rate
- 各台泵的pump_head
- main_pipeline_flow_rate（总管流量）
- main_pipeline_outlet_pressure（总管出口压力）

**拟合方法**:
1. 识别并联运行时段（多台泵同时运行）
2. 计算总流量和总扬程
3. 拟合并联Q-H曲线

**应用场景**:
- ✅ 优化泵组组合
- ✅ 预测并联性能
- ✅ 调度策略优化

**数据可用性**: ✅ 100%

**拟合难度**: ⭐⭐⭐ 中等偏高

**推荐优先级**: ⭐⭐⭐⭐ 高

---

### 6. 管路特性曲线⭐⭐⭐

**物理意义**: 管路系统的阻力特性

**拟合公式**:
```
H_pipe = H_static + K × Q²
```

**依赖数据**:
- pump_flow_rate（流量）
- pump_head（扬程）
- pool_liquid_level（水池液位，静扬程）

**拟合方法**:
- 非线性回归
- 最小二乘法

**应用场景**:
- ✅ 系统阻力分析
- ✅ 管道老化监测
- ✅ 工况点预测

**数据可用性**: ✅ 100%

### 拟合算法选择

#### 1. 多项式回归（Polynomial Regression）

**适用曲线**: Q-H, Q-P, Q-η

**Python实现**:
```python

from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# 2次多项式拟合（Q-H曲线）
poly = PolynomialFeatures(degree=2)
X_poly = poly.fit_transform(Q.reshape(-1, 1))
model = LinearRegression()
model.fit(X_poly, H)

# 预测
H_pred = model.predict(X_poly)
r2 = r2_score(H, H_pred)
```

**拟合阶数选择**:
- Q-H曲线: 2次或3次
