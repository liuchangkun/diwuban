## 🎯 可以计算的新指标

### 优先级1：电气性能指标（高价值）

#### 1.1 pump_apparent_power（泵视在功率）

**物理意义**: 三相交流电路的视在功率，表示电源提供的总功率

**计算公式**:
```
S = √3 × U_avg × I_avg
```

**依赖数据**:
- pump_voltage_a, pump_voltage_b, pump_voltage_c
- pump_current_a, pump_current_b, pump_current_c

**计算步骤**:
1. 计算平均电压: `U_avg = (U_a + U_b + U_c) / 3`
2. 计算平均电流: `I_avg = (I_a + I_b + I_c) / 3`
3. 计算视在功率: `S = √3 × U_avg × I_avg / 1000` (kVA)

**应用价值**:
- ✅ 评估电气设备容量
- ✅ 分析功率因数改善空间
- ✅ 优化电气系统配置

**数据可用性**: ✅ 100%（所有设备都有三相电压和电流数据）

---

#### 1.2 pump_reactive_power（泵无功功率）

**物理意义**: 电感性负载消耗的无功功率，不做有用功但占用电网容量

**计算公式**:
```
Q = P × tan(arccos(PF))
或
Q = √(S² - P²)
```

**依赖数据**:
- pump_active_power（有功功率）
- pump_power_factor（功率因数）
- pump_apparent_power（视在功率，可选）

**计算步骤**:
1. 方法1（使用功率因数）:
   - `φ = arccos(PF)`
   - `Q = P × tan(φ)` (kVar)

2. 方法2（使用视在功率）:
   - `Q = √(S² - P²)` (kVar)

**应用价值**:
- ✅ 评估无功补偿需求
- ✅ 优化功率因数
- ✅ 降低电网损耗

**数据可用性**: ✅ 100%

---

#### 1.3 pump_three_phase_imbalance（三相不平衡度）

**物理意义**: 三相电压或电流的不平衡程度，反映电气系统健康状况

**计算公式**:
```
电压不平衡度 = max(|U_a - U_avg|, |U_b - U_avg|, |U_c - U_avg|) / U_avg × 100%
电流不平衡度 = max(|I_a - I_avg|, |I_b - I_avg|, |I_c - I_avg|) / I_avg × 100%
```

**依赖数据**:
- pump_voltage_a/b/c
- pump_current_a/b/c

**应用价值**:
- ✅ 故障预警（不平衡度>2%需关注）
- ✅ 设备健康监测
- ✅ 电机寿命预测

**数据可用性**: ✅ 100%

### 优先级2：能效分析指标（高价值）

#### 2.1 pump_specific_energy（泵比能耗）

**物理意义**: 单位流量单位扬程的能耗，反映泵的能效水平

**计算公式**:
```
e = P / (Q × H)  (kWh/m⁴)
```

**依赖数据**:
- pump_active_power（有功功率，kW）
- pump_flow_rate（流量，m³/h）
- pump_head（扬程，m）

**计算步骤**:
1. 过滤条件: `pump_flow_rate > 0 AND pump_head > 0`
2. 计算比能耗: `e = P / (Q × H)`
3. 合理范围: `0.001 < e < 0.1` (kWh/m⁴)

**应用价值**:
- ✅ 评估泵运行效率
- ✅ 对比不同工况能效
- ✅ 优化运行策略

**数据可用性**: ✅ 100%（pump_flow_rate > 0的时间点）

---

#### 2.2 pump_shaft_power（泵轴功率）

**物理意义**: 电机输出到泵轴的机械功率

**计算公式**:
```
P_shaft = P_active / eta_motor
```

**依赖数据**:
- pump_active_power（有功功率，kW）
- eta_motor（电机效率，参数，默认0.92）

**应用价值**:
- ✅ 分析电机效率
- ✅ 评估机械损耗
- ✅ 优化电机选型

**数据可用性**: ✅ 100%

**注意**: dim_metric_config中已有pump_shaft_power定义（id=66），但fact_measurements中无数据

#### 2.3 pump_hydraulic_power（泵水力功率）

**物理意义**: 泵传递给液体的有效功率

**计算公式**:
```
P_h = ρ × g × Q × H / 3600  (kW)
```

**依赖数据**:
- pump_flow_rate（流量，m³/h）
- pump_head（扬程，m）
- rho（水密度，1000 kg/m³）
- g（重力加速度，9.81 m/s²）

**计算步骤**:
1. 将流量转换为m³/s: `Q_s = Q / 3600`
2. 计算水力功率: `P_h = rho × g × Q_s × H / 1000` (kW)

**应用价值**:
- ✅ 验证效率计算
- ✅ 分析能量转换
- ✅ 评估泵性能

**数据可用性**: ✅ 100%（pump_flow_rate > 0的时间点）

**注意**: dim_metric_config中已有pump_hydraulic_power定义（id=67），但fact_measurements中无数据

### 优先级3：累计统计指标（中价值）

#### 3.1 pump_energy_consumption（泵能耗）

**物理意义**: 泵的累计电能消耗

**计算公式**:
```
E = ∫ P dt  (kWh)
```

**依赖数据**:
- pump_active_power（有功功率，kW）
- 时间间隔（秒）

**计算步骤**:
1. 计算每个时间点的能耗增量: `dE = P × dt / 3600` (kWh)
2. 累计求和: `E = Σ dE`

**应用价值**:
- ✅ 能耗统计
- ✅ 成本核算
- ✅ 节能评估

**数据可用性**: ✅ 100%

**注意**: 已有pump_kwh（泵电量），可能是同一指标

---

#### 3.2 pump_running_hours（泵运行时长）

**物理意义**: 泵的累计运行时间

**计算公式**:
```
T = ∫ running dt  (小时)
```

**依赖数据**:
- running（运行状态，0/1）
- 时间间隔（秒）

**计算步骤**:
1. 计算每个时间点的运行时长增量: `dT = running × dt / 3600` (小时)
2. 累计求和: `T = Σ dT`

**应用价值**:
- ✅ 维护计划
- ✅ 寿命预测
- ✅ 设备管理

**数据可用性**: ✅ 需要从fact_measurements获取running状态
