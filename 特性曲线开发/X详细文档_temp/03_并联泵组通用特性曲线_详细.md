### 核心原理：并联特性

并联泵组的核心特性：
- **流量叠加**：Q_total = Q₁ + Q₂ + ... + Q_N（在相同扬程下）
- **扬程相同**：H₁ = H₂ = ... = H_N = H_system（并联泵扬程相同）
- **功率叠加**：P_total = P₁ + P₂ + ... + P_N
- **效率计算**：η_total = (ρgQ_totalH_system) / P_total

## 📖 详细曲线清单

### 1. N台并联Q-H曲线

#### 基本信息

**说明**: N台泵并联运行时的Q-H曲线，是泵组最基本的特性曲线

**依赖指标**:
- pump_flow_rate（各泵流量，m³/h）
- pump_head（各泵扬程，m）
- device_running（各泵运行状态）
- 或main_pipeline_flow_rate（主管道流量，m³/h）

**拟合可行性**: ✅ 可拟合
- 数据完全可用
- 数据量：2台并联数据充足（99.31%的时间）
- 数据质量：良好
- 覆盖范围：流量范围覆盖从低负荷到高负荷

#### 拟合方法

**1. 数学方法**：
- **流量叠加法**：Q_total = Q₁ + Q₂ + ... + Q_N，H_total = H₁ = H₂ = ... = H_N
  - 优点：物理意义明确
  - 缺点：需要各泵独立的Q-H曲线
  - 适用场景：各泵特性已知
  
- **直接拟合**：H_N = a₀ + a₁Q_total + a₂Q_total²（N台并联）
  - 优点：简单直接
  - 缺点：未利用单泵特性
  - 适用场景：数据量充足

**2. 物理机理模型**：
- **并联特性方程**：在相同扬程H下，Q_total = N × Q_single
  - 假设：各泵特性相同
  - 优点：简单实用
  - 缺点：实际各泵可能有差异

**3. 机器学习方法**：
- **XGBoost**：输入(Q_total, N)，输出H
  - 参数设置：n_estimators=100-500, max_depth=5-10

**4. 深度学习方法**：
- **MLP**：输入(Q_total, N)，输出H

#### 应用价值

**用途**：泵组性能评估、泵组选型、运行优化

**功能**：
- 预测N台并联时的Q-H特性

**解决的问题**：

- 泵组能否满足需求？（性能评估）

**应用示例**：
- 台数选择：根据流量需求，选择合适的并联台数
- 性能预测：预测N台并联时的扬程
- 运行优化：选择最优并联台数，提高效率

**量化收益**：
- 台数优化：选择合适的并联台数，效率提升5-15%
- 性能预测：准确预测性能，避免选择不当
- 运行优化：优化并联台数，节能5-15%

#### 数据要求

**数据类型**：pump_flow_rate、pump_head、device_running、main_pipeline_flow_rate

**数据量要求**：
- 最小：每种并联台数至少100个数据点
- 推荐：每种并联台数500-1000个数据点
- 理想：每种并联台数>5000个数据点

**数据时间跨度**：
- 最小：1周（覆盖多种并联台数）
- 推荐：1个月（覆盖并联台数变化全范围）
- 理想：3个月（覆盖季节性变化）

**数据覆盖范围**：
- 必须覆盖：常用并联台数（2台、3台）
- 推荐覆盖：所有可能的并联台数（1-6台）
- 理想覆盖：包括启停过程

**数据质量要求**：
- 数据完整性：缺失率<5%

- 流量分布：每种并联台数下，流量在20%-100%范围内均匀分布

#### 精度提升方法

**物理约束**：
- 流量叠加：Q_total = Q₁ + Q₂ + ... + Q_N
- 扬程相同：H₁ = H₂ = ... = H_N
- 单调性约束：H随Q_total单调递减

**机理特性**：
- 并联特性：在相同扬程下，流量叠加
- 单泵特性：利用单泵Q-H曲线推导并联曲线

**边界条件**：
- 最大流量：Q_max(N) ≤ N × Q_max(1)
- 最小扬程：H_min(N) ≥ 0.5 × H_rated

**多变量关联**：
- Q-H-N关联：H = f(Q_total, N)
- 单泵关联：利用单泵Q-H曲线

**数据预处理**：
- 并联台数识别：根据device_running识别并联台数
- 流量汇总：Q_total = Σ pump_flow_rate
- 异常值检测：检测违反并联特性的异常值

**模型融合**：
- 单泵特性 + 并联特性：先拟合单泵Q-H曲线，再用并联特性推导
- 物理模型 + 数据驱动：结合并联特性和机器学习

**正则化技术**：
- 并联特性正则化：在损失函数中加入并联特性约束
- L2正则化：防止系数过大

**集成学习**：
- 单泵特性 + XGBoost：先用单泵特性，再用XGBoost拟合残差
- Stacking：元模型集成
