### 核心原理：相似定律

变频泵特性曲线族的核心是**相似定律**：
- **流量**：Q₁/Q₂ = n₁/n₂ = f₁/f₂
- **扬程**：H₁/H₂ = (n₁/n₂)² = (f₁/f₂)²
- **功率**：P₁/P₂ = (n₁/n₂)³ = (f₁/f₂)³
- **效率**：η₁ ≈ η₂（效率基本不变）

其中：
- n：转速（rpm）
- f：频率（Hz），n ∝ f
- Q：流量（m³/h）
- H：扬程（m）
- P：功率（kW）
- η：效率（%）

### 1. 不同转速下的Q-H曲线族

#### 基本信息

**说明**: 变频泵在不同频率（转速）下的Q-H曲线，是变频泵最重要的特性曲线族

**依赖指标**:
- pump_frequency（泵频率，Hz）
- pump_flow_rate（泵流量，m³/h）
- pump_head（泵扬程，m）

**拟合可行性**: ✅ 可拟合
- 数据完全可用
- 数据量：设备1,2,4,6数据点>25,000，覆盖多种频率
- 数据质量：良好
- 频率覆盖：设备1,2,3,6频率标准差较大（2.58-4.09），覆盖多种转速

#### 拟合方法

**1. 数学方法**：
- **分频率拟合**：对每个频率f，拟合H = a₀(f) + a₁(f)Q + a₂(f)Q²
  - 优点：简单直接，每个频率独立拟合
  - 缺点：未利用相似定律，数据利用率低
  - 适用场景：频率变化范围小
  - 参数设置：对每个频率单独拟合2次或3次多项式
  
- **联合拟合**：H = (a₀ + a₁f + a₂f²) + (b₀ + b₁f)Q + (c₀ + c₁f)Q²
  - 优点：利用所有频率的数据，数据利用率高
  - 缺点：模型复杂，参数多
  - 适用场景：频率变化范围大，数据量充足
  - 参数设置：使用最小二乘法或梯度下降求解

**2. 物理机理模型**：
- **相似定律**：H₁/H₂ = (f₁/f₂)²
  - 优点：物理意义明确，参数少
  - 缺点：假设严格的相似性，实际可能有偏差
  - 适用场景：理论分析、初步估算
  
- **基准曲线法**：先拟合50Hz的Q-H曲线，再用相似定律推导其他频率
  - 方法：H(Q, f) = H(Q×50/f, 50) × (f/50)²
  - 优点：简单实用，物理一致性好
  - 缺点：假设相似定律严格成立
  - 适用场景：大多数变频泵

**3. 机器学习方法**：
- **梯度提升树（XGBoost）**：输入(Q, f)，输出H
  - 优点：能处理复杂非线性关系，精度高
  - 缺点：模型可解释性差
  - 适用场景：追求高精度
  - 参数设置：n_estimators=100-500, max_depth=5-10, learning_rate=0.01-0.1
  
- **随机森林回归**：处理非线性关系
  - 优点：不易过拟合
  - 缺点：模型可解释性差
  - 参数设置：n_estimators=100-300, max_depth=10-20

**4. 深度学习方法**：
- **多层感知机（MLP）**：输入(Q, f)，输出H
  - 优点：能拟合任意复杂关系
  - 缺点：需要大量数据，容易过拟合
  - 参数设置：hidden_layers=[64,32,16], activation='relu', optimizer='adam'
  
- **物理信息神经网络（PINN）**：在损失函数中加入相似定律约束
  - 优点：结合物理约束和数据驱动，精度高，泛化能力强
  - 缺点：实现复杂
  - 参数设置：Loss = MSE + λ × 相似定律约束
  - 相似定律约束：|H(Q,f) - H(Q×50/f, 50)×(f/50)²| < ε

#### 应用价值

**用途**：变频调节、性能预测、运行优化

**功能**：
- 预测任意频率下的Q-H特性
- 指导变频调节（选择合适的频率）
- 评估变频范围（最小/最大频率）
- 优化运行工况（选择最优频率）

**解决的问题**：

- 不同频率下性能如何？（性能预测）
- 如何通过变频满足不同需求？（变频调节）
- 变频范围是多少？（范围确定）

**应用示例**：
- 变频调节：根据流量需求Q_target，选择合适的频率f，使得H(Q_target, f) = H_required
- 性能预测：预测任意频率下的扬程，如f=40Hz时，Q=500 m³/h的扬程

#### 精度提升方法

**物理约束**：
- 相似定律约束：H₁/H₂ = (f₁/f₂)²
- 单调性约束：对于固定频率，H随Q单调递减
- 边界条件：Q=0时H=H₀(f)，H₀(f) ∝ f²

**机理特性**：
- 相似定律：H ∝ f²，Q ∝ f
- 基准曲线：50Hz的Q-H曲线是基准，其他频率通过相似定律推导
- 曲线形状：不同频率下的Q-H曲线形状相似

**边界条件**：
- 频率范围：10Hz ≤ f ≤ 50Hz
- 扬程范围：H_min(f) ≤ H ≤ H₀(f)
- 流量范围：0 ≤ Q ≤ Q_max(f)

**多变量关联**：
- Q-H-f关联：H = f(Q, f)，利用相似定律
- 基准曲线关联：H(Q, f) = H(Q×50/f, 50) × (f/50)²
- 多频率联合拟合：同时拟合所有频率的数据，确保相似定律成立

**数据预处理**：
- 频率分组：按频率分组，每组单独拟合Q-H曲线
- 相似定律归一化：将所有数据归一化到50Hz，Q' = Q×50/f，H' = H×(50/f)²
- 异常值检测：检测违反相似定律的异常值
- 特征工程：添加Q²、f²、Q×f等特征

**模型融合**：
- 基准曲线法：先拟合50Hz的Q-H曲线，再用相似定律推导其他频率
- 物理信息神经网络：在损失函数中加入相似定律约束
- 分组拟合 + 相似定律：每个频率单独拟合，再用相似定律平滑

**正则化技术**：
- 相似定律正则化：在损失函数中加入相似定律约束
- L2正则化：防止系数过大
- 交叉验证：选择最优参数

**集成学习**：
- 基准曲线 + 残差拟合：先用相似定律，再用XGBoost拟合残差
- 多频率集成：每个频率单独拟合，加权平均
- Stacking：元模型集成

### 2. 不同转速下的Q-P曲线族

#### 基本信息

**说明**: 变频泵在不同频率（转速）下的Q-P曲线，描述流量与功率的关系，是能耗分析和节能评估的基础

**依赖指标**:
- pump_frequency（泵频率，Hz）
- pump_flow_rate（泵流量，m³/h）
- pump_active_power（泵有功功率，kW）

**拟合可行性**: ✅ 可拟合
- 数据完全可用：pump_frequency、pump_flow_rate、pump_active_power数据充足
- 数据量：与Q-H曲线族相同
- 数据质量：良好
- 覆盖范围：频率20-50Hz，流量0-3000 m³/h，功率0-200 kW

#### 拟合方法

**1. 数学方法**：
- **分频率拟合**：对每个频率f，拟合P = b₀(f) + b₁(f)Q + b₂(f)Q² + b₃(f)Q³
  - 优点：简单直接，每个频率独立拟合
  - 缺点：未利用相似定律，数据利用率低
  - 适用场景：频率变化范围小
  - 参数设置：对每个频率单独拟合3次多项式

- **联合拟合**：P = (b₀ + b₁f + b₂f²) + (c₀ + c₁f)Q + (d₀ + d₁f)Q² + (e₀ + e₁f)Q³
  - 优点：利用所有频率的数据，数据利用率高
  - 缺点：模型复杂，参数多
  - 适用场景：频率变化范围大，数据量充足
  - 参数设置：使用最小二乘法或梯度下降求解

**2. 物理机理模型**：
- **相似定律**：P₁/P₂ = (f₁/f₂)³
  - 优点：物理意义明确，参数少
  - 缺点：假设严格相似，实际可能有偏差
  - 适用场景：理论分析、初步估算

- **基准曲线法**：先拟合50Hz的Q-P曲线，再用相似定律推导其他频率
  - 方法：P(Q, f) = P(Q×50/f, 50) × (f/50)³
  - 优点：简单实用，物理意义明确
  - 缺点：假设相似定律严格成立
  - 适用场景：快速估算

**3. 机器学习方法**：
- **XGBoost**：输入(Q, f)，输出P
  - 优点：精度高，能处理复杂非线性关系
  - 缺点：可能不满足相似定律
  - 参数设置：n_estimators=100-500, max_depth=5-10, learning_rate=0.01-0.1

- **随机森林**：输入(Q, f)，输出P
  - 优点：不易过拟合
  - 缺点：模型可解释性差
  - 参数设置：n_estimators=100-500, max_depth=10-20

**4. 深度学习方法**：
- **PINN（物理信息神经网络）**：结合相似定律约束
  - 损失函数：L = L_data + λ × L_physics
  - L_physics = |P₁/P₂ - (f₁/f₂)³|²
  - 优点：结合物理约束和数据驱动，精度高
  - 缺点：训练复杂
  - 参数设置：hidden_layers=[64,32,16], λ=0.1-1.0

### 3. 不同转速下的Q-η曲线族

#### 基本信息

**说明**: 变频泵在不同频率（转速）下的Q-η曲线，描述流量与效率的关系，是效率优化和BEP识别的基础

**依赖指标**:
- pump_frequency（泵频率，Hz）
- pump_flow_rate（泵流量，m³/h）
- pump_efficiency（泵效率，%）

**拟合可行性**: ✅ 可拟合
- 数据完全可用：pump_frequency、pump_flow_rate、pump_efficiency数据充足
- 数据量：与Q-H曲线族相同
- 数据质量：良好
- 覆盖范围：频率20-50Hz，流量0-3000 m³/h，效率0-100%

#### 拟合方法

**1. 数学方法**：
- **分频率拟合**：对每个频率f，拟合η = c₀(f) + c₁(f)Q + c₂(f)Q² + c₃(f)Q³ + c₄(f)Q⁴
  - 优点：简单直接，每个频率独立拟合
  - 缺点：未利用相似定律（η基本不变）
  - 适用场景：频率变化范围小
  - 参数设置：对每个频率单独拟合4次多项式

- **高斯函数拟合**：η(Q, f) = η_max × exp(-((Q-Q_BEP(f))²/(2σ(f)²)))
  - Q_BEP(f) = Q_BEP(50) × (f/50)（BEP流量随频率线性变化）
  - η_max基本不变（相似定律）
  - σ(f) = σ(50) × (f/50)（曲线宽度随频率线性变化）
  - 优点：符合效率曲线的钟形特性，利用相似定律
  - 缺点：对称性假设可能不完全准确
  - 适用场景：大多数泵的效率曲线

**2. 物理机理模型**：
- **相似定律**：η₁ ≈ η₂（效率基本不变）
  - 优点：物理意义明确
  - 缺点：实际可能有小幅变化（±2-5%）
  - 适用场景：理论分析、初步估算

- **基准曲线法**：先拟合50Hz的Q-η曲线，假设其他频率的效率曲线形状相同
  - 方法：η(Q, f) = η(Q×50/f, 50)
  - 优点：简单实用
  - 缺点：假设效率完全不变
  - 适用场景：快速估算

**3. 机器学习方法**：
- **XGBoost**：输入(Q, f)，输出η
  - 优点：精度高，能捕捉效率的微小变化
  - 缺点：可能不满足相似定律
  - 参数设置：n_estimators=100-500, max_depth=5-10

**4. 深度学习方法**：
- **PINN（物理信息神经网络）**：结合相似定律约束
  - 损失函数：L = L_data + λ × L_physics
  - L_physics = |η₁ - η₂|²（效率基本不变）
  - 优点：结合物理约束和数据驱动
  - 缺点：训练复杂
  - 参数设置：hidden_layers=[64,32,16], λ=0.1-1.0

#### 应用价值

**用途**：
- 效率预测：预测不同频率和流量下的效率

### 11. 节能曲线

#### 基本信息

**说明**: 对比变频运行和工频运行的节能效果，用于节能效果评估和投资回报分析

**依赖指标**:
- pump_frequency（泵频率，Hz）
- pump_active_power（泵有功功率，kW）
- pump_flow_rate（泵流量，m³/h，可选）

**拟合可行性**: ✅ 可拟合
- 数据完全可用
- 可基于相似定律计算

#### 拟合方法

**1. 数学方法**：
- **节能率计算**：节能率 = (P_50Hz - P_f) / P_50Hz × 100%
  - 优点：简单直接
  - 缺点：需要同时有50Hz和变频的数据
  - 适用场景：对比分析

- **基于相似定律**：P_f = P_50Hz × (f/50)³
  - 节能率 = 1 - (f/50)³
  - 优点：只需要50Hz的数据，即可预测变频节能效果
  - 缺点：假设严格相似
  - 适用场景：快速估算

**2. 物理机理模型**：
- **能耗对比模型**：
  - 工频能耗：E_50Hz = P_50Hz × t
  - 变频能耗：E_f = P_f × t = P_50Hz × (f/50)³ × t
  - 节能量：ΔE = E_50Hz - E_f = P_50Hz × t × (1 - (f/50)³)
  - 优点：物理意义明确
  - 缺点：假设运行时间相同

**3. 机器学习方法**：
- **回归分析**：输入f，输出节能率
  - 使用历史数据拟合节能率曲线
  - 优点：基于实际数据
  - 缺点：需要大量历史数据

#### 应用价值

**用途**：
- 节能效果评估：评估变频改造的节能效果
- 投资回报分析：计算投资回报期
- 运行成本分析：对比变频和工频的运行成本
- 节能潜力分析：评估不同频率的节能潜力
- 决策支持：为变频改造提供决策依据

**功能**：
- 计算节能率：节能率 = 1 - (f/50)³
- 计算节能量：ΔE = P_50Hz × t × (1 - (f/50)³)
- 计算节能成本：节能成本 = ΔE × 电价
- 计算投资回报期：回报期 = 变频器投资 / 年节能成本

**解决的问题**：
- 变频能节省多少能耗？（节能效果评估）

**应用示例**：

- 节能潜力：评估不同频率的节能率，选择最优频率
- 成本对比：计算年运行成本，对比变频和工频

**量化收益**：

  - f=35Hz：节能率≈66%，年节能成本降低66%

### 拟合步骤

1. **数据准备**：收集pump_frequency、pump_flow_rate、pump_head、pump_active_power、pump_efficiency数据
2. **数据清洗**：删除异常值、缺失值
3. **频率分组**：按频率分组，每组至少50个数据点
4. **基准曲线拟合**：先拟合50Hz的Q-H/Q-P/Q-η曲线
5. **相似定律验证**：验证相似定律是否成立
6. **多频率拟合**：使用基准曲线法或联合拟合，拟合所有频率的曲线
7. **模型评估**：评估模型精度（R²、RMSE、MAE）
8. **模型应用**：将模型应用于实时监测、变频调节、运行优化

### 预期精度

- **基准曲线法**：R² > 0.92（假设相似定律严格成立）
- **联合拟合**：R² > 0.94（考虑相似定律偏差）
- **XGBoost**：R² > 0.96（高精度拟合）
- **PINN**：R² > 0.97（结合物理约束和数据驱动）

变频泵特性曲线族是变频调节和优化的基础，包括22条曲线。通过拟合这些曲线，可以：

- ✅ 评估节能效果，量化节能收益
- ✅ 优化启动和调节策略，提高响应速度

建议优先拟合第1-7条和第11-12条曲线（核心曲线），使用基准曲线法或PINN方法，结合相似定律约束，可以获得高精度的拟合结果（R² > 0.95）。

**核心公式**：
- Q₁/Q₂ = f₁/f₂
- H₁/H₂ = (f₁/f₂)²
- P₁/P₂ = (f₁/f₂)³
- η₁ ≈ η₂
