### 核心原理

全变频泵组的核心特性：
- **频率可调**：每台泵的频率可独立调节
- **并联特性**：流量叠加、扬程相同（与并联泵组相同）
- **相似定律**：每台泵满足Q ∝ f，H ∝ f²，P ∝ f³
- **协调控制**：多台泵频率协调，实现最优运行

## 📖 详细曲线清单

### 1-3. 全变频泵组Q-H/Q-P/Q-η曲线

**第1条：全变频泵组Q-H曲线**
- **说明**：N台变频泵并联运行时的Q-H曲线（考虑各泵频率可能不同）
- **依赖指标**：pump_frequency（各泵）、pump_flow_rate（各泵）、pump_head（各泵）
- **拟合方法**：
  - 流量叠加法：Q_total = Σ Q_i，H = H_i（各泵扬程相同）
  - 联合拟合：H = f(Q_total, f₁, f₂, ..., f_N)
  - XGBoost：输入(Q_total, f₁, f₂, ..., f_N)，输出H
- **应用价值**：性能预测、频率优化、运行优化
- **量化收益**：优化各泵频率，效率提升10-20%，节能10-30%

**第2条：全变频泵组Q-P曲线**
- **说明**：N台变频泵并联运行时的Q-P曲线
- **依赖指标**：pump_frequency（各泵）、pump_flow_rate（各泵）、pump_active_power（各泵）
- **拟合方法**：功率叠加法（P_total = Σ P_i）、联合拟合、XGBoost
- **应用价值**：功率预测、能耗分析、频率优化
- **量化收益**：优化各泵频率，降低总功率10-30%

**第3条：全变频泵组Q-η曲线**
- **说明**：N台变频泵并联运行时的Q-η曲线
- **依赖指标**：pump_efficiency（各泵）、pump_flow_rate（各泵）
- **拟合方法**：效率计算（η_total = ρgQ_totalH / P_total）、联合拟合、XGBoost
- **应用价值**：效率评估、频率优化、运行优化
- **量化收益**：优化各泵频率，效率提升10-20%

### 4-9. 全变频泵组频率协调策略和频率分配曲线

**第4条：全变频泵组频率协调策略曲线**
- **说明**：多台变频泵之间的频率协调策略（如等频率、主从控制、优化分配）
- **依赖指标**：pump_frequency（各泵）、pump_flow_rate（各泵）、pump_efficiency（各泵）
- **拟合方法**：
  - 等频率策略：f₁ = f₂ = ... = f_N
  - 主从控制：f_slave = k × f_master
  - 优化分配：求解f₁, f₂, ..., f_N使得η_total最大或P_total最小
- **应用价值**：协调控制、效率提升、能耗降低
- **量化收益**：优化频率协调策略，效率提升5-15%，节能5-20%

**第5条：全变频泵组频率分配曲线**
- **说明**：在给定总流量需求下，各泵的最优频率分配
- **依赖指标**：pump_frequency（各泵）、main_pipeline_flow_rate
- **拟合方法**：优化算法（求解f₁, f₂, ..., f_N使得Q_total = Q_target且η_total最大）
- **应用价值**：频率优化、效率提升
- **量化收益**：最优频率分配，效率提升10-20%

**第6-9条：频率上下限、频率波动、频率切换、频率-流量分配曲线**
- **核心要点**：
  - 频率上下限：确定各泵的最小/最大频率
  - 频率波动：评估频率稳定性
  - 频率切换：优化频率切换过程
  - 频率-流量分配：在不同频率组合下的流量分配
- **应用价值**：频率控制、稳定性提升、切换优化
- **量化收益**：优化频率控制，减少波动30-50%，提高稳定性
