# 文档同步

自动同步代码变更到文档系统,保持文档最新。

## 同步步骤

1. **扫描Git变更**
   ```bash
   git diff --name-status HEAD~1
   ```

2. **识别变更类型**
   - 代码变更 (app/*.py)
   - 配置变更 (configs/*.yaml)
   - 数据库变更 (scripts/sql/*.sql)
   - 文档变更 (docs/*.md)

3. **分析变更内容**
   ```bash
   git diff HEAD~1
   ```

4. **更新对应的PLAYBOOKS条目**
   根据变更类型,更新:
   - docs/PLAYBOOKS/改进与优化记录.md (代码变更)
   - docs/PLAYBOOKS/配置变更记录.md (配置变更)
   - docs/PLAYBOOKS/数据库变更记录.md (数据库变更)
   - docs/PLAYBOOKS/错误与修复记录.md (BUG修复)
   - docs/PLAYBOOKS/决策记录.md (重要决策)

5. **检查CLAUDE.md是否需要更新**
   - 新增API/函数需要在快速参考中体现
   - 架构变更需要更新目录结构
   - 新增配置需要更新配置说明

6. **更新代码索引** (如果存在)
   ```bash
   python scripts/tools/gen_code_index.py
   ```

7. **记录关键决策到Memory**
   使用Memory MCP记录:
   - 新增的重要函数/类
   - 关键阈值配置
   - 架构决策
   - 经验教训

8. **生成本次变更摘要**

## 使用注意事项

- 此Skill应在每次重要提交后运行
- 确保Memory MCP工具可用
- 如果代码索引脚本不存在,可跳过步骤6
- 重点关注架构性变更和重要决策的记录
