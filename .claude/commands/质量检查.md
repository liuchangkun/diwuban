# 质量检查

运行完整的代码质量检查流程:

## 检查步骤

1. **代码风格检查**
   ```bash
   ruff check app/
   ```

2. **代码格式检查**
   ```bash
   black app/ --check
   ```

3. **类型检查**
   ```bash
   mypy app/
   ```

4. **运行测试**
   ```bash
   pytest tests/ --tb=short
   ```

5. **检查Git状态**
   ```bash
   git status
   ```

6. **总结所有发现的问题并给出修复建议**

## 输出格式

请按照以下格式输出结果:

```
📊 质量检查报告
================

✅ 代码风格: [通过/失败] (问题数量)
✅ 代码格式: [通过/失败]
✅ 类型检查: [通过/失败] (错误数量)
✅ 单元测试: [通过/失败] (通过/总计)
✅ Git状态: [干净/有未提交文件]

🔧 需要修复的问题:
1. [问题描述]
   修复建议: [具体建议]

📝 总结:
[整体评估和下一步建议]
```
